677〜680 全体像 公転図・季節と太陽光・昼の長さ 4問

4問とも図を読む問題で、入口は1つ。太陽の光がどちらから当たっているかを先に決める。光が横から当たれば春分・秋分、北極側から当たれば夏至、南極側から当たれば冬至。

季節が決まれば、あとは「太陽が真上に来る緯度（春分・秋分＝赤道、夏至＝北回帰線）」と「昼が長い場所は日の出が早く、日の入りが遅い」の2行で全部の小問が決まる。

677 春分・夏至・秋分・冬至 公転図で季節の位置を選ぶ 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「地球の公転図」と、各地球の「北極」の印。北極が太陽の方へ傾いている地球に丸 → そこが夏至。左右の図で地軸の傾く向きがちがうので、正体を1行書いてから矢印をたどる。

📚 前提知識

  • 地軸は公転面に対して23.4度傾いたまま、向きを変えずに公転する。北極が太陽側＝夏至、反対側＝冬至、横向き＝春分・秋分。
  • 公転の向きは図の矢印。季節は 夏至→秋分→冬至→春分 の順にめぐる。

🔍 こう読み解く

  1. 左の図：北極の印はどの地球も左上。太陽が北極側（左）にあるのは右のD＝夏至、反対のB＝冬至。
  2. 矢印は上が左向き、下が右向き（D→A→B→C→D）。Dの次のA＝秋分、Bの次のC＝春分。
  3. 右の図：北極の印は右上。太陽が北極側（右）にあるのは左のF＝夏至、反対のH＝冬至。矢印をたどって、Fの次のG＝秋分、Hの次のE＝春分。
答え：春分 C・E　夏至 D・F　秋分 A・G　冬至 B・H
コツ：地球の中の斜線（夜）で決めようとすると向きに迷う。先に「北極の印の向き」と「太陽」だけを見て夏至を1つ決め、残りは矢印の順で置く。

678 ① 春分・秋分の日の太陽高度の順 資料問題・順番

👀 まず見るところ

【資料問題】部品は図の正体「春分・秋分の日の太陽光」＝光が横から地軸と直角に当たる図、と聞かれ方「高度が高い順」。光の矢印が地面に垂直にささる場所（C＝赤道）に丸 → そこが90度、離れるほど低い。

📚 前提知識

  • 春分・秋分の日は赤道で太陽高度が90度になり、最も高い（◆ポイント◆）。赤道から南北に離れた分だけ、南中高度は低くなる。
  • 赤道から同じだけ離れていれば、北緯でも南緯でも高度は同じ。

🔍 こう読み解く

  1. Cは赤道 → 90度で最高。
  2. BとDは赤道をはさんで上下対称の点線 → 離れ方が同じなので同じ高度。AとEも同じ。
  3. 赤道から遠いほど低いので、C＞B＝D＞A＝E。
答え：C＞B＝D＞A＝E

📚 前提知識

680 ①A・B・C 日の出が早いのはX・Yのどちらか 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「同じたて線（同じ経度）の上の地点X・Y」と、A・B・Cそれぞれの「太陽の光」の向き。A＝横から（春分・秋分）、B＝北極側から（夏至）、C＝南極側から（冬至）と図に書く → 「昼が長い方が日の出が早い」に直して決める。

📚 前提知識

  • 同じ経度なら、春分・秋分の日は日の出・日の入り・南中の時刻が同じ（◆ポイント◆）。
  • 夏至・冬至では昼の長さが緯度でちがう。同じ経度でも昼が長い方が日の出が早く、日の入りが遅い（◆ポイント◆）。Xは北半球、Yは赤道で、赤道の昼は1年中12時間。

🔍 こう読み解く

  1. A：光が横から → XもYも昼は12時間 → 日の出は同じ。
  2. B：北極側が明るい夏至 → 北半球のXの昼が12時間より長い → 日の出が早いのはX。
  3. C：南極側が明るい冬至 → Xの昼が12時間より短い → 日の出が早いのはY。
答え：A 同じ　B X　C Y

📚 前提知識

  • 太陽が南中するのは、その地点のたて線（経線）が太陽の正面に来たとき。同じ経度なら南中時刻は季節に関係なく同じ（◆ポイント◆）。

🔍 こう読み解く

  2. 季節（光の向き）が変わっても、南中の時刻は3つとも同じ。①③と同じ答えにしないよう、小問ごとに聞かれ方を見直す。

680 ③A・B・C 日の入りが早いのはX・Yのどちらか 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】部品は①と変わった聞かれ方「日の入りが早い」に丸。「昼が長い方は日の入りが遅い」に直して書く → ①の答えをXとYで入れかえるだけになる。

  • 南中時刻が同じで昼が長いなら、日の出は早く、日の入りは遅い。昼の長さは南中をはさんで前後に同じだけのびる。

🔍 こう読み解く

  2. B：Xの昼が長い → Xは日の入りが遅い → 早いのはY。

677〜680 まとめ 入口は光の向き

  • どの図も、最初に太陽の光がどちらから当たるかを書く。横＝春分・秋分、北極側＝夏至、南極側＝冬至。公転図なら「北極が太陽を向く地球＝夏至」から矢印順。
  • 太陽が真上（90度）に来る線：春分・秋分＝赤道、夏至＝北回帰線（北緯23.4度）。そこから離れるほど高度は低い。昼の長さは夏至なら北ほど長く、北極線（北緯66.6度）から上は1日中昼。
  • 同じ経度なら南中はいつも同じ時刻。昼が長い方が日の出が早く、日の入りは遅い。

681〜688 全体像 月から見た地球・月の出入り・日食と月食 8問

前半（681〜684）は「月に立って見る」問題。地球から月を見るときの決まりを、見る側と見られる側を入れかえて使う。681は図、682〜684は一問一答で、どれも「月は地球にいつも同じ面を向けている」「月には大気がない」の2つから決まる。

681 A・B・C・D・E・F・G・H 月から見た地球の形 資料問題・図から決める

👀 まず見るところ

【資料問題】部品は図の正体「北極の側から見た地球と月の位置A〜H・太陽の光は右から」と聞かれ方「月から地球を見たときの地球の形」。地球の右半分（太陽側）を「光る半分」として図に塗る → 各位置から光る半分がどれだけ見えるかで形が決まる。

📚 前提知識

  • 地球も月も、光るのは太陽に向いた半分だけ。図では右から光が来るので、地球の右半分が昼。
  • 地球から見た月の「光る部分」と、月から見た地球の「光る部分」は、合わせるとちょうどまん丸1つ分。つまり月から見た地球の形は、地球から見た月の暗い部分の形と同じ。上弦（右半分が光る）の位置なら、地球は左半分が光って見える。

🔍 こう読み解く

  1. 太陽と地球の間にあるC（新月の位置）からは、地球の光る半分が全部こちらを向く → C＝い（まん丸）。反対側のG（満月の位置）からは暗い半分しか見えない → G＝あ（見えない）。
  2. AとEは光る半分の半分が見える＝半月の形。Aは上弦の位置（月は右半分が光る）なので、地球はその逆の左半分＝う。Eは下弦の位置なので右半分＝え。
  3. 残りは「い寄りか、あ寄りか」で太さを決める。BとDはCの両どなりなのでまん丸に近い（き・く）、HとFはGの両どなりなので細い（か・お）。光る側はとなりの半月と同じ。B・HはAと同じ左側 → B＝き、H＝か。D・FはEと同じ右側 → D＝く、F＝お。
答え：A う　B き　C い　D く　E え　F お　G あ　H か
コツ：まずC（い）とG（あ）を決め、次にA・Eの半月、最後にその間を太いか細いかで埋める。8つを順にたどるより速く、左右もまちがえにくい。

682 ①・②・③ 月から見た地球の満ち欠けの周期と向き 知識問題

①29.5日。地球から見た月の満ち欠け（新月→次の新月）が約29.5日で、月から見た地球はその光る部分と対になっている（681）ので、周期も同じになる。②③どちらも右（西）。光る側はいつも太陽のある側で、太陽が空を東から西へ動くのは月面でも同じ。だから地球から見た月と同じように、右（西）側から満ちて、満ちきったあと右（西）側から欠ける。
答え：① 29.5　② 右（西）　③ 右（西）

683 ① 月の裏側から地球を見ることはできるか 知識問題

できません。月は地球に対していつも同じ面（表側）を向けているので、裏側に立つと地球は一度も空に出てこない。裏側の様子が分かったのは、探査機が回りこんで写してからのこと。
答え：できません

683 ②・③ 表側から見た地球が動かない理由 知識問題

②は位置（方角）。月の表側から見ると、地球はいつも空の同じところに見え、時間がたっても動かない（満ち欠けだけが変わる）。③その理由は、月の自転と公転の周期と向きが等しいから。月が地球のまわりを1周する間に、月自身もちょうど1回転するので、同じ面がずっと地球を向いたままになる。記述では「周期」と「向き」の2語を落とさずに書く。
答え：② 位置（方角）　③ 月の自転と公転の周期と向きが等しいから

684 ①・② 月面の昼の空 知識問題

①大気、②暗く。地球の昼の空が明るい（青い）のは、大気が太陽の光を散らばらせて空全体から光が来るため。月には大気がないので光が散らばらず、太陽の出ている昼でも空は暗い（黒い）ままで、星も見える。「大気がない」から決まることは他にもあり、音が伝わらない・風化がない・昼と夜の温度差が大きい、も同じ理由。
答え：① 大気　② 暗く

684 ③ 月における1日の長さ 知識問題

29.5日。月は地球に同じ面を向けたまま回るので、月面のある場所で太陽が出てから次に出るまでは、地球から見た月の満ち欠け1周（新月→次の新月）と同じ長さになる。月の昼は約15日、夜も約15日と考えると、温度差が大きい理由にもつながる。
答え：29.5

685 ① 9月25日に出た月は何時間何分後に沈んだか 資料問題・時刻の計算

685 ② 9月26日に月が出ていたのは何時間何分か 資料問題・時刻の計算

👀 まず見るところ

718 ① 水蒸気が雲になるときに出るもの 知識問題

熱（凝縮熱）。あたためられた海水から出た水蒸気が上空で水てきに変わる（凝縮する）とき、持っていた熱をまわりに出す。この熱が空気をさらにあたためて上昇気流を強め、台風の力のもとになる。「海水→水蒸気→雲になるときの熱」の流れで覚える。
答え：熱（凝縮熱）
