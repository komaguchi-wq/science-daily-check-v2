136 アブラナの写真のAの部分 資料問題・写真

👀 まず見るところ

【資料問題】部品は写真の正体「①のアブラナ」と、Aの場所＝茎の下の方・花びらが無い細長いふくらみに丸。「Aの内部」の写真で中に丸い粒がぎっしり → 受粉のあとの子房と決まる。

📚 前提知識

  • 受粉すると、めしべの根元の子房が実に、中の胚珠が種子になる。実になりかけの子房の中には、未熟な種子（胚珠）がたくさん入っている。
  • アブラナの種子は脂肪分が多く、菜種油として使われる（巻末解説）。

🔍 こう読み解く

  1. Aは、花びらもおしべも落ちた細長いさや。上の花と同じ茎についているので、花だったものがこうなった、と読む。
  2. 「Aの内部」を見ると、さやの中に丸い粒が並んでいる。粒＝未熟な種子（胚珠）なので、Aは受粉してしばらくたった子房。
  3. 答えには「子房」だけでなく、写真から分かる「中に未熟な種子がたくさん入っている」も入れる。
答え：受粉してしばらくたったあとの子房であり、中に未熟な種子がたくさん入っている。
コツ：「子房」の1語で止めない。「Aの内部」の写真がついているのは、中身まで書かせるため。

137 アブラナの花が下から順に咲くと分かる特徴 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は聞かれ方「下の方から順に咲くことが分かる特徴」に線。写真の上と下を見くらべるのが入口 → 上は黄色い花とつぼみ、下は花びらの無い子房、と2行で置く。

📚 前提知識

  • 茎がのびるとともに、先端に新しいつぼみができていく。だから上ほど若い花。
  • 受粉のあと、花びらやおしべは不要になって枯れ落ちる。アブラナはがくも枯れるが、がくが「へた」として残る植物もある（巻末解説）。

🔍 こう読み解く

  1. 写真の上：新しいつぼみと開いたばかりの花。花びら・おしべがそろっている。
  2. 写真の下：がくや花びらが散って、子房がふくらんださや（A）になっている。
  3. 「下ほど受粉が終わって先に進んでいる」＝下から順に咲いた、という文にする。答えの中心は「下の花はがく・花びらが散り、子房がふくらんでいる」。
答え：下にある花は、がくや花びらが散り、子房がふくらんでいる。
コツ：「上にはつぼみがある」だけでは半分。聞かれているのは「下の方から咲く」証拠なので、下の花の様子を主語にして書く。

138 ツツジの花粉がマルハナバチにつく理由 資料問題・写真3枚

👀 まず見るところ

【資料問題】部品は写真3枚の正体＝花の奥の方・頭をつっ込むハチ・指についた花粉を1行ずつ置く。聞かれ方は「花粉がつくのはなぜ」→ 理由は「ハチが花の中に入る理由」と「花粉の性質」の2つになる。

📚 前提知識

  • 虫媒花は、蜜で虫を呼び、虫のからだに花粉をつけて運んでもらう。蜜を花の奥に置くと、虫はもぐり込むしかなく、おしべに体がふれる。
  • ツツジは4〜5月に咲く合弁花。花びらの模様めがけて虫が飛んでくる（巻末解説）。

🔍 こう読み解く

  1. 左の写真：おしべの根元、花の奥に甘い蜜がある（巻末解説の「甘い蜜」）。蜜は花の奥にもぐり込まないと得られない位置。
  2. 右上：マルハナバチが頭から花につっ込んでいる。この姿勢で、長くのびたおしべが背中や頭にふれる。
  3. 右下：指につけた花粉が糸を引いている。花粉がねばねばしているので、ふれただけでからだにくっつく。
  4. 理由は2つ：「蜜が奥にあるからもぐり込む」＋「花粉がねばねばしている」。
答え：花の奥の方に蜜があり、花にもぐり込まないと得られない。また、花粉がねばねばしている。
コツ：写真が3枚あるときは、1枚＝理由1つのつもりで読む。指の写真を使わない答えは、まだ部品が足りない。

139 ③ レンゲソウが昆虫に花粉をつけるつくり 資料問題・写真

👀 まず見るところ

【資料問題】部品は写真の正体「③レンゲソウとミツバチ」と聞かれ方「昆虫の体に花粉をつけるためのつくり」。ミツバチの腹の下に出ているおしべに丸 → 「とまると花びらが開いておしべが出る」しかけと決まる。

📚 前提知識

  • レンゲソウはマメ科で4月ごろに咲く。マメ科の花は花びらに包まれたおしべ・めしべが、虫がとまった重みで押し開かれて飛び出す。
  • ◆ポイント◆：ミツバチは後ろあしに花粉をまとめて（花粉だんご）巣に持ち帰り、幼虫のえさにする。はたらきバチはすべてメス（巻末解説）。

🔍 こう読み解く

  1. 写真で、ミツバチは花びらの上にとまり、腹の下に白いおしべがふれている（巻末解説「ミツバチの腹につくおしべ」）。
  2. とまる前はおしべが花びらの中にしまわれている。とまると花びらが開き、おしべが飛び出す → からだにつく。
  3. 後ろあしの黄色いかたまりが花粉だんご。これは持ち帰る分で、受粉に使われるのは腹についた花粉。
答え：ミツバチが花びらにとまると、花びらが開いておしべが飛び出し、ミツバチのからだにつくようになっている。

139 ④ ツユクサが昆虫に花粉をつけるつくり 資料問題・写真2枚

👀 まず見るところ

【資料問題】部品は写真の正体「④ツユクサとハナアブのなかま」の2枚。左は目立つ黄色いおしべと、下に長くのびたおしべ、右（矢印のあと）はアブの腹に花粉がついた状態、と正体を置く → 長いおしべが腹に花粉をつける、と決まる。

📚 前提知識

  • ツユクサは夏に咲く単子葉植物。おしべは2種類あり、黄色く目立つおしべ（短い）で虫を呼び、目立たない長いおしべが花粉をつける（巻末解説の写真のラベル）。
  • ハナアブのなかまは花粉を食べるハエに近い仲間。人をおそわないが、身を守るためにハチに擬態している（巻末解説）。

🔍 こう読み解く

  1. 左の写真：アブは黄色いおしべに引かれて花にとまる。とまる足場になっているのが、下へ長くのびた長いおしべ。
  2. 右の写真：矢印のあと、アブの腹に黄色い花粉がべったりついている。つけたのは足場になった長いおしべ。
  3. 答えは「長いおしべがある（とまりやすい）」＋「とまった虫の腹に花粉が押しつけられる」の2つの部品で組む。
答え：昆虫がとまりやすいように長いおしべがあり、とまった昆虫の腹に花粉が押しつけられるようになっている。
コツ：③と④はどちらも「虫の腹」に花粉をつける。③は花びらが開くしかけ、④は長いおしべの足場、とちがいを1語で言えるか確かめる。

140 ⑤・⑥ 昆虫が来ても花粉が運ばれない理由 資料問題・写真2枚

👀 まず見るところ

【資料問題】部品は聞かれ方「昆虫がきても花粉が運ばれない」に線。2枚とも虫が花の中に入っていないことに丸 → 「どこから蜜を取っているか」を写真ごとに1行置けば理由になる。

📚 前提知識

  • 花粉が運ばれるのは、虫のからだがおしべにふれるとき。花にもぐり込まずに蜜だけ取る虫は、花にとっては「ただ取り」になる。
  • スズメガは空中で静止（ホバリング）しながら、ストロー状の長い口をのばして蜜を吸う（巻末解説）。クマバチ・マルハナバチはミツバチと同じなかまで、他の虫をおそったりはしない（巻末解説）。
  • ◆ポイント◆：逆に、口の長い虫に合わせておしべを長くつき出す花もある（ユリ）。ダーウィンがマダガスカル島で見つけたランは、長さ30cmの管の先に蜜があり、口の長い特定のガだけが花粉を運ぶ。

🔍 こう読み解く

  1. ⑤ツリフネソウ：蜜は花の後ろにのびた袋の先（巻末解説「蜜の入っている部分」）。スズメガは花の前で止まり、長い口だけを入れて吸う → からだがおしべにふれない。
  2. ⑥アベリア：クマバチは花の口から入らず、花の根元に口を刺して穴をあけ、そこから蜜を吸っている（巻末解説「花の根元に口を刺す」） → やはりおしべにふれない。
  3. どちらも理由の骨組みは同じ。「花にもぐり込まずに蜜を吸う → からだに花粉がつかない」。写真ごとに「長い口で」「根元に穴をあけて」を足す。
答え：⑤ 花にもぐり込まずに長い口で蜜を吸うため、スズメガのからだに花粉がつかないから。　⑥ 花にもぐり込まずに口で花の根元に穴をあけ蜜を吸うため、クマバチのからだに花粉がつかないから。
コツ：理由の文は「〜するため、からだに花粉がつかないから」で終える。「蜜を吸うから」だけでは、花粉との関係が書けていない。

141 アサガオが自家受粉を効率よく行うしくみ 資料問題・写真の変化

👀 まず見るところ

【資料問題】部品は写真の正体「開花前→開花後」の2組と、聞かれ方「自家受粉を効率よく」。開花前と後でおしべの長さが柱頭に対してどう変わったかを見くらべる → おしべがのびて柱頭にとどく、と決まる。

📚 前提知識

  • 自家受粉＝同じ花のおしべの花粉が、その花のめしべにつくこと。アサガオはつぼみの中でおしべがのび、花が咲くころには自家受粉が完了している（巻末解説）。
  • 自家受粉はなかまの数を増やせる長所（虫がいなくても確実に種子ができる）があるが、似た性質の子孫が増えて環境の変化に弱い短所がある（巻末解説・142）。

🔍 こう読み解く

  1. 開花前の拡大写真：柱頭は上、おしべは短くて柱頭より下にある（巻末解説「短いおしべ・柱頭」）。
  2. 開花後の拡大写真：おしべが長くのびて、先の花粉が柱頭と同じ高さにある（「長いおしべ・柱頭」）。
  3. つまり、つぼみが開くときにおしべがのびて柱頭にふれ、自分の花粉がつく。これが「効率のよい」しくみ。
答え：つぼみが開くとき、おしべがのびてめしべの柱頭にふれる。
コツ：「前→後」の写真が並んでいたら、変わった部分を1つ言葉にする。ここでは「おしべの長さ」。

142 ソバのAとBの花のつくりの違い 資料問題・写真の比較

👀 まず見るところ

【資料問題】部品は写真の正体「⑧ソバのA・B」と設問の決まり「同じ型どうしでは実をつくらない」に線。A・Bそれぞれでおしべとめしべのどちらが長いかを置く → 長さが逆になっている、と決まる。

📚 前提知識

  • ソバは虫媒花で、自分の花粉では実ができない（自家受粉を防ぐ）。そのためにおしべとめしべの長さが逆の2種類の花を咲かせる。
  • ◆ポイント◆：虫のからだの同じ場所についた花粉は、同じ高さの柱頭につきやすい。だから長いおしべの花粉は長いめしべに、短いおしべの花粉は短いめしべにつき、ちがう型どうしで受粉が進む。
  • 自家受粉はなかまの数を増やせる長所があるが、似た性質の子孫が増えて環境の変化に弱い短所がある（巻末解説）。ソバは他家受粉を選んだ植物。

🔍 こう読み解く

  1. A：ハエがとまっている花。花の外までおしべが長く出て、めしべは中に短い（巻末解説「長いおしべ・短いめしべ」）。
  2. B：まん中からめしべが長くのび、おしべは短く花の中にある（「長いめしべ・短いおしべ」）。
  3. 答えは「Aはおしべ長・めしべ短、Bはおしべ短・めしべ長」と、2つの花を対にして書く。
答え：Aの花はおしべが長くめしべが短いが、Bの花はおしべが短くめしべが長い。
コツ：「長い・短い」を4か所（A のおしべ・めしべ、B のおしべ・めしべ）ぜんぶ書く。片方の花だけ説明した答えは、「違い」に答えていない。

143 ナスの花が実になるまでの写真の並べ替え 資料問題・写真の順番

👀 まず見るところ

【資料問題】部品は写真の正体「ナスの花が実になるまで」と聞かれ方「A〜Fを順番に」。先に最初（つぼみ）と最後（実）を決めて置き、残りを「花びらの開き → しおれ → 子房のふくらみ」の順でつなぐ。

📚 前提知識

  • 花の一生は「つぼみ → 開花 → 受粉 → 花びら・おしべが枯れる → 子房がふくらんで実になる」。ナスの花は花びら5枚の合弁花（巻末解説）。
  • ナス科は子房上位（子房ががくより上＝花の先端側にある）。だから実にはへた（がく）が残る（巻末解説）。◆ポイント◆：おしべを取りのぞくと花のまん中に子房が見え、Fの花を切り開くと子房が大きくなり始めている。

🔍 こう読み解く

  1. 最初はE（がくに包まれたつぼみ）、最後はD（へたのついた紫の実）。両端を先に置く。
  2. Cは花びらが開いた花（咲いている）。E→Cは確定。
  3. B・A・Fは咲き終わり。Bは花びらがしおれて下を向いた状態、Aはさらに縮んで黒ずんだ状態。Fは中心がふくらみ始めている（◆ポイント◆の「子房が大きくなってきている」）ので、A→Fの順。
  4. つなぐと E→C→B→A→F→D。「花びらが元気な順 → 子房が大きい順」で見ると迷わない。
答え：E→C→B→A→F→D
コツ：並べ替えは両端から。まん中の3枚（B・A・F）は「しおれ方」と「ふくらみ方」の2つのものさしで順を決める。

136〜143 まとめ 見方のまとめ

  • 写真問題は「花粉がおしべから虫のどこについて、どの柱頭へ行くか」の矢印で読む。虫が花に入っていなければ花粉は運ばれない（140）。
  • 理由を書く問題は、写真1枚＝部品1つ。138は「奥の蜜」＋「ねばねば」、139は「花びらが開く／長いおしべ」＋「腹につく」、140は「もぐり込まない」＋「からだに花粉がつかない」。

144 ①・② キュウリのめ花の矢印の部分と、種子のもと 資料問題・写真の穴うめ

👀 まず見るところ

【資料問題】部品は写真の正体「キュウリのめ花」と、矢印の場所＝花びらの下の細長いふくらみ。「め花」に丸をつければ、花の根元のふくらみ＝子房、右の切った実の中の粒＝種子のもと、と決まる。

📚 前提知識

  • め花にはめしべがあり、その根元のふくらみが子房。子房の中の胚珠が受粉後に種子になり、子房は果実になる。
  • ◆ポイント◆のとおり、キュウリはがくの下に子房がある（子房下位）。143のナスは子房ががくより上（子房上位）で、実にへたが残る。キュウリの実にへたがないのはこのため。

🔍 こう読み解く

  1. 左の写真：黄色い花びらの下に、細い毛のはえた緑のふくらみがある。ここが矢印＝子房。小さなキュウリの形をしている。
  2. 右の写真：子房を縦に切ると、中に白い粒がならぶ。これが胚珠（未熟な種子）。受粉後に成長して種子になる。
  3. 食べるキュウリの中の白い粒は、この未熟な種子をそのまま食べている（巻末解説）。
答え：① 子房　② 胚珠
コツ：「種子のもと」と聞かれたら胚珠、「実になる」と聞かれたら子房。2語をセットで余白に書く。

145 ①・② ヒマワリの花粉の形と受粉のしかた 資料問題・写真の穴うめ

👀 まず見るところ

【資料問題】部品は写真の正体「おしべの花粉」の拡大写真2枚と、設問の「花粉には〔①〕がある」。拡大写真の粒の表面がギザギザ→とげ、と1語に直して書く → とげがある花粉は虫につきやすい＝虫媒花、と②も同時に決まる。

📚 前提知識

  • 虫媒花の花粉は、とげやねばりけがあって昆虫の体につきやすい。風媒花の花粉は小さく軽く、数が多い。花粉の形を見れば、どちらで運ばれるかが決まる。
  • ◆ポイント◆：花粉が柱頭につくと花粉管が胚珠までのびて受精する。

🔍 こう読み解く

  1. 右下の拡大写真：黄色い粒の表面に細かいとげが見える → ①とげ。
  2. とげは昆虫の体にひっかかるためのつくり → ②虫媒花。大きく目立つ黄色い花びら（146）も虫媒花の特徴で、つじつまが合う。
答え：① とげ　② 虫媒花

146 おしべもめしべもないヒマワリの外側の花の役割 資料問題・理由を答える

👀 まず見るところ

【資料問題】部品は設問の「一番外側の花」「おしべもめしべもなく」。断面写真で一番外側の花（左下の矢印の先）を見ると、大きな黄色い花びらだけでできている → 種子を作らない花が持つのは花びらだけ、だから役割は「虫をよぶ」と決まる。

📚 前提知識

  • ヒマワリはたくさんの小さな花が集まって1つの花に見える（頭花・巻末解説）。外側の花びらが大きい花を舌状花、内側の筒の形の花を筒状花という。種子ができるのは筒状花だけ。
  • 虫媒花は、昆虫に見つけてもらうために目立つ花びら・みつ・においを持つ。

🔍 こう読み解く

  1. 断面写真の3本の矢印：一番左が外側の花（大きな花びら1枚）、中と右が内側の花（筒の形で、おしべ・めしべがある）。
  2. 外側の花はおしべ・めしべがないので種子はできない。それでも大きな花びらを持つのは、遠くの昆虫をよぶため。内側の花の受粉を助ける役割。
  3. 答えには「大きく目立つ花びら」と「昆虫を呼び寄せる」の2つの部品を入れる。
答え：大きく目立つ花びらで、昆虫を呼び寄せること。

147 ①・② マツの花粉の形と受粉のしかた 資料問題・写真の穴うめ

👀 まず見るところ

【資料問題】部品は写真の正体「マツのお花」の花粉の拡大写真と、設問の「花粉は小さく〔①〕があり」。拡大写真で花粉の両側に丸いふくらみが2つ → 空気袋、と1語に直して書く → 軽くして風にのせるつくりだから風媒花。

📚 前提知識

  • マツは風媒花。花粉は小さく軽く、両側に空気袋がついていて風に乗りやすい。お花とめ花が別で、花びらがない。
  • ◆ポイント◆：花粉症を引き起こすのは主に風媒花の花粉。スギ（2〜4月）、ブタクサ（8〜10月）。風媒花は花粉を大量に飛ばすため。
  • 巻末解説：め花は受粉後に松かさ（松ぼっくり）になり、種子にははねがあって風で散る。マツは花粉も種子も風で運ぶ。

🔍 こう読み解く

  1. 左の写真：枝の先にかたまってついている赤茶色のものがお花。花びらも目立つ色もなく、虫をよぶつくりがない。
  2. 右下の拡大写真：花粉のまん中の丸いつぶの左右に、小さな袋のようなふくらみが2つ → ①空気袋。
  3. 空気袋で軽くなった花粉は風で遠くまで飛ぶ → ②風媒花。145のヒマワリ（とげ＝虫媒）と対にして覚える。
答え：① 空気袋　② 風媒花
コツ：花粉の拡大写真が出たら「とげ→虫媒」「空気袋→風媒」と、形から先に決める。

148 トウモロコシのひげの本数と粒の個数が同じ理由 記述・写真から理由を説明

👀 まず見るところ

【資料問題】部品は写真の正体「トウモロコシのめ花が成長する様子」と、設問の「ひげの本数と粒の個数が同じ」。右の写真で皮をむくと、粒1つずつからひげが1本ずつ出ているのが見える → ひげ＝めしべ、粒＝子房、と正体を1行書けば理由になる。

📚 前提知識

  • トウモロコシは風媒花で、お花とめ花が別。くきの先の穂がお花、葉のつけ根のひげのついたものがめ花。
  • ひげは1本1本がめしべ（柱頭）で、その根元に子房が1つずつある。受粉すると子房が粒（実）になる。
  • ◆ポイント◆：熟すとひげは枯れて茶色くなる。イネやエノコログサもトウモロコシと同じイネ科で、花からおしべが飛び出している（風媒花のつくり）。

✍️ 答案の組み立て

  1. 要素A：ひげ＝めしべの柱頭、粒＝子房。写真の正体を言葉にする。
  2. 要素B：1個の粒につき1本のひげがついている。だから本数と個数が同じ。
  3. 「〜であるため、〜から。」の形で、AとBをつなぐ。
模範解答：トウモロコシのひげはめしべの柱頭であり、粒は子房であるため、1個の粒につき1本のひげが生えているから。
コツ：「ひげ＝めしべ」だけで終わらせない。「1粒に1本」まで書いて、はじめて本数が同じ理由になる。

149 A・B 花の名前と、花粉を運んでいる動物 資料問題・写真の見分け

👀 まず見るところ

【資料問題】部品は聞かれ方「何のなかま」と「花粉を媒介している動物」の2つに線。Aは青い小さな花のかたまりに緑の虫、Bはピンクの花に緑の小鳥 → 花の形と来ている動物を1組ずつ決める。

📚 前提知識

  • アジサイは小さな花がたくさん集まって1つの花に見える（巻末解説）。外側の花びらのように見える部分はがく。来ているのはハナムグリ（コガネムシのなかま）で、花粉を食べに内側の小さな花にやってくる。
  • サクラにはみつを吸いにメジロ（目のまわりが白い緑色の小鳥）が来る。花粉を鳥が運ぶ花を鳥媒花という。ウグイスと取りちがえやすいが、目の白い輪で見分ける。

🔍 こう読み解く

  1. A：青いつぶつぶの小さな花が集まっている → アジサイ。上にいる緑色でずんぐりした虫 → ハナムグリ。
  2. B：ピンクの花びらで、枝から直接さいている → サクラ。花に頭をつっこんでいる黄緑色の小鳥 → メジロ（この写真では頭が花にかくれていて目の白い輪は見えないので、「サクラの花にもぐる黄緑の小鳥」で決める）。
  3. 花粉を運ぶのは昆虫だけではない。鳥も運ぶ、という例として覚える。
答え：A アジサイ・ハナムグリ　B サクラ・メジロ

150 キノコの傘の裏から落ちた白い粉 知識問題

胞子。キノコは植物ではなくカビのなかま（菌類）で、花や種子を作らず、傘の裏のひだから胞子を落としてふえる。黒い紙に傘を押しつけると、ひだの形にそって白い粉がつく（写真の左）。◆ポイント◆のスギナ（つくし）のように、植物にも胞子でふえるものがある（シダ・コケのなかま）。「種子でふえる」花の単元の最後に、「種子を作らない」仲間を対で覚える。
答え：胞子

144〜150 まとめ 花と受粉（写真）

  • 実と種子の問題（144・148）は「子房→実、胚珠→種子」の1行で決まる。キュウリは子房ががくの下（へたがない）、トウモロコシは1粒＝1つの子房＝ひげ1本。
  • 花粉の写真（145・147）は形で決める。とげ→虫媒花（ヒマワリ）、空気袋→風媒花（マツ）。風媒花の花粉は小さく軽く大量＝花粉症の原因（スギ・ブタクサ）。
