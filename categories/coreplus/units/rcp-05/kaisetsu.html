61 積乱雲の雨が降っている場所 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「積乱雲（入道雲・雷雲）」と聞かれ方「雨が降っている場所について」。雲の底から地面へ落ちる雨のすじを写真に丸で囲む → すじの幅と、その上の雲の色の2つが答えになる。

📚 前提知識（あれば答え合わせに使う）

  • 積乱雲は上にのびる雲で、せまい範囲に短時間の強い雨（夕立・雷雨）を降らせる。
  • 雲が黒く見えるのは、雲が黒いからではなく、水滴が多いところほど日光が吸収されて暗く見えるため（巻末解説）。
  • 雨を降らせる雲は積乱雲のほかに乱層雲（雨雲）がある（◆ポイント◆）。乱層雲は空一面に広がり、広い範囲に弱い雨を長く降らせる。

🔍 こう読み解く

  1. 写真の右寄り、雲の底から地面へ白っぽいすじがのびている。これが雨。すじの幅は雲の一部だけ → せまい範囲に降っている。
  2. 雨のすじのすぐ上、雲の下の方だけが黒い → 水滴が多い＝強い雨のもと。
  3. 「場所」を聞かれているので、「せまい範囲」と「雲の下が暗い」の2つを1文にまとめる。
答え：せまい範囲に強い雨が降っており、雲の下の方が暗い。
コツ：「気づいたこと」の問題は、目にとまった所に丸をつけてから、丸1つにつき1文を書く。丸が2つなら文も2つ。

62 雨上がりの虹 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「雨上がりに見える虹」と聞かれ方「虹について気づいたこと」。虹が2本あることに丸をつけ、それぞれの色の順（外が何色・内が何色）を写真のはしに書く → 明るさと色の並びの違いが答えになる。

📚 前提知識（あれば答え合わせに使う）

  • 虹は、太陽と反対の方角にある水滴に日光が反射・屈折して見える（巻末解説）。
  • 内側の明るい虹が主虹、外側の暗い虹が副虹。副虹は水滴の中で日光が2回反射するため、もどってくる光が少なく暗い。反射が1回多いので色の順も逆になる（巻末解説）。

👀 まず見るところ

【資料問題】部品は条件「Aは春の初め頃、Bは秋の終わり頃」と「東側から（西側を向いて）」。西を向くと左が南・右が北、と写真のはしに書く（直して書く）→ 2枚の太陽の位置を左右でくらべれば、日の入りの方角の違いが決まる。

答え：Aの温度計は黒い球におおわれており、日差しが当たると中の温度が高くなる。Bの温度計は色や形が百葉箱と似たつくりになっている。

68 ② 積乱雲はどのくらいの高さまで成長するか 資料問題・高さの見当

👀 まず見るところ

  3. 残る 10km程度。雲の上が平らに横へ広がっているのは、成層圏に当たって止まった合図。
答え：10
コツ：{1・10・100}のように10倍ずつ離れた選択肢は、「対流圏＝十数km」を1行書けば両はしが消える。

  • 飛行機型の風向計は、機首が風上を向き、尾翼が風下へ流される。

🔍 こう読み解く

  1. 扉が右 → 右＝北。この写真は西を向いて撮っている。
  2. 風向計は機首が左、尾翼が右。◆ポイント◆のとおり、風は写真の左側から吹いてきている。
  3. 左＝南なので、風は南から吹いてきている。風向は「風が吹いてくる方角」（②）→ 風向は南。巻末解説の図も「風向計＝南を向いている」としている。
答え：南
コツ：方角は「扉＝北」から1つ決め、残りを時計回り（北→東→南→西）に写真のふちへ書く。

70 ④ 地面の穴の中に設置されている装置 知識問題

雨量計。地面に埋めた容器で雨水を受ける。降水量の単位はmmで表し、容器の大きさが変わっても同じ数値になる（◆ポイント◆）。
答え：雨量計

71 ① 図2の観察記録はいつの日か 資料問題・透明半球

👀 まず見るところ

【資料問題】部品は図2の正体「透明半球に写した太陽の道すじ」と選択肢「春分 夏至 秋分 冬至」。見るのは道すじの高さと両端の方角（南寄りか北寄りか）。2つ書いてから4つに○×。

📚 前提知識

  • 太陽の道すじは、夏至が最も高く日の出・日の入りが北寄り、冬至が最も低く南寄り（◆ポイント◆）。春分・秋分は真東から出て真西に沈む。
  • 北極や南極の近くでは、太陽が地平線と平行に動いて沈まない日（白夜）がある（◆ポイント◆の写真）。

🔍 こう読み解く

  1. 図2の線は半球の低いところを通っている → 南中高度が低い。
  2. 線の両端が南（手前）に寄っている → 冬。
  3. 春分・秋分は真東・真西、夏至は高くて北寄り → ×。残るのは冬至。
答え：冬至

71 ② 図3は東・西どちらの空か 資料問題・連続写真

👀 まず見るところ

【資料問題】部品は図3の正体「夏に太陽の動きを連続撮影」と、太陽の列の向き（右上へ上がるか、右下へ下がるか）。上がるなら日の出側＝東、下がるなら日の入り側＝西、と1行で決める。

📚 前提知識

  • 太陽は東から出て南の空を通り西に沈む。東の空では右上へ上がり、西の空では右下へ沈んでいく（巻末解説）。
  • ◆ポイント◆：図3では日食が起こっている（太陽が欠けて写っている）。

🔍 こう読み解く

  1. 図3の点の列は、左下の雲の近くから右上へのびている。下の方が明るい＝地平線に近い。
  2. 地平線から右上へ上がっていく → 日の出のあとの東の空。
  3. 西なら、太陽は右下へ下がって地平線に消える向きになる。
答え：東
コツ：「右上へ上がれば東、右下へ下がれば西」。日本で見る太陽の動きは、東でも西でも左から右。

72 透明半球に印をつける位置の確かめ方 知識問題

油性ペンの先端の影が、東西南北の線の交点（半球の中心O）にくるようにする。中心Oが観察する人の位置の代わりで、「太陽—ペン先—O」が一直線にそろう点が、Oから見た太陽の方向になる（巻末解説の図）。打った点を結ぶと太陽の動く道すじが分かる。
答え：油性ペンの先端の影が、東西南北の線の交点にくるようにする。

73 ① 夕方の太陽に起きていること 資料問題・写真

👀 まず見るところ

【資料問題】部品は図1の正体「夕方に太陽を観察」と、拡大の中の形＝三日月のように欠けている。太陽が欠けて見える現象の名前を1語で決める。

73 ② 黒点の温度は周りより高いか低いか 知識問題

74 金星と黒点のちがい 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「太陽の表面と黒い点」と条件「右上にある大きい点は金星」。くらべる所はふちのはっきりさと形の2つ、と先に決めてから見る。

📚 前提知識

  • 金星は地球より内側を公転しているので、太陽の手前を横切ることがある（◆ポイント◆）。太陽の表面にあるのではなく、太陽と地球の間にある。
  • 太陽は球形なので、端の方にある黒点はつぶれて見える（◆ポイント◆）。

🔍 こう読み解く

  1. 右上の大きい点：ふちがくっきりしていて、真円に近い。
  2. ほかの黒点：ぼんやりしていて、端にあるものは横につぶれている。
  3. ちがいの理由：金星は太陽の手前にある別の球、黒点は球面の上の模様。
答え：輪郭がはっきりしている。真円に近い形をしている。

75 Aに雪が残りBに残らない理由 資料問題・写真と方角

👀 まず見るところ

【資料問題】部品は「日の入り頃」と「Aは雪が残る・Bは残らない」。日の入り＝正面が西 → 左が南・右が北、と写真のふちに書く（直して書く）。雪が残る＝日光が当たりにくい斜面＝北向き。

📚 前提知識

  • 日本やハワイ（北半球）では太陽は南の空を通るので、南向きの斜面に日光がよく当たり、北向きの斜面は当たりにくい。
  • ◆ポイント◆：マウナケア山は晴れの日が多く空気が澄み、街の灯りがないため天体観測に適していて、世界各国の天文台がある。

🔍 こう読み解く

  1. 「日の入り頃」で夕焼けが見えている方＝正面が西。左が南、右が北。
  2. 奥の丘は右（北）側の斜面に雪が残り、左（南）側には無い（巻末解説）。
  3. A・Bは手前のくぼんだ地形で、丘とは向きが左右反対（巻末解説）。Aの斜面は北を向くので日光が当たりにくく雪が残り、Bは南を向くので当たりやすく雪が消えた。
答え：Aの斜面は北の方角を向いているため日光が当たりにくく、Bの斜面は南を向いているため日光が当たりやすいから。
コツ：「雪が残る＝日光が当たりにくい＝北向き」の1行を書いてから、方角を写真に当てはめる。

69〜75 まとめ 見直しの要点

  • 観天望気は「晴れ＝夕焼け・朝露」「雨＝飛行機雲・うろこ雲」の2組。理由は天気が西から東へ変わるから。
  • 方角の問題（70③・75）は、扉＝北か日の入り＝西のどちらかを先に写真に書き、残りの方角を埋めてから読む。
  • 透明半球は「ペン先の影を中心Oに」「道すじが低く南寄りなら冬至」「東の空では右上へ上がる」の3行。
