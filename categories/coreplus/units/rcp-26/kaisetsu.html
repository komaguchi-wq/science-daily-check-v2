621 ① 1分間に血液に取り込まれる酸素の量 まざり型→条件文・割合のかけ算

👀 まず見るところ

【まざり型→条件文】部品は表の酸素の行「吸気21・呼気16」と、文の「1回600mL」「1分間あたり16回」。表の2つは差の5%に直して書く → 1分間に吸った空気の量×5% が取り込まれた酸素。

📚 前提知識

  • 吸った空気の酸素と、はいた空気の酸素の差の分が、肺で血液に取り込まれた酸素（◆ポイント◆）。21−16＝5（%）。
  • 二酸化炭素の行（0.04→4）はこの小問では使わない。聞かれているのは「酸素」。

🔍 こう読み解く

  1. 1分間に吸う空気は 600mL×16回＝9600mL。
  2. そのうち血液に取り込まれるのは 21−16＝5%。9600×0.05＝480mL。
答え：480mL
今回：○。

621 ② 1分・1時間に送り出す血液と、1時間で体内を回る回数 条件文・かけ算をたどる

👀 まず見るところ

【条件文】部品は「血液量4200mL」「1分間に80回」「1回70mL」と、Bの「1時間では」。Aは 70×80、Bは「1時間＝60分」に直して A×60、Cは「何周」＝B÷4200 と置く → 3つの式が先に並ぶ。

📚 前提知識

  • 1分間に心臓が送り出す血液＝1回の拍出量×拍動数（◆ポイント◆）。1時間なら×60分。
  • 「体内を何周するか」＝送り出した血液の合計÷体内の血液量。4200mLが1周分。

🔍 こう読み解く

  1. A：70mL×80回＝5600mL（1分間）。
  2. B：5600mL×60分＝336000mL（1時間）。
  3. C：336000mL÷4200mL＝80周。
  4. 確かめ：1分で 5600÷4200＝4/3周 → 1時間で 4/3×60＝80周。同じになる。
答え：A 5600　B 336000　C 80
今回：A ○・B ○・C ×。原本が無いので答えは見ていない。Cで×になりやすいのは、部品を拾えなかった＝「1時間で」を見落として1分間のA÷4200 で割る（4/3周）か、分母を4200でなく別の数にすること。「このことから計算すると」の直前に戻らず、Bの数字を分子に置く。

622 印をつけたネズミからの総数の推定 条件文・割合が同じ

👀 まず見るところ

【条件文】部品は「8匹つかまえ、すべてに印」「20匹つかまえて」「そのうち2匹に印」。「印つき÷全体」と「印つき÷つかまえた数」が同じ、と直して書く → 8/□＝2/20 の1本。

📚 前提知識

  • 印をつけたネズミが空き地全体に均等に散らばると考える（◆ポイント◆）。だから、あとでつかまえた20匹の中の印の割合は、全体の中の印の割合と同じになる。
  • この方法を標識再捕法という。答えが「くらい」なのは、均等に散らばるという仮定の上の推定だから。

🔍 こう読み解く

  1. 全体の中の印の割合：8匹÷□匹。
  2. つかまえた中の印の割合：2匹÷20匹＝1/10。
  3. 8÷□＝1/10 → □＝8×10＝80匹。
答え：80匹くらい
今回：○。

623 ① 1令幼虫の死亡率 まざり型→資料問題・割合

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「成長段階ごとの生存数・死亡数・死亡率（%）」と、①の行「1令幼虫 3604・1265」、指示の「四捨五入し小数第1位まで」。死亡率＝死亡数÷生存数×100 と置く → 1265÷3604×100。

📚 前提知識

  • 死亡率（%）＝死亡数÷生存数×100（◆ポイント◆）。「その段階まで生きていた数のうち、何%が死んだか」。分母は次の段階の数ではない。
  • 式に自信がなければ、数が入っている行で確かめる。卵の行は 141÷4536×100＝3.1 で表と合う。

🔍 こう読み解く

  1. 1令幼虫の行：死亡数1265、生存数3604。
  2. 1265÷3604×100＝35.09… → 小数第2位を四捨五入して 35.1%。
答え：35.1
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品を拾えなかった＝「四捨五入し、小数第1位まで」の指示を飛ばして 35 や 35.09 と書くか、分母を次の行の2339にすること。先に卵の行で式を確かめ、答えを書く直前に「小数第1位」の丸を見直す。

623 ② 2令幼虫の死亡数 まざり型→資料問題・となりの行との引き算

👀 まず見るところ

【まざり型→資料問題】部品は②の行の「生存数2339」と、1つ下の行の「3令幼虫 生存数1985」。「2令で死んだ数＝2令の生存数−3令の生存数」と直して書く → 引き算1回。死亡率15.1は確かめに使う。

📚 前提知識

  • 生命表は上から順に数が減っていく。次の段階の生存数＝この段階の生存数−この段階の死亡数（◆ポイント◆）。だから死亡数は、上下の生存数の差で出る。

🔍 こう読み解く

  1. 2令幼虫2339匹のうち、3令幼虫になれたのが1985匹。
  2. 死亡数＝2339−1985＝354匹。
  3. 確かめ：354÷2339×100＝15.1… で表の死亡率15.1と合う。
答え：354
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝「死亡数＝上下の生存数の差」に直さず、2339×0.151 のかけ算で 353 など半端な数を出すこと。表の上下の行に矢印を1本引いてから引き算に入る。

623 ③ 7令幼虫の生存数 まざり型→資料問題・足し算で戻す

👀 まず見るところ

【まざり型→資料問題】②と変わった部品は、わからないのが「生存数」になったこと。③の行の「死亡数30」と、1つ下の「さなぎ 生存数13」を拾う。「生存数＝死亡数＋次の段階の生存数」と直して書く → 30＋13。

📚 前提知識

  • ②の式を逆向きに使う。この段階の生存数＝この段階の死亡数＋次の段階の生存数（◆ポイント◆）。7令幼虫のうち30匹が死に、13匹がさなぎになれた。

🔍 こう読み解く

  1. 7令幼虫の死亡数30匹、さなぎの生存数13匹。
  2. 30＋13＝43匹。
  3. 確かめ：上の行からも 1495−1452＝43。死亡率も 30÷43×100＝69.77… → 69.8 で表と合う。
答え：43
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝②と同じ「上−下」のつもりで 30−13 のような引き算を作ること。③は「死亡数＋下の生存数」（または上の行の 1495−1452）。矢印の向きを表に書いてから計算する。

624 蒸散量の計算 まざり型→条件文・差で分ける

👀 まず見るところ

【まざり型→条件文】部品は「Aは2mm、Bは7mm、Cは14mm」と、図の下の「どこにワセリン」。A＝茎だけ、B＝茎＋表、C＝茎＋裏、D＝全部、と表に直して書く（◆ポイント◆の○×表）→ 差を取れば表・裏の分が出る。

📚 前提知識

  • ワセリンをぬった所からは蒸散しない（気孔がふさがれる）。水面の油は、水面からの蒸発を止めて、植物からの蒸散だけを測るため。
  • 蒸散する場所は葉の表・葉の裏・茎の3つ。水面の下がり方は、蒸散した場所の分の足し算になる（◆ポイント◆）。
  • 裏（12mm）が表（5mm）より大きいのは、気孔が葉の裏に多いから。答えの確かめに使える。

🔍 こう読み解く

  1. A（葉なし・切り口にワセリン）＝茎だけ → 茎＝2mm。
  2. B（裏にワセリン）＝茎＋表＝7mm → 表＝7−2＝5mm。
  3. C（表にワセリン）＝茎＋裏＝14mm → 裏＝14−2＝12mm。
  4. D（そのまま）＝茎＋表＋裏＝2＋5＋12＝19mm。
答え：19mm
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝A〜Dを「どこから蒸散するか」の○×表に直さず、7＋14＝21 や 2＋7＋14＝23 と足してしまうこと（茎が二重・三重に入る）。先に表・裏・茎の3行の表を書き、Aの2mmを茎に置く。

625 酸素 ダイズが吸収した酸素の量 まざり型→条件文・石灰水の役目

👀 まず見るところ

【まざり型→条件文】部品は「図1には石灰水」と「図1は左に5cm³」。石灰水＝二酸化炭素を吸う、と正体を1行書く → 図1の体積の減りは酸素の吸収分だけになり、5cm³がそのまま答え。

📚 前提知識

  • 呼吸では酸素を吸収し、二酸化炭素を放出する。フラスコの中の気体は「酸素の分だけ減り、二酸化炭素の分だけ増える」。
  • 図1では放出された二酸化炭素がすべて石灰水に吸収されるので、インクの移動＝吸収された酸素の量（◆ポイント◆）。
  • 恒温槽で温度を一定にしているのは、温度による気体の体積変化を無くし、呼吸の分だけを測るため。

🔍 こう読み解く

  1. 図1：酸素が吸収 → 5cm³減る。二酸化炭素の放出と石灰水への吸収は打ち消し合う。
  2. よって吸収した酸素＝5cm³。
答え：5cm³
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品を拾えなかった＝「石灰水」と「水」のビーカーの違いを図1・図2で区別せず、どちらの5・1が酸素かを決められないこと。図1の「石灰水」に丸をつけ、横に「二酸化炭素を吸う」と書いてから数字を見る。

625 二酸化炭素 ダイズが放出した二酸化炭素の量 まざり型→条件文・差から戻す

👀 まず見るところ

【まざり型→条件文】酸素と変わった部品は「図2には水」と「図2は左に1cm³」。水は二酸化炭素を吸わないので、「減った酸素5−増えた二酸化炭素□＝1」と直して書く → □は引き算で出る。

📚 前提知識

  • 図2では二酸化炭素が吸収されないので、インクは酸素の吸収で左へ、二酸化炭素の放出で右へ動こうとする。その差し引きが1cm³（◆ポイント◆）。
  • 吸収した酸素の量は図1と同じ5cm³（同じ数のダイズ・同じ条件）。

🔍 こう読み解く

  1. 図2：酸素の吸収で5cm³減り、二酸化炭素の放出で□cm³増える。合わせて1cm³減った。
  2. 5−□＝1 → □＝4cm³。
  3. 確かめ：酸素5より二酸化炭素4が少ないので、図2でも左に動く。向きが合う。
答え：4cm³
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝図2の1cm³を「二酸化炭素そのもの」と読んで 1cm³ と書くか、5＋1＝6 と足すこと。「酸素で減る・二酸化炭素で増える・差が1」を矢印2本で図2の横に書く。

621〜625 まとめ 4/11 正解

  • ○は 621①・621②A・B・622。「差×回数」「1回×回数」「印の割合が同じ」のように、問題文の数字を順にかける問題は入っている。
  • ×の7問（621②C・623①〜③・624・625）は、すべて数字を組にする前の1行が必要な問題。「1時間で」＝B÷4200、「死亡数＝上の生存数−下の生存数」、「A＝茎だけ」、「石灰水＝二酸化炭素を吸う」。この1行を書いてから数字に手をつける。
  • 表の問題（623・624）は、表に矢印を1本書く（上下の行・○×の列）。矢印の向きが決まれば、引き算か足し算かが決まる。
