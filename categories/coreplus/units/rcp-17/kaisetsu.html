356〜362 全体像 てこの3点の並び・力と距離 7問

7問は2本柱。1つ目は支点・力点・作用点の並び（356・359・360は図に3点を置く、357は並びごとの性質）。2つ目は支点からの距離と力の関係（358・361・362）。入口はどれも同じで、図の中の「動かない所＝支点」を先に丸で置く。

余白に3行書いてから入る。支点＝動かない所／支点から力点が遠いほど小さな力（距離と力は反比例）／力で得をすると、動かす距離で損をする。

A作用点裁断機・栓抜き・オール力は大きく、動く距離は短い
B支点洋ばさみ・釘抜き支点の位置しだい
C力点パンばさみ力は小さく、動く距離は長い

356 ①・②・③・④・⑤・⑥ 6つの道具はA・B・Cのどのてこか 資料問題・図から3点を置く

👀 まず見るところ

【資料問題】部品は資料の正体「6つの道具の絵」と、設問の定義「A：支点と力点の間に作用点」「B：力点と作用点の間に支点」「C：作用点と支点の間に力点」。定義は3語で書く＝A＝作用点が中・B＝支点が中・C＝力点が中。絵ごとに、動かない所（支点）を先に丸 → 残り2点を置けば、どれが「中」かで決まる。

📚 前提知識

  • 支点＝回転の中心で動かない所。力点＝手で力を加える所。作用点＝物に力がはたらく所。
  • ボートのオールは水の中の先端が支点（◆ポイント◆）。水はほとんど動かず、オールうけ（作用点）を通してボートが進む。手が力点。

🔍 こう読み解く

  1. ①洋ばさみ：ねじが支点、持ち手が力点、刃が作用点。支点が中 → B。
  2. ②パンばさみ：つながった端が支点、先が作用点、手でにぎる所がその間 → 力点が中 → C。
  3. ③釘抜き：床につく曲がり角が支点、柄の端が力点、くぎをはさむ先が作用点。支点が中 → B。
  4. ④裁断機：刃のつけ根が支点、柄の端が力点、紙を切る所がその間 → 作用点が中 → A。
  5. ⑤栓抜き：せんのふちに引っかける先が支点、柄が力点、せんを持ち上げる所がその間 → 作用点が中 → A。
  6. ⑥オール：水の中の先端が支点、手が力点、オールうけがその間 → 作用点が中 → A。
答え：① B　② C　③ B　④ A　⑤ A　⑥ A
今回：① ○　② ○　③ ○　④ ○　⑤ ○2×1　⑥ ○。⑤の×は知識＝栓抜きの支点を手に近い側ととりちがえやすい。せんのふちに引っかかる先が支点、せんが持ち上がる所が作用点、と絵に3点を置いてから決める。

357 A・C AのてことCのてこの特徴 知識問題

答えは「力」と「動く距離」の2部品で書く。A（作用点が中）は支点から作用点までが支点から力点までより短いので、力点より作用点の力が大きくなり、そのかわり作用点の動く距離は短くなる。C（力点が中）はその逆で、作用点の力は小さく、動く距離は長くなる。どちらも「力で得をすれば距離で損をする」の1行から出てくる。
答え：A 力点に加えた力に比べ、作用点にかかる力が必ず大きくなる。力点を動かした距離に比べ、作用点が動く距離が必ず短くなる。　C 力点に加えた力に比べ、作用点にかかる力が必ず小さくなる。力点を動かした距離に比べ、作用点が動く距離が必ず長くなる。
今回：A ×（3回とも）　C ×（3回とも）。知識＝「力」と「距離」の2部品がそろって初めて○になる問題。Aは「力は大きく・距離は短く」、Cは「力は小さく・距離は長く」と4語の組で覚え直す。

361 A 力点で加える力が小さい順 条件文・比で並べる

👀 まず見るところ

【条件文】部品は「力点で加える力が小さい順」と「等号・不等号」。4つの図で「支点→作用点」「支点→力点」の目もりの数を読み、力＝おもり×（支点→作用点）÷（支点→力点）に直して4つ書く → 数の小さい順に並べる。

📚 前提知識

  • てこのつり合い：おもり×支点からの距離＝力点の力×支点からの距離。支点と力点の距離が長いほうが小さな力ですむ（◆ポイント◆）。

🔍 こう読み解く

  1. 1目もりを1として、支点からの腕の長さを読む。①：支点0・作用点1・力点4 → 作用点の腕1・力点の腕4 → 1/4。

  4. 小さい順に ①（1/4）＜③＝④（1/3）＜②（1/2）。
答え：①＜③＝④＜②
今回：×（4回とも）。計算＝腕を目もりで数えずに、支点の位置の見た目だけで並べると、③と④の等号が出てこない。1目もりを1として「作用点の腕÷力点の腕」を4つ先に書けば、③＝④が自然に見える。

362 支点から力点までの距離と力点にかける力の関係 知識問題

「どのような関係」と聞かれたら、小さくなると→大きく、大きくなると→小さくの両方向を書く。おもり×支点からの距離が決まっているので、力点が支点から遠いほど小さな力ですむ（力と距離は反比例）。片方向だけでは関係を書いたことにならない。
答え：支点から力点までの距離が小さくなると力点にかける力は大きくなり、支点から力点までの距離が大きくなると力点にかける力は小さくなるという関係。
今回：○2×1。×は知識＝「距離が長いと力が小さい」の片方向で止まりやすい。逆向きの1文も足して「関係」の形にする。

356〜362 まとめ GAS 採点

  • 図に3点を置く問題（356・360・361B・358）はほぼ取れている。支点＝動かない所、の入口はできている。
  • 落としているのは言葉で性質を書く問題（357 A・C が3回とも×、362 も1回×）。「力は大きく・距離は短く」のように力と距離の2部品をそろえて書く。
  • 361 A（4回とも×）は、腕を目もりで数えずに並べた形。1目もりを1として「作用点の腕÷力点の腕」を4つ書くと、③と④が同じ1：3になるのが見える。

🔍 こう読み解く

  1. Aで放したおもりはBを通って右へ上がる。釘のせいで右半分は短いふりこ（半径が小さい円）になる。

答え：同じ高さ
コツ：ふりこ・斜面・坂道の問題は、まず「放した高さ」に横線をひく。おもりはこの線より上には行けない。

389 釘がねん土に打ち込まれる長さを長くする方法2つ 知識問題

「ふりこのおもりを重くする」と「高いところからおもりを放し、釘にぶつかるときの速さを速くする」の2つ。釘を打ち込む勢いは、ぶつかるおもりの「重さ」と「速さ」で決まり、速さは放す高さ（図の「高さ」）で決まる。ふりこの長さを変えても、同じ高さから放せば最下点の速さは同じなので、長さは答えにならない。
答え：・ふりこのおもりを重くする。　・高いところからおもりを放し、釘にぶつかるときの速さを速くする。

390 ①・② 長さのちがうふりこを同じ角度で振る、最下点で速いのはどちらか・その理由 資料問題・図で高さを比べる

👀 まず見るところ

【資料問題】部品は図の正体「短いふりこと長いふりこ・同じ角度」と聞かれ方「最下点での速さはどちらが速いか」。2つの図それぞれに、放した位置から最下点までの高さ（落差）を矢印で書く → 落差が大きい方が速い。

📚 前提知識

  • 最下点の速さを決めるのは、振らせ始めの位置と最下点の高さの差（落差）だけ。角度や長さそのものではない。
  • ◆ポイント◆：同じ角度なら2つの形は相似なので、ふりこの長さが長い方が落差も大きい。

🔍 こう読み解く

  1. 図に落差の矢印を描く（◆ポイント◆の図）。短いふりこは矢印が短く、長いふりこは矢印が長い。
  2. 落差が大きいのは長いふりこ → 最下点で速いのは長いふりこ。
  3. ②の理由は、この流れをそのまま文にする：「ふりこの長さが長い方が、振らせ始めの位置と最下点の位置の落差（高さの差）が大きいから」。
答え：① 長いふりこの方が速い　② ふりこの長さが長い方がふりこを振らせ始めの位置と最下点の位置の落差（高さの差）が大きいから。
コツ：理由を書くときは「角度が同じだから」で止めない。角度→相似→落差が大きい、の最後の「落差」まで書く。

391 ①・② 坂を転がるおもり、A〜Eの速さの順と理由 資料問題・図の高さで順番を決める

👀 まず見るところ

【資料問題】部品は図の正体「静かに手を放したおもりが転がる道」と、答え方「等号・不等号を使って」に丸。A〜Eの高さだけを図から読む（点線が同じ高さの目印）→ 低い点ほど速い、で並べる。

📚 前提知識

  • おもりの速さは、手を放した位置とその位置の落差（高さの差）が大きいほど速い。道の形や通った距離は関係ない。
  • 同じ高さの点は、速さも同じ → 「＝」でつなぐ。

🔍 こう読み解く

  1. 図の点線で高さをそろえる。AとCは同じ高さ（上の点線）、BとEは同じ高さ（下の点線）、Dはいちばん低い。
  2. 低い順＝速い順に並べる：D（最も低い）＞B＝E＞A＝C。
  3. ②の理由は決まりをそのまま書く：「おもりの速さは手を放した位置とその位置の落差（高さの差）が大きいほど速くなるから」。
答え：① D＞B＝E＞A＝C　② おもりの速さは手を放した位置とその位置の落差（高さの差）が大きいほど速くなるから。

394 ② 高さBを長くすると、CとDは 条件文・何で決まるかをたどる

👀 まず見るところ

【条件文】部品は①と変わった「Bを長くする」（B＝転がし始めの高さ）。Bは「C←B」の矢印に入っている → Cが変わり、CはDの部品でもあるのでDも変わる。

📚 前提知識

  • 高い所から転がすほど、台の端での速さは速い（落差が大きいほど速い）。

  1. Bが長い → 落差が大きい → Cは速くなる。

答え：C 速くなる　D 長くなる

394 ④ 台の高さFを長くすると、CとDは 条件文・何で決まるかをたどる

👀 まず見るところ

【条件文】部品は「Fを長くする」（F＝飛び出してから地面までの高さ）。Fは「D←CとF」の矢印にだけ入っている → Cはそのまま、Dだけ変わる。

📚 前提知識

  • Cは台の端に着いた時点で決まっていて、その先の高さFには関係しない。
  • ◆ポイント◆：落下にかかる時間はFで変化する。高い所から落ちるほど落ちている時間が長いので、同じ速さでも横に遠くまで進む。

🔍 こう読み解く

  1. Bは同じ → Cは変わらない。
  2. Fが長い → 落下時間が長い → 同じCで進む時間がのびる → Dは長くなる。
答え：C 変わらない　D 長くなる
