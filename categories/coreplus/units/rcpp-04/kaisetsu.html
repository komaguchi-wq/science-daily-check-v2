788〜792 全体像 発芽と乾燥重量・光と発芽・BTB・肝臓・腎臓 5問

5問は2つに分かれる。788〜790はグラフ・表・実験の図から理由を書く資料問題・まざり型の記述、791・792は肝臓と腎臓の穴うめの知識問題で、知っていれば即答できる。

記述の軸は1つ。植物は呼吸で養分（二酸化炭素を出す）を使い、光合成で養分をつくる（二酸化炭素を使う）。乾燥重量の増減（788）も、BTB液の色（790）も、この2つの大小で決まる。知識の軸は「肝臓がアンモニアを尿素に変え、腎臓が尿素をこし取る」の流れ。

788 ① 2〜6日に乾燥重量が減る理由 資料問題・記述

👀 まず見るところ

【資料問題】部品は資料の正体「種子の乾燥重量・まいてからの日数」と聞かれ方「2〜6日に重さが減っている」。グラフの2日の所に「発芽」、減る区間に「呼吸」と書いて置く → 減った分＝呼吸で使った養分、と決まる。

📚 前提知識

  • 乾燥重量＝水を抜いた重さ＝種子の中の養分の量（◆ポイント◆：乾燥させて比べるから養分の増減がよくわかる）。
  • 発芽したばかりの種子は葉がないので光合成はできず、呼吸で養分を使う一方になる。

✍️ 答案の組み立て

  1. 原因：2日頃に発芽して呼吸が始まった（グラフが下がり始めるのが2日）。
  2. 結果：呼吸で養分を消費した → 乾燥重量が減る。「〜から。」で結ぶ。
模範解答：2日頃に発芽し、呼吸が始まり、養分を消費したから。

788 ② 6〜8日に減り方が小さくなった理由 資料問題・記述

👀 まず見るところ

【資料問題】①と変わった部品は「減り方が小さくなった」。傾きがゆるくなる6日の所に「光合成が始まる」と書いて置く → まだ減っているので、光合成量＜呼吸量のまま差が縮んだ、と決まる。

📚 前提知識

  • 芽が出て緑の葉ができると光合成が始まる。はじめは葉が小さいので、つくる量（光合成）は使う量（呼吸）より少ない。
  • 乾燥重量の変化＝光合成でつくった量−呼吸で使った量。この引き算の向きで増減が決まる。

✍️ 答案の組み立て

  1. 要素A：光合成が始まった。
  2. 要素B：呼吸量よりも少ないながらも養分をつくれるようになった。「少ないながらも」が無いと、③（増える）との区別がつかない。
模範解答：光合成が始まり、呼吸量よりも少ないながらも養分をつくれるようになったから。

788 ③ 8〜10日に重さが増えた理由 資料問題・記述

👀 まず見るところ

【資料問題】②と変わった部品は「重さが増えた」。グラフの底（8日）に「光合成＝呼吸」と書いて置く → その右は光合成量＞呼吸量、と向きが決まる。

📚 前提知識

  • 葉が大きくなるほど光合成量が増える。呼吸量を上回った日から、乾燥重量は増え始める。

✍️ 答案の組み立て

  1. 原因：葉が大きくなった。
  2. 結果：呼吸量より光合成量が大きくなった。②は「少ない」、③は「大きい」と、大小の向きを書き分ける。
模範解答：葉が大きくなり、呼吸量より光合成量が大きくなったから。

789 A・B・C 光と発芽の関係を表から説明する 資料問題・記述

👀 まず見るところ

【資料問題】部品は表の正体「光の○×と発芽の○×」と、条件「水・空気・適当な温度の条件は満たしている」に丸 → 発芽の○×は光だけで決まる。A・B・Cごとに「光○のとき」「光×のとき」の発芽を1組ずつ読む。

📚 前提知識

  • 発芽の3条件＝水・空気・適当な温度。この3つがそろった上で、光も必要な種子がある。
  • 光が当たると発芽する種子＝光発芽種子（◆ポイント◆：レタス・タバコなど小さな種子の植物に多く、発芽してすぐに光合成をする必要がある）。

✍️ 答案の組み立て

  1. A：光○→発芽○、光×→発芽○。どちらでも発芽する → 光の有無は関係がない。
  2. B：光○→○、光×→×。光があるときだけ → 光が必要（光発芽種子）。
  3. C：光○→×、光×→○。Bの逆 → 光があると発芽できない。
  4. 答えの形は「発芽するために光が〜」。表の○×を文に直すだけなので、知識がなくても決まる。
模範解答：A 発芽するために光の有無は関係がない。　B 発芽するために光が必要である。　C 光があると発芽することができない。

790 ① 試験管Bの水の色の変化 まざり型・BTB液

👀 まず見るところ

【まざり型→素材文】部品は手がかりの言葉「青色のBTB液」「息を吹き込んで緑色」「光の当たるところ」。「息＝二酸化炭素を入れた」「光＋オオカナダモ＝光合成」と3語で書く → 二酸化炭素が減れば、色は元の青にもどる。

📚 前提知識

  • BTB液は酸性で黄・中性で緑・アルカリ性で青。二酸化炭素が水にとけると酸性にかたむくので、息を吹きこむと青→緑になる。

🔍 こう読み解く

  1. Bは光が当たり、オオカナダモが光合成をして水中の二酸化炭素を使う。
  2. 二酸化炭素が減る＝酸性のもとが減る → 緑から青にもどる。
答え：青色

790 ② 青色になった理由 まざり型・記述

👀 まず見るところ

【まざり型→素材文】部品は①の答え「青色」と聞かれ方「なぜ」。答えの文は「植物が何をしたか（光合成で二酸化炭素を消費）」＋「水がどうなったか（アルカリ性）」の2つの部品で組む。

📚 前提知識

  • 緑→青は、中性→アルカリ性にもどった印。もどした原因が光合成による二酸化炭素の消費。

✍️ 答案の組み立て

  1. 要素A：光合成のため、水中の二酸化炭素を消費した。
  2. 要素B：その結果、水がアルカリ性になった。「光合成をしたから」だけでは、色が変わる仕組み（二酸化炭素→アルカリ性）が抜ける。
模範解答：光合成のため水中の二酸化炭素を消費し、アルカリ性になったから。

790 ③ 試験管Aを用意した理由 まざり型・対照実験の記述

👀 まず見るところ

【まざり型→素材文】部品はAの条件＝水＋BTB＋息は同じで「オオカナダモを入れない」。Bと「ちがう所は1つだけ」と書いて置く → Aは「植物がないとどうなるか」を見るための対照実験、と決まる。

📚 前提知識

  • 対照実験＝調べたい条件だけを変え、ほかはそろえた実験を並べること。Aが緑のままなら、Bの変化は植物のはたらきだと言える。

✍️ 答案の組み立て

  1. 要素A：色の変化が植物のはたらきによるものである。
  2. 要素B：それを確かめるため。「Bと比べるため」だけでは、何を確かめるのかが書けていない。
模範解答：色の変化が植物のはたらきによるものであることを確かめるため。

790 ④ Bをアルミ箔で覆ったときの色 まざり型・条件が変わる

👀 まず見るところ

【まざり型→条件文】③までと変わった部品は「アルミ箔で覆って」に丸。「光なし＝光合成なし・呼吸だけ」と直して書く → 二酸化炭素は増える向きになる。

🔍 こう読み解く

791 ① 肝臓がつくる消化液 知識問題

胆汁（胆液）。肝臓でつくられ、胆のうにたくわえられてから十二指腸に出る。消化酵素はふくまないが、脂肪を細かい粒にして消化を助ける。「つくるのは肝臓、ためるのは胆のう」と場所を分けて覚える。
答え：胆汁（胆液）

791 ②ア・イ・ウ・エ ブドウ糖をグリコーゲンにして蓄える 知識問題

ア 門脈、イ ブドウ糖、ウ グリコーゲン、エ 血中糖濃度（血糖値）。◆ポイント◆のとおり、小腸で吸収されたブドウ糖は門脈を通って肝臓に入り、グリコーゲンに合成されて蓄えられる。必要なときにブドウ糖に戻して流すので、食後も空腹時も血中糖濃度が一定に保たれる。「小腸→門脈→肝臓」の順と、「ためる形＝グリコーゲン／流す形＝ブドウ糖」の組で覚える。
答え：ア 門脈　イ ブドウ糖　ウ グリコーゲン　エ 血中糖濃度（血糖値）

791 ③オ・カ 有害物質の分解とアンモニアの処理 知識問題

オ 有害物質、カ 尿素。肝臓はアルコールなどの有害物質を分解し（解毒）、体に害のあるアンモニアを害の少ない尿素に変える。できた尿素は血液で腎臓に運ばれ、尿として捨てられる（792へつながる）。◆ポイント◆：肝臓は体の中で最も大きく、体重の約1/50の重さがある。
答え：オ 有害物質　カ 尿素

792 ①ア・イ・ウ 腎臓が不要物をこし取る 知識問題

ア 血液、イ 尿素、ウ ぼうこう。腎臓は血液の中から尿素などの不要物をこし取って尿をつくり、輸尿管を通してぼうこうに送ってためる。791③の「肝臓がアンモニアを尿素に変える」→「腎臓が尿素を捨てる」の順で、2つの臓器を1本の流れにして覚える。
答え：ア 血液　イ 尿素　ウ ぼうこう

792 ② 腎臓が量を調節するもの 知識問題

水分。腎臓は血液中の水分の量を調節して、血液中の塩分濃度を一定に保つ。不要物を捨てる（①）だけでなく、「水分の量を調節する」も腎臓のはたらき、と2つで覚える。
答え：水分

788〜792 まとめ 記述の型と知識の流れ

  • 788と790の記述は、呼吸（養分を使う・二酸化炭素を出す）と光合成（養分をつくる・二酸化炭素を使う）の大小で書く。乾燥重量が減る＝呼吸＞光合成、増える＝光合成＞呼吸。BTBが青＝二酸化炭素が減った、黄＝増えた。
  • 789は表の○×を文に直すだけで決まる。「ただし〜の条件は満たしている」に丸をつけ、光だけで発芽が決まる表だと読む。Bが光発芽種子（レタス・タバコ）。
  • 791・792は1本の流れ：小腸→門脈→肝臓（ブドウ糖をグリコーゲンに・アンモニアを尿素に・胆汁をつくる）→腎臓（血液から尿素をこし取り、水分量を調節）→ぼうこう。

793〜798 全体像 光合成曲線・遷移・森林の分布 6問

6問は「グラフを読む問題」と「名前を答える問題」に分かれる。793・794は光合成曲線のグラフで、0の線（横軸）と曲線の交わり方がすべて。795は裸地から極相までの遷移の図で、理由を文で書く。796〜798はバイオーム・森林の分布・どんぐりの一問一答で、知っていれば即答できる。

グラフで使う決まりは2つだけ。光0のときの値＝呼吸の量／曲線が0の線と交わる点＝光補償点（光合成＝呼吸）。この2行を先に余白に書いてから入る。

793 ① 呼吸で出た二酸化炭素の量 資料問題・グラフの読み取り

👀 まず見るところ

【資料問題】部品は資料の正体「光の強さと二酸化炭素の吸収量」と、たて軸の下にある「−8」。光の強さ0の点（グラフの左端）に丸を置く → 光が無いとき吸収量がマイナス＝出した量なので、ここが呼吸の量と決まる。

📚 前提知識

  • 植物は光があってもなくても呼吸をして二酸化炭素を出す。光0なら光合成は0なので、グラフの値はまるごと呼吸の分になる。
  • たて軸の「吸収量」はマイナスなら「放出」。符号を取った数が量。

🔍 こう読み解く

  1. 光の強さ0のところで曲線を見る → たて軸の−8。
  2. −8＝8だけ出している → 呼吸で生じた二酸化炭素は8。
答え：8
コツ：光合成曲線は「左端の値」を最初に読む。呼吸の量が決まると、②③の計算に全部つながる。

793 ② 光補償点とはどんな点か 資料問題・用語の説明

👀 まず見るところ

【資料問題】部品はグラフの書きこみ「光補償点」が置かれている場所＝曲線が0の線（横軸）と交わる点。ここに丸 → 吸収量が0＝「出す量と吸う量が同じ」に直して書くと、答えの文になる。

📚 前提知識

  • グラフの値＝光合成で吸った量−呼吸で出した量（見かけの光合成量）。これが0になるのは、光合成の吸収＝呼吸の放出のとき。
  • 光補償点より弱い光では出す方が多く、植物は成長できない。

🔍 こう読み解く

  1. 交わる点は光の強さ1000のところ。ここで吸収量は0。
  2. 答えは「呼吸で出す二酸化炭素の量」と「光合成で吸う二酸化炭素の量」の2つを入れて、「等しくなる光の強さ」で結ぶ。
答え：呼吸によって放出される二酸化炭素の量と、光合成によって吸収される二酸化炭素の量が等しくなる光の強さ。

793 ③ 光補償点で光合成が吸収した二酸化炭素 資料問題・計算

👀 まず見るところ

【資料問題】部品は設問の「光の強さ1000の光補償点」と、聞かれている「光合成で吸収した」に丸。グラフの0は「吸収−呼吸＝0」なので、「光合成＝呼吸の分」に直して書く → ①の8がそのまま答えになる。

📚 前提知識

  • グラフに出ている吸収量は「見かけ」。本当の光合成量＝グラフの値＋呼吸の量。

🔍 こう読み解く

  1. 光1000でグラフの値は0。
  2. 光合成量＝0＋呼吸8＝8。吸った8をそのまま呼吸で出しているので、見かけは0になる。
答え：8
コツ：「グラフの値」を聞かれているのか「光合成した量」を聞かれているのかを、設問の言葉に丸をつけて分ける。光合成した量なら呼吸の分を足す。

793 ④ 光飽和点とはどんな点か 資料問題・用語の説明

👀 まず見るところ

【資料問題】部品はグラフの書きこみ「光飽和点」の場所＝曲線が折れて水平になる点（光2500・+12）。ここに丸 → 右へ行っても値が増えない、を「光を強くしても光合成量が増えない限界」に直して書く。

📚 前提知識

  • 光を強くすると光合成はふえるが、どこかで頭打ちになる。その限界の光の強さが光飽和点。これより強い光は使い切れない。

🔍 こう読み解く

  1. グラフは光2500までは右上がり、2500からは水平。
  2. 答えは「これ以上強い光を当てても」＋「光合成量が増えない」＋「限界の点」の3つの部品でつくる。
答え：これ以上強い光を当てても光合成量が増えることがない限界の点。

794 ① A・Bが両方とも枯れる光の強さ 資料問題・2本の曲線

👀 まず見るところ

【資料問題】部品は資料の正体「植物A・Bの光合成曲線」と、聞かれ方「両方とも枯れてしまう」。「枯れる＝曲線が0の線より下」に直して書き、A・Bそれぞれが0の線と交わる点に丸 → 2本とも下にある範囲が答えになる。

📚 前提知識

  • 曲線が0より下＝呼吸で出す方が多い＝養分が減り続けて枯れる。0より上なら成長できる。
  • 交わる点（光補償点）は、Bが光2、Aが光6。陰生植物Bの方が左にある。

🔍 こう読み解く

  1. 光0〜2：A・Bとも0より下 → 両方枯れる。
  2. 光2でBはちょうど0（枯れない）。だから「2未満」までが答え。
  3. 光の強さは0から始まるので、範囲は0以上2未満。
答え：0以上2未満
コツ：「以上・未満」は、交わる点そのもので枯れるかどうかで決める。ちょうど0なら減らないので枯れない＝その点は入れない。

弱い光でも成長することができる。グラフのBのように光補償点が低い（呼吸が少なく、少しの光で0を上回れる）のが陰生植物。そのかわり光飽和点も低く、強い光のもとでは陽生植物Aのようには伸びない。

795 ① 裸地に草木が生えない理由 記述・理由

👀 まず見るところ

795 ③ 陽樹林が陰樹林に変わる理由 記述・理由

👀 まず見るところ

【資料問題】部品は図の「陽樹林→混交林→陰樹林」の流れと、聞かれ方「理由」。木が大きくなると林の中が暗くなる、に直して書く → 「暗いと陽樹の幼木は育たず、陰樹の幼木は育つ」が答えの骨になる。

📚 前提知識

  • 陽樹（アカマツなど）は強い光がないと育たない。大きく育った陽樹の影の下は暗く、自分の子ども（幼木）が育てない。
  • 陰樹の幼木は弱い光でも育つ（794③）。暗い林の中で先に大きくなり、やがて林を入れかえる。最後の陰樹の森が極相（◆ポイント◆）。

✍️ 答案の組み立て

  1. 原因：「大きく育った陽樹の影になって、光が当たらない」。
  2. 陽樹側：「陽樹の幼木は十分な光が当たらず育つことができない」。
  3. 陰樹側：「陰樹の幼木は弱い光でも育つことができる」。陽樹と陰樹の両方を書いて「〜から。」で終える。片方だけだと理由として足りない。
模範解答：大きく育った陽樹の影になって、陽樹の幼木に十分な光が当たらず育つことができないが、陰樹の幼木は弱い光でも育つことができるから。
コツ：遷移の順は「裸地→コケ→草原（ススキ・ヨモギ）→陽樹林→混交林→陰樹林（極相）」。図の5区切りをそのまま言えるようにしておく。

803 ③ 巣からえさ場までの距離をどう伝えるか 素材文・記述

👀 まず見るところ

【素材文】設問は「距離をどのように伝えますか」。部品は聞かれ方「どのように」に丸 → 答えの形は「ダンスの何が変わると、えさ場が近い／遠い」。方角（①）は角度、距離はダンスの速さ、と分けて書く。

📚 前提知識

  • 方角は角度で、距離はダンスをおどる速さで伝える。速いほど近く、ゆっくりなほど遠い。

✍️ 答案の組み立て

  1. 要素1: 何で伝えるか＝ダンスをおどる速さ。
  2. 要素2: どちら向きか＝速いほど近い。「速いほど遠い」と逆にしない。
模範解答：ダンスをおどる速さが速いほど、えさ場が近いことを示す。

799〜803 まとめ おさえる3点

  • 800は「矢印が心臓へ向かうか・出ていくか」で動脈・静脈、「酸素が多いか」で動脈血・静脈血。胎児は胎盤で酸素をもらうので、へその緒では静脈に動脈血が流れる。動脈管・卵円孔は肺を通らない近道。
  • 803は「真上＝太陽の方角（正午は南）」と置きかえてから角度を回す。右回り45°＝南西、135°＝北西。距離はダンスの速さ（速いほど近い）。
  • 覚え直しは2組。落葉の色: 赤＝サクラ・イロハモミジ・ツタ／黄＝イチョウ・ポプラ／茶＝クヌギ・コナラ・カシワ・クリ（ケヤキは黄→茶）。種子の散布: 風＝羽・綿毛／動物につく＝とげ・かぎ毛／はじけ飛ぶ＝ホウセンカ・スミレ・カタバミ／食べられる＝ヤマブドウ・ナンテン。
