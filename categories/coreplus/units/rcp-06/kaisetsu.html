76 コオロギの成長を順に説明する 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「エンマコオロギ・卵から終齢幼虫まで」と、矢印の順。矢印をたどりながら、前の写真と変わったところ（卵の中の黒い点・からだの色・背中のはね）に1枚ずつ丸をつける → 変わったところを順に並べれば、そのまま説明の文になる。

📚 前提知識

  • コオロギは不完全変態。幼虫は成虫によく似た姿で、脱皮をくり返して大きくなり、さなぎの時期がない（巻末解説）。
  • メスは注射針のような長い産卵管で、土の中に細長い卵を1個ずつ産む（巻末解説）。

🔍 こう読み解く

  1. 卵の1枚目と2枚目をくらべる。2枚目には黒い点（眼）と横すじ（からだの節）が見える → 卵の中で眼やからだの節ができ始めている。
  2. ふ化直後（左下）は白く小さい。次の2枚は黒く大きくなり、模様も変わる → からだが黒く大きくなるとともに模様が変わる。
  3. 右の大きな写真は背中に注目。小さなはねのようなものが4枚生え始めている（巻末解説の「小さなはね」の矢印）。
答え：卵の中で眼やからだの節ができ始めている。ふ化後、からだが黒く大きくなるとともにからだの模様が変わり、背中に小さなはねのようなものが4枚生え始める。
コツ：「卵の中」「ふ化後」「はね」の3つの時期で区切ると、説明の順番をまちがえない。

77 モンシロチョウとアゲハの幼虫は何をしているか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「モンシロチョウの幼虫（左）とアゲハの幼虫（右）」と、聞かれ方「それぞれ何をしている」。左は幼虫のからだの前半分と後ろ半分の色のちがい、右は口から出ている白い線に丸 → 左＝脱皮、右＝糸、と写真だけで決まる。

📚 前提知識

  • 昆虫は外骨格をもつので、脱皮をして成長する。成虫になったあとは大きさが変わらない（巻末解説）。
  • チョウはガと同じなかまで、幼虫が口から糸を吐く。ただしカイコのような全身をおおう繭はつくらず、糸でからだを葉や枝にとめて蛹になる（巻末解説）。
  • アゲハの幼虫の目玉模様は胸にあり、本当の眼（単眼）は頭に小さくついている。頭の先から出る黄色い角はにおいの出る角（◆ポイント◆）。

🔍 こう読み解く

  1. 左：頭側（左）の緑が濃く、後ろ側はうすく白っぽい皮が残っている。巻末解説の「脱皮後／脱皮中」のとおり、前半分が古い皮から抜け出たところ。
  2. 右：頭の近くから白い線が後ろへのびている。これは口から吐いた糸で、からだを固定して蛹になる準備をしている（巻末解説「糸」「蛹化中」）。
答え：モンシロチョウは脱皮をしている最中で、からだの前半分ぐらいが抜け出ているところ。アゲハは口から糸を吐き出しており、蛹になる準備をしているところ。
コツ：右の写真の「目」に見える模様は胸の模様。頭の位置は、糸が出ている先（黄色い角のある側）で決める。

78 スズメバチの巣の中の様子 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「スズメバチの巣」。六角形の部屋を1つ選び、中に何匹いるかと白い膜（繭）があるかに丸 → 「1部屋1匹」「一部は繭の中」が決まり、さらに幼虫の部屋と蛹の部屋の並び方を見ると産卵の時期の話までつながる。

📚 前提知識

  • スズメバチは完全変態（卵→幼虫→蛹→成虫）。アリに近いなかまで、集団で役割分担をして暮らす社会性昆虫（巻末解説）。
  • 働きバチはすべてメスで、毒針は産卵管が変化したもの。オスバチは女王バチと交尾したあと死ぬ（巻末解説）。

🔍 こう読み解く

  1. どの部屋にも1匹ずつ。白いクリーム色のつるんとした形が蛹（さなぎ）、頭が茶色でしわのあるものが幼虫（巻末解説のラベル）。
  2. 部屋の口に白い膜が張ってあるものがある → 幼虫が糸で作った繭の中で蛹になっている。
  3. 蛹の部屋は左上と右、幼虫の部屋はまん中あたり、とある程度まとまっている → 女王バチが産卵した時期が場所ごとに違うことが分かる。
答え：幼虫や蛹が1つの部屋に1匹ずついて、一部は繭の中に入っている。また、幼虫がいる部屋と蛹がいる部屋がある程度まとまっており、産卵した時期が違うことが分かる。

79 ハサミムシの成長のしかた 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「ハサミムシの巣」と聞かれ方「成長のしかた」。黒い親のまわりに卵のかたまりと白く小さな幼虫があるか丸 → 親が卵・幼虫のそばにいる＝守っている、幼虫が親と同じ形＝不完全変態、の2点で答えが組み立つ。

📚 前提知識

  • ハサミムシはおしりにはさみをもつ不完全変態の昆虫。コオロギやゴキブリのおしりの2本の長い突起が変化したものといわれ、はさみで他の昆虫をとらえて食べる肉食（巻末解説）。
  • 不完全変態＝幼虫の姿が成虫に似ていて、さなぎにならない。

🔍 こう読み解く

  1. 写真のまん中、黒い親のすぐ左に白いつぶが集まっている → 卵。右上や左の白い小さな虫は幼虫（巻末解説のラベル）。
  2. 親が卵と幼虫から離れずにいる → 親が卵や幼虫を守っている（昆虫ではめずらしい）。
  3. 幼虫は小さいがおしりにはさみがあり、親と同じ形 → 幼虫の姿が成虫に似ている＝不完全変態と考えられる。
答え：親が卵や幼虫を守っている。また、幼虫の姿が成虫と似ていることから不完全変態だと考えられる。

80 羽化中のアブラゼミの様子 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「アブラゼミの羽化」。左の茶色いぬけがらと、右の出てきたばかりのからだをくらべ、からだの色とはねの大きさに丸 → 「白い」「縮んでいる」の2語が答え。

📚 前提知識

  • 節足動物は脱皮した直後はからだがやわらかく、色がうすい。時間がたつと固くなり色がつく（巻末解説）。
  • ぬけがらに見える白い糸は、セミの体内の気管（呼吸するための管）もいっしょに脱皮したもの（巻末解説）。
  • 木の根元にある指先ほどの太さの穴は、セミの幼虫が地中から出てきたときの穴（◆ポイント◆）。

🔍 こう読み解く

  1. 左の茶色くて固そうなものが幼虫のぬけがら。右の白っぽいものが羽化中の成虫 → からだが白い。
  2. 右の成虫の背中にある小さく折りたたまれた白いものがはね。のびる前なのではねが縮んでいる。
  3. ぬけがらの背中には小さなはねのあと（巻末解説）。幼虫のときからはねのもとがある、という76のコオロギと同じ見方ができる。
答え：からだが白く、はねが縮んでいる。

81 昆虫のあごや口の動きはヒトとどう違うか 資料問題・写真から考える

👀 まず見るところ

【資料問題】部品は写真の正体「昆虫の顔A〜D」と聞かれ方「あごや口の動きはヒトとどのような違い」。Cのクワガタムシの大あごが左右から向かい合ってついていることに丸 → ヒトの上下のあごとは向きが違う、で決まる。

📚 前提知識

  • Aはアブ（かむ口＋なめる口・はねは2枚）、Bはカミキリムシ（かむ口・甲虫）、Cはクワガタムシ（大あご＋なめる口）、Dはカマキリ（かむ口・3つの単眼）（巻末解説）。
  • ヒトのあごは下あごが上下に動く。昆虫のあごは頭の両わきについていて、左右に開いたり閉じたりする。

🔍 こう読み解く

  1. Cの写真：大きな2本のあごが左右から出て、先が向かい合っている。閉じるときは左右からはさむ形になる。
  2. B・Dのかむ口も同じ。口の左右に小さなあごが並んでいて、横向きに開閉してえさをかじる。
  3. ヒトのように上下に動くあごはない → 違いは「左右に開閉すること」。
答え：左右に開閉すること。
コツ：クワガタムシを正面から見た写真を思い出す。大あごは縦でなく横に開く。

82 アリのような虫はアリとどこが違うか 資料問題・写真の比較

👀 まず見るところ

【資料問題】部品は写真の正体「アリのような虫（左）とアリ（右）」と聞かれ方「どのような点が違う」。左右であしの本数を数えて書き、左のおしりから出ている線に丸 → 8本と糸、の2点でクモだと決まる。

  • 昆虫はあし6本・からだは頭・胸・腹の3つ・触角がある。クモはあし8本・からだは頭胸部と腹部の2つ・触角がなく、おしりから糸を出す（巻末解説の図）。

83 ③・④ 呼吸する部分Aと移動する部分B 資料問題・図の部分の名前

👀 まず見るところ

【まざり型→資料問題】部品は設問の「呼吸をする部分」と「移動するための部分」に丸。図1のAは貝の中のすじの入った膜、図2のBは貝がらから外へ長くのびた白い部分と正体を1行書く → 水中の呼吸＝えら、のびて動く＝あし。

📚 前提知識

  • 水中で暮らすアサリはえらで呼吸する。えらは水中の酸素を取り入れて二酸化炭素を出すほか、えさをこし取るはたらきもある（巻末解説）。カニ（甲殻類）もえらで呼吸する（◆ポイント◆）。
  • 貝のあしは移動したり砂にもぐったりするときに使う。水を吸うのが入水管、出すのが出水管（巻末解説）。

🔍 こう読み解く

  1. 図1のAは貝の中身の、うすくて何枚も重なったすじのある部分。魚のえらと同じ形 → えら。
  2. 図2のBは貝がらのすき間から出た白く長い部分。砂にもぐるときにのばす → あし。図2の右側の小さな2本の管は入水管・出水管で、Bとは別。
答え：③ えら　④ あし
コツ：「水中で呼吸＝えら」「貝が動く部分＝あし」は、軟体動物でも魚と同じ言葉を使う。

  • 観察問題（76〜82）は、写真の正体を1行書いてから前の写真・となりの写真と変わったところに丸をつける。変わったところを順に並べたものが答えの文。

88 ①・② 水面でトンボを食べているのはだれか 資料問題・写真から読む

👀 まず見るところ

📚 前提知識

🔍 こう読み解く

  1. ①：トンボの下に、黒くてつやのある丸いからだの甲虫 → ゲンゴロウがトンボを食べている。

答え：① ゲンゴロウが水面でトンボを食べている。　② アメンボが水面でトンボを食べている。

89 ① アブラムシのまわりで何が起きているか 資料問題・写真から読む

👀 まず見るところ

【資料問題】部品は写真の正体「茎の上のアリ・アブラムシ・白いとげの虫」と聞かれ方「何という昆虫が何をしている」＝名前＋動作。白いとげだらけの虫がテントウムシの幼虫で、これが主語。小さな丸いアブラムシを食べている。

📚 前提知識

  • テントウムシは成虫も幼虫もアブラムシを食べる（◆ポイント◆）。幼虫は白いとげのあるからだで、成虫とは姿がまったくちがう（完全変態）。
  • アブラムシはアリに守ってもらうかわりに、おしりから出る甘い汁をアリにあたえる。だからアリはテントウムシを追いはらおうとする。

🔍 こう読み解く

  1. まん中の白いとげの虫＝テントウムシの幼虫。口の先に小さな丸い虫（アブラムシ）→ 捕食している。
  2. そのまわりに黒いアリが何匹も集まっている → アブラムシを守ろうとしている。
  3. 答えは2つの動きをつなぐ。「テントウムシの幼虫がアブラムシを捕食し、アリがアブラムシを守ろうとしている」。
答え：テントウムシの幼虫がアブラムシを捕食しており、アリがアブラムシを守ろうとしている。
コツ：「幼虫」を落とさない。白いとげの姿は成虫のテントウムシではない。

89 ② 成虫になっているアリは何匹か 資料問題・数える

👀 まず見るところ

【資料問題】部品は聞かれ方「成虫になっている昆虫が何匹」に線。数えるのは黒いアリだけ。白いつぶや白い幼虫は成虫ではないので数に入れない → 大きい1匹＋小さい3匹。

📚 前提知識

  • ②の大きなアリは女王アリ、小さな3匹ははたらきアリ（メス）。女王が産んだ卵や、卵から孵った幼虫・蛹の世話をする（◆ポイント◆）。
  • 白いつぶ＝卵、白くて節のあるもの＝幼虫・蛹。アリは完全変態なので、これらは成虫とは姿がちがう。

🔍 こう読み解く

  1. 左の大きな黒いアリが1匹（女王）。
  2. 右上・右・右下に小さな黒いアリが3匹（はたらきアリ）。

90 A・B・C 羽化の写真を読む 資料問題・写真から読む

👀 まず見るところ

【資料問題】部品は写真の正体「うすい色でやわらかそうな虫が、ぬけがらから出ている」3枚と聞かれ方「何をしている様子」。色がうすい＋ぬけがら＝羽化。あとは「だれが」「何から」を1枚ずつ決める。

📚 前提知識

  • 羽化＝成虫になること。羽化直後はからだがやわらかく、色がうすい（◆ポイント◆）。時間がたつと色がつきかたくなる。
  • 完全変態（テントウムシ）は蛹から成虫に。不完全変態（タガメ・トンボ）は幼虫から直接成虫に。トンボの幼虫はヤゴという名前がある。

🔍 こう読み解く

  1. A：黒い点のある茶色のからから、黄色いまるい虫が出ている。この殻は蛹 → テントウムシが蛹から成虫に羽化。
  2. B：平たく大きな水の虫。うすい赤茶色で、ぬけがらは幼虫の皮 → タガメが幼虫から成虫に羽化。
  3. C：草にぶら下がった黒い殻（ヤゴ）から、白っぽいはねの虫が出ている → トンボがヤゴから成虫に羽化。
  4. 答えは「（名前）が（蛹／幼虫／ヤゴ）から成虫に羽化している様子」の形。完全変態だけ「蛹から」になる。
答え：A テントウムシが蛹から成虫に羽化している様子。　B タガメが幼虫から成虫に羽化している様子。　C トンボが幼虫であるヤゴから成虫に羽化している様子。
コツ：「蛹から」か「幼虫から」かは、虫の名前が決まった時点で完全変態・不完全変態から決める。

84〜90 まとめ 3つの見分け方

  • 仲間分けはあしの数が入口。6本＝昆虫（シミ・シラミ・シロアリ）、8本＝クモ類（ダニ）、たくさん＝甲殻類（フナムシ・フジツボ・カメノテ・ザリガニ）。名前で決めない。
  • 「何をしているか」は主語を正しく。88はトンボが食べられる側、89は白いとげがテントウムシの幼虫、90はうすい色＋ぬけがら＝羽化。
  • 覚え直し：外来種＝アメリカザリガニ（ウシガエルのえさ・100年前）／幼生が漂う＝プランクトン／甲殻類は節足動物／完全変態は蛹から・不完全変態は幼虫から羽化。
