【資料問題】部品は図の正体「地震が発生した地下の位置・その真上の地表の点・観測地点の断面図」を1行で置く。Aは「地震が発生した地点」と書いてあるので震源、Bはその真上の地表（直角の印）で震央、Cは観測地点とAを結ぶ長さなので距離、と図の印から決まる。

📚 前提知識

  • 震源＝地下で地震が起こった場所。震央＝震源の真上の地表の点。
  • 震源距離＝震源から観測地点までの距離。震央から観測地点までは震央距離といい、別の語。

🔍 こう読み解く

  1. A：「地震が発生した地点」の×印 → 震源。
  2. B：Aから真上へのびた線と地表の交点（直角の印） → 震央。
  3. C：観測地点からAへ引いた線 → 点ではなく長さ。震源から観測地点までの震源距離。
答え：A 震源　B 震央　C 震源距離
今回：A ○　B ○　C ×。Cは部品を拾えなかった＝Cが「点」でなく「線の長さ」だという図の形を読まずに、震央などの点の名前を入れた型になりやすい。Cの線の両端（観測地点とA）を見てから語を決める。

313 ② マグニチュードが1大きくなるとエネルギーは約何倍か 条件文・計算

314 ② 震度は何段階か 条件文・数える

👀 まず見るところ

【条件文】部品は「0〜7まで」と「5と6はそれぞれ2つに分かれ」。頭で数えず、0・1・2・3・4・5弱・5強・6弱・6強・7 と紙に並べて書く（直して書く）→ 数えるだけで決まる。

📚 前提知識

  2. 5と6が2つずつに分かれるので、8＋2＝10段階。

315 ア・イ 地震計の記録の2つのゆれの名前 資料問題・図の用語

👀 まず見るところ

【資料問題】部品は図の正体「同じ地震を観測した2地点の地震計の記録（たて軸＝震源距離・横軸＝時間）」と、文の「アは先にくる小さなゆれ、イはあとからくる大きなゆれ」に丸 → 先・小＝初期微動、あと・大＝主要動、と2語で決まる。

📚 前提知識

  • 震源からは速さのちがう2種類の波が伝わる（◆ポイント◆）。速いP波が着くと小さなたてゆれ＝初期微動、おそいS波が着くと大きなよこゆれ＝主要動。
  • P波とS波の到着の時間差（初期微動継続時間）は、震源から遠いほど長い。図でも地点A（遠い）のほうがアの区間が長い。緊急地震速報はこの差を利用している（◆ポイント◆）。

🔍 こう読み解く

  1. 地点Aの記録で、ウ（小さなゆれの始まり）からエ（大きなゆれの始まり）までの小さな波がア → 初期微動。
  2. エのあとの大きな波がイ → 主要動。
  3. ウの線のほうが傾きが急＝同じ時間で遠くまで届く＝P波のほうが速い、と図でも確かめられる。
答え：ア 初期微動　イ 主要動
今回：ア ○　イ ○。

316 ① 上下のゆれを記録する地震計が利用するもの 知識問題

ばね。おもりをばねでつるすと、地面がすばやく上下にゆれても、おもりはほとんど動かずその場に残る（不動点）。この「動かないおもり」と「ゆれる地面」のずれを記録する。上下＝ばね、東西・南北＝ふりこ（②）と向きで組にして覚える。
答え：ばね
今回：×。知識＝地震計の「上下はばね、よこはふりこ」の組が入っていなかった。上下に動けるのはばね、よこに動けるのはふりこ、と向きから結びつける。

316 ② 東西・南北のゆれを記録する地震計が利用するもの 知識問題

ふりこ。◆ポイント◆の図のとおり、ふりこの糸の端を持ってすばやく手をよこに動かすと、おもりはほとんど動かない。この動かないおもりが不動点になり、よこにゆれる地面とのずれを記録できる。東西用と南北用で2台、上下のばね式と合わせて3種類で1セット。
答え：ふりこ
今回：×。知識＝◆ポイント◆の「すばやく動かすとおもりは動かない」をふりこの図ごと覚える。①と組で「上下＝ばね、よこ＝ふりこ」。

317 ① 地震によって海に発生する波 知識問題

津波。海底で地震が起こり海底が上下に動くと、その上の海水が持ち上がって波になり、岸に押しよせる。「海に発生する波」という部分で決まる。
答え：津波
今回：○。

317 ② 地盤がゆるみ建物が倒壊する現象 知識問題

液状化現象。砂と水がまざった地盤が強くゆれると、砂のつぶがばらばらになって地盤が液体のようにゆるむ。建物がかたむいたり、マンホールが浮き上がったりする。うめ立て地や川の近くで起こりやすい。「現象」まで書く。
答え：液状化現象
今回：○。
