1〜8 全体像 写真を見て答える観察問題 8問

8問とも「写真のどこを見るか」で決まる問題。暗記した答えを書くのではなく、写真の中の手がかり（月のどちら側が光っているか・空の明るさ・月の高さ・こげ・環）を1つ丸で押さえてから、知っている決まりとつなぐ。

使う決まりは4つ。月は太陽の光を反射している＝光っている側に太陽がある／地平線近くの月は大気で赤っぽく・ゆがんで見える／満潮は月の南中から少し遅れて来る／月には大気がない（空は暗い・クレーターが残る）。

1 のぼってくる細い月は明け方か夕方か 資料問題・写真

👀 まず見るところ

【資料問題】部品は写真の正体「地平線の近くに見える細い月」と、設問の「のぼってくる」。写真で月の光っている側と、空の明るい側に丸 → どちらも左なので、太陽は左（＝のぼる側）の地平線の下にある、と決まる。

📚 前提知識

  • 月は太陽の光を反射して光っている。だから光っている側に太陽がある。
  • 二十七日の月（左が細く光る）は明け方の東の空。三日月（右が細く光る）は夕方の西の空（◆ポイント◆）。

🔍 こう読み解く

  1. 写真の月は左側が光っている。空も左のほうが明るい（巻末解説は「朝焼け」と書いている）。
  2. のぼってくる月なので、見ているのは東の空。太陽もそのすぐ下、つまりこれから日の出 → 明け方。
  3. 確かめ：巻末解説の写真では時計が7時を指している。朝6〜7時に東の空、で話が合う。
答え：明け方
コツ：「細い月」と見たら、光っている側に小さく「太陽」と書きこむ。左なら明け方の東、右なら夕方の西。

2 沈む満月は南中している満月とどこが違うか 資料問題・写真の比較

👀 まず見るところ

【資料問題】部品は2枚の正体「②沈む満月」と「④南中している満月」。②は地平線の近く、④は空の高い所、と正体に書きそえる → 違いは「色・形・模様の向き」の3つに分けて写真を見くらべる。

📚 前提知識

  • 地平線の近くにある月は、地球の大気で光の進み方が変わるため、朝焼け・夕焼けと同じように赤っぽく見え、輪郭がゆがんで縦につぶれる（巻末解説）。
  • 月面の黒い模様（海）の傾きは、月の出・南中・月の入りで変わる。満月は朝6時頃に沈む。

🔍 こう読み解く

  1. 色：②は赤っぽい、④は白い → 赤っぽく見える。
  2. 形：②は上下につぶれて横長で、ふちが波打っている → 輪郭がゆがむ・縦につぶれて横長。
  3. 模様：②の海の形は、④の南中した満月と向きが合っていない → 黒い模様（海）の傾きが違う。巻末解説は「月の入りの頃の傾き」と同じ、と説明している。
答え：赤っぽく見える。輪郭がゆがんで見える。縦につぶれて横長に見える。黒い模様（海）の傾きが違う。
コツ：「どのような点が違うか」は、色・形・模様 のように観点を先に書き出してから1つずつ見くらべると、1つで止まらない。

3 クレーターがよく見えるところ 資料問題・写真

👀 まず見るところ

【資料問題】部品は「A・Bの見え方を参考に」と、④の2枚の正体「満月と下弦の月」。③でA・Bのどちらに影が多いかに丸 → 影が多い側＝光と暗やみの境目の近く、と決まり、④ではその場所をさがす。

📚 前提知識

  • ③は左側から日光が当たっていて、Aは影が少し、Bはほとんどが影（◆ポイント◆）。クレーターは影があって初めて立体的に見える。
  • 満月は正面から日光が当たるので、クレーターの影がほとんどできず見えにくい（巻末解説）。

🔍 こう読み解く

  1. ③で、Bは右の暗い部分のすぐ近く＝光が横からななめに当たる場所。影が長くのびて、くぼみがはっきりする。
  2. ④の満月は全体が正面から照らされ、影がない → 見えにくい。
  3. ④の下弦の月で、光と影の境目のラインに目を向ける。ここがBと同じ条件 → 半月の満ち欠けの境目付近。
答え：半月の満ち欠けの境目付近
コツ：「影がある＝横から光」「影がない＝正面から光」の2行を余白に書いてから写真にもどる。

4 干潟を通る道路の写真の様子 資料問題・写真と潮の満ち干

👀 まず見るところ

【資料問題】部品は設問の「潮の満ち干は月の引力と関係」と、写真の正体「干潟を通る道路」。写真の右上の小さな月の高さと、電柱の列の足もとに丸 → 月は高い（南中の少しあと）・道路は水の下、の2つが決まる。

📚 前提知識

  • 海水は月に引かれるように動き、月の南中から少し遅れて満潮になる（巻末解説）。
  • 満潮と干潮は約6時間おきに入れかわり、干潮のときは◆ポイント◆の写真のように道路が現れる。満月・新月のときは差が最大（大潮）。

🔍 こう読み解く

  1. 写真の月は空の高い所にある → 南中したばかり、またはその少しあと（巻末解説では「下弦の月の少し前」）。
  2. 南中から少し遅れて満潮 → 今はちょうど潮が満ちている時間。
  3. 電柱の列は海の上に立っていて、道路の面が見えない → 道路は水没している。◆ポイント◆の干潮の写真と見くらべると差がはっきりする。
答え：月が南中してから少し経っており、潮が満ちて道路が水没している。
コツ：空の月を見落としやすい。「月の引力」と設問にあったら、写真の空に月をさがす。

5 月面で見上げた空は地球の空とどう違うか 資料問題・写真

👀 まず見るところ

【資料問題】部品は写真の正体「月面で見上げた空」と、設問の「地球で見上げた空と」の比較。写真の左上の太陽と、そのまわりの空の色に丸 → 太陽が出ているのに空が黒い、が決まる。

📚 前提知識

  • 地球の空が青いのは、大気が青っぽい光を散乱させるから。月には大気がないので、昼でも空は真っ暗（巻末解説）。
  • 月のように小さく重力が弱い天体は、大気を引きとめられないので、大気がないのがふつう。

🔍 こう読み解く

  1. 写真では左上に太陽が強く光っている → 昼間。
  2. それでも空は黒い。地球なら青空になるところ。
  3. 違いを1文に：太陽が見えているが、空は暗い。理由を聞かれたら「大気がないから」。
答え：太陽が見えているが、空は暗い。

6 宇宙船が地球に戻るときの危険 資料問題・写真から理由

👀 まず見るところ

【資料問題】部品は写真の正体「月から帰還したアポロ宇宙船（実物）」と、設問の「⑦から〜分かりますか」＝写真に証拠がある。宇宙船の底の黒いこげに丸 → 高温になった、が決まる。

📚 前提知識

  • 宇宙には空気抵抗がなく、宇宙船は秒速10km近くで大気にぶつかる。前の空気が圧縮されて1000℃以上の高温になる（巻末解説）。

🔍 こう読み解く

  1. 写真の下半分、宇宙船の底の面が黒く焦げている（巻末解説は「黒く焦げた宇宙船の底」と印をつけている）。
  2. 焦げる＝強い熱を受けた証拠。熱を受けたのは地球にもどるとき＝大気圏へ突入する際。
  3. 答えは「証拠 → 分かること」の形で：底面がこげている → 大気圏突入で非常に高温になる。
答え：宇宙船の底面がこげていることから、大気圏へ突入する際に非常に高温になることが分かる。
コツ：「〜から…が分かりますか」は、写真の証拠を先に書いてから結論を書く。証拠を落とすと半分の答えになる。

7 望遠鏡で見た木星と土星の特徴 資料問題・写真

👀 まず見るところ

【資料問題】部品は写真の正体「天体望遠鏡で観察した木星と土星」と、設問の「それぞれ」＝2つ分書く。写真の大きいほうのしま模様とまわりの小さな点、小さいほうの環に丸 → 木星と土星の特徴が1つずつ決まる。

📚 前提知識

  • 木星は太陽系最大の惑星で、表面に赤い帯のしま模様がある。地球から観察しやすい4つの大きな衛星（イオ・エウロパ・ガニメデ・カリスト）をガリレオ衛星とよぶ（巻末解説）。
  • 土星には大きな環があり、環の見え方や明るさは日によって変わる（◆ポイント◆）。

🔍 こう読み解く

  1. 写真の下の大きな天体が木星。赤っぽいしま（帯）があり、そのそばに小さな点が4つ並んでいる → 木星の衛星。
  2. 右上の小さいほうが土星。本体のまわりに環がついて見える。
  3. 木星：赤い帯＋4つの衛星。土星：大きな環。「それぞれ」なので2つを分けて書く。
答え：木星には赤い帯があり、4つの衛星が見られる。また、土星には大きな環が見られる。

8 A・Bのどちらが早い時刻の上弦の月か 資料問題・写真

👀 まず見るところ

【資料問題】部品はA・Bの正体「右側が光る半月＝上弦の月」と、聞かれ方「どちらの方が早い時刻」。月の形は同じなので、見るのは空の明るさ。Bは青空、Aは黒い空に丸 → Bは日没前、Aは日没後と決まる。

📚 前提知識

  • 上弦の月は18時頃に南中し、月の出は12時頃、月の入りは0時頃（◆ポイント◆・巻末解説の図）。
  • 巻末解説の図では、15時頃は南東の空（まだ昼で空が明るい）、21時頃は南西から西の空（日没後で暗い）。

🔍 こう読み解く

  1. Bは空が青い＝まだ日没前。上弦の月が日没前に見えるのは、南中する前の南東の空（15時頃）。
  2. Aは空が黒い＝日没後。南中を過ぎて南西から西にかたむいた月（21時頃）。
  3. 早いのは日没前のB。
答え：B
コツ：同じ形の月が2枚なら、見くらべるのは月でなく空の明るさ。上弦は「昼に出て夕方に南中、夜中に沈む」。

1〜8 まとめ 写真の見方

  • 月の問題は「光っている側に太陽」から入る。左が光れば明け方の東（1）、右が光れば上弦や三日月で夕方の空（8）。空の明るさは時刻の証拠になる。
  • 地平線近くの月は大気のせいで赤く・ゆがむ（2）。逆に月には大気がないので、空は暗く（5）、クレーターも消えずに残る（3）。宇宙船のこげも、地球の大気に高速でぶつかった証拠（6）。
  • 「〜から分かること」「それぞれ」「どのような点が違うか」の問いは、写真の証拠を先に書き、答えの数を設問に合わせる（4・6・7は2つの要素、2は4つ）。

9 月の「海」が平らな理由 素材文・理由の記述

👀 まず見るところ

【素材文】設問は「なぜ平らか」。部品は手がかりの言葉「ゲンブ岩でできており」に丸 → ゲンブ岩＝マグマが固まった岩、と正体を1行書く → 「流れたマグマが固まった」が答えの骨になる。

📚 前提知識

  • ゲンブ岩はマグマが冷えて固まった黒っぽい岩石（◆ポイント◆）。写真のキラウェア火山（ハワイ）の溶岩のように、ねばり気の少ないマグマは流れやすく、低いところへ広がる。
  • 月の黒い模様が「海」。海の形は「餅をつくウサギ」にたとえられ、海の傾きを見ると月の向き（方角）が分かる（巻末解説 P.206）。

🔍 こう読み解く

  1. 「平ら」なものはどうやってできるかを考える。さらさら流れるものがくぼみにたまると、表面は水面のように平らになる。
  2. ゲンブ岩のもと＝ねばり気の少ないマグマ。それがくぼみに広がってたまり、固まったのが海。だから平らで、色も黒い。
  3. 答えは「ねばり気の少ないマグマ」「くぼみに広がりたまる」「固まった」の3つの部品を順につなぐ。
答え：ねばり気の少ないマグマがくぼみに広がりたまって固まってできたから。
コツ：理由の記述は「何が／どうなって／だから平ら」の順。「ゲンブ岩だから」だけでは理由になっていない。

10 地球にクレーターが少ない理由（2つ） 素材文・理由を2つ

👀 まず見るところ

【素材文】部品は「月に比べて」と答え方の指示「2つ」に丸。「月に無くて地球にあるもの」を3語で書く（大気・雨・風）→ 隕石が落ちる前と落ちたあと、で理由が1つずつ決まる。

📚 前提知識

  • クレーターは隕石がぶつかってできた穴。月には大気も水もないので、隕石はそのままぶつかり、できた穴もそのまま残る。
  • 地球でクレーターが残るのは、風化・侵食を受けにくい砂漠など（◆ポイント◆）。写真のアメリカのクレーターもその例。

🔍 こう読み解く

  1. 落ちる前：地球には大気がある → 隕石は大気にぶつかって燃え尽きる。地面まで届くものが少ない。
  2. 落ちたあと：地球には雨や風がある → できたクレーターが風化や侵食でくずれ、長い年月のうちに消える。
  3. 「前」と「あと」で1つずつ。これで2つがそろう。
答え：・地球の大気にぶつかって隕石が燃え尽きるから。　・雨や風などによってクレーターが風化や侵食されるから。
コツ：「2つ答えなさい」は、同じ理由の言いかえを2つ書かない。落ちる前／落ちたあと、と時間で分けると別の理由になる。

11 ① 月食の月は南中の前か後か 資料問題・写真の見くらべ

👀 まず見るところ

【資料問題】部品は写真の正体「月食の満月」と、くらべる相手「P.4の④の満月（南中している）」。2枚を並べ、黒い模様（海）の傾きが同じかずれているかを見る → 傾きで時刻が決まる。

📚 前提知識

  • 月は東からのぼり、南を通って西に沈む。その間に月面の模様は少しずつ回って見え、のぼるときと沈むときで模様の傾きがちがう（◆ポイント◆）。南中のときの傾きが基準。
  • 月食は太陽・地球・月が一直線に並ぶ満月のときに起こる。満月は18時頃に出て、0時頃に南中し、6時頃に沈む（巻末解説の図）。

🔍 こう読み解く

  1. ④の南中している満月で、大きな海のかたまりがどこにあるかを見る（左上のあたり）。
  2. 11の写真の海は、それと同じ向きになっていない＝月が傾いている。
  3. 巻末解説「満月の動き」の図で同じ傾きの月をさがすと、21時頃の月に近い。南中（0時頃）より前 → 「南中する前」。
答え：南中する前
コツ：写真の見くらべは「同じ模様が基準の写真からどちらに回ったか」を矢印で描く。頭の中で回さない。

11 ② 満ち欠けと月食の欠け方のちがい 資料問題・写真の見くらべ

👀 まず見るところ

【資料問題】部品は聞かれ方「欠け方にどのような違い」と、くらべる相手＝④の下弦の月。欠けている境目の線に注目し、「どこを通るか」「くっきりか」の2点で2枚に○×をつける。

📚 前提知識

  • 満ち欠けの影は月自身の夜の部分。太陽は月のちょうど半分を照らすので、境目の線は月の中心を通り、くっきりしている（④の下弦の月）。
  • 月食の影は地球の影。地球は月よりずっと大きいので影のふちは大きな円弧になり（◆ポイント◆の図A）、地球の大気を通った光のせいで輪郭がぼやける（図B）。

🔍 こう読み解く

  1. 線の通る場所：④の下弦は中心をまっすぐ通る。11は中心をはずれた大きな弧。
  2. 線のようす：④はくっきり、11はぼんやり。
  3. この2点をそのまま文にする。
答え：・影の境界線が月の中心線を通っていない点。　・影の境界線がぼやけている点。

12 天体の大きさと形の関係 資料問題・写真と数値

👀 まず見るところ

【資料問題】部品は写真の下の数字「長径535m」「直径23km」「直径2400km」と形。正体を1行＝「左から小さい順、形はいびつ→丸」と書く → 大きさと形の関係がそのまま答えになる。

📚 前提知識

  • 天体が丸い形をしているのは自身の重力が原因（◆ポイント◆）。大きいほど重力が強く、でこぼこを中心に引き寄せて球に近づく。
  • イトカワは小惑星、フォボスは火星の衛星、冥王星は準惑星。どれも「惑星以外の天体」。

🔍 こう読み解く

  1. 535m（イトカワ）：落花生のようにいびつ。23km（フォボス）：ごつごつした丸。2400km（冥王星）：ほぼ球。
  2. 単位が m → km → km と大きくなるにつれ、形は球に近づく。
  3. 答えは「大きくなるほど球に近い」。逆向き（小さいほどいびつ）でも同じ内容。
答え：天体の大きさが大きくなるほど形が球に近くなる。
コツ：単位がちがう数字は先にそろえる（535m＝0.535km）。並び順を確かめてから関係を書く。

13 ① 望遠鏡で見た惑星を太陽に近い順に 資料問題・写真と順番

👀 まず見るところ

【資料問題】部品は「太陽に近い順に左から」と、写真の正体＝5つ（地球は入らない）。「水金地火木土天海」を余白に書き、地球を飛ばして5つを当てはめる。写真の色と環で答え合わせ。

📚 前提知識

  • 太陽に近い順：水星・金星・地球・火星・木星・土星・天王星・海王星。地球は金星と火星の間（◆ポイント◆）。地球から撮った写真なので地球は写らない。
  • 見分け：火星は鉄のさび（酸化鉄）で赤い。木星はしま模様で最大。土星は環。水星は小さく、金星は明るく大きく見える。

🔍 こう読み解く

  1. 「水金地火木土」から地球を外す → 水・金・火・木・土の5つ。写真も5枚 → 数が合う。
  2. 左から：小さな点＝水星、明るい丸＝金星、赤＝火星、しま＝木星、環＝土星。色と形が順番どおりなので確定。
  3. 土星の右（外側）に天王星・海王星があるが、写真には無い。
答え：水星・金星・火星・木星・土星
コツ：「地球から見た」とあれば、答えの列に地球を入れない。5枚と5つで数を合わせてから書く。

13 ② 惑星が月より暗く見える理由 素材文・理由の記述

👀 まず見るところ

【素材文】部品は「月と同じく太陽の光を反射」と「月よりも暗く」に丸。「同じ」なのに「暗い」→ 月と惑星でちがうものを1語で書く（距離）→ 答えの中心が決まる。

📚 前提知識

  • 光は距離が2倍になると明るさは1/4、3倍で1/9（◆ポイント◆）。遠いほど急に暗くなる。
  • 月は地球のすぐそばを回る衛星。惑星は太陽のまわりを回るので、地球からの距離は億km単位でけたちがいに遠い（巻末解説の「太陽からの距離」の表）。

🔍 こう読み解く

  1. 「反射して光る」のは同じ。ちがうのは地球からの距離。
  2. 遠いほど届く光は弱い（2倍で1/4）。惑星は月よりはるかに遠いので暗い。
  3. 答えは「地球との距離が月に比べて遠いから」。「小さいから」ではない（木星は月よりずっと大きい）。
答え：地球との距離が月に比べて遠いから。

14 ① 三日月が沈みかけている西の空は、いつか 素材文・時刻の選択

👀 まず見るところ

【素材文】部品は手がかりの言葉「三日月」「沈みかけている」「西の空」に丸。三日月は夕方の西の月、と正体を1行書く → 選ぶのは「日の入りの少しあと」。

📚 前提知識

  • 三日月＝15時頃南中、夕方に西の空、右側が光る（巻末解説の表）。日の入り後、西の低い空にしばらく見えてから沈む。
  • 反対に明け方の東の空に見えるのは二十七日の月（9時頃南中、左側が光る）。「日の出の少し前」はこちら。

🔍 こう読み解く

  1. 三日月は太陽のすぐ東側にある → 太陽が沈んだ直後の西の空で見える。
  2. 「沈みかけている」＝月の入り。三日月の月の入りは日の入りの少しあと。
  3. 「日の出の少し前」なら東の空に二十七日の月。西と東が逆なので×。
答え：日の入りの少しあと
コツ：月の形→時刻は「三日月＝夕方西、二十七日の月＝明け方東」の2行を余白に書く。

14 ② 宵の明星と呼ばれる星 知識問題

金星。夕方に西の空で見える金星が宵の明星、明け方に東の空で見える金星が明けの明星（巻末解説の表）。金星は地球より内側を回るので夕方か明け方の数時間しか見えず、地球に最も近い惑星なので大きく明るく見える（◆ポイント◆）。写真の「左側が欠けた（右側が光る）」形は、夕方の西の空の金星の形と一致する。
答え：金星

15 ロケットが積んでいる液体 素材文・空らん

👀 まず見るところ

【素材文】部品は手がかりの言葉「燃料を燃やすために」「液体にした」に丸。「燃やすのに必要なもの」と正体を1行 → 酸素と決まる。2つの空らんは同じ言葉。

📚 前提知識

  • 物が燃えるには酸素が必要（◆ポイント◆）。空気のない宇宙では、燃料だけでは燃えない。
  • 酸素は−183℃で液体になる（◆ポイント◆）。
  • 月面には空気がなく風も吹かない → 国旗に支えをつけて立てた（◆ポイント◆の写真）。

🔍 こう読み解く

  1. 1つ目の空らん：宇宙に無くて、燃やすのに要るもの＝酸素。「空気」と書きたくなるが、2つ目の空らん「液体にした〔　〕」と同じ言葉なので、燃焼に関係する酸素にしぼる。
  2. 側面の氷の話が確かめになる：−183℃の液体酸素で冷やされ、まわりの水蒸気が氷になった。
答え：酸素（2つの空らんとも）
コツ：同じ文の中に空らんが2つあるときは、両方に入れて読み直す。片方だけ合う言葉は答えではない。

9〜15 まとめ 見直しの要点

  • 理由の記述（9・10・13②）は、問題文の手がかりの言葉（「ゲンブ岩」「月に比べて」「反射」）に丸をつけ、「何が／どうなって／だから」の3つでつなぐ。10は落ちる前（大気）／落ちたあと（雨や風）で2つ。
  • 写真の見くらべ（11・12）は基準を決める：11は④の満月・下弦の月と並べて模様の傾きと影の境目（中心を通らない・ぼやける）、12は数字の順にいびつ→球。
  • 覚え直し：水金地火木土天海（地球から見た写真には地球が無い）／三日月＝夕方の西・二十七日の月＝明け方の東／宵の明星・明けの明星＝金星／燃えるには酸素（−183℃で液体）。
