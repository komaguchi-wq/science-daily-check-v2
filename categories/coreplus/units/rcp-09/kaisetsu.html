121 カラスノエンドウのさやの変化 資料問題・写真の観察

👀 まず見るところ

【資料問題】部品は写真の正体「道端のカラスノエンドウ」と、設問の「果実（さや）を探し」「時間とともに」。写真の中のさやを全部丸で囲み、色と形で順に並べる → 緑→黒→ねじれて開く、の順が決まる。

📚 前提知識（あれば答え合わせに使う）

  • カラスノエンドウは春に道端で見られる雑草。食用のエンドウより小さく、葉が変化した巻きひげでつる（茎）を支えてのびる（巻末解説）。
  • 緑のさやは未熟で種子はやわらかく、熟すと固くなる。ダイズを未熟なうちに収穫したものが枝豆（巻末解説）。

🔍 こう読み解く

  1. 写真の左に細長い緑色のさや（A）。右上に黒いさや（B）。
  2. 中央より少し左の黒いさやは、2つに割れてねじれて開いている（C）。左下には開いて種子がほとんど残っていないさや（D）。
  3. 色は緑→黒、形は閉じる→ねじれて開く、と2つの軸で並べて答えにする。
答え：最初はさやが緑色をしているが、種子が熟すと黒くなり、ねじれるように開く。
コツ：「変化」を聞かれたら、写真の中で同じものを2つ以上見つけて、ちがいを「色」と「形」の2語で書く。

122 カラスノエンドウの種子の広がり方 資料問題・写真から考える

👀 まず見るところ

【資料問題】部品は121で丸をつけた「ねじれて開いたさや」と、設問の「どのようにして広がる」。開いたさやに種子が残っていない、という写真の事実を1行で置く → ねじれて開くときに散らばる、と決まる。

📚 前提知識（あれば答え合わせに使う）

  • 豆のさやはめしべの子房だった部分。受粉のあと、子房以外（花びらなど）が枯れて、子房だけが育ってさやになる（◆ポイント◆・インゲンマメの写真）。

🔍 こう読み解く

  1. 開いたさや（C・D）は中が空。種子は動物に運ばれたのでも、風で飛ぶ形でもない。
  2. ねじれて開く＝さやが勢いよく割れる動き。その力で種子が周囲に散らばる。
答え：さやがねじれて開くときに、周囲に種子が散らばる。
コツ：「どのように広がる」は、写真にある動きの言葉（ねじれる・開く）をそのまま答えに使う。

123 豆のへそとはどのような部分か 資料問題・写真から考える

👀 まず見るところ

【資料問題】部品は設問の定義「豆の黒い部分をへそ」と、ソラマメの写真の「さやの内側のくぼみ」。黒い部分がさやのどこに向いているかを写真に線で置く → へそ＝さやとつながっていた所、と決まる。

📚 前提知識（あれば答え合わせに使う）

  • さやは親のからだの一部。種子（胚珠が育ったもの）は、さやからへそを通じて栄養分をもらう（巻末解説）。根はへそのわきから生えてくる。
  • エンドウの種子はグリーンピース、発芽直後のものは豆苗。子葉（種子の栄養）が根元についているので、切ってもまた何度かのびる（◆ポイント◆）。

🔍 こう読み解く

  1. ソラマメの写真で、豆の黒い部分はさやの内側のくぼみと向かい合っている。ここでくっついていた。
  2. エンドウの写真では、右の豆のへそのわきから白い根が出ている。へそが種子の「入口」になっている。
  3. つながっていた部分なので、種子が散らばるときにここで外れる。
答え：へそはさやとつながっており、種子が散らばるときに外れる。
コツ：「どのような部分か」は「何とつながっていたか」で答える。くっついていたあとは、くぼみや色のちがいとして写真に残る。

124 アサガオとイネの発芽のちがい 資料問題・写真をくらべる

👀 まず見るところ

【資料問題】部品は写真の正体「アサガオとイネの発芽・上が前、下が後」と聞かれ方「どのような違い」。下の2枚で「種子の中身がどれだけ外に出たか」をくらべる → 全部出る／1か所から出る、の差が決まる。

📚 前提知識（あれば答え合わせに使う）

  • アサガオは双子葉植物で無胚乳種子（養分を子葉にたくわえる）。イネは単子葉植物で有胚乳種子（養分を胚乳にたくわえる）（巻末解説）。
  • 胚乳は栄養のかたまりで、成長とともに小さくなっていく。

🔍 こう読み解く

  1. アサガオ（下）：黒い種皮が空っぽになって残り、中身が全部外に出ている。出てきた黄色い部分はほとんど葉（子葉・双葉）。
  2. イネ（下）：種子はそのまま残り、1か所から小さな芽と根だけが出ている。中の胚乳が残っているから。
  3. 「中身がすべて出る」対「1か所から出る」の形でまとめる。
答え：アサガオは種皮を脱ぎ捨てるように中身がすべて出てきており、中身はほとんど葉（子葉・双葉）である。それに対し、イネは種子の1か所から小さな芽と根が出てくる。
コツ：「違い」の答えは「Aは〜。それに対しBは〜。」の2文で書く。片方だけ書くと半分になる。

125 ダイコンの成長で見られる変化 資料問題・写真をくらべる

👀 まず見るところ

【資料問題】部品は写真の正体「ダイコンの栽培・左から右へ育つ」と聞かれ方「どのような変化」。3枚で「消えたもの」と「太ったもの」を1つずつ丸で置く → 子葉がなくなる・根が太くなる、と決まる。

📚 前提知識（あれば答え合わせに使う）

  • ダイコンはアブラナ科。芽生え（スプラウト）がカイワレダイコン（巻末解説）。
  • 食べるダイコンは胚軸と幼根が育った部分。ダイコンのひげは主根からのびる側根（巻末解説）。

🔍 こう読み解く

126 ゾウムシはどのように産卵するか 資料問題・写真から考える

👀 まず見るところ

【資料問題】部品は写真の正体「青いドングリにつくゾウムシ」と設問の「どのように産卵」。左の写真でゾウムシの長い口の先がどこに当たっているかに丸 → 口で穴を開けて中に卵を産む、と決まる。

📚 前提知識（あれば答え合わせに使う）

  • ゾウムシはカブトムシと同じ甲虫のなかまで完全変態（巻末解説）。長いのは鼻ではなく口と頭の一部。
  • この長い口で植物の種子に穴を開けて中に産卵する農業害虫。お米に産卵するコクゾウムシも同じなかま（巻末解説）。

🔍 こう読み解く

答え：未熟な青いドングリに長い口をさして穴を開けて卵を産み付ける。

127 野菜工場の写真で気づいたこと 資料問題・写真から考える

👀 まず見るところ

【資料問題】部品は写真の正体「ブロッコリーの野菜工場」と設問の「気づいたことを説明」。部屋全体が赤紫色、という写真の事実を1行で置く → ライトの色の組み合わせの話に決まる。

📚 前提知識（あれば答え合わせに使う）

  • 赤・青・緑は光の3原色。重ねると別の色になり、赤＋青＝赤紫（◆ポイント◆・巻末解説）。
  • 葉は緑色で、緑の光は反射されるため光合成にあまり使われない。だから赤と青のライトを使う（巻末解説）。ブロッコリーは赤色光で発芽が促進される。
  • 野菜工場は土を使わない水耕栽培が多く、室内管理で安定して収穫できるが、コストがかかる（巻末解説）。

🔍 こう読み解く

  1. 天井のLEDライトの列が見え、苗も床も赤紫色に照らされている。
  2. 赤紫＝赤＋青。青いライトと赤いライトが並んでいる、と色から逆算する。
  3. 余裕があれば「緑の光は葉に反射されて使われにくいので、緑を省いている」まで書くと説明になる。
答え：部屋が全体的に赤紫色に照らされているので、青いライトと赤いライトが並んでいると考えられる。
コツ：「気づいたこと」は、写真でいちばん目立つ色や形を1つ言い、その理由を1文そえる。

128 ② 種子を割ると出る白い粉は種子のどの部分か 素材文・穴うめ

👀 まず見るところ

【素材文】設問は「白い粉は種子の〔②〕の部分」。部品は手がかりの言葉「種子を割ると」「白い粉」に丸 → 白い粉＝養分（でんぷん）のかたまり＝胚乳、と決まる。

📚 前提知識

  • 双子葉植物は子葉に養分をたくわえるものが多いが、オシロイバナやカキのように胚乳にたくわえるものもある（◆ポイント◆）。
  • オシロイバナは有胚乳種子で、胚乳にでんぷんをたくわえている。果実は果皮が硬く、一見、種子と区別がつかない（巻末解説）。

🔍 こう読み解く

  1. 「白い粉」が出るほど大量にある部分＝養分をためている部分。胚（芽や根になる部分）は小さいので違う。
  2. 双子葉だから子葉、と反射で答えない。オシロイバナは例外で、養分は胚乳にある。
答え：胚乳
コツ：「双子葉＝無胚乳」の例外（オシロイバナ・カキ）は、写真の白い粉とセットで覚える。

121〜128 まとめ 観察問題の書き方

  • 「変化」「違い」は、写真の中で同じものを2つ見つけて色と形でくらべる（121・124・125）。答えは「Aは〜。それに対しBは〜。」の2文。
  • 「どのように」は、写真で目立つ動き・道具・場所を設問の言葉のまま使う（122 ねじれて開く／126 長い口で穴を開ける／127 赤紫＝赤＋青）。
  • 覚え直し：へそ＝さやとつながっていた所／アサガオ＝無胚乳・イネ＝有胚乳／オシロイバナとカキは双子葉でも胚乳に養分／ダイコンの食べる部分＝胚軸＋幼根。

rcp-09 129〜135（p.38〜39・種子と発芽）

129〜135 全体像 種子のつくり・発芽・種子の散布 7問

7問は3つの話に分かれる。129・130・135は種子のどこに養分があるか（子葉＝無胚乳種子／胚乳＝有胚乳種子）。131・132は光と発芽後の姿（もやし）。133・134は種子の運ばれ方（風・はじける・動物の毛）。

写真で決める問は、まず「写真の正体」を1行書く。ドングリなら「2枚に開いた子葉」、マツの種子なら「はね」、ダイズなら「黄色い子葉・細長い胚軸」。この1行が答えの部品になる。

無胚乳種子子葉ドングリ・クリ・ダイズ・ヒマワリ・クルミ

129 ①・②・③ ドングリは何科・養分はどこ・何種子か 知識問題

①ブナ科 ②子葉 ③無胚乳。ドングリはブナ科（コナラ・クヌギ・クリなど）の堅い果実をまとめて呼ぶ名前。左の写真で、殻の中身が2枚に開いているのが子葉で、ここに養分をためる＝無胚乳種子（◆ポイント◆）。子葉が2枚＝双子葉植物、とセットで決まる。巻末解説のとおり、ブナ科の子葉は分厚く、発芽しても地上に出ずに地中に残る。右の写真で上に広がる葉は本葉で、子葉は根元の地面近くに残っている（赤っぽい2枚）。
答え：① ブナ　② 子葉　③ 無胚乳
コツ：「無胚乳＝胚乳が無い＝養分は子葉」と、言葉の中に答えがある。②と③は1組で答える。

130 ① 発芽で最初に出るのは芽と根のどちらか 知識問題

根。発芽ではまず幼根が種皮を破って出て、水を吸えるようにしてから芽がのびる。右の写真（クリの縦断面）では、とがった先端の近くに小さな幼根があり、ここから根が出る（◆ポイント◆）。
答え：根

130 ② クリが発芽した直後の様子を作図する 資料問題・作図

👀 まず見るところ

【資料問題】部品は写真の正体「クリを縦に切断した断面」と、①で決めた「最初に出るのは根」。断面のとがった先端の近くにある幼根の位置に丸 → 根はそこから出る、と図に置く。

📚 前提知識

  • ブナ科の子葉は分厚く、発芽しても地中に残る（巻末解説）。だから発芽直後の図に、地上に出た子葉は描かない。

🔍 こう読み解く

  1. クリの形をそのまま描く（下が丸く、上がとがった形）。
  2. とがった先端から根を1本出し、下向きに曲げて長くのばす。紙面の答えの写真も、先端から出た根が横にのびてから下へ向かっている。
  3. 子葉は殻の中に残したまま。芽はまだ描かない（根が先）。
答え：紙面の写真を参照（クリの先端から根が出て、下向きにのびている図）
コツ：自分で描いたら「根はどこから出ているか」「子葉は殻の中か」の2点を確かめる。

131 図1と図2のダイズの見た目のちがい 資料問題・写真の比較

👀 まず見るところ

【資料問題】部品は写真の正体「どちらもダイズの発芽直後」と聞かれ方「見た目にどのような違い」。同じ植物なので、ちがうのは形と色だけ。図1の2か所（細長い・黄色い）に丸を置く。

📚 前提知識（あれば答え合わせに使う）

  • 図1の長い部分は胚軸（子葉と根の間の茎）、先の黄色いふくらみが子葉（巻末解説の図）。図2は子葉が緑で、本葉が出かけている。

🔍 こう読み解く

132 131のちがいが出るのはなぜか 資料問題・理由

👀 まず見るところ

【資料問題】部品は131で置いた2つの丸「細長い」「黄色い」。緑でない＝葉緑素がつくられていない、に直して書く → 原因は光が当たっていないこと、と決まる。

📚 前提知識

  • 葉の緑は葉緑素。葉緑素は光が当たるとつくられるので、暗い所で育てた芽は黄色や白のままになる（巻末解説）。
  • 暗い所の芽は光をさがしてひょろ長くのびる。こうして育てたダイズがもやし。

🔍 こう読み解く

  1. 黄色い＝葉緑素がない＝光が当たっていない。
  2. 細長い＝暗い所で光を求めてのびた。2つの特ちょうが同じ原因で説明できる。
  3. 「〜から。」の形で、図1の育て方を書く → 図1は日光を当てずに育てたから。
答え：図1は日光を当てずに育てたから。
コツ：「なぜ」と聞かれたら、答えの文末を「〜から。」にしてから書き始める。

133 ①・② マツのめばな・種子を運ぶもの 資料問題・写真から決める

👀 まず見るところ

【資料問題】部品は写真の正体「松ぼっくりとマツの種子」と設問の「松ぼっくりの中にある種子」。種子ができる方の花＝めばな、と1行書く。種子の写真のはねに丸 → 運ぶのは風。

📚 前提知識

  • マツは裸子植物で子房がなく、めばなのりん片に胚珠がむき出しでつく（◆ポイント◆）。受粉後にめばなが松ぼっくりになり、中に種子ができる。
  • 松ぼっくりは晴れた日に開き、はねのついた種子が回転しながら飛ばされる（◆ポイント◆）。同じ裸子植物のイチョウは、めばなにギンナンができる。

🔍 こう読み解く

  1. ①「種子ができる」のは胚珠のある花＝めばな。おばなは花粉を出すだけ。
  2. ②種子の写真を見ると、小さな種子の先に、種子より大きなひらたいはねが1枚のびている → はね＝風で飛ぶ合図。
  3. 風で運ぶ種子は、軽くて、はねや毛がある（タンポポの毛・モミジのはねと同じ仲間）。
答え：① めばな　② 風

134 A・B・C 植物の名前と種子の散布方法 資料問題・写真から決める

👀 まず見るところ

【資料問題】部品は聞かれ方「名前と種子の散布方法」の2つ。写真ごとに正体を1行（A：細長いさや、B：はねのついた種子、C：とげだらけの実）→ 形がそのまま運ばれ方になる。

📚 前提知識

  • 種子の運ばれ方は形で決まる。はね・毛＝風／とげ・ねばり＝動物のからだにつく／さやがはじける＝自分で飛ばす／甘い実＝動物に食べられてふんで運ばれる。
  • オナモミのとげが服や毛にくっつくしくみを参考に、面ファスナー（マジックテープ）が発明された（◆ポイント◆）。

🔍 こう読み解く

  1. A：黄色い花と、上を向いた細長いさや → カタバミ。熟したさやがはじけて種子を飛ばす。
  2. B：赤い葉と、プロペラのようなはねのついた種子（2つで1組） → イロハモミジ。はね＝風にのって飛ぶ。
  3. C：かぎ形のとげにおおわれた実 → オナモミ。動物の毛について運ばれる。
答え：A カタバミ→実がはじけて散らばる　B イロハモミジ→風にのって飛ぶ　C オナモミ→動物の毛について運ばれる
コツ：名前が出なくても、散布方法は写真の形（はね・とげ・さや）だけで決まる。先に方法を書く。

135 食品の種子から無胚乳種子をすべて選ぶ 知識問題

ヒマワリ・クルミ。オオムギ・トウモロコシはイネ科の単子葉植物で、養分は胚乳にある有胚乳種子。麦飯で食べているのはオオムギの胚乳、ポップコーンはトウモロコシの胚乳が加熱されてはじけたもの（◆ポイント◆）。ヒマワリ・クルミは双子葉植物で、食べている部分が養分をためた子葉＝無胚乳種子。「すべて選ぶ」なので、4つ全部に有／無をつけてから答える。
答え：ヒマワリ・クルミ
コツ：双子葉でも有胚乳の例外（オシロイバナ・カキ）があるので、「双子葉＝無胚乳」で決めずに、食べている部分が子葉か胚乳かで考える。

129〜135 まとめ 見直しの要点

  • 養分の場所：無胚乳種子は子葉（ドングリ・クリ・ダイズ・ヒマワリ・クルミ）、有胚乳種子は胚乳（イネ科のオオムギ・トウモロコシ、例外のオシロイバナ・カキ）。発芽は根が先。
  • もやし：光が当たらないと葉緑素ができず黄色、光を求めて細長くのびる。131は見た目、132は理由と、聞かれ方で書き分ける。
  • 散布：はね＝風（マツ・イロハモミジ）、とげ＝動物の毛（オナモミ）、さやがはじける（カタバミ）。写真の形を1行書けば決まる。
