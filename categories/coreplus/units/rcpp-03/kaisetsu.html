724 ① 平行なガラス板を通る光 資料問題・正しい道すじ

👀 まず見るところ

【資料問題】部品は図の正体「ガラスの板（上下の面が平行）」と、光が境目を通る回数＝2回（空気→ガラス、ガラス→空気）。境目ごとに「近づく／遠ざかる」を図に置く → 出てくる光は入った光と平行、と決まる。

📚 前提知識

  • 光が空気からガラスに入るとき、境目で法線（境目に垂直な線）に近づく向きに折れる。ガラスから空気へ出るときは逆に法線から遠ざかる。
  • 上下の面が平行な板では、入るときと出るときの折れ方が打ち消し合い、出た光は入った光と平行になる（横にずれるだけ）。

🔍 こう読み解く

  1. 上の面で1回目。ガラスに入るので法線に近づく＝まっすぐ進む線（ウ）より立った向きに折れる。ア（左へ折れる）は向きが逆。
  2. 下の面で2回目。空気へ出るので法線から遠ざかり、元の角度にもどる。
  3. 入った光と平行で、少し右にずれて出る線がイ。ウは折れていない線、エは入るときに遠ざかる向きへ折れた線。
答え：イ

📚 前提知識

答え：エ

726 海が青く見える理由 知識問題

海水に吸収されにくい青色の光が、海底などに反射して目に届くから。太陽の光にはいろいろな色がまざっていて、水は青以外の色を吸収しやすい。残った青だけが深くまで進み、はね返って目に入る。「青が通りぬける」のではなく「青だけが残ってはね返ってくる」と覚える。
答え：海水に吸収されにくい青色の光が海底などに反射して目に届くから。

727 全身をうつす鏡（70cm）の高さ 知識問題

つま先と目の高さの中間から、頭の先と目の高さの中間までの高さ。理由は反射の法則（入射角＝反射角）。つま先から出た光が鏡ではね返って目に届くとき、はね返る点はつま先と目のちょうど中間の高さ。頭の先からの光は、頭の先と目の中間の高さではね返る。だから鏡の下はしと上はしをそこに合わせれば全身が入る。必要な長さは身長の半分（140cm→70cm）。
答え：つま先と目の高さの中間から頭の先と目の高さの中間までの高さ。

779 ① ガラス管の中の水銀76cm分の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「断面積が1cm²」「密度13.6g/cm³」「76cm」の3つの数字。図の管のとなりに 1cm²×76cm＝体積76cm³ と直して書く → 重さ＝密度×体積の式に入る。

📚 前提知識

  • 重さ（g）＝密度（g/cm³）×体積（cm³）。細長い管の中の体積は、断面積×高さで出す。

🔍 こう読み解く

  1. 水銀の体積：1×76＝76cm³。
  2. 重さ：13.6×76＝1033.6g。小数点の位置は 13.6×76≒14×76≒1064 で見当をつけてから確かめる。
答え：1033.6g
コツ：この1033.6gが、あとで出てくる「1気圧≒1kg重/cm²」の正体。数字そのものより、76cm・13.6・1cm²の3つから作れることを押さえる。

779 ② ①の値は何の重さと等しいか 素材文・用語

👀 まず見るところ

【素材文】設問は「何の重さと等しいか」。部品は本文の「大気の重さによる圧力を大気圧」と「断面積が1cm²」の2語に丸 → 水銀の柱をおし上げているのは1cm²分の空気の重さ、と決まる。

📚 前提知識

  • 管の上は真空なので、水銀の柱を下からささえているのは水銀の面をおす大気の力だけ。管の中の水銀の重さと、同じ断面積（1cm²）にかかる大気の重さがつり合って止まる。
  • だから「1cm²あたりの大気の重さ≒1033.6g≒約1kg」。これが1気圧（76cmHg）の意味。

🔍 こう読み解く

  1. 水銀が76cmで止まった＝柱の重さ（下向き）とおし上げる力（上向き）が同じ。
  2. おし上げる力の正体は、断面積1cm²の面にのっている空気の重さ。答えは「1cm²あたりの大気の重さ」と、面積をつけて書く。
答え：1cm²あたりの大気の重さ
コツ：「大気の重さ」だけでは、どれだけの面積分かが分からない。本文に「断面積1cm²」とある以上、答えにも1cm²を入れる。

780 ストローで吸うと水が上がってくる理由 知識問題

ストローの中の気圧が下がり、外の気圧によって水が押されるから。吸うのは「水を引き上げる」のではなく、ストローの中の空気を減らして気圧を下げること。すると水面をおす外の大気のほうが強くなり、水がストローの中へおし上げられる。779の水銀と同じしくみで、「気圧の低いほうへ、外の空気がおしこむ」と1行で覚える。
答え：ストローの中の気圧が下がり、外の気圧によって水が押されるから。

781 味噌汁のおわんのふたが取れにくくなる理由 知識問題

おわんが冷えると中の水蒸気が水に戻り、体積が小さくなると、おわんの中の気圧が下がって、外の気圧の方が大きくなるから。書く順番は冷える→水蒸気が水に戻る→中の気圧が下がる→外の気圧のほうが大きいの4段。「中の気圧が下がる」だけでなく、なぜ下がるか（水蒸気が水に戻って体積が減る）まで書くのが記述の決め手。ふたをおさえているのは外の空気の重さで、780のストローと同じ向きの話。
答え：おわんが冷えると中の水蒸気が水に戻り、体積が小さくなると、おわんの中の気圧が下がって、外の気圧の方が大きくなるから。

782 ①B・①C 磁石B・Cの下側の極 資料問題・図と極

📚 前提知識

  • 磁石は同じ極どうしが反発し、ちがう極どうしが引き合う。磁石がくっつかずに浮いているなら、向かい合う面は同じ極。

  3. Cの下側はBの上側（S）と反発しているのでS極。図に下からN・S／N・S／S・N と書きこむと取りちがえない。
答え：B N極　C S極

  2. せまい＝近い＝磁力が大きい → AとB。

782 ③ 台ばかりが示す重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「1個の重さが10g」「磁石A〜C」「軽い棒」。「A〜C＝3個」「軽い棒＝0g」と直して書く → 台ばかりは 10×3 で決まり、磁力は関係しない。

📚 前提知識

  • 浮いていても、磁石の重さは消えない。BとCの重さはAをおす磁力として下へ伝わり、Aの重さと合わせて台ばかりに全部かかる。
  • 台ばかりが示すのはのっている物の重さの合計。磁力は物どうしの間でおし合う力なので、合計には出てこない。

🔍 こう読み解く

  1. のっているのは磁石3個（＋重さ0の棒）。
  2. 10×3＝30g。
答え：30g
コツ：「浮いているから軽くなる」と考えたくなるが、浮かせている力はAが出している。Aは下の台ばかりにそのぶん強くおしつけられる。

783 ① 折り曲げた針金の重心（×） 条件文・作図

📚 前提知識

784 ① 動滑車にぶら下がった台の上で手でひもを引く力 条件文・計算

👀 まず見るところ

【条件文】部品は「体重36kg」と「人以外の重さは考えない」。図で、人と台を上に引いているひもの本数を数えて矢印で置く（直して書く）＝動滑車の左右2本＋手がにぎる1本の3本 → 36÷3 の式になる。

📚 前提知識

  • 1本のひもがかけ通っているとき、ひもの力（張力）はどこでも同じ。定滑車は向きを変えるだけで力の大きさは変えない。
  • 人が手でひもを引くと、ひもも同じ力で人を上に引き返す。この1本も人を支える力に数える。

786 ①・②・③ かたい球をぶつけたあとの動き 条件文・重さの大小

👀 まず見るところ

【条件文】部品は3つの文の「同じ重さ」「Cが重い」「Dが軽い」に丸。A＝B、C＞A、D＜A と記号に直して図の横に置く → ぶつけられた球が勢いをどれだけ受け取るかが、この大小で決まる。

📚 前提知識

  • かたい球の衝突では、動いていた球の勢いがぶつけられた球にわたされる。同じ重さなら勢いがそっくり入れかわる（動いていた方は止まり、止まっていた方が同じ速さで進む）。
  • 重い球が軽い球にぶつかると、重い球は少しおそくなって進み続け、軽い球は前より速く飛ぶ。軽い球が重い球にぶつかると、軽い球ははね返り、重い球はゆっくり前へ動く。

🔍 こう読み解く

  1. ① A＝B → Aは止まり、BがAと同じ速さで進む。
  2. ② C＞A → Cは衝突前のCよりおそく同じ向きに進み、Aは衝突前のCより速く進む。
  3. ③ D＜A → Dは衝突前のDよりおそく反対向きに進み（はね返る）、Aは衝突前のDよりおそく進む。
答え：① A 止まる・B Aと同じ速さで進む　② C 衝突する前のCより遅く進む・A 衝突する前のCより速く進む　③ D 衝突する前のDより遅く反対に進む・A 衝突する前のDより遅く進む
コツ：①の「入れかわる」を基準にして、重い方がぶつかれば「止まりきらず進む」、軽い方がぶつかれば「返される」。答えは両方の球について書く。

787 電流計と電圧計のつなぎ方 条件文・作図

👀 まず見るところ

【条件文】部品は「豆電球に流れる電流」と「豆電球にかかる電圧」。「電流＝電流計を通り道にわりこませる（直列）」「電圧＝豆電球の両はしから2本出す（並列）」に直して書いてから線を引く。

📚 前提知識

  • 電流計は回路に直列、電圧計は並列（◆ポイント◆）。電流計は流れる道の途中に入れるので、外すと回路が切れる。電圧計は豆電球をまたぐようにつなぐので、外しても豆電球は光る。
  • 計器の＋端子は電池の＋側、−端子は電池の−側につなぐ。

🔍 こう読み解く

  1. 本線を1本の輪にする：電池の−端子 → 豆電球の左の端子、豆電球の右の端子 → 電流計、電流計 → 電池の＋端子。線は3本。

  3. 確かめ：電流計だけ外すと輪が切れる（直列）、電圧計だけ外しても輪は残る（並列）。
答え：電池−→豆電球→電流計→電池＋ を1本の輪につなぎ（電流計は直列）、豆電球の両はしの端子から電圧計へ2本つなぐ（電圧計は並列）。線は全部で5本
