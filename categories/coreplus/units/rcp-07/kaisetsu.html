91 産卵時のオスとメス（写真①） 資料問題・写真の読み取り

👀 まず見るところ

【資料問題】部品は写真の正体「産卵時のメダカのオスとメス」と聞かれ方「メスはどちら」「オスは何をしている」。正体を1行書く → 産卵中なら、ひれでメスを包んでいる側がオスと決まる。

📚 前提知識

  • オスは背びれに切れこみがあり、しりびれが大きく平行四辺形に近い（p.30の◆ポイント◆）。メスの背びれには切れこみがなく、しりびれは後ろが細い三角形。
  • メダカは体外受精。メスが産んだ卵にオスがその場で精子をかける。ほかのオスに先にかけられないように、オスはメスのからだをひれで包んで産卵をうながす（巻末解説p.222）。

🔍 こう読み解く

  1. 写真①の手前の魚は、背びれとしりびれが大きく広がり、奥の魚の下にからだを寄せている → これがオス。
  2. 奥の魚は、ひれが小さくおなかがふくらんでいる → メス。
  3. オスがしていること＝背びれとしりびれでメスのからだを包み、産卵をうながしている。「包んでいる」まで書いて答えになる。
答え：メスは写真奥。オス（写真手前）は尻びれと背びれでメスのからだを包み、産卵をうながしている。
コツ：写真で迷ったら、まず2匹のしりびれの大きさをくらべる。大きい方がオス。

92 あ・い・う メスが1回に産む卵の数・受精の前後・卵の直径 知識問題

あ 20・い した後・う 1。メスは1回に約20個の卵を産み、その場でオスが精子をかけるので、水草に産み付けるのは受精した後の卵。卵1個は直径約1mm（巻末解説では1〜1.5mm程度）。「200個」はメダカには多すぎる数、「0.1mm」は目に見えない大きさ、と選択肢を消すと残る。産卵は早朝、空が明るくなり始めたころ（巻末解説p.222）。
答え：あ 20　い した後　う 1

93 水草に産み付けられた卵（写真③） 資料問題・写真の読み取り

👀 まず見るところ

【資料問題】部品は写真の正体「水草に産み付けられた卵」と聞かれ方「いくつ」「どのような違い」。丸い透明なものを数えて丸で囲む → 2つの丸の中身のちがい（眼があるか）で答えが決まる。

📚 前提知識

  • 産卵直後の卵は油の粒が全体に散らばって見えるだけ。日がたつと目が黒くなり、からだの形が見えてくる（p.30の問99・100）。
  • 卵には付着毛という毛が生えていて、水草にからみつきやすい（巻末解説p.222）。

🔍 こう読み解く

  1. 写真③で丸いものは、右上に1つ、左下に1つ → 卵は2個。
  2. 右上（写真上）の卵は中に黒い点が2つ＝メダカの眼、からだの形も見える。左下の卵は透明で、見えるのは油滴だけ。
  3. 眼やからだができるには日数がかかる → 写真上の卵のほうが先に産み付けられたと分かる。
答え：卵は2個あり、片方（写真上）はメダカの眼やからだがはっきりしていることから、先に水草に産み付けられたものであると分かる。

94 小川のメダカと睡蓮鉢のメダカ（写真④⑤） 資料問題・写真の見くらべ

👀 まず見るところ

【資料問題】部品は写真の正体「④小川／⑤睡蓮鉢」と聞かれ方「見比べて気づいたこと」。ちがいを3つ（水の色・メダカの向き・メダカの色）に分けて正体の横に書く → それぞれ「流れがあるか」で理由がつく。

📚 前提知識

  • メダカは周りの景色を見て同じ場所に留まろうとする性質がある。流れのある小川では、全員が上流を向いて泳ぐ（巻末解説p.222）。
  • 流れのない水では植物性プランクトンがふえて水が緑色になる。日光が当たりすぎると水温が上がるので、スイレンの葉が日かげをつくる。
  • ④の黒っぽいメダカが野生型。⑤の橙色は飼育用に作られた品種。野生のメダカは数が減り、絶滅危惧種に指定されている。

🔍 こう読み解く

  1. 向き：④は全員が同じ向き（流れに向かって）。⑤は向きがばらばら → 水の流れがない。
  2. 水の色：⑤は緑色 → 流れがなく植物性プランクトンがふえている。⑤にはスイレンの葉があり、直射日光をさえぎって水温が上がらないようにしている。
  3. メダカの色：④は黒っぽい野生型、⑤は飼育用の橙色。
答え：水の流れがない⑤では、植物性プランクトンが増えて水が緑色になり、メダカの泳ぐ方向もばらばらである。また、水温が上がらないように直射日光をさえぎる工夫もされている。⑤は飼育用の橙色のメダカであるが、④は野生型のメダカで黒っぽい色をしている。
コツ：「気づいたこと」は、ちがいを1つ書いたら「流れがないから」と理由を1つ足す。これで1組。

95 池の水が茶色い理由（写真⑥） 資料問題・写真の読み取り

👀 まず見るところ

【資料問題】部品は写真の正体「池の水を顕微鏡で拡大」と設問の「茶色く」。写真で一番たくさんある針のような茶色い粒に丸 → その正体（ケイソウ）が水の色と結びつく。

📚 前提知識

  • ケイソウは茶色っぽい植物性プランクトン。晴れたあたたかい日に大繁殖して、池の水が茶色くにごることがある（巻末解説p.222）。
  • 写真下の大きな緑色のものはミカヅキモ（◆ポイント◆）。大きさが0.5mmになるものもあり、動物プランクトンに食べられにくい。

🔍 こう読み解く

  1. 写真⑥で数が多いのは、細長い針のような茶色い粒 → ケイソウ。
  2. 水の色は「数の多いプランクトンの色」で決まる → ケイソウが大繁殖したから茶色。
  3. 緑色のミカヅキモは1つだけ目立つが、数が少ないので水の色には関係しない。
答え：茶色いプランクトン（ケイソウ）が大繁殖している。
コツ：水の色は「緑＝緑色の植物性プランクトン」「茶色＝ケイソウ」と色で結びつけておく。

96 ミジンコで気づいたこと（写真⑦） 資料問題・写真の読み取り

👀 まず見るところ

【資料問題】部品は写真の正体「ミジンコ」と聞かれ方「気づいたこと」。見えるものを外側から順に3つ（からだの節・背中側の丸い粒・おなかの緑色の筋）に丸 → それぞれが節・卵・食べ物に対応する。

📚 前提知識

  • ミジンコはエビ・カニと同じ甲殻類（p.31の◆ポイント◆）。からだに節があり、触角で泳ぐ。
  • ふつうは体内で卵をふ化させ、メスだけでふえる。環境が悪くなるとオスが生まれたり、丈夫な休眠卵を産んだりする（巻末解説p.222）。

🔍 こう読み解く

  1. からだの輪かくに線が入っている → からだに節がある。
  2. 背中側（写真右下）に丸い粒がいくつも並んでいる → 卵をもっている。
  3. からだの中を通る筋が緑色 → 消化管の中に緑色の植物性プランクトンが入っている＝植物性プランクトンを食べている。
答え：からだに節がある。また、卵をもち、植物性プランクトンを食べている。

97 メダカがミジンコを食べられない理由（写真⑧） 資料問題・写真の読み取り

👀 まず見るところ

【資料問題】部品は写真の正体「メダカとミジンコ」と聞かれ方「食べることができません。なぜ」。メダカとミジンコの大きさをくらべて正体の横に書く → メダカがまだ小さい、が答えの中心になる。

📚 前提知識

  • ふ化直後のメダカは体長4〜5mmほど。おなかに卵黄のうがあり、数日はえさをとらなくても生きられる。ふ化後2週間ほどまでは「針子」とも呼ばれる（巻末解説p.223）。
  • 写真⑧の白い丸い粒は、ミジンコの休眠卵（巻末解説p.222）。

🔍 こう読み解く

  1. 写真⑧のメダカは、ミジンコと同じくらいの大きさしかない → まだ子メダカ。
  2. 口に入らない大きさのものは食べられない → 大きなミジンコを食べられるほど成長していないから。
  3. 親メダカならミジンコはえさになる。「子メダカだから」まで書く。
答え：子メダカであり、大きなミジンコを食べられるほどの大きさに成長していないから。

98 サケの切り身A・Bの違い（写真⑨⑩） 資料問題・写真の見くらべ

👀 まず見るところ

【資料問題】部品は写真の正体「サケの切り身A・B」と「⑩を参考に」。Aの背骨の下の大きな穴と、Bの穴がないことに丸 → ⑩で頭側・尾側のどちらを切ったかが決まる。

📚 前提知識

  • 魚の内臓は、肛門（腹びれと尻びれの間）のあたりまで、ろっ骨におおわれて入っている（◆ポイント◆のメダカの骨格）。尾に近い部分には内臓がない。
  • 切り身の細い方が腹側。脂肪分が多く、マグロなら大トロになる部分。サケは白身魚で、えさのエビやカニの色素で身が赤くなる（巻末解説p.222）。

🔍 こう読み解く

  1. Aは背骨の下に大きな穴が開き、まわりをろっ骨が囲んでいる → 内臓が入っていたところ＝頭の方の輪切り。
  2. Bは背骨があるだけで穴がほとんどない → 内臓がない尾の方の輪切り。
  3. ⑩で確かめる：頭に近い切り口ほど内臓の空どうが大きく、尾に向かうほど身がつまっている。
答え：Aは頭の方を輪切りにしたもので、背骨の下に内臓が入っていた穴が大きく開いている。Bは尾の方を輪切りにしたため穴はほとんど見られない。

91〜98 まとめ 覚えること

  • オスとメスの見分けはひれ（オス＝背びれに切れこみ・しりびれが大きい）。産卵は体外受精で、オスがメスを包む。卵は1回約20個・直径約1mm・付着毛で水草にからむ。
  • 写真の問題は「見えたこと＋だから何」の2段で書く。流れがない→向きばらばら・水が緑／茶色い水→ケイソウ／穴が大きい→頭側。
  • ミジンコは甲殻類・節がある・卵をもつ・植物性プランクトンを食べる。子メダカ（針子）はミジンコと同じ大きさなので食べられない。

99 ①・② 産卵直後の卵はどちらか・数時間での変化 資料問題・写真くらべ

👀 まず見るところ

【資料問題】部品は写真の正体「水温25℃・産卵直後と数時間後の卵」と、図に書かれた言葉「油の粒」「胚盤」。図1と図2で、油の粒の数と胚盤の有無を○×で書く → 油の粒が散らばっている方が産卵直後と決まる。

📚 前提知識

  • メダカの卵は直径1〜1.5mmほど。産卵直後は小さな油の粒が全体に散らばり、水草にからむ付着毛がある（巻末解説）。

🔍 こう読み解く

  2. 図2：油の粒は少なく大きい、上に「胚盤」の文字 → 数時間後。

答え：① 図1　② 油の粒が集まって大きくなり、メダカのからだになる胚盤ができている。
コツ：②で「胚盤ができた」だけ書いて終わりにしない。図に書かれた言葉（油の粒・胚盤）が2つあるときは、2つとも答えに使う。

102 ①・② 写真のメダカはオスかメスか・何をしているか 資料問題・写真から決める

👀 まず見るところ

📚 前提知識

  • メダカのひれは5種類。対になるのが胸びれ・腹びれ、1枚ずつが背びれ・しりびれ・尾びれ。
  • 魚の肛門は腹びれとしりびれの間にあり、そのあたりまでろっ骨におおわれた内臓が入っている（◆ポイント◆の骨格図）。

🔍 こう読み解く

  1. 背中のまん中より後ろに背びれ。メスなので切れ込みのない丸い形で描く。
  2. えらのすぐ後ろに胸びれ、腹のまん中に小さな腹びれ、その後ろに三角のしりびれ（後ろほど細い）。
  3. 肛門は腹びれの後ろ・しりびれのつけ根の前。解答図では、ここに丸がついている。
答え：背びれ（切れ込みなし）・胸びれ・腹びれ・しりびれ（後ろが細い三角）を描き、腹びれとしりびれの間に○（解答図のとおり）
コツ：ひれを描く前に「対になるひれは2種類」と書く。胸びれと腹びれは片方を忘れやすい。

104 違い カダヤシとメダカの違い 資料問題・写真＋知識

👀 まず見るところ

【資料問題】部品は写真の正体「カダヤシのメスとオス」と聞かれ方「メダカとの違い」。写真の2匹の長さを見くらべて書く → 写真だけで「オスとメスの大きさに差がある」が決まり、残りは知識で足す。

📚 前提知識（あれば答え合わせに使う）

  • カダヤシのメスはお腹の中で稚魚を育ててから産む（メダカは卵を水草に産み付ける）。
  • カダヤシは低温に弱い。

🔍 こう読み解く

  1. 写真：メスが上で大きく、オスは下で半分ほどの長さ → オスとメスのからだの大きさに差がある（メダカは差が小さい）。
  2. 知識で2つ足す：メスがお腹の中で稚魚を育てる／低温に弱い。
  3. 答えは写真から1つ＋知識から1〜2つの形で書くと、説明として足りる。
答え：オスとメスのからだの大きさに差がある。メスはお腹の中で稚魚を育てる。低温に弱い。

105 光合成をするもの 光合成をするプランクトン 知識問題

A・B・C・E・G・I。緑色のA・B・C・G・Iと、茶色だが光合成をするケイソウEの6つ。色のないゾウリムシD・ワムシF・ケンミジンコHは光合成をしない（他のプランクトンを食べる）。ミドリムシ（B）とボルボックス（C）は光合成も運動もする、と例外を1行で持っておく。
答え：A・B・C・E・G・I

99〜105 まとめ 見る場所と覚える語

  • 卵の写真は「油の粒が散らばる→集まって胚盤→目が黒くなる→ひれと血液→25℃で11日でふ化」の順。並べる問題は最初と最後を先に決める。
