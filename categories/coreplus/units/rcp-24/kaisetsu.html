598 ① 日の出6時46分・日の入り16時34分の昼の長さ 条件文・時刻の引き算

👀 まず見るところ

【条件文】部品は「日の出6時46分」「日の入り16時34分」。昼の長さ＝日の入り−日の出 に直して書く → 16:34−6:46。分が引けないので1時間を60分にくずす。

📚 前提知識

  1. 16時34分 − 6時46分。34分から46分は引けないので 15時94分 − 6時46分 と書き直す。
  2. 15−6＝9時間、94−46＝48分 → 9時間48分。
答え：9時間48分

598 ② この日は春分・夏至・秋分・冬至のどれか 条件文・昼の長さから決める

👀 まず見るところ

【条件文】部品は①の「9時間48分」と「南中高度31.6度」。昼の長さを12時間とくらべる、に直して書く → 2時間以上短い＝昼がいちばん短い冬至。

📚 前提知識

  • 春分・秋分は昼と夜がほぼ12時間ずつ。夏至は昼がいちばん長く、冬至は昼がいちばん短い。

  1. 昼9時間48分は12時間より2時間12分短い → 春分・秋分ではない。
  2. 短い方なので冬至。南中高度31.6度（低い）とも合う。
答え：冬至

598 ③ 太陽の南中時刻 条件文・昼のまん中

👀 まず見るところ

【条件文】部品は「南中時刻」。南中＝日の出と日の入りのちょうどまん中なので、日の出＋昼の長さ÷2 に直して書く → 6:46＋（9時間48分÷2）。

📚 前提知識

  • 太陽は日の出から日の入りまで同じ速さで動くので、南中は昼の長さの半分進んだ時刻（◆ポイント◆）。
  • 別の見方：日の出と日の入りの平均 （6:46＋16:34）÷2 でも同じ（◆ポイント◆の別解）。

🔍 こう読み解く

  1. 9時間48分÷2＝4時間54分。
  2. 6時46分＋4時間54分＝10時100分＝11時40分。
  3. 確かめ：16時34分−4時間54分＝11時40分。日の入り側から引いても同じになる。
答え：11時40分

598 ④ この地点の東経 条件文・南中時刻から経度

👀 まず見るところ

【条件文】部品は③の「11時40分」と、決まりの「東経135度で正午に南中」。12:00との差20分を 1度＝4分 で度に直して書く → 20÷4＝5度。早い＝東、なので135に足す。

📚 前提知識

  • 太陽は1日（24時間）で360度 → 1時間で15度 → 1度動くのに4分（◆ポイント◆）。
  • 日本の時刻は東経135度（明石）で太陽が12時に南中するように決めてある。東にある地点ほど南中が早い（図：東京11:40、那覇12:20）。

  1. 12時00分−11時40分＝20分早い。
  2. 20分÷4分＝5度 → 東経135度から5度ずれている。
  3. 早い＝東側なので 135＋5＝140。東経140度。
答え：140
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝「20分早い」を東西どちらに置くか決めずに 135−5＝130 と引くか、20÷4 でなく 20×4 と計算すること。先に図へ「東ほど早い」の矢印を1本描いてから足し引きを決める。

598 ⑤ この地点の北緯 条件文・南中高度から緯度

599 ① 日本が1月1日午前0時のときのグリニッジ 条件文・時差

👀 まず見るところ

【条件文】部品は「1月1日午前0時」「グリニッジ（経度0度）」。日本の東経135度との差を 135÷15＝9時間 に直して書く → 西にあるので9時間遅れ、0時から戻れば前日。

📚 前提知識

  • 経度が15度ずれると時刻は1時間ずれる（360÷24）。西にずれると遅れ、東にずれると進む（◆ポイント◆）。
  • 日本の時刻は東経135度が基準。グリニッジは経度0度なので、135度西。

🔍 こう読み解く

  1. 135÷15＝9時間。グリニッジは西なので9時間遅れ。
  2. 1月1日0時の9時間前＝24−9＝15時 → 12月31日午後3時。
答え：12月31日午後3時

599 ② 日本が1月1日午前0時のときのロサンゼルス 条件文・時差と日付変更線

👀 まず見るところ

【条件文】①と変わった部品は「西経120度」。東回りで数えると 45＋60＝105度東＝7時間進む、と直して書く → ただし日付変更線を西から東にまたぐので日付は1日前。西回り255度＝17時間遅れでも同じ。

📚 前提知識

  • 東経・西経180度に日付変更線がある。西から東（東経側→西経側）へまたぐと1日前の日付になる（◆ポイント◆）。
  • 西回りで数えれば 135＋120＝255度 → 255÷15＝17時間遅れ。日付変更線をまたがないので、こちらの方が間違えにくい（◆ポイント◆の別解）。

🔍 こう読み解く

  1. 東回り：東経135度→180度まで45度、180度→西経120度まで60度。合計 105度東。
  2. 105÷15＝7時間進む → 1月1日午前7時。日付変更線をまたいだので1日戻して 12月31日午前7時。
  3. 確かめ（西回り）：255÷15＝17時間遅れ。1月1日0時の17時間前＝12月31日7時。同じになる。
答え：12月31日午前7時

600 ① 10月9日午後11時の星Sの位置 条件文・日周運動

👀 まず見るところ

【条件文】部品は「10月10日午前3時にア」と「10月9日午後11時」。日付は前日でも時刻は4時間前、と直して書く → 15×4＝60度戻る。図の1目盛りは30度なので時計回りに2目盛り。

📚 前提知識

  • 北の空の星は北極星を中心に反時計回りに、1日で1回転（360度）→ 1時間に15度（◆ポイント◆）。
  • 図はアからシまで12等分なので1目盛り＝360÷12＝30度＝2時間分。「前」の時刻は、動く向きと逆（時計回り）に戻す。

🔍 こう読み解く

  1. 10月9日午後11時は、10月10日午前3時の 4時間前。日付が変わっているだけで、年周運動の分は無い。
  2. 15×4＝60度戻る → 1目盛り30度なので2目盛り、反時計回りの逆＝時計回りに ア→イ→ウ。
答え：ウ
今回：×。原本が無いので答えは見ていない。この問いで×になりやすいのは、部品の形を直さなかった＝「10月9日」を見て日付のずれと思い月の動き（30度）を混ぜるか、「前」なのに反時計回りに進めてサに置くこと。先に「午前3時の4時間前」と書き直し、図に時計回りの矢印を1本描く。

601 ③ 気温17℃・湿度80%の空気から水滴が出る温度 まざり型→資料問題・露点

👀 まず見るところ

【まざり型→資料問題】部品は「17℃」「湿度80%」と答え方の「表の値で答える」。まず含む量＝14.5×0.8 を出し、表で飽和量がその数を下回る最初の気温をさがす、に直して書く。

📚 前提知識

  • 冷やして飽和水蒸気量が「含まれる量」より小さくなると、入りきらない分が水滴になって出てくる（◆ポイント◆）。この温度を露点という。

  2. 表を左へたどる：14℃は12.1（11.6より大きい→まだ出ない）、13℃は11.3（11.6より小さい→出る）。
  3. 水滴が出てくるのは 13℃。
答え：13℃
