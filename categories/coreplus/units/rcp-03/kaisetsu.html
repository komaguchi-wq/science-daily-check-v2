31〜38 全体像 川の写真を読む観察問題7問＋土砂の堆積1問

31 カーブの外側の流れが速いと分かる理由 資料問題・写真から説明

👀 まず見るところ

【資料問題】部品は写真の正体「①カーブした川」と聞かれ方「どのようなことから分かりますか」＝写真に写っている証拠を答える。カーブの外側と内側を分けて丸をつけ、ちがいを言葉にする。

📚 前提知識

  • 流れが速い所は川底や岸が削られる（侵食）。流れが遅い所は運ばれてきた石や砂が積もる（堆積）。
  • カーブでは水が外側に押しつけられるので、外側が速く、内側が遅い。

🔍 こう読み解く

  1. 外側（写真の右上）は岸が切り立った崖。削られ続けている証拠。
  2. 外側の水面には白波が立っている。水が速く、岩にぶつかっている証拠。
  3. 反対に内側（写真の左）は石がたまった川原が広がる。速い・遅いのちがいが、崖と川原のちがいになって写っている。
答え：川のカーブの外側は崖になっており、また、カーブの外側に白波が立っている。
コツ：「外側＝崖・白波（削る）」「内側＝川原（積もる）」と写真に書きこんでから答えを組み立てる。

32 左側が上流だと考えられる理由 資料問題・写真から説明

👀 まず見るところ

【資料問題】部品は写真の正体「②川の中のアユ」と聞かれ方「左側が上流だと考えられる理由」。証拠は2種類＝魚の頭の向きと、川底の石のかさなり方。それぞれに丸をつける。

📚 前提知識

  • 川の魚は流されないように、流れに逆らって頭を上流に向けて泳ぐ。その場にとどまるための向き。
  • 川底の石は流れに押されるので、上流側の石が下流側の石の上にかぶさるように、同じ向きにかたむいて重なる。
  • アユは川で産卵し、稚魚は海で育って川にもどり、石についた藻類を食べる（巻末解説）。

🔍 こう読み解く

  1. 魚の頭はみな左を向いている → 流れは左から右 → 左が上流。
  2. 川底の石を見ると、左側の石が右側の石の上におおいかぶさっている → 流れに押された向きも左から右。
  3. 2つの証拠が同じ向きをさしているので、左が上流と決まる。
答え：川の魚はその場にとどまるために水の流れに逆らって泳ぐから。／右側の石に対して左側の石が上におおいかぶさるように積み重なっているから。
コツ：「理由を探しましょう」なら証拠は1つで終わりにしない。魚と石の2つを書く。

33 別々の日の利根川 Aと比べたBの違い 資料問題・2枚の写真を比べる

👀 まず見るところ

【資料問題】部品は写真の正体「③別々の日に撮影した利根川」と聞かれ方「Aと比べてBは」。2枚に共通の目印（橋）に丸をつけて位置をそろえ、水面の高さ・幅・色の3つを順に比べる。

📚 前提知識

  • 日本の川は短くて流れが急なので、雨が降ると水位が急に上がる。土砂くずれやダムの放流でも変わる（巻末解説）。
  • 増水した水は上流の土砂をまきこむので、茶色くにごる。
  • ◆ポイント◆ 都市では増水に備え、わざと水をあふれさせてためる遊水地をつくることがある。

🔍 こう読み解く

  1. 高さ：Bでは橋の脚の大部分が水につかっている → 水位が上がった。
  2. 幅：Aで見えていた河川敷（岸の広い草地）がBでは水没し、木の先だけが出ている → 川幅が広がった。
  3. 色：Aの水は青っぽく、Bは土砂で茶色。この3つを1文にまとめる。
答え：川の水位が上昇し、川幅が広がり、水が土砂で茶色くにごっている。
コツ：2枚を比べる問題は「高さ・幅・色」のように比べる項目を先に決めてから見る。

34 川沿いに見られる施設は何か 資料問題・写真から決める

👀 まず見るところ

【資料問題】部品は写真の正体「④川沿いに見られる施設」。山の上から建物へ下りてくる太いパイプと、建物の下から川へ放出されている水に丸 → 高い所の水を落として使う施設と決まる。

📚 前提知識

  • 水力発電は、ダムなどにためた水が落ちる勢いで発電機を回す。二酸化炭素を出さない。
  • 夜中の余った電気で水をダムへもどし、電気を多く使う昼間に備えることもできる（巻末解説）。
  • ◆ポイント◆ 発電機の中にはモーターのような部品（コイルと磁石）が入っている。

🔍 こう読み解く

  1. パイプは山の上（高い所）から建物へ → 水を落として勢いをつける仕組み。
  2. 建物のすぐ下で水が川へ放出されている → 使い終わった水を川にもどしている。
  3. 高い所の水＋発電機の建物＋放出 → 水力発電所。
答え：水力発電所

35 A・B コンクリート製の段差 AとBは何のため 資料問題・写真から目的を決める

👀 まず見るところ

【資料問題】部品は写真の正体「⑤川の途中に見られるコンクリート製の段差」と聞かれ方「それぞれ何のため」＝AとBで別の答えを書く。Aは手前の大きな壁、Bはおくの階段状のジグザグ水路。形のちがいに丸をつける。

📚 前提知識

  • Aの大きな壁は砂防えん堤。土砂をせき止めて流れをゆるやかにし、川底が削られすぎたり、下流が洪水や土砂災害にあったりするのを防ぐ（巻末解説）。
  • えん堤をつくると、32のアユのように川をさかのぼる魚が進めなくなる。そこで魚がのぼれるようにゆるい段差を折り返した水路を横に付ける（魚道）。

🔍 こう読み解く

  1. A：高い壁で水が一気に落ちている → 土砂はここで止まる → 土砂を下流に流さないため。
  2. B：低い段が何段もジグザグに続く → 魚が少しずつ上れる道 → 魚が上流にのぼれるため。
  3. 巻末解説の図のとおり、Bの水路は折り返しながら上へ向かっている。壁の高さと段の低さ、が決め手。
答え：A 土砂が下流に流れるのを防ぐ。　B 魚が上流にのぼれるようにする。
コツ：人がつくった物は「川の何を防ぐか／何を助けるか」で答える。形が高い＝止める、低く続く＝通す。

36 西表島の白い砂浜はどのようにしてできたか 資料問題・写真から説明

👀 まず見るところ

【資料問題】部品は写真の正体「⑥西表島のサンゴ礁と海岸」と、2枚の拡大写真が指している場所＝海岸から少し離れた茶色い所と、海岸の白い所。「どのようにしてできた」なので、茶色→白→砂浜の順番を言葉にする。

📚 前提知識

  • サンゴの茶色は、中にすむ褐虫藻（植物性プランクトン）の色。褐虫藻がいなくなるとサンゴは栄養不足で死に、炭酸カルシウムの白い骨格だけが残る（巻末解説）。
  • 残った白い骨格が波や潮でくだかれ、運ばれて浜にたまる。

🔍 こう読み解く

  1. 左の拡大写真＝沖の茶色い生きたサンゴ。右の拡大写真＝海岸の白いサンゴのかけら（枝の形が残っている）。
  2. 同じ形で色だけちがう → 白いかけらは死んだサンゴ。
  3. 沖で死んだサンゴのかけらが潮に流されて海岸にたまった、と順番どおりにつなぐ。
答え：海岸から少し離れたところに見える茶色い生きたサンゴが死んで白いかけらになり、潮によって流されてできた。

37 グランドキャニオンの地形はどのようにしてできたか 資料問題・写真から説明

👀 まず見るところ

【資料問題】部品は写真の正体「⑦グランドキャニオン」と聞かれ方「どのようにしてできた」。岩の横じま（地層）と、谷の両側で同じしまが続いていることに丸 → 「地層ができる」「地上に出る」「川が削る」の3段で答える。

📚 前提知識

  • 横じまの地層は、川が運んだ土砂が海底に積もってできる。それが地上に出てくると、しま模様の岩として見える。
  • 谷の両側で同じ地層が続いていれば、もとは1つだった地層を川が削って分けたと分かる。表面のぎざぎざは雨などで削られたあと（巻末解説）。
  • コロラド川が数百万〜数千万年かけて削り、長さ400km以上・深さ1km以上の谷になった（巻末解説）。

🔍 こう読み解く

  1. 岩に横じま → 海底で積もった地層。
  2. 谷の向こう側にも同じしまが同じ高さで続く → 川がまん中を削って谷にした。
  3. 順番は「海底に堆積 → 地層が地上に出る → 川が削る」。この3段を1文にする。
答え：海底に堆積した土砂が地層になったものが地上に出てきて、川によって削られて谷ができた。
コツ：「どのようにしてできた」は、できた順番を矢印で3つ書いてから文にする。

38 粒が大きい土砂が堆積する場所 知識問題

河口に近い。粒が大きいほど早く沈むので、川が海に出たところですぐ落ち、小さい泥は遠くまで運ばれてから沈む。ビーカーの写真では下ほど粒が大きい（小石→砂→泥の順に沈む）。水そうの実験では河口から遠いほど粒が小さい。粒が小さいほど体積あたりの表面積が大きく、水の抵抗を受けて沈むのに時間がかかるため（巻末解説）。
答え：河口に近い

31〜38 まとめ 採点なし

  • 観察問題は「写真の正体を1行」→「聞かれ方に線」→「写真に丸」の順。答えは写真に写っている証拠（崖・白波・魚の向き・橋の脚・パイプ・しま模様）を言葉にしたものになる。
  • 決まりは2つ。速い所は削る・遅い所は積もる（31 外側＝崖、33 増水＝にごる、37 川が谷を削る）と、人工物は防ぐため・通すため（34 水力発電、35 砂防えん堤と魚の道）。
  • 38は「粒が大きい＝早く沈む＝河口に近い」。ビーカー（下ほど大きい）と水そう（遠いほど小さい）の2枚を1組で覚える。

rcp-03 39〜45（p.14〜15・川と地層）

39〜45 全体像 川が運ぶ土砂と地形 7問

7問は「川が土砂を運ぶ→たまる→地形ができる」の順に並んでいる。39は運ぶ量が増えるとき、40・41はたまってできる地形の名前（扇状地・三角州・三日月湖）、42は写真から上流を選ぶ、43は川底が高くなる天井川、44・45は地層が動く力と氷河がつくる谷。

39 川から土砂が運ばれる量が増えるのはどのようなとき 知識問題

大雨によって川が増水したとき。水の量が増えると流れが速く強くなり、ふだんは動かない大きな石や大量の土砂まで運ぶ（◆ポイント◆の写真は、豪雨のあと上流から運ばれた土砂で川が茶色くにごり、河口に土砂が広がった様子）。答えは「大雨」と「増水」の2語を入れて書く。
答え：大雨によって川が増水したとき。
コツ：「どのようなとき」と聞かれたら、答えの文末を「〜したとき。」の形にそろえる。

40 ①・②・③ 川が山から出る所と河口にできる地形 素材文・穴うめ

👀 まず見るところ

【素材文】部品は、①の前の「山から平野に出るとき」と、②③の前の「河口付近」「粒の小さい土砂」に丸。場所が「山の出口」か「河口」かで地形の名前が決まり、②の「水はけ」は粒の大きさから決まる。

📚 前提知識

  • 扇状地は、山のふもとで川の傾斜が急にゆるやかになり、堆積作用が急に大きくなってできる（巻末解説）。小石や砂など粒の大きい土砂がたまるので水はけが良く、川の水が地下にしみこんで水無川になることもある（◆ポイント◆の「普段の川の様子」が、水のない川原）。
  • 三角州は河口にできる。泥や粘土のような粒の小さい土砂は、すき間がなく水を通しにくいので水はけが悪い。だから水田に向き、粘土は焼いてレンガにもなる（◆ポイント◆）。

🔍 こう読み解く

  1. ①「山から平野に出るとき」「大量の土砂が堆積」→ 扇状地。写真でも、川が山から出た所で平野が扇のように広がっている。
  2. ②「粒の小さい土砂」→ 水を通しにくい → 水はけの悪い地形。
  3. ③「河口付近」→ 三角州。写真の上側、川が海に出る所の平らな土地。
答え：① 扇状地　② 悪い　③ 三角州
コツ：扇状地＝水はけ良い（小石・砂）、三角州＝水はけ悪い（泥）。粒の大きさから水はけを決める。

41 ①・② 川の曲がり方と取り残された部分 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「年月とともに」と「川の一部分が取り残されてできた」に丸。①は時間がたつと曲がりがどうなるか、②は右の写真の、川から切りはなされた三日月の形が答えになる。

📚 前提知識

  • 中流域は上流に比べて傾斜がゆるやかで、川は蛇行しやすい（◆ポイント◆）。カーブの外側は流れが速くて削られ、内側はたまるので、曲がりは年月とともに大きくなる。
  • 曲がりが大きくなりすぎると、洪水のときに水が近道を通って流れが変わり、残された曲がりの部分が三日月湖になる。

🔍 こう読み解く

  1. ①「年月とともに」→ 外側が削られ続けるので、曲がり方は大きくなる。
  2. ②右の写真で、今の川（右側）のとなりに、三日月の形をした水たまりが残っている → 三日月湖。
答え：① 大きく　② 三日月湖

42 A・Bのどちらが上流か 資料問題・写真から決める

👀 まず見るところ

【資料問題】部品は写真の正体「Aは白く流れ落ちる水と大きな石、Bは小さく丸い石の川原」を1行で書き、聞かれ方「どちらが上流」「理由とともに」に線。石の大きさと形だけで、知識がなくても決まる。

📚 前提知識（あれば答え合わせに使う）

  • 石は上流では大きく角ばり、下流にいくほど水に流されて石どうしがぶつかり、小さく丸くなる（◆ポイント◆・巻末解説の【石の様子】）。
  • 上流は傾斜が急なので流れも急。川は湧き水から始まり、崖の地層から水が出る場合は水はけの悪い層のすぐ上からしみ出す（◆ポイント◆）。

🔍 こう読み解く

  1. A：大きな石が転がり、水が白く泡立って落ちている → 流れが急。
  2. B：石がどれも小さく丸い → 長く運ばれた下流の川原。
  3. 理由は「石」と「流れ」の2つを書く：角ばった大きな石が多い／川の流れが急。
答え：A　理由：角ばった大きな石が多い。川の流れが急である。
コツ：理由を書くときは、写真に見えているもの（石の形・大きさ、水の様子）を言葉にする。「上流だから」と答えをくり返さない。

43 天井川の高さが昔より高くなった理由 素材文・理由

👀 まず見るところ

【素材文】部品は「もとは低いところを流れていました」と「川の高さが昔より高くなった」に丸。「川が持ち上がった」のではなく、川底に何かが積もったと考えれば、積もるものは土砂と決まる。

📚 前提知識

  • 上流から運ばれた土砂は川底にも少しずつ堆積する。自然の川は土砂がたまっては洪水であふれることをくり返すが、堤防をつくると土砂がたまり続け、川底が高くなる（◆ポイント◆）。
  • 川底が高くなると洪水しやすくなるので堤防をさらに高くする。これをくり返して、人が住む土地より高い所を流れる天井川になる（巻末解説の断面図）。

🔍 こう読み解く

  1. 写真では、川（上）の下を電車が通っている → 川底が道路や線路より高い。
  2. 高くなったのは、川底に土砂がたまっていったから。答えは「土砂」と「たまる」の2語で書く。
答え：川底に土砂がたまっていったから。

44 ①・② 地層がななめになったり曲がったりする力 素材文・穴うめ

👀 まず見るところ

【素材文】部品は空らんの後ろの「〔①〕活動」「〔②〕の運動」に丸。「〜活動」「〜の運動」とつながる地球の力の名前は決まっているので、言葉のつながりから答えが出る。

📚 前提知識

  • 海底にできた地層は、火山活動やプレートの運動で大きな力を受け、ななめにかたむいたり曲がったりして、陸の上に持ち上がる。
  • 世界最高峰のエベレストにも地層が見られるので、元は海底だったと分かる（◆ポイント◆）。

🔍 こう読み解く

  1. ①「〔　〕活動」→ 火山活動。
  2. ②「〔　〕の運動」→ プレートの運動。
  3. 写真の左は海岸でななめにかたむいた地層、右は曲がった地層。どちらも海底でできたときは水平だった。
答え：① 火山　② プレート
コツ：「地層はできたときは水平」を先に置く。ななめ・曲がりは、あとから力がかかった印。

45 ①・②・③ 氷河がつくる谷と石 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「雪などが押し固められてできた」と「〔②〕字谷」、③の前の「このようにしてできた谷」に丸。①は雪が固まったもの＝氷河と決まり、②③は左右の写真の谷の形と石の形を見る。

📚 前提知識

  • 氷河は川が凍ったものではなく、降った雪が自身の重さで押し固められたもの。年に数十cmほどの速さで流れる（巻末解説）。
  • 水は低い所に集中して削るので上流はV字谷。氷はせまい範囲に集中しないので、広く削ってU字谷になる。氷河が削った石は、流れで転がらないため大きさがばらばらで角ばっている。
  • U字谷に海水が入りこんだ入り江がフィヨルド。北欧のような寒い地域に多い（◆ポイント◆）。

🔍 こう読み解く

  1. ①「雪が押し固められた」→ 氷河。左の写真の、谷の奥から流れ下る白いもの。
  2. ②左の写真の谷は底が広く、断面がUの形 → U字谷。川がつくるVと区別する。
  3. ③右の写真の石は、大きさがそろわず角が立っている → 角ばった。川の石（42のB）のように丸くない。
答え：① 氷河　② U　③ 角ばった
コツ：谷の形と削るものを1組で置く。V＝川（水）、U＝氷河（氷）。石は、川なら丸い、氷河なら角ばる。

39〜45 まとめ 覚えること

  • 川の地形は場所で決まる：山の出口＝扇状地（水はけ良い）／中流＝蛇行・三日月湖／河口＝三角州（水はけ悪い）。穴うめは空らんの前後の場所の言葉に丸。
  • 石を見れば上流か分かる：大きく角ばる＝上流、小さく丸い＝下流。写真の理由は「石の形・大きさ」と「流れの速さ」の2つで書く。
  • 天井川は堤防＋土砂がたまるのくり返し。地層が傾く・曲がるのは火山活動・プレートの運動。V字谷＝川、U字谷＝氷河（石は角ばる・フィヨルド）。
