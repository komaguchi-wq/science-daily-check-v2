46 写真①：Aをもとに、Bで何が起こっているか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「①流れ出る溶岩（AとB）」と聞かれ方「AをもとにBは何が起こっているか」。Aから「赤く光る＝高温の溶岩」を1行書き、Bで同じ赤い光と「白い湯気・海」を見つける → 高温の溶岩が海に流れ出た、と決まる。

📚 前提知識

  • マグマが地上に出たものが溶岩。熱をもつ物体は光を放つので、流れている溶岩は赤く光り、冷えると黒く固まる（ねばり気の少ないマグマは黒い岩石＝ゲンブ岩になる）。
  • 水は水蒸気になると体積が約1700倍にふくらむ。マグマが水にふれると水蒸気爆発を起こすことがある（巻末解説）。

🔍 こう読み解く

  1. Aでは、しわのある黒い溶岩の先端だけが赤い。赤く光る所＝いま流れている高温の溶岩、黒い所＝冷えて固まった溶岩。
  2. Bの下は海。黒い岩の先に赤い光があり、その上に大量の白い湯気が上がっている。
  3. Aで分かった「赤い＝高温」を使うと、Bは高温の溶岩が海に流れ出て水を沸騰させ、湯気とともに溶岩が飛び散っている場面だと決まる。
答え：海に流れ出た高温の溶岩によって水が沸騰し、大量の湯気が出るとともに溶岩が飛び散っている。
コツ：◆ポイント◆の地熱発電は、このマグマの熱を利用して電気を生み出すしくみ。「マグマの熱＝利用できる」とセットで覚える。自分で解くときは「Aで分かったこと」を先に1行書いてからBを見る。

47 写真②：富士の樹海は普通の林とどこが違うか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は設問の「溶岩が流れたあとにできた林」と聞かれ方「普通の林とはどのような点が違う」。写真の地面を見る → 土ではなく岩がごろごろ、木の根が地表をはうように横にのびている、の2つに丸。

📚 前提知識

  • 溶岩が固まった岩石は硬く、樹木は地中に根を張れない。土が少ない（土壌が貧しい）ので、最初に生えるのはコケのような生物（◆ポイント◆）。
  • コケや背の低い草の死がいが分解されて、少しずつ土ができていく（巻末解説）。

🔍 こう読み解く

  1. 普通の林なら地面は土におおわれ、根は地中にもぐって見えない。
  2. 写真では地面がコケにおおわれた岩で、根が岩の上を横に張っているのが見える。
  3. 「地面に岩が多い」＋「根が横にのびる」をつなげて1文にする。
答え：地面に岩が多く樹木の根が地表をはうように横にのびている。
コツ：違いを聞かれたら「普通なら〜、ここでは〜」と2つを並べてから書くと、答えの文がまとまる。

48 写真③：火山に設置されているものは何のためか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「火山に設置されているもの」と聞かれ方「何のために」。写真のトンネル形の建物と、まわりに転がる黒い石に丸 → 上から落ちてくる石を防ぐもの、と決まる。

📚 前提知識

  • 噴火で飛んでくる石を噴石という。溶岩が冷えた火山岩（火山弾・軽石など）と、山体の岩石が飛ばされたものがある。大きいと自動車ぐらいになり、家の屋根を突き破ることもある（巻末解説）。

🔍 こう読み解く

  1. 写真は火山の斜面。木も建物もなく、地面に黒い石がたくさん転がっている＝噴火で飛んできた石。
  2. 建物は両側が開いたトンネル形で、金属製とコンクリート製の2つ。入口が開いているので「住む」ためではなく、一時的に逃げこむための形。
  3. 「飛んでくる石（噴石）から身を守る退避所」と1文にする。
答え：火山の噴火によって飛んでくる石（噴石）から身を守るための退避所として設置されている。

49 写真④⑤：貝の化石は貝殻とどこが違うか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「⑤貝の化石（左）と貝殻（右）」と聞かれ方「どのような点が違う」。左の化石は岩にはまりこんで岩と同じ色、右の貝殻は砂の上に白く転がっている、の違いに丸。

📚 前提知識

  • 化石は、地中に自然に埋まって1万年以上かけてできたものを指す（巻末解説）。長い間岩石の中にあるので、成分も岩石に近くなる。
  • 岩石の成分によっては宝石のような輝きをもつ化石になることもある。コハク（樹脂）に取り込まれた生き物は、非常に良い状態で化石になる（◆ポイント◆）。

🔍 こう読み解く

  1. 写真④は、川原で金槌とタガネで石をくだいて化石を取り出している。化石は岩の中に入っている、と分かる。
  2. 写真⑤左の二枚貝の化石は岩と一体で、色も岩と同じ茶色。右の貝殻は白くて軽そうで、砂の上にばらばらに転がっている。
  3. 「岩石の中に入っている」＋「成分も岩石に近い」の2点で書く。
答え：化石は岩石の中に入っており、成分も岩石に近くなっている。

50 似ている点・異なる点 写真⑥：火山灰と川砂の似ている点・異なる点 資料問題・拡大写真の比較

👀 まず見るところ

【資料問題】部品は写真の正体「火山灰（上）と川砂（下）・右は拡大」と聞かれ方「似ている点や異なる点」。拡大写真で粒の色と粒の形を別々に見る → 色は同じ、形は角ばる／丸い、と決まる。

📚 前提知識

  • 直径1/16mm〜2mmの土砂を砂と呼び、火山灰は火山噴出物のうち2mm以下のもの（巻末解説）。
  • 川の砂も、もとはマグマが冷えてできた岩石が細かくなったもの。だから火山灰と似た成分（黒・白・無色透明・緑などの粒）を含む。石英・かんらん石など、大きければ宝石と呼ばれるものもある。

🔍 こう読み解く

  1. 色：上下どちらの拡大写真にも、黒・白・無色透明・緑の粒が混ざっている → 似ている点。
  2. 形：上（火山灰）の粒はかどが立っていて、下（川砂）の粒は丸みをおびている → 異なる点。
  3. 火山灰は噴火で飛び散ってそのまま積もるので角が残り、川砂は流れる水に運ばれる間にぶつかって角がとれる（紙面の写真から読み取れる理由づけ）。
答え：似ている点：黒・白・無色透明・緑などの粒からできている。　異なる点：火山灰は粒が角ばっていて、川砂は粒が丸みを帯びている。
コツ：「似ている点」と「異なる点」で見る項目を分ける（色＝似ている、形＝異なる）。1つの項目で両方を言おうとしない。

51 写真⑦：屛風ヶ浦の崖の茶色い層から分かること 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は設問の「茶色っぽい層（赤土の層）は火山灰の堆積物」と聞かれ方「気づいたことを説明」。崖の写真で茶色の層の数と、いちばん上の層の厚さを見る → 噴火の回数と、最近の噴火の大きさが決まる。

📚 前提知識

  • 火山灰の層が1枚＝噴火1回分。層がいくつもある＝噴火が何度もあった。
  • 「ローム」は砂や泥が混ざった土砂。この火山灰層が赤茶色なのは鉄分（酸化鉄）を含むため（巻末解説）。

🔍 こう読み解く

  1. 崖には、薄い茶色の層が白っぽい層と交互に何枚も見える → 火山の噴火が何度も起こった。
  2. いちばん上の茶色の層だけがとても厚い → 直近に大量の火山灰が積もった。
  3. この2つを「・」で分けて書く。
答え：・薄い茶色の層がいくつも見られることから、火山の噴火が何度も起こったと考えられる。・一番上の火山灰層がとても厚く、直近に大量の火山灰が積もったことが分かる。
コツ：巻末解説には、崖が波で削られないように消波ブロックを置いた結果、南の九十九里浜の砂が減ったといわれる、という話もある。「崖崩れ」「消波ブロック」も写真に写っている。

52 写真⑧：ボーリング調査で地下の地層をどう調べるか 資料問題・写真の説明

👀 まず見るところ

【資料問題】部品は写真の正体「ボーリング調査の様子（左）と取り出された地下の土砂（右）」と聞かれ方「どのようにして調べて」。左の機械の金属の筒と、右の土砂が筒の形をしていることに丸 → 筒を打ち込んで中身を取り出す、と決まる。

📚 前提知識

  • 複数の地点でボーリング調査をすると、地下の地層のつながりを推測でき、地下水や温泉の位置も分かる（巻末解説）。
  • 地盤がやわらかいと建物が傾いたり地震でゆれやすくなったりするので、ビルを建てる前にもボーリング調査をする。掘り進めやすくするために水を使うことがある。

🔍 こう読み解く

  1. 左の写真：地面にあけた穴に、機械で金属の筒を上から打ち込んでいる。
  2. 右の写真：取り出された土砂が細長い筒の形のまま。筒を引き抜くと、中に地層がそのまま入っている。
  3. 「筒を打ち込む → 引き抜く → 中の地層を観察する」の順で1文にする。
答え：金属の筒を上から打ち込んで引き抜いたあと、筒の中に入っている地層の一部を観察する。

53 上空に舞い上がった火山灰を流すもの 知識問題

風。火山灰は火山噴出物のうち直径2mm以下の軽い粒なので、噴煙とともに上空へ舞い上がり、風で広い範囲に運ばれる。日本では偏西風により火山の東側に多く積もる（巻末解説）。写真の桜島も、噴煙が横（右）へ流れている。火山灰が堆積してできた岩石が凝灰岩で、やわらかく加工しやすいので彫像や建造物に使われる（◆ポイント◆）。
答え：風

46〜53 まとめ 写真問題の見方

  • 写真問題は、聞かれ方に線を引いてから、写真の中の目に見える手がかり1つ（赤い光・横にはう根・転がる石・角ばった粒・層の数と厚さ・金属の筒）を見つけ、その理由を1文にする。知識で埋めようとしない。
  • 「違い」を聞かれたら、見る項目を分けて（色は同じ／形が違う、普通の林なら／ここでは）2つ並べてから書く。
  • 覚える語は3つ：噴石（退避所で防ぐ）・火山灰＝2mm以下（風で東側に）・凝灰岩（火山灰が固まった岩）。

54 ①・② 高温の火山ガスと混ざって流れ下るもの 素材文・空らん＋選択

👀 まず見るところ

【素材文】①の部品は「高温の火山ガスと混ざり流れ下る」に丸 → 火山から流れ下るものは溶岩流と火砕流の2つで、ガスと混ざる方が火砕流。②の部品は「700℃に達する」と右の写真（真っ黒な煙が山を下る）→ 速さも「ふつうの人や車では逃げられない」側を選ぶ。

📚 前提知識

  • 噴火で出るものは、噴煙（火山ガス・火山灰）・溶岩流・火砕流。火砕流＝軽石や火山灰が高温の火山ガスと混ざって斜面を流れ下るもの（巻末解説の図）。
  • 火砕流にのまれた建物は、形があまり変わらないまま焼け焦げる（◆ポイント◆）。右の写真の校舎は、ガラスが割れ骨組みだけ残っている。

🔍 こう読み解く

  1. ①「軽石や溶岩などが火山ガスと混ざり流れ下る」＝火砕流。溶岩流は液体の岩がゆっくり流れるもので、ガスとは混ざらない。
  2. ②温度700℃、しかも建物をまるごと焼く → 走る人（時速十数km）では遅すぎ、飛行機（時速数百km以上）では速すぎる。高速道路を走る自動車（時速100km前後）が目安。
答え：① 火砕流　② 高速道路を走る自動車
コツ：「溶岩流＝流れる岩、火砕流＝流れる熱いガスと石」と2語で分けて置く。被害が大きいのは火砕流の方。

55 ①・② ドーム状の火山のマグマと岩石の色 素材文・2択×2

👀 まず見るところ

【素材文】部品は「ドーム状に盛りあがった」に丸。流れずにその場で盛り上がる＝ねばり気が強い、と直して書く → ①が決まれば、②の色はねばり気の強いマグマの決まり（白っぽい）で自動的に決まる。

📚 前提知識

  • マグマのねばり気が強いと、流れにくいので火口の上に盛り上がってドーム状になり、冷えると白っぽい岩石になる。ねばり気が弱いと、遠くまで流れて平たい形になり、黒っぽい岩石になる。
  • 写真は北海道の昭和新山。1943〜45年に麦畑が盛り上がってできた火山で、郵便局長の三松正夫が成長の記録（ミマツダイヤグラム）を残した（巻末解説）。

🔍 こう読み解く

  1. 形から：ドーム状＝流れず盛り上がる＝ねばり気が強く。
  2. 色は形とセットで覚える：ねばり気が強い＝白っぽい。写真の山肌も明るい色をしている。
答え：① 強く　② 白
コツ：「ドーム・強い・白」と「平たい・弱い・黒」の3語ずつで置くと、どれか1つ分かれば残りが決まる。

56 火山の近くの白い煙にもっとも多い気体 知識問題

水蒸気。火山ガスの主成分は水蒸気で、冷えて細かい水のつぶになると白い煙（湯気と同じ）に見える。二酸化硫黄や硫化水素などの有毒ガスも混ざることがあり、写真の黄色いものは硫黄（◆ポイント◆・巻末解説）。「白い煙＝水蒸気」は温泉の湯気と同じ、と結びつける。
答え：水蒸気

57 穴だらけの石はどうしてできたか 知識問題

マグマから火山ガスが出ることでできた。地下のマグマには水がとけこんでいて、マグマが上がって圧力が小さくなると水が水蒸気になってあわ立つ。そのあわのあとが穴（巻末解説）。白っぽいものを特に軽石と呼ぶ。ホットケーキの断面が穴だらけになるのと同じで、焼くときに気体が出た跡（◆ポイント◆）。答えは「マグマ」「火山ガス（水蒸気）」の2語を入れて1文で書く。
答え：マグマから火山ガスが出ることでできた。

58 ①・② 地球の表面をおおうものと、その下の高温の層 素材文・空らん

👀 まず見るところ

【素材文】①の部品は「何枚もの」「年間数cmずつ移動」に丸 → 地球の表面を板のようにおおって動くもの＝プレート。②の部品は「地下深くにある高温の」「とけてマグマに」に丸 → プレートの下にある層＝マントル。

📚 前提知識

  • 地球の表面は十数枚のプレート（かたい岩の板）でおおわれ、その下のマントルの対流に乗って年に数cmずつ動く（巻末解説の図：海嶺で広がり、海溝で沈みこむ）。
  • 沈みこんだプレートは高温のマントルにとけてマグマになる。日本に火山と地震が多いのは、海のプレートが陸のプレートの下に沈みこむ場所だから。

🔍 こう読み解く

  1. 「何枚も」「移動」→ 枚数で数えて動くもの＝プレート。
  2. 「ぶつかると片方が沈み込んで」「地下深くの高温の」→ プレートの下の層＝マントル。
  3. 写真はアイスランドのギャオ。プレートとプレートが左右に離れていく境目で、地面が引き裂かれている（◆ポイント◆）。
答え：① プレート　② マントル
コツ：「表面＝プレート、その下＝マントル」と上下の順で置く。マグマは、沈んだプレートがマントルの熱でとけたもの。

59 マグマが冷えて固まった岩石はどちらか 資料問題・写真の見比べ

👀 まず見るところ

【資料問題】部品は写真の正体を1行ずつ。Aは「小石が集まって固まった石」、Bは「白と黒の大きな結晶が組み合わさった石」と書く → 結晶でできているBが、マグマが冷えてできた岩石と決まる。

📚 前提知識

  • マグマが冷えて固まった岩石（火成岩）は、とけていた成分が結晶になってできる。地下深くでゆっくり冷えると結晶が大きくそろう（等粒状組織）＝深成岩で、Bはカコウ岩（石英・長石・黒雲母の3種類の結晶・巻末解説）。
  • Aは直径2mm以上の粒（レキ）が集まって固まったレキ岩。流れる水が運んだ小石が積もってできた堆積岩で、マグマとは関係がない。

🔍 こう読み解く

  1. Aの表面：丸みのある小石がたくさん見える → 「運ばれて積もった」岩＝堆積岩。
  2. Bの表面：白い部分（石英・長石）と黒い部分（黒雲母）が角ばった結晶として組み合わさっている → 「とけて固まった」岩＝火成岩。
  3. 結晶が大きいほど、地下でゆっくり冷えた証拠。B。
答え：B
コツ：岩石の写真は「粒（小石）」か「結晶（角ばったつぶ）」かで見分ける。粒なら堆積岩、結晶なら火成岩。

60 ①・②・③ 生き物と関係のある化石を選ぶ 資料問題・写真の対応

👀 まず見るところ

【資料問題】部品は①〜③の生き物の正体「カニ・サンゴ・シダ（ヘゴ）」と、A〜Cの正体「穴だらけの丸い骨格・黒い石炭・地面に残った穴」を1行ずつ書く。生き物の「からだのどこが残るか」で結ぶ → 骨格を持つサンゴだけがAになり、残り2つは消去法。

📚 前提知識

  • ①はシオマネキ（カニ）。オスは片方のはさみが大きい。砂にほった巣穴のあとも化石として残る（◆ポイント◆）。ふんや足跡のように、からだそのものでないものも化石になる。
  • ②はサンゴ（産卵中）。イソギンチャクやクラゲの仲間で、炭酸カルシウムのかたい骨格を持つ。Aはその骨格の化石。
  • ③はヘゴ（シダの仲間）。大昔のシダなどの樹木が地下で圧縮され炭化したものが石炭（B）。今の森林では分解者が植物を分解してしまうので、石炭はほとんどできない（◆ポイント◆）。

🔍 こう読み解く

  1. いちばん形で分かるのはA：穴が規則正しく並んだ丸いかたまり＝サンゴの骨格 → ②＝A。
  2. Bは黒くてつやのあるかたまり＝石炭。植物からできる → 植物は③しかない → ③＝B。
  3. 残ったCは地面に並んだ穴のあと。カニの巣穴の化石 → ①＝C。写真①でもカニのすぐ下に巣穴が見える。
答え：① C　② A　③ B
コツ：「生き物の名前」でなく「何が残るか（骨格・炭・穴）」を1行書くと、見た目が似ていない写真どうしでも結べる。

54〜60 まとめ おさえる3点

  • マグマの中の水が水蒸気になる、の1行で 56（白い煙＝水蒸気）と 57（穴だらけの石）の両方が決まる。
  • ねばり気は3語セットで置く：ドーム・強い・白／平たい・弱い・黒（55）。火砕流は「熱いガスと石が流れ下る」で溶岩流と区別する（54）。
  • 写真の問題は正体を1行書いてから結ぶ。岩石は「粒か結晶か」（59・Bがカコウ岩）、化石は「骨格・炭・巣穴の何が残るか」（60）。
