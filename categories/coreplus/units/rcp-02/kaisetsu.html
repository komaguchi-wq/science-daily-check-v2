16 ①の中央付近に見える明るい1等星 資料問題・写真と星座早見

👀 まず見るところ

📚 前提知識（あれば答え合わせに使う）

🔍 こう読み解く

  1. ②の拡大図で、窓わくのまん中（北極星から下におりた線の上）を見る。すぐそばにある1等星の印はベガ。デネブは左上、アルタイルは左下に離れている。
  2. ①の中央にある青白く明るい星がそれ。巻末解説 p.207 の図でも、こと座のベガは天頂付近を通る。
  3. 8月22日の20時だけでなく、7月7日の23時頃にも同じ星空が見える（巻末解説）。
答え：ベガ
コツ：「写真の中央＝天頂＝星座早見の窓わくの中央」と1行書いてから②を見る。②の中央から探せば、他の1等星と迷わない。

17 ①の写真から夏の大三角を探す 資料問題・写真

👀 まず見るところ

【資料問題】部品は「夏の大三角」＝デネブ・ベガ・アルタイルの3つと、16で決めた「中央の星＝ベガ」。ベガに丸を置き、天の川をはさんで並ぶ残り2つの明るい星を結ぶ → 写真の中央から左へ開く三角になる。

📚 前提知識

🔍 こう読み解く

  2. ベガから左上（北東寄り・天の川の中）の明るい星がデネブ、左下（南東寄り・天の川の中）の明るい星がアルタイル。

21 ①に写る火星と木星を探す 資料問題・写真と星座早見

👀 まず見るところ

【資料問題】部品は「星座早見に載っていない」と「火星と木星」。②にある1等星の位置を①から先に消す → 残った明るい点が惑星。

📚 前提知識

  • 惑星は星座をつくる星とはちがう動きをするので、星座に対する位置が変わり、星座早見には描かれていない（巻末解説）。
  • この日時に写る1等星は、ベガ・デネブ・アルタイル・アークトゥルス・アンタレスの5つ。スピカは地平線すれすれで写っていない（巻末解説）。火星は赤っぽく、木星は1等星より明るく見える。

🔍 こう読み解く

  1. ①の明るい星のうち、②にある5つの1等星（中央のベガ、左上のデネブ、左下のアルタイル、右のアークトゥルス、下のアンタレス）に丸をつけて消す。
  2. 残る明るい点は2つ。左下（南東寄り）の赤っぽい星が火星、右下（南西寄り）の白く明るい星が木星。

答え：左下（南東寄り）の赤っぽい明るい星が火星、右下（南西寄り）の明るい星が木星（巻末解説 p.207 ①の図で確認）

22 ③を参考にして①から流れ星を探す 資料問題・写真

👀 まず見るところ

【資料問題】部品は資料の正体「③A＝流れ星の写真」。流れ星は点でなく「細い光の線」に写る、と1行書く → ①の中から線の光をさがす。

📚 前提知識

  • 流れ星は、宇宙にあるちりなどが地球の大気にぶつかって高温になり、一瞬だけ光るもの（巻末解説）。シャッターを開けて撮ると、短い時間に動くので線になって写る。
  • 彗星が残したちりに地球がぶつかると大量の流れ星が見え、これが流星群。空の1点（放射点）から放射状に広がって見える（③B・巻末解説）。
  • 流れ星と間違えやすいのが彗星。太陽の光を反射して光り、尾を引くが、一瞬で消えたりはしない（◆ポイント◆）。

🔍 こう読み解く

  1. ③Aで写り方を確かめる。流れ星は星の点とちがい、進む向きに細く長い線。
  2. ①の右上（北西寄り）に細い線が2本ある。北極星のすぐ右の短い線と、北斗七星の下にある長めの線。これが流れ星。
  3. 巻末解説 p.207 ①の図の「流れ星」の丸と重ねて確かめる。
答え：写真の右上（北西寄り）、北極星の右の短い線と北斗七星の下の長めの線（巻末解説 p.207 ①の図で確認）

23 ①・②・④ 北の空を長時間撮った写真の向きと中心の星 まざり型→資料問題・図1・図2

👀 まず見るところ

【まざり型→資料問題】この小問は写真から決める。部品は「シャッターを開きっぱなし」「星々の中央」「図の左側」。星の線が同心円を描く中心に丸 → 中心の星が④、その星のある空が①、見上げた空の左が②と順に決まる。

📚 前提知識

  • 天体は北極星を中心に動いて見える。北極星は地軸の延長線上にあるため、地球から見える位置がほとんど変化しない（◆ポイント◆）。
  • 北の空では、星は北極星を中心に反時計回りに動く（巻末解説）。北を向いて立つと、左が西・右が東。

🔍 こう読み解く

  1. 図1・図2とも、星の線が1つの点を中心にした同心円になっている。動かない中心の星が北極星（④）。
  2. 北極星が見えるのは北の空 → ①は北。
  3. 北を向いて見上げた空なので、図の左側が西、右側が東 → ②は西（巻末解説 p.208 の図の下の「西←北→東」）。
答え：① 北　② 西　④ 北極星
コツ：同心円の写真は「中心＝北極星＝北の空」とセットで決める。方角は南の空のときと左右が逆（北向きは左が西）なので、向いている方角を先に書く。

23 ③・⑤ 北極星の等級と、星が動いて見える理由 知識問題

③は2、⑤は自転。北極星はこぐま座の2等星で、1等星ほど明るくはない（星座早見の印でも★2等星）。星が北極星を中心に回って見えるのは、地球が地軸を軸にして1日に1回自転しているため。北極星は地軸の延長線上にあるので、ほぼ動かない（◆ポイント◆）。「公転」は季節で見える星座が変わる理由なので、1晩の動きとは区別する。
答え：③ 2　⑤ 自転

16〜23 まとめ 見直しの要点

  • 全天写真と星座早見は「中央＝天頂」「上が北・下が南・左が東・右が西」の2行を先に書く。16（ベガ）・19（西）・20（8月）はこの2行と②の目もりだけで決まる。
  • 探す問題（17・18・21・22）は、ベガ→夏の大三角→北斗七星・カシオペヤ座→北極星の順に印をつけ、残った明るい点が惑星、細い線が流れ星。答えは巻末解説 p.207 ①の図で確かめる。
  • 23は「同心円の中心＝北極星＝北の空＝地球の自転」をひとまとまりで。北向きの写真は左が西。

24 図1は北海道と沖縄のどちらか 資料問題・写真と緯度

👀 まず見るところ

【資料問題】部品は写真の正体「北の空の星の動き（円の中心＝北極星）」と聞かれ方「北海道と沖縄のどちら」。図1と図2で、円の中心が地平線からどれだけ高いかを見比べる → 中心が低い方が緯度の低い沖縄と決まる。

25 ②・③・④ 写真の方角と左右の方角 資料問題・3つ星の向き

26 ①・② 北の空の写真の方角と季節 資料問題・星座の位置

👀 まず見るところ

【資料問題】部品は写真の正体「こぐま座（北極星）が中央の星空・20時頃」と、下にある「北斗七星」・上にある「カシオペヤ座」。北極星が写っていれば北の空、20時にカシオペヤ座が高くて北斗七星が低ければ秋と決まる。

📚 前提知識

  • 北斗七星とカシオペヤ座は北極星をはさんで反対側にあり、どちらも北極星をさがす目印。
  • 北斗七星は春から夏、カシオペヤ座は秋から冬に、夜中に高いところに見える（◆ポイント◆）。

🔍 こう読み解く

  1. 写真の中央に「こぐま座」、左下に「北斗七星（おおぐま座）」、右上に「カシオペヤ座」。こぐま座の先の北極星が中央にあるので北の空（①）。
  2. 20時の時点でカシオペヤ座が高く、北斗七星は地平線近く → カシオペヤ座が高い季節＝秋（②）。
  3. 確かめ：夏の大三角のはくちょう座が北の空の上に写っている。夏の星座が北へ下がってきた秋の夜のながめ。
答え：① 北　② 秋

26 ③・④ 1時間後の北斗七星とカシオペヤ座 資料問題・北の空の回転

👀 まず見るところ

【資料問題】部品は「1時間後」と、2つの星座の今の位置「北斗七星＝左下」「カシオペヤ座＝右上」。北極星を中心に反時計回りの矢印を写真に描く → 左下の星は下へ、右上の星は上へ動くと決まる。

📚 前提知識

  • 北の空の星は北極星を中心に反時計回りに、1時間に15度動く（23の◆ポイント◆の図）。
  • 反時計回りは、北極星の左側では下へ、右側では上へ向かう動き。

🔍 こう読み解く

  1. 写真の中央（北極星）に反時計回りの円を描く。左下にある北斗七星は、円に沿ってさらに下へ → 低い（③）。
  2. 右上にあるカシオペヤ座は、円に沿って上へ → 高い（④）。
  3. 北斗七星が沈みかけ、カシオペヤ座がのぼりきる途中、という②の秋の夜の動きとつじつまが合う。
答え：③ 低い　④ 高い
コツ：「高い・低い」は頭で考えず、北極星に反時計回りの矢印を描いてから読む。左は下へ、右は上へ。

27 ①・②・③ 図1の方角・季節・左側の方角 資料問題・夏の大三角

👀 まず見るところ

【資料問題】部品は「〔②〕の大三角」と写真の正体「天の川と3つの1等星・地平線付近」。天の川の中の明るい星3つ＝夏の大三角と決まれば季節は夏、地平線付近に見える＝のぼってくる東の空と決まる。

📚 前提知識

  • 夏の大三角＝ベガ（こと座）・アルタイル（わし座）・デネブ（はくちょう座）。天の川をはさんでベガとアルタイルが向かい合い、デネブは天の川の中。
  • アルタイルとベガ・デネブは真東より北寄りから出て、真西より北寄りに沈む（巻末解説）。
  • 東を向くと左が北、右が南。

🔍 こう読み解く

  1. 図1の天の川の中と両わきに明るい星が3つ。巻末解説の図ではベガ（左上）・デネブ（左下）・アルタイル（右）。これが夏の大三角 → 夏（②）。
  2. 大三角が地平線近くにあるのは、のぼってきたばかりの夜。夏の夜に見えるのは東の空（①）。
  3. 東を向いて左が北（③）。アルタイルの近くの黄緑色の線はホタルの光（◆ポイント◆）で、季節が6〜7月の夏であることのもう1つの合図。
答え：① 東　② 夏　③ 北

27 ④ 天の川を右へたどると見える1等星をもつ星座 資料問題・天の川の向き

👀 まず見るところ

【資料問題】部品は「天の川を右の方へたどる」「1等星をもつ」。①で右＝南と決めたので、夏の天の川を南へたどった先の星座、と置きかえる → さそり座のアンタレスに決まる。

📚 前提知識

  • 夏の天の川は、北のはくちょう座から南のさそり座・いて座の方へのびる。さそり座の1等星は赤いアンタレス。
  • 夏の天の川が濃いのは、銀河の中心方向を見ているから（◆ポイント◆）。中心方向はさそり座・いて座のあたり。

🔍 こう読み解く

  1. 図1の右端は天の川がいちばん濃い部分。濃い＝銀河の中心方向＝南の空。
  2. 南の天の川にある1等星の星座はさそり座。9ページの星座早見でも、アンタレスは南の地平線近くの天の川のそば。
答え：さそり

27 ⑤ 太陽系をふくむ無数の星の集まり 知識問題

銀河。図2のようなうずまき形の星の集まりが宇宙にはいくつもあり、太陽系は天の川銀河の中にある。星座をつくる星はどれも太陽系と同じ天の川銀河の星（◆ポイント◆）。天の川は、その銀河を内側から見た姿。
答え：銀河

28 写真のオリオン座はどちらの方角か 資料問題・3つ星の向き

👀 まず見るところ

【資料問題】部品は写真の正体「オリオン座」と聞かれ方「どちらの方角」。写真の3つ星の向きを丸で囲む → 横に並んでいれば西の空と決まる。

📚 前提知識

  • オリオン座の3つ星は、東の空では縦、西の空では横に並ぶ（◆ポイント◆）。25の写真（縦）とこの写真（横）が対になっている。

🔍 こう読み解く

  1. 写真の中央やや下、木の左に3つ星。横一列に並んでいる。
  2. 横＝沈むとき＝西の空。巻末解説の図でも、左が南・右が北の西向きの写真。
答え：西

29 写真に写っている冬のダイヤモンドの1等星4つ 資料問題・星の位置関係

👀 まず見るところ

【資料問題】部品は「冬のダイヤモンドの6つの1等星のうち」と「写っている4つ」。◆ポイント◆の六角形の図を写真に重ね、写真の上の端より上にある2つを外す → 残りの4つが答え。

📚 前提知識

  • 冬のダイヤモンド＝ポルックス・カペラ・アルデバラン・リゲル・シリウス・プロキオンの六角形。まん中にベテルギウス（赤）。
  • 南中時はポルックスとカペラが六角形のいちばん上にあり、この写真には写っていない（◆ポイント◆）。

🔍 こう読み解く

  1. 28で見つけた3つ星からオリオン座を作り、右下の青白い星がリゲル、中央の赤い星がベテルギウス。
  2. 巻末解説の図で、オリオン座の左下にシリウス、左上にプロキオン、右上にアルデバラン（そのそばにすばる）。
  3. 六角形の上の2つ（ポルックス・カペラ）は写真の上に切れている → 答えは残りの4つ。
答え：アルデバラン・リゲル・シリウス・プロキオン
コツ：「写っていないのはどれか」から考える。◆ポイント◆の図で上に出ている2つを消せば、残りが自動的に決まる。

30 ①・② 日の出か日の入りか・季節は夏か冬か 資料問題・太陽とオリオン座

👀 まず見るところ

【資料問題】部品は写真の中の「太陽の位置（左下）」と「オリオン座の3つ星の向き」。3つ星が縦なら東の空＝日の出と決まり、太陽がオリオン座（真東）より左＝北寄りからのぼっていれば夏と決まる。

📚 前提知識

  • 太陽は夏至に真東より北寄りから出て、冬至に真東より南寄りから出る（◆ポイント◆の図）。
  • オリオン座の3つ星は真東から出て真西に沈む。夏のオリオン座は太陽とほぼ同じ方角にあるので、夏は日の出の直前にしか見えない（◆ポイント◆）。

🔍 こう読み解く

  1. 写真の右上に3つ星が縦に並んだオリオン座 → 東の空 → 太陽はのぼる途中＝日の出（①）。
  2. 東を向くと左が北。太陽はオリオン座（真東）より左＝北寄りにある → 真東より北から出る季節＝夏（②）。
  3. 確かめ：冬ならオリオン座は夕方の東の空にのぼり、朝には西に沈んでいる。朝の東の空にオリオン座があるのは夏の方。
答え：① 日の出　② 夏

24〜30 まとめ 自分で解くときの合図

  • 方角は3つ星の向きで決める：縦＝東（25・30）、横＝西（28）。決まったら十字を描いて左右の方角を写す（東を向けば左が北）。
  • 北の空は北極星が中心：中心の高さ＝緯度（24・高い方が北海道）、動きは反時計回り（26・左は下へ、右は上へ）。
  • 季節は星座で：夏の大三角＋ホタル＝夏（27）、カシオペヤ座が高い夜＝秋（26）、朝の東にオリオン座＋北寄りの日の出＝夏（30）。冬のダイヤモンドの上2つ（ポルックス・カペラ）は南中時にいちばん高い（29）。
