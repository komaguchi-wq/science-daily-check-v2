824 グルカゴン・インスリン 血糖値を調節する2つのホルモン グラフの読み取り・はたらきの説明

👀 まず見るところ

【資料問題】部品は3つのグラフの正体「食後の血液中の濃さ・ブドウ糖／グルカゴン／インスリン」を1行で書き、点線の「食事」のあとに各線が上がるか下がるかを見る。ブドウ糖が増えたときに増えるのがインスリン、減るのがグルカゴン → 増えた糖を下げる係と、糖が足りないとき上げる係に分かれる。

📚 前提知識

  • ホルモンは体のはたらきを調節する物質。体内の臓器でつくられ、血液にのって全身に送られる。グルカゴンとインスリンはどちらもすい臓でつくられる。
  • グルカゴンは肝臓にたくわえたグリコーゲンをブドウ糖に変えて血液に出す（血糖値を上げる）。インスリンは血液中のブドウ糖を細胞の中にとり込ませる（血糖値を下げる）。
  • インスリンが出にくくなり血糖値が下がらない病気が糖尿病。本来は尿に出ないブドウ糖が尿に出てくることから付いた名前。

🔍 こう読み解く

  1. 食事のあと、ブドウ糖の線が山になる。同じタイミングでインスリンも山になる → 糖が増えたときに出て、糖を下げる役。
  2. グルカゴンは食事のあと谷になる → 糖が増えたら引っ込み、糖が足りないときに出て上げる役。2つは反対向きの係で、組になって血糖値をほぼ一定に保つ。
  3. 答えは「上げる／下げる」の向きが決め手。言い方は「血糖値を上げる」「血糖値を下げる」の短い形でよい。
答え：グルカゴン＝血糖値を上げる　インスリン＝血糖値を下げる
コツ：どちらが上げるか迷ったら、グラフで「ブドウ糖と同じ動きをする線」を探す。同じ動き＝増えた糖を処理する係＝下げるインスリン。焼肉の「ホルモン」は小腸などの内臓の名前で、ここでいうホルモンとは別もの。

825 ①AB型・①O型 「AO」と「BO」の両親から生まれる子 図の読み取り・組み合わせ

👀 まず見るところ

【資料問題】部品は本文の決まり「父親と母親からそれぞれ1つずつ受け継ぐ」と、図の正体「例1はAとBを選んだ子、例2はOとOを選んだ子」。親の「AO」から1つ、「BO」から1つを選ぶ組み合わせを4つ全部書き出す（直して書く）→ 出てきた組の中にABとOOがあるかで決まる。

📚 前提知識

  • 本文の表どおり：「AA」「AO」＝A型、「BB」「BO」＝B型、「AB」＝AB型、「OO」＝O型。Oは相手がA・Bだと表に出ない。

🔍 こう読み解く

  1. 父「AO」から A か O、母「BO」から B か O。かけ合わせは AB・AO・OB・OO の4通り。
  2. AB → AB型の子が生まれる。OO → O型の子が生まれる。図の例1（AO）と例2（OB）は、4通りのうちの2つを見せているだけで、残り2つも同じように起こる。
  3. 両親がA型とB型でも、子はA・B・AB・Oの4種類すべてになりうる。「親に無い型は生まれない」と思い込まないこと。
答え：AB型＝生まれる　O型＝生まれる
コツ：親の文字を縦横に並べた2×2の表（たて A・O／よこ B・O）を書くと、4つの組を落とさない。

825 ② AB型とO型の両親から生まれる子の血液型 条件文・組み合わせ

👀 まず見るところ

【条件文】部品は設問の「AB型とO型の両親」。このままでは組み合わせを作れないので、本文の表で遺伝子の形「AB」「OO」に直して書く → AB から1つ、OO から1つを選べば子の組が決まる。

📚 前提知識

  • O型の遺伝子は「OO」の1通りしかない。AB型も「AB」の1通り。だから両親の遺伝子の形が迷わず決まる。
  • 子はAかBのどちらかを受け継ぎ、もう片方はO以外にならない → 「AO」か「BO」。

🔍 こう読み解く

  1. 「AB」から A または B、「OO」からは O だけ。組は AO と BO の2通り。
  2. AO＝A型、BO＝B型。AB型もO型も生まれないことまで言えると、①との対比で覚えやすい。
答え：A型・B型
コツ：血液型はABO式のほかにRh式などもある（Rhはアカゲザルのこと）。ちがう型の血液が体に入ると血液が固まって命にかかわるので、輸血では型を合わせる。血液型と性格には関係がない。

826 ① 緑緑と黄黄をかけ合わせたときの黄色の確率 条件文・遺伝の組み合わせ

👀 まず見るところ

【条件文】部品は本文の決まり「緑黄のとき黄色」と、設問の「緑緑のエンドウと黄黄のエンドウ」。親から1つずつ選ぶ組を4つ書き出す（直して書く）→ 4つがぜんぶ同じ組になるので、確率はその組の色で決まる。

📚 前提知識

  • 種子の色の遺伝子は 緑緑・緑黄・黄黄 の3通り。緑緑だけ緑色、緑黄と黄黄は黄色。
  • 両方そろわないと性質が出ない遺伝子（緑）を潜性（劣性）、片方あれば出る遺伝子（黄）を顕性（優性）という。
  • メンデル（オーストリア）が1865年、エンドウの実験で確かめた決まり。

🔍 こう読み解く

  1. 緑緑からは緑しか来ない。黄黄からは黄しか来ない。組は4つとも緑黄。
  2. 緑黄は黄色の種子 → 4つのうち4つが黄色＝100%。親に緑色がいても、子には緑色が1つも出ない。
答え：100%

826 ② 緑黄を自家受粉させたときの黄色の確率 条件文・遺伝の組み合わせ

👀 まず見るところ

【条件文】①と変わった部品は「緑黄のエンドウを自家受粉」に丸。自家受粉＝同じ株の花粉がつくので、親は緑黄と緑黄。選び方を2×2の表にして4つ書き出す（直して書く）→ 緑緑が何個あるかで決まる。

📚 前提知識

  • ①と同じ決まり。緑緑だけが緑色、緑が1つでも黄があれば黄色。
  • 確率は「あてはまる組の数 ÷ 全部の組の数」。組は4つが基本。

🔍 こう読み解く

  1. 一方の緑黄から 緑 か 黄、もう一方の緑黄からも 緑 か 黄。組は 緑緑・緑黄・黄緑・黄黄 の4通り（緑黄と黄緑は同じ色なので分けて数える）。
  2. 緑色になるのは緑緑の1つだけ。黄色は残りの3つ → 3÷4＝75%。
  3. 検算：緑色は25%。黄緑と緑黄をまとめて「3通り」と数えると 2/3 になって間違う。4つに分けて数える。
答え：75%
コツ：遺伝子（DNA）の構造が分かったのは1953年。メンデルの実験のとき（1865年）は、遺伝を起こす物質が何かはまだ分かっていなかった。

827 ①・②・③・④ DNAからたんぱく質ができるまで 図の読み取り・名前

👀 まず見るところ

【まざり型→資料問題】部品は本文の流れ「DNA → 必要な部分をコピーした mRNA → リボソームで tRNA が運んできたアミノ酸をつなぐ → たんぱく質」の4語に丸。図は①〜④が核の中から細胞質へ、矢印の順に並んでいるので、丸をつけた4語を矢印の順に図へ置く。

📚 前提知識

  • DNAは遺伝情報をもつ物質で、2重らせんの形。細胞の核の中にある。
  • mRNAはDNAの必要な部分だけを写し取ったコピー。核を出てリボソーム（粒）へ行く。tRNAはアミノ酸を1つずつリボソームへ運ぶ係。
  • アミノ酸が鎖のようにつながったものがたんぱく質。

🔍 こう読み解く

  1. ②は核の中の、らせんの形のもの → DNA。②からコピーされて核の外へ出ていく③ → mRNA。
  2. ①は tRNA がつかんでリボソームへ運んでくる黒い粒 → アミノ酸。
  3. ④はリボソームから出てくる、黒い粒がつながった鎖 → アミノ酸がつながったたんぱく質。
答え：① アミノ酸　② DNA　③ mRNA　④ たんぱく質
コツ：新型コロナウイルスのmRNAワクチンは、ウイルスの遺伝子の一部（mRNA）を接種して、ウイルスのたんぱく質をヒトの体内でつくらせるしくみ。「mRNA→たんぱく質」の流れがそのまま使われている。
