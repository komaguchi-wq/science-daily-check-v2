発展1 (8) 日本とハワイがくっつくまでの年数 条件文・単位の計算

👀 まず見るところ

【条件文】部品は「1年間におよそ6cm」と「約6000km」。単位がcmとkmでちがうので、そのままでは式に入らない。6000kmを「600000000cm」に直して書く → 6でわれば年数になる。

📚 前提知識

  • 1km＝1000m、1m＝100cm。だから1km＝100000cm（0が5つ）。
  • かかる時間＝距離÷速さ。「1年間に6cm」は1年あたりなので、距離を6cmでわる。

🔍 こう読み解く

  1. 使う式を余白に書く。年数＝距離（cm）÷6（cm／年）。
  2. 単位をそろえる。6000km＝6000000m＝600000000cm（6億cm）。
  3. 600000000÷6＝100000000年＝1億年。
  4. 検算。6cmで1年 → 6m（100倍）で100年 → 6km（1000倍）で10万年 → 6000km（1000倍）で1億年。本文の「パンゲアは2億年前ごろ」とも同じ億年のけたで、大陸の動きの話として合う。
答え：1億年後
コツ：0の数は4けたごとに区切って数える。6｜0000｜0000cm＝6億cm。解答らんには「年後」が印刷されているので、書くのは「1億」。

  2. 理由は、その工夫で何が正確になるかを書く。糸の向こうに山を見れば、山の線がどの糸をこえたかで高さの変化が読める →「高さの変化を正確にはかるため」。
  3. 理由を「正確に記録するため」だけにすると、工夫②の理由と区別がつかない。糸は「高さ」をはかるため、と書き分ける。
模範解答：工夫① 糸を水平に4本張った。／理由 高さの変化を正確にはかるため。

発展2 (3)工夫②・(3)理由② あごをのせる台 記述・絵の読み取り

👀 まず見るところ

【資料問題】部品は「工夫を2つ」。糸のほかにもう1つ、今度は人のまわりをさがす → 三松さんのあごの下に小さな台がある。顔を動かさないためのもの、と決まる。

📚 前提知識

  • 目の位置が動くと、同じ山でも糸との重なり方が変わってしまう。(1)(2)の問題文にくり返し出てくる「同じ場所から」は、目の位置まで同じにして初めて成り立つ。
  • 解答冊子の説明は「自分の感覚にたよった観測ではなく、正確で科学的な観測をするために視点を固定し、測定の基準を設けることが重要」。視点の固定があごの台、測定の基準が糸にあたる。

✍️ 答案の組み立て

  1. 工夫：何を固定する台かまで書く。「あごの位置を固定する台を作った」。「台を作った」だけでは、絵をかく机と区別がつかない。
  2. 理由：あごを固定すると何が決まるか →「観測を行う目の位置を固定するため」。
模範解答：工夫② あごの位置を固定する台を作った。／理由 観測を行う目の位置を固定するため。
コツ：「工夫と理由」の記述は、工夫＝絵に見えるもの、理由＝それで何が正確になるか。2組の理由が同じ文にならないように、「高さ」「目の位置」と言葉を分ける。

発展2 (4) 火山活動のくわしい記録が重要な理由 記述・理由

👀 まず見るところ

【素材文】設問は「なぜ重要なのか」。部品は「たびたび活動」「1977年と2000年に噴火」に丸 → くり返し噴火する山だから、記録は次の噴火へのそなえに使える、と書く。

📚 前提知識

  • 記録を重ねると、噴火の前ぶれや進み方が分かってくる。これが噴火の予知につながる。
  • 解答冊子の説明：予知のためだけでなく、災害時に適切な行動をとるためにも重要。ハザードマップも、噴火の様子やその火山の特徴を調べておかないと作れない。
  • 有珠山の2000年の噴火では、前ぶれの地震をもとに噴火の前に住民が避難し、犠牲者が出なかったとされる。

✍️ 答案の組み立て

  1. 部品A（記録から分かること）：火山活動のしくみを理解する。
  2. 部品B（何に役立てるか）：噴火の予知や対策に役立てる。
  3. 部品C（何のためか）：被害を最小限にとどめる。A→B→Cの順につなぎ、「〜ため。」で終える。
模範解答：火山活動のしくみを理解し、噴火の予知や対策に役立てて、被害を最小限にとどめるため。
コツ：「次の噴火に役立つから」で止めると部品Bだけになる。何に役立て、その結果何を減らすのかまで書くと、3つの部品がそろう。

発展2 (5) ミマツダイヤグラムが貴重な理由 記述・理由

👀 まず見るところ

【素材文】設問は「貴重な資料とされる理由」。部品ははじめの説明文の「昭和新山が誕生」「くわしく記録」に丸 → 何を（山が誕生するまで）・どのように（くわしく）記録したかを書き、「類を見ない」を言いかえる。

📚 前提知識

  • 「類を見ない」は、ほかに同じようなものが無いという意味。答案では「世界でも初めて」と言いかえる。
  • 図2の日付は昭和19年5月12日から昭和20年9月10日まで。畑が山になっていくはじめから終わりまでを、同じ場所から同じ方法で記録し続けている。

✍️ 答案の組み立て

  1. 部品A（何を）：火山の噴火によって新しい山が誕生するまでの過程。
  2. 部品B（どのように）：とても詳しく記録した。
  3. 部品C（なぜ貴重か）：世界でも初めてのものだった。理由を聞かれているので「〜から。」で終える。
模範解答：火山の噴火によって新しい山が誕生するまでの過程をとても詳しく記録した世界でも初めてのものだったから。
コツ：「くわしく記録したから」だけでは、何の記録かが抜けている。丸をつけた「誕生」を使って、「山が誕生するまでの過程」と書く。

発展2 まとめ 記録の読み方

  • 同じ場所からの記録（図1）は、いちばん上と下の絵を見比べ、変わった所に丸。図の中の文字「麦畑」も部品になる。
  • 重ねた線（図2）は、間が広い＝急に変化、せまい＝ゆっくり。「いつ広いか」を日付と結びつけて書く。
  • 理由の記述は「何を・どのように・何のため」。設問文と説明文で丸をつけた言葉（たびたび活動・誕生・くわしく記録）をそのまま使う。
