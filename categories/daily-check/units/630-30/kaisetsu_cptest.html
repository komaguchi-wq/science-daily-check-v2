630-30 L（コアプラス＋確認テスト・光合成のグラフ／気体の集め方／アルミニウムと塩酸／オリオン座の動き）

L 全体像 コアプラス＋確認テスト 10問

中身は5つに分かれる。(1)(2)は光合成のグラフ、(3)〜(5)はどんぐり・酸性雨・カイロの知識、(6)は気体の集め方とメスシリンダー、(7)(8)はアルミニウムと塩酸の計算、(9)(10)はオリオン座の動き。

グラフ・表・図の問題は、「どこで比べるか」を先に決めると迷わない。(2)は0の線、(7)は水素が120で止まる所、(9)(10)は図の30度を時間や月に直す。

L (1) 明るいところで育ちがよい植物 資料問題・グラフの右はし

👀 まず見るところ

【資料問題】資料の正体は「光の強さと二酸化炭素の吸収量」のグラフ。聞かれ方「明るいところ」に線 → 見るのは右はし（光が強い側）。右はしで上にあるAが、育ちがよい。

📚 前提知識

  • 二酸化炭素の吸収量が多い＝光合成がさかん＝養分（でんぷん）をたくさん作れる＝よく育つ。
  • 強い光を受けるほど光合成の量が大きくなる植物を陽生植物、弱い光でも育つかわりに、光を強くしても早めに頭打ちになる植物を陰生植物という。グラフではAが陽生、Bが陰生の形。

🔍 こう読み解く

  1. 縦軸は二酸化炭素の吸収量、横軸は光の強さ。右へ行くほど明るい。
  2. 右はし（光の強さ15あたり）では、Aの線がBより上。2本の線が交わるのは光の強さ9あたりで、それより明るいとAのほうが多く吸収する。
  3. うす暗い側（光の強さ5あたり）では逆にBが上。「明るいところ」と聞かれているのでA。
答え：A
自分で解くときのチェック：線が途中で入れかわるグラフは、設問の「明るい／暗い」に丸をつけてから、右はしを見るか左はしを見るかを決める。

L (2) 光の強さ7で育てたときのAとB 資料問題・0の線とくらべる

👀 まず見るところ

【資料問題】部品は「光の強さを7」。横軸の7から上へ線を引く（図に置く）。比べる相手はもう一方の植物でなく0の線。AもBも0より上なので、どちらも枯れない。

📚 前提知識

  • 植物は光合成で二酸化炭素を吸収し、呼吸で出している。吸収量が＋なのは、光合成で作る養分が呼吸で使う養分より多いということ → 育つ。
  • 吸収量が−の明るさが続くと、養分を使うほうが多くなり、やがて枯れる。0の点は、光合成と呼吸がちょうどつり合う明るさ。

🔍 こう読み解く

  1. 線が0を横切る所を目もりで読む。Bは光の強さ2あたり、Aは6あたり。
  2. 7はどちらよりも右 → A・Bとも吸収量は＋。Aは0を少しこえた所、Bはもう一定の高さになっている。
  3. 両方＋なので、AもBも枯れない＝ウ。
答え：ウ
自分で解くときのチェック：7ではAの線がBより下にあるので「Aだけ枯れる」を選びたくなる。枯れるかどうかは0より上か下かだけで決める。光の強さが4なら、Aだけが−になってアが答えになる。

L (3) どんぐりをつくる木のなかまと図のどんぐり 素材文・図の見分け

👀 まず見るところ

【素材文】①の部品は「科の果実の総称」に丸 → 木1本の名前でなく、なかまの名前を答える。②は右図のぼうしの形を見る。細長いりん片がそり返ってもじゃもじゃ → クヌギ。

📚 前提知識

  • どんぐりは、クヌギ・コナラ・カシ・シイなどブナ科の木の実をまとめた呼び名。
  • どんぐりのぼうし（殻斗）は木ごとに形がちがう。クヌギは実が丸く、ぼうしは細長いりん片が外へそり返る。コナラは実が細長く、ぼうしは浅いおわん形でうろこもよう。

🔍 こう読み解く

  1. ①「〔　〕科」の形なので、なかまの名前 → ブナ。
  2. ②図の実は丸く、ぼうしは細長いりん片がそり返っている → クヌギ。うろこもようの浅いぼうしならコナラ、と形で分ける。
答え：① ブナ　② クヌギ

L (4) 工場の煙にふくまれるSOx 知識問題

硫黄酸化物（いおうさんかぶつ）。SOxのSは硫黄、Oは酸素を表す記号で、石炭や石油にふくまれる硫黄が燃えるとできる。自動車の排気ガスなどに多い窒素酸化物（NOx）とセットで、どちらも雨にとけて酸性雨の原因になる。Sなら硫黄、Nなら窒素、と頭文字で区別する。
答え：硫黄酸化物

L (5) 使い捨てカイロが発熱するしくみ 知識問題

①鉄（鉄粉）　②酸素。鉄が空気中の酸素と結びつく（さびる）ときに熱が出る。カイロは鉄を粉にして空気にふれる面積を大きくし、短い時間でいっきに反応させている。外袋を開けると温かくなるのは、そこで初めて空気中の酸素にふれるから。
答え：① 鉄（鉄粉）　② 酸素

L (6) メスシリンダーに集まった気体と体積 まざり型・図の読み取り

👀 まず見るところ

【まざり型→資料問題】部品は図の2か所。石灰石とメスシリンダーのあいだにある空のフラスコと、拡大図の目もり「20が上・30が下」。前者で気体の正体、後者で体積の読み方が決まる。

📚 前提知識

  • 石灰石に塩酸を加えると二酸化炭素が発生する。二酸化炭素は水に少しとけるので、そのまま水の中をくぐらせると体積が少なめに出てしまう。
  • そこで、あいだに空のフラスコをはさむ。二酸化炭素は空気より重いので底にたまり、もとからフラスコに入っていた空気を押し出す。空気は水にほとんどとけないので、押し出された分がそのままメスシリンダーに集まる。
  • メスシリンダーは、水面の平らな所を真横から見て、いちばん小さい1目もりの10分の1まで読む。

🔍 こう読み解く

  1. 気体の通り道を指でたどる。石灰石のフラスコ → 空のフラスコ（底までとどく長い管から入る）→ 短い管 → メスシリンダー。
  2. 二酸化炭素は底にたまり、上にあった空気が短い管から出ていく → 集まっているのはフラスコ内の空気。
  3. メスシリンダーはさかさなので、数字は上から下へ増える。20と30のあいだが10目もり → 1目もり1cm³。水面は20から下へ7目もり目の線の上 → 27。10分の1まで読んで27.0。
答え：① （フラスコ内の）空気　② 27.0cm³
自分で解くときのチェック：さかさの目もりは、数字が増える向きの矢印を先に書く。線の上にぴったりのときも「27」で止めず、「.0」まで書く。

L (7) アルミニウム0.3gと塩酸80cm³・あまるのはどちら 資料問題・過不足

👀 まず見るところ

【資料問題】資料の正体は「アルミニウム0.1gに加えた塩酸と水素の量」。水素が120で止まる所に丸 → 0.1gとちょうど反応する塩酸は40cm³。これを3倍して80cm³と比べる。

📚 前提知識

  • 塩酸を増やしても水素が増えなくなったら、アルミニウムがなくなった合図。反応する相手がいないので、足した塩酸はあまる。
  • 「ちょうど」の組を1つ作れば、あとは比例で考えられる。ここではアルミニウム0.1g＋塩酸40cm³ → 水素120cm³。

🔍 こう読み解く

  1. 表を左から読む。塩酸10cm³ごとに水素は30cm³ずつ増え、40cm³で120cm³。50cm³でも120cm³のまま → 40cm³でアルミニウム0.1gがちょうどなくなる。
  2. アルミニウム0.3gは0.1gの3倍 → 全部とかすのに必要な塩酸は 40×3＝120cm³。
  3. あるのは80cm³で、120cm³に足りない → 塩酸が先になくなり、アルミニウムがあまる。（80cm³でとかせるのは0.2gなので、0.1gが残る。）
答え：アルミニウム
自分で解くときのチェック：表の上に「0.1gのとき」、問題文の「0.3g」の横に「×3 → 塩酸120」と書いてから80と比べる。

L (8) (7)のときに発生した水素 条件文・計算

👀 まず見るところ

【条件文】部品は「(7)のとき」＝塩酸80cm³は全部使われ、アルミニウムがあまる。水素の量は使い切るほう（塩酸）で決まる → 「塩酸10cm³で水素30cm³」を8倍に直して書く。

📚 前提知識

  • 発生する気体の量は、先になくなるほうの量で決まる。あまるほうの量で計算すると多すぎる答えになる。

🔍 こう読み解く

  1. 表から、塩酸10cm³が全部反応すると水素30cm³。
  2. 塩酸80cm³は10cm³の8倍 → 30×8＝240cm³。
  3. 確かめ：とけたアルミニウムは0.2g。0.1gで120cm³だから 120×2＝240cm³。同じになる。
答え：240cm³
自分で解くときのチェック：アルミニウム0.3gで計算して 120×3＝360 とするのがよくあるまちがい。(7)で「あまる」と答えたほうは、計算に使わない。

L (9) オリオン座がAに見える時刻 条件文・星の1日の動き

👀 まず見るところ

【条件文】部品は「午後8時頃南中」と図の「30度」。30度は時間に直して書く（1時間に15度 → 2時間）。Aは南中より東側＝南中の前なので、午後8時の2時間前。

📚 前提知識

  • 星は地球の自転のために、1日（24時間）で1回り（360度）して見える。360÷24＝1時間に15度。
  • 南の空の星は、東からのぼって南で最も高くなり（南中）、西へしずむ。南を向いて立つと、左手が東、右手が西。

🔍 こう読み解く

  1. 図のまん中のオリオン座に「2月中旬・午後8時」と書きこむ。
  2. Aはまん中より左＝東側。星は東から西へ動くので、Aにあるのは南中の前。
  3. 30÷15＝2時間前 → 午後8時−2時間＝午後6時。
答え：午後6時
自分で解くときのチェック：前と後を逆にすると午後10時になる。図に「東・西」と動く向きの矢印を先に書いてから計算する。

L (10) 午後8時にAに見える月 条件文・星の1年の動き

👀 まず見るところ

【条件文】(9)と変わった部品は「午後8時に」＝時刻をそろえて月を変える。図の「30度」は今度は月に直して書く（1か月に30度 → 1か月）。Aは南中の手前なので1か月前。

📚 前提知識

  • 同じ時刻に見える星の位置は、地球の公転のために、1年（12か月）で1回り（360度）する。360÷12＝1か月に30度ずつ、東から西へずれていく。
  • 言いかえると、同じ位置に来る時刻は1か月に2時間ずつ早くなる。

🔍 こう読み解く

  1. 午後8時の位置は、2月中旬がまん中（南中）。
  2. Aはそれより30度東＝まだ南中まで来ていない位置。1か月に30度ずつ西へ進むので、Aに見えるのは1か月前 → 1月中旬。
  3. 確かめ：(9)より、2月中旬にAに来るのは午後6時。1か月前は2時間おそくなるので午後8時。合っている。
答え：1月
自分で解くときのチェック：同じ30度でも、時刻を変えるなら÷15で2時間、月を変えるなら÷30で1か月。設問の「何時頃」「何月中旬」に丸をつけて、どちらで割るかを決める。

L まとめ 未解答・自分で解くとき

  • グラフと表は「どこで比べるか」を先に決める：(1)は右はし、(2)は0の線、(7)は水素が増えなくなる所。
  • (6)は気体の通り道をたどって正体を決め、さかさの目もりは増える向きを確かめてから10分の1まで読む。(8)は先になくなるほうで計算する。
  • 星の30度は、時刻を変えるなら2時間、月を変えるなら1か月。東側（南中の前）なら、どちらも「前」へもどす。

M (1) 光の強さ3000のときの呼吸と光合成 資料問題・グラフの読み取り

👀 まず見るところ

【資料問題】部品は資料の正体「光の強さと二酸化炭素の吸収量」と、答え方「+・−をつけずに」に丸。グラフ左端の−8に丸を置く → 光0の値が呼吸の量。光合成の量は「グラフの値＋呼吸」に直して書く。

📚 前提知識

  • 植物は光があってもなくても呼吸をして二酸化炭素を出す。光0では光合成が0なので、グラフの値 −8 がまるごと呼吸の分になる。
  • グラフのたて軸は「光合成で吸った量−呼吸で出した量」。だから、光合成で吸った量＝グラフの値＋呼吸の量。

🔍 こう読み解く

  1. ①：光の強さ0でグラフは −8 → 呼吸で出す量は8。光が3000になっても呼吸の量は同じ8。
  2. ②：光の強さ3000でグラフは +12（2500から先は水平）。
  3. 光合成で吸った量＝12＋8＝20。
答え：① 8　② 20
今回：① 8　② 20 ○。答案のグラフに3000のたて線が引いてあり、読む場所を紙に置いてから答えている。

M (2) 18時間を光500で育てたとき、残り6時間に必要な光 条件文・計算

👀 まず見るところ

【条件文】部品は「18時間を光の強さ500」「残りの6時間」と「枯れません」。「枯れない」を「1日の吸収量の合計が0以上」に直して書く → 500での不足分を、6時間で取り返す光の強さが決まる。

📚 前提知識

  • グラフの値がマイナスの間は、呼吸で出す方が多く、養分が減っていく。1日の合計がマイナスなら枯れる。ちょうど0なら減らないので枯れない。
  • グラフの値は1時間あたりの量として使う。時間をかければ、その時間の合計になる。

🔍 こう読み解く

  1. 光500のグラフの値は −4。18時間で −4×18＝−72（72の不足）。
  2. 残り6時間で72を取り返す → 1時間あたり 72÷6＝+12 が必要。
  3. グラフが +12 になるのは光の強さ2500。それより強くても +12 のままなので「2500以上」。
答え：2500
今回：2500 ○。答案の式は「1日の呼吸192 → 192−72＝120 → 120÷6＝20」。光合成の量でそろえる別の道すじで、20は(1)②と同じ値（光2500から先の光合成の量）になる。どちらの道でも答えは同じになる。

M (3) シイ・カシ・クスノキの森林と分布 素材文・選択＋地図

👀 まず見るところ

【素材文】設問は「落葉か常緑か」と「地図のどこか」。部品は手がかりの言葉「シイ・カシ・クスノキ」に丸 → 照葉樹林の木＝冬も葉を落とさない常緑、と決まる。照葉樹林はあたたかい西日本なので、地図はウ。

📚 前提知識

  • 日本の森林は気温で分かれ、南から 亜熱帯多雨林（沖縄など）→ 照葉樹林（関東から西）→ 夏緑樹林（中部の山地・東北から北海道）→ 針葉樹林（北海道の東部など）の順に並ぶ。
  • 照葉樹＝シイ・カシ・クスノキ。葉が厚く、表面が光る常緑広葉樹。夏緑樹＝ブナ・ミズナラ。冬に葉を落とす落葉広葉樹。針葉樹＝エゾマツ・トドマツ。

🔍 こう読み解く

  1. ①：シイ・カシ・クスノキは冬も葉をつけたままの木 → 常緑。
  2. ②：地図の4つを南から並べる。エ＝沖縄などの島、ウ＝関東から西の白い部分、イ＝北海道から東北・中部の山地の灰色の部分、ア＝北海道東部の黒い部分。
  3. 照葉樹林は南から2番目 → ウ。イは夏緑樹林（ブナ）、アは針葉樹林、エは亜熱帯多雨林。
答え：① 常緑　② ウ
今回：① 落葉　② イ ×。知識＝シイ・カシ・クスノキを落葉樹の側に入れた。①を落葉としたうえでイを選んだのなら、地図の読みは筋が通っている。直すのは木の名前の仕分け1つ。ノートに「シイ・カシ・クス→照葉（常緑）・西日本／ブナ・ミズナラ→夏緑（落葉）・東北など」と2行で書く。

M (4) バイオームを決める2つのもの 知識問題

降水量。バイオームは、ある地域の植物と、そこにすむ動物などをまとめたもの。気温と降水量の2つで決まる。雨が十分にあれば森林になり、どんな森林になるかは気温で決まる。日本は降水量が十分にあるので、(3)のように気温のちがいで森林が南北に分かれる。
答え：降水量

H (4)① 厚紙でかくした太陽光パネル 条件文・図に当てはめる

👀 まず見るところ

【条件文】部品は「光が当たっていないところは電流が流れません」。図の厚紙でかくれた部分に×を書きこむ（図に置く）→ 左の導線から右の導線まで、×を通らずに行ける道が残るほうが回る。

📚 前提知識

  • 図のパネルは、左と右に導線がついている。電流はパネルの中を左右の向きに通りぬける。
  • 回路は1か所でもとぎれると、全体に電流が流れない。

🔍 こう読み解く

  1. A：厚紙がパネルの左半分をかくしている。左の導線から入ったところがすべて×で、道がとぎれる → 回らない。
  2. B：厚紙がかくしているのは下側。上側は左はしから右はしまで光が当たっていて、道がつながっている → 回る。
答え：B
今回：B ○。

H (4)② 太陽光パネル2枚のつなぎ方と回転の速さ 条件文・直列と並列

👀 まず見るところ

【条件文】部品は「乾電池とは異なり」と「一定量の電流を流そうとする」。図に直して書く：C＝直列（1本道）、D＝並列（2本が合流）→ 1枚が流す量が決まっているなら、合流するDのほうが電流が多い。

📚 前提知識

  • 乾電池は直列で電流が強くなり、並列では変わらない。太陽光パネルは問題文の決まりのため、その逆になる。両方をセットで比べる。
  • 並列の回路では、分かれ道それぞれの電流が合流して、モーターに流れこむ。

🔍 こう読み解く

  1. C（直列）：2枚が1本道に並ぶ。1本道を流れる電流はどこも同じ量なので、流れるのは1枚分の一定量のまま。
  2. D（並列）：2枚がそれぞれ一定量を流し、モーターの手前で合流する → 約2倍の電流。
  3. 電流が多いほどプロペラは速く回る → D。
答え：D
今回：D ○。図の横に「それぞれの電気が一定」という内容のメモを書いてから選んでいる。問題文の決まりを図に置けている。

H まとめ 90点（10問中9問）

  • 取れた9問は、(1)③の「Cl＝−」、(3)の「4・32・16」、(4)②の「一定」と、部品を紙に置いてから決めた問題。この手順で合っている。
  • 落とした(1)①は、決まりの条件を当てはめるところ。本文の決まりは「水に溶けると」が条件。設問の物（結晶）がその条件に入っているかを先に確かめる。
  • 覚え直しは1つ。電気を通すのは粒が分かれて動けるとき。食塩の結晶と砂糖水は通さず、食塩水と塩酸は通す。
