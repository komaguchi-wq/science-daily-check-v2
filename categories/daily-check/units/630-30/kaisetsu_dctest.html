重心。ふりこの長さは糸や棒の長さではなく、支点からおもりの重心までの長さ。球のおもりなら球の中心までになる。おもりを2つつけた(4)では「2つを合わせた重心まで」になるので、この答えが(4)の入口になる。

DC1 (2) 10往復を測って10で割る理由 知識問題

1往復だけを測ると、ストップウォッチを押すタイミングのずれが、そのまま周期のずれになる。10往復をまとめて測って10で割れば、押すタイミングのずれも10分の1にうすまる。答えには「誤差」の語を入れて、「〜ため。」で終える。
答え：誤差の影響をなるべく小さくするため。
今回：「誤差をへらすため」○。

DC1 (3)D 周期2.8秒になるふりこの長さ 資料問題・表の決まりを使う

📚 前提知識

  • ふりこの長さが4倍（2×2）で周期は2倍、9倍（3×3）で周期は3倍。長さを2倍にしても周期は2倍にならない（50cmで1.4秒）。

🔍 こう読み解く

  1. 表から決まりを取る。25cm→1.0秒、100cm→2.0秒。長さ4倍で周期2倍。
  2. Dの周期2.8秒は、50cmのときの1.4秒のちょうど2倍。
  3. 周期2倍 → 長さは4倍 → 50×4＝200cm。
  4. 確かめ：100cmは表にすでにあり、周期は2.0秒。2.8秒にはならない。

今回：100 ×（赤で200と直してある）。知識＝周期が2倍なら長さは4倍。1.4秒→2.8秒の2倍に合わせて、長さも50cmの2倍にした形と読める。100cmは表にすでにあって2.0秒なので、書く前に表の同じ数と見比べる。

DC2 全体像 ホシムクドリの渡りの実験・地震計 4問

(1)は、鳥が何を手がかりに方向を決めるかを調べる実験。実験Ⅰ〜Ⅲは条件を1つずつ変えているので、Ⅰとくらべて結果が変わったかどうかを見る。

実験天気強い磁石時刻Tの向き
Ⅰ晴れなし南西
Ⅱくもりなし決まらない
Ⅲ晴れあり（N極が西）南西

天気を変えると結果が変わり、磁石を置いても変わらない。だから手がかりは太陽の光。②はこの結論を、鏡で光の向きを変えた図2に当てはめる。(2)は地震計の知識。

DC2 (1)① 何を最も優先して方向を決めるか 素材文・実験をくらべる

👀 まず見るところ

【まざり型→素材文】部品は実験Ⅱの「くもりの日」と実験Ⅲの「強い磁石」に丸。Ⅰとくらべて、くもりでは向きが決まらず、磁石を置いても南西のまま → 向きを決めているのは太陽の光と決まる。

📚 前提知識

  • 条件を1つだけ変えた実験どうしをくらべると、その条件が結果に関係するかどうかが分かる。
  • 渡り鳥は、太陽や星の位置、地球の磁気などを手がかりにするとされる。磁石を置いたのは、磁気を使っているかを確かめるため。

🔍 こう読み解く

  1. ⅠとⅡ：ちがいは天気だけ。晴れ→南西、くもり→決まらない。太陽が見えないと方向を決められない。
  2. ⅠとⅢ：ちがいは磁石だけ。磁石でまわりの磁力を変えても、晴れていれば南西のまま。磁力より太陽を先に使っている。
  3. 図1の矢印の名前は「太陽光の方向」。答えは図の言葉に合わせて「太陽の光の向き」。
答え：太陽の光の向き
今回：「日が差す方向」○。

DC2 (1)② 鏡で光の向きを変えたときの鳥の向き 資料問題・図1の関係を図2に移す

👀 まず見るところ

【まざり型→資料問題】部品は図1の「太陽光の方向」の矢印（南東から来る）と、鳥の向き「南西」。「光が来る方向から時計回りに90°」と直して書く → 図2で鏡に反射したあとの光が来る方向が分かれば、8方位が決まる。

📚 前提知識

  • ①より、この鳥は太陽の光の向きで方向を決める。図2の磁石は実験Ⅲと同じ「N極が西」の置き方なので、向きには関係しない。
  • 鏡に当たった光は、当たったときと同じ角度ではね返る。南北に立てた鏡なら、東西の向きだけが逆になる。

🔍 こう読み解く

  1. 図1：光は南東から来て北西へ進む。鳥は南西を向く。南東→南→南西で、光が来る方向から時計回りに90°。
  2. 図2：矢印の光を鏡までのばす。いちばん下の矢印は、左下（南西側）の窓のわきに南北に立つ鏡の東の面に当たる。北西へ進んでいた光は北東へ進む光になり、その窓から容器に入る。右下（南東側）の窓の前は鏡がふさいでいて、光はまっすぐ入れない。
  3. 鳥にとって、光は南西から来る。そこから時計回りに90° → 南西→西→北西。
  4. 確かめ：光の来る方向が南東→南西と90°回ったので、鳥の向きも南西→北西と同じだけ回る。
答え：北西
今回：西 ×。図2に線をかいて反射を追っている。部品の形を直さなかった＝図1の「光は南東から・鳥は南西」を「光が来る方向から時計回りに90°」と書いたあとが無い。次は図1の関係を1行書いてから、矢印を1本だけ鏡までのばす。

DC2 (1)③ 親鳥ではなく若鳥を用いた理由 記述

👀 まず見るところ

【まざり型→素材文】設問は「若鳥を用いた理由」。部品は問題文の「秋になると南西の向きに渡り」と「若鳥」。親鳥と若鳥のちがいを「渡りの経験がある／ない」と直して書く → 経験のない鳥で調べたい実験と決まる。

📚 前提知識

  • 実験では、調べたい条件（太陽の光・磁石）のほかに結果を変えるものが入らないようにする。親鳥は前に渡りをしているので、そのときの経験で方向を決めるかもしれない。

✍️ 答案の組み立て

  1. 部品A（親鳥を使わない理由）：親鳥は今までの渡りの経験から方向が分かる可能性がある。
  2. 部品B（若鳥を使う理由）：若鳥は渡りの経験がない。
  3. 出力の形：「親鳥は（A）ため、（B）若鳥を用いた。」理由を聞かれているので「〜ため」でつなぐ。
模範解答：親鳥は今までの渡りの経験から方向が分かる可能性があるため、渡りの経験がない若鳥を用いた。
今回：「経験について」×。中心の語「経験」は拾えている。部品の形を直さなかった＝だれに経験が「ある／ない」のか、あると何がこまるのかを文にしていない。部品A・Bの2つを「〜ため、〜を用いた。」の形に入れる。

DC2 (2) 地震計で上下のゆれを記録するもの 知識問題

ばね。地震計は、地面がゆれてもおもりだけはほとんど動かないことを利用して、動く地面とのずれを記録する。東西・南北のゆれは、ふりこのおもりが止まったままになる。ふりこは横にしかふれないので、上下のゆれはばねにつるしたおもりで記録する。
答え：ばね
今回：ばね ○。

DC2 まとめ 2/4 正解

  • 取れた：(1)①と(2)。実験Ⅰ〜Ⅲをくらべて「太陽の光」と決められている。
  • 落とした(1)②は、図1の関係を1行に直すのが先。「光が来る方向から時計回りに90°」と書けば、図2は光が来る方向を1つ決めるだけになる。
  • 落とした(1)③は、拾った「経験」を文にする。理由の記述は「だれが・どうだから・どうした」の形で書く。
