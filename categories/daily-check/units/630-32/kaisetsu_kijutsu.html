(1)〜(8)は文で説明する記述、(9)(10)は作図。分野は 電流計(1)／気体(2)／光と大気(3)／地層(4)／ヒトのからだ(5)／動物の卵(6)／月(7)(9)／電磁石(8)／クモ(10) と広いが、聞かれ方は「理由・方法と結果・どのようなものか・仕組み・役割・2つ」のどれか。設問の最後の言葉に丸をつけ、「〜から。」「〜化石のこと。」「〜仕組み。」「〜役割。」と文の終わり方を先に決めてから中身を考える。

記述⑫ (1) 電流計の－端子を5A端子からつなぐ理由 理由の記述・実験操作

👀 まず見るところ

【素材文】設問は「5A端子からつなぐ理由」。「から」に丸 → いちばん大きい端子から順に、という意味。答えの形は「電流が端子の値より大きいと、〜してしまうから。」で、小さい端子から始めたときに起こる困ったことを書く。

📚 前提知識

  • 電流計の－端子は 5A・500mA・50mA の3つ。それぞれ「この値まではかれる」という上限を表している。
  • 上限より大きい電流が流れると、針が目もりの右はしをこえてふりきれる。値が読めないうえ、電流計がこわれるもとになる。
  • 流れる電流の大きさが分からないうちは、上限がいちばん大きい5A端子から始め、針のふれが小さければ 500mA、50mA と順につなぎかえる。

✍️ 答案の組み立て

  1. 要素A（どんなとき）：流れる電流の値が、選んだ－端子の値よりも大きいとき。
  2. 要素B（何が起こる）：針がふりきれてしまう。「〜から。」で結ぶ。
模範解答：電流計に流れる電流の値が選択した－端子の値よりも大きいと、針がふりきれてしまうから。
コツ：「電流計がこわれるから。」だけでは、なぜこわれるかが抜けている。端子の値より大きい電流→針がふりきれるの2段で書く。

記述⑫ (2) 気体が水素だと確かめる方法と結果 方法と結果の記述

👀 まず見るところ

【素材文】設問は「確かめる方法と結果」。「方法」「結果」の2語に丸 → 答えの形は「〜を近づけると、〜する。」。何をするか1つ、何が起こるかを続けて書けば決まる。

📚 前提知識

  • 水素は燃える気体。空気とまざった水素に火を近づけると、ポンと音をたてて一気に燃える。
  • 水素が燃えると水ができる。その水が試験管の内側について白くくもる。
  • 酸素は「物を燃やすのを助ける気体」で、線香が炎を上げて燃える。水素は「自分が燃える気体」。この2つを取りちがえない。

✍️ 答案の組み立て

  1. 要素A（方法）：集めた気体に火のついた線香を近づける。
  2. 要素B（結果1）：ポンと音をたてて炎を出す。
  3. 要素C（結果2）：試験管の内側が白くくもる。
模範解答：集めた気体に火のついた線香を近づけると、ポンと音をたてて炎を出し、試験管の内側が白くくもる。
コツ：「火を近づける。」で止めると方法だけ。設問は「方法と結果」なので、音とくもりまで書いて結果にする。

記述⑫ (3) 夕日が赤く見える理由 理由の記述

👀 まず見るところ

【素材文】設問は「夕日が赤く見える理由」。「夕日」に丸 → 昼の太陽とのちがいは高さが低いこと。低い太陽の光は大気を長く通る、ここから書き始めて「赤い光が目に届くため。」で結ぶ。

📚 前提知識

  • 太陽の光にはいろいろな色の光がまざっている。大気を通るとき、青い光は散乱しやすく（空気のつぶに当たって散らばりやすく）、赤い光は散乱しにくい。
  • 夕方は太陽が低いので、光は大気の中をななめに進み、通る距離が長くなる。青い光は途中で散らばってしまい、散乱しにくい赤い光が多く残って目に届く。
  • 昼の空が青いのは、散乱した青い光が空全体から目に入るため。同じ「散乱」で説明できる。

✍️ 答案の組み立て

  1. 要素A（原因）：日光が大気を通る距離が長い。
  2. 要素B（結果）：散乱しにくい赤い光が目に届く。「〜ため。」で結ぶ。
模範解答：日光が大気を通る距離が長いので、散乱しにくい赤い光が目に届くため。
コツ：「赤い光が届くから。」だけでは、なぜ夕方だけ赤いのかが分からない。大気を通る距離が長いを前に置く。

記述⑫ (4) 示相化石とはどのようなものか 言葉の説明の記述

👀 まず見るところ

【素材文】設問は「示相化石とはどのようなものをいうか」。聞かれ方に丸 → 答えの形は「〜がわかる化石のこと。」。何がわかるか（環境か、時代か）を取りちがえなければ決まる。

📚 前提知識

  • 示相化石＝地層ができた当時の環境がわかる化石。限られた環境にしかすめない生物の化石が向いている。例：サンゴ（あたたかくて浅い、きれいな海）、シジミ（河口や湖）、アサリ（浅い海）。
  • 示準化石＝地層ができた時代がわかる化石。例：サンヨウチュウ、アンモナイト、ナウマンゾウ。
  • 区別のしかた：示「相」＝ようす（環境）、示「準」＝基準（時代）。

✍️ 答案の組み立て

  1. 要素A（いつの）：その地層がたい積した当時の。
  2. 要素B（何がわかる）：自然環境がわかる。「〜化石のこと。」で結ぶ。
模範解答：その地層がたい積した当時の自然環境がわかる化石のこと。
コツ：「時代がわかる化石」と書くと示準化石の説明になる。示相化石は環境。「たい積した当時の」も落とさない。

記述⑫ (5) 肺に空気が取り込まれる仕組み 仕組みの記述

👀 まず見るところ

【素材文】設問は「肺に空気が取り込まれる仕組み」。「取り込まれる」に丸 → 息を吸うときだけを書く。答えの形は「〜が動くことで、〜が大きくなり、〜が下がる仕組み。」で、動く物の名前を2つ出せば決まる。

📚 前提知識

  • 肺には筋肉が無く、自分ではふくらめない。まわりの横隔膜とろっ骨（の間の筋肉）が動いて、胸の中の広さを変えている。
  • 吸うとき：横隔膜が下がり、ろっ骨が上がる → 胸の容積が大きくなる → 肺の中の圧力が下がる → 外の空気が流れこむ。注射器のピストンを引くと中に空気が入るのと同じ。
  • はくときは逆で、横隔膜が上がり、ろっ骨が下がる。

✍️ 答案の組み立て

  1. 要素A（動き）：横隔膜が下がり、ろっ骨が上がる。
  2. 要素B（広さ）：胸の容積が大きくなる。
  3. 要素C（圧力）：肺の中の圧力が下がる。「〜仕組み。」で結ぶ。
模範解答：横隔膜が下がりろっ骨が上がることで、胸の容積が大きくなり、肺の中の圧力が下がる仕組み。
コツ：上下の向きを逆に書きやすい。吸うときは横隔膜は下・ろっ骨は上。「肺がふくらむから。」だけでは動く物の名前が抜けている。

記述⑫ (6) は虫類・鳥類の卵のからの役割 役割の記述

👀 まず見るところ

【素材文】設問は「は虫類や鳥類における」卵のからの「役割」。「は虫類や鳥類」に丸 → どちらも陸上に卵をうむなかま。陸上で卵に起こる困ったこと（かわく）が出れば、「〜を防ぐ役割。」の形で決まる。

📚 前提知識

  • 魚類・両生類は水中に卵をうむ。水の中ではかわく心配が無いので、卵にからは無い。
  • は虫類・鳥類は陸上に卵をうむ。陸上では中の水分がにげてかわいてしまうので、からで乾燥を防いでいる。

✍️ 答案の組み立て

  1. 要素A（何を）：乾燥を。
  2. 要素B（どうする）：防ぐ。聞かれ方に合わせて「〜役割。」で結ぶ。
模範解答：乾燥を防ぐ役割。
コツ：「卵を守る役割。」では何から守るのかが書けていない。陸上にうむことと結びつけて乾燥の1語を入れる。

記述⑫ (7) 月の公転周期と満ち欠けの周期がずれる理由 理由の記述

👀 まず見るところ

【素材文】設問は「公転周期と満ち欠けの周期がずれる理由」。2つの周期に丸 → 満ち欠けは月・地球・太陽の並び方で決まる。月が1周する間に地球も動くことを書き、「位置関係がもとと同じにならないから。」で結ぶ。

📚 前提知識

  • 月の公転周期は約27.3日、満ち欠けの周期（新月から次の新月まで）は約29.5日。満ち欠けのほうが約2日長い。
  • 月の形は太陽・地球・月の位置関係で決まる。新月は太陽―月―地球の順に並んだとき。
  • 月が地球のまわりを1周する間に、地球も太陽のまわりを公転して先へ進む。だから月が1周しても太陽―月―地球の並びにはもどらず、月はもう少し余分に回らないと次の新月にならない。

✍️ 答案の組み立て

  1. 要素A（原因）：月が公転する間に、地球も公転する。
  2. 要素B（結果）：一公転後の月と地球・太陽の位置関係がもとと同じにならない。「〜から。」で結ぶ。
模範解答：月が公転する間に、地球も公転するため、一公転後の月と地球・太陽の位置関係がもとと同じにならないから。
コツ：「地球が自転するから」と書きやすいが、ここで効くのは地球の公転。自転は1日の動きの話で、周期のずれとは関係しない。

記述⑫ (8) 電磁石の磁力を強くする方法2つ 方法の記述・2つ

👀 まず見るところ

【素材文】設問は「磁力を強くする方法を2つ」。「2つ」に丸 → 答えの形は「・〜する。」を2行。電磁石の強さを決めるもの（電流・巻き数・しん）から2つ選び、それぞれ「何をどうする」まで書く。

📚 前提知識

  • 電磁石の磁力は、コイルに流れる電流が強いほど、コイルの巻き数が多いほど強くなる。
  • コイルの中に軟鉄のしんを入れると、しんが磁石になって磁力が強まる。しんは太いほど強い。
  • 電流を強くするには、かん電池を直列につなぐ数を増やす。

✍️ 答案の組み立て

  1. 候補A：コイルに流れる電流を強くする。
  2. 候補B：コイルの巻き数を増やす。
  3. 候補C：コイルに軟鉄の太いしんを入れる。この3つから2つを、1つずつ行を分けて書く。
模範解答：・コイルに流れる電流を強くする。／・コイルの巻き数を増やす。／・コイルに軟鉄の太いしんを入れる。　などから2つ。
コツ：「電流」「巻き数」と単語だけ書いても方法にならない。強くする・増やすと、どちら向きに変えるかまで書く。

記述⑫ (9) 皆既月食のときの月・太陽・地球の図 作図

👀 まず見るところ

【条件文】部品は「皆既月食」と、条件「光の進むようす」に丸 → 並ぶ順は太陽―地球―月。円を3つ並べるだけでは足りず、太陽と地球のはしを結ぶ光の線を引いて、地球の影の中に月を置く。

📚 前提知識

  • 月食は太陽―地球―月の順に一直線に並び、月が地球の影に入る現象（満月のとき）。日食は太陽―月―地球の順で、まん中に来る天体がちがう。
  • 太陽は地球より大きいので、地球の後ろにできるこい影は先へ行くほどせまくなる。月がこの影に全部入ると皆既月食、一部だけ入ると部分月食。
  • 大きさの順は 太陽＞地球＞月。

✍️ 答案の組み立て

  1. 左に大きな円（太陽）、右寄りに中くらいの円（地球）、そのさらに右に小さな円（月）を一直線に描き、名前を書く。
  2. 太陽の上はしと地球の上はし、太陽の下はしと地球の下はしを結ぶ2本の直線を引き、地球の後ろまでのばす。この2本にはさまれた、せまくなっていく所が地球のこい影。
  3. 太陽の上はしと地球の下はし、太陽の下はしと地球の上はしを結ぶ線も2本引く。太陽と地球の間で交わり、地球の後ろでは広がっていく。
  4. 月は、2でかいたせまくなる2本の線の内側に全部入るように置く。
模範解答：別紙の図のとおり。要点＝太陽・地球・月をこの順に一直線に並べ（太陽がいちばん大きく、月がいちばん小さい）、太陽のはしと地球のはしを結ぶ直線を4本（同じ側どうし2本・反対側どうし2本）引き、同じ側どうしを結んだ2本にはさまれた地球の後ろの影の中に月を置く。
コツ：地球と月の順を逆にすると日食の図になる。月食は地球がまん中。月は線の外にはみ出さないように小さく描く。

記述⑫ (10) クモのあしをかきいれる 作図

👀 まず見るところ

【資料問題】図の正体を1行＝「クモを背中側から見た図。前の小さい部分（目がある）が頭胸部、後ろの大きい部分が腹部」。設問は「あしをかきいれなさい」に丸 → 決めるのは本数（8本）とつけ根の場所（頭胸部）の2つ。

📚 前提知識

  • クモは昆虫ではない。からだは頭胸部と腹部の2つに分かれ、あしは8本（4対）。
  • あしは8本とも頭胸部から出る。腹部からは1本も出ない。
  • 昆虫は 頭・胸・腹の3つで、あしは6本とも胸から出る。「あしは胸のある部分から」という点はクモも昆虫も同じ。

✍️ 答案の組み立て

  1. 前の小さい部分（頭胸部）の左右から4本ずつ、合わせて8本かく。図に初めからかかれている頭の先の小さな2本は、この8本に数えない（別紙もこの2本とは別に8本かいている）。
  2. つけ根はすべて頭胸部。後ろの大きい腹部にはつけない。
  3. 前の2対は前向き、後ろの2対は後ろ向きに広げ、あしは途中で折れ曲がった形（節がある）にする。
模範解答：別紙の図のとおり。要点＝あしは左右4本ずつの計8本・すべて前の小さい部分（頭胸部）から出る・腹部からは出ない・前の2対は前向き、後ろの2対は後ろ向きで、途中で折れ曲がっている。
コツ：昆虫と同じ6本にしたり、腹部からあしを出したりしやすい。かき終えたら本数を数え、つけ根の場所を見直す。
