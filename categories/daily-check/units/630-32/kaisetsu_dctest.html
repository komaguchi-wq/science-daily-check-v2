DC1 全体像 月・金星・木星の位置 8問

8問とも、入口は問題文の「日の出前の東の空」。この言葉を、図2・図4の地球の上の「明け方の地点」に直して書きこめば、月も金星も木星も同じやり方で決まる。

書きこむ手順は1つ。太陽に向いた側が「昼」。そこから自転の矢印の向きに、昼 → 夕方 → 真夜中 → 明け方と4つの印をつける。その地点に立つと、自転で進んでいく向きが東になる。

DC1 (1) 明け方の東の空の細い月の形 条件文・作図

👀 まず見るところ

【条件文】部品は「日の出前の東の空」と「細い月」に丸。日の出前なので、図1の東の地平線の下に太陽を描きこむ（直して書く）→ 月の光る側は太陽のある左下と決まる。

📚 前提知識

  • 月は太陽の光が当たっている側だけが光る。だから光っている側に太陽がある。
  • 明け方の東の空に見える細い月は、新月の少し前の月（別紙では「二十七日の月」）。

🔍 こう読み解く

  1. 図1は左が東、右が南東。太陽はこれから東からのぼるので、月から見て左下にある。
  2. 光るのは左下の細い部分だけ。残りの右上の広い部分に斜線をかく。
  3. 設問の「暗い部分を斜線で」に丸をつけておく。光る側に斜線をかくと逆になる。
答え：左下が細く光り、右上の広い部分に斜線（別紙の図のとおり）
今回：○。左下を細く残して右上に斜線がかけている。「日の出」にも丸がついていた。

DC1 (2) 図2での月の位置 条件文・図に置く

👀 まず見るところ

【条件文】部品は「日の出前の東の空」と「矢印は地球の自転の向き」。図2の地球に「明け方」の地点を書きこむ（直して書く）→ 地球の上側。そこから東に見える月が答え。

📚 前提知識

  • 太陽と同じ方向にあるアが新月、反対側のオが満月。細い月は新月のとなりのイかク。
  • 地球の上の人にとって、自転で進んでいく向きが東。

🔍 こう読み解く

  1. 太陽は左。地球の左が昼。矢印は反時計回りなので、下が夕方、右が真夜中、上が明け方。
  2. 明け方の地点は、これから太陽のある左へ進む。左が東。
  3. 地球の上の地点から見て左（東）にある細い月はク。イは夕方の西の空に見える月なので合わない。
答え：ク
今回：ク ○。

DC1 (3) 次の日の同じ時刻の月 条件文・変化を選ぶ

👀 まず見るところ

【条件文】部品は「次の日」と「同じ時刻」に丸。「次の日」は図2で月をクからアへ少し進める矢印に直して書く → 新月に近づくので形は細く、位置は太陽に近い東の低い所になる。

📚 前提知識

  • 月は地球のまわりを、地球の自転と同じ向き（図2では反時計回り）に回る。ク → ア → イ の順に進む。
  • 月の出は1日に約48分ずつおそくなる（別紙）。同じ時刻に見ると、前の日より東に下がった位置にいる。

🔍 こう読み解く

  1. ①形：クの次は新月のア。新月に近づくほど光る部分はやせる → イ（小さくなっていた）。
  2. ②位置：月の出がおそくなるぶん、同じ時刻にはまだのぼりきっていない → イ（低いところ）。
  3. ①と②は同じ理由から出る。「太陽の方向に近づいた」と1行書けば、細くなることと低くなることがそろって決まる。
答え：① イ　② イ
今回：①ア ②イ ×（①②がそろって1問）。②は合っていて、①の形だけが逆。部品の形を直さなかった＝「次の日」を図2の ク→ア の矢印にしなかった。図2にはキからクへの矢印がかいてあったので、次はその矢印をアまでのばし、新月に向かうことを確かめてから選ぶ。

DC1 (4) およそ3週間後の月の位置 条件文・図に置く

👀 まず見るところ

【条件文】部品は「およそ3週間後」。図2の8か所で数えられるように「1週間＝2つ分」に直して書く → 3週間は6つ分。クから反時計回りに6つ進めた所が答え。

📚 前提知識

  • 月の満ち欠けは約29.5日で1周。新月（ア）から上弦（ウ）までが約1週間なので、1週間で図2の2つ分進む。

🔍 こう読み解く

  1. 進む向きは (3) と同じ反時計回り。
  2. クから6つ：ア → イ → ウ → エ → オ → カ。
  3. 確かめ：カは満月（オ）を過ぎて下弦（キ）になる前の月。満月の少しあとの、右側が欠けはじめた月にあたる。
答え：カ
今回：カ ○。

DC1 (5) カの月が見やすい時刻と方角 条件文・図から方角を決める

👀 まず見るところ

【条件文】部品は選択肢の「真夜中」「明け方」「夕方」。図2の地球に時刻の地点を書きこみ（直して書く）、その地点からカが南より東か西かを見る → 真夜中の地点からは南東。

📚 前提知識

  • 図2の地球のある地点に立つと、その地点の真上の方向が南の空。そこより自転で進む側が東、通りすぎた側が西。
  • 満月（オ）は真夜中に南中、下弦（キ）は明け方に南中する。その間のカは午前3時ごろに南中する。

🔍 こう読み解く

  1. 真夜中の地点は地球の右。真上（南）はオの方向。自転で進む向きは図の上なので、上側が東。
  2. カはオより上にある → 真夜中には南より東＝南東。南中の3時間前なので、まだ東寄りにいる、と考えても同じ。
  3. ほかも確かめる：イ 明け方は南中を過ぎて南西 → ×／ウ 夕方はまだのぼっていない → ×／エ 真夜中は南西ではなく南東 → ×。
答え：ア
今回：エ ×。時刻の「真夜中」は合っていて、方角の東西が逆。部品の形を直さなかった＝真夜中の地点を図2に書きこまず、東がどちら側かを決めなかった。次は地球の右に「真夜中」、上向きに「東」と書いてからカを見る。
コツ：月が南中より前なら東寄り、南中を過ぎたら西寄り。南中の時刻（満月＝真夜中、下弦＝明け方）と今の時刻をくらべれば、東西は決まる。

DC1 (6)金星・(6)木星 図4での金星と木星の位置 条件文・図に置く

👀 まず見るところ

【条件文】部品は「日の出前」「天体望遠鏡で見ると図3」「南東側は木星」。「日の出前」は図4の地球の右側＝明け方の地点に直して書く → 金星も木星も図の右側にあり、形と方角で1つにしぼれる。

📚 前提知識

  • 金星は、地球に近い側にあるときは大きく欠けて見え、太陽の向こう側に回るほど丸に近く見える。
  • 天体望遠鏡では上下左右が逆に見える（別紙）。図3は右上が光っているので、実際に光っているのは左下＝これからのぼる太陽のある側。「どれだけ欠けているか」は逆にしても変わらない。

🔍 こう読み解く

  1. 図4は太陽が上。地球の上が昼、矢印は反時計回りなので、左が夕方、下が真夜中、右が明け方。明け方に見えるのは図の右側の星だけ → 金星はウかエ、木星はキ。左側のア・イ・オは夕方に見える位置。
  2. 金星：図3は半分より広く光っている。地球に近いウなら半分より大きく欠けて見えるので合わない。太陽の向こう側寄りのエ。
  3. 木星：明け方の地点から見て、東は太陽のある上の向き、南は真上にあたる右の向き。その間の南東にあるのはキ。クは太陽と同じ方向、カは真夜中に南に見える位置なので合わない。
答え：金星 エ　木星 キ
今回：金星ウ ×　木星オ ×。金星は「明け方の側（右）」までは合っている。部品の形を直さなかった＝図3の「半分より広く光る」を「太陽の向こう側寄り」に直さなかった。木星のオは夕方の側。金星と同じく、地球の右に「明け方」と書いてから右側の中でさがす。

DC1 (7) 地球と金星が同じ位置関係にもどる日数 条件文・計算

👀 まず見るところ

【条件文】部品は「360日」「225日」。どちらも「1日に何度進むか」に直して書く（360÷日数）→ 進む角度の差で360度を割れば、同じ位置関係にもどる日数が出る。

📚 前提知識

  • 内側を回る金星のほうが速い。金星が地球よりちょうど1周（360度）多く回ったとき、太陽・金星・地球の並び方が元にもどる。算数の旅人算（追いつき）と同じ形。

🔍 こう読み解く

  1. 地球：360÷360＝1日に1度。金星：360÷225＝1日に1.6度。
  2. 1日に開く差は 1.6−1＝0.6度。
  3. 360÷0.6＝600日。
答え：600日
今回：600 ○。

DC2 (1)①動脈・(1)①静脈 酸素ヘモグロビンの割合を読む まざり型・グラフの読み取り

👀 まず見るところ

【まざり型→資料問題】グラフの正体を1行：「横＝血液中の酸素量（mmHg）、縦＝酸素ヘモグロビンの割合（%）」。部品は「動脈100mmHg」「静脈30mmHg」→ 横軸に印をつけ、上にたどって縦軸を読むだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 動脈の血液は肺で酸素を受け取った直後なので割合が高い。静脈の血液は組織に酸素を渡したあとなので低い。

🔍 こう読み解く

  1. 目盛りを確かめる。横軸は50と100の間が5マスなので1マス10mmHg。縦軸は20ごとに数字があり、その間が2マスなので1マス10%。
  2. 横100の線を上にたどる → 曲線は90%。
  3. 横30の線を上にたどる → 曲線は20%。
答え：動脈 90%　静脈 20%
自分で解くときのチェック：読んだ2点（100と90、30と20）をグラフに点で打っておく。②でそのまま使う。

DC2 (1)② 酸素を渡した酸素ヘモグロビンの割合 まざり型・計算

👀 まず見るところ

【まざり型→条件文】部品は「組織に運ばれた酸素ヘモグロビンのうち」と「小数第1位を四捨五入」に丸。「〜のうち」は÷90（運ばれた量で割る）に直して書く → 100で割らないと決まる。

📚 前提知識

  • 動脈で90%あった酸素ヘモグロビンが、静脈では20%に減っている。減った分が、組織に酸素を渡した酸素ヘモグロビン。

🔍 こう読み解く

  1. 渡した分：90−20＝70。
  2. もとにする量は、組織に運ばれた酸素ヘモグロビンの90。70÷90×100＝77.7…
  3. 小数第1位を四捨五入して78%。70%と答えると、全ヘモグロビンをもとにした割合になってしまう。
答え：78%
自分で解くときのチェック：割り算の前に「何のうち？」を式の横に書く。ここでは「90のうち70」。

DC2 (2) ガリレオ衛星 知識問題

イオ・エウロパ・ガニメデ・カリストの4つ。ガリレオ・ガリレイが望遠鏡で見つけた木星の衛星。残りは別の天体：タイタンは土星の衛星、フォボスとダイモスは火星の衛星、イトカワは「はやぶさ」、リュウグウは「はやぶさ2」が探査した小惑星。記号で4つ答える。
答え：ア・ウ・エ・オ
