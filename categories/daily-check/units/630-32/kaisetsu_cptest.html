👀 まず見るところ

【資料問題】正体を1行「水酸化ナトリウム水溶液40cm³は同じ・塩酸だけ増やす・残った固体g」。固体は10cm³ごとに0.2gずつ増える → 増え方が止まる所が、ちょうど中和した所と決まる。

  3. X（30cm³）＝1.8。Y（50cm³）も、あまった塩酸は何も残さないので1.8のまま。
答え：X 1.8　Y 1.8
コツ：表の下に「40cm³＋30cm³でちょうど → 食塩1.8g」と書いてから(2)へ進む。(3)(4)はこの1行を使う。

L (6) 豆電球の光を1点に集める 二択・レンズとの距離

👀 まず見るところ

【条件文】部品は「図1の状態から」と「1点に集める」。図1は豆電球が焦点にある状態。光が集まるのは光源が焦点より遠いときだけ → 遠ざける。

📚 前提知識

  • 光源が焦点にあると平行、焦点より遠いと集まり、近いと広がる。レンズが光を曲げる強さは同じなので、光源がはなれて入ってくる光の広がりが小さくなるほど、内側へ集まりやすくなる。

🔍 こう読み解く

  1. 今は平行＝集まる・広がるのちょうど境目。
  2. 近づけると、レンズに入る光の広がりが大きくなり、曲げきれずに広がったまま出ていく。
  3. 遠ざけると、入る光の広がりが小さくなり、レンズを出たあと内側へ向かって1点に集まる。
答え：遠ざける

L (7) スクリーンに像がうつるろうそくの位置 選択・すべて選ぶ

👀 まず見るところ

【条件文】部品は「スクリーンに像をうつす」と答え方の「すべて選びなさい」に丸。像がうつる＝光が1点に集まる、に直す → (6)と同じ分け方で、ア・イ・ウ全部に○×をつける。

📚 前提知識

  • スクリーンにうつる像（実像）は、ろうそくの1点から出た光がレンズを通ってもう一度1点に集まった所にできる。

🔍 こう読み解く

  1. ア 焦点距離より近い → 光は広がる。集まらないのでうつらない → ×。
  2. ウ 焦点距離と同じ → (5)のとおり平行光線。集まらない → ×。
  3. イ 焦点距離より遠い → 光が1点に集まり、そこにスクリーンを置けばうつる → ○。
  4. 「すべて」と聞かれているが、○はイの1つだけ。

L (8) 厚い凸レンズに変える 二択2つ・焦点距離と像の位置

👀 まず見るところ

【条件文】部品は(7)と変わった「厚いものに変える」。厚い＝光を曲げる力が強い、に直して書く → 光が手前で集まるので、①焦点距離も②像の位置もレンズ側へ寄る。

📚 前提知識

  • 凸レンズはふくらみが大きい（厚い）ほど光を大きく曲げる。大きく曲がった光はレンズに近い所で集まるので、焦点距離は短い。

🔍 こう読み解く

  1. ①：厚いレンズ → 光を強く曲げる → 焦点がレンズに近づく → 焦点距離は短くなる。
  2. ②：ろうそくの位置は変えていない。同じ光がもとのレンズより強く曲げられるので、集まる点（像）もレンズに近づく。
  3. 像のできる所にスクリーンを合わせる → スクリーンをレンズに近づける。
答え：① 短く　② 近づける
コツ：①と②は別々に考えず、「強く曲がる → 手前で集まる」の1本で両方決める。

L (9) 近視用の眼鏡のレンズ 知識問題

凹レンズ。近視は、遠くのものからの光が網膜より手前で集まってしまう状態。凹レンズで光を少し広げてから目に入れると、集まる位置がおくにずれて網膜に合う。遠視用と虫めがねは凸レンズ、と両方セットで覚える。
答え：凹

L (10) 自転車のペダルと後輪の回転数 図の数値を選ぶ・計算

👀 まず見るところ

【資料問題】図3の長さは4つ（20cm・10cm・5cm・30cm）。チェーンがかかっているのは「前のギア10cm」と「うしろのギア5cm」だけ → 回転数を決めるのはこの2つ。聞かれているのは「何回転」で、進むきょりではない。

📚 前提知識

  • ペダルと前のギア、うしろのギアと後輪は、それぞれ同じ軸についていていっしょに同じ回数だけ回る。
  • チェーンでつながった2つのギアは、チェーンの動く長さが同じ。だから回転数は半径の逆の比になる（小さいギアほど多く回る）。

🔍 こう読み解く

  1. ペダル6回転 → 前のギアも6回転。
  2. 半径は 前：うしろ＝10：5＝2：1 → 回転数は逆の 1：2。うしろのギアは 6×2＝12回転。
  3. 後輪はうしろのギアといっしょに回るので、後輪も12回転。
答え：12回転
コツ：ペダルの長さ20cmは「こぐ力」、後輪の半径30cmは「進むきょり」を聞かれたときに使う数。回転数の問題では使わない。

👀 まず見るところ

【資料問題】部品は表の正体「塩酸40cm³は同じ・加える水溶液10cm³ごとの固体g」。となりどうしの差を表の下に書くと 0.6・0.6・0.5・0.4。最後の0.4が、中和が終わったあとにふえた水酸化ナトリウムだけの重さと決まる。
