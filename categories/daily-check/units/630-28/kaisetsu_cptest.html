L (1) 食塩水を加熱して試験管に集まるもの 条件文・図＋選択

👀 まず見るところ

【まざり型→条件文】部品は「食塩水を加熱」と、図でガラス管の先が「試験管」に入っていること。フラスコから出ていくのは水蒸気だけ、と図に矢印で置く → 試験管に集まるのは水蒸気が冷えたもの＝水、と決まる。

📚 前提知識

  • 食塩水を加熱すると水だけが水蒸気になって出ていき、食塩はフラスコに残る（食塩は100℃では気体にならない）。この分け方が蒸留。
  • ガラス管を通るうちに水蒸気は冷えて水にもどる。だから試験管に集まるのは液体の水。

🔍 こう読み解く

  1. 出ていく中身を決める：気体になれるのは水だけ → ガラス管を通るのは水蒸気。
  2. 試験管の中で冷えて水にもどる → 食塩は入っていないので「こい／うすい食塩水」ではなく水。
答え：ウ

L (2) 沸騰石の穴に入っているもの 知識問題

空気。沸騰石の小さな穴にある空気が、加熱すると小さな泡になって出てくる。この泡が「泡のはじまり」になるので、液体の中から泡が出やすくなり、急に大きな泡がふき上がる突沸をおさえられる。穴の空気＝泡の種、と結びつけて覚える。
答え：空気

L (3) 火を消したときガラス管で起こること 条件文・図＋選択

👀 まず見るところ

【条件文】部品は「(1)のあと、そのまま火を消す」と、図で「ガラス管の先が水の中」にあること。「火を消す→フラスコが冷える」と直して書く → 中の水蒸気が水にもどって体積が減り、水が吸い込まれる側に決まる。

📚 前提知識

  • 水蒸気は水にもどると体積が大きく減る。フラスコの中がすかすかになる分、外から押しこまれる。
  • だからこの実験では、火を消す前にガラス管の先を水から出しておく。冷えた水がフラスコに逆流すると、フラスコが割れることがある。

🔍 こう読み解く

  1. 火を消す → フラスコの中の水蒸気が冷えて水にもどる → 中の気体が減る。
  2. ガラス管の先は水の中なので、減った分を埋めるように水が吸い込まれてくる。泡が吹き出すのは加熱している間の話。
答え：イ
コツ：「加熱中＝出ていく（泡）」「冷えると＝入ってくる（逆流）」の2つをセットで持つ。

L (4) 富士山の山頂での気圧と沸点 知識問題

① 低い、② 低く。高いところほど上にある空気が少ないので気圧が低い。沸騰は、液体の中からできる泡がまわりの空気の押す力に勝ったとき起こるので、気圧が低いほど低い温度で沸騰する。山の上で米がうまく炊けないのはこのため。逆に圧力なべは気圧を高くして沸点を100℃より上げる。
答え：① 低い　② 低く

L (5) 温度計に水が使われない理由 素材文・空らん＋選択

👀 まず見るところ

【素材文】設問は空らんの温度と二択。部品は「最も密度が大きくなる」と「それより温度が低くても高くても」に丸 → 密度が最大＝体積が最小の温度だから、そこからどちらへ動いても体積は増える、と決まる。

📚 前提知識

  • 水は4℃で体積が最小（密度が最大）。4℃から冷やしても温めても、体積は増える。氷が水に浮くのも、0℃に近づくほど水がふくらむのと同じ流れ。
  • 灯油や水銀は、温度が上がれば体積が増え、下がれば減る、と一方向に変わる。だから目盛りがつけられる。

🔍 こう読み解く

  1. ①：密度が最も大きい温度 → 4℃。
  2. ②：4℃が「いちばん縮んだ状態」なので、低くても高くても体積は増える。たとえば2℃と6℃で体積が同じになり、どちらの温度か目盛りで区別できない。
答え：① 4℃　② 増える

L (6) 湿度表と乾球・湿球の温度差 資料問題・表＋選択

👀 まず見るところ

【資料問題】部品は表の正体「乾球の温度と温度差から湿度（%）を読む表」と聞かれ方「湿度が高いほど、差は」。表を横に1行たどる → 差0.0で100、差が大きいほど数字が下がる。湿度が高いのは差が小さい側、と表だけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 湿球はガーゼの水が蒸発するときに熱をうばわれて温度が下がる。空気がしめっていると蒸発しにくく、下がり方が小さい。湿度100%なら蒸発せず、乾球と同じ温度（差0）。

🔍 こう読み解く

  1. 乾球21℃の行：差0.0→100、1.0→91、2.0→82、3.0→73、4.0→65。差が増えるほど湿度は下がる。
  2. 裏返すと、湿度が高いほど差は小さくなる。どの行で見ても同じ向き。
答え：小さく

L (7) 空気が上昇したときの飽和水蒸気量 素材文・選択

👀 まず見るところ

【素材文】設問は二択。部品は「上昇して気温が下がる」と「飽和水蒸気量」に丸 → 飽和水蒸気量は気温で決まる量なので、気温が下がれば小さくなる、と決まる。

📚 前提知識

  • 飽和水蒸気量＝空気1m³が含むことのできる水蒸気の最大量。気温が高いほど大きく、低いほど小さい。
  • 上昇した空気は、まわりの気圧が下がってふくらみ、温度が下がる。

🔍 こう読み解く

  1. 気温が下がる → 含める量（飽和水蒸気量）が小さくなる。
  2. 入りきらなくなった水蒸気が水滴に変わる＝雲。文の後半「水滴に変わり雲ができやすく」ともつながる。
答え：小さく

L (8) 台風の接近で海水面が上がる現象 知識問題

高潮。台風の中心は気圧が低いので海面が吸い上げられ、さらに強い風が海水を岸へ吹き寄せて、海水面がふだんより高くなる。高潮＝台風（気圧と風）、津波＝地震、と原因で区別して覚える。
答え：高潮

L (9) 低気圧の空気の流れを表した図 資料問題・図の選択

👀 まず見るところ

【資料問題】部品は聞かれ方「低気圧」と、4つの図のちがい「中心の矢印が上か下か・まわりの矢印が中心へ向かうか外へ向かうか」。低気圧＝吹きこんで上昇、と書いてから、2つの条件が両方そろう図を選ぶ。

📚 前提知識

  • 低気圧はまわりより気圧が低いので、まわりから空気が集まり（吹きこみ）、行き場を失って上昇する。上昇した空気は冷えて雲になり、天気が悪い。
  • 高気圧はその逆。中心で下降し、まわりへ吹き出す。雲ができにくく晴れ。

🔍 こう読み解く

  1. 中心の矢印が上向きの図 → イとウ。下向きのアとエは外す。
  2. まわりの矢印が中心へ向かうのはウ。イは上昇しながら外へ吹き出していて、つじつまが合わない。
  3. 確かめ：アは下降＋吹き出し＝高気圧の図。エは下降＋吹きこみで、空気がたまる一方になるので起こらない。
答え：ウ

L (10) 台風の北西にいる観測者の風向き 資料問題・図＋漢字1字

👀 まず見るところ

【資料問題】部品は図の正体「観測者は台風の中心の北西（方位記号は北が上）」と聞かれ方「風向き＝風が吹いてくる方角・漢字1字」。中心のまわりに反時計回りの矢印を描き、観測者の位置の矢印がどちらから来ているかを読む。

📚 前提知識

  • 台風は発達した低気圧なので、風は中心に向かって反時計回りに吹きこむ（(9)のウの図）。
  • 風向は「吹いてくる方角」。北風＝北から南へ吹く風。

🔍 こう読み解く

  1. 中心を囲む反時計回りの円を描く。北側では東→西、西側では北→南に風が流れる。
  2. 観測者はその間の北西。円をなぞるだけなら北東寄りから来る風だが、中心へ吹きこむ分を足すと、ほぼ北から南へ向かう風になる。
  3. 漢字1字なので「北東」ではなく北。
答え：北
コツ：台風の問題は、中心に「反時計回り＋内向き」の矢印を描いてから観測者の位置に指を置く。頭の中だけで回さない。

M (1) 実験を始めたときの氷の温度 資料問題・グラフの目もり

👀 まず見るところ

【資料問題】資料の正体は「氷に一定の熱を加え続けたときの温度変化」。部品は縦の目もり＝0から100まで5マス。正体の下に「1マス＝20℃」と1行書く → Aは0の2マス下と決まる。

📚 前提知識（あれば答え合わせに使う）

  • 氷は0℃になるまで温度が上がり、0℃でとけている間は温度が止まる。だから最初の平らな線は0℃、2つ目の平らな線は100℃（ふっとう）。

🔍 こう読み解く

  1. 0と100の間を数えると5マス → 1マス＝100÷5＝20℃。
  2. Aは0の線から2マス下 → 0−20×2＝−40℃。マイナスを忘れずに書く。
答え：−40℃
今回：−40℃ ○。

M (2) 実験開始からすべてとかすまでの熱 条件文・熱量の計算

👀 まず見るところ

【まざり型→条件文】部品は「実験開始から」と「すべてとかすまで」に丸。開始＝A（−40℃）、とかし終わり＝0℃の平らな線の右端。つまり氷を−40℃→0℃にあたためる分ととかす分の2つを足す。

📚 前提知識

  • 水1gを1℃上げる熱が1カロリー。氷1gを1℃上げるには0.5カロリー（水の半分）、氷1gをとかすには80カロリー。
  • 熱を一定の速さで加えているので、グラフの横のマス数は熱の量に比例する。

🔍 こう読み解く

  1. あたためる分：100g×40℃×0.5＝2000カロリー。
  2. とかす分：100g×80＝8000カロリー。
  3. 合計 2000＋8000＝10000カロリー。
  4. 検算はグラフで。水が0→100℃になる5マスは100×100＝10000カロリーなので1マス＝2000カロリー。Aから0℃までが1マス（2000）、とけている間が4マス（8000）で、足すと同じ10000になる。
答え：10000カロリー
今回：8000カロリー ×。部品を拾えなかった＝「実験開始から」に丸がなく、とかす分の8000だけで止まった。開始点Aは−40℃なので、0℃まで上げる2000が先に要る。次は「開始から」を見たらAの温度を書く。

M (3) 氷と食塩を3：1で混ぜたときの温度 知識問題

−21℃。氷に食塩を混ぜると、氷がとけるときにまわりから熱をうばい、0℃よりずっと低くなる（寒剤）。混ぜる割合が氷3：食塩1のとき、最も下がって−21℃。マイナスをつけて答える。
答え：−21℃
今回：−10.5℃ ×。知識。数字が21の半分になっていて、割合と温度をごちゃ混ぜにした形。「3：1で−21℃」を1組で覚える。

M (4) 水蒸気の体積変化で発電しているもの 知識問題

ア（火力）とエ（原子力）。どちらも燃料や核の熱で水をふっとうさせ、水蒸気の力でタービンを回す。水が水蒸気になると体積が約1700倍にふくらむ力を使っている。水力は水の落ちる力、風力は風、太陽光は光をそのまま電気に変えるので、水蒸気は関係ない。「すべて選ぶ」なので2つ書く。
答え：ア・エ
今回：ア・エ ○。

M (5) 雲ができたB地点の湿度 条件文・湿度

👀 まず見るところ

【まざり型→条件文】部品は「B地点からC地点の間で雲ができた」に丸。雲ができる＝空気中の水蒸気がこれ以上入りきらない状態（飽和）なので、雲ができ始めた地点の湿度は100%と決まる。計算はいらない。

📚 前提知識

🔍 こう読み解く

  1. Bは雲ができ始めた高さ＝空気が飽和に達した点 → 湿度100%。
  2. 数字（800m・2000m）はこの問では使わない。(6)で使う。
答え：100%
今回：100% ○。

M (6) D地点の気温 条件文・フェーン現象の計算

👀 まず見るところ

【条件文】部品は「100mにつき1℃」「雲ができると100mにつき0.5℃」「A地点が30℃」の3つ。図に直して書く：A＝30℃、B（800m）、C（2000m）、D（0m）の4か所に気温のらんを作り、上りは−、下りは＋で順にうめる。

📚 前提知識

  • 雲のない空気は100mで1℃、雲ができている間は100mで0.5℃しか変わらない（雲ができるときに熱が出るから。理由は(7)）。
  • 山をこえて下りるときは雲が消えているので、下りはずっと100mで1℃上がる。上りより下りのほうが変化が大きいので、Dの気温はAより高くなる。これがフェーン現象。

🔍 こう読み解く

  1. A→B：800m上る、雲なし → 30−8＝22℃。
  2. B→C：2000−800＝1200m上る、雲あり → 22−1200÷100×0.5＝22−6＝16℃。
  3. C→D：2000m下る、雲なし → 16＋20＝36℃。
答え：36℃
今回：38℃ ×。計算。図にはA 30・B 22・C 16まで正しく書けていた。最後の下り2000m×1℃＝20を足して36なのに、38になっている。4か所目のDのらんも先に作っておき、C→Dの「2000m・雲なし・＋20」を1行書いてから足す。

M (7) 雲ができると温度が下がりにくくなる理由 素材文・理由の選択

👀 まず見るところ

【素材文】設問は「雲ができると温度が下がりにくくなる理由」。部品は、雲ができる＝水蒸気が水てきになる＝「凝縮」に丸。凝縮のときに熱が「出る」のか「うばわれる」のかで、ウとエのどちらかに決まる。

📚 前提知識

  • 水が水蒸気になる（気化）ときはまわりから熱をうばう（打ち水がすずしい理由）。逆に、水蒸気が水になる（凝縮）ときはまわりに熱を出す。

🔍 こう読み解く

  1. 雲ができる＝凝縮なので、ウ（気化）は向きが逆。ア・イは「熱を伝えやすい・にくい」の話で、温度が下がりにくくなる理由にならない。
  2. 凝縮で出た熱が空気をあたためるので、100mで1℃の冷え方が0.5℃にゆるむ → エ。
答え：エ
今回：エ ○。

M (8) 暴風域の風速と、図の中の暴風域 資料問題＋知識・台風の進路予想図

👀 まず見るところ

【資料問題】資料の正体は「台風の進路予想図」。部品は、いま台風がいる×印のまわりの円。×を中心にした円が2つあり、内側の色つきがD、外側がE。暴風域は強風域より内側なので、Dと決まる。①の数字は知識。

📚 前提知識

  • 暴風域＝風速25m/秒以上の範囲、強風域＝風速15m/秒以上の範囲。強いほうが中心に近く、せまい。
  • 進路予想図の円は3種類。中心のまわりの円（暴風域・強風域）、進む先の点線の円（予報円＝中心が来るかもしれない範囲）、それを包む太い線（暴風警戒域＝暴風域に入るおそれのある範囲）。

🔍 こう読み解く

  1. ×印を中心にした円のうち、小さい色つきがD、大きいのがE。暴風域は強風域の内側 → ②はD。
  2. A・Cは進む先の点線の円（予報円）、Bはそれらを包む線（暴風警戒域）。今の暴風域ではない。
