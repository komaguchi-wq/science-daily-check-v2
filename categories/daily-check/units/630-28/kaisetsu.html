確認1 (1) 石灰水が白くにごることから分かること 知識問題

気体Aは二酸化炭素。石灰水に溶けている水酸化カルシウムが二酸化炭素と反応して、水に溶けない炭酸カルシウムができるので白くにごる（解答冊子）。「石灰水が白くにごる」は二酸化炭素の見分け方そのもので、塩酸＋炭酸カルシウム（石灰石・貝がら・卵のから）で出る気体も二酸化炭素。答えは「気体Aは二酸化炭素である」と、気体の名前を言い切る形で書く。
答え：気体Aは二酸化炭素である。

確認1 (2)①② アンモニア水のBTB液の色の変化 知識問題

① 青、② 黄。アンモニア水はアルカリ性なのでBTB液は青。二酸化炭素を通すと、アンモニアと中和が進んで中性の緑になり、さらに通すと二酸化炭素が溶けて酸性（炭酸水）になるので黄（解答冊子）。BTBは 酸性＝黄・中性＝緑・アルカリ性＝青 の3色で、問題文の「緑色になり」が真ん中の中性にあたる。

確認11 (1) 水素の性質で正しくないもの 素材文・正しくないもの（すべて）

👀 まず見るところ

【まざり型→条件文】部品は各文の「どの液を・何倍に・何g」。先に余白へ「A100＝B120」「C60＝D90」「B120＝D180」「C100＝A（6：5）」の4つの等式を置き、ア〜オは全部をAとDの組か、CとBの組に直して中性の組と比べる。うすめた・濃くしたは、その倍率で「もとの液の重さ」に直す。

📚 前提知識

  • 「2倍にうすめた液 90g」はもとの液45gと同じ働き、「2倍に濃くした液 108g」はもとの液216gと同じ働き。
  • 塩酸が余れば酸性、水酸化ナトリウムが余ればアルカリ性、過不足なしで中性。

🔍 こう読み解く

  1. ア：A 200gに必要なBは240g。B 240g＝D 360g（×3/2）。D 360gぴったり → 中性。
  2. イ：C 30gに必要なDは45g（60：90）。D 45g＝B 30g（×2/3）。塩酸Bが67.5gで30gより多い → 酸性。
  3. ウ：A 120gに必要なBは144g → D 216g → 2倍に濃くしたDなら半分の108g。108gぴったり → 中性。
  4. エ：C：D＝2：3で中性。Cを2倍にうすめ、Dを3倍にうすめると 4：9 で中性。90：180＝4：8 で塩酸が足りない → アルカリ性（どちらにも入れない）。
  5. オ：A：D＝100：180＝5：9で中性。Aを3倍にうすめ、Dを2倍に濃くすると 15：4.5＝10：3 で中性。150：50＝3：1 は塩酸が多い → 酸性。
答え：酸性 イ・オ　中性 ア・ウ
コツ：5つとも「必要な相手の重さ」を計算してから、実際の重さと大小を比べる。「ぴったり／塩酸が多い／水酸化ナトリウムが多い」の3つに分けて書くと、答える記号を取りちがえない。
