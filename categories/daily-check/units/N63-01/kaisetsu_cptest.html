N63-01 CP（コアプラス確認テスト 光・音②〈反射・音〉・鏡の見え方／光の道すじ／音の高さ／反射音）

CP 全体像 コアプラス確認テスト 10問

範囲は光・音②（反射・音）（コアプラス 435〜453・618〜620）。(1)〜(6)は鏡の反射（全身がうつる鏡の大きさ／鏡で見える人／鏡の回転／2枚の鏡で光の道すじ）、(7)〜(9)は音の高さ（波形・リコーダー・コップとびん）、(10)は反射音の計算。

図の問題は、鏡のうしろの像・反射のマス数・ふるえるものの名前を、先に図へ書いてから決める。

CP (1) 全身を見るのに必要な鏡の大きさ 資料問題・図の線を読む

👀 まず見るところ

【資料問題】部品は図1の正体「T君の体から鏡へ引いた7本の線」と、目の高さの線「ウ」。目と頭のてっぺん（ア）のまん中、目と足もと（キ）のまん中に丸 → その2本のあいだが答え。

📚 前提知識

  • 鏡で見えるのは、体から出た光が鏡ではね返って目にとどく所。頭のてっぺんからの光は、目と頭のてっぺんのちょうどまん中の高さで鏡に当たって目に入る。足もとも同じで、目と足のまん中。
  • だから全身を見るのに必要な鏡のたての長さは、身長の半分（140cmなら70cm）。鏡までの距離には関係しない。

🔍 こう読み解く

  1. 目の高さはウの線。頭のてっぺんはア。アとウのまん中はイ。
  2. 足もとはキ。ウとキのまん中はオ。
  3. イからオまでが、全身がうつる範囲。それより上と下は使われない。
答え：イからオまで
今回：イからオまで ○。図1の目から鏡へ線を引いてから決めている。

CP (2) 鏡に近づいたときの姿 知識問題

ません（はみ出さない）。鏡までの距離を変えても、頭のてっぺんからの光が鏡に当たる所は「目と頭のまん中の高さ」のまま。必要な鏡の大きさは身長の半分で変わらないので、(1)で決めた鏡なら近づいても遠ざかってもはみ出さない。近づくと鏡の中の自分は大きく見えるが、うつる範囲は同じ。
答え：ません
今回：ません ○。

CP (3) 鏡で自分の姿が見える人 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図2の鏡の「両はし」（左のふちから2マスの線〜6マスの線）と、聞かれ方「すべて選び」に丸。両はしから鏡に垂直な線を下へのばす（図に置く）→ その2本の線のあいだに立つ人だけが、自分の姿を見られる。

📚 前提知識

  • 自分の姿を見るには、自分から鏡に垂直に当たった光が同じ道を通ってもどってくればよい。だから鏡の真正面（両はしから垂直に引いた線のあいだ）にいることが条件。
  • 鏡の面をのばした線の上（ア）は、光が鏡の面に当たらないので何もうつらない。

🔍 こう読み解く

  1. 鏡は横一列。人も鏡のはしも図のたて線の上にあるので、左のふちから何マスの線かで数える。左はしは2マス、右はしは6マス。両はしから下へ垂直の線を引く。
  2. 選ぶ：ウ（4マス）とエ（6マス＝右はしの真下）は2本の線のあいだ → 見える。
  3. 選ばない：イ（1マス）とオ・カ（7マス）は線の外。アは鏡と同じ横の列にいて、鏡を真横から見る形 → 見えない。
答え：ウ・エ
今回：ウ・エ ○。

CP (4) 鏡を通してA君を見ることができる人 資料問題・像を置いてすべて選ぶ

👀 まず見るところ

【資料問題】部品は「鏡を通してA君を」。A君を鏡のうしろへ折り返した像A'（鏡から2マス上）に直して図に置く → 各人とA'を結んだ直線が鏡の板を通れば見える、通らなければ見えない。

📚 前提知識

  • 鏡にうつるものは、鏡をはさんで線対称の位置（像）にあるように見える。A君は鏡の2マス下にいるので、像は鏡の2マス上。
  • 「人→鏡→A君」の光の道は、「人→像」の1本の直線に置きかえられる。その直線が鏡の両はしのあいだを横切るかどうかだけで決まる。

🔍 こう読み解く

  1. A君は鏡の2マス下・左のふちから5マスの線の上。像A'はその折り返しで、鏡の2マス上・同じ5マスの線の上に置く。
  2. 選ぶ：イ・ウ・エは、A'と結ぶと線が鏡の左はしと右はしのあいだを通る → 見える。カ（7マス・鏡の3マス下）も、右下から左上のA'へ向かう線が鏡の右はし（6マス）の少し内側を通る → 見える。
  3. 選ばない：オ（7マス・鏡の1マス下）はA'と結ぶ線が鏡の右はし（6マス）より右で鏡の高さを横切る → そこに鏡はないので見えない。アは鏡と同じ列なので見えない。
答え：イ・ウ・エ・カ
今回：ウ・エ・オ ×。部品の形を直さなかった＝A君を鏡のうしろの像A'に直して置かず、A君と鏡の両はしを結んだ線から目分量ではね返りを引いて決めた形（答案の図はA君と鏡のはしを結ぶ線と、はしから各人への線）。像を置けば、オの線は鏡の右はしの外、カの線は内側、とマス目で言い切れる。次は像A'を先に打ち、6人全員とA'を結ぶ。

CP (5) 反射光を10度ずらす鏡の回転 知識問題

5度。鏡を回すと、入射角と反射角が同じだけ変わる。鏡を5度回せば入射角が5度変わり、反射角も5度変わるので、反射光の向きは合わせて2倍の10度動く。「鏡の回転×2＝反射光のずれ」と組で結びつける。
答え：5度
今回：5 ○。

CP (6) 2枚の鏡の部屋から光が出て行く所 資料問題・マス目で反射を描く

👀 まず見るところ

【資料問題】部品は入ってくる光のマス数「横2・たて3」（上のふちの左から2マスの点から、左の鏡の上から3マス下の点へ）。反射のたびに、このマス数を向きだけ変えて写す（図に置く）→ 2回はね返って上のはしに出る所が決まる。

📚 前提知識

  • 光は鏡に当たると、入射角＝反射角ではね返る。マス目の図では「横○マス・たて△マス」の進み方のうち、鏡に垂直な向きだけが逆になる。左の鏡では横の向き、下の鏡ではたての向きが逆。

🔍 こう読み解く

  1. 入る光：上のふち・左から2マスの点から、左へ2・下へ3進み、左の鏡の上から3マス下に当たる。
  2. 左の鏡で横だけ逆：右へ2・下へ3 → 下の鏡の、左から2マスの点に当たる。
  3. 下の鏡でたてだけ逆：右へ2・上へ3。上のふちまでは6マス上がるので横は4マス進み、左から6マスの点に出る。上の記号はアが3マス・イ4・ウ5・エ6・オ7（カは右上の角）なので、6マスはエ。
答え：エ
今回：カ ×。部品の形を直さなかった＝入る光の「横2・たて3」をマス数に直して写さず、左の鏡からの反射を目分量で引いた（答案の線は下の鏡の4マス目あたりに当たっている）。次は反射のたびに「横2・たて3」と数えて点を打ってから線を引く。

CP (7) 最も低い音の波形 資料問題・波の数を数える

👀 まず見るところ

【資料問題】部品は「同じ時間だけ表示」と、聞かれ方「最も低い音」に丸。低い＝ふるえる回数が少ない → 同じ時間で波の数がいちばん少ないものを数えて選ぶ。波の高さは見ない。

📚 前提知識

  • 音の高さは1秒間にふるえる回数（振動数）で決まる。多いほど高く、少ないほど低い。同じ時間の表示なら、波の数で比べられる。
  • 音の大きさは波の高さ（振幅）で決まる。高い・低い＝波の数、大きい・小さい＝波の高さ、と2組に分けておく。

🔍 こう読み解く

  1. 山の数を数える。A＝5、B＝2、C＝3。
  2. いちばん少ないBが、いちばん低い音。
  3. Aは波が低いので「小さい音」だが、波の数は多いので高い音。Cは波がいちばん高いので、いちばん大きい音。
答え：B
今回：A ×。知識＝「低い」を波の高さで見て、いちばん小さい音のAを選んだ。低い・高いは波の数、大きい・小さいは波の高さ。次は設問の「低い」に丸をつけ、横に「数」と書いてから数える。

CP (8) リコーダーの穴をふさぐと音は 知識問題

低く。リコーダーは中の空気の柱がふるえて音が出る。穴をふさぐと、息が出ていく穴が遠くなってふるえる空気の柱が長くなり、ふるえ方がゆっくりになるので音は低くなる。穴を全部ふさいだときがいちばん低い音。
答え：低く
今回：低く ○。

CP (9) コップとびんで高い音が出るほう 資料問題・何がふるえるか

👀 まず見るところ

【資料問題】部品は図の「金属棒」でたたく（図4）と、口でふく「びん」（図5）。たたく→ふるえるのはコップと水、ふく→ふるえるのはびんの中の空気。ふるえるものの名前を図のわきに書く → 「水が多いと高いか低いか」が図4と図5で逆向きに決まる。

📚 前提知識

  • たたく（図4）：ふるえるのはコップ本体と中の水。水が多いほど重くてふるえにくく、音は低い → 水が少ないアが高い。
  • ふく（図5）：ふるえるのは水の上の空気の柱。水が多いほど空気の柱が短く、ふるえが速くて音は高い → 水が多いイが高い。

🔍 こう読み解く

  1. 図4：水が少ないのはア、多いのはイ。たたくのでふるえるのはコップ＋水。軽いほうが高い → ア。
  2. 図5：水が少ないのはア、多いのはイ。ふくのでふるえるのは空気。空気の柱が短いほうが高い → イ。
  3. 同じ「水が多い」でも、たたくと低く、ふくと高い。答えが逆になるこの2問はセットで整理する。
答え：図4 ア　図5 イ
今回：図4 ア　図5 イ ○。

CP (10) 反射音を聞いたときの船と岸壁の距離 条件文・計算

👀 まず見るところ

【条件文】部品は「15m/秒で岸壁に向かっている」「6秒後」「340m/秒」と、求めるもの「反射音を聞いたときの位置」に丸。6秒間に音が進んだ道と船が進んだ道を1本の線に置く（図に置く）→ 鳴らした位置までの距離を出してから、船が進んだ分をひく。

📚 前提知識

  • 音は岸壁まで行ってもどる。そのあいだ船も岸壁に向かって進むので、音が進んだ距離＋船が進んだ距離＝鳴らした位置から岸壁までの2倍。
  • 聞いたときの位置は、鳴らした位置より船が進んだ分だけ岸壁に近い。

🔍 こう読み解く

  1. 音が6秒で進んだ距離：340×6＝2040m。
  2. 船が6秒で進んだ距離：15×6＝90m。
  3. 鳴らした位置から岸壁まで：(2040＋90)÷2＝1065m。
  4. 聞いたときは90m進んでいるので、1065−90＝975m。
答え：975m
今回：1065 ×。答案の式「355×6×1/2＝1065」は、音と船の速さを足して出会い算で解く形で、鳴らした位置から岸壁までの距離としては正しい。部品を拾えなかった＝求めるもの「反射音を聞いたとき」に丸がなく、鳴らしたときの位置で止まった。次は求めるものに丸をつけ、最後に90mをひく。

CP まとめ 60点（10問中6問）

  • 取れた：(1)(2)(3)(5)(8)(9)。鏡の大きさの決め方と、たたく・ふくの区別はできている。
  • 落とした4問は、どれも紙に置く部品が1つ足りなかった：(4)像A'／(6)「横2・たて3」のマス数／(7)「低い＝波の数」／(10)「聞いたとき」の丸。
  • 覚え直しは2つ：高い・低い＝波の数、大きい・小さい＝波の高さ／鏡の回転×2＝反射光のずれ。
