L (1) 燃やすと二酸化炭素が発生するもの 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問は「二酸化炭素が発生するもの」を「すべて」。二酸化炭素の炭（炭素）がもとの物に入っているか、と直して書く → 4つに○×をつけるだけで決まる。

📚 前提知識

  • 燃える＝酸素と結びつくこと。できるものは、もとの物に何が入っているかで決まる。炭素があれば二酸化炭素、水素があれば水。
  • エタノールと木炭は炭素をふくむ。水素は水しかできない。スチールウール（鉄）は気体を出さず、酸素とくっついて黒い酸化鉄になり重くなる。

🔍 こう読み解く

  1. ア エタノール → 炭素と水素をふくむ → 二酸化炭素と水 → ○。
  2. イ 水素 → 炭素なし → 水だけ → ×。ウ スチールウール → 金属 → 気体は出ない → ×。
  3. エ 木炭 → 炭素そのもの → 二酸化炭素 → ○。答えはア・エ。
答え：ア・エ
自分で解くときのチェック：「すべて」なので、4つ全部に○×を書いてから答えを写す。1つ見つけて止まらない。

L (2) ろうそくを燃やすと二酸化炭素と何ができるか 知識問題

水（水蒸気）。ろうは炭素と水素でできているので、燃えると炭素から二酸化炭素、水素から水ができる。火を近づけた冷たいビーカーの内側がくもるのが、この水蒸気。(1)のエタノールも同じ組み合わせ。
答え：水（水蒸気）

L (3) 湿ったところに置いた鉄にできるさび 知識問題

① 赤　② 酸化鉄。鉄が水と空気中の酸素にふれてゆっくり酸素と結びつくと、赤茶色の赤さびができる。正体は酸化鉄で、スチールウールを燃やしたときの黒い酸化鉄と同じ「鉄＋酸素」。燃やす＝速くて熱が出る、さびる＝ゆっくりで熱がほとんど出ない、のちがいで覚える。
答え：① 赤　② 酸化鉄

L (4) ろうそくの火が消えたあとの水面 資料問題・水と石灰水のくらべ

👀 まず見るところ

【資料問題】資料の正体「同じ容器・下の液だけA＝水、B＝石灰水」を1行。ちがいは石灰水が二酸化炭素を吸うこと → 火が消えたあと、容器の中の気体がより減るのはBと決まる。

📚 前提知識

  • ろうそくが燃えている間は中の空気があたためられてふくらみ、一部が外に出る。火が消えて冷えると気体が縮み、できた水蒸気も水にもどるので、中の気体が減って水面は上がる。
  • 石灰水は二酸化炭素をとかしこむ（白くにごる）。燃えてできた二酸化炭素が気体でなくなる分、Bの方が気体が多く減る。

🔍 こう読み解く

  1. ①：A・Bとも、冷えて気体が減る → 水面は上がり。
  2. ②：Bは、それに加えて二酸化炭素が石灰水に吸われる → 減る量が大きい → 水面の変化が大きいのはB。
答え：① 上がり　② B
自分で解くときのチェック：「ろうそくが燃えると酸素が減って二酸化炭素がふえる」だけでは、AとBの差が説明できない。差をつくるのは下の液のちがい。

L (5) 実験後に容器の中の二酸化炭素が多いのはどちらか 資料問題・(4)の続き

👀 まず見るところ

【資料問題】部品は「容器の中にある二酸化炭素」と(4)で置いた「石灰水は二酸化炭素を吸う」。吸われたBの方は気体の二酸化炭素が減っている → 多いのはAと決まる。

📚 前提知識

  • ろうそくが燃えてできる二酸化炭素の量はA・Bで同じ。ちがうのは、そのあと液にとけるかどうか。水にも少しはとけるが、石灰水の方がはるかによく吸う。

🔍 こう読み解く

  1. できた二酸化炭素は同じ → Bは石灰水に吸われて気体の二酸化炭素が減る。
  2. 残っているのが多いのはA。(4)②で「Bの水面が大きく上がった」理由と同じ1つの事実で、2問が決まる。
答え：A
自分で解くときのチェック：(4)で「B」と書いた勢いで(5)も「B」としない。(4)は「減った量」、(5)は「残っている量」で、答えは逆になる。

L (6) 20gの銅を完全に燃やすのに必要な酸素 条件文・比の計算

👀 まず見るところ

【条件文】部品は「4gの銅粉」「5gの黒い物質」「20gの銅」。5−4＝1gを「くっついた酸素」に直して書く → 銅：酸素＝4：1 で、20gの銅には酸素5gと決まる。

📚 前提知識

  • 金属を燃やすと、結びついた酸素の分だけ重くなる。ふえた重さ＝使った酸素の重さ。黒い物質は酸化銅。
  • 銅と酸素は決まった重さの比（4：1）で結びつく。銅をふやせば、酸素も同じ倍率でふえる。

🔍 こう読み解く

  1. 余白に「銅4g＋酸素□g＝酸化銅5g」→ □＝5−4＝1g。
  2. 銅：酸素＝4：1。銅20gは4gの5倍 → 酸素も5倍 → 1×5＝5g。
答え：5g
自分で解くときのチェック：聞かれているのは「酸素」。酸化銅の重さ（25g）を答えにしない。

L (7) ガラスを通りぬける光の進み方 資料問題・屈折

👀 まず見るところ

【資料問題】資料の正体「空気→ガラス→空気と、ななめに入る光」を1行。ガラスに入るとき1回、出るとき1回折れ、出た光は入った光と平行と置く → 入った矢印と同じ向きに出ている線を選ぶだけで決まる。

📚 前提知識

  • 光は空気からガラスにななめに入ると、進みにくい側へ境目に立てた垂線に近づく向きに折れる（屈折）。ガラスから空気に出るときは逆に垂線から遠ざかる。
  • 入る面と出る面が平行なら、2回の折れ曲がりが打ち消し合って、出た光は入った光と平行になる。ずれるだけで、向きは変わらない。

🔍 こう読み解く

  1. 入る光と平行に出ている矢印をさがす → イ。ガラスの中で立ち気味（垂線に近づく）に進み、出るところでもとの向きにもどっている。
  2. ア：ガラスの中で左へ折れ返している → 反射でも屈折でもない。ウ・エ：ガラスに入るところで、入る光より寝る向き（垂線から遠ざかる向き）に折れている → 入るときの折れ方が逆。どれも×。
答え：イ
自分で解くときのチェック：ガラスの中の線が「入る光より立っているか」と、出た線が「入る光と平行か」の2点を見る。片方だけで決めない。

L (8) 鏡から遠ざかると全身がうつるようになるか 条件文・鏡にうつる範囲

👀 まず見るところ

【条件文】部品は「身長150cm」「一辺10cmの鏡」「鏡から遠ざかる」。鏡にうつる自分の長さは鏡の長さの2倍（10cm→20cm分）と直して書く → 遠ざかっても20cmのままで、150cmには足りないと決まる。

📚 前提知識

  • 鏡にうつる自分は、鏡の面をはさんで同じきょりの向こう側にいる。自分と像のまん中に鏡があるので、鏡の長さの2倍までしかうつらない。
  • 遠ざかっても、自分と像のまん中に鏡がある関係は変わらない。見える範囲は同じで、像が小さく見えるだけ。

🔍 こう読み解く

  1. うつる長さ＝10×2＝20cm分。身長150cmの一部しかうつらない。
  2. 遠ざかっても20cmのまま → 全身がうつるようにはなりません。
答え：なりません
自分で解くときのチェック：「遠ざかると小さく見える＝たくさんうつる」と思いやすい。小さくなるのは像で、うつる範囲はふえない。全身を見るには身長の半分（75cm）の鏡がいる。

L (9) 鏡が2枚入った筒をのぞいたときの「5」 資料問題・鏡の向きを追う

👀 まず見るところ

【資料問題】資料の正体「上の鏡は横から来た光を下へ、下の鏡は下りてきた光を手前へ曲げる（曲げる向きが90度ちがう）」を1行。鏡1枚で1回折り返すので、「5」の上と右（奥側）がどこへ行くかを追えば決まる。

📚 前提知識

  • 鏡は、鏡に向かう向きだけを折り返す。上の鏡（左上から右下へ斜め）に横から当たった光は真下に曲がり、「5」の上側から来た光ほど筒の左側を下りる。
  • 下の鏡（奥の上から手前の下へ斜め）に上から当たった光は手前に曲がり、筒の奥側を下りた光ほど高い位置から出てくる。

🔍 こう読み解く

  1. 「5」の上 → 上の鏡で筒の左側へ → 下の鏡では左右は変わらない → のぞくと左に見える。
  2. 「5」の右（カードは筒の方を向いているので、奥側）→ 上の鏡では奥のまま → 下の鏡で高い位置へ → のぞくと上に見える。
  3. 上が左、右が上 → 「5」を左へ90度たおした形 → ア。イは180度回した形、ウは左右を裏返した形、エは右へ90度たおした形。
答え：ア
自分で解くときのチェック：「鏡2枚＝元にもどる」は、2枚の鏡が平行なとき（ふつうの潜望鏡）だけ。この筒は下の鏡が手前を向いているので、曲げる向きが90度ちがう。

L (10) 万華鏡でPの位置にうつる模様 資料問題・折り返しを2回

👀 まず見るところ

【資料問題】資料の正体「3枚の鏡＝太線の三角形。○が上の角、△が左下、×が右下」を1行。Pの三角形は右の辺で1回、横の線で1回折り返した先と置く → 折り返す辺に近い印はその場に残り、残りの1つだけ向こうへ飛ぶ、で決まる。

📚 前提知識

  • 万華鏡の模様は、鏡の辺を折り目にして線対称にうつる。辺の両はしの角にある印は折っても同じ場所に残り、辺から遠い角の印だけが辺の向こう側へ移る。
  • 2回折り返すと、1回目でできた三角形の辺をまた折り目にする。Pの三角形まで、鏡の線を何本またぐかを数える。

🔍 こう読み解く

  1. 1回目：太線の右の辺（○と×を結ぶ辺）で折る → ○と×はそのまま、△が右へ移る。できた逆三角形は「上の2角が○・△、下の角が×」。
  2. 2回目：その逆三角形の上の辺（横の線）で折る → ○と△はそのまま、×が上へ移ってPの三角形のいちばん上の角へ。
  3. Pの三角形：上が×、左下が○、右下が△ → エ。
答え：エ
自分で解くときのチェック：図に直接、1回目・2回目の三角形の角へ○△×を書きこむ。頭の中で回転させると、○と△が入れかわりやすい。

L まとめ 解く前に紙に置く3つ

  • 燃やしてできるものは、もとの物に炭素があるかで決まる（エタノール・木炭→二酸化炭素、水素→水）。金属は気体を出さず重くなり、ふえた重さが酸素（銅4g→5gなら酸素1g、20gなら5g）。
  • 水と石灰水のちがいは石灰水が二酸化炭素を吸うこと。だから水面が大きく上がるのはB、残っている二酸化炭素が多いのはA。
  • 光は「ガラスを出た光は入った光と平行」「鏡にうつる範囲は鏡の2倍で固定」「鏡1枚で1回折り返す（筒は上と右を追う・万華鏡は辺に近い印が残る）」の3つを図に書いてから選ぶ。

M (1) 炭素を含むものをすべて選ぶ 知識問題

イ・ウ・オ・カ。炭素を含むものは、燃えると二酸化炭素が出るもの。豚肉（生き物のからだ）・ノート用紙（木から作る）・プラスチックと灯油（石油から作る）はどれも燃えて二酸化炭素を出す（紙や肉は黒くこげる）。食塩とガラスは燃えず、炭素を含まない。「燃えて黒くこげるか」で見分けると、生き物由来と石油由来がひとまとまりで選べる。すべて選ぶ問題なので、6つ全部に○×をつけてから書く。

M (2) でんぷん・ブドウ糖・砂糖をまとめた栄養素の名前 知識問題

炭水化物。でんぷんや糖のなかまをまとめた呼び名で、おもにエネルギーのもとになる栄養素。炭素・水素・酸素からできているので「炭」「水」の字が入る。たんぱく質（肉・魚・豆）・脂肪（油）とあわせて三大栄養素。漢字4字指定。

M (3) 湿ったところで銅にできるさび 知識問題

緑青（ろくしょう）。銅が水分や空気中の二酸化炭素などと長い時間かけて結びついてできる青緑色のさび。古い銅像や寺の屋根が青緑色なのがこれ。鉄のさびは赤茶色、銅を加熱してできる酸化銅は黒、と色で3つを区別する。
答え：緑青

M (4) スチールウールを燃やしたあとの水面までの高さ 条件文・空気の体積

👀 まず見るところ

【条件文】部品は図の「10cm」（ふたから水面まで）と「底のない容器」に丸。空気の中の酸素は約1/5、と直して書く → 燃焼で酸素が使われた分だけ水が上がるので、10×1/5＝2cm減ると決まる。

📚 前提知識

  • 空気の体積の約1/5が酸素（約21%）、残りのほとんどがちっ素。ちっ素は燃焼に使われないので、そのまま残る。
  • スチールウール（鉄）が燃えると酸素と結びついて酸化鉄になる。酸化鉄は固体で、気体は出てこない。だから容器の中の気体は、使われた酸素の分だけ減る。

🔍 こう読み解く

  1. はじめ、ふたから水面までの気体の高さは10cm。このうち酸素の分は 10×1/5＝2cm。
  2. 燃焼で酸素が全部使われ、気体は固体の酸化鉄に変わって出てこない → 気体が2cm分減り、その分だけ水面が上がる。
  3. 10−2＝8cm。
答え：8cm
自分で解くときのチェック：ろうそくを燃やす問題とは別。ろうそくは燃えると二酸化炭素（気体）が出るので、同じ計算にならない。「何が燃えて、何ができるか」を先に書く。

M (5) 12gの銅を熱して14gになったとき残っている銅 条件文・比の計算

👀 まず見るところ

【条件文】部品は「4gの銅…5gの黒い物質」と「12g…14g」に丸。前半を「銅4：酸素1：酸化銅5」に直して余白に書く → 増えた2gは酸素なので、結びついた銅は2×4＝8gと決まる。

📚 前提知識

  • 銅を加熱すると空気中の酸素と結びついて黒い酸化銅になる。重さが増えるのは、結びついた酸素の分。
  • 結びつく重さの比は決まっていて、この問題では 銅4g＋酸素1g＝酸化銅5g。

🔍 こう読み解く

  1. 12g → 14g で増えた 2g が酸素の重さ。
  2. 酸素1gと結びつく銅は4g → 酸素2gなら銅 2×4＝8g が酸化銅になった。
  3. 残っている銅は 12−8＝4g。確かめ：酸化銅10g＋銅4g＝14gで合う。
答え：4g
自分で解くときのチェック：14gを「酸化銅の重さ」として 14×4/5 としない。14gは酸化銅と残った銅の合計。「増えた分＝酸素」から入ると一本道。

M (6) ガラスを通る光の正しい進み方（①②） 資料問題・屈折と全反射

👀 まず見るところ

【資料問題】部品は図の「45°」と、光がガラスの面に当たる角度。①はななめに入って、ななめに出る＝入るとき・出るときの2回曲がる。②は面に直角に入るので曲がらず、中で45度で当たってはね返る。この2つを図に書くと、答えの線が1本ずつ残る。

📚 前提知識

  • 光は空気からガラスに入るとき、面に立てた垂線に近づく向きに曲がる。ガラスから空気に出るときは垂線から離れる向きに曲がる。面に直角に当たる光は、どちらも曲がらない。
  • ガラスの中から面にななめに当たると、角度が大きいとき（45度なら十分）光は外に出ずに全部はね返る（全反射）。直角のガラスに直角に入れると、2回はね返って来た向きと平行にもどる。

🔍 こう読み解く

  1. ①：アは入っても出ても曲がっていない1本の直線 → ×。ウは入るときに曲がらず、アと同じ線で進んでから出るところだけ曲げている → ×。イは入るときは正しく立つが、出るときに垂線へ近づく向き（逆向き）に曲がっている → ×。
  2. ①：入るとき垂線に近づくので、中の線は入る前より立つ。出るときは左下の面の垂線から離れる向きに曲がり、ほぼ真下を向く → エ。
  3. ②：直角に入るので曲がらず直進。左の面に45度で当たる → 全反射。下の面にも45度で当たる → また全反射。
  4. ②：2回はね返ったあと、入ったときと同じ面から直角に出ていく。入ってきた光と平行で向きが逆 → エ。アは左の面で外に出た線、ウは下の面で出た線、イは曲がらずに通りぬけた線なので×。
答え：① エ　② エ
自分で解くときのチェック：面に当たる点ごとに、短い垂線を1本ずつ書く。「近づく／離れる」はその垂線に対して決めるので、垂線を書かずに目で追うと向きを取りちがえる。

M (7) 2枚の鏡を60度で向かい合わせたときの像の数 条件文・計算

👀 まず見るところ

【条件文】部品は「60度」に丸。360÷角度−1 の式を余白に書く → 360÷60−1＝5と決まる。

📚 前提知識

  • 2枚の鏡を角度をつけて合わせると、鏡にうつった像がさらにもう1枚の鏡にうつり、像が増える。像と物体は鏡のまわりに等しく並び、360度を角度で割った数から物体そのものの1つを引いた数が像の数。
  • 90度なら 360÷90−1＝3個（(10)の図）。角度が小さいほど像は多い。

🔍 こう読み解く

  1. 360÷60＝6。物体と像をあわせて6つが、円を6等分した位置に並ぶ。
  2. そのうち1つは物体そのもの → 像は 6−1＝5個。
答え：5個
自分で解くときのチェック：「−1」を忘れて6個としない。6つのうち1つは本物。

M (8) 自分の全身がうつって見える鏡 資料問題・図えらび

👀 まず見るところ

【資料問題】部品は図の正体「マス目の中の鏡の上端と下端の高さ」と聞かれ方「全身」。全身が見える条件を「上端は頭のてっぺんと目のまん中より上、下端は目と足のまん中より下」と直して書く → ア〜オの鏡の両端をこの2つの高さと比べるだけで決まる。

📚 前提知識

  • 鏡の中の像は、鏡の向こう側の同じ距離にある。頭のてっぺんの像から目に届く光は、鏡の上で「頭のてっぺんと目のまん中」の高さではね返る。足の像からの光は「目と足のまん中」の高さではね返る。
  • だから全身を見るのに必要な鏡の長さは身長の半分で、鏡の位置がその範囲を覆っていればよい。鏡から離れても近づいても、この高さは変わらない。

🔍 こう読み解く

  1. 図で、頭のてっぺん・目・足のマス目の高さを読み、「頭と目のまん中」「目と足のまん中」の2本の線を各図に引く。
  2. ア：鏡の上端が目の高さ → 頭のてっぺんが見えない ×。ウ・オ：鏡の下端が「目と足のまん中」より上 → 足が見えない ×。
  3. イ：鏡が長く、2本の線の外側まで覆う ○。エ：鏡は短いが、上端と下端がちょうど2本の線に重なる ○ → イ・エ。
答え：イ・エ
自分で解くときのチェック：「長い鏡なら見える」ではない。長さより位置。足が見えるかは鏡の下端、頭が見えるかは鏡の上端で決める。

M (9) 木全体を見るのに必要な鏡の縦の長さ 条件文・鏡の像と比

👀 まず見るところ

【条件文】部品は図の「3m」「4m」「1m」に丸。木の像を鏡の向こう側5m（木から鏡までと同じ距離）に書き足す → 人から像まで 1＋5＝6m、鏡は人から1m。鏡を通る幅は木の高さの1/6と決まる。

📚 前提知識

  • 鏡にうつる木は、鏡の向こう側の同じ距離にある像として見える。木から鏡まで 4＋1＝5m なので、像は鏡の向こう5m。
  • 目から像の上端と下端へ引いた2本の線が鏡を通る幅が、必要な鏡の長さ。目を頂点にした相似な三角形なので、長さは距離の比で縮む。目の高さがどこでも同じ答えになる。

🔍 こう読み解く

  1. 像の位置：鏡の向こう5m。人から像までの距離は 1＋5＝6m。
  2. 人から鏡までは1m。鏡を通る幅：像の高さ3m × 1/6＝0.5m。
  3. 確かめ：(8)の「身長の半分」は、人から像までが鏡までの2倍のときの答え。今回は6倍なので1/6になる、と同じ理屈。
答え：0.5m
自分で解くときのチェック：3×1/4（木から人までの4mで割る）としない。比に使うのは「人から像まで」の6mで、像を先に図に書けば取りちがえない。

M (10) 直角に合わせた2枚の鏡にうつる物体の像をかく 資料問題・作図

👀 まず見るところ

【資料問題】部品は解答らんの図の正体「縦の鏡と横の鏡が直角・物体はたての鏡から3マス右、横の鏡から1マス下」。像は鏡をはさんで同じ距離、と直して書く → 像は 360÷90−1＝3個で、位置はマスを数えて決まる。

📚 前提知識

  • 1枚の鏡の像は、鏡をはさんで物体と線対称の位置。鏡から物体までと同じマス数だけ向こう側。
  • 2枚の鏡が直角なら像は3個。縦の鏡の像、横の鏡の像、そして「像がもう1枚の鏡にうつった像」が斜めの位置に1個できる。

🔍 こう読み解く

  1. 縦の鏡の像：物体は縦の鏡の右3マス → 鏡の左3マス、高さは同じ行。
  2. 横の鏡の像：物体は横の鏡の下1マス → 鏡の上1マス、同じ列。
  3. 3個目：左3マス・上1マスの位置（1つ目の像を横の鏡でうつした位置＝2つ目の像を縦の鏡でうつした位置。どちらから考えても同じ点）。
  4. ●を3つかく。解答は、左上・左・上の3点。
答え：3個の●（縦の鏡の左3マス・同じ行／横の鏡の上1マス・同じ列／その両方＝左3マス・上1マス）
自分で解くときのチェック：3個目を忘れやすい。(7)の式で「90度なら3個」と先に個数を出してから、マスを数える。

M まとめ 解く前に紙に置く3つ

  • 燃焼の計算は比を先に書く。(4)は空気の1/5が酸素で 10×1/5＝2cm減って8cm。(5)は「増えた2g＝酸素」から 銅4：酸素1 で8gが結びつき、残りは4g。
  • 屈折は面ごとに垂線を1本。入るとき近づく・出るとき離れる（①エ）。直角のガラスに直角に入れた光は45度で2回全反射して平行にもどる（②エ）。
  • 鏡は像を鏡の向こう側の同じ距離に書く。全身鏡は身長の半分で位置が決め手（イ・エ）、木は人から像まで6mなので 3×1/6＝0.5m、直角の鏡の像は 360÷90−1＝3個（60度なら5個）。

H (1)① クジラが減るとアニサキスも減るか 資料問題・○×

👀 まず見るところ

【資料問題】部品は図の正体「アニサキスの食物連鎖の輪」と本文の「クジラの胃の中で成虫になり卵を産む」。図の矢印を指でたどって1本の輪に直す → 卵を産む場所がクジラだけなので、クジラが減れば卵も減ると決まる。

📚 前提知識

  • 寄生する生き物は、卵を産む相手（最終宿主）がいないと数をふやせない。図では卵が出てくる矢印がクジラからの1本しかない。
  • 食物連鎖の図は、矢印の向き＝「食べられる→食べる」。オキアミ→サバ・イカ→クジラの順に、アニサキスも体の中にいたまま運ばれる。

🔍 こう読み解く

  1. 図の点線をたどる：クジラ → 卵がフンと一緒に排出される → 成長する → アニサキス → オキアミ → サバ・イカ → クジラ。輪になっている。
  2. 輪の出発点（卵を産む場所）はクジラの胃だけ。クジラが減る → 産まれる卵が減る → アニサキスも減る。
  3. 文のとおり → ○。
答え：○
自分で解くときのチェック：「ヒトにも寄生するからクジラがいなくても平気」と考えない。本文の「本来の宿主ではないヒト」で、ヒトは輪の外だと分かる。

H (1)② ヒトの胃の中で産卵して増殖し続けるか 素材文・○×

👀 まず見るところ

【素材文】設問は文の正誤。部品は本文の「本来の宿主ではないヒトの体内では長く生きることはできません」に丸 → 長く生きられない相手の中で「増殖し続ける」は成り立たないと決まる。

📚 前提知識

  • 成虫になって卵を産むのは、最終宿主のクジラの胃の中だけ（本文）。ヒトの体内は生きる場所として合わないので、成虫にならずに死ぬ。

🔍 こう読み解く

  1. 選択肢の文を2つに切る：「ヒトの体内に入ると」／「胃の中に産卵して増殖し続ける」。
  2. 後半を本文と照らす。本文は「長く生きることはできません」→ 産卵も増殖もしない。
  3. 後半が本文と逆 → ×。解答冊子も「本来の宿主ではないヒトの体内では長く生きることができません」。
答え：×
自分で解くときのチェック：「食中毒を引き起こす」とあるので「ヒトの中でも元気に生きる」と思いやすい。食中毒は体内に入ったときの痛みで、増えることとは別。

H (1)③ 新鮮な魚介類を食べれば食中毒を防げるか 素材文・○×

👀 まず見るところ

【素材文】部品は本文の「加熱や冷凍によって死にます」「生食することで…食中毒」に丸。防ぐ方法として本文にあるのは加熱・冷凍だけで、「新鮮」という言葉はどこにもない → 文は本文にない話なので×と決まる。

📚 前提知識

  • アニサキスは生きたまま魚の体内にいる。新鮮な魚ほどアニサキスも生きているので、鮮度では防げない。死なせる手段が加熱と冷凍。

🔍 こう読み解く

  1. 文の決め手は「新鮮な魚介類を食べる」。本文で食中毒を防ぐ手がかりをさがす → 「加熱や冷凍によって死にます」。
  2. 新鮮でも生で食べれば「生食」なので、本文の「生食することで…食中毒」に当てはまる。
  3. → ×。解答冊子は「魚介類を生で食べないことが一番大切」。
答え：×
自分で解くときのチェック：「新鮮＝安全」は食中毒の一般的なイメージ。選択肢の言葉が本文にあるかを先に確かめると、イメージで○にしなくてすむ。

H (2)① 動物が消化できない植物の成分 素材文・穴うめ

👀 まず見るところ

【素材文】部品は空らんの前後「植物に含まれる」「動物は…消化することができず」「微生物に消化を助けてもらっている」に丸 → 植物にあって、動物の消化液では分解できない成分＝食物繊維と決まる。

📚 前提知識

  • 植物の体（葉・くき・細胞のかべ）をつくる食物繊維は、ヒトやイヌなど動物の消化液では分解できない。デンプン・タンパク質・脂肪の三大栄養素とはちがう。
  • 草食動物は、消化管の中にすむ微生物に食物繊維を分解してもらい、その栄養を吸収している。だから消化管が長く、微生物をためる場所（胃や盲腸）が大きい。

🔍 こう読み解く

  1. 空らんの条件は3つ：植物に含まれる／動物は消化できない／微生物なら消化できる。
  2. デンプンは動物も消化できるので×。3つすべてに合うのは食物繊維。
答え：食物繊維
自分で解くときのチェック：「デンプン」と書かない。デンプンは植物に含まれるが、動物も消化できる（だ液のアミラーゼ）。

H (2)②③ 微生物を胃にためる動物・盲腸にためる動物 資料問題・3つから選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「3種類の動物の消化管」と設問の「胃にためておく」「盲腸にためておく」に丸。図でその部分がいちばん大きい動物に印をつける → 胃が4つあるヒツジ、盲腸が太く長いウサギと決まる。

📚 前提知識

  • ヒツジやウシは胃が4つあり、特に大きな第1胃に微生物をためて植物を分解する（解答冊子）。分解してから小腸へ送るので、栄養を効率よく吸収できる。
  • ウサギは盲腸に微生物をためて分解する。盲腸は小腸より後ろにあるので、分解してできた栄養を小腸で吸収できず、糞に残る。だからその糞を食べ直す（解答冊子）。
  • イヌは肉食で、胃も盲腸も小さく、消化管が短い。②③のどちらにも入らない。

🔍 こう読み解く

  1. 図で「胃」をさがす：ヒツジは第1胃〜第4胃の4つ、イヌとウサギは1つ。胃にためる＝ヒツジ（②）。
  2. 図で「盲腸」をさがす：ヒツジは（盲腸）と小さく、イヌも小さい。ウサギは盲腸が太く長い → 盲腸にためる＝ウサギ（③）。
  3. 確かめ：③の文「糞の中にまだ吸収されていない栄養」は、盲腸が小腸より後ろにあるウサギにだけ合う。
答え：② ヒツジ　③ ウサギ
自分で解くときのチェック：②と③で同じ動物を書かない。「効率よく吸収」は胃（小腸の前）、「糞に栄養が残る」は盲腸（小腸の後ろ）と、場所の前後で分ける。

H (3)①② 窒素の循環の図で矢印を選ぶ 資料問題・図の矢印

👀 まず見るところ

【資料問題】部品は図の3つの箱と、入れる言葉「動物・植物・排せつ物や死がい」。先に箱を埋める：矢印が2本入って1本出る右の箱＝排せつ物や死がい、そこから戻る先の下の箱＝植物、残りの上の箱＝動物 → ①は植物→動物のA、②は植物→排せつ物や死がいのCと決まる。

📚 前提知識

  • 窒素はタンパク質の材料（本文）。植物は土の中の窒素を根から取り入れ、動物は植物や他の動物を食べてその窒素をもらう。空気中の窒素はどちらも直接使えない（本文）。
  • 動物の排せつ物や、動物・植物の死がいは、土の中の微生物（菌類・細菌）に分解されて土の窒素にもどり、また植物に取り入れられる。これが「循環」。

🔍 こう読み解く

  1. 右の箱：矢印B・Cが入り、Dが出る。動物からも植物からも来るのは排せつ物や死がい。
  2. 下の箱：排せつ物や死がいからD（分解された窒素）が戻ってくる → 土から窒素をもらう植物。上の箱：植物からAでもらう → 動物。
  3. ①「ウサギがニンジンを食べる」＝植物→動物 → A。②「落ち葉が積もる」＝植物の体が死がいになる＝植物→排せつ物や死がい → C。
答え：① A　② C
自分で解くときのチェック：箱を埋める前に①②を見ない。②を「Dの逆」や「B」と答えるのは、植物の箱がどれか決めていないとき。先に3つの箱に言葉を書き込む。

H (4)① 干ばつのあと割合が増えたフィンチ 資料問題・AかB

👀 まず見るところ

【資料問題】部品は本文の「やわらかい種子が減り」と図の2羽のくちばしの太さ。「やわらかい種子が減る」を「残ったのは固い種子」に直して書く → 固い種子を割れる太いくちばしのBが生き残って割合が増えると決まる。

📚 前提知識

  • くちばしは食べ物に合った形をしている。太くて短いくちばしは固い種子を割るのに向き、細いくちばしはやわらかい種子や虫に向く。
  • 環境が変わって食べ物が変わると、その食べ物に合った体の個体が生き残りやすく、その割合が増える。これが(4)②の人物の考え。

🔍 こう読み解く

  1. 図を見比べる：Aはくちばしが細く、Bは太い。
  2. やわらかい種子が減った → 残った固い種子を食べられる個体が生き残る → 太いくちばしのB。
  3. 解答冊子も「Aに比べてBはくちばしが太く、固い種子を食べるのに向いている」。
答え：B
自分で解くときのチェック：「減った」のはやわらかい種子で、鳥ではない。聞かれているのは「割合が増えた鳥」なので、減った種子→残った種子→それを食べられる鳥、と1段ずつ直す。

H (4)② 『進化論』を提唱した人物 知識問題

ダーウィン（チャールズ・ダーウィン）。イギリスの学者で、ガラパゴス諸島のフィンチやゾウガメの観察をもとに、環境に合った個体が生き残って子孫を残すという自然選択（自然淘汰）の考えを『種の起源』で発表した。(4)①の「固い種子に合うくちばしの鳥が増えた」は、その考えがそのまま起きた例。エンドウの遺伝＝メンデル、進化論＝ダーウィン、と人物をセットで区別する。
答え：（チャールズ・）ダーウィン

H まとめ 解く前に紙に置く3つ

  • (1)の○×は選択肢の言葉が本文にあるかで決める。「長く生きることはできません」「加熱や冷凍」が決め手。「新鮮」は本文にない言葉なので×。
  • 図は大きさと矢印の出入りで読む。(2)は胃が4つのヒツジ・盲腸が大きいウサギ。(3)は矢印が2本入って1本出る箱＝排せつ物や死がいを先に埋め、植物→動物がA、植物→死がいがC。
  • (4)は「やわらかい種子が減った」を「固い種子が残った」に直してから図を見る。太いくちばしのBが増える。これを説明したのがダーウィンの『進化論』。
