DC1 (1)② えの位置の金星の形 資料問題・ア〜キから選ぶ

👀 まず見るところ

【資料問題】部品は「えの位置」を図に置く＝太陽の左側で、地球から見て太陽の向こう寄り（遠い）。遠いほど光る部分は丸に近く、左側（夕方）なので光るのは右 → 「丸に近く、左がわずかに欠けた」イ、と決まる。

📚 前提知識

  • 金星の形は地球との位置関係で決まる。太陽の向こう側（う）に近いほど丸く小さく、地球に近づく（き）ほど細く大きい。半分になるのは か・く。

答え：イ
コツ：まず「太い／半分／細い」を位置の遠近で決め、次に「右が光る（夕方）／左が光る（明け方）」で左右を決める。2段階に分けると取りちがえない。

DC2 (1)① A〜Dの結果からいえること 資料問題・ア〜エから選ぶ

👀 まず見るところ

【資料問題】部品は資料の正体「24時間のうちの明期と暗期・時間」と聞かれ方「A〜Dの結果から」に丸。各行を数字に直すと 咲く＝暗10〜12（明12〜14）、咲かない＝暗9（明15）。暗期と明期は足していつも24なので、どちらが原因かは決められない → 片方を切り捨てないエ、と決まる。

📚 前提知識

  • 実験で原因を決めるには、その条件だけを変えた組がいる。A〜Dは明期を変えると暗期も自動で変わるので、「暗期のせい」とも「明期のせい」とも言い切れない。
  • 資料だけで決まる問題。知識（アサガオは暗期で決まる）を先に使うと、アやウを選びたくなる。

🔍 こう読み解く

  1. A〜Cは咲く：暗期 12・11・10、明期 12・13・14。Dは咲かない：暗期9、明期15。境目は「暗期10以上」でも「明期14以下」でも説明できる。
  2. ア「明期は関係ない」・イ「暗期は関係ない」→ 関係ないと示した組がない → ×。ウ「両方そろわないと咲かない」→ 片方だけの組がない → ×。
  3. エ「両方、もしくは一方の条件だと咲く」→ 見えた事実の範囲をこえていない → エ。
答え：エ
コツ：「〜からいえること」は、資料にない組（ここでは明期だけ変えた実験）を根拠にした選択肢を消す問題。言いすぎの選択肢から切る。

DC2 (1)② Eを加えて分かること 資料問題・a〜cの言葉を選ぶ

👀 まず見るところ

【資料問題】部品は「Eの結果も加えると」に丸と、Eの行の18時間のところの白い線。Eを数字に直す＝明12・暗6＋6（合計12）。暗期の合計がAと同じ12時間なのに咲かない → 「連続した暗期が、ある時間より長い」と決まる。

📚 前提知識

  • 短日植物の開花を決めるのは連続した暗期の長さ。暗期のとちゅうで短い光を当てると、暗期はそこで切れて数え直しになる。
  • A〜Dで分からなかった「明期か暗期か」を、Eが決める。Eは明期の合計がAと同じ12時間で、変わったのは暗期が続いているかどうかだけ。

🔍 こう読み解く

答え：a 連続　b 暗期　c 長い

DC2 (2) アサガオの花が見られない時期 素材文・ア〜エからすべて選ぶ

👀 まず見るところ

【素材文】部品は設問の「だんだんと日が短くならないと」と聞かれ方「見られない時期をすべて」に丸。「日が短くなる」を日付に直す＝夏至（6月）から冬至（12月）まで → その外側の3月・5月は日が長くなる時期なので咲かない、と決まる。

  2. ウ8月・エ11月 → 夏至から冬至の間＝日が短くなっていく → 条件に合う（咲きうる）→ 選ばない。

DC2 (3) 金星の見た目の大きさが変わる理由 記述

👀 まず見るところ

【素材文】設問の部品は「地球から見て」「見た目の大きさが変化する」に丸。見た目の大きさを決めるのは地球からの距離、と1行で置く → 図2で金星が き（近い）と う（遠い）を行き来することが理由、と決まる。

📚 前提知識

  • 同じ大きさのものでも、近いと大きく、遠いと小さく見える。金星そのものの大きさは変わらないので、変わるのは地球との距離。
  • 地球と金星は公転の周期がちがうので（解答冊子）、図2の き のように近づくときと、う のように太陽の向こう側へ行くときがある。

✍️ 答案の組み立て

  1. 要素A（何が変わるか）：地球から金星までの距離。
  2. 要素B（文の形）：「〜が変化するため。」と、理由の形で結ぶ。
  3. 理由の理由まで書くなら「地球と金星が異なった周期で公転しているため」を前に足す（解答冊子の解説）。無くても距離の1点で答えになる。
模範解答：地球から金星までの距離が変化するため。
コツ：「大きさが変わる」と聞かれて「満ち欠けするから」と書くのは別の話。形と大きさは分けて、大きさは距離で答える。

DC まとめ 100点（大問1 各10点×8・大問2 各5点×4）

  • 金星の問題は図2に線を1本引く：地球と太陽を結ぶ線の上（う・き）＝見えない、線の左＝宵の明星（夕方・右が光る）、右＝明けの明星（明け方・左が光る）。形は「遠いほど丸く小さい、近いほど細く大きい、か・くで半分」。
  • 惑星の表は密度で2組（岩石 3〜5.5／ガス 1前後）に切り、直径の最大は太陽だと見抜いてから木星を決める。
  • アサガオは「連続した暗期がある時間より長い」と咲く。暗期の合計が同じでも、とちゅうで光が入ると咲かない（E）。日が短くなるのは夏至から冬至まで。
