確認2 (1) エナメル線の長さをそろえた理由 知識問題

エナメル線にもわずかに抵抗がある。長さがちがうと回路全体の抵抗が変わり、流れる電流まで変わってしまう。だから巻かずに余った分も切り取らずに残して長さをそろえ、抵抗を同じ＝電流を同じにしている。調べたい条件（巻き数や鉄くぎ）以外はそろえる、という実験の基本。
答え：エナメル線全体の抵抗を同じにするため。
今回：「エナメル線の長さを一緒にするため。」×。問いが「なぜ長さを同じにしたのか」なので、長さの話をくり返すと理由にならない。長さをそろえる → 抵抗が同じ → 電流が同じの、最後のところまで書く。

確認2 (2) 電磁石の強さの調べ方 知識問題

強さは目に見えないので、数えられる形・測れる形に置きかえる。定番は、鉄の小さいクリップを引きつけて個数を比べる方法。解答冊子には別の方法も2つ出ている。ねん土のおもりを増やしていき何gまで支えられるか調べる方法と、ばねばかりで鉄片を引き上げ、はずれるときの目もりを読む方法。
答え：鉄でできた小さいクリップなどを使い、引きつけた個数を比べる。
今回：「ひきつけた鉄くぎの量を記録。」×。方向は合っているが、「量」では何を数えるのかが決まらず、「記録」だけでは比べたことにならない。何を（小さいクリップ）・どう数えて（個数）・どうする（比べる）の3つをそろえて書く。

確認2 (6) 鉄しんに軟鉄を使う理由 知識問題

焼きなました鉄（軟鉄）は、電流を切るとすぐに磁力がなくなる。硬い鋼だと磁力が残って磁石のままになり、引きつけた鉄を離せなくなる。電磁石の長所は「必要なときだけ磁石になる」ことなので、残ってしまっては困る、という理由。クレーンの電磁石で鉄をつかんで離す場面を思い浮かべると結びつけやすい。
答え：電流を切ったときに磁力が残らないようにするため。
今回：「電流を切ったらすぐに磁力が失われるから。」○。

確認2 (7) エナメル線とは何か／銅線を巻いたときの不都合 知識問題

エナメル線は、銅線の表面に電気を通さない樹脂（エナメル）をぬった線。表面が電気を通さないので、となり合う巻き線が触れても電流はそこを通れず、コイルを何周もきちんと回る。むき出しの銅線を巻くと、触れたところで電流が近道してしまい（ショート）、コイルを回る回数が減って磁力が出なくなる。答えの中心は「電気を通さない」の5文字。「とそう（塗装）」や「ぬってある」だけでは、何のためにぬったのかが言えていない。
答え：説明＝銅線のまわりに電気を通さないものをぬった線。／不都合＝コイルに巻いた際に銅線どうしが接すると電流が流れてショートしてしまう。
今回：説明「銅線にとそうをぬった線。」×。不都合「すぐにショートする。」は内容が合っている。説明のほうを「電気を通さないものをぬった線」と書ければ、両方そろった。

  • 落としたのは記述の(1)(2)と(7)の説明。どれも「もう一段先」を書けば届いた。長さ→抵抗（電流）、量→個数を比べる、ぬった→電気を通さないものをぬった。

確認3 (1) 方位磁針B〜Dの針の向き 図に書き込む・磁力線

👀 まず見るところ

見本のA。Aは棒磁石のN極の正面にあり、針の黒い方（N極）が左＝棒磁石から遠ざかる向きを指している。同じ極は反発するので当然の向きで、Cは反対側（S極の正面）だから、Aとは逆に考えればよい。BとDは棒磁石の「横」にあるので、正面とは別の考え方がいる。

📚 前提知識

  • 磁力線はN極から出てS極に入る。方位磁針を置くと、針のN極は磁力線の向きを指す。
  • 棒磁石の横（真ん中の上や下）では、磁力線はN極からS極へ向かって棒磁石と平行に走る。解答冊子の磁力線の図で、棒磁石の上下に並んだ方位磁針の針がすべて「N極→S極の向き」を指しているのがそれ。

🔍 こう読み解く

  2. B・D（棒磁石の横）：磁力線はN極（左）からS極（右）へ流れるので、針のN極は右を向く。針は水平のまま。
  3. 書き終えたら確かめ：Aは黒が左、Cは黒が左、B・Dは黒が右。「Cの黒はAと同じ左」が最初はひっかかりやすいので、Cは「S極にN極が引かれる」で決める。
答え：解答冊子の「(1)の答え」の図（B・Dは針のN極が右＝S極の側を向く、CはN極が左＝棒磁石の側を向く。3つとも水平）
今回：○。B・C・Dとも黒い方の向きが図と一致している。横の位置にある針の向きが分かっていた。

確認3 (2) 棒磁石を1回転させたときの針の回転方向 図に書き込む・動きの追跡

👀 まず見るところ

見本のAの矢印。Aの下の「回転方向」の矢印は左から右へ、つまり反時計回りで、棒磁石（時計回り）とは逆に書かれている。ここで「針は棒磁石と同じ向きには回らない」と気づいてから、なぜそうなるかを1つの磁針で確かめ、B〜Dへ広げる。棒磁石を少しだけ（ほんの数度）時計回りに回したとき、どの極がどの磁針に近づいてくるかを見る。

📚 前提知識

  • 針は、近づいてくる極を追いかけて回る。N極が近づけば針のS極が、S極が近づけば針のN極がそちらへ向く。
  • 1回転の途中で止まって考えず、「最初の少しの動き」で回転方向を決めれば、あとは同じ向きに回り続ける。

🔍 こう読み解く

  1. B：棒磁石が時計回りに少し動くと、左にあったN極が上へ、つまりBの方へ近づいてくる。Bの針は黒（N極）が右、S極が左を向いているので、左を向いていたS極が下（棒磁石のN極の方）へ引かれる。左を向いた端が下へ動く回り方は反時計回り。
  2. D：同じ動きで、右にあったS極が下へ、Dの方へ近づく。Dの針は右を向いたN極が上（S極の方）へ引かれる → 右の端が上へ動くのは反時計回り。
  3. C：右にあったS極がCから下へ離れていく。Cの針のN極（左向き）はそのS極を追って下へ動く → 左の端が下へ動くのは反時計回り。3つとも反時計回りで、解答冊子の図の太い矢印と一致する。
答え：解答冊子の「(2)の答え」の図（B・C・Dとも反時計回り）
今回：×。Cは反時計回りで合っているが、BとDを時計回りに書いていて、採点者が赤で反時計回りの矢印を書き足している。「棒磁石と同じ向きに回る」と決めてしまったのだと思う。見本のAが反時計回りで書かれているのが、そうではない合図だった。次は、棒磁石を少しだけ回して「どの極がその磁針に近づくか → 針のどちらの端が引かれるか」を1つずつ確かめてから矢印を書く。
コツ：「針の端が、近づいてくる極の方へ動く」を1つの磁針で試すと、残りも同じ手順で決まる。棒磁石の回転方向をそのまま写さない。

発展2 (1) 電池を逆につないだときの先端の極 図の読み取り・右手

👀 まず見るところ

問題文の「N極が引き寄せられました」。引き寄せられるのはちがう極どうしだから、いまの先端はS極。図1の巻き方を追わなくても、ここだけで現在の極が決まる。

📚 前提知識

  • 電磁石の極は電流の向きで決まる。電池の＋と−を入れかえると、コイルを流れる電流の向きが逆になり、N極とS極が入れかわる。
  • 磁石はちがう極どうしが引き合い、同じ極どうしは反発する。方位磁針のN極が寄ってきた側はS極。

🔍 こう読み解く

  1. N極が引き寄せられた → いまの先端はS極。
  2. 電池を逆にする → 電流が逆 → 極も逆。S極だった先端はN極になる。
答え：N極
自分で解くときのチェック：「引き寄せられた」を「ちがう極」に言いかえてから考える。方位磁針のN極が寄る＝そこはS極。

発展2 (2)ⅰⅱ 図2のコイルb・cの先端の極 電流の通り道＋右手

👀 まず見るところ

図2の3本の「電流」の矢印と、金属板A・Bがどの部品にふれているか。Aは①と③に、Bは②にふれている。問題文にコイルbは「①→b→②」、コイルcは「③→c→②」と通り道が書いてあるので、この2本の道を図2でなぞる。

📚 前提知識

  • 金属板A・Bは動かない板（ブラシ）、部品①〜③は軸といっしょに回る金属片（整流子のはたらき）。板がふれている部品だけに電流が出入りする。
  • 右手の使い方：4本の指をコイルの手前側（斜線）に流れる電流の向きに合わせてにぎると、親指の先がN極。反対側の端がS極。
  • コイルaのように両端が同じ極（①も③も＋）につながると、電流は流れず磁石にならない。(2)の文章の1つ目がそれを教えている。

🔍 こう読み解く

  1. コイルb：①から出た電流はコイルbの上側の線を通って先端まで行き、手前の斜線を下から上へ流れて②へ戻る（解答冊子の図3の矢印が同じ向き）。右手の4本の指を「下から上」に合わせると、親指は軸のほうを向く。軸側がN極、先端はS極。
  2. コイルc：③から出た電流は先端まで行き、手前の斜線を右から左へ流れて②へ戻る。右手を合わせると親指は先端のほうを向く。先端はN極。
  3. 確かめ：bとcは同じ向きに巻いた同じコイルなのに極がちがう。bは①→②、cは③→②と入る部品がちがうから。ここを押さえると(3)(4)が速くなる。
答え：ⅰ S　ⅱ N
自分で解くときのチェック：3つのコイルは同じ巻き方なので、「部品の番号を時計回りの隣へ流れる（①→②、③→①）ならS、逆向き（③→②）ならN」と覚えておくと、(3)(4)は右手を使わずに答え合わせができる。

発展2 (3) 図3のコイルa・b・cの先端の極 電流の通り道＋右手

👀 まず見るところ

図3で金属板A・Bがどの部品にふれているか。図2から時計回りに少し回って、Aは③だけ、Bは②だけにふれ、①はどちらにもふれていない。つまり電流は③から入って②へ出る。これを決めてから、(2)の文章と同じ形で通り道を書く。

📚 前提知識

  • コイルの両端がつながる部品：a＝①と③、b＝①と②、c＝③と②。図2の(2)の文章から読み取れる。
  • 電流は行き止まりには流れない。①に板がふれていなくても、aを通って①に来た電流はbを通って②へ抜けられるので、aとbは直列で流れる。

🔍 こう読み解く

  1. 通り道は2本。＋極→A→③→a→①→b→②→B→−極 と、＋極→A→③→c→②→B→−極。
  2. コイルa：③→①。手前の斜線を右手でなぞると（解答冊子の図3で矢印は上から下）、親指は軸のほう → 先端はS極。
  3. コイルb：①→②。(2)と同じ向きなので、(2)と同じS極。
  4. コイルc：③→②。(2)と同じ向きなので、(2)と同じN極。
答え：a S極　b S極　c N極
自分で解くときのチェック：まず「Aは何番、Bは何番」を図の下に書く。b・cは(2)の答えを使い回せるので、右手を使うのはaだけでよい。

発展2 (4) 図4のコイルa・b・cの先端の極 電流の通り道＋×の見きわめ

👀 まず見るところ

図4で金属板Bが①と②の2つにふれている（Aは③だけ）。①も②も−極側になったので、①と②の間にあるコイルbは両端が同じ極。図2のコイルaと同じ状態なので、bが×だとここで見当がつく。

📚 前提知識

  • 両端が同じ極につながったコイルには電流が流れない。(2)の文章「コイルaの両端はともに＋極へつながっているため、磁石の性質をもたない」を−極に置きかえて使う。
  • 解答冊子の言い方では「コイルbの両端は、コイルa・コイルcの両方から電流が流れ、うち消しあう」。どちらの言い方でも、結論は「電流が流れない＝極なし」。

🔍 こう読み解く

  1. 通り道は2本。＋極→A→③→a→①→B→−極 と、＋極→A→③→c→②→B→−極。今回は①にBがふれているので、aを通った電流はbへ行かず①からそのままBへ出る。
  2. コイルa：③→①。(3)と同じ向きなのでS極。
  3. コイルc：③→②。(2)(3)と同じ向きなのでN極。
  4. コイルb：両端①②がどちらも−極側 → 電流が流れない → ×。
答え：a S極　b ×　c N極
自分で解くときのチェック：1枚の板が2つの部品にふれていたら、その2つの部品の間のコイルが×。図2ではA（①③）→a、図4ではB（①②）→b。

発展2 (5) 時計回りに回し続ける磁石の置き方 (3)(4)の結果を使う・選択

👀 まず見るところ

ア・イは磁石が上下、ウ・エは左右。(2)〜(4)で×になったコイルは、図2では左を向いたa、図4では右を向いたb。つまり左右は「コイルが極を失う位置」で、ここが磁石の置き場所になる。まずウ・エにしぼり、あとは向きを決めるだけ。

📚 前提知識

  • モーターが回り続けるには、磁石の正面に来たコイルが磁石にくっついて止まらないことが必要。正面で極を失うコイルは引き止められず、勢いで通り過ぎる。だから磁石は「コイルが極を持たないところ」に置く（解答冊子の説明）。
  • 回転の向きは、極を持って近づいてくるコイルが「引かれる」向きで決まる。時計回りに図2→図3→図4と動くので、図3・図4で近づいているコイルの極を使う。

🔍 こう読み解く

  1. 図3のコイルb（右上・S極）は時計回りに右の磁石へ近づいていく。引き寄せるには右の磁石のコイル側をN極にする。
  2. 図4のコイルc（左下・N極）は時計回りに左の磁石へ近づいていく。引き寄せるには左の磁石のコイル側をS極にする。
  3. 左の磁石はコイル側がS、右の磁石はコイル側がN。この組み合わせはウ。エはどちらも逆で、反時計回りに回る。
答え：ウ
自分で解くときのチェック：図2でも確かめられる。ウの右の磁石（コイル側N）は、右上のb（S）を引き、右下のc（N）を押す。どちらも時計回りの力になっている。
