N63-02 CP（コアプラス確認テスト 範囲454〜476・人体①（呼吸・消化））

CP 全体像 コアプラス確認テスト 10問・人体①（呼吸・消化）

範囲は人体①（呼吸・消化）。(1)〜(4)が呼吸（肺胞の気体のやりとり・はく息の二酸化炭素・呼吸運動の模型と横隔膜）、(5)〜(8)が消化と吸収（肝臓とたん汁・すい液で消化できる栄養・柔毛の大きさと毛細血管に入る栄養）、(9)(10)がセロハンの袋の実験（でんぷんと麦芽糖のどちらが袋を通るか）。

図のある問は、線の先が何の器官か・矢印がどちら向きかを先に図へ書きこむと、知識の出番が1つにしぼれる。

CP (1) 肺胞の図の●は何の気体か 資料問題・矢印の向き

👀 まず見るところ

【資料問題】部品は図の「血管の矢印の向き」。血液は右上から入り、左へ出ていくと図に書く → 入ってくる血液に●が多く、●は血液から肺胞へ出されている。出されるのは二酸化炭素と決まる。

📚 前提知識

  • 肺胞では、血液が運んできた二酸化炭素を肺胞の中へ出し、肺胞の中の酸素を血液に取りこむ。肺胞がたくさんあるのは、気体をやりとりする面積を広げるため。
  • 肺胞に入ってくる血液は二酸化炭素が多く、出ていく血液は酸素が多い。

🔍 こう読み解く

  1. 血管の矢印をたどる。右上から入り、肺胞のまわりを回って左へ出る。
  2. 右側（入る側）の血液には●が並び、点線の矢印は●が血液から肺胞の中へ向かっている → ●は血液が捨てる気体＝二酸化炭素。
  3. 左側（出る側）の血液には○が並び、○は肺胞から血液へ入っている → ○が酸素。鼻や口への点線は、●をはく息として外へ出す向き。
答え：二酸化炭素
今回：二酸化炭素 ○。

CP (2) はく息にふくまれる二酸化炭素の割合 知識問題

約4%。吸う息の二酸化炭素は約0.04%、はく息は約4%で、およそ100倍にふえる。0.04は吸う空気のほうの数字、40%は多すぎる（はく息でもほとんどはちっ素と酸素）。「吸う0.04 → はく4」と2つ組で覚える。
答え：4
今回：4 ○。

CP (3) 糸を下に引くと容器内の気圧と風船はどうなるか 資料問題・呼吸運動の模型

👀 まず見るところ

【資料問題】部品は図の「ゴム膜」と「糸を下に引く」。ゴム膜が下がる矢印を図に置く → 容器の中が広がるので気圧は下がる。気圧が下がると外の空気が風船へ入り、ふくらむ。

📚 前提知識

  • 同じ量の空気で部屋が広がると、空気がうすくなって気圧は下がる。外のほうが気圧が高くなるので、管を通って空気が風船に流れこむ。
  • この装置はヒトの呼吸の模型。風船＝肺、ガラス容器＝胸、ゴム膜＝横隔膜。横隔膜が下がると息を吸い、上がると息をはく。

🔍 こう読み解く

  1. 糸を下に引く → ゴム膜が下へ引かれ、ガラス容器の中の空間が広がる。
  2. 空間が広がる → 中の空気がうすくなる → 気圧は下がる（①）。
  3. 外の空気のほうが気圧が高い → 上の管から空気が入り、風船はふくらむ（②）。これが息を吸う動き。
答え：① 下がる　② ふくらみ
今回：① 下がる　② ふくらみ ○。

CP (4) 図2のゴム膜にあたるからだの部分 知識問題

横隔膜。肺の下にある筋肉の膜で、下がると胸が広がって息を吸い、上がると息をはく。模型では風船＝肺、ガラス容器＝胸、ゴム膜＝横隔膜の対応で覚える。漢字は「横隔膜」。
答え：横隔膜
今回：横かくまく ○。次は漢字で「横隔膜」と書けるようにしておく。

CP (5) 図3のEの内臓と、そこでつくる消化液 資料問題・器官の位置

👀 まず見るところ

【資料問題】部品は「図のE」の線の先。横隔膜のすぐ下、図の左側（からだの右側）にあるいちばん大きな内臓に丸 → 肝臓と決まる。肝臓がつくる消化液は1つ、たん汁。

📚 前提知識

  • 肝臓はからだの中でいちばん大きな内臓で、横隔膜の下・からだの右側にある。たん汁をつくり、たんのうにためてから十二指腸へ出す。
  • たん汁は消化酵素をふくまないが、脂肪を細かい粒にして、すい液が脂肪を消化するのを助ける。

🔍 こう読み解く

  1. Eの線の先は、横隔膜（F）の下にある大きな内臓 → 肝臓（①）。Gはその下のたんのう、Hは胃。
  2. 肝臓がつくる消化液はたん汁（たん液）（②）。胃液やすい液と取りちがえない。
答え：① 肝臓　② たん汁（たん液）
今回：① かんぞう　② たん汁 ○。

CP (6) 図3のJの消化液で消化できる栄養 資料問題・器官と消化液

👀 まず見るところ

【資料問題】部品は「図のJ」の線の先。胃の下にかくれた細長い器官＝すい臓と図に書く → すい液は、でんぷん・たんぱく質・脂肪の3つすべてを消化する。答えは全部○。

📚 前提知識

  • 消化液と消化する栄養の組：だ液→でんぷん／胃液→たんぱく質／すい液→でんぷん・たんぱく質・脂肪／腸液→でんぷん・たんぱく質。3つすべてを消化するのはすい液だけ。
  • 脂肪を消化できるのはすい液だけ。たん汁は脂肪を細かくして手伝うが、自分では消化しない。

🔍 こう読み解く

  1. Jの線は、胃（H）の下で横に長くのびた器官に向かっている。小腸（K）や大腸（L）ではない → すい臓。
  2. すい臓がつくる消化液はすい液。消化できるのは3つ全部 → ①でんぷん ○、②たんぱく質 ○、③脂肪 ○。
答え：① ○　② ○　③ ○
今回：① ○　② ○　③ × ×（③がちがう）。知識＝「すい液は3つすべて」が抜けた形。①②○・③×は腸液の組なので、Jを小腸と見た可能性もある。次はJの線の先をたどり、図に「すい臓」と書いてから消化液を決める。

CP (7) 柔毛の長さ 知識問題

約0.1cm（約1mm）。柔毛は小腸の内側のひだに無数に生えている小さな突起で、長さは1mmほど。小腸の内側の面積を大きくして、栄養を吸収しやすくしている。1cmは指の幅ほど、10cmは手のひらより大きく、どちらも腸の中に生える突起としては大きすぎる。
答え：0.1
今回：0.1 ○。

CP (8) 柔毛の毛細血管に吸収される栄養 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問の「毛細血管」と「すべて」に丸。図4の柔毛の中には毛細血管とリンパ管の2本の管がある → 4つの栄養を「消化後の形か／どちらの管か」で全部○×をつける。

📚 前提知識

  • 柔毛の中には2種類の管がある。ブドウ糖とアミノ酸は毛細血管に入り、肝臓へ運ばれる。脂肪酸（とモノグリセリド）はリンパ管に入る。
  • 吸収されるのは消化が終わった小さな粒だけ。でんぷんは大きな粒のままなので吸収されず、ブドウ糖に分解されてから吸収される。

🔍 こう読み解く

  1. ア アミノ酸：たんぱく質の消化後の形で、毛細血管に入る → ○。
  2. ウ ブドウ糖：でんぷんの消化後の形で、毛細血管に入る → ○。
  3. イ 脂肪酸：消化後の形だが、入るのはリンパ管 → ×。エ でんぷん：消化前の大きな粒で、吸収されない → ×。
答え：ア・ウ
今回：ア・ウ ○。

CP (9) セロハンの袋の実験・ヨウ素液の反応 まざり型・袋を通る粒

👀 まず見るところ

【まざり型→条件文】部品は「37℃で十分時間」と「セロハンの袋」。図のAに「でんぷん→麦芽糖」、袋に「小さい粒だけ通る」と直して書く → 時間がたてばAにでんぷんは残らず、Bにも入らない。ヨウ素液はどちらも変化しない。

📚 前提知識

  • だ液はでんぷんを麦芽糖に消化する。はたらきが強いのは体温に近い37℃で、十分な時間を置けばでんぷんは全部麦芽糖になる。
  • セロハンには目に見えない小さな穴があり、麦芽糖のような小さい粒は通るが、でんぷんのような大きい粒は通れない。小腸の壁と同じしくみ。
  • ヨウ素液はでんぷんがあると青紫色になる。麦芽糖には反応しない。

🔍 こう読み解く

  1. A（袋の中）：37℃で十分時間 → だ液がでんぷんを全部麦芽糖にした → でんぷんなし → ヨウ素液は変化しない → ×。
  2. B（袋の外の水）：でんぷんは大きくてセロハンを通れない。消化が終わる前にも外へは出ていない → でんぷんなし → ×。
答え：A ×　B ×
今回：A ×　B ○ ×（Bがちがう）。知識＝セロハンを通れる粒の大小。でんぷんは大きい粒で袋の外には出られない。次は袋の線の横に「大きい粒×・小さい粒○」と書いてからA・Bを決める。

CP (10) セロハンの袋の実験・ベネジクト液の反応 条件文・(9)と変わった部品

👀 まず見るところ

【条件文】(9)と変わった部品は「ベネジクト液」「加熱」に丸 → 調べる相手が、でんぷんから麦芽糖に変わる。麦芽糖はAでできて、小さい粒なので袋を通ってBにも出ている。

📚 前提知識

  • ベネジクト液は麦芽糖やブドウ糖があるとき、加熱すると赤褐色の沈殿ができる。でんぷんには反応しない。
  • (9)で書いた「小さい粒だけ通る」をそのまま使う。麦芽糖はセロハンを通って外の水に広がる。

🔍 こう読み解く

  1. A（袋の中）：でんぷんが消化されて麦芽糖がある → 赤褐色に変化 → ○。
  2. B（袋の外の水）：麦芽糖は小さいのでセロハンを通りぬけ、水の中にも出ている → 赤褐色に変化 → ○。
  3. (9)と(10)をセットで見る：でんぷん（大）は袋の中で消えて外にも出ない＝×× ／ 麦芽糖（小）は中でできて外にも出る＝○○。
答え：A ○　B ○
今回：A ○　B × ×（Bがちがう）。知識＝(9)と同じく、袋を通れるのが「小さい粒＝麦芽糖」であることが逆になっている。(9)B○・(10)B×は、でんぷんが通って麦芽糖が通らない形。次は袋の横に書いた「大きい粒×・小さい粒○」を(10)でも見てから答える。

CP まとめ 70点（10問中7問）

  • 取れた：(1)〜(5)(7)(8)。呼吸のしくみと、器官の位置・消化後の形の仕分けはできている。
  • 落とした3問は、消化の知識2つ。(6)すい液はでんぷん・たんぱく質・脂肪の3つすべてを消化する。(9)(10)セロハンを通れるのは小さい粒（麦芽糖）だけで、でんぷんは通れない。
  • 覚え直しはこの2行：すい液＝3つ全部（脂肪を消化できるのはすい液だけ）／セロハン＝小さい粒○・大きい粒×（ヨウ素液→でんぷん、ベネジクト液→麦芽糖）。
