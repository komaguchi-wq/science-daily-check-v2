L (1) 酸素を集める方法 資料問題・気体の集め方

👀 まず見るところ

【資料問題】部品は「酸素を集める」と、図の正体「ア＝びんを下向き・イ＝びんを上向き・ウ＝水の中」を1行。酸素は水にとけにくい、と直して書く → 水と置きかえて集めるウと決まる。

📚 前提知識

  • 気体の集め方は「水にとけにくいか」で先に分ける。とけにくい気体（酸素・水素・ちっ素）は水上置換。水と置きかえるので、空気がまざらず、たまった量が目で見える。
  • 水にとけやすい気体は、空気より重いか軽いかで分ける。空気より重い（二酸化炭素・塩化水素）は上方から入れて下にためる下方置換（イの形）、空気より軽い（アンモニア）は上方置換（アの形）。

🔍 こう読み解く

  1. 酸素は水にとけにくい → 水上置換が使える。
  2. 図で水そうと「集気びんのふた」があるのはウだけ。びんの中の○は、たまっていく酸素のあわ。
  3. アは上方置換（アンモニア）、イは下方置換（二酸化炭素）の形。酸素は水にとけにくいので、わざわざ空気の重さで分ける必要がない。
答え：ウ
今回：ウ ○。

L (2) 発生中の過酸化水素水と二酸化マンガン 知識問題

① ア（うすくなっていき）　② イ（変わりません）。酸素のもとは過酸化水素水で、過酸化水素が水と酸素に分かれるので、発生が進むほど液はうすくなる。二酸化マンガンは自分は変化せず、分かれるのを助けるだけ（触媒）なので、量も性質も変わらず、あとでもう一度使える。「減るのは材料のほう、減らないのは助けるほう」で組にして覚える。
答え：① ア　② イ
今回：① ア ○　② イ ○。

L (3) 赤色リトマス紙の色が変わらない液性 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「赤色リトマス紙」と「変わらない」に丸。赤を青に変えるのはアルカリ性だけ、と1行書く → 変わらないのは残りの酸性と中性の2つと決まる。

📚 前提知識

  • リトマス紙は「赤→青がアルカリ性、青→赤が酸性」。中性はどちらも変えない。
  • 「変わらない」と聞かれたら、変える液性を1つ決めて、それ以外を答える。酸性は赤色リトマス紙を赤のままにしておく（変えるのは青色リトマス紙のほう）。

🔍 こう読み解く

  1. 赤色リトマス紙を変える（青にする）のはアルカリ性だけ → ウは×。
  2. 酸性は赤を赤のまま、中性も変えない → ア・イ。
答え：ア・イ
今回：アイ ○。

L (4) ①〜⑥のうちアルカリ性の水溶液 知識問題

②・③・⑤。アルカリ性はアンモニア水・重そう水・石灰水（ほかに水酸化ナトリウム水溶液）。重そう（炭酸水素ナトリウム）は弱いアルカリ性で、ホットケーキのふくらし粉。酸性は⑥炭酸水（二酸化炭素がとけた水）、中性は①アルコール水と④食塩水。「炭酸水は酸性・重そう水はアルカリ性」を組で覚える。
答え：②・③・⑤
今回：②③⑤ ○。

L (5) 現在の空気中の二酸化炭素濃度 知識問題

エ（0.04%）。空気の成分はちっ素約78%・酸素約21%で、残り1%の中にアルゴンと二酸化炭素がある。二酸化炭素は約0.04%（400ppm台）で、少ないながら年々増えている。「4%」と取りちがえない。4%もあれば、はく息（約4%）と同じ濃さになる。
答え：エ
今回：エ ○。

L (6) ア〜エで発芽するもの 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】図の正体「ア〜エ＝温度・脱脂綿（乾いた／湿らせた）・箱・照明のちがい」を表にして1行。発芽の3条件「水・空気・適温」に照らす → 湿らせた脱脂綿で25℃のイ・ウだけ発芽、と決まる。

📚 前提知識

  • 発芽に必要なのは水・空気・適温の3つ。光と肥料はいらない（種子の中の養分で芽を出すので、土も肥料も要らない）。
  • 水は、種子が水を吸ってふくらみ、たくわえた養分を使える形に変えるために必要。温度は低すぎると種子のはたらきが止まる。

🔍 こう読み解く

  1. ア：25℃・乾いた脱脂綿 → 水がない → ×。
  2. イ：25℃・湿らせた脱脂綿 → 水・空気・適温そろう → ○。
  3. ウ：25℃・湿らせた脱脂綿・箱で暗い → 光はいらないので ○。
  4. エ：5℃の冷蔵庫・乾いた脱脂綿・照明あり → 水がなく低温 → ×。
答え：イ・ウ
今回：イウ ○。

L (7) ア〜エの結果から分かる発芽の条件 資料問題・対照実験

👀 まず見るところ

【資料問題】部品は「ア〜エの結果から」「分かる条件」に丸。知っている条件ではなく、図でちがいが1つだけの組を表からさがす → ア・イ（乾いた／湿らせた）で水、イ・ウ（箱）で光がいらない、と決まる。温度は1つだけちがう組がない。

📚 前提知識

  • 実験から「この条件が必要」と言えるのは、その条件だけを変えて、ほかを全部そろえた2つを比べたときだけ（対照実験）。2つ以上ちがうと、どちらが原因か決められない。
  • 「分かる条件」は「必要な条件」と別物。発芽に適温が必要なのは本当でも、この図に温度だけを変えた組がなければ、「分かる」とは言えない。

🔍 こう読み解く

  1. ア（乾いた・25℃・明るい）とイ（湿らせた・25℃・明るい）：ちがいは水だけ。アは発芽せずイは発芽 → 水が必要と分かる → イ。
  2. イとウ：ちがいは箱（光）だけ。どちらも発芽 → 光はいらないと分かる。エは答えに入らない。
  3. 温度：5℃のエは乾いた脱脂綿でもあるので、イと2つちがう（水と温度。照明は冷蔵庫の中を部屋と同じ明るさにするためのもの）。エが発芽しなかった理由を温度と決められない → ウは入れない。
  4. 空気・肥料は、どの図でも変えていないので分からない。答えはイだけ。
答え：イ
今回：イウ ×。部品を拾えなかった＝「ア〜エの結果から分かる」でなく、知識の「水・空気・適温」から答えた。次は図を表に写して、ちがいが1つだけの組（ア・イ）に線を引いてから選ぶ。
コツ：「〜の結果から分かる」と書かれていたら、答えは図の中にしかない。先に「1つだけちがう組はどれとどれか」を余白に書く。

L (8) 植物が光合成に使う物質 知識問題

二酸化炭素・水。光合成は、葉の緑の粒（葉緑体）で、気孔から入った二酸化炭素と根から吸った水を、光の力ででんぷんと酸素に変えるはたらき。「入るのは二酸化炭素と水、出るのはでんぷんと酸素」と向きを組で覚える。光は材料でなく、はたらきに使うエネルギー。
答え：二酸化炭素・水（順不同）
今回：水・二酸化炭素 ○。

L (9) 暗い所に置いたオオカナダモとBTB液の色 条件文・BTB液

👀 まず見るところ

【条件文】部品は「息を吹き込んで緑色」と「暗いところ」に丸。暗い＝光合成なし・呼吸だけ、と直して書く → 二酸化炭素が増えて酸性にかたむき、緑から黄と決まる。

📚 前提知識

  • BTB液は 酸性＝黄・中性＝緑・アルカリ性＝青。二酸化炭素が水にとけると炭酸水になり酸性にかたむくので、二酸化炭素が増えると黄、減ると青にもどる。
  • 植物は昼も夜も呼吸をしている。明るい所では光合成で取り込む二酸化炭素のほうが多いので青へ、暗い所では呼吸だけなので黄へ。

🔍 こう読み解く

  1. はじめに息を吹き込んで緑＝二酸化炭素が少し入った中性のスタート。
  2. 暗いところ → 光合成は止まり、呼吸だけ → オオカナダモが二酸化炭素を出す。
  3. 二酸化炭素が増える → 酸性に → 緑から黄色。もし明るい所なら、二酸化炭素が減って青になる。
答え：黄色
今回：黄 ○。

L (10) 色が変わった原因 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「呼吸によって」に丸。呼吸＝酸素を取り入れ二酸化炭素を出す、と3語で書く → 色を変えたのは放出した二酸化炭素と決まる。(9)の黄色とつながる。

📚 前提知識

  • 呼吸は「酸素を吸収して二酸化炭素を放出」、光合成はその逆向き。BTB液の色を動かすのは二酸化炭素のほうで、酸素はとけても色を変えない。

🔍 こう読み解く

  1. (9)で黄色になった＝酸性になった＝二酸化炭素が増えた。
  2. 二酸化炭素が増えるのは、呼吸で放出したから → ① 放出　② 二酸化炭素。
  3. 「吸収した酸素」では、酸素が減っても色は変わらないので合わない。
答え：① 放出　② 二酸化炭素
今回：① 放出 ○　② 二酸化炭素 ○。

M (1) オキシドールと二酸化マンガン 知識問題

① 水　② 触媒。過酸化水素は酸素と水に分かれる。二酸化マンガンは分解を速めるだけで自分は変化せず、反応のあとも同じ量が残る。このはたらきをする物質を触媒という。だから二酸化マンガンを増やしても、出てくる酸素の全体の量は変わらず、出る速さだけが変わる。
答え：① 水　② 触媒
今回：① 水 ○　② しょくばい ○。ひらがなで○がついている。次は「触媒」と漢字で書けるようにする。

M (2) 図1の気体検知管は何用か 資料問題・目盛りで見分ける

👀 まず見るところ

【資料問題】部品は図2の目盛りの正体「6〜24・%」を1行。空気中の酸素は約21%なので、21がこの目盛りの中に入る＝酸素用と決まる。二酸化炭素は空気中に約0.04%しかないので、この目盛りでは測れない。

📚 前提知識

  • 気体検知管は、測りたい気体の濃さに合った目盛りがついている。空気中の酸素は約21%、二酸化炭素は約0.04%。測る気体で目盛りの大きさがまるでちがう。
  • 酸素用は色が変わった所の右端の数字（%）を読む。息をはいた空気を測ると、酸素は21%より少し小さい値になる。

🔍 こう読み解く

  1. 図2の目盛りは 6・8・10・…・24 で、単位は「%」。
  2. 21%（空気中の酸素）がこの範囲（6〜24）に入る → 酸素の濃さを測る管。0.04%の二酸化炭素は入らない。
  3. 確かめ：図2で色が変わっているのは21の少し手前まで。空気の酸素約21%と合う。
答え：酸素
今回：酸素 ○。

M (3) 気体検知管の折る端と差し込む端 資料問題・図の矢印

👀 まず見るところ

【資料問題】部品は図1の右側に書かれた「採取器→」の矢印と、管の両端が閉じた形。空気を通すには両端を折る、採取器の文字がある右端を差し込む、と図に丸をつければ決まる。

📚 前提知識

  • 気体検知管はガラスの管で、両端が閉じている。空気を通すには、両方の端を専用の器具で折る。
  • 気体採取器のハンドルを引くと、管の先から空気が吸いこまれて検知剤を通る。管には流れの向きを示す「G▶」の矢印があり、矢印の先（採取器）側を採取器に差し込む。

🔍 こう読み解く

  1. ① 片方だけ折っても空気は通らない → 両端。
  2. ② 図1で「採取器→」と書かれているのは右側 → 右端を採取器に差し込む。空気は左端から入り、検知剤を通って右へ流れる。
答え：① 両　② 右
今回：① 両 ○　② 右 ○。

M (5) 牛のげっぷに含まれる温室効果ガス 知識問題

① メタン　② 水（水蒸気）。メタンは天然ガスの主成分で、牛のげっぷや水田からも出る温室効果ガス。炭素と水素でできているので、燃やすと炭素は二酸化炭素に、水素は水になる。ろうそく・アルコール・都市ガスなど、炭素と水素をふくむものが燃えたときは、いつもこの2つができる。

M (6) 北半球の夏の二酸化炭素濃度 素材文・増加か減少か

👀 まず見るところ

【素材文】部品は「北半球で夏」と「二酸化炭素濃度」に丸。夏を「植物の葉がしげって光合成がさかん」に直して書く → 二酸化炭素が使われて減少と決まる。

📚 前提知識

  • 植物は光合成で二酸化炭素をとり入れる。葉が多い夏は吸収が多く、葉が落ちる冬は吸収が減るので、大気中の二酸化炭素は夏に減り、冬に増える。1年ごとの小さなぎざぎざになる。
  • 北半球は陸地と森林が多いので、北半球の季節で地球全体の増減が決まる。長い目で見ると、化石燃料を燃やす分で年々増え続けている。

🔍 こう読み解く

  1. 「夏＝暑い＝増える」ではなく、「夏＝葉がしげる＝光合成が多い」と言いかえる。
  2. 光合成が多い → 二酸化炭素がよく使われる → 濃度は減少。冬はその反対で増加。
答え：減少
今回：増加 ×。知識＝「夏」を「植物の光合成がさかん」に結びつけられなかった。二酸化炭素の増減は、気温でなく植物の光合成で考える。(9)(10)と同じ筋。

M (7) アルカリ性の液をすべて選ぶ 素材文・すべて選ぶ

👀 まず見るところ

M (8) 種子の乾燥重量のグラフと光合成のはじまり 資料問題・グラフの減り方

👀 まず見るところ

【資料問題】部品はグラフの正体「種子のX重量・まいてからの日数」と、聞かれ方「光合成がはじまったのは」。「はじまった」を「減り方がゆるくなった点」に直して書く → 2〜4日の急な減りが、4日からゆるむので4日と決まる。

📚 前提知識

  • 種子の重さは水の分でふらつくので、水をとばした乾燥重量で養分の量をはかる。発芽前の0〜2日は水を吸うだけで、乾燥重量は変わらない。
  • 発芽すると呼吸で養分を使い、乾燥重量は減る。葉が開いて光合成がはじまると、作る分が足されて減り方がゆるくなり、作る分が呼吸で使う分をこえた所から増えはじめる。

🔍 こう読み解く

  1. ① 水をとばした重さ → 乾燥重量。「養分」は重さの名前ではない。
  2. ② 2日→4日は1目盛り以上の急な減り（呼吸だけ）。4日→6日→8日は減り方がだんだん小さくなる → 光合成が足されはじめたのは4日ごろ。
  3. 8〜10日の底は「光合成＝呼吸」、10日からの増加は「光合成＞呼吸」。光合成がはじまったのは底よりずっと前。
答え：① 乾燥　② 4日
今回：① 養分 ×　② 8 ×。部品の形を直さなかった＝「光合成がはじまった」を「増えはじめた」に置きかえて底の8日を読んだ。正しくは「減り方がゆるくなった点」。グラフの各区間の減り幅を数字で書くと4日で変わるのが見える。

  • 1g＝1000mg。0.00128g×1000＝1.28mg。単位をそろえてから比べる。
  • ヒラメの重さとDDTの量は比例する（同じ濃さなので）。1000gで1.28mgなら、0.32mgはその 0.32÷1.28＝1/4 の重さ。

🔍 こう読み解く

  1. ①の 0.00128g を mg に直す → 1.28mg（1000gあたり）。
  2. 0.32mg は 1.28mg の 1/4 → ヒラメも 1000g の 1/4。
  3. 1000÷1.28×0.32＝250g。解答冊子と同じ式。
答え：250g
今回：無記入 ×。①が決まらなかったので手がつかなかった。②は①の答えがなくても「1000gに1.28mg（＝1.28ppm×1000g）」から出せるので、①で止まっても②の式を書く。
コツ：ppmの問題は「÷1000000」「g⇄mg は×1000」の2行を先に余白に置くと、①②が同じ道でつながる。
