DC1 (1)① 太さが一様でない棒の重心 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様でない棒」「左端から何cm」に丸と、図1の「60g」「10g」。棒の重さ 60−10＝50g を、まだ場所の分からない矢印として図に置く（直して書く）→ ばねばかりを支点にしたつり合いで、矢印の場所が決まる。

📚 前提知識

  • つり合っている棒では、上向きの力の合計＝下向きの力の合計。ばねばかり60gが支えているのは、10gのおもりと棒の重さなので、棒は50g（解答冊子）。
  • 太さが一様でない棒は、重心がまん中にない。重心の場所は「どこにあれば回転のつり合いが取れるか」で逆算する。

🔍 こう読み解く

  1. ばねばかりは棒のまん中（左端から60cm）。ここを支点にする。
  2. 左回り：10g×60cm＝600。右回りも600になる場所に棒の50gを置く → 600÷50＝12cm、支点の右。
  3. 左端からは 60＋12＝72cm（解答冊子の式「60＋12＝72」）。
答え：72cm
今回：72 ○。図1の横に「50」と「60」が書いてあり、棒の重さを先に出してから位置を逆算できている。

DC1 (1)② ばねばかりXの示す値 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様な120gの棒」と、図2の「20cm・20cm・80cm」。棒の120gは左端から60cm（まん中）に矢印で置く（直して書く）。支点は値を聞かれていない右端のばねばかりに取る → 右端の力を使わずにXが決まる。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなす。120cmの棒なら左端から60cm。
  • 力が3つ以上あるときは、分からない力の場所を支点にすると、その力の分が式から消える（解答冊子「右端のばねばかりを支点にして考えます」）。

🔍 こう読み解く

  1. 右端を支点にして距離を書き直す：おもり120gは100cm、棒の120gは60cm、Xは80cm。
  2. 左回り：120×100＋120×60＝12000＋7200＝19200。
  3. 右回り：X×80＝19200 → X＝240g。下向きの合計も120＋120＝240なので、右端のばねばかりは0g（解答冊子）。
答え：240g
今回：240 ○。紙面に「19200」「12000」「7200」「60」があり、右端支点で解答冊子と同じ式を立てている。

DC1 (2)① 両側から50gで引いたばねの長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「自然長が12cm、15gで3cmのびます」と、図3の「50g・50g」。決まりは「5gで1cm」に直して余白に書く。ばねを引く力は両側の合計でなく片側の50g → のびは10cmと決まる。

📚 前提知識

  • ばねののびは、引く力に比例する。15gで3cm → 5gで1cm。この形にしておくと、あとの計算が割り算1回ですむ。
  • 両側から同じ力で引くばねは、片側を壁に固定して反対側だけ引いたのと同じ。壁は引き返す役をしているだけで、ばねにかかる力は片側の分。

🔍 こう読み解く

  1. ばねAを引く力＝50g（100gではない）。
  2. のび＝50÷5＝10cm。
  3. 長さ＝12＋10＝22cm。
答え：22cm
今回：22 ○。図3の横に「5g 1cm」「10cm」と書いてあり、決まりを直してから片側の50gで計算できている。

DC1 (2)② 直列のばねCの長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「ばねBの長さが29cm」と、図4の「50g・おもりX」。29cmは「のび17cm→85g」に直して図のBの横に置く（直して書く）→ Bを引く85gは「50g＋X」なので、Xが決まり、Cを引く力も決まる。

📚 前提知識

  • 直列につないだばねは、上のばねほど下にあるものを全部支える。B＝50g＋X、C＝Xだけ。
  • 長さから力を出すときは、先に自然長12cmを引いて「のび」にする。のび÷1cmあたり5g。

🔍 こう読み解く

  1. Bののび＝29−12＝17cm → Bを引く力＝17×5＝85g。
  2. おもりX＝85−50＝35g。
  3. Cを引く力は35g → のび＝35÷5＝7cm → 長さ＝12＋7＝19cm。
答え：19cm
今回：19 ○。紙面の「12」「17」「85」「7」の順で、長さ→のび→力→Xの流れが置けている。

DC1 (3)① 輪軸のつり合い 条件文・計算

👀 まず見るところ

【条件文】部品は「小さい方の半径は2cm、大きい方の半径は4cm」と、図5の下の輪軸で「10gは大きい輪、①は小さい輪」にかかっていること。半径を図の輪に書きこむ（図に置く）→ てこと同じ「力×半径」のつり合いで①が決まる。

📚 前提知識

  • 輪軸は、中心を支点にしたてこ。力×半径が左右で等しいときにつり合う。大きい輪にかける力は小さくてすむ。

🔍 こう読み解く

  1. 図5の下の輪軸：10gの糸は外側（半径4cm）、①gの糸は内側（半径2cm）からおりている。
  2. 10×4＝①×2 → ①＝20g。
答え：20g
今回：20 ○。

DC1 (3)② 動滑車を支える糸の力 条件文・計算

👀 まず見るところ

【条件文】部品は「滑車と輪軸の重さは考えない」と、図5のまん中の滑車が動滑車（両側の糸で支えられ、下に輪軸がぶら下がる）であること。動滑車の下にかかる重さ 10＋20＝30g を図に置く → 糸1本は半分の15g、それが上の定滑車を通って②になる。

📚 前提知識

  • 動滑車は、ぶら下がる重さを2本の糸で半分ずつ支える。滑車自体の重さがないので、足すのは下にあるものだけ。
  • 定滑車は力の向きを変えるだけで、大きさは変えない。糸の片方が15gなら、反対側のおもりも15g。

🔍 こう読み解く

  1. 動滑車にぶら下がる重さ＝10g＋①の20g＝30g（輪軸の重さは0）。
  2. 糸1本の力＝30÷2＝15g。
  3. 右側の糸は上の定滑車を通って②につながる → ②＝15g。
答え：15g
今回：15 ○。図5の滑車の両側に「15」と書きこんであり、動滑車の半分を糸に置けている。

DC1 (4)① 浮いている物体の浮力 条件文・計算

👀 まず見るところ

【条件文】部品は「120gで200cm³の物体P」「水の密度は1g/cm³」に丸。120÷200＝0.6g/cm³ と直して書く → 水より軽いので浮く。浮いている物体の浮力は、体積ではなく重さで決まる。

📚 前提知識

  • 浮力＝おしのけた水の重さ。全部しずめれば200gだが、浮いているときは水に入っている分だけ。
  • 浮いて止まっている物体は、浮力と重さがつり合っている → 浮力＝物体の重さ。だから120g。

🔍 こう読み解く

  1. 密度 120÷200＝0.6 ＜ 1 → 浮く（図6でもPの上が水面から出ている）。
  2. 浮いているので 浮力＝重さ＝120g。200gと答えないように、先に「浮くか」を決める。
答え：120g
今回：120 ○。

DC1 (4)② 台ばかりの増え方 条件文・計算

👀 まず見るところ

【条件文】部品は「台ばかりの示す値」「入れる前と比べて何g大きく」に丸。①の「浮力120g」を、水がPを押し上げる矢印と、Pが水を押し返す同じ大きさの矢印の2本で図に置く → 下向きの120gがそのまま台ばかりに乗る。

📚 前提知識

  • 水が物体を浮力で押し上げると、物体は水を同じ大きさで押し返す。その分が容器ごと台ばかりにかかる。
  • 浮いている物体なら、増える分＝浮力＝物体の重さ。「物体をそのまま台ばかりに乗せたのと同じ」と考えてもよい。

🔍 こう読み解く

  1. ①より浮力は120g。
  2. 台ばかりの増え分＝浮力＝120g。
答え：120g
今回：120 ○。
コツ：①と②が同じ120gになるのは「浮いている」から。しずんでいる物体（糸でつるして入れる等）なら、増える分は浮力＝体積分の水の重さになる。2つの型を並べて持っておく。

DC2 全体像 種子植物の分類・てこの用語 4問（各5点・20点）

(1)〜(3)は「子房があるか」で被子植物と裸子植物を分ける問題。(1)で被子植物と答えたら、(2)は「含まれないもの」＝裸子植物を選び、(3)は裸子植物の特徴を全部選ぶ。3問が1本につながっている。(4)はてこの用語。

今回は10／20点。(1)(2)は正解、(3)は「花を咲かせない」のエを選んで×、(4)は空らん。覚え直しは「裸子植物の花」と「力のモーメント」の2つ。

DC2 (1) 子房をつくり果実ができる植物 知識問題

被子植物。胚珠が子房に包まれているので、受粉すると子房が果実になる。子房がなく胚珠がむき出しなのが裸子植物（マツ・イチョウ・スギ・ソテツ）。「被」は「おおう」の意味で、漢字は「被子」。
答え：被子植物
今回：ひし植物 ○（「被」がひらがな。採点は正解だが、入試では漢字で書けるようにしておく）。

DC2 (2) 被子植物に含まれないもの 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「(1)で答えた仲間に含まれない」と「すべて」に丸 → 聞かれているのは裸子植物。5つの名前に「果実ができるか」で○×をつける。

📚 前提知識

  • 裸子植物はマツ・スギ・ヒノキ・イチョウ・ソテツなど。花びらがなく、果実もできない（イチョウの「ぎんなん」は種子で、果実ではない）。
  • イチゴ・アサガオ・トウモロコシは被子植物。トウモロコシは単子葉で花びらは目立たないが、子房はある。

🔍 こう読み解く

  1. ア イチゴ（果実あり）→ 被子。エ アサガオ・オ トウモロコシ → 被子。
  2. イ マツ・ウ イチョウ → 裸子。この2つが答え。
答え：イ・ウ
今回：イ ウ ○。

DC2 (3) 裸子植物の特徴 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「子房をつくらず」（＝裸子植物）と「すべて」に丸。ア〜エを「種子」「花のつくり」「花があるか」の3語に分けて1つずつ○× → 花はある（咲かせないのではない）ので、エだけが×。

📚 前提知識

  • 裸子植物の花は、花びら・がくがない不完全花で、お花とめ花に分かれた単性花。花びらがないので「花がない」と見えるが、花はある。
  • マツ・イチョウの種子は有胚乳種子（養分を胚乳にたくわえる）。
  • 花を咲かせないのは、種子をつくらない植物（シダ・コケ）。種子植物である裸子植物には当てはまらない。

🔍 こう読み解く

  1. ア 有胚乳種子 → ○。イ 単性花 → ○。ウ 不完全花 → ○。
  2. エ 花を咲かせない → ×。裸子植物は「花はあるが花びらがない」。
  3. 「すべて選ぶ」なので、○のア・イ・ウを全部書く。
答え：ア・イ・ウ
今回：エ ×（正解 ア・イ・ウ）。知識＝「花びらがない」を「花がない」と取りちがえた。裸子植物は「花はある・花びらとがくがない・お花とめ花」の3語で置き直す。「すべて選ぶ」で1つだけの答えになったら、選びもれを疑う。

DC2 (4) てこを回転させるはたらきの大きさ 知識問題

モーメント。「力×支点からの距離」で表す、てこを回そうとするはたらきの大きさ。(1)〜(3)でずっと使ってきた「力×距離」の名前がこれ。文中の「ガリレオ」「てこを回転させるはたらき」が手がかり。カタカナ5字。
答え：モーメント
今回：空らん ×（正解 モーメント）。知識＝用語の名前。計算で使う「力かける距離」に「モーメント」という名前をつけて覚える。

DC まとめ 90／100点（大問1 80／80・大問2 10／20）

  • 取れた：大問1の計算8問すべて。棒の重さを図に置く・右端を支点にする・ばねを「5gで1cm」に直す・動滑車は半分、の4つが手として入っている。
  • 落とした2問はどちらも用語の知識。裸子植物＝「花はあるが花びらがない・単性花・不完全花・有胚乳種子」の4語、てこの「力×距離」＝モーメント、を覚え直す。
  • 「すべて選びなさい」で答えが1つになったら、残りの選択肢をもう一度○×で確かめる。
