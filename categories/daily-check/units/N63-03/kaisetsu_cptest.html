N63-03 CP（コアプラス確認テスト・人体②：血液循環／骨格／ヒトの誕生）

CP 全体像 コアプラス確認テスト 10問（範囲 477〜494・621）

テーマは「人体②（血液循環・骨格・ヒトの誕生）」。(1)〜(4)が血液のじゅんかん（心臓の図・赤血球・腎臓・心拍の計算）、(5)〜(7)が骨と筋肉（直立二足歩行・骨の数とじん帯・うでの筋肉）、(8)〜(10)がヒトの誕生（卵子と出産までの日数・へその緒・産声）。

図で決まるのは(1)(7)(9)、計算は(4)だけ。残りは一問一答なので、図の問題は心房＝受け入れる／心室＝送り出すのように、決まりを図の横に書いてから選ぶ。

CP (1) 心臓の模式図：動脈と、二酸化炭素の多い血管 資料問題・2つ選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「ヒトの心臓の模式図」と、聞かれ方「動脈を2つ」「二酸化炭素を多く含む…2つ」に線。上の部屋A・Bに「心房＝受け入れる」、下のC・Dに「心室＝送り出す」と書く → 下から出る管が動脈、ぬりつぶされたA・Cにつながる管が二酸化炭素の多い血液、と決まる。

📚 前提知識

  • 動脈＝心臓から出ていく血管、静脈＝心臓にもどる血管。血液の種類（酸素が多いか少ないか）で決めるのではない。
  • 血液の道すじ：全身 → 大静脈 → 右心房 → 右心室 → 肺動脈 → 肺 → 肺静脈 → 左心房 → 左心室 → 大動脈 → 全身。肺で酸素をもらうので、肺動脈は二酸化炭素が多く、肺静脈は酸素が多い。名前と中身が逆になる2本。
  • 図では右心房A・右心室Cと、そこにつながる管がぬりつぶされている。ぬりつぶし＝二酸化炭素の多い血液。

🔍 こう読み解く

  1. 管の行き先を1本ずつたどる。ア→上の部屋A（右心房）に入る＝大静脈。エ→上の部屋B（左心房）に入る＝肺静脈。イ→下の部屋Dから出て上へ枝分かれ＝大動脈。ウ→下の部屋Cから出て左右の肺へ＝肺動脈。
  2. ①動脈＝心室から出る管 → イ・ウ。アとエは心房に入る管なので静脈。選ばない。
  3. ②二酸化炭素が多い血液＝全身から帰ってきて肺に向かうまで。ぬりつぶされたA・Cにつながるア・ウ。イとエは肺を通ったあとの血液で、酸素が多いので選ばない。
答え：① イ・ウ　② ア・ウ
今回：① ウ・イ ○　② ウ・エ ×（正解ア・ウ）。部品を拾えなかった＝ぬりつぶし（二酸化炭素の多い側）を部品にせず、肺につながる2本をそろえて選んだ。エは肺から酸素をもらって帰る管。次は右心房・右心室に「二酸化炭素が多い」と書き、そこにつながる管を選ぶ。
コツ：ウ（肺動脈）は①にも②にも入る。「動脈なのに二酸化炭素が多い」のは肺動脈だけ、と組で押さえる。

CP (2) 赤血球の色素と、二酸化炭素の多い血液の色 知識問題

① ヘモグロビン　② イ（赤黒い）。赤血球の赤い色素ヘモグロビンは、酸素の多い所で酸素と結びつき、少ない所ではなす。酸素と結びついているときは鮮やかな赤、はなれて二酸化炭素の多い血液では赤黒い色になる。「酸素が多い＝あざやか、少ない＝黒ずむ」と組で覚える。
答え：① ヘモグロビン　② イ
今回：① ヘモグロビン　② イ ○。

CP (3) 血液をこす臓器と、不要物が最も少ない血管 素材文・空らん

👀 まず見るところ

【素材文】設問は「臓器の名前」と「その臓器につながる血管の名前」。部品は手がかりの言葉「二酸化炭素以外の不要物」と「最も少ない」に丸 → 不要物をこし出す臓器＝腎臓、こされたあとの血液が流れる管＝腎静脈、と決まる。

📚 前提知識

  • 腎臓は血液中の不要物（尿素など）をこし出して、尿をつくる。二酸化炭素を出すのは肺なので、問題文は「二酸化炭素以外」と断っている。
  • 臓器に入る管が動脈、出ていく管が静脈。腎臓に入る腎動脈の血液には不要物がまだ多く、出ていく腎静脈の血液は不要物が最も少ない。

🔍 こう読み解く

  1. ①「血液がこされる臓器」→ こす＝不要物を取り出す → 腎臓。
  2. ②「不要物が最も少ない」→ こし終わったあとの血液 → 腎臓から出る側の腎静脈。腎動脈はこす前なので少なくない。
答え：① 腎臓　② 腎静脈
今回：① じんぞう　② じん静脈 ○。「少ない＝出る側」で静脈を選べている。
コツ：「最も少ない」は出口の静脈、「最も多い」は入口の動脈。肺なら酸素が最も多いのは肺静脈（出口）、と同じ向きで考える。

CP (4) 血液が全身を1周する時間 条件文・計算

👀 まず見るところ

【条件文】部品は「血液量4L」「1分間あたり80回」「1回の心拍で60mL」と、答え方「何秒」に丸。4Lは4000mLに直して書き、「1分で 60×80＝4800mL」を余白に置く → 4000mLを送り出す時間が決まる。

📚 前提知識

  • 血液が全身を1周する＝心臓が血液の全部（4L）を送り出し終わる、と考える。1回に60mLずつ、1分に80回。
  • 単位をそろえてから割る。LとmL、分と秒がまざったままでは式に入らない。

🔍 こう読み解く

  1. 1分間に送り出す量＝60mL×80回＝4800mL。
  2. 全身の血液4L＝4000mL。4000÷4800＝5/6分。
  3. 秒に直す：60秒×5/6＝50秒。
答え：50秒
今回：50 ○。余白に「1分で4800mL」「5/6」と書いてから答えている。部品を紙に置く手順どおり。
コツ：4800mL÷60秒＝1秒に80mL → 4000÷80＝50秒、でも同じ答えになる。どちらでも、先に4Lを4000mLに直す。

CP (5) ヒトの歩き方と、足の裏のアーチ 知識問題

① 直立二足　② 土ふまず。ヒトは直立二足歩行をするので、重い頭と上半身を背骨で支える。背骨のS字カーブと足の裏の土ふまず（アーチ状で地面に触れない部分）は、どちらも歩くときのしょうげきをやわらげるつくり。「S字カーブ・土ふまず・かかとをつけて歩く」の3つを、二足歩行のセットで覚える。
答え：① 直立二足　② 土ふまず
今回：① 直立二足　② 土ふまず ○。

CP (6) 骨の数と、骨と骨をつなぐもの 知識問題

① 200　② じん帯。ヒトの骨は全身に約200個。関節で骨と骨をつなぎ、ずれないようにしているのがじん帯（図2のXの、関節のまわりを包む帯）。筋肉と骨をつなぐのはけん、関節で骨の表面をおおってクッションになるのがなん骨。「じん帯＝骨と骨／けん＝筋肉と骨／なん骨＝クッション」と3語で分ける。
答え：① 200　② じん帯
今回：① 200 ○　② なん骨 ×（正解じん帯）。知識＝関節にある3つ（じん帯・けん・なん骨）の役目が分かれていない。問題文の「骨と骨がつながれて」に丸をつければ、「つなぐ＝じん帯」、「おおう＝なん骨」で分けられる。

CP (7) うでを曲げるときの筋肉Y 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】部品は図3の正体「うでの骨と、ひじをはさむ2本の筋肉」と、聞かれ方「曲げるとき」に線。Yが曲がる側（内側）か、反対側（外側）かを図に書く → 曲がる側の筋肉が縮む、と決まる。

📚 前提知識

  • 筋肉は縮むことでしか骨を動かせない。だから、ひじの内側と外側に1本ずつ、向かい合う筋肉がついている。
  • うでを曲げるときは内側の筋肉が縮み、外側がゆるむ。のばすときは逆に、外側が縮んで内側がゆるむ。

🔍 こう読み解く

  1. 図3は、手が左上、ひじが中ほど、かたが右下。うではほぼのばした形で、手の側がわずかに上へ向いている＝曲がる側は上側。
  2. Yは上うでの2本の筋肉のうち上側（曲がる側・内側）についていて、Yのはしはひじをこえて前うでの骨につく。もう1本は反対の外側で、ひじの先につく。
  3. 曲げるとき、曲がる側の筋肉Yは縮む → 縮み。
答え：縮み
今回：縮み ○。
コツ：自分のうでを曲げて、力こぶができる側を確かめる。力こぶ＝縮んで太くなった内側の筋肉。

CP (8) 卵子の直径と、受精から出産までの日数 知識問題

① 0.1　② 266。ヒトの卵子は直径約0.1mm（精子はそれよりずっと小さい）で、人の細胞では最も大きいものの1つ。受精卵は母親の子宮で育ち、受精から約266日（約38週）で生まれる。選択肢の「38」は週で数えた数なので、「日」と聞かれたら266。
答え：① 0.1　② 266
今回：① 0.1　② 266 ○。

CP (9) 母親と胎児をつなぐ管Zと、その中の血管 資料問題・図＋知識

👀 まず見るところ

【資料問題】部品は図4の正体「子宮の中の胎児と胎盤」と、Zが「母親と胎児をつなぐ管」。聞かれ方「ア〜ウから1つ」に線。胎盤の横に「血液は混ざらない」と書く → Zの中を通る血管は胎児のものだけ、と決まる。

📚 前提知識

  • 胎児は胎盤で母親から酸素と養分を受け取り、二酸化炭素と不要物をわたす。胎盤と胎児をつなぐ管がへその緒。
  • 胎盤では、母親の血液と胎児の血液は混ざらない。うすいかべをはさんで物だけをやりとりする。だから、へその緒の中を流れているのは胎児の血液で、血管も胎児のもの。

🔍 こう読み解く

  1. ①図でZは、胎児のおなかから胎盤までのびている管 → へその緒。
  2. ②母親の血液は胎盤までしか来ない。へその緒を通るのは、胎盤へ行って帰る胎児の血液。
  3. ア「母親の血管」は胎盤より手前で止まるので×。ウ「母親と胎児の血管」は血液が混ざらない決まりに反するので×。残るイ。
答え：① へその緒　② イ
今回：① へそのお ○　② ウ ×（正解イ）。知識＝「胎盤で母親と胎児の血液は混ざらない」が答えに使われていない。次は胎盤に「混ざらない」と書いてから、母親の血液がどこまで来ているかを図でたどる。

CP (10) 肺呼吸を始めるときの行動 知識問題

産声（をあげる）。生まれる前の胎児は肺を使わず、胎盤から酸素をもらっている。生まれて最初に大きく泣く産声で、肺に初めて空気が入り、肺呼吸が始まる。「胎盤の呼吸 → 産声 → 肺の呼吸」の順で結びつける。
答え：産声（をあげる）
今回：うぶ声をあげる ○。

CP まとめ 70点（10問中7問）

  • 取れた：(2)(3)(4)(5)(7)(8)(10)。(4)は「1分で4800mL」「5/6」と部品を紙に置いてから解けている。
  • 落とした3問は、どれも2つを分ける決まりが1つ足りない形：(1)ぬりつぶし＝二酸化炭素の多い側／(6)じん帯＝骨と骨・なん骨＝クッション／(9)胎盤で血液は混ざらない。
  • 覚え直しはこの3つ：肺動脈は動脈なのに二酸化炭素が多い／じん帯・けん・なん骨の3語／へその緒の血管は胎児のもの。
