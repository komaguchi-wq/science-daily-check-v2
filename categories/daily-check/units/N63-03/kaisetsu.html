確認8 (1) 星の動きを写した4枚の写真の方角 資料問題・図1〜図4の対応

👀 まず見るところ

【資料問題】資料の正体は「一定の時間の星の動き・下側が地平線」、聞かれ方は「どの方角の空」に線。北（同心円）と南（上にふくらむドーム）を先に置き、残りは右上がり＝東寄り／右下がり＝西寄り、弧の曲がり方で北寄りか南寄りを決める。

📚 前提知識

  • 星は北極星を中心に回って見える。北の空＝北極星を中心とする同心円、南の空＝上にふくらむドームの形。
  • 東寄りの空の星は右上がり（のぼる）、西寄りの空の星は右下がり（しずむ）。
  • 北寄り（北東・北西）の弧は北極星を中心にした円の一部なので、ふくらみは北極星の反対側に出る。南寄り（南東・南西）の弧は南のドームのつづきなので上にふくらむ。

🔍 こう読み解く

  1. 図3：1点のまわりの同心円 → 中心が北極星 → 北＝ア。図2：左右に広がる上にふくらんだ弧 → 南＝エ。
  2. 図1：線が右上がりなので東寄り。弧は左上（北極星のある側）をかこむように曲がり、ふくらみが右下に出ている → 北寄り → 北東＝イ。
  3. 図4：線が右下がりなので西寄り。弧は南のドームのつづきで上にふくらんでいる → 南寄り → 南西＝オ。
  4. 記号は4つとも別（ア・イ・エ・オ）になっていることを見直してから書く。
答え：図1 イ　図2 エ　図3 ア　図4 オ
コツ：自分で解くときは、4枚の下にまず「北／南」を置いてから、残り2枚に「のぼる→東」「しずむ→西」と書く。北東か南東かは、弧の曲がり方が北極星をかこむ形（北寄り）か、上にふくらむドーム（南寄り）かで決める。

確認8 (2) 星が点に写るカメラの回転軸の向き まざり型→素材文・記号選択

👀 まず見るところ

📚 前提知識

  • 星が動いて見えるのは地球が地軸を中心に自転しているから。地軸をのばした先にあるのが北極星なので、北極星の方向＝地軸と平行。
  • 北極星の高度は、その土地の緯度と同じ。東京は北緯約35度なので、真北の地平線から約35度の高さに見える。

🔍 こう読み解く

  1. カメラを固定すると図1〜図4のように星が線になる。点に写すには、星と同じ向き・同じ速さでカメラを回す必要がある。
  2. 星の動きの中心は北極星なので、回転軸は北極星に向ける。北極星は真北、高さ約35度 → ウ。
  3. ア（真上）・イ（真北の地平線）は向きが北極星からずれている。エは真南なので逆。オ（東西に水平）は北極星の方向ではない。
答え：ウ
コツ：自分で解くときは、選択肢を読む前に余白へ「北極星＝真北・高さ35度（東京の緯度）」と書く。その1行と同じ文を選ぶだけになる。

発展4 (1) 図1の星空の季節 資料問題・季節

👀 まず見るところ

【資料問題】資料の正体は「北緯39度・21時ごろの星空」。図2の☆＝「オリオン座の3つ星」がどこにあるかを1行書く → 西の地平線に近い低い空。冬の星座が21時にもう沈みかけている季節、と決まる。

📚 前提知識

  • オリオン座は冬の星座。冬（1〜2月ごろ）は21時ごろ南の高い空に見える（南中）。
  • 同じ時刻に見える星の位置は、1か月に約30度（2時間分）ずつ西へずれる。南中の位置から西の地平線（90度先）まで来るのに3か月ほどかかる。
  • 春の夕方の空の目印は、北東の高い所にのぼった北斗七星と、南〜東のしし座。

🔍 こう読み解く

  1. 図2で☆の場所を読む。西の目盛りから南へ1目盛り、外から2つ目の円のあたり → 西の低い空（高度20度ほど）。
  2. 冬なら21時に南の高い空にあるオリオン座が、もう西に沈みかけている → 冬から3か月ほどあと ＝ 春。
  3. 確かめ: 図1の北東（右下）に、ひしゃくの形の北斗七星が高くのぼっている。春の夕方の空の形と合う。
答え：春
コツ：自分で解くときは、季節を「オリオン座がどこに見えるか」で決める。冬の21時＝南の高い所、春の21時＝西の低い所、秋の21時＝まだ東から出ていない。

発展4 (2) ともくん・まりちゃんの考え方での南中時刻 まざり型→条件文・時刻の計算

👀 まず見るところ

【まざり型→条件文】部品は「15度の変化を1時間分」と、2人でちがう言葉「とも＝見える方角」「まり＝北極星を中心に動いた角度」。図2に、ともは南から☆までの目盛り、まりは★から南・★から☆の線を引いて角度を置く → 角度÷15が南中からの時間。

📚 前提知識

  • 南中＝星が真南に来たとき。図2では南の線（上の縦線）の上にあるとき。この3つ星は真東から出て、南の空を通って南中し、真西に沈む（問題文）。
  • 「15度で1時間」の元は、地球が1日（24時間）で360度自転すること。360÷24＝15。
  • 答え方は「24時制で整数」。21時より前の時刻になるので、21から引く。

🔍 こう読み解く

  1. とも: 地平線の目盛りは15度おき。☆の方角は西から南へ1目盛り → 南から数えて約75度。75÷15＝5時間 → 21−5＝16時。
  2. まり: 北極星★から南へまっすぐ引いた線と、★から☆へ引いた線の間の角度は約45度（直角の半分）。45÷15＝3時間 → 21−3＝18時。
  3. 「およそ」でよいので、角度は目盛り1つ＝15度の単位で読めば十分。
答え：とも 16時　まり 18時
コツ：星座早見の答えは17時（問題文）で、2人のちょうど間。本当に15度ずつ進むのは「天球の上の弧」（(4)の問題文）で、方角の変化も、平らな図の上で測った北極星のまわりの角度も15度ずつにはならない。だから2人の予想は両方ずれる。

発展4 (3) 表1のA〜Dを図4に置いて道すじをかく 資料問題・作図

👀 まず見るところ

【資料問題】資料の正体「表1＝3つ星の高度と方角（南から東が−・西が＋）」と、図4の向き「東が上・南が右（上から見た図）」を1行書く。円は高度15度ごと、目盛りは方角15度ごとなので、A〜Dを1点ずつ置けば道すじが決まる。

📚 前提知識

  • 高度＝地平線から見上げた角度。図4では外の円が高度0度、1つ内側に入るごとに15度、中心（天頂）が90度。
  • 方角は南の線から測る。「−」は東側（図4では南から上へ）、「＋」は西側（南から下へ）。
  • 3つ星は真東から出て真西に沈む（問題文）ので、道すじは南の線について左右対称。南中高度51度（C）は「90度−緯度39度」と同じで、春分・秋分の太陽と同じ通り道（発展2の解説と同じ）。

🔍 こう読み解く

  1. A（高度2度・方角−90度）: 東の目盛りの、地平線のすぐ内側。B（19度・−74度）: 東から南へ約1目盛り、外から1つ目の円（15度）の少し内側。
  2. C（51度・0度）: 南の線の上、45度の円と60度の円の間。D（41度・＋45度）: 南と西のちょうど間（3目盛り）、45度の円のすぐ外側。
  3. A→B→C→Dをなめらかな曲線でつなぎ、Dの先は真西の地平線まで同じ形でのばす。南にふくらむ弓の形になる。
答え：解説の図（真東から出てA・B・C・Dを通り、南にふくらんで真西に沈む曲線）
コツ：自分で解くときは、点を打つ前に図4の「東」に丸。図2と同じ向き（南が上）のつもりで打つと、東西が入れかわる。

発展4 (4) 南中から4時間後の点E 条件文・作図

👀 まず見るところ

【条件文】部品は「南中してから4時間後」と「天球上の弧を15度ずつ」「真西から30度ずれた天球上の点をつないだ線」。4時間は60度に直して書き、南中から真西までの90度から引く → Eは「真西まであと30度」の点、と決まる。

📚 前提知識

  • 3つ星は真東から出て真西に沈むので、南中は出てから沈むまでのちょうどまん中。南中から真西までは90度＝6時間。
  • 「真西から30度」の点は地平線の上だけでなく空の中にもある。図4では、西の目盛りから北へ2目盛りの点・真西の真上30度（外から2つ目の円）・西から南へ2目盛りの点をつなぐと、そのおよその線になる（解説冊子）。

🔍 こう読み解く

  1. 4時間×15度＝60度。南中から真西まで90度 → 残り 90−60＝30度。Eは(3)の道すじの上で「真西まであと30度」の点。
  2. 図4に「真西から30度」の線をかく: 西から北へ2目盛りの地平線の点、西の線と外から2つ目の円の交点、西から南へ2目盛りの点、の3点をゆるい曲線でつなぐ。
  3. この線と(3)の道すじが交わる点がE。Dより下、高度20度ほど・真西から南へ15〜20度の所。
  4. 確かめ: 南中17時＋4時間＝21時。図2の21時の☆（西の低い空）と同じ場所になる（解説冊子）。
答え：解説の図（(3)の道すじと「真西から30度」の線の交点。Dと真西の間、高度20度ほど）
コツ：「4時間後＝方角が60度ずれる」と読みかえない。15度ずつ進むのは天球上の弧で、図4の上では方角も高度も等間隔には進まない（問題文）。角度は「真西まであと何度」で置く。

発展4 まとめ 未解答・自分で解くときの3点

  • 図2と図4は向きがちがう（図2＝見上げ・南が上／図4＝見おろし・東が上）。点を打つ前に余白へ「東↑」と書く。
  • 「15度＝1時間」が使えるのは天球の上の弧。方角の変化や、平らな図で測った北極星まわりの角度から時刻を出すと、(2)のようにずれる。
  • 3つ星（天の赤道の星）の決まり: 真東から出て真西に沈む・南中高度＝90度−緯度・南中は出てから沈むまでのまん中（6時間ずつ）。
