N63-05 CP（コアプラス確認テスト・動物②（無セキツイ動物）範囲511〜527・623）

CP 全体像 コアプラス確認テスト 10問・100点

範囲は動物②（無セキツイ動物）。中身は、昆虫のからだと仲間分け（(1)(2)(6)）、さなぎになるか・幼虫はどこにすむか（(3)(4)(5)）、くらし（(7)(8)）、表の計算（(9)(10)）の4つ。

(3)〜(5)と(8)は「すべて選ぶ」。1つ見つけて終わりにせず、選択肢ごとに○×をつけてから答えを書く。(9)(10)は表の数字を式に置くだけで決まる。

CP (1) 外骨格を持つ動物の仲間と、からだを大きくする方法 知識問題

① 節足　② 脱皮。昆虫は、からだの外側がかたい外骨格でおおわれた節足動物の仲間（エビ・カニ、クモ、ムカデも同じ仲間）。外側がかたいので、そのままでは大きくなれず、古い皮をぬぐ脱皮のたびに大きくなる。「外骨格 → のびない → 脱皮」とつなげて覚える。
答え：① 節足　② 脱皮

CP (2) ミジンコに最も近い動物 知識問題

エ（ザリガニ）。ミジンコは小さいが、エビ・カニ・ザリガニと同じ甲殻類（節足動物）。アのゾウリムシは1つの細胞でできた生き物、イのダニはクモの仲間（節足動物だが甲殻類ではない）、ウのアサリは貝の仲間（軟体動物）。「ミジンコ＝小さなエビの仲間」と結びつける。
答え：エ

CP (3) さなぎになる昆虫（成虫の図） 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「5種類の成虫」と聞かれ方「さなぎになるものをすべて」に線。図の下に名前を1行ずつ書く（テントウムシ・タガメ・アブ・アリ・コオロギ）→ 名前が決まれば「完全変態か不完全変態か」で○×が決まる。

📚 前提知識

  • さなぎになる（完全変態）：チョウ・ガ、甲虫（カブトムシ・テントウムシ・ゲンゴロウ・ホタル）、ハチ・アリ、ハエ・アブ・カ。
  • さなぎにならない（不完全変態）：バッタ・コオロギ、カマキリ、トンボ、セミ、カメムシ・タガメ。幼虫と成虫の形が似ている仲間。

🔍 こう読み解く

  1. ア 丸い背中に黒い点 → テントウムシ（甲虫）→ さなぎになる ○。
  2. イ 前あしがかまのように太い → タガメ（カメムシの仲間）→ ならない ×。オ 長い触角と太い後ろあし → コオロギ（バッタの仲間）→ ならない ×。
  3. ウ はねが2枚で太いからだ → アブ（ハエの仲間）→ ○。エ くびれた細い腰 → アリ（ハチの仲間）→ ○。残るのはア・ウ・エ。
答え：ア・ウ・エ
自分で解くときのチェック：図の下に名前を書いてから、5つ全部に○×をつける。名前が出てこない図は、仲間（甲虫か・ハチか・バッタか）だけでも書く。

CP (4) 水の中にすむ幼虫 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図の正体「5種類の幼虫」と聞かれ方「水の中に生息」に線。図の下に「名前＋すむ場所」を1行ずつ書く（トンボ・水／セミ・土／カブトムシ・土／テントウムシ・葉／ゲンジボタル・水）→ 水と書いたものだけが答え。

📚 前提知識

  • トンボの幼虫（ヤゴ）は池や川の水中で小さな生き物を食べる。ゲンジボタルの幼虫も川の中で巻き貝（カワニナ）を食べて育つ。
  • セミとカブトムシの幼虫は土の中（セミは木の根の汁、カブトムシは腐葉土）。テントウムシの幼虫は葉の上でアブラムシを食べる。

🔍 こう読み解く

  1. ア 細長いからだに大きな目、はねの芽 → トンボの幼虫（ヤゴ）→ 水 ○。
  2. イ 太い前あしで土をほる形 → セミの幼虫 → 土 ×。ウ 白く丸まった形 → カブトムシの幼虫 → 土 ×。
  3. エ 細長く黒っぽい → テントウムシの幼虫 → 葉の上 ×。オ 節ごとにとげのある平たいからだ → ゲンジボタルの幼虫 → 川の中 ○。答えはア・オ。
答え：ア・オ
自分で解くときのチェック：「水の中」に線を引き、すむ場所を図の下に書いてから選ぶ。(5)でも同じ図を使うので、名前のメモはそのまま残す。

CP (5) (4)の幼虫のうち、さなぎにならないもの 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】(4)と変わった部品は「さなぎにならないもの」に丸（水の中かどうかは関係なくなる）。(4)で書いた名前の横に「完／不」を書く → 不完全変態のトンボとセミだけが残る。

📚 前提知識

  • トンボ・セミは不完全変態。幼虫が最後の脱皮でそのまま成虫になる（セミのぬけがらは、さなぎのからではなく幼虫の皮）。
  • カブトムシ・テントウムシ・ホタルは甲虫の仲間で完全変態。さなぎの時期がある。

🔍 こう読み解く

  1. ア トンボ → さなぎにならない ○。イ セミ → ならない ○。
  2. ウ カブトムシ・エ テントウムシ・オ ゲンジボタル → 甲虫なので、さなぎになる ×。
  3. 答えはア・イ。(4)の「水の中」の組（ア・オ）とは別の分け方になる。
答え：ア・イ
自分で解くときのチェック：(4)と同じ図でも聞かれ方が変わる。「さなぎにならない」の「ならない」に丸をつけ、○×の向きを逆にしない。

CP (6) アオムシのあしのつき方 資料問題・図の見分け

👀 まず見るところ

【資料問題】部品は図の「あしの数と場所」。4つの図の下に「前○・まん中○・後ろ○」と対の数を書く → 「前3・まん中4・後ろ1」になっている図だけが正しい。

📚 前提知識

  • アオムシ（チョウの幼虫）も昆虫なので、本当のあしは胸に3対。成虫になってもこの3対がそのまま残る。
  • 腹には歩くための腹脚が4対と、おしりの先に尾脚が1対。腹脚は、胸のあしから少し間をあけたところに並ぶ。

🔍 こう読み解く

  1. 前（胸）のあしを数える。アは2対、エは4対 → どちらも×。
  2. イとウは前が3対。まん中のあしを数えると、イは6対が続いていて多い → ×。
  3. ウは前3対・まん中4対・後ろ1対 → ウ。
答え：ウ
自分で解くときのチェック：「昆虫のあしは3対」を先に図の横に書き、前のあしの数で2つ消してから、まん中を数える。

CP (7) モンシロチョウが卵を産まない葉 知識問題

エ（レタス）。モンシロチョウはアブラナ科の葉（キャベツ・アブラナ・コマツナ・ダイコンなど）に卵を産み、幼虫のアオムシはその葉を食べて育つ。レタスはキク科で仲間がちがう。設問は「適当でないもの」なので、アブラナ科でない1つを選ぶ。
答え：エ

CP (8) 卵で冬越しをする昆虫 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問は「卵で冬越しをするもの」に丸。部品は6つの名前。名前の横に「卵／幼虫／さなぎ／成虫」のどれかを1語ずつ書く → 卵と書いたものだけが答え。

📚 前提知識

  • 卵で冬越し：カマキリ（木の枝に泡のかたまりの卵のう）、バッタ（土の中に卵）、コオロギも同じ。
  • 幼虫で冬越し：オオムラサキ（落ち葉の裏）、カブトムシ（土の中）、ギンヤンマなどトンボ（水中のヤゴ）。成虫で冬越し：ゲンゴロウ（水中）・テントウムシ。アゲハはさなぎで冬越し。

🔍 こう読み解く

  1. ウ カマキリ → 卵のうの中の卵 ○。カ トノサマバッタ → 土の中の卵 ○。
  2. ア オオムラサキ → 幼虫 ×。イ カブトムシ → 幼虫 ×。エ ギンヤンマ → 幼虫（ヤゴ）×。オ ゲンゴロウ → 成虫 ×。
  3. 答えはウ・カ。
答え：ウ・カ
自分で解くときのチェック：6つ全部に「卵／幼虫／さなぎ／成虫」を書いてから選ぶ。1つでも空らんのまま答えを書かない。

CP (9) 卵が成虫になれる確率 条件文・計算

👀 まず見るところ

【条件文】部品は「卵が成虫になれる確率」と答え方「四捨五入して小数第1位」「%」に丸。表の「卵 4536」「成虫 7」に丸 → 式は 成虫÷卵×100 に直して余白に書く。

📚 前提知識

  • 「AがBになれる確率（%）」＝ Bの数 ÷ Aの数 × 100。もとになる数（卵）で割る。
  • 小数第1位まで答える → 小数第2位を四捨五入する。

🔍 こう読み解く

  1. 7 ÷ 4536 × 100 ＝ 0.154…（%）。
  2. 小数第2位の5を四捨五入 → 0.2%。
  3. 確かめ：4536個のうち7個は1000個に1〜2個の割合 → 0.1〜0.2%あたり。けたが合っている。
答え：0.2%
自分で解くときのチェック：0.15と書いて止めない。「小数第1位まで」に丸をつけ、答えを書く直前にもう一度見る。

CP (10) 死亡率が高いのは卵とさなぎのどちらか 資料問題・表の比較

👀 まず見るところ

【資料問題】部品は表の正体「成長段階ごとの生存数」と聞かれ方「死亡率が高い」に線。死亡率は「その段階で死んだ数÷その段階に入った数」に直して書く → 卵は 4536→3604、さなぎは 13→7 の減り方を割合で比べる。

📚 前提知識

  • 死んだ数そのものではなく割合で比べる。卵は数が多いので死んだ数も多く見えるが、それでは比べたことにならない。
  • ある段階の死亡率 ＝（その段階の生存数 − 次の段階の生存数）÷ その段階の生存数。

🔍 こう読み解く

  1. 卵の段階：4536 − 3604 ＝ 932 が死んだ。932 ÷ 4536 ＝ 約0.21 → 約21%。
  2. さなぎの段階：13 − 7 ＝ 6 が死んだ。6 ÷ 13 ＝ 約0.46 → 約46%。
  3. 半分近くが死ぬさなぎのほうが高い。
答え：さなぎ
自分で解くときのチェック：死んだ数（932と6）だけ見て「卵」と答えない。割る数は、その段階の生存数。

CP まとめ 未解答・自分で解くとき

  • 「すべて選ぶ」4問（(3)(4)(5)(8)）は、図や名前の横に名前・すむ場所・冬越しの形を1語ずつ書き、全部に○×をつけてから答える。
  • 仲間分けの軸は2つ：さなぎになるか（甲虫・チョウ・ハチ・ハエは○／バッタ・カマキリ・トンボ・セミ・カメムシは×）と、幼虫がどこにすむか（トンボ・ホタルは水、セミ・カブトムシは土）。
  • 表の計算は「何で割るか」で決まる。(9)は卵の数で割り、(10)はその段階の生存数で割る。死んだ数そのものでは比べない。
