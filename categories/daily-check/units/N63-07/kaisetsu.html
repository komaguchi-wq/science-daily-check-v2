【条件文】部品は「塩酸の量は30cm³」で固定と、「水酸化ナトリウム水溶液をだんだん増やす」。表の下に「中和＝少ないほう／液量＝30＋水酸化ナトリウム水溶液」の2行を書く（直して書く）。30cm³を境に、中和の量が増えるのをやめる。

📚 前提知識

  • 基準は30：30・60cm³で6.3℃。上昇温度＝6.3×（中和÷30）×（60÷液量）。
  • 水酸化ナトリウム水溶液が30cm³をこえると塩酸30cm³は全部反応ずみ。中和の量は30のまま、液量だけ増えて温度は下がる。

🔍 こう読み解く

  1. 0cm³：中和0 → 0℃。
  2. 10cm³：6.3×10/30×60/40＝3.15℃。20cm³：6.3×20/30×60/50＝5.04℃。30cm³：6.3℃（表のとおり）。
  3. 40cm³：6.3×60/70＝5.4℃。50cm³：6.3×60/80＝4.725℃。60cm³：6.3×60/90＝4.2℃。
答え：左から 0・3.15・5.04・（6.3）・5.4・4.725・4.2（℃）
自分で解くときのチェック：数字が「上がって、6.3で最大、そのあと下がる」山の形になっているか。4.725は割り切れない形のまま書く。

発展4 (3) 上昇温度が2.1℃になる水酸化ナトリウム水溶液の量 条件文・逆算（2つ答える）

👀 まず見るところ

【条件文】部品は「2.1℃」と答え方「2つ答えなさい」に丸。最初の表で2.1℃は10：50と50：10の2か所。(1)②の「比が同じなら上昇温度も同じ」を使い、塩酸30cm³に対して比を1：5と5：1にそろえる。

📚 前提知識

  • 2つ答える＝完全中和の手前（水酸化ナトリウム水溶液が足りない）と先（余る）で1回ずつ同じ温度になる。(2)の表が山の形だったのと同じ理由。

🔍 こう読み解く

  1. 塩酸：水酸化ナトリウム水溶液＝5：1 → 30：6 → 6cm³。
  2. 塩酸：水酸化ナトリウム水溶液＝1：5 → 30：150 → 150cm³。
  3. 検算：6cm³のとき 6.3×6/30×60/36＝2.1℃。150cm³のとき 6.3×60/180＝2.1℃。
答え：6cm³、150cm³

発展4 まとめ 「比が同じ＝温度が同じ」

  • 塩酸を固定して相手を増やすと、上昇温度は「比例して上がる → 完全中和で最大 → 液量が増えて下がる」の山になる。
  • 同じ上昇温度は山の両側に1つずつ。「2つ答えなさい」は、この両側を聞いている。
  • 比が同じなら上昇温度は同じ。この決まりで、表に無い数字（30：150など）も表の数字（10：50）に引きもどせる。

発展5 (1) 空欄ア（1L中の食塩）とイ（④の固体） 資料問題・表の読み取り

👀 まず見るところ

【資料問題】部品は表の正体「100mLのAに塩酸Bを加えて蒸発させた固体のg」と、①の「塩酸0mL」。塩酸を入れていない①の5.17gは「水酸化ナトリウム4g＋食塩」だけ、と正体を1行書けばアが決まる。イは表の増え方（20mLごとに＋0.37g）をたどる。

📚 前提知識

  • 1Lに40g → 100mLには40÷10＝4gの水酸化ナトリウム。食塩も同じく1/10が入っている。
  • 完全中和までは、塩酸を同じ量ずつ足すと固体は同じ量ずつ増える（⑥⑦が同じ7.02gなので、100mLまでは直線）。

🔍 こう読み解く

  1. ア：①の固体5.17g−水酸化ナトリウム4g＝食塩1.17g（100mL分）。1Lなら×10で11.7g。
  2. イ：5.17→5.54→5.91と0.37gずつ増える。④は5.91＋0.37＝6.28g。検算：⑤6.28＋0.37＝6.65で表と合う。
答え：ア 11.7　イ 6.28
自分で解くときのチェック：解答冊子の(1)アの説明文は「食塩」と「水酸化ナトリウム」の語が入れかわって印刷されている（4gが水酸化ナトリウム、1.17gが食塩）。数字で追えば答え11.7は変わらない。

発展5 (2) ビーカー②の固体に含まれる食塩 条件文・計算

👀 まず見るところ

【条件文】部品は「ビーカー②（塩酸20mL）」と求めるもの「食塩は何g」に丸。食塩は「もとの1.17g＋中和で生じた分」なので、完全中和（塩酸100mL）で生じる食塩を先に決め、20mLはその1/5、と直して書く。

発展5 (3) 食塩と水酸化ナトリウムの重さが等しくなる塩酸の量 条件文・追いつき算

👀 まず見るところ

【条件文】部品は「食塩と水酸化ナトリウムの重さが等しかった」と答え方「四捨五入して整数」に丸。塩酸1mLあたりの「食塩の増える量」「水酸化ナトリウムの減る量」を÷100で出す（直して書く）→ 最初の差2.83gが1mLに0.0985gずつ縮む追いつき算になる。

📚 前提知識

  • 塩酸100mLで、食塩は1.17→7.02g（＋5.85g）、水酸化ナトリウムは4→0g（−4g）。1mLあたり食塩＋0.0585g、水酸化ナトリウム−0.04g。

🔍 こう読み解く

  1. 最初の差：水酸化ナトリウム4g−食塩1.17g＝2.83g。
  2. 1mLごとに差は0.0585＋0.04＝0.0985g縮む。
  3. 2.83÷0.0985＝28.7… → 四捨五入して29mL。
  4. 別の道：グラフで水酸化ナトリウムの直線（4→0）と食塩の直線（1.17→7.02）が交わる所。100mLを2.83：7.02に分けた点なので 100×2.83÷（2.83＋7.02）＝28.7…。
答え：29mL
自分で解くときのチェック：「等しい」は両方が動く問題。片方だけ（食塩が2.83g増える）で割ると答えがずれる。減る側も式に入れる。

発展5 (4) 150mLのAに塩酸B30mLを加えたときの固体 条件文・比で引きもどす

👀 まず見るところ

【条件文】部品は「150mL」「30mL」。どちらも②（100mL・20mL）の1.5倍、と直して書く。比が同じなら中身の配分もそのままなので、固体も②の1.5倍になる。

📚 前提知識

  • 水溶液も塩酸も同じ倍率で増やせば、反応する量・余る量・もとの食塩がすべて同じ倍率 → 固体も同じ倍率。

🔍 こう読み解く

  1. 150÷100＝1.5、30÷20＝1.5 → ②の1.5倍。
  2. 5.54×1.5＝8.31g。
  3. 別の道：150mLには水酸化ナトリウム6g・食塩1.755g。塩酸30mLで水酸化ナトリウム1.2gが食塩1.755gに変わる → 4.8＋1.755＋1.755＝8.31g。
答え：8.31g

発展5 まとめ 固体＝3つの合計

  • 固体＝もとの食塩＋生じた食塩＋余った水酸化ナトリウム。この3つに分けて考えると、(1)〜(4)が全部同じ道具で解ける。
  • 先に決めるのは完全中和の点（⑥⑦が同じ → 100mL）。ここでの「生じた食塩5.85g」「水酸化ナトリウム0g」が基準になる。
  • 比が同じなら固体も同じ倍率（(4)）。表に無い量は、表にある組み合わせの何倍かに直す。
