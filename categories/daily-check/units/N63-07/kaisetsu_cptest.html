N63-07 CP（コアプラス確認テスト 範囲545〜561・625 植物①（種子・呼吸・光合成））

CP 全体像 コアプラス確認テスト 10問

範囲は「植物①（種子・呼吸・光合成）」。(1)〜(3)は種子のつくり（カキ＝胚乳あり／インゲンマメ＝胚乳なし）、(4)〜(7)は発芽中のダイズの呼吸（赤インクの動きを酸素と二酸化炭素に分ける）、(8)〜(10)はふ入りの葉のヨウ素液実験（アルミはく＝日光なし、ふ＝葉緑体なし）。

計算は(6)(7)の2問だけ。図3の「水酸化ナトリウム水溶液」を「二酸化炭素は全部吸われる」に直して書けるかで決まる。

CP (1) カキの種子の断面図・イとエの名前 資料問題・図の名前

👀 まず見るところ

【資料問題】図1の正体を1行で書く：「カキの種子＝胚乳がある種子」。図の中でいちばん広い灰色の部分がイ、まん中の白く細長い部分（エ・オ・カをまとめたウ）が胚。広い所が胚乳、胚の上の部分が子葉と決まる。

📚 前提知識

  • 種子は、外側の種皮（ア）、養分をたくわえる胚乳（イ）、植物のもとになる胚（ウ）からできている。胚はさらに子葉・胚軸・幼根に分かれる。
  • カキは胚乳に養分をたくわえる種子。胚乳が大きく、胚は小さいので、図でも胚が小さく描かれている。

🔍 こう読み解く

  1. イの線は、種子の大部分をしめる灰色の部分へ引かれている → 養分の入れ物の胚乳。
  2. ウはエ・オ・カをまとめた印 → 胚。胚の中で、上にあって2枚の葉の形になるエが子葉。下のとがった側（カ）が幼根、その間（オ）が胚軸。
答え：イ 胚乳　エ 子葉
今回：胚乳・子葉 ○。

CP (2) インゲンマメの種子・最初に出てくる部分 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】設問の「発芽するときに最初に種子から出てくる」に丸 → 名前は幼根と決まる。あとは図2の小さな部分（ケ・コ・サ）のいちばん下をさがす。根は下へ出るので、下側に引かれたサ。

📚 前提知識

  • インゲンマメは胚乳がなく、養分は子葉（ク）にたくわえる。だから子葉が大きく、図の2つの丸い部分が子葉。
  • 発芽の順番は幼根 → 胚軸 → 幼芽。まず根が出て水を吸い、そのあと茎がのびて子葉が持ち上がる。

🔍 こう読み解く

  1. 「最初に出てくる」＝根 → 答えの名前は幼根。
  2. 図2の右の子葉についた小さな部分を上から見る。ケ＝小さな葉の形（幼芽）、コ＝そのつけ根（胚軸）、サ＝いちばん下（幼根）。
  3. キは外側の線（種皮）、クは丸い大部分（子葉）。幼根はサ。
答え：部分 サ　名前 幼根
今回：サ・幼根 ○。

CP (3) カキと同じ部分（胚乳）に養分をたくわえる植物 知識問題

ア イネ・エ マツ。カキは(1)のとおり胚乳に養分をためる種子（有胚乳種子）。同じなかまはイネ・ムギ・トウモロコシ・マツ・カキ。選ばないイ エンドウ・ウ クリは、インゲンマメやダイズ・アブラナと同じで養分を子葉にためる（無胚乳種子）。マメのなかま（エンドウ・インゲンマメ・ダイズ）とクリ・アブラナは子葉、穀物（イネ・ムギ・トウモロコシ）とマツ・カキは胚乳、と2組に分けて覚える。2つ選ぶ指定。
答え：ア・エ
今回：ア・エ ○。問題用紙でイ・ウを線で消し、ア・エに丸をつけてから選んでいる。4つ全部に印をつける手順ができている。

CP (4) 呼吸で二酸化炭素といっしょにできる物質 知識問題

水。呼吸は「養分＋酸素 → 二酸化炭素＋水＋エネルギー（熱）」で、光合成の式をちょうど逆にした形。光合成が「水＋二酸化炭素 → でんぷん＋酸素」なので、呼吸でできるのは水と二酸化炭素。コアプラスの言葉は「水」で、「水蒸気」と書くと×になる。
答え：水
今回：水蒸気 ×。知識＝呼吸の式の右側を「水」と覚え直す。光合成の式の左側（水・二酸化炭素）をそのまま右へ持ってくると出てくる。

CP (5) 水酸化ナトリウム水溶液の代わりに使えるもの 資料問題・図の役目

👀 まず見るところ

【資料問題】部品は図3の「水酸化ナトリウム水溶液」と設問の「代わりとして使える」。この水溶液の役目を1行で書く：「二酸化炭素を吸う」→ 同じ役目ができる水溶液をさがす。

📚 前提知識

  • 水酸化ナトリウム水溶液は二酸化炭素をよく吸収する。びんの中に置くと、ダイズが出した二酸化炭素がすぐに吸われて、気体として残らない。
  • 石灰水も二酸化炭素を吸収する（吸収して白くにごる）。塩酸・アルコール水・砂糖水に二酸化炭素を吸う力はない。

🔍 こう読み解く

  1. 図3と図4のちがいは、びんの中の小さな容器の中身だけ（水酸化ナトリウム水溶液／水）。つまりこの水溶液は二酸化炭素を取りのぞくために入っている。
  2. 二酸化炭素を吸収できる水溶液はウの石灰水。ア・イ・エは吸収しない。
答え：ウ
今回：ウ ○。

CP (6) ダイズが吸収した酸素の量 条件文・計算

👀 まず見るところ

【条件文】部品は図3の「左に4cm³分動く」と「水酸化ナトリウム水溶液」。図3の横に「二酸化炭素＝0、動いた分＝酸素」と直して書く → 4cm³がそのまま吸収した酸素の量になる。

📚 前提知識

  • 赤インクがびんの側（左）へ動くのは、びんの中の気体が減ったから。減った分の体積が、動いた分の体積。
  • 図3では、呼吸で出た二酸化炭素は水酸化ナトリウム水溶液に全部吸われる。だから気体が減った理由は酸素を吸ったことだけ。

🔍 こう読み解く

  1. 気体の減り＝吸った酸素−出た二酸化炭素（気体のまま残った分）。
  2. 図3は二酸化炭素が残らないので、減り＝吸った酸素 → 4cm³。
答え：4cm³
今回：2.4 ×。部品の形を直さなかった＝図3の「水酸化ナトリウム水溶液」を「二酸化炭素は残らない→4は酸素だけ」に直していない。(5)で役目は分かっていたので、次は図3の横にこの1行を書いてから式に入る。

CP (7) ダイズが放出した二酸化炭素の量 条件文・計算

👀 まず見るところ

【条件文】(6)と変わった部品は図4の「0.8cm³」と、容器の中身が「水」。図4の横に「酸素−二酸化炭素＝0.8」と直して書く → 酸素は(6)の4なので、ひき算で二酸化炭素が決まる。

📚 前提知識

  • 図4の水は二酸化炭素を吸わない。吸った酸素のぶん減り、出た二酸化炭素のぶん増えるので、インクはその差だけ動く。
  • ダイズの吸う酸素と出す二酸化炭素の量は同じではない。同じなら図4のインクは動かないはずで、0.8動いたのは出した二酸化炭素のほうが少ないから。

🔍 こう読み解く

  1. 図3より、吸った酸素＝4cm³（図4でも同じダイズなので同じ）。
  2. 図4の式：4−二酸化炭素＝0.8。
  3. 二酸化炭素＝4−0.8＝3.2cm³。
答え：3.2cm³
今回：1.6 ×。(6)の2.4と(7)の1.6は「たして4・ひいて0.8」になる組で、図3の4を酸素と二酸化炭素の合計と読んだとみられる。部品の形を直さなかった＝図3は「二酸化炭素0」、図4は「差」と、2つの図の横にそれぞれ1行書いてから式を立てる。
コツ：図3＝酸素だけ／図4＝酸素−二酸化炭素。この2行がそろえば、式は「4−0.8」の1本で終わる。

CP (8) ヨウ素液で青紫色になる部分 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】聞かれ方「すべて選び」に線。図7の部品は2つ：点線の四角＝アルミはくで日光なし、白い部分＝ふで葉緑体なし。この2つのどちらにも入らない場所だけが青紫色になる。

📚 前提知識

  • ヨウ素液が青紫色になるのは、でんぷんがあるところ。でんぷんは、葉緑体が日光を受けて光合成したところにできる。
  • 一晩暗いところに置くのは、前の日のでんぷんを使い切って（運び出して）、実験で作った分だけを調べるため。
  • 図6の手順：熱湯（葉をやわらかくする）→ 湯であたためたアルコール（緑色をぬいて、色の変化を見やすくする）→ 水（アルコールを洗い流す）。

🔍 こう読み解く

  1. 図7のア〜オを「日光」「葉緑体」の2つで仕分けする。ア＝緑・日光あり、イ＝ふ・アルミはく、ウ＝緑・アルミはく、エ＝ふ・日光あり、オ＝緑・日光あり。
  2. 両方そろうのはアとオ。ウは葉緑体はあるが日光がない、エは日光はあるが葉緑体がない、イはどちらもない。
答え：ア・オ
今回：ア・オ ○。

CP (9) この実験から分かる、でんぷんづくりに必要な条件 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は設問の「(8)の実験から分かる」と「すべて」。知っている条件を全部書くのではなく、実験でくらべた条件だけに直す。図7でくらべているのは、アルミはくの有無（日光）と、ふの有無（葉緑体）の2つ。

📚 前提知識

  • 光合成に必要なものは、日光・葉緑体・二酸化炭素・水。ただし「実験から分かる」と聞かれたら、答えるのはその実験で結果に差が出た条件だけ。
  • 二酸化炭素が必要かを調べるなら、二酸化炭素をぬいたふくろをかぶせる葉と、かぶせない葉をくらべる実験が別に要る。この実験にはそれがない。

🔍 こう読み解く

  1. アとウのくらべ：ちがいはアルミはくだけ。アだけ青紫 → 日光が必要（ウ）。
  2. アとエのくらべ：ちがいはふだけ。アだけ青紫 → 葉緑体が必要（オ）。
  3. 酸素・二酸化炭素・水は、この実験では変えていないので「この実験から分かる」とは言えない → 選ばない。
答え：ウ・オ
今回：ウ・オ ○。

CP (10) 暗いところに置くのを忘れた場合 条件文・すべて選ぶ

👀 まず見るところ

【条件文】(8)と変わった部品は「暗いところに置くのを忘れて」。これを「前の日のでんぷんが残ったまま」に直して書く → 日光があってもなくても、葉緑体がある部分には全部でんぷんがある。

📚 前提知識

  • 葉は昼の光合成でためたでんぷんを、夜のあいだに糖に変えて運び出す。暗いところに置かないと、緑の部分すべてに前の日のでんぷんが残っている。
  • ふの部分には葉緑体がないので、前の日もでんぷんは作られていない。

🔍 こう読み解く

  1. (8)で青紫になったア・オはそのまま青紫。
  2. ウは、アルミはくで今日の光合成はできていないが、前の日のでんぷんが残っている → 青紫になる。
  3. イ・エはふ（葉緑体なし）なので、前の日もでんぷんなし → 変わらない。緑の部分すべて＝ア・ウ・オ。
答え：ア・ウ・オ
今回：ア・ウ・オ ○。(8)の答えにウを足す形で決められている。

CP まとめ 70点（10問中7問）

  • 取れた：(1)(2)(3)(5)(8)(9)(10)。種子のつくりと、ふ入りの葉の仕分け（日光×葉緑体）は読めている。
  • 落とした(6)(7)は1つの読みちがい：図3の「水酸化ナトリウム水溶液」を「二酸化炭素は残らない → 動いた4は酸素だけ」に直せていない。図3の横にこの1行、図4の横に「酸素−二酸化炭素」の1行を書いてから式を立てる。
  • 覚え直しは1つ。呼吸の式は「養分＋酸素 → 二酸化炭素＋水」。水蒸気ではなく水。
