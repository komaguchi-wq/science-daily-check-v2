L 全体像 化学 3問（石灰水・中和）＋天体 7問（オリオン座と星の動き）（100点満点）

L (1) 石灰水に息を吹き込むとできる白いにごり 知識問題

① 炭酸カルシウム　② 溶けません。石灰水（水酸化カルシウムの水溶液）に二酸化炭素が入ると、炭酸カルシウムができる。石灰石や貝がらと同じ物質で、水に溶けないので小さな粒のまま液の中に散らばり、白くにごって見える。もし水に溶ける物質なら、液は透明のままでにごらない。「にごる＝溶けない」をひとまとまりで考える。
答え：① 炭酸カルシウム　② 溶けません

L (2) A液100cm³とB液100cm³を混ぜた液の性質 条件文・中和

👀 まず見るところ

【条件文】部品は「A液40cm³とB液50cm³で中性」。これを「A100 なら B は125必要」に直して書く → 混ぜるBは100しかないのでBが足りない＝塩酸が余ると決まる。

📚 前提知識

  • 塩酸と水酸化ナトリウム水溶液は、決まった体積の比でちょうど中和する。比からずれた分は、そのまま余る。
  • 混ぜた液の性質は、余ったほうで決まる。塩酸が余れば酸性、水酸化ナトリウム水溶液が余ればアルカリ性。

🔍 こう読み解く

  1. ちょうど中和する比は A：B＝40：50＝4：5。
  2. A100cm³ を中和するのに必要なBは 100×5÷4＝125cm³。Bは100cm³しかない。
  3. Bが足りない → 塩酸（A）が余る → 酸性。別の見方：B100 を中和するにはAが80で足りるので、Aが20余る。
答え：酸性
自分で解くときのチェック：「同じ100cm³ずつだから中性」と思わない。中性になる比は40：50で、100：100ではない。

L (3) 混ぜた液の水分を蒸発させて残る食塩 条件文・中和の計算

👀 まず見るところ

【条件文】部品は「(2)のとき」と「1.2gの食塩」。(2)で書いた「Bが足りない」を「B100cm³は全部中和に使われた」に直して書く → 食塩は B50cm³ のときの2倍と決まる。

📚 前提知識

  • 食塩は、中和した分だけできる。余った塩酸は、水分を蒸発させると水といっしょに出ていき、あとに何も残らない（塩化水素は気体）。
  • 余るのが水酸化ナトリウムのときは、固体として残るので答えに足す。どちらが余ったかで、残る固体のふえ方が変わる。

🔍 こう読み解く

  1. A40：B50 の中和で食塩1.2g。つまり B50cm³ が中和すると 1.2g。
  2. (2)では B100cm³ がすべて中和に使われた（相手のAは80cm³）→ Bが2倍なので食塩も2倍。
  3. 1.2×2＝2.4g。余ったA20cm³は何も残さない。
答え：2.4g
自分で解くときのチェック：A100cm³ をもとに 1.2×100÷40＝3g としない。中和に使われたAは80cm³だけ。使い切ったほう（B）で計算する。

L (4) 地平線付近のオリオン座と星Aの名前 資料問題・東西と星の名前

👀 まず見るところ

【資料問題】資料の正体「地平線付近のオリオン座」を1行。部品は図の「三つ星がたて」と、大きな2つの星A・B。三つ星がたて＝東の空と決まり、東を向くと左が北なので、北側の1等星ベテルギウスが左のA。

📚 前提知識

  • オリオン座は、東の空では三つ星がたて（立った姿）で昇り、南の空ではななめ、西の空ではよこに近い姿で沈む。三つ星の向きで、東か西かが決まる。
  • オリオン座の1等星は2つ。ベテルギウス（赤・肩・三つ星より北側）とリゲル（青白・足・三つ星より南側）。南中したときは左上がベテルギウス、右下がリゲル。

🔍 こう読み解く

  1. 三つ星がたてに立っている → 昇ってくるところ → 東。
  2. 東を向くと左手が北、右手が南。三つ星より北側にある1等星はベテルギウス → 左のA＝ベテルギウス、右のB＝リゲル。
  3. 確かめ：南中した姿（左上ベテルギウス・右下リゲル）を、三つ星がたてになるまで左回りに回すと、ベテルギウスが左、リゲルが右にくる。図と合う。
答え：① 東　② ベテルギウス
自分で解くときのチェック：西の空なら三つ星はよこに近く、ベテルギウスが右上・リゲルが左下と左右が入れかわる。「たて＝東」を先に決めてから星の名前へ進む。

L (5) オリオン座が午後8時頃に南中する月 知識問題

2月。オリオン座は2月中旬の午後8時ごろに南中する冬の代表の星座で、ベテルギウスはシリウス・プロキオンと冬の大三角をつくる。星の南中は1か月に約2時間ずつ早まるので、1月中旬なら午後10時、3月中旬なら午後6時に南中する。「2月・午後8時」を基準にして前後を出す。
答え：2月

L (6) 三つ星の動きを表す弧 資料問題・星の道

👀 まず見るところ

【資料問題】資料の正体「星の動きを表した半球の図・北が左・南が右・東がおく・西が手前」を1行。部品は「三つ星」→「三つ星は天の赤道の上にある」に直して書く → 道は「東」と「西」の文字の点を通る弧と決まる。

📚 前提知識

  • オリオン座の三つ星は、ほぼ天の赤道の上にある。天の赤道上の星は、真東から出て真西に沈む。
  • 北寄りの星は北東から出て北西に沈み（道イ）、南寄りの星は南東から出て南西に沈む（道エ）。北極星の近くの星は地平線の下に入らず、ぐるりと回る（道ア）。

🔍 こう読み解く

  1. 図の「東」の点から出ている弧をさがす。点線で「東」から頂点へ上がり、実線で「西」の点に下りる弧はウ。
  2. イは「東」より北側の地平線から出ている。エは「東」より南側から出ている。アは地平線に届かない。
  3. 真東から出て真西に沈む道はウだけ → ウ。
答え：ウ
自分で解くときのチェック：点線（おく側）と実線（手前側）は同じ1本の道。弧の出発点が「東」の文字にぴったり重なっているかを見る。

L (7) 北緯36度の地点でのXの角度 条件文・緯度と星の道

👀 まず見るところ

【条件文】部品は「北緯36度」と図の角X＝観測者から見た道ウのいちばん高い所の角度（三つ星の南中高度）。36度を「北極星の高さ＝36度」に直して図の左の角に書く → X＝90−36 と決まる。

📚 前提知識

  • 北極星の高度は、その地点の緯度と同じ。北緯36度なら36度。
  • 星の道（天の赤道）は、北極星の方向に対して直角。だから天の赤道が地平線となす角は 90度−緯度。天の赤道上の星の南中高度も同じ 90度−緯度 になる。

🔍 こう読み解く

  1. 図の中心（観測者）から出る2本の点線を見る。左の点線は北極星の方向で、地平線との角＝北極星の高さ＝36度。
  2. 右の点線は道ウのいちばん高い所（南中）へのび、地平線との角がX。天の赤道上の星の南中高度は 90−緯度 → X＝90−36＝54。
  3. 確かめ：道ウが地平線と交わる角も 90−36＝54度で同じ値。
答え：54度
自分で解くときのチェック：36度をそのまま答えに書かない。36度は北極星の高さ（図の左の角）で、聞かれているのは南の空での三つ星の高さ（右の角X）。

L (8) 星A・Bが地平線から出て沈むまでの時間 資料問題・北寄りの星と南寄りの星

👀 まず見るところ

【資料問題】部品は「(4)の星A・B」と「それぞれ」。(4)の「A＝北側・B＝南側」を(6)の図の道イ・道エに置きかえる → 北寄りの道は地平線の上の部分が半分より長いと決まる。

📚 前提知識

  • 天の赤道上の星（道ウ）は、真東から真西までちょうど12時間で動く。
  • 北寄りの星（道イ）は、道のうち地平線より上の部分が半分より長いので、出てから沈むまで12時間より長い。南寄りの星（道エ）は短い。夏の太陽が長く出ているのと同じ理屈。

🔍 こう読み解く

  1. A＝ベテルギウスは三つ星より北側 → 道イ → 12時間より長い → 選択肢ア。
  2. B＝リゲルは三つ星より南側 → 道エ → 12時間より短い → 選択肢イ。
  3. 三つ星そのものなら道ウで、ちょうど12時間（選択肢ウ）。
答え：A ア　B イ
自分で解くときのチェック：選択肢の「ア・イ・ウ」と図の道の「イ・ウ・エ」は別の記号。解答らんに書く直前に、どちらの記号かを見直す。

L (9) オリオン座の南中高度が最も高くなる時期 素材文・選択

👀 まず見るところ

【素材文】部品は「南中高度」と「オリオン座」に丸。季節で南中高度が変わるのは太陽の話で、星は変わらない → 「最も高くなる時期」は無く、1年中変わらないと決まる。

📚 前提知識

  • 太陽の南中高度が季節で変わるのは、地球が地軸をかたむけたまま太陽のまわりを回るから（夏至に高く、冬至に低い）。
  • 星は地球からはるかに遠く、見える方向が1年を通して変わらない。星の南中高度は緯度と星の位置だけで決まり、季節は入らない。北緯36度なら三つ星の南中高度はいつも54度。
  • 季節で変わるのは、南中する時刻のほう（1か月に約2時間早まる）。

🔍 こう読み解く

  1. 「南中高度」で、太陽の問題と見分ける。聞かれているのは星座。
  2. 星の南中高度は季節で変わらない → 3月でも12月でも同じ高さ。
  3. → オ。
答え：オ
自分で解くときのチェック：「3月・6月・9月・12月」と月が並ぶと、季節で変わると思いやすい。変わるのは「見える時刻」で、「高さ」ではない。

L (10) 1等星は5等星の約何倍の明るさか 知識問題

約40倍。1等級ちがうごとに明るさは約2.5倍。1等星と5等星は4等級差なので、2.5×2.5×2.5×2.5≒39 → 約40倍。基準は「1等星は6等星（5等級差）の100倍」で、そこから1等級あたり約2.5倍と覚える。6等星との100倍と取りちがえない。
答え：40倍

L まとめ 解く前に紙に置く3つ

  • 中和は「どちらが余るか」を先に書く。(2)はBが足りない＝塩酸が余る→酸性。(3)の食塩は使い切ったB100cm³で計算して 1.2×2＝2.4g。
  • オリオン座は三つ星がたて＝東の空。東を向くと左が北なので、左のAが北側の1等星ベテルギウス、右のBがリゲル。(8)はこの北・南をそのまま使い、北寄りのAは12時間より長い。
  • 北極星の高さ＝緯度36度を図に置く。三つ星の道は「東」「西」を通る弧ウ、南中高度X＝90−36＝54度。星の南中高度は1年中同じで、変わるのは時刻（2月中旬 午後8時）。

M (1) 塩酸はA液とB液のどちらか 資料問題・表の読み取り

👀 まず見るところ

【資料問題】部品は表の正体「A液40のまま・B液だけ増やす・残った固体g」と右はしの「1.5→1.5」。B液を増やしても固体が増えない＝余ったB液は何も残さない → B液が塩酸と決まる。

📚 前提知識

  • 塩酸は気体（塩化水素）が水にとけたもの。蒸発させると何も残らない。水酸化ナトリウム水溶液は固体がとけたもので、蒸発させると白い固体が残る。
  • 中和でできる食塩は固体として残る。中和が終わったあとに余った液が「固体を残すか残さないか」で、どちらが塩酸かを見分ける。

🔍 こう読み解く

  1. 固体はB液10cm³ごとに0.1gずつ増え、50cm³で1.5g。60cm³でも1.5gのまま → 50cm³で中和が終わり、その先のB液は余っている。
  2. 余ったB液は固体を増やしていない → B液＝塩酸。もしB液が水酸化ナトリウム水溶液なら、余った分がそのまま固体になって増え続けるはず。
  3. 確かめ：表を左に1列のばすとB液0cm³で固体1.0g。A液だけでも固体が残る → A液は水酸化ナトリウム水溶液で合う。
答え：B液
今回：B液 ○。

M (2) 食塩の重さのグラフ 資料問題・グラフえらび

👀 まず見るところ

【資料問題】部品は縦軸の正体「食塩の重さ」（固体ぜんぶではない）。食塩は中和でできる分だけ → 0から始まり、中和が終わる50cm³で止まる形と決まる。

📚 前提知識

  • 食塩は塩酸と水酸化ナトリウムが中和したときにだけできる。B液（塩酸）が0なら食塩も0。
  • 中和が終わったあとは塩酸が余るだけで、食塩はそれ以上増えない。

🔍 こう読み解く

  1. B液0cm³ → 食塩0g。0から始まるグラフはアとイだけ。ウは1.0gから始まる「固体ぜんぶ」（表そのもの）のグラフ。
  2. 50cm³で中和完了。その先は食塩が増えない → 横ばいになるア。イはのび続けるので×（B液が水酸化ナトリウム水溶液だったときの固体ぜんぶの形）。
答え：ア
今回：ウ ×。部品を拾えなかった＝縦軸の正体「食塩の重さ」でなく、表の「固体」のグラフを選んだ。固体＝食塩＋余った水酸化ナトリウムなので、ウは(2)のアと(3)のエを足した形。縦軸の言葉に丸をつけ、「0から始まるか」を先に見る。

M (3) 水酸化ナトリウムの重さのグラフ 資料問題・グラフえらび

👀 まず見るところ

【資料問題】部品は縦軸の正体「水酸化ナトリウムの重さ」。最初はA液40cm³分の1.0gが全部残っていて、中和で減り、50cm³で0になる形と決まる。

  2. 減っていって50cm³で0、その先も0 → エ。
  3. 確かめ：(2)のア（食塩）＋(3)のエ（水酸化ナトリウム）＝ウ（固体ぜんぶ）。3本で1組。

今回：エ ○。

M (4) A液100cm³とB液100cm³で残る固体 条件文・比例計算

👀 まず見るところ

【条件文】部品は「A液100cm³とB液100cm³」。A：B＝1：1 に直して書く → 表の「40と40」の列（固体1.4g）と同じ混ぜ方なので、100÷40＝2.5倍するだけで決まる。

📚 前提知識

  • 同じ割合で混ぜれば、残る固体の重さも液の量に比例する。
  • 中和はA液40：B液50で完了。1：1はB液（塩酸）が足りない混ぜ方なので水酸化ナトリウムが余り、固体は食塩＋水酸化ナトリウム。

🔍 こう読み解く

👀 まず見るところ

【資料問題】部品は図の②＝核の「DNA」から出て「リボソーム」へ向かう短い断片と、本文の「DNAから…コピーした断片をmRNA」に丸。DNAのコピーがリボソームへ行く、と図の横に書く → ②はmRNAと決まる。

📚 前提知識

  • DNAは核の中にあり、核の外には出ない。たんぱく質づくりに必要な部分だけをコピーした断片（mRNA）が核を出て、リボソームへ情報を運ぶ（本文）。
  • mRNA＝情報を運ぶ、tRNA＝アミノ酸を運ぶ。「運ぶもの」で2つを区別する。解答冊子はmRNAワクチンの例をあげている。

🔍 こう読み解く

  1. 図で②の線がつながる先を2つ見る → 核の中のDNAのそば（白い矢印の元）と、リボソームへ入る短い断片。
  2. DNAからコピーされてリボソームへ行くのは、本文の「mRNA」。
  3. tRNAは図に名前が書いてあるので、残りのRNAである②はmRNA。
答え：mRNA
今回：mRNA ○。

  • 落とした(3)①は知識型だが、名前は分かっていて最後の1字だけ「レ」になった。カタカナの名前は、書いたあとに1字ずつ区切って読み返す。
  • 覚え直しはこの2つ：エンドウの遺伝＝メンデル／mRNA＝DNAのコピー（情報を運ぶ）・tRNA＝アミノ酸を運ぶ。
