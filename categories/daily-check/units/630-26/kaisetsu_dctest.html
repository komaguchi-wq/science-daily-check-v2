DC1 (1) 前線Aの種類 資料問題・名前を書く

👀 まず見るところ

【資料問題】部品は資料の正体「低気圧の中心が東へ進んでいます」（矢印）と、図の「北」の向き。「低」からAは南西へ、Bは南東へのびている、と図に書く → 温帯低気圧の型そのもので、南西が寒冷前線と決まる。

📚 前提知識

  • 温帯低気圧は寒気と暖気の境目でできる（解答冊子）。北半球では、中心から南西に寒冷前線、南東に温暖前線がのび、2本にはさまれた南側が暖気。
  • 梅雨前線・秋雨前線は停滞前線。動かない前線で、「東へ進む低気圧」の図には出てこない。

🔍 こう読み解く

  1. 「低」を起点に、Aの線をたどる → 左下（南西）へのびる。Bは右下（南東）へのびる。
  2. 南西側の前線＝寒冷前線。図の横に「A＝寒冷」「B＝温暖」と書いておく。(2)〜(7)で何度も使う。
答え：寒冷前線
今回：梅雨 ×（正解 寒冷前線）。部品を拾えなかった＝「低」からどちらへのびているかを図から取らず、前線の名前だけを思い出した。図1には鉛筆の線があるが、「A＝寒冷」のメモはない。次は「低」から南西か南東か、を先に書く。

DC1 (2) 前線A・Bの記号 資料問題・図にかく

👀 まず見るところ

【資料問題】部品は(1)で決めた「A＝寒冷・B＝温暖」と、矢印「東へ進んでいます」。印は前線が進む側（ここでは東側）に置く → Aは線の東側に▲、Bは線の東側に半円、と決まる。

📚 前提知識

  • 寒冷前線＝▲（寒気が暖気の下へもぐりこんで押す形）、温暖前線＝半円（暖気が寒気の上へはい上がる形）。印の向きが、その前線の進む向き。

🔍 こう読み解く

  1. Aの線の右（東）側に、▲を進む向きに並べる。
  2. Bの線の右（東）側に、半円を並べる。解答冊子の図では、Aの▲もBの半円も東側についている。
答え：前線A＝線の東側に▲、前線B＝線の東側に半円（解答冊子の図）
今回：×。答案はA・Bとも三角の印で、Aの三角は線の西側についている。知識＝「寒冷＝▲・温暖＝半円」の対応と「印は進む側（東側）」の決まり。(1)でBが温暖前線と決まれば、半円を使う所まで自動で決まる。

DC1 (3) 速く進むのはどちらの前線か 知識問題

A（寒冷前線）。寒気は重く、暖気の下にもぐりこんで押し進むので、温暖前線より速い。だから寒冷前線はやがて温暖前線に追いつき、重なって閉塞前線になる。「追いつく方が速い」と結びつけて覚える。
答え：A
今回：A ○。

DC1 (4) 最も気温が高い地点 資料問題・C〜Fから選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「最も気温が高い」と、図の「2本の前線にはさまれた南側」。ここに「暖気」と書きこむ（図に置く）→ その中にある地点E、と決まる。

📚 前提知識

  • 温帯低気圧は南側に暖気、北側に寒気（解答冊子）。暖気があるのは寒冷前線と温暖前線にはさまれた部分だけで、そこ以外のC・D・Fは寒気の中。

🔍 こう読み解く

  1. 図1でAとBにはさまれた南側をなぞる → 中にあるのはEだけ。
  2. DはAの西側（寒冷前線が通ったあと＝寒気が入った）、FはBの東側（温暖前線がまだ来ていない＝寒気）、Cは北側 → どれも寒気。
答え：E
今回：D ×（正解E）。部品を拾えなかった＝「2本にはさまれた南側＝暖気」を図に置かずに選んだ。DはAの西側、つまり寒冷前線が通過したあとで寒気の側。次は暖気の部分を先に図でぬる。

DC1 (5) 積乱雲が発生している地点 資料問題・C〜Fから選ぶ

👀 まず見るところ

【資料問題】部品は「入道雲（積乱雲）」に丸。積乱雲は寒冷前線のすぐ西側にできる、と図のAの左に書く（図に置く）→ そこにある地点D、と決まる。

📚 前提知識

  • 寒冷前線では寒気が暖気を急にもち上げるので、西側（通過した直後）に積乱雲ができ、短時間に強い雨が降る（解答冊子）。
  • 温暖前線では暖気がゆるやかにはい上がるので、東側に乱層雲が広がり、長時間おだやかな雨。F側はこちら。

🔍 こう読み解く

  1. 積乱雲＝寒冷前線（A）の西側。Aのすぐ左にあるのはD。
  2. C（低気圧の北）、E（暖気の中）、F（温暖前線の東＝乱層雲）は合わない。
答え：D
今回：C ×（正解D）。知識＝積乱雲は寒冷前線のすぐ西側、という「雲の場所」が置けていない。(4)と(5)は裏表で、暖気のEがいちばん暖かく、Aを越えたDで積乱雲、と2つセットで図に書く。

DC1 (6) 地点Eの風向きの変化 まざり型・ア〜エから選ぶ

👀 まず見るところ

【まざり型→資料問題】部品は「地点E」と「前線Aの通過により」に丸。Eは今は暖気の中（Aの東）、Aが通過すると寒気の中（Aの西）になる、と図に矢印で置く → 南西の風から北西の風、と決まる。

📚 前提知識

  • 低気圧のまわりの風は、反時計回りに中心へふきこむ。中心の南側（暖気の中）では南西の風、寒冷前線が通ったあとの西側では北西の風。
  • 寒冷前線の通過＝風が南寄りから北寄りに急に変わり、気温が下がる。この3つはいつもセット。

🔍 こう読み解く

  1. 通過前：EはAとBの間の南側 → 南西から暖気がふきこむ → 南西の風。
  2. 通過後：Aが東へ進んでEを追いこすと、Eは寒気の側 → 北西の風。
  3. 「南西 → 北西」の組み合わせはエ。ア・イは北東が入り、ウは最後が南西で、どれも「北寄りに変わる」に合わない。
答え：エ
今回：エ ○。

DC1 (7) 前線A・Bの雨と気温 素材文・ア〜エから選ぶ

👀 まず見るところ

【素材文】設問は「それぞれ」なので2つ答える。部品は選択肢の「長時間おだやか／短時間に強い」と「上がる／下がる」の2語に丸 → A＝寒冷なら「短時間・下がる」、B＝温暖なら「長時間・上がる」と決まる。

📚 前提知識

  • 寒冷前線：積乱雲 → 短時間に強い雨、通過後は寒気が入って気温が下がる（解答冊子）。
  • 温暖前線：乱層雲 → 長時間おだやかな雨、通過後は暖気が入って気温が上がる（解答冊子）。

🔍 こう読み解く

  1. A（寒冷）＝短時間に強い雨＋下がる → エ。
  2. B（温暖）＝長時間おだやかな雨＋上がる → ア。
  3. イ（長時間＋下がる）・ウ（短時間＋上がる）は、雨と気温の組み合わせがちぐはぐ。どちらの前線にも当てはまらない。
答え：A エ　B ア
今回：A ア・B ウ ×（正解 A エ・B ア）。知識＝「寒冷＝短時間・強い・下がる／温暖＝長時間・おだやか・上がる」の2組が、(1)でAの名前が決まらなかったまま選んだ形。前線の名前が決まれば、選択肢は雨と気温の2語を見るだけで決まる。

DC1 (8) 前線を伴わない低気圧 知識問題

熱帯低気圧。赤道付近で海水があたためられ、強い上昇気流でできる低気圧で、前線はない。中心付近の最大風速が毎秒約17（17.2）m以上になると台風と呼ばれる（解答冊子）。用語は「熱帯低気圧」で、「性」は入らない。
答え：熱帯低気圧
今回：熱帯性低気圧 ×（正解 熱帯低気圧）。知識＝用語の形。「温帯低気圧」と対にして「熱帯低気圧」と4字＋3字で覚える。

DC2 (1)① オスはメスをどう感じ取っているか 記述・実験から分かること

👀 まず見るところ

【素材文】部品は図1の「透明な容器…密閉」と図2の「黒い板…ふたを開けた」に丸。横に「見える・空気×」「見えない・空気○」と3語で書く → 羽ばたいたのは空気が通る図2なので、目でなくにおいと決まる。

📚 前提知識

  • 実験で「変えたもの」が結果を決める。図1→図2で変わったのは「見えるか」と「空気が通るか」の2つ。見えなくても羽ばたいたので「見える」は関係なく、残った「空気が通る」が原因。
  • 空気で運ばれるのは、メスのからだから出る物質。それをオスはにおいとして感じる。

✍️ 答案の組み立て

  1. 要素A（何を）：メスから出される物質を。
  2. 要素B（どうやって）：においで感じ取っている。
  3. 形：「メスから出される物質を、においで感じ取っている。」
模範解答：メスから出される物質を、においで感じ取っている。
今回：5点中3点 ×（答案「においで感じとっている。」）。部品チェック＝A ×（「メスから出される物質を」がない）／B ○。「どのように感じ取っているか」には「何を」も入れる。設問の「カイコガのメスを」に丸をつければ、答えの主語の相手が見える。

DC2 (1)② オスとメスで異なるからだの部分 記述・図を見比べる

👀 まず見るところ

【素材文】設問の部品は「からだのある部分」と「どのようにオスとメスで異なるか」に丸。図1のオスとメスの絵を見比べ、ちがう所（触角）に印 → 答えは「部分の名前＋どちらが大きいか」の形と決まる。

📚 前提知識

  • ①で「におい」と決まったので、関係する部分はにおいを感じる触角。図ではオスの触角がメスより大きく、くしのように広がっている。

✍️ 答案の組み立て

  1. 要素A（部分）：触角。
  2. 要素B（ちがい）：メスよりオスの方が大きい。
  3. 形：「メスよりオスの方が、においを感じる触角が大きい。」
模範解答：メスよりオスの方がにおいを感じる触角が大きい。
今回：○（答案「オスはにおいをよく知るために触角が大きい。」）。部品チェック＝A 触角 ○／B オスの方が大きい ○。「メスより」の比べる相手まで書くと、もっと確実になる。

DC2 (2) 「猛烈な台風」の意味 素材文・ア〜エから選ぶ

👀 まず見るところ

【素材文】設問の部品は「猛烈な」に丸。「強い・非常に強い・猛烈な」は台風の強さの言葉で、強さは中心付近の風の強さで決まる（解答冊子）→ 風がとても強い＝ウ、と決まる。

📚 前提知識

  • 台風の「強さ」は中心付近の最大風速で「強い」「非常に強い」「猛烈な」の3段階（解答冊子）。気圧の低さや雨量では決めない。
  • 台風の「大きさ」は強風域の広さで「大型」「超大型」。「強さ」と「大きさ」は別の言葉。

🔍 こう読み解く

  1. 「猛烈な」は強さの言葉 → 強さを決めるのは風 → ウ。
  2. ア（気圧）は、低いほど風は強くなるが、呼び方を決める基準ではない。イ（雨量）・エ（速さ）も基準ではない。
答え：ウ
今回：ア ×（正解ウ）。知識＝台風の呼び方の基準は「風」。「猛烈な（強さ）＝風速、大型（大きさ）＝強風域の広さ」を2組セットで置き直す。
