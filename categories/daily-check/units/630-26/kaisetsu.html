630-26 確認1（7ページ・細胞の呼吸と血液の流れ）

確認1 全体像 文章の穴うめ＋知識 9問

文章の空らんA・B・Cで決まるのは(3)(4)だけ。残りの7問は、消化・肺・血液・心臓の一問一答で、文章を読み直さなくても答えられる。先に(1)(2)(5)(7)(8)(9)を片づけ、文章は(3)(4)のためだけに読むと速い。

文章のつながりは1本。ブドウ糖＋酸素 → エネルギー＋二酸化炭素＋水。これが細胞の呼吸で、出た二酸化炭素は血液で肺へ運ばれて外へ出る。ここに(3)(4)(6)(7)(9)が全部ぶら下がっている。

確認1 (1) デンプンを消化する消化こう素 知識問題

アミラーゼ。だ液に含まれ、デンプンを麦芽糖に分解する。ペプシンは胃液でたんぱく質を分解、カタラーゼは過酸化水素を分解する酵素（解答冊子）。「デンプン＝アミラーゼ、たんぱく質＝ペプシン」の組で覚える。
答え：イ

確認1 (2) ブドウ糖を吸収する内臓 知識問題

小腸。内側の壁にある柔毛（柔突起）の毛細血管からブドウ糖を取り入れる。柔毛が無数にあるのは、表面積を大きくして効率よく吸収するため（解答冊子）。胃や十二指腸は消化の場で、吸収の中心ではない。
答え：エ

確認1 (3) ブドウ糖が分解されてできる（A）と（B） 素材文・組み合わせ選択

👀 まず見るところ

【素材文】部品は文章の最後の「（A）は血液によって肺に運ばれ、そこから体外に排出」に丸 → 肺から出すものはA＝二酸化炭素と決まる。選択肢は二酸化炭素を含むイ・オ・カの3つに絞られる。

📚 前提知識

  • 細胞の呼吸：ブドウ糖を酸素で分解してエネルギーを取り出し、二酸化炭素と水が出る（解答冊子）。燃えるときと同じで、炭素は二酸化炭素に、水素は水になる。

🔍 こう読み解く

  1. Aは肺から外へ出る気体 → 二酸化炭素。二酸化炭素を含むのはイ「ちっ素と二酸化炭素」・オ「水素と二酸化炭素」・カ「二酸化炭素と水」の3つ。
  2. 「分解される時につくられる」のは、ブドウ糖が酸素と結びついてできるもの。ちっ素は体で使われも作られもしない気体、水素は燃料側であって、できるものではない → B＝水。
  3. 組み合わせは「二酸化炭素と水」＝カ。
答え：カ
コツ：空らんが2つあるときは、文章から決まる方（A）を先に固め、選択肢を減らしてから残りを考える。

確認1 (4) （C）のはたらきの名前 素材文・漢字2字

👀 まず見るところ

【素材文】部品は「肺から取り込んだ酸素もこの時使われます」と、設問の「漢字2文字」に丸 → 酸素を使ってブドウ糖からエネルギーを取り出すはたらき＝呼吸、と決まる。

📚 前提知識

  • 呼吸には2つの意味がある。肺で空気を出し入れする呼吸と、細胞の中で酸素を使って養分を分解しエネルギーを取り出す呼吸（細胞の呼吸）。Cは後者。

🔍 こう読み解く

  1. Cの文は「ブドウ糖が分解される時にエネルギーがつくられ、酸素が使われ、（A）＝二酸化炭素が出る」。これが細胞の呼吸の定義そのもの。
  2. 答え方は漢字2文字なので「呼吸」。「細胞の呼吸」「燃焼」「代謝」と書かない。
答え：呼吸

確認1 (5) 肺をつくる小さな袋 知識問題

肺胞。直径0.1〜0.2mmの袋が多数集まっていて、空気とふれる表面積を大きくし、気体の交換の効率を上げている。まわりを毛細血管が取り巻き、そこで酸素と二酸化炭素を交換する（解答冊子）。(2)の柔毛と同じ「小さいものを多数＝表面積を大きく」の考え方。
答え：肺胞

確認1 (6) 肺胞の図のEにつながる血管 資料問題・血管の名前

👀 まず見るところ

【資料問題】図の正体は「肺胞のまわりの毛細血管・D→Eの向きに血が流れ、酸素が血に入る」の1行。矢印の向きを見れば、Eは酸素をもらったあとの血が出ていく側と決まる。

📚 前提知識

  • 右心室 → 肺動脈 → 肺 → 肺静脈 → 左心房。肺動脈には酸素の少ない静脈血、肺静脈には酸素の多い動脈血が流れる（解答冊子）。
  • 血管の名前は「心臓から出る＝動脈／心臓にもどる＝静脈」で決まり、中の血の酸素の多さとは別の話。肺のまわりだけ逆になる。

🔍 こう読み解く

  1. Dの矢印は肺胞に向かって入り、Eの矢印は肺胞から出ていく。酸素の矢印は肺胞から血管へ向いている → Eの血は酸素をもらったあと。
  2. 肺を出て心臓（左心房）にもどる血管は肺静脈。だからE＝肺静脈、D＝肺動脈。
答え：肺静脈
コツ：図を見たらD・Eの横に「酸素少→多」と書き、「肺にもどる血は静脈」と結びつける。「酸素が多いから動脈」と考えると逆になる。

確認1 (7) 酸素と結びつく血液中の細胞 知識問題

赤血球。含まれるヘモグロビンが、酸素の多いところ（肺）で酸素と結びつき、少ないところ（体の各部）で酸素をはなす性質をもつ（解答冊子）。白血球は細菌を食べて体を守る、血小板は血を固める、血しょうは液体で養分や二酸化炭素を溶かして運ぶ、と役割で区別する。
答え：ア

確認1 (8) 肺から戻った血液が最初に入る部屋 知識問題

左心房。肺 → 肺静脈 → 左心房 → 左心室 → 大動脈 → 全身の順（解答冊子の心臓の図）。心臓の部屋は「房＝血が入ってくる上の部屋、室＝血を送り出す下の部屋」。「最初にもどる」と聞かれたら房、「送り出す」と聞かれたら室。肺から戻るのは左側、全身から戻るのは右側。
答え：ウ

確認1 (9) ブドウ糖を蓄える器官と蓄える形 知識問題

肝臓とグリコーゲン。小腸で吸収したブドウ糖を肝臓がグリコーゲンに変えて一時的に蓄え、空腹時にはブドウ糖にもどして血液へ出す（解答冊子）。だから血液中の糖の濃度が一定に保たれる。肝臓は体の中で最大の臓器で、小腸から肝臓へ血が通る血管が門脈。
答え：器官名 肝臓　物質の名前 グリコーゲン

  • (6)は図の矢印で決める。「肺にもどる血管＝肺静脈（酸素が多くても静脈）」を図の横に書いてから答える。

630-26 確認2（7ページ・血液の循環の模式図）

確認2 全体像 血液の循環の模式図 10問

図1は、心臓を真ん中に置いて「肺を回る道」と「からだを回る道」を1本の輪につないだ模式図。10問のうち8問は、図1に3つのことを書きこめば、あとは読み取るだけになる。解く前に①〜③を図に書いてから設問に入る。

書きこむことどこを見て決めるか
① 血の流れる向き（矢印）肺の2本は「右心室→肺→左心房」。からだの道は「左心室→各部→右心房」。左の列が心臓へもどる静脈、右の列が心臓から出る動脈
② 心臓の4つの部屋の名前上の2つ（肺の管とつながる側）が心房、下の2つが心室。図は体を正面から見た形なので、向かって左が「右」
③ 名前のある血管A 大静脈・B 肺静脈・C 肝静脈・E 門脈・G 腎静脈（冊子の図）

(4)〜(6)は「どの臓器を通った直後か」、(9)(10)は「動脈」と「動脈血」のちがい。言葉が1字ちがうだけで答えが変わるので、設問の言葉に丸をつけてから図を見る。

確認2 (1) 心臓の①〜④の部屋の名前 図の読み取り・用語

👀 まず見るところ

【資料問題】部品は図の正体「血液の循環の模式図」と、①②が肺からの2本の管とつながる上側にあること。上＝心房・下＝心室、向かって左＝右、と図のわきに書く → 4つの名前が決まる。

📚 前提知識

  • 血液が入ってくる部屋が心房、送り出す部屋が心室。心房は上、心室は下にある。
  • 人体の図は本人を正面から見た形で描く。だから図の左側が本人の「右」（冊子の図でも左側が右心房・右心室）。
  • 冊子の解説：左心室は全身へ血液を送り出すため強く収縮し、壁が心臓の中で最も厚い。心臓には逆流を防ぐ弁がある。

🔍 こう読み解く

  1. ①と②は肺からの管の根元にある上の部屋 → 心房。③と④は下 → 心室。
  2. 左右は本人の向き。向かって左の①③が「右」、向かって右の②④が「左」。
  3. 確かめ：①にはA（大静脈）から全身の血がもどる → 右心房で合う。②にはB（肺からの管）が入る → 左心房で合う。
答え：① 右心房　② 左心房　③ 右心室　④ 左心室
コツ：自分で解くときは、答えを書く前に「向かって左＝右」を図の上に書いたかを確かめる。

確認2 (2) 血管A・Bの名前 図の読み取り・用語

👀 まず見るところ

【資料問題】部品は「Aの血管」が左の列（からだの各部から心臓へもどる側）にあり、「Bの血管」が肺から②へ入る管であること。「どこから・どの部屋へ」を1行で書く → 名前が決まる。

📚 前提知識

  • 血管の名前は「どこへ向かうか」で決まる。心臓へもどるのが静脈、心臓から出るのが動脈。
  • 全身から右心房へもどる太い血管が大静脈、肺から左心房へもどる血管が肺静脈（冊子の解説）。

🔍 こう読み解く

  1. Aは左の列の上端。からだの各部・腎臓・肝臓から集まった血が右心房に入る直前 → 全身からもどる血管＝大静脈。
  2. Bは肺から出て左心房（②）に入る管 → 肺からもどる血管＝肺静脈。
  3. 両方セットで押さえる：大静脈には静脈血、肺静脈には動脈血が流れる（(10)で使う）。
答え：A 大静脈　B 肺静脈

確認2 (3) 毛細血管を流れる血液のはたらき 記述

👀 まず見るところ

【素材文】設問は「毛細血管に流れる血液のはたらき」を「簡単に説明」。聞かれているのは血管の形でなく、血液が細胞と何をわたし、何を受け取るか。わたす2つ・受け取る2つを3語で書き出す → 答案の骨組みが決まる。

📚 前提知識

  • 毛細血管は動脈と静脈をつなぐ非常に細い血管で、各器官に網目状に広がる。細いので、血液と細胞の間で物質のやり取りができる（冊子の解説）。
  • 確認1の文にあるとおり、細胞は酸素と養分（ブドウ糖）を使ってエネルギーをつくり、二酸化炭素などを出す。血液はその運び役。

✍️ 答案の組み立て

  1. 要素A（わたす）：細胞に酸素と養分を受けわたす。
  2. 要素B（受け取る）：細胞から二酸化炭素と不要物を受け取る。
  3. 「〜するはたらき。」で結ぶ。「細い血管です」のような形の説明だけでは、はたらきの答えにならない。
模範解答：細胞に酸素や養分を受けわたし、二酸化炭素や不要物を受け取るはたらき。
コツ：書き終えたら「わたす」と「受け取る」の両方があるかを見る。片方だけだと半分の答え。

確認2 (4) 食後に養分を最も多く含む血管 図の読み取り・選択

👀 まず見るところ

【資料問題】部品は「食後」と「養分を最も多く」に丸。養分を吸収するのは小腸なので、図で小腸を出た直後の血管を探す → 小腸から肝臓へ上がるE。

📚 前提知識

  • 養分（ブドウ糖など）は小腸の柔毛から吸収され、まず肝臓に運ばれる。小腸と肝臓をつなぐ血管が門脈（冊子の図のE）。
  • 食後しばらくの間は、吸収したばかりの養分で門脈の血液がいちばん濃い（冊子の解説）。

🔍 こう読み解く

  1. 図1で小腸につながる血管は、右から入るF（動脈側）と、肝臓へ上がるE。
  2. Fは小腸に入る前の血、Eは小腸を通って養分を受け取った後の血 → E。
  3. Eが肝臓へ向かっているのは、養分を肝臓にたくわえるため。この流れが(5)につながる。
答え：E

確認2 (6) 二酸化炭素以外の不要物が最も少ない血管 図の読み取り・選択

👀 まず見るところ

【資料問題】部品は「二酸化炭素以外の」と「最も少ない」に丸。二酸化炭素は肺、それ以外の不要物は腎臓がこし出す → 腎臓を出た直後の血管を探す → G。

📚 前提知識

  • 不要物のうち二酸化炭素は肺で出す。尿素などそれ以外の不要物は腎臓でこし出され、尿としてぼうこうへ送られる（冊子の解説）。
  • 腎臓から心臓へもどる血管が腎静脈（冊子の図のG）。ここでは尿素の割合が最も少ない。

  3. もし「二酸化炭素が最も少ない」と聞かれたら、肺を出た直後のB（肺静脈）になる。設問の言葉で答えが変わる。

確認2 (7) 血液の成分ア・イ 図の読み取り・用語

👀 まず見るところ

【資料問題】部品は図2の正体「血管内を循環している血液の成分」と引き出し線の先。アはまん中がくぼんだ円ばん形で数がいちばん多いつぶ、イはつぶのないすき間（液体）を指す → 固体の成分と液体の成分で分ける。

📚 前提知識

  • 血液の固体成分は3つ。赤血球（円ばん形・最も多い・ヘモグロビンで酸素を運ぶ）、白血球（大きく、形が決まっていない・細菌を食べる）、血小板（小さなかけら・血を固める）。

🔍 こう読み解く

  1. 図2で大きくて中に点々のある2つが白血球、小さなかけらが血小板、くぼんだ円ばんがたくさん → アは赤血球。

  3. 役目をセットで：赤血球＝酸素、血しょう＝二酸化炭素・養分・不要物を運ぶ。

確認2 (8) 血液の流れの並べかえ 図をたどる・並べかえ

👀 まず見るところ
