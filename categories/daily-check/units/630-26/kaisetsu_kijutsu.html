記述⑥ 全体像 記述8問＋作図2問（各10点・100点）

(1)〜(8)は文で説明する記述、(9)(10)は作図。分野は 熱と光(1)／天気(2)／気体(3)(7)／月と太陽(4)(10)／光合成の実験(5)(6)／上皿てんびん(8)／器具の図(9) と広いが、聞かれ方は「利点・理由・方法・手順」の4つだけ。設問の最後の言葉に丸をつけ、「〜点。」「〜ため。」「〜を確かめる。」と文の終わり方を先に決めてから中身を考えると、書き出しで止まらない。

記述の得点要素は「原因」と「結果」の2つが基本で、別紙の模範解答もすべてこの2段でできている。今回は解いた原本が無いので、各カードの「コツ」を自分で書くときのチェックに使う。

記述⑥ (1) 夏に白い服を着る利点 利点の記述

👀 まず見るところ

【素材文】設問は「白い服」の「利点」。この2語に丸 → 答えの形は「白は〜だから、〜という点。」。白と黒で何がちがうか（光・熱の反射）を言えれば決まる。

📚 前提知識

  • 白い物は太陽の光や熱を反射しやすく、黒い物は吸収しやすい。だから日なたでは黒い服のほうが先に熱くなる。
  • 百葉箱が白くぬられているのも同じ理由。中の温度計に太陽の熱の影響を与えないため。

✍️ 答案の組み立て

  1. 要素A（原因）：白い色は太陽の光や熱を反射しやすい（吸収しにくい）。
  2. 要素B（結果）：だから他の色の服より暑くなりにくい。「〜点。」で結ぶ。
模範解答：白い色は太陽の光や熱を反射しやすい(吸収しにくい)ため、他の色の服よりも暑くなりにくい点。
コツ：「すずしい」だけでは要素Bしかない。「光や熱を反射する」の原因を前に置いて2段にする。

記述⑥ (2) 日本の天気が西から東に変わる理由 理由の記述

👀 まず見るところ

【素材文】設問は「日本において」「西から東」に変わる「理由」。部品は「西から東」に丸 → 同じ向きに吹く風の名前（偏西風）が出れば、「風が〜を運ぶため。」の形で決まる。

📚 前提知識

  • 日本の上空には、1年中西から東へ向かう強い風＝偏西風が吹いている。
  • 天気を決めているのは低気圧や高気圧（移動性高気圧）。これが偏西風に流されて西から東へ動くので、天気も同じ順で移っていく。天気予報で「西の空を見る」のはこのため。

✍️ 答案の組み立て

  1. 要素A（原因）：上空に偏西風という強い西風が吹いている。
  2. 要素B（結果）：低気圧や高気圧がその風で西から東へ移動する。「〜ため。」で結ぶ。
模範解答：日本の上空には偏西風という強い西風がふいており、低気圧や高気圧がこの西風によって西から東へ移動するため。
コツ：「偏西風がふいているから。」だけで止めない。風に何が運ばれるか（低気圧・高気圧）まで書いて2要素にする。

記述⑥ (3) 気体が二酸化炭素だと確かめる方法 方法の記述

👀 まず見るところ

【素材文】設問は「確かめる方法」で、条件は「気体検知管を使う以外」。この条件に丸 → 二酸化炭素だけが起こす反応を1つ選ぶ。答えの形は「〜に通し、〜を確かめる。」。

📚 前提知識

  • 二酸化炭素を石灰水に通すと白くにごる。二酸化炭素だけに起こる変化なので、見分ける決め手になる。
  • 「火を近づけると消える」は、ちっ素など燃えない気体でも同じになるので、二酸化炭素と言い切る根拠にはならない。

✍️ 答案の組み立て

  1. 要素A（何をする）：気体を石灰水に通す。
  2. 要素B（何を見る）：白くにごることを確かめる。
模範解答：石灰水に通し、白くにごることを確かめる。
コツ：「石灰水を使う」だけでは方法になっていない。通す→白くにごるの2つで1セット。

記述⑥ (4) 太陽と月の見かけの大きさが同じ理由 理由の記述

👀 まず見るところ

【素材文】設問は「見かけの大きさ」が「同じ」理由。「見かけ」に丸 → 本当の大きさは太陽のほうがずっと大きい。見かけが同じになるのは「大きさの比＝距離の比」のときなので、答えは「直径も距離も約400倍だから。」の形。

📚 前提知識

  • 遠くの物ほど小さく見える。直径が400倍でも距離が400倍遠ければ、見かけの大きさは同じになる。
  • 太陽の直径は月の約400倍、地球から太陽までの距離も地球から月までの約400倍。だからどちらも見かけの大きさ（視直径）は約0.5度で、日食のとき月が太陽をちょうど隠せる。

✍️ 答案の組み立て

  1. 要素A：太陽の直径は月の直径の約400倍。
  2. 要素B：地球から太陽までの距離も、月までの距離の約400倍。この2つがそろうので見かけが同じ、と「〜から。」で結ぶ。
模範解答：太陽の直径は月の直径の約400倍で、地球から太陽までの距離も地球から月までの距離の約400倍だから。
コツ：「太陽が遠いから」だけでは片側だけ。直径と距離の両方に同じ倍率が入って初めて「同じ」の説明になる。

記述⑥ (5) 葉を温めたアルコールにつける理由 理由の記述・実験操作

👀 まず見るところ

【素材文】設問は「でんぷんがつくられる条件を調べる実験」で「温めたアルコールにつける理由」。実験の目的に丸 → 最後にヨウ素液で色を見る実験だと分かれば、「色を見やすくするため」に向かって書ける。

📚 前提知識

  • アルコールは葉の緑色のもと＝葉緑素をとかし出す。葉は白っぽくなる（脱色）。
  • 緑のままだと、ヨウ素液をつけたときの青むらさき色が緑にまぎれて見えにくい。白くしてから色を見る。
  • 手順の流れは、熱湯でやわらかくする → 温めたアルコールで脱色 → 水で洗う → ヨウ素液。

✍️ 答案の組み立て

  1. 要素A（何をする）：葉の中の葉緑素をとかし出し、葉を白くする。
  2. 要素B（何のため）：ヨウ素でんぷん反応の色の変化を見やすくする。「〜ため。」で結ぶ。
模範解答：葉の中の葉緑素をとかし出し、葉を白くしてヨウ素でんぷん反応による色の変化を見やすくするため。
コツ：「葉を白くするため。」で止めると目的が抜ける。白くする→色が見やすいまでつなげる。

記述⑥ (6) アルコールを直接火で温めない理由 理由の記述・実験操作

👀 まず見るところ

【素材文】設問は「直接火で温めない理由」。「直接火で」に丸 → 答えはアルコールの性質（気化しやすい・火がつきやすい）＋「〜を防ぐため。」の形。かわりにどう温めるか（湯せん）も頭に置く。

📚 前提知識

  • アルコールは気化しやすく（蒸発しやすく）、その気体に火がつく＝引火しやすい。
  • だから直接火にかけず、お湯の入ったビーカーにアルコールの容器をつけて温める（湯せん）。

✍️ 答案の組み立て

  1. 要素A（性質）：アルコールは気化しやすい。
  2. 要素B（危険）：引火することを防ぐ。「〜ため。」で結ぶ。
模範解答：アルコールは気化しやすく、引火することを防ぐため。
コツ：「あぶないから」では理由になっていない。気化と引火の2語を入れる。

記述⑥ (7) 途中に空の三角フラスコを置く理由 資料問題・装置の図

👀 まず見るところ

【資料問題】図の正体を1行＝「石灰石＋塩酸で二酸化炭素を発生させ、空のフラスコを通して水上置換でメスシリンダーに集める装置」。設問は「体積をなるべく正確に」に丸 → 二酸化炭素が水にとけることが問題点で、空のフラスコがそれをどう防ぐかを書く。

📚 前提知識

  • 二酸化炭素は水に少しとける。そのまま水上置換で集めると、とけた分だけ体積が少なく測れる。
  • 空の三角フラスコを間に置くと、発生した二酸化炭素はフラスコの中の空気を押し出す。メスシリンダーに入るのは押し出された空気で、空気は水にほとんどとけない。
  • 押し出された空気の体積＝発生した二酸化炭素の体積。だから正確に測れる。

✍️ 答案の組み立て

  1. 要素A（問題点）：二酸化炭素は水にとける。
  2. 要素B（解決）：三角フラスコ内の空気と置き換えて、空気のほうを集める。「〜ため。」で結ぶ。
模範解答：二酸化炭素は水にとけるので三角フラスコ内の空気と置き換えるため。
コツ：「二酸化炭素が水にとけるから」だけでは、空のフラスコの役目が書けていない。空気と置き換えるの一言までが答え。

記述⑥ (8) 上皿てんびんの手順②③ 手順の記述・空らん2つ

👀 まず見るところ

【素材文】設問は「右ききの人」の手順の「②と③」。部品は「右きき」と、前後の①「水平な台」・④「針が左右等しくふれたとき」に丸 → ②は「のせたあとの調節」、③は「消しゴムをどちらの皿に・分銅をどう」と決まる。

📚 前提知識

  • 皿をのせたら、調節ねじで針が左右等しくふれるようにする。針が止まるまで待たなくてよい。
  • 右ききの人は、はかる物を左の皿、分銅を右の皿にのせる。右手で分銅をのせおろししやすいから。
  • 分銅はピンセットでつまみ（手の汗や油で重さが変わらないように）、重いものからのせる。軽いものからだと、のせかえの回数が増える。

✍️ 答案の組み立て

  1. ②：調節ねじで調節し、指針が左右等しくふれるようにする。（①の「水平な台」のあと、使う前の調節）
  2. ③：消しゴムを左の皿に置き、右の皿にピンセットで重い分銅からのせていく。（「左の皿」「ピンセット」「重い分銅から」の3つがそろって満点）
模範解答：②調節ねじで調節し指針が左右等しくふれるようにする。／③左の皿に置き、右の皿にピンセットを使い重い分銅からのせていく。
コツ：③で落ちやすいのは「ピンセット」と「重い分銅から」。皿の左右だけ書いて終わらない。

記述⑥ (9) ビーカーの見取り図 作図

👀 まず見るところ

【素材文】設問は「見取り図」。見取り図＝立体をななめ上から見た形で、見えない線は点線。「ビーカー」に丸 → 形の決め手は 注ぎ口・だ円の口・まっすぐな側面・底の点線 の4つ。

📚 前提知識

  • ビーカーは円柱形。ななめ上から見ると、口はだ円、側面は2本の縦線、底は手前が実線で奥が点線になる。
  • 口のふちに液体を注ぐための注ぎ口（小さなくちばし）が1つ。これが無いとコップと区別できない。

✍️ 答案の組み立て

  1. 口をだ円で描き、左上に注ぎ口を1つ出す。
  2. だ円の両はしから下へまっすぐ2本の側面を引く。
  3. 底は手前半分を実線、奥の半分を点線で結ぶ。
模範解答：別紙の図のとおり。要点＝だ円の口に注ぎ口が1つ・側面はまっすぐな2本線・底は手前が実線で奥が点線。
コツ：底を1本の直線で描くと「正面図」になってしまう。見取り図は底もだ円（奥は点線）。

記述⑥ (10) 皆既日食のときの太陽・月・地球の図 作図

👀 まず見るところ

【条件文】部品は「皆既日食」と、条件「見える地域が分かるように」に丸 → 3つの天体を一直線に並べるだけでは足りず、月の影が地球に届く場所を図に置く。太陽と月のはしを結ぶ線を2本引けば、その交わる先が答え。

📚 前提知識

  • 日食は太陽―月―地球の順に一直線に並び、月が太陽を隠す現象（新月のとき）。
  • 月の影のうち、太陽が全部隠れるこい影が届くのは地球のごくせまい範囲。そこだけが皆既日食で、まわりの広い範囲は部分日食になる。
  • 大きさの順は 太陽＞地球＞月。(4)の通り、太陽は大きく遠く、月は小さく近い。

✍️ 答案の組み立て

  1. 左に大きな円（太陽）、右に中くらいの円（地球）、その間の地球寄りに小さな円（月）を一直線に描き、名前を書く。
  2. 太陽の上はしと月の上はし、太陽の下はしと月の下はしを結ぶ2本の直線を引き、月の後ろで交わらせて地球まで届かせる。
  3. 2本の線が地球の表面と出会う1点に矢印をつけ、「皆既日食が見える地域」と書く。
模範解答：別紙の図のとおり。要点＝太陽・月・地球をこの順に一直線に並べ、太陽と月の上下のはしを結ぶ2本の線が月の後ろで交わって地球に届く1点を「皆既日食が見える地域」と示す。
コツ：円を3つ並べただけでは「見える地域」の条件を満たしていない。影の線2本と矢印まで描いて完成。
