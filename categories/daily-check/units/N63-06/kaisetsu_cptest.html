N63-06 CP（コアプラス確認テスト 範囲528〜544 動物③（メダカ・プランクトン））

CP 全体像 コアプラス確認テスト 10問

範囲は528〜544「動物③（メダカ・プランクトン）」。(1)〜(5)はメダカの産卵と卵の育ち（めすの見分け・卵の大きさ・ふ化までの日数・しま模様の実験）、(6)(7)は5種のプランクトンを「光合成をするか」「自分で動けるか」で仕分ける問題、(8)〜(10)は顕微鏡の使い方（手順・レンズの選び方・プレパラートを動かす向き）。

図で決まるのは(1)(3)(6)(7)(9)(10)。図の問題は「どこを見れば決まるか」を1つ決めてから選ぶ。(6)(7)の「すべて選びなさい」は、5つ全部に○×をつけてから書く。

CP (1) 産卵しているメダカの図 資料問題・図から1つ選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「産卵している」と、図の2か所＝ひれの形と卵のついている場所。4匹の背びれ・しりびれに丸をつけて「めす／おす」と書く → 卵を産めるのはめすだけ。残った2匹は、卵がしりびれの前についているほうが本物。

📚 前提知識

  • メダカのおすは背びれに切れこみがあり、しりびれが大きい平行四辺形。めすは背びれに切れこみがなく、しりびれは後ろへいくほど細い三角形。
  • めすは産んだ卵をしばらく腹びれの後ろ（しりびれの前）につけたまま泳ぎ、そのあと水草にこすりつける。

🔍 こう読み解く

  1. ウとエは背びれに切れこみがあり、しりびれも大きい → おす。おすは卵を産まないので×。
  2. アとイはめすの形。卵の場所を見ると、イはしりびれの後ろ・尾の近くについている。産卵の場所と合わない → ×。
  3. アはめすで、卵が腹びれの後ろ・しりびれの前についている → ○。
答え：ア
今回：ア ○。

CP (2) メダカの卵の直径と、水草につける卵 知識問題

① 1 mm　② したあと。メダカの卵は直径約1mmで、肉眼でも粒が見える大きさ。めすが産んだ卵におすが精子をかけて受精したあと、めすが卵を水草につける。0.2mmは小さすぎて粒がはっきり見えず、5mmはメダカの体には大きすぎる、と大きさの感覚で消す。
答え：① 1（mm）　② したあと
今回：① 1　② したあと ○。

CP (3) メダカの卵を成長の順に並べる 資料問題・図を順に並べる

👀 まず見るところ

【資料問題】部品は4つの図の「油のつぶ」と「目」。それぞれの図に「つぶ散らばる／集まる／目あり」と1語ずつ書く → 散らばる→集まる→体ができる→目が黒く大きい、の順に並ぶ。

📚 前提知識

  • 受精したばかりの卵は、養分である油のつぶが全体に散らばっている。育ちはじめると油のつぶは片側（下）に集まり、反対側に体のもとができる。
  • そのあと頭・目・心臓・血管ができ、ふ化が近づくと目が黒く大きくなり、体が卵の中で丸く巻く。

🔍 こう読み解く

  1. ア：小さなつぶが全体に散らばっている → いちばん最初。
  2. イ：つぶが下にまとまり、上に細胞のかたまりがある → 2番目。
  3. エ：小さな体と頭のふくらみができ、つぶは下にまとまったまま → 3番目。ウ：目が黒く大きく、体が卵の内側をぐるりと巻いている → 最後（ふ化直前）。
答え：ア・イ・エ・ウ
今回：ア イ エ ウ ○。

CP (4) 産卵の時刻と、ふ化までの日数 知識問題

① 早朝　② 10日後。メダカは早朝（夜明けごろ）に産卵する。水温25℃のとき、ふ化までは約10日。水温が高いほど早く、低いほどおそくなる。「25℃で10日」を1組で覚える。
答え：① 早朝　② 10（日後）
今回：① 早朝 ○　② 11 ×。知識＝「25℃で約10日」の数が1つずれた。選択肢は「5・10・20」の3つで、11はその中にない。答える直前に、書いた数が選択肢の中にあるかを見直す。

CP (5) しま模様の紙を反時計回りに回すとメダカは 条件文・向きを決める

👀 まず見るところ

【条件文】部品は「反時計回り（矢印の方向）に回転」と、図の矢印。図に「紙＝反時計」と書き、横に「メダカはしまと同じ向き」と直して書く → 紙と同じ反時計回りに泳ぐと決まる。

📚 前提知識

  • メダカは、まわりの景色が動くと景色と同じ向きに泳いで、景色に対する自分の位置を保とうとする。川で流されずにその場にとどまる性質と同じ。
  • 水そうの水を回しても、流れに逆らって泳ぐ。「水が動く→逆向き」「景色が動く→同じ向き」をセットで分ける。

🔍 こう読み解く

  1. 動いているのは水ではなく、まわりのしま模様（景色）。
  2. 景色が反時計回りに動く → メダカは景色について行くように、同じ反時計回りに泳ぎ続ける。
答え：反時計（回り）
今回：反時計 ○。

CP (6) 光合成をするプランクトン 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「光合成をするものをすべて」。5つの図の下に名前を1語ずつ書き、「緑（葉緑体あり）か」で○×を5つつける → ○が答え。1つ見つけて終わりにしない。

📚 前提知識

  • 図の5つは、ア ケイソウ・イ ツボワムシ・ウ イカダモ・エ ミドリムシ・オ ゾウリムシ。
  • 光合成をするのは葉緑体をもつ植物プランクトン＝ケイソウ・イカダモと、動物と植物の両方の性質をもつミドリムシ。ツボワムシ・ゾウリムシは動物プランクトンで、ほかの生き物を食べて生きる。

🔍 こう読み解く

  1. 選ぶ：ア ケイソウ（ガラス質のからの中に葉緑体）○、ウ イカダモ（4つの細胞が横に並ぶ緑色の藻）○、エ ミドリムシ（細長い体に葉緑体がつまっている）○。
  2. 選ばない：イ ツボワムシ（つぼ形の体で、口のまわりの毛で食べ物を集める）×、オ ゾウリムシ（全身の毛で泳ぎ、えさを食べる）×。
答え：ア・ウ・エ
今回：アウエ ○。図の下（ア・エ）に○の印をつけてから書いている。

CP (7) 自分で動けるプランクトン 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】(6)と変わった部品は「自分で動けるもの」に丸。見るのは図の毛（せん毛・べん毛）。毛が描いてある3つに○、毛のない2つに× → ○が答え。

📚 前提知識

  • 自分で動けるのは、せん毛やべん毛をもつもの。ゾウリムシは全身のせん毛、ツボワムシは口のまわりのせん毛、ミドリムシは1本の長いべん毛で泳ぐ。
  • ケイソウ・イカダモは動くための毛がなく、水に流されてただよう。
  • ミドリムシは「光合成もする・自分でも動く」ので、(6)にも(7)にも入る。

🔍 こう読み解く

  1. 選ぶ：イ ツボワムシ（上のふちに毛）○、エ ミドリムシ（先から1本のべん毛）○、オ ゾウリムシ（体のまわり全部に毛）○。
  2. 選ばない：ア ケイソウ・ウ イカダモは毛がない ×。
答え：イ・エ・オ
今回：イエオ ○。

CP (8) 顕微鏡の手順（反射鏡の調整とレンズの距離） 知識問題

① のせる前に　② 近づけて。反射鏡で視野を明るくするのは、プレパラートをのせる前（視野全体が見える状態で明るさを決める）。ピント合わせは、横から見ながら対物レンズとプレパラートを近づけておき、そのあと接眼レンズをのぞきながら遠ざけて合わせる。近づけるときにのぞいていると、レンズがプレパラートにぶつかる。「近づけるときは横から・遠ざけながら合わせる」をセットで。
答え：① のせる前に　② 近づけて
今回：① のせる前に　② 近づけ〜 ○。②は「て」を省いて書いているが正解あつかい。

CP (9) 最初に使う接眼レンズと対物レンズ 資料問題・長さで決める

👀 まず見るところ

【資料問題】部品は「最初に観察する」に丸＝低倍率。図の4本を長い／短いで分けて下に書く → 接眼は長いほうが低倍率、対物は短いほうが低倍率、と逆になる。

📚 前提知識

  • 最初は低倍率で観察する。視野が広く明るいので、見たいものを見つけやすい。
  • 接眼レンズは長いほど低倍率、対物レンズは短いほど低倍率。逆向きなので、2つをセットで覚える。
  • 図の見分け：ア・イは上が平らなふた形の接眼レンズ、ウ・エは上にぎざぎざのリング（取りつけねじ）がある対物レンズ。

🔍 こう読み解く

  1. 接眼レンズはアとイ。長いのはア → 低倍率 → ①はア。
  2. 対物レンズはウとエ。短いのはエ → 低倍率 → ②はエ。
答え：① ア　② エ
今回：① ア　② エ ○。

CP (10) プランクトンを視野の中央に動かす向き 資料問題・向きを決める

👀 まず見るところ

【資料問題】部品は図の「プランクトンが左下にいる」と、聞かれ方「プレパラートを動かす」。図の横に「顕微鏡は上下左右が逆」と書く → 見えている向き（左下）にそのまま動かせば、中央に来る。

📚 前提知識

  • 顕微鏡で見える像は、実物と上下左右が逆。プレパラートを右に動かすと、像は左へ動く。
  • だから、像を中央に寄せたいときは「像が見えている向き」へプレパラートを動かす。

🔍 こう読み解く

  1. 像は左下にある。中央へ動かすには、像を右上へ動かしたい。
  2. 像を右上に動かすには、プレパラートはその逆の左下へ動かす＝像が見えている向きと同じ。
答え：左下
今回：左下 ○。

CP まとめ 90点（10問中9問）

  • 取れた9問は、図の問題（ひれの形・油のつぶ・毛・レンズの長さ・像の位置）を「どこを見るか」で決められている。(6)は図の下に○をつけてから答えており、この置き方でよい。
  • 落とした(4)②は数の覚えちがい。「水温25℃で約10日」と1組で覚え直す。選ぶ形の問題では、答えが選択肢の中にある数かを書く前に見る。
  • 覚え直しはこの3つ：ミドリムシは光合成もするし自分で動く／接眼は長いほど・対物は短いほど低倍率／像は上下左右が逆なので見えている向きにプレパラートを動かす。
