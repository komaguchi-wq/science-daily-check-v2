DC1 (1) レキ岩は何が固まったか 知識問題

エ（小石と砂と泥）。レキ岩は小石（レキ）が主役だが、小石どうしのすき間を砂や泥がうめて固まっている。「小石だけ」ではなく、砂と泥もいっしょ、と結びつけて覚える。砂岩は砂が主役、泥岩は泥が主役で、粒の大きさで名前が決まる。
答え：エ
今回：エ ○。

DC1 (2) 火山灰が固まってできた岩石 知識問題

ギョウカイ岩（凝灰岩）。火山灰が降り積もって押し固められた岩石で、レキ岩・砂岩・泥岩と同じ「たい積岩」の仲間。粒が角ばっているのが特徴で、丸い粒のレキ岩・砂岩と区別する。カタカナか漢字で。
答え：ギョウカイ岩
今回：ギョウカイ岩 ○。

DC1 (3) 白っぽく、大きな粒がすき間なく並ぶ岩石 資料問題・岩石名

👀 まず見るところ

【資料問題】部品は設問の「全体的に白っぽい」と、図1の正体「大きな粒だけが、すき間なく組み合わさった図」の2つ。白い＝花こう岩か流もん岩の2択、大きな粒だけ＝深成岩、で花こう岩に決まる。

📚 前提知識

  • マグマが地下深くでゆっくり冷えると、結晶が大きく育って同じくらいの大きさの粒がすき間なく並ぶ（深成岩）。地表近くで急に冷えると、大きな粒のまわりに細かい粒が入る（火山岩）。
  • 深成岩は色で3つ。白っぽい花こう岩・中間の閃緑岩・黒っぽい斑れい岩。

🔍 こう読み解く

  1. 図1は大きな粒だけで細かい地の部分がない → ゆっくり冷えた深成岩。
  2. 深成岩のうち白っぽいもの → 花こう岩。
答え：カコウ岩
今回：カコウ岩 ○。

DC1 (4) シジミが示す自然環境 知識問題

ウ（河口や湖）。シジミはみそ汁のシジミそのもので、川の水と海水がまざる河口や、湖にすむ。だから化石で出てくれば、そこが河口や湖だったと分かる示相化石。浅い海はサンゴ、深い海（やや深く冷たい海）はホタテガイ、と区別する。
答え：ウ
今回：ウ ○。

DC1 (5) Aが積もった間の土地の動き 資料問題・選択

👀 まず見るところ

【資料問題】部品は設問の「Aで示した範囲」「海面に対して土地」と、Aの3層の正体。凡例で下から泥→小石→砂と読み、それぞれの横に「深い・浅い・中くらい」と書く → 深さの変化がそのまま土地の上下になる。

📚 前提知識

  • 粒が大きいものほど岸の近く（浅い所）で沈む。小石＝浅い、砂＝中くらい、泥＝深い。
  • 海が浅くなる＝土地が持ち上がった（隆起）。海が深くなる＝土地が沈んだ（沈降）。

🔍 こう読み解く

  1. 下から順に、泥（深い）→小石（浅い）→砂（中くらい）。深い→浅い→少し深く、と2段階で変わっている。
  2. 深い→浅いは隆起、浅い→少し深くは沈降。「隆起した後、沈降した」のウ。
  3. ア・イは1方向の変化なので、層が3つで向きが変わる図とは合わない。
答え：ウ
今回：ウ ○。図に「中・浅・深」と書きこんでから選べている。

DC1 (6) 同じ間の海面の動き 資料問題・選択（(5)の裏返し）

👀 まず見るところ

【資料問題】部品は(5)と変わった言葉「陸地に対して海面は」。見る図も期間も(5)と同じで、立場を土地から海面に裏返しただけ。(5)の答え「隆起→沈降」を「海面が下降→上昇」に直して書く → それがそのままエ。

📚 前提知識

  • 土地が隆起すると、海面は相対的に下がる。土地が沈降すると、海面は上がる。同じ出来事をどちらから見るかのちがい。

🔍 こう読み解く

  1. (5)：深い→浅い→中くらい ＝ 土地は 隆起→沈降。
  2. 海面の立場に直す：隆起＝海面が下降、沈降＝海面が上昇。「下降した後、上昇した」のエ。
  3. 確かめ：(5)でウ（2段階）を選んだのに、(6)で「しだいに」の1方向（ア・イ）を選ぶと、同じ図を見ているのに話が合わない。
答え：エ
今回：ア ×（答案）。部品の形を直さなかった＝(5)で決めた「隆起→沈降」を海面の言葉に裏返さず、(6)を別の問題として読み直した。次は(5)の答えの横に「海面は 下がる→上がる」と直して書いてから選択肢を見る。
コツ：(5)(6)のように「〜に対して」が入れかわる2問は、1問目の答えを裏返すだけ。図をもう一度読み直さない。

DC1 (7) B—Cの断層のでき方 資料問題・選択

👀 まず見るところ

【資料問題】部品は「B—Cの断層」と、図2で火山灰の層が線の左右でどれだけずれているか。斜めの線の上側にのった左の側が、火山灰ごと下に落ちている → 引かれてできた正断層。

📚 前提知識

  • 断層は、斜めの面の上にのっている側がどう動いたかで見分ける。上の側がずり落ちていれば左右から引かれた正断層、上の側がはい上がっていれば左右から押された逆断層。
  • 選択肢の「上下から押された／引かれた」は、断層の原因として出てこない。地層をずらす力は横向き（左右）の力。

🔍 こう読み解く

  1. Cの線は左下から右上へのぼっている。この面の上にのっているのは左の側。
  2. 火山灰の層は、左の側が右の側より低い → 上にのった左の側がずり落ちた。
  3. ずり落ちるのは引かれたとき → 「左右から引かれてできた」のエ。
答え：エ
今回：エ ○。

DC1 (8) 最低何回陸地になったか 資料問題・回数

👀 まず見るところ

【資料問題】部品は設問の「現在を含めて」「最低何回」に丸と、図2のBの波線（不整合）。陸になった証拠は「不整合の数＋今の地表（木が生えている）」で数える → 1＋1＝2回。

📚 前提知識

  • 不整合（波打った境目）は、地層がいちど陸に上がってけずられ、また海に沈んで上に新しい層が積もったあと。不整合1つ＝陸になった回数1回。
  • 「最低」とあるのは、けずられて証拠が消えた回があるかもしれないから。図に残っている証拠だけ数える。

🔍 こう読み解く

  1. Bの波線の下には断層で切れた古い層、上にはAの新しい層。間にいちど陸になった時期がある → 1回。
  2. いちばん上に木が生えている＝今も陸 → 「現在を含めて」で＋1回。
  3. 合わせて2回。Aの3層の中には波線がないので、Aが積もる間は海のまま。
答え：2回
今回：2回 ○。

DC1 まとめ 7/8 正解

  • 岩石・化石の一問一答(1)〜(4)と、図2を読む(5)(7)(8)は取れている。層の深さを書きこむ・断層のずれを見る・不整合を数える、はできている。
  • 落とした(6)は、(5)の答えを裏返すだけの問題。「土地に対して」と「海面に対して」が入れかわったら、前の答えを海面の言葉に直して書くのが次の一手。
  • 覚え直しは1つ：隆起＝海面が下がる／沈降＝海面が上がる。

DC2 全体像 ボーリング調査と地層の傾き 4問

3地点の柱状図から同じ層(a)の標高をそろえ、どちらに低くなっているかを決める定番の問題。やることは2段だけ。①図1の等高線から各地点の標高を読んで柱状図の0mの横に書く → ②(a)の深さを引いて、(a)の標高を図1の地点の横に書く。「しゅう曲や断層はなく、厚さは同じ」とあるので、(a)の標高の差がそのまま傾きになる。

DC2 (1)A・B・C 地層(a)の下部の標高 条件文・計算

👀 まず見るところ

【まざり型→条件文】部品は「(a)の下部の標高」と、図1でA・Bは70mの線の上、Cは80mの線の上にあること。柱状図の0mの横に70・70・80と書き、図2から(a)の下の深さ（A 15m・B 5m・C 20m）を読む → 標高−深さ で3つとも決まる。

📚 前提知識

  • 柱状図の縦軸は「地面からの深さ」で、地面の高さは地点ごとにちがう。層の標高＝その地点の標高−深さ。
  • 「下部」は層の下の境目。(a)はAでは14〜15m、Bでは4〜5m、Cでは19〜20mにあるので、下部はそれぞれ15・5・20m。

🔍 こう読み解く

  1. A：標高70m、(a)の下部は深さ15m → 70−15＝55m。
  2. B：標高70m、深さ5m → 70−5＝65m。
  3. C：標高80m、深さ20m → 80−20＝60m。求めた3つの数を図1の地点の横に書いておくと、(2)はそれを見るだけになる。
答え：A 55m　B 65m　C 60m
今回：A 55m ○、B 65m ○、C 60m ○。図1のA・B・Cの横に55・65・60と書きこんであり、手順どおり。

DC2 (2) 地層が低くなっている方向 資料問題・選択

👀 まず見るところ

【資料問題】部品は設問の「低くなっている」に丸と、図1に書いた(a)の標高A 55・B 65・C 60。Bを起点に、北のAと西のCがどちらも低い → 北と西を合わせて北西。南北と東西を1つずつ決めて組み合わせる。

📚 前提知識

  • 図1の点線で、AはBの真北、CはBの真西。南北の傾きはA—B、東西の傾きはC—Bで別々に見られる。
  • しゅう曲も断層もないので、傾きは一方向にまっすぐ。

🔍 こう読み解く

  1. 南北：B 65m → A 55m。北へ行くと10m低い → 北へ低くなる。
  2. 東西：B 65m → C 60m。西へ行くと5m低い → 西へ低くなる。
  3. 北と西を合わせて北西 → エ。「高くなる方向」なら逆の南東になるので、丸をつけた「低く」をもう一度見てから答える。
答え：エ
今回：ア ×（答案：北東）。部品を拾えなかった＝「低くなっている」に丸がなく、南北は正しく北と決めたのに、東西はBの方が高い側（東）を答えた形だと思う。次はBを起点に「北は低い？ 西は低い？」と1つずつ○×をつけて組み合わせる。

DC2 まとめ 3/4 正解

  • (1)の標高の計算は3つとも正しく、図1に数を書きこむ手順もできている。
  • 落とした(2)は、書いた3つの数を「低い方向」で組み合わせるところ。南北と東西を1つずつ決めて、最後に合わせる。
  • 覚え直し：層の標高＝地点の標高−深さ。求めた数は図1に書いて、方角は図1で決める。

DC3 (2) プレートが動くことで起こること 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「プレートが動いている」と聞かれ方「すべて選びなさい」に丸。4つの文を「プレートの動きで説明できるか」で1つずつ○×にし、空気の話（天気）だけを外す。

📚 前提知識

  • ハワイ島は太平洋プレートの上にあり、プレートごと少しずつ日本の方へ動いている。
  • 日本付近ではプレートがぶつかって沈みこむ。そのひずみがはね返るときに大きな地震が起こり、沈みこんだプレートのところでマグマができて火山が多くなる。
  • 台風は海の上の暖かい空気からできる天気の現象で、プレートとは関係がない。

🔍 こう読み解く

  1. ア ハワイが近づく → プレートの動きそのもの → ○。
  2. イ 大きな地震 → プレートがぶつかる場所 → ○。エ 火山が多い → 沈みこみでマグマ → ○。
  3. ウ 台風 → 空気の話 → ×。残ったア・イ・エが答え。
答え：ア・イ・エ
今回：ア・イ ×（エが抜けた）。知識＝「火山もプレートの沈みこみでできる」が結びついていなかった。地震と火山は同じ場所（プレートの境目）に集まる、とセットで持つ。

DC3 まとめ 2/4 正解

  • 表の計算は式まで合っていて、落としたのは筆算の 57×9 1か所。わり算のあとに九九を1回だけ確かめる。
  • (2)の抜けは知識。地震・火山・ハワイの移動の3つはプレートの話、台風は天気の話、と分けて持つ。
