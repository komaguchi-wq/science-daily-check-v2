630-31 確認1（6ページ・地球儀を真上から見た昼と夜）

確認1 全体像 地球儀と光・昼の長さ 5問

図2は地球儀を真上（北極の上）から見た図。線が1点に集まっている所が北極で、光は左（イ）から来るので、白＝昼・灰色＝夜。5問とも、この図に「白＝昼」「中心＝北極」「矢印＝回る向き」の3つを書きこんでから読むと、知識はほとんどいらない。

北極が灰色の側（エ寄り）にずれている。北極に光が届かない＝北半球の冬で、(3)(5)はここから決まる。

確認1 (1) 真夜中の位置 資料問題・記号

👀 まず見るところ

【資料問題】部品は資料の正体「真上から見た様子」と「左側からライトの光」。図2に「イ＝太陽の側」と正体を1行書く → 真夜中は太陽の正反対なので、イの反対のエに決まる。

📚 前提知識

  • 太陽の正面を向いた位置が正午（南中）、その正反対が真夜中。地球上のどこでも、太陽との向きだけで時刻が決まる。

🔍 こう読み解く

  1. 光はイの側から当たるので、イを向いている場所が正午。
  2. その正反対＝灰色の真ん中にあるエが真夜中。アとウは昼と夜の境目なので候補から外れる。
答え：エ
コツ：図2の外に「イ＝正午・エ＝真夜中」と書いてから(2)へ進む。

確認1 (2) 日の出をむかえている位置 資料問題・記号

👀 まず見るところ

【資料問題】部品は図2の「回転の方向」の矢印（ア→イ→ウ→エの向き）と、聞かれ方「日の出」に線。日の出＝夜から昼に入る瞬間なので、矢印にそって灰色から白へ入る境目を探す → ア。

📚 前提知識

  • 地球は西から東へ自転する。北極の上から見ると反時計回りで、図2の矢印もその向き。
  • 自分のいる場所が夜の側から昼の側へ回りこむ瞬間が日の出、昼から夜へ入る瞬間が日の入り。

🔍 こう読み解く

  1. 矢印の向きに1周たどる：エ（真夜中・灰）→ ア → イ（正午・白）→ ウ → エ。
  2. アは灰から白へ入る境目＝日の出。ウは白から灰へ出る境目＝日の入り。
  3. 確かめ：真夜中エ→日の出ア→正午イ→日の入りウ の順で、0時・6時・12時・18時がきれいに並ぶ。
答え：ア
コツ：アとウで迷ったら、矢印を指でなぞって「どちらへ進むか」で決める。境目の位置だけ見ると半々で迷う。

確認1 (3) A君〜D君の昼の長さ まざり型→条件文・計算

👀 まず見るところ

【まざり型→条件文】部品は「1回転するのに24時間」と、求めるもの「昼の長さ」に丸。1周360度＝24時間 → 「30度＝2時間」に直して図2の横に書く。あとは各自の緯線（円）のうち白い部分が何区切りあるかを数えるだけ。

📚 前提知識

  • 昼の長さ＝自分の緯線のうち、光が当たっている（白い）部分を1周するのにかかる時間。1周が24時間なので、白い部分の角度÷360×24で求まる。
  • 図2の北極から出ている線（経線）は30度ごと。解答冊子では「1区切り30度（＝2時間）」と注がついている。

🔍 こう読み解く

  1. A君（赤道・いちばん外の円）：白い部分は半周＝180度 → 24×180/360＝12時間。
  2. B君の円：白い部分は4区切り＝120度 → 24×120/360＝8時間。
  3. C君の円：白い部分は2区切り＝60度 → 24×60/360＝4時間。
  4. D君の円：全部が灰色の中 → 光が当たる部分がない → 0時間。
答え：A君 12時間　B君 8時間　C君 4時間　D君 0時間
コツ：北極に近い円ほど白い部分が小さい。12→8→4→0 と4時間ずつ減っていくので、並べて検算できる。

確認1 (4) どこでも昼の長さが同じになる光の向き 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は「どこでも昼の長さが同じ」と「すべて選び」に線。昼の長さが同じ＝どの円も白と灰が半分ずつ。半分ずつに切れるのは、昼夜の境目の線が北極（線が集まる点）を通るとき。光がアやウから来ると、境目はイ−エの線になり北極を通る。

📚 前提知識

  • 円を中心を通る線で切ると、必ず半分ずつになる。緯線の円の中心は北極なので、境目が北極を通れば、どの緯度でも昼12時間・夜12時間（＝春分・秋分の状態）。
  • 光を当てる向きを変えると、昼夜の境目は光の向きと直角の線になる。

🔍 こう読み解く

  1. いまはイから光が当たり、境目はア−ウの線。北極は線の右（エ寄り）にあるので、境目は北極を通らず、円は半分ずつに切れていない。
  2. アから当てると境目はイ−エの線。北極はこの線の上にある → どの円も半分ずつ → 昼12時間でそろう。
  3. ウから当てても境目は同じイ−エの線 → 同じく12時間でそろう。「すべて選び」なのでアとウの両方。イ・エは境目がア−ウの線で、いまと同じく北極を通らない。
答え：ア・ウ
コツ：「光の向き」でなく「境目の線が北極を通るか」で判定する。境目は光と直角、と図に線を引いてから選ぶ。

確認1 (5) 図1の地球儀はいつの様子か 資料問題・季節

👀 まず見るところ

【資料問題】部品は図2の北極の位置（線が集まる点）が灰色の中にあること。北極に1日中光が当たらない＝北半球が太陽と反対にかたむいている → 冬至。(3)でD君が0時間だったのも同じ合図。

📚 前提知識

  • 地軸がかたむいたまま公転するので、北極が太陽の方を向く日が夏至（北極は1日中昼）、太陽と反対を向く日が冬至（北極は1日中夜）。春分・秋分は境目が北極を通り、どこでも昼12時間。
  • 冬至は北半球で昼がいちばん短い。(3)の「北へ行くほど昼が短く、北極近くは0時間」はその形。

🔍 こう読み解く

  1. 春分なら境目が北極を通るはず → (4)で見たとおり、いまは通っていない → 春分ではない。
  2. 北極が白（昼）なら夏至、灰色（夜）なら冬至。図2の北極は灰色の側 → 冬至。
  3. 確かめ：図1でも、地軸の上（北極側）は光の当たらない影の側にかたむいている。
答え：冬至
コツ：季節は「北極が昼か夜か」の1点で決める。昼なら夏至、夜なら冬至、境目の上なら春分・秋分。

確認1 まとめ 図2に3つ書きこめば全問決まる

  • 最初に図2へ「白＝昼・灰＝夜」「線の集まる点＝北極」「矢印の向き」を書きこむ。(1)(2)は向き、(3)(4)(5)は北極の位置だけで決まる。
  • 昼の長さは「30度＝2時間」に直してから、白い区切りを数える。北極に近いほど短く、北極が夜の側なら冬至。
  • 「どこでも昼の長さが同じ」＝境目が北極を通る。光の向きそのものではなく、境目の線で考える。

📚 前提知識

  • 月の形は、太陽・地球・月の角度で決まる。月が太陽の反対側にあれば満月、太陽と同じ側なら新月。
