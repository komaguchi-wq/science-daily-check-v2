DC1 (1)① グラフのBの温度 資料問題・平らな所を読む

👀 まず見るところ

【資料問題】部品は本文の「氷がとけて全部水になり」と、グラフの1つ目の平らな所B〜C。B〜Cの上に「氷がとけている」と書く（図に置く）→ Bはとけ始めで0℃と決まる。

📚 前提知識

  • 氷がとけている間は、加えた熱が氷を水に変えることに使われる。だから温度は0℃のまま上がらず、グラフは平らになる。

🔍 こう読み解く

  1. Aは加熱開始＝−20℃の氷。A〜Bは氷のまま温度が上がっている。
  2. Bで折れて平らになる → 氷がとけ始めた所 → 0℃。
答え：0℃
今回：0 ○。

DC1 (1)② すべて水蒸気になったあとの温度 資料問題・F・G・Hから選ぶ

👀 まず見るところ

【資料問題】部品は「水がすべてふっとうし、水蒸気に変わりました」と「その後」に丸。Eの先は水蒸気だけで、変わるものが残っていない → 熱は温度を上げることに使われ、上がるFと決まる。

📚 前提知識

🔍 こう読み解く

  2. H（下がる）は冷やしたときの形。加熱は続いているので合わない。
  3. 残ったF（上がる）。A〜B、C〜Dと同じ「1つの状態だけのときは上がる」形になる。
答え：F
今回：F ○。

DC1 (1)③ 液体の水が存在する区間 資料問題・ア〜コから選ぶ

👀 まず見るところ

【資料問題】聞かれ方の部品は「液体の水が存在する」に丸。「水だけ」とは言っていないので、氷とまざるB〜C、水蒸気とまざるD〜Eも入る → 区間ごとに状態を書きこめばB〜Eと決まる。

📚 前提知識

  • 平らな所では2つの状態がまざっている。B〜Cは氷と水、D〜Eは水と水蒸気。どちらにも液体の水がある。

🔍 こう読み解く

  1. 水があるのは B〜C（氷＋水）、C〜D（水だけ）、D〜E（水＋水蒸気）の3つ。A〜Bは氷だけ、Eの先は水蒸気だけ。
  2. つなげるとB〜E。選択肢で「BE間」をさがす → キ。
  3. ク（CD間）は「水だけ」の区間。聞かれ方を「水だけ」と読むと、こちらを選んでしまう。
答え：キ
今回：キ ○。余白に「B〜E」のメモがある。区間を先に決めて、あとから選択肢をさがす順で解いたと考えられる。

DC1 (1)④ ふっとうしている区間 資料問題・ア〜コから選ぶ

DC1 (1)⑤ 0℃の氷40gをとかす熱 条件文・計算

👀 まず見るところ

【条件文】部品は「1gの氷を…80カロリー」と「40gの氷」。「1gで80」は ×40 に直して書く → 80×40 の1本の式で決まる。「0℃の状態から」なので、温度を上げる分の熱は入らない。

📚 前提知識

  • 融解熱＝0℃の氷を0℃の水に変えるための熱。温度は変わらないのに熱がいる。氷の重さに比例する。

🔍 こう読み解く

  1. 1gで80カロリー、氷は40g。
  2. 80×40＝3200カロリー。グラフではB〜Cの平らな所で使われた熱にあたる。
答え：3200カロリー
今回：3200 ○。問題文の横に「3200カロリー」とメモしてあり、⑥でそのまま使えている。

DC1 (1)⑥ ウ〜エの加熱時間 まざり型・時間は熱量に比例

👀 まず見るところ

【まざり型→条件文】部品は「ア〜ウの時間が4分間」と「ガスバーナーの熱は一定」。ア〜ウ＝B〜C（氷がとける間）なので、図の下に「4分＝3200カロリー」と直して書く → ウ〜エの熱量を出せば時間は比例で決まる。

📚 前提知識

  • 熱が一定なら、加熱時間は熱量に比例する。時間を熱の量そのものとして計算できる。
  • 水1gを1℃上げる熱が1カロリー。水の温度を上げる熱量は「重さ×上がった温度」。

🔍 こう読み解く

  1. ウ〜エ＝C〜D。40gの水が100℃上がる → 40×100＝4000カロリー。
  2. 4分で3200カロリー（⑤）。4000カロリーなら 4×4000/3200＝5分間。
  3. 別の見方：3200÷4＝1分あたり800カロリー。4000÷800＝5分間。同じになる。
答え：5分間
今回：5 ○。余白に「800」「4000」のメモがある。1分あたり800カロリーに直してから4000を割った、と考えられる。

DC1 (2) 30℃の水100gと60℃の水200gを混ぜる 条件文・計算

👀 まず見るところ

【条件文】部品は「30℃の水100g」「60℃の水200g」。それぞれ「重さ×温度」の熱量に直して書く（3000と12000）→ 熱量の合計÷重さの合計で温度が決まる。

📚 前提知識

  • 「熱は外へ逃げない」ので、混ぜる前の熱量の合計と混ぜたあとの熱量は同じ（630-24 確認13と同じ式）。

🔍 こう読み解く

  1. 熱量の合計：100×30＋200×60＝3000＋12000＝15000。
  2. 重さの合計：100＋200＝300g。15000÷300＝50℃。
  3. 確かめ：答えは30℃と60℃の間で、重い方（200g・60℃）に近い。合っている。
答え：50℃
今回：50 ○。余白の「3000」「12000」「15000÷300＝50」は、解答冊子の式と同じ流れ。

DC1 (3) 100℃の金属Xを何g入れるか 条件文・金属を水に直す

👀 まず見るところ

【条件文】部品は「金属X1gは水0.2gと同じ」と、求めるもの「金属Xを何g」に丸。0.2は「水1gぶん＝金属X5g（1÷0.2）」に直して書く → 100℃の水なら何gかを先に出し、最後に×5で決まる。

📚 前提知識

  • 金属X1gが運べる熱は、水0.2gぶんしかない。だから同じ熱を運ぶには、水の5倍の重さの金属Xがいる（1÷0.2＝5）。
  • 混ぜたとき、温度の変わり方の比と重さの比は逆になる（重い方ほど温度は変わりにくい）。

🔍 こう読み解く

  1. まず「100℃の水を入れる」と考える（解答冊子）。20℃の水は 30−20＝10℃上がり、入れる方は 100−30＝70℃下がる。温度変化の比は 10：70＝1：7。
  2. 重さは逆の7：1。100℃の水なら 350×1/7＝50g。
  3. 水50gぶんを金属Xに直す。金属Xは水の5倍の重さがいるので 50×5＝250g。
  4. 確かめ：金属X250gは水 250×0.2＝50gぶん。2の50gにもどる。
答え：250g
今回：10g ×（正解250g）。部品の形を直さなかった＝「金属X1gは水0.2gと同じ」に線を引いて拾えているが、直した形を書かずに式へ入れた。余白の最後の式は、350に1/7と1/5をかけて10。350の1/7＝50g（100℃の水なら50g）までは解答冊子と同じで、最後に5倍する所を1/5にしたと考えられる。温度差ははじめ「10：80」と書き、あとで70に直したと考えられる跡がある。次は式の前に「水50gぶん → 金属Xは5倍」と1行書いてから計算する。
コツ：向きは両方セットにしておく。金属Xの重さ→水に直すときは×0.2、水の重さ→金属Xに直すときは÷0.2（＝×5）。答えを書く前に「水50gより重くなるはず」と大小を先に決めると、10gはおかしいと気づける。

DC2 (1) 羽化するアズキゾウムシの数 A・B・C 資料問題・グラフをくり返し読む

👀 まず見るところ

【資料問題】部品は資料の正体「横＝容器に入れる親の数／たて＝羽化した子の数」と答え方「Cは十の位まで」に丸。「子を取り出して新しい容器に入れ」は、たての値を横じくに移す、と直して書く → A・Bは読むだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 「安定する」＝親の数と、羽化する子の数が同じになること。同じなら、次の代も同じ数がくり返される（解答冊子）。
  • グラフの上で「親の数＝子の数」の点は、(100, 100)、(200, 200)…を結んだななめの直線の上にある。

🔍 こう読み解く

  1. 例で読み方を確かめる。横400から上へ進み、曲線にぶつかった高さが650。本文の「400匹 → 650匹」と合う。
  2. A：横650から上へ → 曲線の高さは550。B：横550から上へ → 600。
  3. C：550、600…と、ある数をはさんで下・上と行き来しながら、幅がせばまっていく。落ち着く先は「親の数＝子の数」の点。原点と(800, 800)を結ぶ直線を引き、曲線と交わる点を読む → 580。
答え：A 550　B 600　C 580
今回：○（原本はA・B・Cとも赤丸、記録も同じ）。A 550・B 600 は解答と同じ。Cの答案は「575」と読め、解答冊子の580と5ちがうが赤丸がついている。グラフには横じくの550・600・650あたりからたて線、たての550〜600の間に横線が3本引いてあり、代ごとに読み進めたあとがある。575は600の次の代を読んだ値と考えられる。答え方は「十の位まで」なので、ななめの直線との交点を読んで580と書く。
コツ：ななめの直線は、定規で原点とグラフの右上のかどを結ぶ。(100, 100)のような目もりの交点を通っているかで確かめられる。

DC2 (2) 気化熱による現象 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は設問の「液体が気体になるとき」と「すべて」に丸。ア〜エの横に「何が液体→気体になるか」を1語ずつ書く → 液体が出てこないエだけが外れる。

📚 前提知識

  • 気化熱＝液体が気体になるときに、まわりからうばう熱。うばわれた側の温度が下がるので、涼しく（冷たく）感じる。
  • ドライアイスは固体のまま直接気体になる（昇華・630-24 確認1(2)）。液体を通らない。

🔍 こう読み解く

  1. ア 緑のカーテン → 葉から水が水蒸気になって出ていく（蒸散）。液体→気体 → ○。
  2. イ 打ち水 → まいた水が蒸発する → ○。ウ アルコール消毒 → 手についたアルコール（液体）が蒸発する → ○。
  3. エ ドライアイス → 固体→気体。涼しくはなるが「液体が気体になるとき」に合わない → ×。
答え：ア・イ・ウ
今回：ア・イ・ウ ○。設問の「気化熱による現象として」に線が引いてあり、エを外せている。
