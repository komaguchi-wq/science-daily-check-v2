L (1) ばねばかりでつるした、軽い棒のてこ 条件文・計算

👀 まず見るところ

【条件文】部品は図の「6cm」「4cm」。(1)のおもりは支点から 6＋4＝10cm と直して図に書く → ばねばかりの位置を支点にすれば、左回り＝右回りの式1本で決まる。

📚 前提知識

  • てこのつり合いは、支点のまわりで「おもりの重さ×支点からの距離」の左回りの合計と右回りの合計が等しい。
  • ばねばかりでつるした点を支点にすると、ばねばかりの力は距離が0なので式に入らない。「軽い棒」は棒の重さを考えないという合図。

🔍 こう読み解く

  1. 支点＝ばねばかりの位置。左回りは 70×8＝560。
  2. 右回りは、60gが6cmで 60×6＝360、(1)のおもりが10cmで □×10。
  3. 560＝360＋□×10 → □×10＝200 → □＝20。
答え：20g
自分で解くときのチェック：距離は「となりのおもりから」ではなく「支点から」。4cmのまま式に入れると □×4＝200 で50gになる。図に10cmと書いてから式へ進む。

L (2) はしをばねばかりで上に引くてこ 条件文・計算

👀 まず見るところ

【条件文】部品はばねばかりの「40g」。右はしを上向きに引く矢印に直して図に置き、支点（三角の台）から 20＋30＝50cm と書く → 左はしの50gと同じ回転の側に入ると決まる。

📚 前提知識

  • 支点の右側を上向きに引く力は、支点の左側を下向きに引く力と同じ向き（左回り）に棒を回す。力が上向きか下向きかで、式のどちら側に入るかが決まる。
  • 三角の台が棒を支える力は、支点そのものにかかるので距離0。式には入らない。

🔍 こう読み解く

  1. 距離を支点からに直す。50gは左へ10cm、(2)のおもりは右へ20cm、ばねばかりは右へ50cm。
  2. 左回り：50×10＋40×50＝500＋2000＝2500。
  3. 右回り：□×20＝2500 → □＝125。
答え：125g
自分で解くときのチェック：ばねばかりの40gを右回りの側に入れると、500＝□×20＋2000 となって解けない。式が成り立たないときは、力の矢印の向きを見直す。

L (3) さおばかり・皿に何ものせないときの分銅の位置 条件文・計算

👀 まず見るところ

【条件文】部品は「重さが100gの太さが一様な棒」。100gは棒のまん中（左はしから30cm＝支点から右へ10cm）に下向きの矢印で置く（直して書く）→ 皿・棒・分銅の3つでつり合いの式が決まる。

📚 前提知識

  • 太さが一様な棒の重さは、棒のまん中に全部かかっているとみなせる。長さ60cmなら、はしから30cmのところ。
  • 支点が棒のまん中からずれていると、棒の重さも棒を回す。ここでは矢印が支点の右にあるので、分銅と同じ右回りに入る。

🔍 こう読み解く

  1. 左回り：皿100gが支点から20cm → 100×20＝2000。
  2. 右回り：棒 100×10＝1000 と、分銅 100×□。
  3. 2000＝1000＋100×□ → 100×□＝1000 → □＝10。
答え：10cm
自分で解くときのチェック：図に棒の重さの矢印を描いたか。描かずに 100×20＝100×□ とすると20cmになる。

L (5) さおばかりではかれる最大の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「最大で」に丸。「分銅をいちばん遠くにつるしたとき」に直して書く → 分銅の位置は支点から右はしまでの40cmと決まり、皿にのせる重さを□にして式を立てる。

📚 前提知識

🔍 こう読み解く

  1. 右回りの最大：棒 100×10＝1000 と、分銅 100×40＝4000 → 合わせて5000。

  3. 確かめ：0gの位置は10cm、右はしは40cmで、分銅は30cm動かせる。10gにつき2cmだから 30÷2×10＝150g。

自分で解くときのチェック：250gで止めない。250gは皿をふくめた重さで、聞かれているのは「皿にのせるもの」。皿の100gを引く。

L (8) 火山灰が鍵層に適している理由 素材文・選択

👀 まず見るところ

【素材文】部品は「鍵層」に丸。鍵層＝はなれた場所の地層を「同じ時にできた」と結びつける目印、と直して書く → 目印になる条件は、広い範囲に・短い時間で積もることと決まる。

📚 前提知識

  • 鍵層は、地層のつながりやできた時代を比べる手がかりになる層。火山灰の層がその代表。
  • 火山灰はふん火のときに風で遠くまで運ばれ、短い間に降り積もる。ふん火ごとに火山灰の特ちょうがちがうので、ほかの層と見分けやすい。

🔍 こう読み解く

  1. ①：せまい範囲にしか積もらない層では、はなれた場所どうしを比べられない → 広く。
  2. ②：積もるのに長い時間がかかる層では、「同じ時」の目印にならない → 短い。
答え：① 広く　② 短い

M (7) ハワイ島の火山をつくる火山岩 素材文・穴うめと図えらび

👀 まず見るところ

【素材文】部品は「斜面がゆるやかなたて状火山」と「火山岩」に丸。前の語で岩石名、後の語で図が決まる → ねばりけの弱いマグマ＝ゲンブ岩、火山岩＝小さな粒の中に大きな結晶が散らばるア。

📚 前提知識

  • マグマのねばりけが弱いと、うすく広がって流れるので、斜面のゆるやかな火山になる。このマグマが冷えてできる火山岩がゲンブ岩で、色は黒っぽい。
  • 火山岩は地表や地表近くで急に冷えるので、結晶が育ちきれない。大きな結晶のまわりを、ごく小さな粒がうめるつくり（斑状（はんじょう）組織）になる。

🔍 こう読み解く

  1. ①：たて状火山 → ねばりけが弱い → ゲンブ岩。解答らんに「岩」が印刷されているので、書くのは「ゲンブ」まで。
  2. ②：アは大きな結晶と小さな粒がまざる → 火山岩。イは大きな結晶だけがすきまなく並ぶ → 深成岩（(8)のつくり）。火山岩はア。
答え：① ゲンブ　② ア
今回：① ゲンブ ○　② ア ○。

M (8) 深成岩の結晶のつくり 知識問題

等粒状（とうりゅうじょう）。深成岩は地下深くでゆっくり冷えるので、どの結晶も大きく育ち、同じくらいの大きさの粒がすきまなく並ぶ。(7)の図イがこのつくり。「等しい大きさの・粒・のようす」と意味で区切ると、漢字3字が出てくる。火山岩の斑状組織と対にする。
答え：等粒状（組織）
今回：「等粉」と読める ×。知識＝「粒」が「粉」になり、「状」が抜けている。「等・粒・状」の3字を意味で区切って書き直す。

M (9) 石灰岩が熱で変成した岩石 知識問題

大理石。石灰岩がマグマの熱を受けて、結晶が大きく育ち直した岩石（変成岩）。もとが石灰岩なので、塩酸をかけると二酸化炭素が出る性質は変わらない。
答え：大理石
今回：大理石 ○。

今回：チャート ○。

H (1)① イーストといっしょに混ぜる〔X〕 素材文・穴うめ

👀 まず見るところ

【素材文】部品は本文2〜3行目の「糖分を分解してエネルギーを生み出します」に丸。イーストが使うのは糖分 → 小麦粉・食塩・水のほかに「イーストと」混ぜる〔X〕は砂糖と決まる。

📚 前提知識

  • イースト（酵母）は生きている微生物。酸素が十分にないとき、糖分を分解してエネルギーを得て、アルコールと二酸化炭素を出す（嫌気呼吸）。だから、はたらかせるには糖分をあたえる。
  • 重そうも生地をふくらませるが、こちらは加熱されて二酸化炭素を出す薬品。イーストのはたらきとは別のしくみ。

🔍 こう読み解く

  1. 空らんの前は「イーストと〔X〕を混ぜて」。イーストは生き物なので、いっしょに入れるのは「イーストが使うもの」と考える。
  2. 本文にもどると「イーストは…糖分を分解してエネルギーを生み出します」。使うものは糖分。
  3. 糖分をあたえる材料 → 砂糖。解答冊子は「砂糖（グラニュー糖）」。
  4. 確かめ：次の文は「イーストから排出された〔Y〕によってパン生地がふくらみ」。ふくらませる役はイースト自身なので、Xに別のふくらし粉を入れると話が合わない。
答え：砂糖（グラニュー糖）
今回：重そう ×。部品を拾えなかった＝「糖分を分解して」を拾わず、「パンをふくらませるもの」の知識から重そうを書いたと考えられる。本文で丸がついているのは「アルコール」だけで、これは③の部品。次は空らんの前の「イーストと」に丸をつけ、イーストが何を使うかを本文からさがす。

H (1)② パン生地をふくらませる〔Y〕 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「イーストから排出された」と「ふくらみ」に丸。生地をふくらませるのは気体。イーストが出すのはアルコールと二酸化炭素で、気体は二酸化炭素のほう。

📚 前提知識

  • イーストは嫌気呼吸で糖分を分解するとき、アルコールと二酸化炭素を出す（解答冊子）。本文には「アルコールが発生する」としか書かれていないので、もう1つの二酸化炭素は知識で足す。
  • 二酸化炭素のあわが生地の中に閉じこめられてすきまができる。これが「やわらかい食感」の理由。

🔍 こう読み解く

  1. 「排出された」→ イーストが体の外に出したもの。候補はアルコールと二酸化炭素の2つ。
  2. 「ふくらみ」→ 生地を中からおし広げるのは気体 → 二酸化炭素。
答え：二酸化炭素
今回：二酸化炭素 ○。

H (1)③ 子供でも食パンを食べられる理由〔Z〕 素材文・穴うめ

👀 まず見るところ

【素材文】部品は空らんの文の「パンを作る過程で」に丸。過程の最後は「焼く」＝高温。アルコールは焼く温度より低い温度でふっとうするので、気体になって出ていく → Zは気化（蒸発）。

📚 前提知識

  • アルコール（エタノール）のふっ点は約78℃。食パンの生地をオーブンで焼く温度は150〜200℃（解答冊子）。ふっ点より高くなるので、液体のアルコールは気体になる。

🔍 こう読み解く

  1. 設問は「子供でも食べることができる理由」→ アルコールが残っていないことを言えばよい。
  2. 空らんの形は「ほとんど〔Z〕するから」。なくなる理由は、焼くときの熱で気体になること → 気化。「蒸発」でも正解。
答え：気化（蒸発）
今回：気化 ○。本文の「アルコール」に丸がついていて、③の部品を拾えている。

H (2)① 鳥は肺の代わりに気嚢で酸素を吸収するか まざり型→素材文・○×

👀 まず見るところ

【まざり型→素材文】部品は本文の「横隔膜をもっておらず」「袋をふくらませたり縮ませたりすることで呼吸」。気嚢は横隔膜の代わりに空気を動かす袋で、酸素を取り入れるのは肺 → 「肺の代わりに」が合わず×。

H (2)② →と⇒で二酸化炭素が多いのは⇒か 資料問題・○×（矢印の読み分け）

👀 まず見るところ

【資料問題】部品は図の2種類の矢印。→は肺に入る前（気管から後気嚢・肺へ）、⇒は肺を出たあと（肺から前気嚢へ、そして外へ）と図の横に1行書く。肺を通ると二酸化炭素が増えるので、多いのは⇒。

📚 前提知識

  • 肺では、空気中の酸素が血液に入り、血液中の二酸化炭素が空気に出る。だから肺を通ったあとの空気は、酸素が少なく二酸化炭素が多い。

🔍 こう読み解く

  1. 「息を吸うとき」の図：→は口から気管を下り、後気嚢と肺へ向かう。⇒は肺から前気嚢へ向かう。
  2. 「息を吐くとき」の図：→は後気嚢から肺へ。⇒は気管を上って外へ出る。
  3. どちらの図でも⇒は肺を通ったあとの空気 → 二酸化炭素が多い → ○。
答え：○
今回：○ ○。図に書きこみは無いが、③も合っているので、2種類の矢印を読み分けられたと考えられる。

H (2)③ 吸うとき前気嚢も後気嚢も酸素の多い空気か 資料問題・○×（「も」を確かめる）

👀 まず見るところ

【資料問題】部品は文の「前気嚢の中も後気嚢の中も」。「息を吸うとき」の図で2つを別々に確かめる。後気嚢に入るのは→（肺の前）、前気嚢に入るのは⇒（肺のあと）→ 前気嚢は酸素が少なく×。

📚 前提知識（あれば答え合わせに使う）

  • 鳥の空気の道すじは、外 → 後気嚢 → 肺 → 前気嚢 → 外。肺にはいつも同じ向きに空気が流れる。これが本文の「一方通行」で、吸う息と吐く息が肺の中で混ざらない理由。

🔍 こう読み解く

  1. 後気嚢：吸うときに→が入る → 肺を通る前の、酸素の多い空気。ここは文と合う。
  2. 前気嚢：吸うときに⇒が入る → 肺を通ったあとの、酸素の少ない空気。ここが文と合わない。
  3. 2つのうち片方だけ正しい文は誤り → ×。解答冊子も「前気嚢には肺を通過したあとの酸素の少ない空気（⇒）」。
答え：×
今回：× ○。②の矢印の意味を、③にも使えたと考えられる。
