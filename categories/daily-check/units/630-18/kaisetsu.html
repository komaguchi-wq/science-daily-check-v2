📚 前提知識

  • 北半球では風が進む向きの右へそれる（地球の自転）ので、吹きこむときは反時計回り、吹き出すときは時計回りになる。

発展4 (1) 空らん（A）日本の上空を西から東へ吹く風 素材文・用語

👀 まず見るところ

【素材文】部品は（A）の直前「日本の上空を西から東へ吹いてくる」に丸 → 日本の上空で西から東に吹き続ける風＝偏西風。あとの「東から西へ吹いている」は貿易風の説明で、（A）とは逆向き。

📚 前提知識

  • 偏西風は緯度およそ35〜65度の上空を西から東へ吹く風。日本の天気が西から東へ変わるのはこの風のため。
  • 貿易風は緯度およそ30度以下の赤道近くを東から西へ吹く風。どちらも地球の自転と南北の温度差でいつも吹いている「恒常風」（解答冊子）。

🔍 こう読み解く

  1. じゅんさんの文は「赤道の貿易風は、日本の上空の（A）が東から西へ吹いているようなもの」。（A）は日本の上空の風の名前。
  2. 「西から東へ」＋「日本の上空」→ 偏西風。漢字3字で書く。
答え：偏西風

発展4 (2) 空らん（B）〜（D）を選ぶ 素材文・記号

👀 まず見るところ

【素材文】部品は各空らんの前後の言葉に丸 → （B）「海面のあたたかい海水を吹き寄せる貿易風のほうが…ところを吹いている」、（C）「日本は太平洋の…にある」、（D）「ラニーニャ現象が起きているときのほうが」。3つとも会話文と地図の向きで決まる。

  • 貿易風は海面近くの低いところを吹くので、海面の水を西へ押し流せる。偏西風は上空を吹く（解答冊子）。

  2. （C）貿易風は東から西へ。インドネシアや日本は吹き寄せられる側＝太平洋の西側（イ）。

発展4 (3) 貿易風の向きを地図に1本の矢印でかく 条件文・作図

発展4 (4) エルニーニョ・ラニーニャの断面図 資料問題・記号

👀 まず見るところ

【資料問題】資料の正体は「海面水温の分布図2枚」と「断面図ア〜カ（風の向き・強さ＋あたたかい水）」。先に風の向きで消す（貿易風は左向き＝東→西なのでオ・カは×）。次に地図の30℃の場所と、断面図のあたたかい水の寄り方を合わせる。

📚 前提知識

  • ラニーニャ＝貿易風が強い → あたたかい水が西（インドネシア側）に厚くたまり、断面はカタカナの「ラ」の形。東側（ペルー沖）は冷たい水が上がってくる。
  • エルニーニョ＝貿易風が弱い → あたたかい水が西に寄らず、太平洋の中央〜東まで広がる。断面は平らに近い。

🔍 こう読み解く

  1. 地図②（ラニーニャ）は30℃がインドネシアのそば、南米側は18℃と低い → 西があたたかく東が冷たい（解答冊子）。地図①（エルニーニョ）は30℃が太平洋の中央にある。
  2. 断面図を風の向きで消す：オ・カは右向き（西→東）で貿易風ではない → ×。残りア〜エはすべて左向き。
  3. ラニーニャ＝強い風＋西に厚い「ラ」の形 → ア（イは強い風だが水が平ら）。エルニーニョ＝弱い風＋平らに広がる → エ（ウは弱い風なのに「ラ」の形）。
答え：① エ　② ア
コツ：「風の向き → 風の強さ → 水の形」の順に1つずつ消す。6枚を一度に見比べない。

発展4 (5) ラニーニャのときに日本で見られやすい現象2つ 素材文・2つ選ぶ

👀 まず見るところ

【素材文】部品は「ラニーニャ現象」「2つ」に丸と、会話文の結論「日本は西側にあるから、ラニーニャのときのほうが水温が高くなる」。水温が高い → 夏が暑い・水蒸気が多い、の2方向に広げる。地震・火災は海水温と関係がない。

📚 前提知識

  • ラニーニャで太平洋の西側の海面水温が上がると、積乱雲の活動が活発になり、夏は太平洋高気圧が北に張り出しやすく、日本の気温が高くなる（解答冊子）。
  • 南から湿った気流が入りやすく、南の地方を中心に降水量が多くなる。冬はむしろ西高東低が強まって寒く、大雪になりやすい（解答冊子）。

🔍 こう読み解く

  1. オ〜クの地震・火災は海水温とは別の話 → まとめて×。残りはア〜エの気温と降水量。
  2. 夏の気温：水温が高い＋高気圧が張り出す → 高くなる → ア○。イ「冬の気温が高くなる」は逆（寒くなる）→ ×。
  3. 降水量：南からの湿った空気で南の地方に雨 → ウ○。エ「北の地方」→ ×。答えはア・ウ。
答え：ア・ウ

発展4 まとめ ラニーニャ・エルニーニョ

  • 貿易風＝赤道近くを東から西へ（海面近く）、偏西風＝日本の上空を西から東へ。矢印は名前の「吹いてくる方向」が始点。

  • ラニーニャの日本：夏は暑い・南の地方で雨が多い・冬は寒く大雪。「水温が高い」から2方向に広げて覚える。
