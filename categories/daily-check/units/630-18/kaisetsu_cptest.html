CP (1) ショート回路はどれか 資料問題・実物のつなぎ方

👀 まず見るところ

【資料問題】部品は正体「実物の絵・＋極から−極までの道」と聞かれ方「ショート回路をすべて」。＋極から出て−極に着くまでにフィラメントを通らない道があるか、4つ全部に○×をつける。

📚 前提知識

  • ショート回路＝乾電池の＋極と−極が、豆電球を通らずに導線や金属だけでつながった回路。大きな電流が流れて乾電池が熱くなる。
  • 豆電球は「先のとがった金属（底）」と「横のねじの部分」の2か所につながないと光らない。同じ部分に2本つないでも、フィラメントを通らない。

🔍 こう読み解く

  1. ア：＋極 → 右の豆電球（底が＋極、横に導線）→ 上の豆電球の底に2本とも → −極。右の豆電球は通るので、ショートではない。
  2. イ：＋極に右の豆電球の底、横から導線 → 左の豆電球の横 → 底が−極。豆電球2個を通る → ×。
  3. ウ：＋極からの導線が左の豆電球の横（ねじ）に、その横が右の豆電球の横にふれ、右の横から−極へ。ねじ→ねじ→導線でフィラメントを1つも通らない → ショート回路。
  4. エ：＋極に上の豆電球の底、その横に右の豆電球の横、右の底から−極。2個を通る → ×。
答え：ウ
コツ：実物の絵は「底」と「横」を見分ける。ねじの横どうしがふれている所は導線と同じ。

CP (2) 豆電球が1つだけつくもの 資料問題・実物のつなぎ方

👀 まず見るところ

【資料問題】部品は聞かれ方「1つだけつく」。(1)で4つにつけた「通る豆電球の数」をそのまま使う → アだけ上の豆電球の底に2本がきていて、通らない。

📚 前提知識

  • 豆電球の同じ金属部分に導線を2本つなぐと、電流はその金属を通りぬけるだけで、フィラメントには流れない。

🔍 こう読み解く

  1. ア：上の豆電球は底に2本 → 通らない。右の豆電球は底が＋極・横に導線 → 光る。1つだけ。
  2. イ・エ：2個とも通る → 2つつく。ウ：ショート回路で、どちらもつかない。
答え：ア

CP (3) LED 2個をつないだときの様子 資料問題・向きの読み取り

👀 まず見るところ

【資料問題】部品は正体「LEDの足の長さ」と乾電池の記号「長い線＝＋極」。＋極から順に導線をたどり、各LEDに長い足から入るかを書く。1つでも逆なら直列全体に流れない。

📚 前提知識

  • LED（発光ダイオード）は決まった向きにしか電流を通さない。長い足を＋極側につなぐと光る。逆向きだと流れない。
  • 直列つなぎでは、1か所でも電流が止まると回路全体に流れない。

🔍 こう読み解く

  1. 乾電池の記号は左が長い線 → 左が＋極。左の導線は A の長い足につながる → Aは正しい向き。
  2. A の短い足から出た導線は、上を回って B の短い足に入る → Bは逆向き。
  3. 直列なので B で止まり、Aにも流れない → どちらも光らない。
答え：エ
コツ：LEDの問題は、＋極から導線を指でたどって「長い足に入る＝○、短い足に入る＝×」と各LEDに書く。

CP (4) 豆電球を並列につないだときの回路全体の抵抗 知識問題

小さく。並列にすると電流の通り道が2本になるので、全体としては電流が流れやすくなり、抵抗は小さくなる。直列は通り道が長くなる→抵抗は大きくなる、とセットで覚える。
答え：小さく

CP (5) 豆電球が最も明るく光る回路 資料問題・電流を数で置く

👀 まず見るところ

【資料問題】部品は正体「乾電池の記号が直列か並列か」と「豆電球が直列か並列か」。豆電球1個・乾電池1個を1として、豆電球1個に流れる数を4つの図のわきに書く → いちばん大きい数が答え。

📚 前提知識

  • 乾電池の直列は電流を押す力が2倍 → 豆電球の電流は2倍。乾電池の並列は押す力は1個と同じ → 明るさは変わらず、長持ちする。
  • 豆電球の直列は通りにくさが2倍 → 電流は半分。豆電球の並列は、それぞれに1個のときと同じ電流が流れる。

🔍 こう読み解く

  1. A：乾電池直列（2）× 豆電球並列（そのまま）→ 1個に 2。
  2. B：乾電池直列（2）× 豆電球直列（÷2）→ 1。C：乾電池並列（1）× 豆電球並列 → 1。D：乾電池並列（1）× 豆電球直列（÷2）→ 0.5。
  3. いちばん大きいのは A の 2。
答え：A

CP (6) 乾電池が最も長持ちする回路 資料問題・乾電池から出る電流

👀 まず見るところ

【資料問題】部品は聞かれ方「乾電池が最も長持ち」。これは「乾電池1個から出る電流がいちばん小さい」に直して書く → (5)で置いた数を、乾電池1個あたりに直す。

📚 前提知識

  • 乾電池の寿命は、そこから出る電流の大きさで決まる。電流が小さいほど長持ち。
  • 並列の乾電池は、回路全体の電流を2個で分けて出すので、1個あたりは半分。直列の乾電池は、どちらにも回路全体の電流がそのまま流れる。

🔍 こう読み解く

  1. A：豆電球2個×2 ＝ 全体4。直列なので乾電池1個にも 4。
  2. B：全体1 → 乾電池1個 1。C：豆電球2個×1 ＝ 全体2、並列で2個が分けて 1。
  3. D：全体0.5を並列2個で分けて 0.25。いちばん小さい → D。
答え：D

CP (7) アと同じ大きさの電流が流れるところ 資料問題・各点の電流

👀 まず見るところ

【資料問題】部品は「アと同じ大きさ」と各点の位置「豆電球1個の枝か・全体の線か・乾電池1個の枝か」。アはAの上の豆電球の枝 → 2。イ〜キに数を書き、2の所をすべて選ぶ。

📚 前提知識

  • 並列の枝では、それぞれの枝の電流を足したものが、枝の外（全体の線）を流れる。
  • 直列の線は、どこでも同じ電流。

🔍 こう読み解く

  1. A：ア＝上の豆電球の枝 ＝ 2。イ＝全体の線 ＝ 2＋2 ＝ 4。
  2. B：ウ ＝ 1。C：エ＝全体の線 ＝ 1＋1 ＝ 2。オ＝乾電池1個の枝 ＝ 1。
  3. D：カ＝全体 0.5。キ＝乾電池1個の枝 0.25。2 になるのは エ だけ。
答え：エ
コツ：「同じ大きさ」の問題は、先に全部の点に数を書く。1つ見つけて止まると「すべて選ぶ」で落とす。

CP (8) 回路Aの電流計 条件文・計算

👀 まず見るところ

【条件文】部品は「電流計は240mA」（豆電球1個＋乾電池1個）と図の「豆電球3個直列・乾電池2個直列」。240を1として、乾電池直列は×2、豆電球直列は÷3 に直して書く。

📚 前提知識

  • 豆電球を直列に n 個つなぐと、電流は 1/n。乾電池を直列に n 個つなぐと、電流は n 倍。
  • 電流計は回路に直列につなぐ。直列なので、どこにつないでも同じ値を示す。

🔍 こう読み解く

  1. 乾電池2個直列 → 2倍。豆電球3個直列 → 1/3。合わせて 2/3。
  2. 240 × 2 ÷ 3 ＝ 160mA。
答え：160mA

CP (9) 回路Bの電流計 条件文・計算

👀 まず見るところ

【条件文】部品は図の「電流計がどの枝の電流を集めているか」。Bは3本の並列（上：2個直列・中：1個・下：1個）で、電流計は上と中の2本だけが合流した線にある。下の枝は電流計を通らない。

📚 前提知識

  • 並列の枝は、それぞれ乾電池に直接つながっているのと同じ。豆電球1個の枝は1（240mA）、2個直列の枝は 1/2（120mA）。
  • 電流計の値は、その線に合流している枝の電流の合計。

🔍 こう読み解く

  1. 上の枝：豆電球2個直列 → 120mA。中の枝：1個 → 240mA。下の枝：1個 → 240mA。
  2. 電流計の線に合流しているのは上と中 → 120 ＋ 240 ＝ 360mA。
  3. 下の枝を足して600にしない。下の枝は電流計の下で乾電池にもどっている。
答え：360mA
コツ：電流計の両側の線を指でたどり、「どの枝がこの線を通るか」に印をつけてから足す。

CP (10) 回路Cの電流計 条件文・計算

👀 まず見るところ

【条件文】部品は図の「電流計が豆電球と並列」と注意書き「こわれる場合は×」。電流計は導線と同じ（抵抗ほぼ0）に直して書く → 並列の豆電球は電流計に素通りされて光らず、残るのは右の豆電球1個。

📚 前提知識

  • 電流計の内部は抵抗がとても小さい。豆電球と並列につなぐと、電流はほぼ全部が電流計を通り、その豆電球には流れない（導線でショートしたのと同じ）。
  • 電流計がこわれる「×」は、乾電池に直接並列（豆電球を1つも通らない）につないだとき。この図は右に豆電球が1個残っているので、こわれない。

🔍 こう読み解く

  1. 電流計と並列の豆電球は、導線で短絡されたのと同じ → ないものとして消す。
  2. 残った回路は 豆電球1個＋乾電池1個 → 240mA。その全部が電流計を通る。
答え：240mA
コツ：「電流計と並列の豆電球」を見たら、まず×を書いて消す。そのあとに豆電球が残れば数字、残らなければ「×」。

CP まとめ 電気回路の数え方

  • 実物の絵は「底」と「横」の2か所を通るかで決める。ねじ横どうしがふれる＝導線（ウのショート）、同じ部分に2本＝通らない（アの上の豆電球）。
  • 回路図は「豆電球1個・乾電池1個＝1」と置いて、乾電池直列×2／豆電球直列÷n／並列はそのまま、全体は足す。(5)〜(7)はこの数を図に書けば一気に決まる。
  • 電流計は導線と同じ。豆電球と並列なら、その豆電球を消す。乾電池に直接並列なら「×」。
