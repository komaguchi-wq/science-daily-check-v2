N63-08 CP（コアプラス確認テスト・植物②＝茎と葉のつくり／花と果実／蒸散・範囲562〜578・624）

CP 全体像 コアプラス確認テスト 植物② 10問

範囲は「植物②（植物のつくり・蒸散）」。(1)〜(4)は茎と葉の断面図で維管束の名前・位置・中身、(5)〜(7)は花のどこが実になるか（カキ・リンゴ・裸子植物）、(8)〜(10)はワセリンの蒸散実験と蒸散の条件。

図の問題は「茎では道管が内側、葉では表側」の1行を図の横に置くと(2)〜(4)がつながる。(8)(9)は試験管ごとに「表＋裏＋茎」の式を書いてから引き算する。

CP (1) AとBの集まりを合わせた名前 知識問題

維管束（いかんそく）。図1の白い部分A＝師管、黒い部分B＝道管で、この2つが束になったものが維管束。左の円のように全体に散らばるのが単子葉類、右の円のように輪に並ぶのが双子葉類。「維管束＝道管＋師管の束」と、束の中身まで一組で覚える。
答え：維管束

CP (2) 図1のCの名前とはたらき 資料問題・茎の断面

👀 まず見るところ

【資料問題】部品は図1右の「C」の線の先＝8つの束をつなぐ内側の輪。輪の位置を「白（師管）と黒（道管）のあいだ」と1行に直して書く → 外側と内側のさかい目にあるのは形成層と決まる。

📚 前提知識

  • 双子葉類の茎では、外側に師管、内側に道管が並び、そのあいだに形成層がある。
  • 形成層は細胞分裂をさかんに行い、外側に新しい師管、内側に新しい道管をつくる。これで茎が太くなる。単子葉類には形成層がない。

🔍 こう読み解く

  1. 図1右で、Cは輪になって1周している。束の白い部分（外）と黒い部分（内）のちょうど境を通る。
  2. 師管と道管のあいだで輪になっている部分 → ① 形成層。
  3. 「成長するためにさかんに行う」＝細胞を増やすこと → ② 細胞分裂。
答え：① 形成層　② 細胞分裂
自分で解くときのチェック：図1右の束の横に「外＝師管／内＝道管」と書いてからCを見る。輪がその境にあれば形成層。

CP (3) 葉の断面で表側はどちらか 資料問題・葉の断面

👀 まず見るところ

【資料問題】部品は図2の正体「葉の断面」と聞かれ方「表側は左右どちら」。細長い細胞が表皮から内側へすき間なく並ぶ側（図2では横長の細胞が上下にぎっしり）に丸 → そこが柵状組織＝表側。図2では右。

📚 前提知識

  • 葉の表側は光をよく受ける側。細長い細胞をたてにすき間なく並べた柵状組織があり、葉緑体が多い。
  • 裏側は丸い細胞がすき間をあけて並ぶ海綿状組織で、表皮には気孔が多い。すき間と気孔は、気体の出入りのため。

🔍 こう読み解く

  1. 図2は葉を横倒しにした図。右側は、横長の細胞が表皮から内側へ向かってすき間なく2列に並ぶ → 柵状組織。
  2. 左側は丸い細胞とすき間が多く、左はしの表皮に、点（葉緑体）のある小さな細胞2つがすき間をはさんで向かい合った気孔がある → 裏側。
  3. 柵状組織のある右が表側。
答え：右
自分で解くときのチェック：葉の断面図は「ぎっしり＝表、すき間と気孔＝裏」の2つを両方確かめてから答える。図が左右反対になっていても同じ手順で決まる。

CP (4) 図1のBと同じ管は図2のどちらで、何が通るか 資料問題・茎と葉の対応

👀 まず見るところ

【資料問題】部品は図1の「Bの集まり」の線の先＝束の内側の黒い部分。「茎で内側＝道管＝葉では表側」と図の横に直して書く → (3)で表側は右なので、右にあるYが道管と決まる。

📚 前提知識

  • 道管は茎では内側、葉では表側を通る。師管は茎では外側、葉では裏側。茎から葉へ曲がるときに内側が上（表）を向く、と考えると位置がそろう。
  • 道管を通るのは根から吸収した水や肥料。葉でつくられた養分を運ぶのは師管。

🔍 こう読み解く

  1. 図1で「Bの集まり」の線は、束の内側（黒い部分）に当たっている → B＝道管。
  2. 図2の維管束は、左にXの小さな細胞、右にYの大きな細胞。表側（右）にあるのが道管 → ① Y。
  3. 道管の中身は根から吸収した水や肥料 → ② イ。アの「葉でつくられた養分」は師管（X）。
答え：① Y　② イ
自分で解くときのチェック：(3)の答え「表側＝右」を図2に書きこんでから(4)に進む。(3)を間違えると(4)①も連動してずれる。

CP (5) カキのA・Bは花のどの部分か 資料問題・花と果実

👀 まず見るところ

【資料問題】部品はカキの図で「A」の線の先＝実の上にかぶさる黒いへたと、「B」の線の先＝白い種のすぐ外側の黒っぽい身（種には当たらない）。「カキは子房が実になる」と図の横に1行置く → Aは外側を包んでいたがく、Bは子房と決まる。

📚 前提知識

  • 受粉すると子房が果実に、中の胚珠が種子になる。図3では、カ＝胚珠、キ＝それを包む子房。
  • 図3の外側の部品は、ア＝花びら、イ＝がく、ウ＝花たく（花びらやがくがつく台）、ク＝花を支える柄。カキやナス、ミカンは子房がそのまま実になり、へた（がく）は実になっても残る。

🔍 こう読み解く

  1. A：実の上にかぶさって残っている黒い部分＝へた。花のとき、いちばん外側で全体を包んでいたがく → イ。
  2. B：線の先は白い種の左どなりで止まり、種をつつむ黒っぽい身を指している。カキの身は子房が育ったもの → キ。白い種は胚珠（カ）が育ったもので、Bが指す「身」とは別。
答え：A イ　B キ
自分で解くときのチェック：Bの線は種のすぐそばまでのびるので、カ（胚珠→種子）と答えたくなる。線の先が「白い種の中」か「種のまわりの身」かを拡大して先に決める。白い種に当たっていなければ子房（キ）。

CP (6) リンゴのC・Dは花のどの部分か 資料問題・花と果実

👀 まず見るところ

【資料問題】部品はリンゴの図で「C」の線の先＝上につき出た柄と、「D」の線の先＝まん中のしんの外側の身。「リンゴは花たくが実になる」と1行置く → Cは花を支えていた柄、Dは花たくと決まる。

📚 前提知識

  • リンゴ・ナシは、子房でなく花たく（ウ）が大きくふくらんで食べる部分になる。子房はまん中のしんになり、種子はその中。
  • 実の上の柄は、花のときに花を支えていた柄（ク）がそのまま残ったもの。

🔍 こう読み解く

  1. C：実の上につき出た細い柄。図3でいちばん下、花全体を支えているク。
  2. D：しん（子房＝キ）の外側に広がる身。リンゴでは花たくが育った部分 → ウ。
  3. (5)と比べて両方セットで覚える：カキは子房（キ）が実、リンゴは花たく（ウ）が実。どちらも種子は胚珠（カ）から。
答え：C ク　D ウ
自分で解くときのチェック：リンゴの図は「しん＝子房」を先に丸で囲む。その外側がD＝花たく、と場所で決める。

CP (7) マツやイチョウの仲間と、むき出しの部分 知識問題

① 裸子　② 胚珠。マツ・イチョウ・スギ・ソテツは裸子植物。子房がなく胚珠がむき出しなので、子房が育ってできる果実はできず、種子だけができる（マツの松ぼっくりの中、イチョウのぎんなん）。子房に胚珠が包まれているカキやリンゴは被子植物、と組で区別する。
答え：① 裸子　② 胚珠

CP (8) AとBで減った水の差は何からの蒸散か 条件文・蒸散実験

👀 まず見るところ

【条件文】部品は「Aは6.5」「Bは4.7」と、図4の「Bは葉の表側にワセリン」。試験管ごとに「A＝表＋裏＋茎／B＝裏＋茎」と図の下に直して書く → A−Bで残るのは表側の分と決まる。

📚 前提知識

  • ワセリンをぬると気孔がふさがれ、その面からは蒸散しない。水面の油は、水面からの蒸発を止めるため。
  • 減った水＝蒸散した水。A＝表＋裏＋茎、B＝裏＋茎、C＝表＋茎、D＝茎。2本の差が、ぬった場所の分になる。

🔍 こう読み解く

  1. 図4の下に、A「表＋裏＋茎」、B「裏＋茎」、C「表＋茎」、D「茎」と書く。
  2. A−B＝（表＋裏＋茎）−（裏＋茎）＝表。6.5−4.7＝1.8cm³ が葉の表側からの蒸散。
  3. 聞かれているのは「AとBの差」が何と等しいか → ア 葉の表側。
答え：ア
自分で解くときのチェック：Bは「表側にワセリン」＝表側から出ない。Aから引いて残るのは「Bで止めた面」＝表側。ぬった面と残る面を逆にしない。

CP (9) Dで減った水の量 条件文・計算

👀 まず見るところ

【条件文】(8)と変わった部品は「Cは2.3」と求めるもの「D」＝茎だけ。「裏＝A−C」「茎＝A−表−裏」と(8)の式のとなりに直して書く → 表と裏の分をAから引いた残りがDと決まる。

📚 前提知識

  • Dは葉の両面にワセリンなので、残るのは茎からの蒸散だけ。Aから表と裏の分を引けば求まる。
  • 裏側の分（A−C）が表側の分（A−B）より大きいのは、気孔が葉の裏に多いから。

🔍 こう読み解く

  1. 表＝A−B＝6.5−4.7＝1.8cm³（(8)より）。
  2. 裏＝A−C＝6.5−2.3＝4.2cm³。
  3. 茎＝A−表−裏＝6.5−1.8−4.2＝0.5cm³。これがD。
  4. 確かめ：B＝裏＋茎＝4.2＋0.5＝4.7 で問題文と合う。
答え：0.5cm³
自分で解くときのチェック：近道は B＋C−A＝4.7＋2.3−6.5＝0.5。BとCを足すと茎が2回入るので、Aを引くと茎が1回分残る。

CP (10) 蒸散がさかんになるとき 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問の「すべて選びなさい」に丸。部品は選択肢の言葉「光」「風が吹いていない」「気温が高い」「乾燥」。「せんたく物がよくかわく条件か」に直して4つ全部に○×をつける。

📚 前提知識

  • 蒸散は気孔から水蒸気が出ていくこと。気孔は光が当たると開くので、昼のほうがさかん。
  • 水蒸気が出やすいのは、せんたく物がかわく条件と同じ：気温が高い・空気が乾いている・風がある。風がないと、葉のまわりに湿った空気がたまって出にくくなる。

🔍 こう読み解く

  1. ア 光が当たっている → 気孔が開く → ○。
  2. ウ 気温が高い → 水が蒸発しやすい → ○。エ 乾燥している → まわりの空気に水蒸気が少なく、出ていきやすい → ○。
  3. イ 風が吹いていない → 逆。風が吹いているときがさかん → ×。選ばない理由は「向きが逆」の1つだけ。
  4. 「すべて」なので、○の3つをまとめて書く → ア・ウ・エ。
答え：ア・ウ・エ
自分で解くときのチェック：「〜していないとき」の選択肢は、「していないとき」と「しているとき」のどちらがさかんかを一度言い直してから○×をつける。

CP まとめ 未解答・自分で解くとき

  • 図1・図2は「茎では道管が内側、葉では表側」を図の横に置くと、(2)形成層の位置・(3)表側・(4)Yが1本の線でつながる。
  • 花と実は両方セット：カキは子房（キ）、リンゴは花たく（ウ）が実になり、種子はどちらも胚珠（カ）。裸子植物は子房がないので実ができない。
  • ワセリンの実験は、試験管ごとに「表＋裏＋茎」の式を書いてから引き算。D（茎）は B＋C−A でも出る。
