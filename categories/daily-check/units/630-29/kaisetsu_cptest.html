630-29 L（コアプラス＋確認テスト・斜面の運動／ろうそくとアルコールランプ／溶解度）

L 全体像 コアプラス＋確認テスト 10問

中身は3つに分かれる。(1)〜(3)は斜面の運動（速さは高さ、ぶつけた後の動きは重さと速さ）、(4)〜(8)は炎と器具（ろうそく・アルコールランプ・ガスバーナー）、(9)(10)は溶解度の計算。

斜面の3問は「何を変えたか」に丸をつけてから選ぶ。溶解度の2問は「水100gあたり」の数字を、問題の水の量に直してから式に入れる。

L (1) おもりxを重くしたときの衝突の速さ 条件文・変えた条件

👀 まず見るところ

【条件文】変えた部品は「おもりxの重さ（図のA）」だけ。聞かれているのは「衝突するときの速さ（図のC）」に丸。高さBは変えていない → 速さは高さで決まるので、変わらない。

📚 前提知識

  • 斜面を転がり下りたおもりの速さは、転がり始めた高さで決まる。重いおもりも軽いおもりも、同じ高さからなら下に着いたときの速さは同じ。

🔍 こう読み解く

  1. 図で、Aは重さ・Bは高さ・Cは速さ、と役わりを書きこむ。
  2. 重さAを変えても高さBはそのまま → 衝突の速さCは変わらない＝ウ。
答え：ウ
自分で解くときのチェック：「重いほど速い」と思い込みやすい。速さを変えるのは高さ、という決まりを図のBのとなりに書いてから選ぶ。

L (2) おもりxを重くしたときにyが飛ぶ距離 条件文・変えた条件

👀 まず見るところ

【条件文】部品は「(1)のとき」＝xを重くしたまま、と聞かれる相手が「おもりyの飛ぶ距離（図のD）」に変わったこと。xの速さは同じでも重さが増えた → yを強くおし出すので、Dは大きくなる。

📚 前提知識

  • ぶつけられた物（y）の動きは、ぶつかる物（x）の重さと速さの両方で決まる。重いほど、速いほど、yは遠くへ飛ぶ。

🔍 こう読み解く

  1. (1)で、衝突の速さCは変わらないと決まった。
  2. 速さが同じで重さだけ増えた → yをおし出す力が強くなる → yの飛ぶ距離Dは大きくなる＝ア。
答え：ア
自分で解くときのチェック：(1)と(2)はセット。「速さは高さだけで決まる」「飛ぶ距離は重さと速さの両方」の2行を並べて書くと、答えが逆にならない。

L (3) B点とC点を転がる速さ 資料問題・図の高さをくらべる

👀 まず見るところ

【資料問題】資料の正体は「方眼の上に描かれた斜面の図」。部品はB点とC点の高さをマス目で読むこと → どちらも底から1マス目の同じ高さ。速さは高さで決まるので、BとCの速さは同じ。

📚 前提知識

  • 転がるおもりの速さは、出発点からどれだけ下りたか（高さの差）で決まる。斜面の向きが右下がりか右上がりかは関係ない。

🔍 こう読み解く

  1. Aから出発し、Bまでは下り、底を転がり、Cへ上る。
  2. マス目で高さを読むと、BとCは同じ段。Aから下りた高さが同じ → 速さも同じ＝ウ。
答え：ウ
自分で解くときのチェック：方眼の図は、点の横の位置でなく何マス目の高さかを数える。B・Cの横に高さの数を書きこんでから選ぶ。

L (4) ろうそくの炎にガラス管を差しこむ 知識問題

①白い ②出ます。炎の中心（炎心）には、とけて気体になったろうが燃えずに残っている。ガラス管で外に出すと冷えて細かい粒になり白いけむりに見える。これはろうそのものなので、火を近づけると燃えて炎が出る。黒いけむり（すす）が出るのは内炎にさしたとき、と区別する。
答え：① 白い　② 出ます

L (5) ろうが完全燃焼してできる物質 知識問題

二酸化炭素と水。ろうは炭素と水素でできているので、空気中の酸素と結びつくと、炭素からは二酸化炭素、水素からは水（水蒸気）ができる。石灰水が白くにごる・冷たいコップがくもる、という実験とセットで覚える。酸素が足りないと、炭素が燃え残って「すす」になる。
答え：二酸化炭素・水

L (6) アルコールランプの炎がろうそくとちがう点 知識問題

①すす ②暗い。ろうそくの炎が明るいのは、内炎で燃え残ったすす（炭素の粒）が熱せられて光るから。アルコールはろうより炭素が少なく燃えやすいので、すすがほとんど出ない → 光る粒がないので暗い炎になる。「すすが出ない＝暗い」のつながりで覚える。
答え：① すす　② 暗い

L (7) アルコールランプで加熱するときの金網の位置 資料問題・図の炎と線

👀 まず見るところ

【資料問題】資料の正体は「炎と、金網の高さを示す3本の線ア〜ウ」。部品は炎の先端がどの線にあたるか → 先端近くの線がア。いちばん温度が高い外炎の先で熱するので、ア。

📚 前提知識

  • 炎は外側から外炎・内炎・炎心。酸素にいちばんふれる外炎が最も高温で、物を熱するときは外炎の先の部分にあてる。

🔍 こう読み解く

  1. 図で、ウは炎のつけ根、イは炎のまん中（内炎）、アは炎の先端あたり。
  2. いちばん熱い外炎の先にあたるのはア。イ・ウだと内炎にふれて温度が低く、すすもつく。
答え：ア

L (8) ガスバーナーに火をつける順 知識問題

オ→エ→ウ→ア→イ。閉まっているか確認（オ）→元栓を開く（エ）→マッチの火を近づける（ウ）→ガス調節ねじを開く（ア）→空気調節ねじを開く（イ）。ポイントは2つ。火を先に用意してからガスを出す（ガスだけ出ると危ない）、ガスがついてから空気を足して青い炎にする。消すときはこの逆の順。
答え：オ→エ→ウ→ア→イ

L (9) 60℃の水125gを20℃に冷やしたときの結晶 条件文・溶解度の計算

👀 まず見るところ

【条件文】部品は「水100gに25g（60℃）・5g（20℃）」と、問題の水が「125g」であること。100gあたりの数字は ×1.25 に直して書く → 60℃で31.25g、20℃で6.25g。その差が結晶。

📚 前提知識

  • とける限度（溶解度）は水の量に比例する。水100gの数字をそのまま使わず、水の量の比で直す。
  • 冷やして出てくる結晶＝（高い温度でとけていた量）−（低い温度でとけていられる量）。

🔍 こう読み解く

  1. 水125gは100gの1.25倍。60℃でとける量は 25×1.25＝31.25g。
  2. 20℃でとけていられる量は 5×1.25＝6.25g。
  3. 結晶は 31.25−6.25＝25g。（100gあたりの差 25−5＝20g を1.25倍しても同じ。）
答え：25g
自分で解くときのチェック：「水125g」に丸をつけた時点で、余白に「×1.25」と書く。100gのまま 25−5＝20 と答えるのが定番のまちがい。

L (10) 60℃の飽和水溶液100gにとけている量 条件文・溶解度の計算

👀 まず見るところ

【条件文】部品は「飽和水溶液100g」。(9)の「水100g」とちがい、水溶液（水＋物質）の重さなので、水100g＋物質25g＝水溶液125g の組に直して書く → 125gのうち25gが物質。

📚 前提知識

  • 飽和水溶液の重さ＝水の重さ＋とけている物質の重さ。60℃なら 100＋25＝125g の中に25g。
  • 水溶液が何gでも、物質の割合（25／125）は同じ。

🔍 こう読み解く

  1. 60℃の飽和水溶液125gに物質25g、という組をつくる。
  2. 水溶液100gはその 100÷125＝0.8倍 → 物質も 25×0.8＝20g。（比で 125：25＝100：□ でも同じ。）
答え：20g
自分で解くときのチェック：「水100g」か「水溶液100g」か、設問の言葉に丸。水溶液と書いてあったら、まず「水100＋物質25＝125」の組を作る。

L まとめ 未解答・自分で解くとき

  • 斜面の3問は決まり1つ：速さは高さで決まる。重さは、ぶつけた相手の飛ぶ距離にだけ効く。
  • 炎の5問は「炎心＝ろうの気体（白いけむり）・内炎＝すす（明るい）・外炎＝最高温」の3層で全部つながる。ガスバーナーは「火→ガス→空気」の順。
  • 溶解度は水の量が100gかどうかに丸。水125gなら×1.25、水溶液100gなら「水100＋物質25＝125」の組に直してから計算する。

630-29 M（コアプラス確認テスト・斜面から飛び出すおもり／2つの斜面の速さと時間／炎と薬品の知識／結晶の計算）

M 全体像 630-19・20の復習＋発展知識 10問

題材は4つ。(1)〜(3)は斜面から飛び出すおもりの飛ぶ距離、(4)(5)は形のちがう2つの斜面の速さと時間、(6)〜(9)は実験器具と炎の知識、(10)は飽和水溶液を冷やしたときの結晶の計算。答えだけを書く形式。

運動の5問は、決まりが2本しかない。「斜面を下りた速さは、下りた高さだけで決まる（重さは関係ない）」と「飛ぶ距離は、飛び出す速さと台の高さで決まる」。図の A・B・C・D のどれが変わり、どれが変わらないかを図に丸をつけてから選択肢を読む。

M (1) おもりを重くしたときの飛ぶ距離 条件文・変わるものと変わらないもの

👀 まず見るところ

【条件文】部品は、変えたもの「おもりxの重さを重く」と聞かれているもの「飛ぶ距離（図のD）」。図のA・B・Cのどれも変えていない、と図の横に書く → 重さはB（速さ）を変えないので、Dも変わらない。

📚 前提知識

  • 斜面を転がり下りた速さは下りた高さ（A）だけで決まる。重いおもりも軽いおもりも、同じ高さから転がせば下に着いたときの速さは同じ。
  • 飛び出したあとの飛ぶ距離は、飛び出す速さ（B）と台の高さ（C）で決まる。

🔍 こう読み解く

  1. 重さを変えても、Aが同じならBは同じ。
  2. BもCも同じなら、D（飛ぶ距離）も同じ。
  3. 重さがきくのは「別のものにぶつけて動かす」とき（Lの木片のような問題）。自分が飛ぶ距離には、重さはきかない。この2つを区別する。
答え：ウ
今回：ア ×。知識＝「重いほど遠くへ飛ぶ」と考えた形。変わるのは重さだけで、速さを決めるA・飛ぶ距離を決めるB・Cは変わっていない。次は「変えたもの」に丸をつけ、A・B・Cのどれが変わるかを先に確かめる。

M (2) 飛び出す速さが2倍になったときの飛ぶ距離 条件文・比例

👀 まず見るところ

【条件文】(1)と変わった部品は「飛び出す速さ（図のB）が2倍」。台の高さCはそのままなので、落ちるまでの時間は変わらない、と図の横に書く → 飛ぶ距離＝速さ×落ちる時間 だからちょうど2倍。

📚 前提知識

  • 飛び出したおもりは、横には飛び出した速さのまま進み、縦には落ちていく。横の動きと縦の動きは別々に考えられる。
  • 地面に着くまでの時間は台の高さ（C）だけで決まり、横の速さには関係しない。

🔍 こう読み解く

  1. Cが同じ → 落ちるまでの時間は同じ。
  2. 横に進む距離D＝横の速さ×時間。速さが2倍、時間がそのままなので、Dは2倍。
答え：ア
今回：ア ○。

M (3) 台の高さが2倍になったときの飛ぶ距離 条件文・比例しないもの

👀 まず見るところ

【条件文】(1)と変わった部品は「台の高さ（図のC）が2倍」。今度は変わるのが落ちるまでの時間のほうで、横の速さBはそのまま → 時間が2倍にならないので、Dも2倍より小さい。

📚 前提知識

  • 落ちる距離は、時間が2倍になると4倍、3倍になると9倍と、時間×時間に比例する。落ちるほど速くなるから。
  • 裏返すと、高さが4倍になってやっと時間が2倍。高さ2倍では、時間は2倍に届かない。

🔍 こう読み解く

  1. Cが2倍 → 落ちるまでの時間は、2倍より小さい（4倍のときに2倍になる）。
  2. 横の速さBはそのままなので、D＝B×時間 も2倍より小さい。
  3. (2)と(3)は両方セット。速さを2倍→Dはちょうど2倍、高さを2倍→Dは2倍より小さい。
答え：ウ
今回：ウ ○。

M (4) 形のちがう斜面でBを通過する速さ 条件文・図から高さを読む

👀 まず見るところ

【条件文】部品は図1と図2の「AからBまで」と聞かれているもの「Bを通過するときの速さ」。マス目でAとBの高さの差を数えて図に書く → どちらも4マス下りているので、Bの速さは同じ。

📚 前提知識

🔍 こう読み解く

  2. 図2：Aから1マス下りて平らな道、最後に3マス下りてB。合計4マス。
  3. 下りた高さが同じなので、Bを通過する速さは図1も図2も同じ。
答え：ウ
今回：ウ ○。

M (5) AからBまでにかかる時間 条件文・途中の速さで決まる

👀 まず見るところ

【条件文】(4)と変わった部品は「かかる時間」。時間を決めるのはBの速さでなく途中の速さ。平らな道がAから何マス下にあるかを「速い／おそい」に直して図に書く → 図2の平らな道は1マスしか下りていないので、おそい道が長い図2のほうが時間がかかる。

📚 前提知識

  • 平らな道では速さは変わらない。その速さは、平らな道がAから何マス下にあるかで決まる。下にあるほど速い。
  • かかる時間は、道の長さを速さで進んだ合計。同じ長さの道なら、おそいほど時間がかかる。

🔍 こう読み解く

  1. 図1の平らな道はAから3マス下 → 速い。図2の平らな道はAから1マス下 → おそい。平らな道の長さはどちらも同じ。
  2. 同じ長さをおそく進む図2のほうが、平らな道で時間がかかる。斜面の部分は、合わせて同じ高さ（4マス）を同じ長さだけ下りるので、かかる時間は図1と図2で同じ。
  3. だから時間は図2の方が長い。
  4. (4)と(5)は両方セット。速さは「Bの高さ」で決まり、時間は「途中の高さ」で決まる。同じ高さに着くから同じ時間、とはならない。
答え：イ
今回：ウ ×。部品の形を直さなかった＝平らな道の高さを「速い／おそい」に直して図に書かず、(4)の「同じ」をそのまま時間にも使った。次は平らな道の横に「3マス下＝速い」「1マス下＝おそい」と書いてから選ぶ。

M (10) 飽和水溶液100gを冷やして出る結晶 条件文・溶解度の計算

👀 まず見るところ

【条件文】部品は「60℃の飽和水溶液100g」（水100gではない）と答え方「四捨五入して整数」。水100g＋30g＝130gの飽和水溶液を基準に直して書く → 130gを冷やすと30−10＝20g出るので、100gなら比で出す。

📚 前提知識

  2. 飽和水溶液100gは130gの 100/130＝10/13 倍なので、結晶も 20×10/13＝200/13＝15.38…g。
  3. 小数第1位を四捨五入して15g。

M まとめ 8/10 正解
