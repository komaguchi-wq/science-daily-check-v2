DC1 (1) 亜鉛に塩酸を加えて出る気体 知識問題

水素。亜鉛・鉄・マグネシウム・アルミニウムのような金属に塩酸を加えると水素が出る。石灰石に塩酸なら二酸化炭素、と出る気体の組をセットで覚える。
答え：水素
今回：水素 ○。

DC1 (2) 塩酸で亜鉛と同じ気体が出るもの 知識問題

ア（鉄）とウ（マグネシウム）。塩酸にとけて水素を出す金属は、亜鉛・鉄・マグネシウム・アルミニウム。銅は塩酸にとけないので気体は出ない。石灰石は塩酸と反応するが出るのは二酸化炭素、二酸化マンガンにうすい塩酸を加えても水素は出ない（酸素を出すのは過酸化水素水と組んだとき）。「すべて選びなさい」なので、1つ見つけて止まらず5つ全部に○×をつける。
答え：ア・ウ
今回：ア・ウ ○。

DC1 (3) 亜鉛0.65gをとかし切る塩酸の量 資料問題・表から読む

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「塩酸の量と出た気体・cm³」と、DとEで気体が「240cm³で同じ」になっている所。頭打ちの240cm³が亜鉛0.65gのとけ切る量なので、240cm³が出る塩酸の量を50→60の比で逆算する。

📚 前提知識

  • 気体が増えなくなったら、亜鉛がなくなって塩酸が余っている。増え続けている間は、塩酸がなくなって亜鉛が余っている。

🔍 こう読み解く

  1. A〜Cは塩酸50cm³につき気体60cm³。比は 50：60＝5：6。
  2. 気体の上限240cm³は 60×4 → 塩酸は 50×4＝200cm³。
  3. 確かめ：Dの250cm³・Eの300cm³はどちらも200より多いので、240で止まる。表と合う。
答え：200cm³
今回：200 ○。余白に「0.65－200－240」と書いてから答えていて、手順が正しい。ただし解答らんの字は「260」にも見えるので、0は閉じてはっきり書く。

DC1 (4) 亜鉛1.30g＋塩酸400cm³で出る気体 条件文・比例の計算

👀 まず見るところ

【まざり型→条件文】部品は「1.30g」（＝0.65gの2倍）と「塩酸400cm³」。(3)の1行「0.65g＝200cm³＝240cm³」を全部2倍に直して横に書く → 塩酸はちょうど400cm³で過不足なし、気体は240の2倍と決まる。

📚 前提知識

  • 亜鉛が2倍なら、とかし切るのに必要な塩酸も2倍、出る気体も2倍。ただし塩酸が足りなければ、気体は塩酸の量で決まる。

🔍 こう読み解く

  1. 1.30g の亜鉛をとかし切る塩酸は 200×2＝400cm³。加えた塩酸も400cm³なので、ちょうど使い切る。
  2. 気体は 240×2＝480cm³。
  3. もし塩酸が400より少なければ「塩酸50cm³につき60cm³」で計算し、多ければ480で止まる、と先に場合分けを決めておく。
答え：480cm³
今回：480 ○。余白の「1.3－400－480」のとおり、2倍の1行を書いてから答えている。

DC1 (5) ビーカーEにBTB液 資料問題＋知識

👀 まず見るところ

【まざり型→資料問題】部品は表の「E＝塩酸300cm³」と(3)で決めた「とけ切るのは200cm³」。300は200より多い → 反応後に塩酸が100cm³余っていると決まる。色はそのあと知識で。

📚 前提知識

  • BTB液は 酸性＝黄・中性＝緑・アルカリ性＝青。塩酸は酸性なので、余っていれば黄色。
  • 亜鉛と塩酸が反応してできる塩化亜鉛の水溶液は中性。もし塩酸がちょうど使い切られていれば緑になる。

🔍 こう読み解く

  1. Eは塩酸300cm³。使われるのは200cm³だけなので、100cm³分の塩酸が残る。
  2. 塩酸が残っている＝酸性 → BTB液は黄色。
答え：黄色
今回：黄 ○。

DC1 (6) 亜鉛を半分にしたときのグラフ 条件文・グラフをかく

👀 まず見るところ

【まざり型→条件文】部品は「亜鉛の量を半分」と、変えていない「塩酸は上と同じ濃さ」。「0.65g＝200cm³＝240cm³」の3つを全部半分に直して書く → 「0.325g＝100cm³＝120cm³」。折れ曲がる点が (100, 120) に決まる。

📚 前提知識

  • 塩酸の濃さが同じなら、グラフの最初のかたむきは変わらない（塩酸50cm³につき気体60cm³）。亜鉛の量が変わると、変わるのは頭打ちになる高さと、そこへ着く塩酸の量。

🔍 こう読み解く

  1. 亜鉛が半分 → 出る気体の上限は 240÷2＝120cm³。
  2. とかし切る塩酸も半分 → 200÷2＝100cm³。だから折れ点は (100, 120)。
  3. 0から (100, 120) まで表と同じかたむきの直線、そこから右は120cm³で水平。
答え：原点から (100, 120) まで直線で上がり、そこから300cm³まで120cm³で水平（解答冊子のグラフ）
今回：×。上限は120に下げたが、折れ点を (200, 120) にかいていて、最初のかたむきが表より小さい。部品の形を直さなかった＝「亜鉛を半分」を気体の上限だけに使い、とかし切る塩酸の量も半分になることを書かなかった。次は「g＝cm³＝cm³」の3つをセットで半分にしてから線を引く。

DC1 (7) 塩酸の濃さを半分にしたときのグラフ 条件文・グラフをかく

👀 まず見るところ

【まざり型→条件文】部品は(6)と変わった所「塩酸の濃さを半分」と、変えていない「亜鉛は0.65gのまま」。濃さ半分は「同じ気体を出すのに塩酸が2倍いる」に直して書く → 50cm³で30cm³、とかし切るには400cm³。

📚 前提知識

  • 塩酸の濃さが半分なら、同じ体積にふくまれる塩化水素が半分なので、出る気体も半分。グラフのかたむきが半分になる。亜鉛が同じなら上限の240cm³は変わらない。

🔍 こう読み解く

  1. うすい塩酸50cm³で気体30cm³。上限240cm³に着くのは 50×8＝400cm³のとき。
  2. グラフの横じくは300cm³まで。400はグラフの外なので、折れ点はかかない（解答冊子）。
  3. 0から (300, 180) まで、かたむき30/50の直線を1本。180＝30×6。
答え：原点から (300, 180) まで1本の直線（解答冊子のグラフ。折れ点は400cm³で、グラフの外）
今回：○。(300, 180) までの直線がかけている。

DC1 (8) 蒸発させて残る固体の量の比 条件文・比の計算

👀 まず見るところ

【まざり型→条件文】部品は求めるもの「CはEの何倍」と、表の気体「C 180・E 240」。残る白い固体は反応でできた塩化亜鉛で、できた量は出た水素の量と比例する → 180÷240 の割り算に直して書く。

📚 前提知識

  • 蒸発させて残るのは、反応でできた塩化亜鉛。余った塩酸は気体（塩化水素）がとけたものなので、蒸発させると何も残らない。
  • できた塩化亜鉛の量は、反応した亜鉛の量＝出た水素の量に比例する（解答冊子）。

🔍 こう読み解く

  1. Eは水素240cm³ → 亜鉛0.65gが全部反応した分の塩化亜鉛。
  2. Cは水素180cm³ → 反応した亜鉛はEの 180÷240＝0.75倍。残る塩化亜鉛も0.75倍。
  3. 「Cは塩酸が少ないから固体も少ない」と向きを確かめてから答える。Eの塩酸100cm³分の余りは固体にならない。
答え：0.75倍
今回：3/4 ○。0.75と同じ値で正解。解答らんが「倍」なので小数で書いておくと採点者に伝わりやすい。

DC1 まとめ 7/8 正解

  • 「0.65g＝200cm³＝240cm³」の1行を余白に書いてから解いていて、(3)(4)(8)の計算は手順どおり。
  • 落とした(6)は、亜鉛を半分にしたとき上限だけ半分にして、折れ点の塩酸の量を半分にしなかった。亜鉛が変わる＝「g・cm³・cm³の3つがセットで変わる」、濃さが変わる＝「かたむきが変わる」、と変わる場所を先に決める。
  • 覚え直し：塩酸が余れば黄（酸性）／残る固体は塩化亜鉛で、できた水素の量に比例。

DC2 全体像 ミツバチの8の字ダンス・化合物 4問

(1)は8の字ダンスの読みかえ。問題文の決まりは1つだけ。直進部分の向き＝えさ場の向き、真上の方向＝太陽の方向。図2は北が上の地図なので、「真上」を「太陽のある方角」に直してから図2に重ねる。正午の太陽は南＝(お)。

(2)は化合物と単体の区別。1種類の元素だけでできているもの（酸素・水素・銅）は単体、2種類以上が結びついたもの（食塩・二酸化炭素）が化合物。

DC2 (1)① 正午の8の字からえさ場の向き 資料問題・図を重ねる

👀 まず見るところ

【資料問題】部品は図1の「直進部分は真上から右に45°」と、問題文の「真上の方向＝太陽の方向」。正体を1行「真上＝正午の太陽＝南（お）」と直してから、南から時計回りに45°を図2で数える。

📚 前提知識

  • 正午の太陽は南にある。図2は(あ)が北・(う)が東・(お)が南・(き)が西の地図。
  • 8の字ダンスは、垂直な巣板の上で「真上」を太陽の向きに見立てる。直進部分が真上から右に何度かたむいているかが、太陽から見てえさ場が何度右（時計回り）にあるかを表す。

🔍 こう読み解く

  1. 図1の真ん中の図：太陽の方向を上にして、えさ場は右に45°。これと8の字の「真上から右に45°」が同じ形。
  2. 図2で太陽の向きを(お)＝南に置く。南から時計回りに45° → 南西＝(か)。
  3. 確かめ：地図は北が上なので、南から時計回りは西へ向かう。(え)の南東ではない。
答え：（か）
今回：い ×。部品の形を直さなかった＝「真上の方向」を図2の上（あ＝北）のまま使い、北から右に45°で(い)にした。真上は「太陽の方向」で、正午なら南。次は図2に先に「太陽＝(お)」と書きこんでから45°を数える。

DC2 (1)② 3時間後の8の字 条件文・図をかく

👀 まず見るところ

【条件文】部品は①と変わった「3時間後」と、変わらない「同じえさ場」。3時間後は太陽が西へ45°動くので「太陽＝南西（か）」に直して書く → えさ場(か)と太陽(か)が同じ向きになり、直進部分は真上を向く。

📚 前提知識

  • 太陽は1時間に15°ずつ東から西へ動く。3時間で45°。正午に南だった太陽は、3時間後には南西。
  • えさ場と太陽の向きが同じなら、8の字の直進部分は真上。右にずれていれば右に、左なら左にかたむく。

🔍 こう読み解く

  1. ①より、えさ場は(か)＝南西。これは3時間たっても動かない。
  2. 太陽は南(お)から南西(か)へ。えさ場と太陽の向きがぴたり重なる。
  3. 太陽とえさ場の角度は0° → 直進部分は真上の方向に向かってまっすぐ。8の字は左右対称に、直進部分を縦にかく（解答冊子）。
答え：直進部分が真上の方向を向いた8の字（解答冊子の図。直進部分は上向き、左右の輪を回って戻る）
今回：×。直進部分を左上にかたむけてかいている。部品の形を直さなかった＝「3時間後」を太陽の向き（南→南西）に直さず、①の答えからかたむきを決めた。①を取りちがえたまま進んだ分もある。次は「太陽は1時間15°」と書き、太陽とえさ場の向きを両方図2に置いてから差を見る。

DC2 (1)③ 集団で役割分担して生活する昆虫 知識問題

社会性昆虫。ミツバチ・アリ・シロアリのように、女王・はたらきバチ（アリ）などの役割を分けて集団で生活する昆虫をこう呼ぶ。解答らんに「昆虫」があるので、書くのは「社会性」の3字。
答え：社会性（昆虫）
今回：社会性 ○。

DC2 (2) 複数の物質が結びついた化合物 知識問題

ア（食塩）とイ（二酸化炭素）。食塩はナトリウムと塩素、二酸化炭素は炭素と酸素が結びついた化合物。酸素・水素は1種類の元素だけでできた単体で、銅のような金属も単体。「○○と○○が結びついた」と言えるものだけを選ぶ。余白の「O₂ H ?」のように、1つの記号で書けるものは単体と見分けられる。
答え：ア・イ
今回：ア・イ・オ ×。ア・イは合っているが、オ（銅）を足した。知識＝金属は1種類の元素だけでできた単体。迷った「?」のまま入れずに、「何と何が結びついたか」を言えないものは外す。

DC2 まとめ 1/4 正解

  • 落とした(1)①②は同じ原因。「真上の方向」を図2の北のまま使い、太陽の方角に直さなかった。8の字の問題は、まず図2に「太陽＝今の時刻の方角」を書きこみ、次にえさ場、最後に角度の差、の順で。
  • (2)は「銅も単体」の知識。金属はすべて単体、と1行で覚え直す。
  • 取れた③の社会性昆虫は、アリ・シロアリも仲間、までセットにしておく。
