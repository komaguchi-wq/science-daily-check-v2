N63-04 CP（コアプラス確認テスト 範囲495〜510・622 動物①（セキツイ動物）：呼吸と産卵の分類／フナの解剖と心臓／カエルの成長／ニワトリの卵／標識再捕法）

CP 全体像 コアプラス確認テスト 10問・100点

範囲は495〜510・622「動物①（セキツイ動物）」。(1)(2)は10種の動物を5つのなかま（魚類・両生類・ハ虫類・鳥類・ホ乳類）に分けてから選ぶ問題、(3)(4)はカワセミとカエルの卵の一問一答。

(5)(6)はフナの解剖と心臓の図、(7)はカエルの成長の並べかえ、(8)はニワトリの卵の図、(9)は鳥の心臓の部屋数、(10)は印をつけたネズミから全体の数を求める計算。図の問題は矢印と形のちがいを先に図へ書きこむと決まる。

CP (1) えら呼吸をする時期がある動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問の「えら呼吸をする時期がある」「すべて」に丸。部品は10種それぞれのなかまの名前 → ア〜コの横に魚・両・ハ・鳥・ホの1字で書く → 魚類と両生類だけが残る。

📚 前提知識

  • 一生えら呼吸なのは魚類。両生類は子（おたまじゃくし）のときえら呼吸で、おとなになると肺と皮ふで呼吸する。だから「時期がある」という聞き方になる。
  • ハ虫類・鳥類・ホ乳類は、水の中でくらすものも肺呼吸。シャチやラッコはホ乳類、ウミガメやワニはハ虫類、ペンギンは鳥類で、息つぎに水面へ出る。

🔍 こう読み解く

  1. なかま分け：ア イモリ＝両、イ ウミガメ＝ハ、ウ コウモリ＝ホ、エ サメ＝魚、オ ダチョウ＝鳥、カ シャチ＝ホ、キ サンショウウオ＝両、ク ペンギン＝鳥、ケ ラッコ＝ホ、コ ワニ＝ハ。
  2. 選ぶ：魚類のエ サメ、両生類のア イモリ・キ サンショウウオ。イモリとサンショウウオは「〜ウオ」「〜モリ」の名前でも両生類（ヤモリはハ虫類）。
  3. 選ばない：水にすむウミガメ・シャチ・ペンギン・ラッコ・ワニは全部肺呼吸。コウモリは空を飛ぶがホ乳類で肺呼吸。
答え：ア・エ・キ
自分で解くときのチェック：「水にすむ＝えら」と決めない。先に10種の横になかまの1字を書き、魚と両だけを拾う。

CP (2) 陸上に産卵する動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】(1)と変わった部品は「陸上に産卵」に丸。(1)で書いたなかまの1字をそのまま使う → 卵を産むのは魚・両・ハ・鳥、そのうち陸上に産むのはハ虫類と鳥類と決まる。

📚 前提知識

  • 魚類と両生類は水中に殻のない卵を産む。ハ虫類と鳥類は陸上に殻のある卵を産む（殻があるので乾かない）。ホ乳類は卵を産まず、子を産む（胎生）。
  • ウミガメは海でくらすが、産卵のときは砂浜に上がって卵を産む。ペンギンも陸上の巣で卵をあたためる。

🔍 こう読み解く

  1. (1)のなかま分けから、ハ虫類＝イ ウミガメ・コ ワニ、鳥類＝オ ダチョウ・ク ペンギン → この4つを選ぶ。
  2. 選ばない：魚類のサメと両生類のイモリ・サンショウウオは水中に産卵。ホ乳類のコウモリ・シャチ・ラッコは卵を産まない。
答え：イ・オ・ク・コ
自分で解くときのチェック：ウミガメを「海の生き物だから水中」と落としやすい。産卵の場所はなかまで決める（ハ虫類・鳥類＝陸上）。

CP (3) 青とオレンジ色の羽毛が目立つ水辺の鳥 知識問題

カワセミ。池や川のまわりにすみ、長くとがったくちばしで水中の魚をとらえる。図1のシルエットも「体のわりに大きな頭と長いくちばし」が目印。「青とオレンジ」「水辺」「魚をとる」の3つで結びつける。
答え：カワセミ

CP (4) 池の中にあった長いひも状の卵 知識問題

ヒキガエル。図2のように、ゼリー状の長いひもの中に黒い卵が並ぶのがヒキガエルの卵。アマガエルやトノサマガエルの卵はかたまりの形で産まれるので、「ひも状＝ヒキガエル」と形で見分ける。
答え：ヒキガエル

CP (5) 解剖ばさみの使い方とフナの心臓 資料問題・図から選ぶ

👀 まず見るところ

【資料問題】部品は図の2か所。解剖ばさみの先の形（とがった方・丸い方）と、フナの図でえらのすぐ後ろの黒い部分。はさみは「丸い方が中」、心臓は「えらのとなり」と図に書く → ①②とも決まる。

📚 前提知識

  • 解剖ばさみは、先が丸い方の刃を体内に差しこむ。とがった方を入れると、内臓を切ってしまう。
  • 魚の心臓は血液をえらへ送るので、えらのすぐ後ろ（下側）にある。おなかの中で大きく見える白いふくろはうきぶくろ、曲がりくねった管は腸。

🔍 こう読み解く

  1. ①：図のはさみは、アの刃が細くとがり、イの刃は先が丸い。体内に入れるのは丸いイ。
  2. ②：えらは頭のすぐ後ろ（A・Bのあたり）。その後ろの下側にある黒い小さな部分が心臓＝C。上の白いふくろDはうきぶくろ、下の曲がった管Fは腸なので、どちらも心臓ではない。
答え：① イ　② C
自分で解くときのチェック：心臓は「胸のまん中」ではなくえらのとなり。図にえらの位置を先に書いてから、そのすぐ後ろをさがす。

CP (6) えらの血管につながるのはX・Yのどちらか 資料問題・矢印の向き

👀 まず見るところ

【資料問題】部品は図の矢印。Xは心房へ入る向き、Yは心室から出る向き → 図の横に「X＝入口、Y＝出口」と書く。魚は心臓を出た血液がそのままえらへ行くので、出口Yがえらにつながる。

📚 前提知識

  • 心臓の中では、血液は心房で受けて、心室から送り出す。どの動物でも心房が入口、心室が出口。
  • 魚類は1心房1心室。血液の流れは心臓 → えら → 全身 → 心臓の一回り。えらで酸素を受け取った血液は、心臓にもどらずそのまま全身へ行く。

🔍 こう読み解く

  1. 図の矢印をたどる：X → 心房 → 心室 → Y。Xから入り、Yから出る。
  2. 心臓から出た血液が次に行く場所は、魚ではえら。だからえらの血管につながるのはY。
  3. Xは全身をめぐって酸素の少なくなった血液がもどってくる側。
答え：Y
自分で解くときのチェック：「えら＝酸素をもらう所だから入口」と考えると逆になる。矢印の出口がえら行き、と流れの順で決める。

CP (7) カエルが卵から成長する順番 資料問題・図の並べかえ

👀 まず見るところ

【資料問題】部品は5つの図の形のちがい。卵2つは「みぞの有無」、おたまじゃくし3つは「外えらの有無・あしの有無」と図の下に書く → みぞなし→みぞあり→外えらあり→外えらなし→あし、の順に決まる。

📚 前提知識

  • 卵は産まれた直後はまん丸。受精すると細胞分裂が始まり、表面にみぞが入って分かれていく（ニワトリの卵と同じく、分裂をくり返してからだになる）。
  • ふ化したばかりのおたまじゃくしは、頭の横に外えらがある。やがて外えらは体の中に入って見えなくなり（内えら）、そのあと後ろあし → 前あしの順に出て、尾が短くなって陸に上がる。

🔍 こう読み解く

  1. 卵2つ：イはなめらかなまん丸、アは表面にみぞ（分裂の線）がある → イ → ア。
  2. おたまじゃくし3つ：エは頭の横に外えらがある＝ふ化直後。オは外えらがなく、あしもない。ウはあしが出ている → エ → オ → ウ。
  3. つなげて イ・ア・エ・オ・ウ。
答え：イアエオウ（イ→ア→エ→オ→ウ）
自分で解くときのチェック：ア・イは「みぞがあるほうが後」、エ・オは「外えらがあるほうが先」。似た2枚はちがう所に丸をつけてから並べる。

CP (8) ニワトリの卵でヒヨコになる部分と、ふ化までの日数 資料問題・図＋知識

👀 まず見るところ

【資料問題】①の部品は設問の「細胞分裂をくり返してヒヨコのからだになる」に丸 → 黄身の上にある小さな点（はい）をさがす。②は選択肢「7・14・21」から、ニワトリの約21日（3週間）を選ぶ。

📚 前提知識

  • ヒヨコになるのは、黄身（卵黄）の表面にある小さなはい。黄身そのものはヒヨコになるのではなく、育つための養分。
  • 図の各部分：Eの大きな球が卵黄（養分）、Bの黄身のまわりが卵白（水分と養分、衝撃から守る）、Dのねじれたひもがカラザ（黄身をまん中に支える）、Aのすみの空所は気室（空気の部屋）。
  • ニワトリの卵は約38℃で約21日あたためるとふ化する。

🔍 こう読み解く

  1. ①：「からだになる部分」は黄身の上の小さな点 → C。E（卵黄）やB（卵白）は養分なので選ばない。
  2. ②：約21日。7日・14日では短い。
答え：① C　② 21日
自分で解くときのチェック：「ヒヨコになる＝大きい黄身」と答えやすい。設問の「細胞分裂をくり返して」に丸をつけ、小さな点のほうを選ぶ。

CP (9) 鳥類の心臓の心房と心室の数 知識問題

① 2　② 2。鳥類とホ乳類は2心房2心室で、酸素の多い血液と少ない血液が混ざらないので、体温を保つのに有利。魚類は1心房1心室、両生類は2心房1心室、ハ虫類は2心房1心室（心室に不完全なしきり）。「魚→両→ハ→鳥・ホ」の順に部屋が増える、と流れで覚える。
答え：① 2　② 2

CP (10) 印をつけたネズミから全体の数を推定する 条件文・計算

👀 まず見るところ

【条件文】部品は3つの数「12匹に印」「翌日15匹つかまえ」「そのうち印は3匹」。「全体の中の印の割合＝つかまえた15匹の中の印の割合」と式の形に直して書く → 全体：12＝15：3 で決まる。

📚 前提知識

  • 標識再捕法：印をつけて放したネズミは、空き地全体のネズミに均等に混ざると考える。だから「全体の中で印つきがしめる割合」と「2回目につかまえた中で印つきがしめる割合」が同じになる。

🔍 こう読み解く

  1. 2回目につかまえた15匹のうち、印つきは3匹 → 印つきの割合は 3÷15＝5分の1。
  2. 空き地全体でも、印つき12匹が全体の5分の1にあたる。
  3. 全体＝12÷(1/5)＝12×5＝60匹。式でまとめると 12×15÷3＝60。
答え：60匹
自分で解くときのチェック：3つの数を「全体：印＝つかまえた数：その中の印」の形に置いてから計算する。12＋15＝27 のような足し算の答えが出たら、割合の式に直せていない合図。

CP まとめ 未解答・自分で解くとき

  • (1)(2)は10種の横になかまの1字を書いてから選ぶ。えら呼吸の時期がある＝魚・両、陸上に産卵＝ハ・鳥。水にすむかどうかでは決めない。
  • 図の問題は矢印と形のちがいが部品。(6)は心室から出る側＝えら行き、(7)は「みぞ」「外えら」「あし」の有無、(8)は黄身の上の小さな点。
  • 覚え直しはこの3つ：心臓の部屋は魚1・1／両2・1／ハ2・1（不完全）／鳥・ホ2・2。ニワトリは38℃で約21日。標識再捕法は 全体：印＝つかまえた数：印つき。
