DC 1(1) コイルの中と外の方位磁針 図の読み取り・記号選択

👀 まず見るところ

Xはコイルの中、Yはコイルの外。磁力線はコイルの中を通りぬけ、外側を回って戻るので、中と外では向きが逆になる。答えは左右が反対のアとイの組に決まる。

📚 前提知識

  • 磁力線はN極から出てS極へ入る。コイルの内側では、S極の端からN極の端へ向かって通りぬける。
  • 方位磁針の黒い針（N極）は、そこを通る磁力線の向きにそろう。
  • どちらの端がN極になるかは、電流の向きとコイルの巻き方で決まる。図1では左端がN極。

🔍 こう読み解く

  1. 図1のコイルは左端がN極。コイルの内側の磁力線は、右（S極側）から左（N極側）へ向かう。
  2. X＝コイルの中なので、針のN極は左を向く → ア。
  3. Yはコイルの外。左のN極から出た磁力線が、外を回って右のS極へ戻る途中にある → 向きは右 → イ。
  4. ウ・エは針がコイルの軸と直角を向いた形。コイルの磁力がはたらいていれば、この向きにはならない。
答え：X ア　Y イ
今回：X ア ○　Y イ ○。図1のコイルの左に「N」と書きこんでから答えている。書きこんでから選ぶ手順ができていた。

DC 1(2) 電磁石の強さくらべ 回路図・順位を選ぶ

👀 まず見るところ

電磁石は同じものなので、差がつくのは流れる電流の大きさだけ。電磁石までの道に豆電球が何個分あるかを数える。少ないほど電流が大きく、磁力も強い。

📚 前提知識

  • 電磁石の強さは、巻き数が同じなら電流の大きさで決まる。
  • 豆電球は電流を通しにくくする。直列2個なら2個分で電流は半分、並列2個なら0.5個分で電流は2倍になる。
  • 電池と並列につながれた豆電球は、電磁石の道には入っていない。電磁石は電池に直接つながっているのと同じ形になる。

🔍 こう読み解く

  1. イを基準にする。豆電球1個分なので電流を1とする。
  2. ウは並列2個＝0.5個分 → 電流2。エは直列2個＝2個分 → 電流0.5。オは1個＋並列2個＝1.5個分 → 電流3分の2。
  3. アは豆電球が電池と並列で、電磁石には電池がそのままつながっている。道の上の豆電球は0個分なので、電流は5つの中でいちばん大きい。
  4. 強い順に ア＞ウ＞イ＞オ＞エ。2番目がウ、4番目がオ。
回路アウイオエ
道の上の豆電球0個分0.5個分1個分1.5個分2個分
電流（イを1として）いちばん大213分の20.5
答え：2番目 ウ　4番目 オ
今回：2番目 イ ×　4番目 エ ×。回路の横に「イ 1」「ウ 2」「エ 2分の1」「オ 3分の2」と正しく書けている。ずれたのはアに「0」と書いたところだけで、アを最下位にしたため順位が1つずつ後ろへ動いた。アは電流が0ではなく、豆電球が0個分＝電流が最大である。
コツ：電池と並列につながれた豆電球は横道。電磁石が電池に直接つながる形は、いつでもいちばん強い。

DC 1(3)① モーターの回る向き 図の読み取り・記号選択

👀 まず見るところ

コイルにできる極の位置。極ができるのは巻いた輪の面が向いている側で、図2では上の面と下の面である。左右の端に極を置くと、磁石と向かい合ってつり合い「動かない」に見えてしまう。

📚 前提知識

  • コイルに電流が流れると電磁石になる。N極・S極は、輪の面に対して垂直な向きにできる。
  • ちがう極どうしは引き合い、同じ極どうしは反発する。この力がコイルを回す。
  • 回る向きは「電流の向き」と「磁石の置き方」の2つで決まる。どちらか一方を逆にすると逆回り、両方逆にすると元と同じ向きになる。

🔍 こう読み解く

  1. 図2のコイルは輪の面が上下を向いている。だから極は上の面と下の面にできる。
  2. 図2の電流の向きでは、下の面がN極、上の面がS極になる。
  3. 下のN極は、左の磁石のS極に引かれる。コイルの下側が左へ動く回り方は時計回り。
  4. 半回転すると極の向きが逆になって止まりそうになるが、そこで整流子が電流の向きを変える（→②）。
答え：ア（時計回り）
今回：ウ ×。図2に「N」「S」と書きこんでいて、極を決めてから考える手順までは進んでいる。ただし極を左右に置いたため、磁石と向かい合ってつり合う形になり「これでは動かない」に行きついた。次は極は輪の面（上と下）と置きかえてから、どちらの磁石に引かれるかを見る。

DC 1(3)② 整流子の役割 知識問題

整流子は、半回転ごとにコイルに流れる電流の向きを切りかえる部品。向きを変えないと、半回転したところで力が逆向きになり、コイルは行ったり来たりして止まってしまう。電流の大きさや磁力の大きさを変える部品ではない。
答え：イ（電流の向きを変える）
今回：ア ×。「電流の大きさを変える」を選んでいる。大きさを変えるのは豆電球やニクロム線などの抵抗の役目で、整流子は向きの係と分けておく。

DC 1(4)①② ばねののびと磁力 グラフ＋計算

👀 まず見るところ

図4の直線を左へのばすと、巻き数0のところで5cm。巻き数0なら磁力も0なので、この5cmはおもりBの重さだけによるのび。のびを「Bの分」と「磁力の分」に分けるのがこの問題の入口。

📚 前提知識

  • ばねAは10gで20cmのびる。のび1cmあたり0.5gにあたる。
  • DがBから離れるのは、ばねが引く力が「Bの重さ＋電磁石がBを引きつける力」と等しくなったとき。だから のび＝Bの分＋磁力の分。
  • 電磁石の磁力は、電流が同じなら巻き数に比例する。グラフが直線になるのはこのため。

🔍 こう読み解く

  1. ①　巻き数0ののび＝5cm。これがBの重さの分。
  2. 10g で 20cm のびる → 5cm のびる重さは 10×5÷20＝2.5g。
  3. ②　200回ののびは10cm。磁力の分は 10−5＝5cm。
  4. 600回ののびは20cm。磁力の分は 20−5＝15cm。
  5. 15÷5＝3倍。（のびの20÷10＝2倍としないこと。おもりの分5cmが両方に入っている）
答え：① 2.5g　② 3倍
今回：① 2.5 ○　② 3 ○。図4の下に「10g」「5g」とメモがあり、5cm分＝2.5gを自分で出している。おもりの分を先に差し引く手順が身についている。
コツ：グラフが原点を通らないときは、通らない分が何を表すかを先に決める。ここでは巻き数0ののび＝おもりの重さ。

DC 2(1)① 「AA」×「BB」からできる種子 遺伝・記号選択

👀 まず見るところ

親のカードが「AA」と「BB」。AAから渡せるのはAだけ、BBから渡せるのはBだけで、選べる余地がない。だから子のカードは全部「AB」に決まる。

📚 前提知識

  • 子は、花粉を出した側から1枚、受粉した側から1枚、合わせて2枚を受けとる。
  • 「AA」「AB」は丸形、「BB」はしわ形。Aが1枚でもあれば丸形になる。

🔍 こう読み解く

  1. 花粉側（AA）から出るカードはA。受粉させた側（BB）から出るカードはB。
  2. 組み合わせはABの1通りだけ。ばらつきようがない。
  3. ABは丸形。できる種子は丸形だけ → ア。
答え：ア（丸形だけ）
今回：ウ ×。余白に「AA」「AB」「A B」と書き出していて、道具は使えている。ただし①で「両方できる」と答えると、次の②（自家受粉で丸形としわ形の両方ができる）と同じ話になってしまう。①は親がAAとBBで、渡せるカードが1種類ずつしかないところが決め手になる。

DC 2(1)② 自家受粉でできる種子の割合 遺伝・整数比

👀 まず見るところ

①でできた種子は全部「AB」。そのAB自身を自家受粉させるので、両親ともAB。片方からA・B、もう片方からA・Bで、組み合わせは4通り。4通りを全部書き出してから数える。

📚 前提知識

  • 自家受粉＝同じ株の花粉が、同じ株のめしべにつくこと。親は両方ともABになる。
  • できるのは AA・AB・BA・BB の4通り。BAはABと同じ組み合わせ。
  • 丸形になるのは AA・AB・BA の3通り、しわ形は BB の1通りだけ。

🔍 こう読み解く

  1. 父方のカードをA・B、母方のカードをA・Bとして、4通りを書き出す → AA／AB／BA／BB。
  2. 丸形（AA・AB・BA）が3、しわ形（BB）が1。
  3. 最も簡単な整数比にして 3：1。
答え：丸：しわ＝3：1
今回：空らん ×。ただし問題文の横に「3：1」と書いてある（その下に書き直した跡もある）。考えは正しいところまで届いていたので、失点の原因は解答らんに写していないことだけ。出した答えは、その場で解答らんへ移す。

DC 2(2) エナメル線が銅線とちがう点 記述・5点

👀 まず見るところ

設問文が答えの半分を言っている。「導線同士がふれていても電気が直接流れてしまわないようにするため」。聞かれているのは、その役目をしているものが表面にある、という一点。文末は「〜点。」でそろえる。

📚 前提知識

  • エナメル線＝銅線の表面に、電気を通さないエナメルをぬった線。
  • コイルは導線を何重にも重ねて巻く。むき出しの銅線だと、となりの線とふれたところで電流が近道し、巻いた数だけの磁力が出ない。
  • 両端はエナメルをはがしてから回路につなぐ。はがさないと電流が流れない。

✍️ 答案の組み立て

  1. 要素A：銅線のまわりに、電気を通さないものがぬってある（コーティングされている）。
  2. 要素B：文末を「〜点。」にして、「ちがう点」の答えの形にそろえる。
模範解答：銅線のまわりに電気を通さない物をコーティングしているという点。
今回：5点中5点 ○。答案は「銅線に電気を流さない物質をまいている点。」。「電気を通さないものが表面にある」という要素が入り、文末も「〜点。」でそろっている。採点でも「物質」に赤で印が付いている。言葉づかいが模範解答とちがっても、要素が入っていれば点になる例である。
