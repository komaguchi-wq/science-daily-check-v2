(1) 状態変化・(2) 心臓・(3) 顕微鏡・(4) 百葉箱・(5) 月・(6) 根毛・(7) 蒸散・(8) 津波と高潮、作図は (9) 北極星のさがし方・(10) 食塩の結晶。分野はばらばらだが、聞かれ方は「理由」「利点」「条件を2つ」「違い」の4種類だけで、聞かれ方を見た時点で文の形（〜ため。／〜できる点。／・〜とき。を2行／AはB、CはD）が決まる。

今回は手をつけた (2)(5) がどちらも○で、残る8問は白紙。書いた2問は要素がそろっているので、課題は知識より白紙を1行で埋めることにある。どの問いも、設問の言葉を借りて主語を置けば半分は書ける。

記述③ (1) 氷を加熱しても0℃のまま変化しない理由 理由の記述・状態変化

👀 まず見るところ

【素材文】設問は「0℃のままでしばらく…理由」。部品は「加熱していく」「0℃のまま」に丸 → 熱は入っているのに温度が上がらない、だから熱は別の仕事に使われている、と直して書く。文末は「〜ため。」

📚 前提知識

  • 氷がとけて水になる（固体→液体）あいだは、加えた熱が状態を変えることに使われ、温度を上げることには回らない。
  • 全部とけ終わると、熱がふたたび温度を上げる仕事に回り、水の温度が上がり始める。グラフの水平な部分がこの時間。

✍️ 答案の組み立て

  1. 要素A：加えた熱が何に使われるか → 氷が水になるため（とけるため）。
  2. 要素B：その熱が温度上昇に使われない、という向き → 「〜だけに熱が使われるため。」で結ぶ。
模範解答：氷が水になるためだけに熱が使われるため。
今回：無答（白紙）。「熱は入っているのにどこへ行ったか」と問い直せば、「氷をとかすのに使われるため。」の1行で書けた。次は設問の「加熱」と「0℃のまま」を並べて、矛盾の説明として書く。
コツ：「0℃のまま」の理由を「氷が冷たいから」と書くと、熱の行き先が無い答えになる。熱の行き先＝「とけること」を主語にする。

記述③ (2) 左心室の壁が最も厚いことの利点 利点の記述・ヒトのからだ

👀 まず見るところ

【素材文】設問は「左心室…厚い…利点」。部品は「左心室」に丸 → 血液の行き先を「全身へ」と書き出す。「利点」なので文末は「〜できる点。」。厚い壁＝強い力、行き先＝全身、の2語で決まる。

📚 前提知識

  • 心臓の4つの部屋のうち、左心室は大動脈を通して全身へ血液を送り出す。右心室はすぐ近くの肺へ送るだけなので、壁はうすくてよい。
  • 筋肉の壁が厚いほど強く縮み、血液を遠くまで強く押し出せる。「厚さ＝送り出す力」と置きかえる。

✍️ 答案の組み立て

  1. 要素A：どこへ → 全身に。
  2. 要素B：どう送るか → 勢いよく（強い力で）血液を送り出すことができる点。
模範解答：全身に勢いよく血液を送り出すことができる点。
今回：○（答案「体全体に勢いよく血液をおくり出せる。」）。「体全体＝全身」「勢いよく」の2要素がそろっている。「〜点。」で終えていないが、利点の内容が書けているので正解。

記述③ (3) 顕微鏡で低倍率のレンズから使う理由 理由の記述・顕微鏡

👀 まず見るところ

【素材文】設問は「低倍率のレンズから使用する理由」。部品は「から」に丸 → 「最初に」する理由、つまり「見つける」段階の話だと決める。低倍率の性質（視野が広い）→ だから何がしやすいか、の2段で書く。

📚 前提知識

  • 倍率を上げると視野はせまく、暗くなる。低倍率なら広い範囲が一度に見えるので、観察したいものを見つけやすい。
  • 手順は「低倍率で見つける → 見たいものを視野の中央に動かす → 高倍率にかえる」。中央に寄せてから高倍率にするのは、視野がせまくなっても外れないため。

✍️ 答案の組み立て

  1. 要素A（性質）：低倍率は視野が広い。
  2. 要素B（だから）：観察するものを見つけやすい → 「〜から。」で結ぶ。
模範解答：視野が広いため、観察するものを見つけやすいから。
今回：無答（白紙）。「視野」の一語が出れば1行で終わる問題だった。次は「低倍率＝広く見える」と余白に書き、「広いと何がしやすいか」を続ける。
コツ：「明るいから」だけでは、見つけやすさの理由として弱い。「視野が広い」を先に書く。

記述③ (4) 百葉箱が木材だと温度上昇を防げる理由 理由の記述・気象観測

👀 まず見るところ

【素材文】設問は「木材でつくられている…温度上昇を防ぐ…理由」。部品は「木材」に丸 → 百葉箱の工夫は5つあるが、聞かれているのは木の性質1つだけ。「木＝熱を伝えにくい」に直して書く。文末は「〜ため。」

📚 前提知識

  • 熱の伝わり方は伝導・対流・放射の3つ。木は金属にくらべて伝導で熱を伝えにくいので、外の熱が箱の内側へ届きにくい。
  • 百葉箱のほかの工夫は別の理由と対にする。白くぬる＝日光（放射）を反射する／よろい戸＝風を通して対流で熱をにがす／芝生の上＝地面からの照り返しを防ぐ／とびらは北向き＝開けたとき日光が入らない。

✍️ 答案の組み立て

  1. 要素A：木の性質 → 伝導による熱を伝えにくい。
  2. 要素B：だから外の熱が中に伝わりにくい → 「〜するため。」で結ぶ。
模範解答：伝導による熱を伝わりにくくするため。
今回：無答（白紙）。「木材」と指定された時点で、答えは木の性質だけでよかった。次は「金属とくらべて木はどうか」と置きかえて1行書く。
コツ：「白いから日光を反射する」は色の理由で、材料の理由ではない。設問が材料・色・戸のどれを聞いているか、部品の語で見分ける。

記述③ (5) 月がいつも同じ面を向けて回る理由 理由の記述・月

👀 まず見るところ

【素材文】設問は「いつも同じ面を向けて…回っている理由」。部品は「同じ面」「回っている」に丸 → 回り方が2つ（自転と公転）あることに気づけば、答えの形は「〜が等しいから。」の1文。何と何が等しいかを言えれば決まる。

📚 前提知識

  • 月は自分も1回転（自転）しながら地球のまわりを1周（公転）する。自転の向きと公転の向きが同じで、1回転にかかる時間と1周にかかる時間が等しいため、地球にはいつも同じ面が向く。
  • もし月が自転していなければ、公転のあいだに地球からは月のすべての面が見える。「同じ面」は自転していない証拠ではなく、ぴったり合わせて自転している証拠。

✍️ 答案の組み立て

  1. 要素A：自転と公転の向きが同じ。
  2. 要素B：自転と公転の周期が等しい → 「〜ため。」で結ぶ。
模範解答：月の自転と公転の向きと周期（角速度、公転にかかる時間）が等しいため。
今回：○（答案「月と自転と公転の向きと周期が等しいから。」）。向きと周期の2要素がそろっている。書き出しは「月の自転と公転」が正しい形なので、次は助詞だけ確かめる。

記述③ (6) 根に根毛があることの利点 利点の記述・植物のつくり

👀 まず見るところ

【素材文】設問は「根毛があることの利点」。部品は「根毛」に丸 → 根の仕事「水と肥料の吸収」を書き出す。細い毛がたくさん＝「表面積が広くなる」に直して書けば、「だから吸収しやすい」まで一直線。文末は「〜できる点。」

📚 前提知識

  • 根毛は根の先に近い部分の表面にある細い毛。細いものがたくさん生えることで、土にふれる表面積が大きくなる。
  • 吸収は表面で起こるので、表面積が大きいほど多くの水や、水にとけた肥料を取りこめる。小腸の柔毛・肺の肺胞と同じ理屈。

✍️ 答案の組み立て

  1. 要素A：つくりの特徴 → 表面積が広くなる。
  2. 要素B：だからできること → 水や水にとけた肥料を効率良く吸収できる点。
模範解答：表面積が広くなり、効率良く水や水にとけた肥料を吸収できる点。
今回：無答（白紙）。「表面積」の一語が思い出せれば、柔毛・肺胞と同じ文で書けた。次は「細い・たくさん」と見たら「表面積が広い」と置きかえる。
コツ：「水を吸う」だけで終えず、「水にとけた肥料」まで入れる。根が吸うのは水と肥料の2つ。

記述③ (7) 蒸散が活発になる条件を2つ 条件の記述・2つ答える

👀 まず見るところ

【素材文】設問は「蒸散作用が活発になるときの条件を2つ」。部品は「2つ」に丸 → 答えの形は「・〜とき。」を2行。中身は「せんたく物がかわきやすい条件」に直して書けば、気温・湿度・風がすぐ出る。

📚 前提知識

  • 蒸散＝葉の気孔から水が水蒸気になって出ていくこと。水が蒸発しやすい条件（気温が高い・湿度が低い・風がある）で活発になる。
  • 気孔は日光が当たると開く。だから「日光がよく当たるとき」も条件になる。体内の水分が多いときは、出す水が十分にあるので活発。

✍️ 答案の組み立て

  1. 要素A：1つ目 → 「・気温が高いとき。」のように、1行1条件で書く。
  2. 要素B：2つ目 → 別の種類の条件を選ぶ（気温と日光、湿度と風、のように性質のちがう2つ）。
模範解答：・気温が高いとき。／・日光がよく当たるとき。／・湿度が低いとき。／・風が吹いているとき。／・体内の水分が多いとき。 などから2つ。
今回：無答（白紙）。候補が5つもある問題なので、「かわきやすい日」を思いうかべれば2行は書けた。次は「2つ」に丸をつけ、先に「・」を2つ解答らんに置いてから中身を考える。

記述③ (8) 津波と高潮の違い 違いの記述・気象と地震

👀 まず見るところ

【素材文】設問は「津波と高潮の違い」。部品は「違い」に丸 → 答えの形は「津波は〜。高潮は〜。」の2文を対にする。くらべる軸は「何が原因で海水が動くか」。原因が地震か低気圧か、で決まる。

📚 前提知識

  • 津波＝地震で海底が動くと、その上の大量の海水が持ち上がったり沈んだりして、波となって岸へおし寄せる。海の深いところから全部の水が動くので、ふつうの波とは規模がちがう。
  • 高潮＝台風などの低気圧が来ると、気圧が低いぶん海面が吸い上げられ、強い風が海水を岸へ吹き寄せて海面が高くなる。満潮と重なるとさらに高くなる。

✍️ 答案の組み立て

  1. 要素A（津波）：原因＝地震・海底が動く → 大量の海水が動いて発生する。
  2. 要素B（高潮）：原因＝台風などの低気圧 → 海面が上昇する。
  3. 2文とも「原因 → 海水がどうなるか」の順にそろえると、違いが読み手に伝わる。
模範解答：津波は地震によって海底が動くことで大量の海水が動いて発生する。高潮は台風などの低気圧により、海面が上昇すること。
今回：無答（白紙）。「津波は地震、高潮は台風。」の1行でも原因の対比は書けていた。次は「違い」と見たら先に主語を2つ書き、原因を1語ずつ入れる。
コツ：高潮を「大きな波」と書くと津波と区別がつかない。高潮は海面そのものが高くなること、と書き分ける。

記述③ (9) 北斗七星から北極星をさがす作図 作図

👀 まず見るところ

【資料問題】図の正体は「北斗七星（ひしゃくの形・7つの星）」。部品は「北斗七星を利用して」「☆で示し」に丸 → 使うのはひしゃくの先の2つの星だけ。2星の間を1とし、5倍のばした先に☆を置く。

📚 前提知識

  • 北極星は2等星で目立たないので、北斗七星かカシオペヤ座から見つける。北斗七星のひしゃくの水をくむ側の先の2つの星を結び、その長さを5倍のばした先が北極星。
  • のばす向きは、ひしゃくの口が開いている側（柄と反対側）。逆へのばすと見つからない。カシオペヤ座からも同じ要領で5倍。

✍️ 答案の組み立て

  1. ひしゃくの先（柄から遠い側）の2つの星を線で結ぶ。これが①の長さ。
  2. その線を、ひしゃくの口が開く向きへまっすぐのばす。
  3. ①の長さを目盛りのように5つ分とり、5倍の位置に☆を書いて「北極星」と記す。
模範解答：別紙の図のとおり。要点＝ひしゃくの先の2つの星を結んだ長さ（①）を、口の開く向きに5倍（⑤）のばした先に☆（北極星）。目盛りを5つ打って長さを示す。
今回：無答（白紙）。星をつなぐ線は印刷されているので、「どの2つを使うか」と「5倍」の2点だけで完成した。次は先に「5倍」と余白に書いてから定規を当てる。
コツ：☆の位置だけでなく、使った2星を結ぶ線と目盛りの線も残す。作図は「どう求めたか」が見える線が得点になる。

記述③ (10) 食塩の結晶の形 作図

👀 まず見るところ

【素材文】設問は「食塩の結晶を大きくかきなさい」。部品は「食塩」と「大きく」に丸 → 形は立方体（さいころ形）、大きさは解答らんいっぱい。何の結晶かで形が決まるので、先に「食塩＝立方体」の3語を書く。

📚 前提知識

  • 結晶の形は物質ごとに決まっている。食塩＝立方体、ミョウバン＝正八面体、ホウ酸＝六角形の板、硫酸銅＝ななめにゆがんだ板。
  • 食塩の結晶の面には、正方形が入れ子になった階段のようなくぼみの模様が見えることがある（別紙の図にもある）。模様が無くても立方体が書けていれば形は正しい。

✍️ 答案の組み立て

  1. 正面に正方形をかき、奥行きをつけて立方体の見取り図にする。6面すべて正方形のさいころ形。
  2. 解答らんの半分以上を使う大きさで、辺はまっすぐに。
  3. 余裕があれば、面の中に正方形を入れ子にした模様を入れる。
模範解答：別紙の図のとおり。要点＝立方体（さいころ形）の見取り図。各面に正方形が入れ子になった階段状の模様。
今回：無答（白紙）。「食塩＝立方体」と覚えていれば、さいころを1つかくだけだった。次は結晶の形を物質名とセットで思い出し、見取り図でかく。
コツ：ミョウバンの正八面体（ピラミッドを2つ底で合わせた形）と取りちがえやすい。「食塩はさいころ、ミョウバンはダイヤ」と対で覚える。
