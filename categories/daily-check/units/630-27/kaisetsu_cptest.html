L (1) 並列につないだA・Bの電流と発熱量 資料問題・大小関係①②

👀 まず見るところ

【資料問題】部品は図1の正体「並列」と本文の「長さが異なる」（図ではAが短い）。並列＝「AにもBにも電池と同じ電圧」と図の横に書く → 短くて電流が通りやすいAのほうが、電流も発熱量も大きいと決まる。

📚 前提知識

  • 材質と太さが同じなら、電熱線は長いほど電流を通しにくい（抵抗が大きい）。短いAは通しやすい。
  • 並列つなぎは、それぞれの電熱線に電池の電圧がそのままかかる。同じ電圧なら、通しやすい線ほど大きい電流が流れる。
  • 発熱量は電流×電圧で決まる。同じ電圧なら、電流が大きいほうがよく発熱する。

🔍 こう読み解く

  1. 図1は並列。AとBには同じ電圧がかかる。
  2. Aは短い＝通しやすい → 電流は A＞B → ①ア。
  3. 同じ電圧で電流はAが大きい → 発熱量も A＞B → ②ア。
答え：① ア　② ア
自分で解くときのチェック：図のA・Bの箱の長さを見比べて、短いほうに「通しやすい」と書いてから選ぶ。

L (2) 直列につないだA・Bの電流と発熱量 資料問題・大小関係①②

👀 まず見るところ

【資料問題】部品は図2の正体「直列」。直列＝「1本道なので電流はどこも同じ」と図の横に書く → ①は A＝B。発熱量は同じ電流なら通しにくい長いBのほうが大きいと決まる。

📚 前提知識

  • 直列つなぎは電流の道が1本なので、AにもBにも同じ大きさの電流が流れる。
  • 同じ電流なら、通しにくい（長い）線ほど電圧を多く受け持ち、発熱量は大きい。電熱線の発熱は「電流×電流×通しにくさ」と考えるとよい。

🔍 こう読み解く

  1. 直列 → 電流は A＝B → ①ウ。
  2. 電流は同じ、Bのほうが長くて通しにくい → 発熱量は A＜B → ②イ。
  3. (1)と(2)で発熱の大小が逆になる。並列は「短いほうが熱い」、直列は「長いほうが熱い」をセットで押さえる。
答え：① ウ　② イ
自分で解くときのチェック：「電流が同じだから発熱も同じ」としない。同じ電流でも、通しにくい線のほうが熱くなる。

L (3) 4本の中で発熱量が最も小さいもの 資料問題・4つを比べる

👀 まず見るところ

【資料問題】部品は聞かれ方「最も発熱量が小さい」と、図1・図2の電流の大きさ。直列（図2）の電流は、並列（図1）のどの枝の電流よりも小さい、と書く → 図2のうち短いAが最小と決まる。

📚 前提知識

  • 直列は2本分の長さを電流が通るので、全体として通しにくく、電流は図1のA・Bのどちらより小さい。
  • 発熱量は、電流が小さいほど小さく、同じ電流なら通しやすい（短い）線のほうが小さい。

🔍 こう読み解く

  1. 図1の中では、(1)より発熱の小さいほうはB。図2の中では、(2)より小さいほうはA。候補は「図1のB」と「図2のA」。

今回：固体 ×。部品の形を直さなかった＝「100気圧」と「0℃」を1つの交点にせず、グラフ左上の「固体」の文字と「0℃＝氷」の知識で答えた。グラフには0℃のたて線と左からの横線が引けているが、横線は固体と液体の境で止まり、0℃のたて線まで届いていない。次は横線を0℃のたて線と交わる点までのばし、その点が境の左右どちらかを見る。

H (3)② 図の範囲内で正しい文をすべて選ぶ 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「図の範囲内」「すべて選びなさい」に線。ア・イは2本の境の線のかたむき、ウ・エは0℃・100℃のたて線が通る領域で、4つ全部に○×をつける。

📚 前提知識

  • 液体と気体の境（右の曲線）は右上がり＝気圧が低いほど沸点が低い（本文の富士山で沸点が1気圧と異なる話）。

🔍 こう読み解く

  1. ア「気圧が低い方が沸騰しやすい」→ 右の境を下へたどると温度が下がる → 低い気圧ほど低い温度で沸騰 → ○。
  2. イ「気圧が低い方が液体の水が凍りやすい」→ 左の境を下へたどると温度が右（高い方）へ → 低い気圧ほど高い温度で凍る＝凍りやすい → ○。

  4. エ「100℃のとき固体にできない」→ 100℃のたて線は上から下まで液体と気体しか通らない → ○。

今回：ア イ エ ○。グラフに0℃と100℃のたて線が引いてあり、ウ・エはたて線で判断できている。

H (4)① ちりやほこりが含まれている水は過冷却が起きやすいか 素材文・○×

  • ちりやほこりは核になるので、0℃になるとすぐ結晶ができ始め、温度は0℃にとどまる（解答冊子「0℃より低い温度に下がりにくくなります」）。

  2. 設問は反対の「ちりが含まれている＝核がある」。だから結果も反対で、すぐ凍って過冷却は起きにくい。
  3. 「起きやすい」は誤り → ×。
