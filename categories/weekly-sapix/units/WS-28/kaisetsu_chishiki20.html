WS-28 知識の20題（電磁石・さおばかり・輪軸・ふりこ・燃焼・花・メダカ・天体・化石 20問）

K20 全体像 知識の20題 20問（各5点・100点）

電磁石（1・2）、さおばかり（3・4）、輪軸と動滑車（5・6）、ふりこ（7）、炭素の燃焼（8・9）、触媒（10）、花のつくり（11・12）、メダカ（13・14）、じん臓（15）、透明半球（16・17）、満月の高さ（18・19）、示準化石（20）の寄せ集め。計算は 3・4・5・6・8・9 の6問で、使う式はどれも1行（てこ＝重さ×うでの長さ／輪軸＝重さ×半径／燃焼＝3：8：11）。残り14問は図を1か所見るか、知っていれば決まる。

解く前に、設問の「すべて選びなさい」「3つ」「2つ」「どちら（右・左）に何cm」に丸をつけておく。1・10・12・13・14・20 は複数答える問題で、1つで止めると落とす。

K20 (1) 釘の左側がN極になる電磁石 条件文・図・すべて選ぶ

👀 まず見るところ

【条件文】部品は「左側がN極」と「すべて」に丸。ア〜エの図で変わるのは巻き方（ア・イとウ・エ）と電池の向き（ア・ウとイ・エ）の2つだけなので、各図の横に「巻き＝アと同じ／逆」「電池＝アと同じ／逆」と書く（図に置く）→ 2つとも逆なら極はアと同じ、1つだけ逆なら反対。

📚 前提知識

  • 電磁石の極は、右手の4本の指を電流の向きにそって巻きつけたとき、親指の向きがN極。電池の記号は長い線が＋極。
  • 巻き方を逆にしても、電池の向きを逆にしても、極は反対になる。両方逆にすると元にもどる。

🔍 こう読み解く

  1. アを右手で調べる → 左がN極（解答冊子の図：ア 左N・右S）。
  2. イは巻き方がアと同じで電池だけ逆 → 左はS。ウは電池がアと同じで巻き方だけ逆 → 左はS。
  3. エは巻き方も電池も逆 → 2回ひっくり返ってアと同じ＝左がN。答えはア・エ。
答え：ア・エ
コツ：4つ全部に右手を当てなくてよい。1つ決めたら、残りは「アと何が逆か」を数えるだけ。偶数個なら同じ、奇数個なら反対。

K20 (2) 鉄釘を焼きなましてから鉄心にする理由 知識問題

エ（磁力が残らないようにするため）。鉄釘をそのまま鉄心にすると、電流を止めたあとも磁力が残ってしまう（解答冊子）。電磁石は「電流が流れているときだけ磁石」でないと使えないので、鉄心には磁力が残らない軟鉄や焼きなました鉄を使う。「強い磁力のため（イ）」ではない、と区別する。
答え：エ

K20 (3) さおばかり・50gのせたら分銅はどこ 条件文・計算

👀 まず見るところ

【条件文】部品は「皿に50gの物体をのせた」（変わったのはこれだけ）と、答え方「さげひもからどちら（右・左）に何cm」に丸。図1の皿の下に「+50g」、さげひもから皿まで「10cm」、分銅の今の位置「左4cm」を書きこむ（図に置く）→ 増えた左回りの力だけで式が立つ。

📚 前提知識

  • てこのつり合い＝重さ×支点からの距離 が左右で等しい。もともとつり合っている図なら、棒の重さは考えず増えた分だけを考えればよい（解答冊子）。

🔍 こう読み解く

  1. 左に増えた回転力：50g×10cm＝500。
  2. これを100gの分銅を右へ動かして打ち消す：500÷100g＝5cm 右へ。
  3. 分銅はもともと「さげひもの左4cm」にあるので、5cm右へ動かすと さげひもの右1cm。
答え：右に1cm
コツ：「何cm動かす」でなく「さげひもからどちらに何cm」と聞いている。5cmで止めず、答えを書く直前に丸を見直す。

K20 (4) さおばかりは何gまではかれるか 条件文・計算

👀 まず見るところ

【条件文】部品は「何gまで」＝分銅を棒の右はしまで動かしたとき、に直して書く。図1の右はしに「分銅ここ・さげひもから30cm」と書きこむ（図に置く）→ 分銅が動いた長さ 4＋30＝34cm で(3)と同じ式。

📚 前提知識

  • さおばかりではかれる最大の重さは、分銅をいちばん遠くに動かしたときに皿にのせられる重さ（解答冊子）。

🔍 こう読み解く

  1. 分銅が動く長さ：左4cmから右30cmまで＝34cm。
  2. 右に増える回転力：100g×34cm＝3400。
  3. 皿にのせられる重さ：3400÷10cm＝340g。
答え：340g
コツ：30cmだけで計算すると300gになる。分銅は「左4cm」から出発しているので、動く長さは4＋30。

K20 (5) 輪軸と動滑車・Bは何g 条件文・計算

👀 まず見るところ

【条件文】部品は「滑車は60g」「半径6cmと4cm」「A 480g」に丸。図2で、Aをつるす動滑車の2本のひもに「270g」、小さい輪（4cm）にかかるひもにも「270g」、Bは大きい輪（6cm）と書きこむ（図に置く）→ 輪軸の式が1行で立つ。

📚 前提知識

  • 動滑車は、おもりと滑車の重さの合計を2本のひもで半分ずつ支える。滑車に重さがあるときは忘れずに足す。
  • 輪軸のつり合い＝重さ×半径 が左右で等しい（てこと同じ）。

🔍 こう読み解く

  1. 動滑車が支える重さ：480＋60＝540g → ひも1本は 540÷2＝270g。
  2. そのひもは半径4cmの輪に、Bは半径6cmの輪にかかる：270g×4cm＝B×6cm。
  3. B＝1080÷6＝180g。
答え：180g
コツ：480÷2＝240 から始めると滑車の60gが落ちる。「滑車は60g」の丸を見た時点で、Aの下に「+60」と書く。

K20 (6) Bを15cm引き下げるとAは何cm上がる 条件文・計算

👀 まず見るところ

【条件文】部品は「Bを15cm引き下げ」と「Aは何cm上がる」に丸。図2に矢印で「B 15cm↓ → 小さい輪のひも ?cm↑ → A ?cm↑」と順に書く（図に置く）→ 輪軸で半径の比、動滑車で半分、の2段階。

📚 前提知識

  • 輪軸がひもを巻き取る長さは半径に比例する（大きい輪で15cmなら小さい輪は 15×4/6）。
  • 動滑車は、ひもを引いた長さの半分しか上がらない（力が半分になる代わり）。

🔍 こう読み解く

  1. 大きい輪（6cm）が15cm回ると、小さい輪（4cm）は 15×4÷6＝10cm 巻き取る。
  2. 動滑車のひもが10cm短くなるので、Aは 10÷2＝5cm 上がる。
答え：5cm
コツ：(5)は「力は半径の大きい方が小さい」、(6)は「動く長さは半径の大きい方が長い」。力と長さは逆向きの関係、と1組で置く。

K20 (7) 木片の動く距離が大きい順 条件文・図・並べかえ

👀 まず見るところ

【条件文】部品はア〜エの図の糸の長さ・角度・おもりの重さと、答え方の例「＞と＝」に丸。各図の横に「おもりの高さ×重さ」に直して書く → 木片の動く距離はこの積の大きい順。糸の長さは高さを出すためだけに使う。

📚 前提知識

  • 木片の動く距離は、ぶつかるときのおもりの速さと重さで決まる。速さは放した高さだけで決まり、糸の長さや角度そのものでは決まらない。
  • 60度のときは糸と垂直線が正三角形を作るので、おもりの高さは糸の長さの半分。30度のときは、おもりの高さは糸の長さの7分の1ほどで、60度の半分よりずっと低い（同じ角度なら、糸が長いほど高さも大きい）。

🔍 こう読み解く

  1. アとイ：長さも角度も同じ → 高さが同じ → 重いア（30g）＞イ（20g）。
  2. アとウ：長さが同じで角度は ウ60度 → ウの高さは 30÷2＝15cm、アは約4cm → ウ＞ア。
  3. エ：45cm・30度 → 高さは約6cm。アより高く（同じ角度で糸が長い）、ウの15cmより低い → ウ＞エ＞ア。重さは3つとも30g。
  4. まとめて ウ＞エ＞ア＞イ。等しいものはない。
答え：ウ＞エ＞ア＞イ
コツ：「角度が大きい」「糸が長い」はどちらも「高い」の合図。ただし 60度の半分 と 30度の7分の1 では差が大きいので、角度のちがいを先に見る。

K20 (8) 炭素12gが燃えてできる二酸化炭素 条件文・計算

👀 まず見るところ

【条件文】部品は「炭素3g＋酸素8g→二酸化炭素」と「12gが燃えて」に丸。15gと燃え残り3gは使わない。余白に表「炭素 3 ／酸素 8 ／二酸化炭素 11」を書き（直して書く）→ 12÷3＝4倍するだけ。

📚 前提知識

  • 燃える前の重さの合計＝燃えたあとの重さ。炭素3g＋酸素8g＝二酸化炭素11g（解答冊子の表）。
  • 燃え残った炭素は反応していないので、酸素も二酸化炭素も増やさない。

🔍 こう読み解く

  1. 燃えた炭素は12g＝3gの4倍。
  2. 二酸化炭素も4倍：11×4＝44g（酸素は8×4＝32g 使った）。
答え：44g
コツ：「15g入れた」を式に入れると 55g になる。問題文の中の「燃えた」の数字だけが部品。

K20 (9) 二酸化炭素1Lは酸素1Lの何倍の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「使われる酸素の体積と発生する二酸化炭素の体積は同じ」と「(8)のことも含めて」に丸。「同じ体積なら、重さの比がそのまま1Lどうしの比」に直して書く → (8)の表の 酸素32g：二酸化炭素44g を割るだけ。

📚 前提知識

  • 使われた酸素と、できた二酸化炭素は体積が同じ。だから「酸素8g→二酸化炭素11g」がそのまま同じ体積どうしの重さの比＝8：11になる（解答冊子）。1Lどうしで比べても比は変わらない。

🔍 こう読み解く

  1. (8)の表：酸素32g が二酸化炭素44g になり、体積は同じ。
  2. 44÷32＝11÷8＝1.375倍。
答え：1.375倍
コツ：11÷8 の割り算は 1.375 で割り切れる。小数で止まらないなら、どこかで数字を取りちがえている。

K20 (10) 過酸化水素水の触媒になるもの3つ 知識問題

ア・エ・カ（生のジャガイモ・生のレバー・刻んだピーマン）。触媒は二酸化マンガンのほか、生のレバーや生野菜・血液に含まれるカタラーゼ（解答冊子）。「生の」が目じるしで、加熱するとカタラーゼははたらかなくなる。魚の骨・石灰石・チョーク（炭酸カルシウム）は塩酸と反応するもの、アルミニウムは塩酸や水酸化ナトリウム水溶液と反応するもので、どれも触媒ではない。「3つ」なので3つ書く。
答え：ア・エ・カ（順不同）

K20 (11) 図3の⑦の名前 資料問題・図の名前

👀 まず見るところ

【資料問題】部品は図3の正体「一般的な花のつくりの断面図」を1行、そして⑦の線の先＝⑧（ふくらんだ部分）の中にある小さな粒に丸 → ふくらみが子房、その中の粒が胚珠と決まる。

📚 前提知識

  • 被子植物の花は、胚珠が子房に包まれている（解答冊子）。受粉後、子房が実に、胚珠が種子になる。
  • 図3の対応：④花びら、⑤がく、⑦胚珠、⑧子房（①②③⑥はおしべ・めしべの部分で、②が柱頭）。

🔍 こう読み解く

  1. ⑧は花の根もとでふくらんでいる → 子房。
  2. ⑦はその中の粒 → 胚珠。「子房」と書かないように、線の先が「ふくらみの外側」か「中の粒」かを見る。
答え：胚珠
コツ：⑦と⑧の線は近い。答えを書く前に、線の先がどこに当たっているかをもう一度見る。

K20 (12) イネの花にないもの2つ 資料問題・図・2つ選ぶ

👀 まず見るところ

【資料問題】部品は「イネの花にはないもの」と「2つ」に丸。知識「イネの花には花びらとがくがない」を先に書き（3語で書く：イネ＝花びら×・がく×）→ 図3で花びら＝④、がく＝⑤を指すだけ。

📚 前提知識

  • イネの花は風で花粉を運ぶ風媒花。虫を呼ぶ必要がないので、花びらとがくがなく、えいという皮で包まれている（解答冊子「イネの花には花びらとがくがありません」）。

🔍 こう読み解く

  1. 図3の④は横に広がる大きな部分＝花びら、⑤はその下の小さな部分＝がく。
  2. おしべ・めしべ・胚珠・子房はイネにもある（米ができる）。答えは④・⑤。
答え：④・⑤（順不同）
コツ：「ない」と聞かれて「ある」ものを選ばない。④⑤に×、残りに○をつけてから書く。

K20 (13) メダカのオス・メスを区別できるひれ 知識問題

せびれ・しりびれ。オスはしりびれが大きく平行四辺形、せびれに切れこみがある。メスはしりびれが小さく三角形に近く、せびれに切れこみがない（解答冊子）。むなびれ・はらびれ・おびれでは区別できない。「すべて」なので2つ書く。
答え：せびれ・しりびれ

K20 (14) メダカの2枚あるひれ 知識問題

むなびれ・はらびれ。体の両側に対になっているむなびれとはらびれはそれぞれ2枚（解答冊子）。背中・おなか・しっぽの真ん中にある せびれ・しりびれ・おびれは1枚ずつで、合計5種類7枚。(13)の「せびれ・しりびれ」と取りちがえない。
答え：むなびれ・はらびれ

K20 (15) 二酸化炭素以外の不要物をこし取る器官 知識問題

腎臓（じん臓）。尿素などの不要物は腎臓で血液中からこし取られ、尿になる（解答冊子）。二酸化炭素だけは肺で出す。「二酸化炭素以外」とあるので肺ではない。漢字なら「腎臓」、ひらがなで「じん臓」でもよい。
答え：腎臓（じん臓）

K20 (16) 緯度が高いのはAとBのどちら 資料問題・透明半球

👀 まず見るところ

【資料問題】部品は図4の正体「同じ日の2地点の太陽の道すじ」を1行と、聞かれ方「緯度が高い」に線。図で見るのはどちらの道すじが天頂に近いか（A）→ 南中高度が低いBの方が緯度が高い。

📚 前提知識

  • 同じ日なら、緯度が高いほど南中高度は低い（解答冊子）。北へ行くほど太陽は低く通る。

🔍 こう読み解く

  1. 図4で、Aの道すじは天頂のすぐそばを通り、Bの道すじはそれより南寄り（低い）。
  2. 南中高度 A＞B → 緯度は B の方が高い → イ。
答え：イ
コツ：「日の出の位置が北寄りか」は季節の合図で、緯度の合図ではない。緯度は天頂からの近さだけで決める。

K20 (17) 昼が長いのはAとBのどちら 資料問題・透明半球

👀 まず見るところ

【資料問題】部品は図4の日の出・日の入りの位置が東・西より北寄りに丸 → 「北寄り＝夏」に直して書く。夏と決まれば、(16)で出した「Bが高緯度」と合わせて、昼が長いのは高緯度のB。

📚 前提知識

  • 日の出・日の入りが北寄りなら夏、南寄りなら冬（解答冊子）。
  • 夏は高緯度ほど昼が長い（北極では白夜）、冬は高緯度ほど昼が短い。季節が決まらないと、どちらが長いかは決まらない。

🔍 こう読み解く

  1. 図4：AもBも東より北側から出て、西より北側にしずむ → 夏。
  2. 夏＋Bが高緯度 → 昼が長いのはB → イ。
答え：イ
コツ：この問題は「夏」と決めてから答える。冬の図なら答えは逆（A）になるので、季節を飛ばして「高緯度＝長い」としない。

K20 (18) 満月Aと満月B、高く見えるのは 資料問題・地軸の傾き

👀 まず見るところ

【資料問題】部品は図5の正体「地球と満月の位置・半年ちがい」を1行と、地球A・Bの地軸（斜めの線）の上側がどちらへ傾いているかに丸。地軸の上側（北極側）が傾いている向きにある天体が、日本から高く見える → Bは地軸が満月の側に傾いている。

📚 前提知識

  • 地軸の北極側が太陽の方へ傾く季節が夏で、太陽は高い。月も同じで、地軸が月の側に傾くとその月の南中高度は高い（解答冊子）。
  • 満月は太陽の反対側にある。だから夏の満月は低く、冬の満月は高い。

🔍 こう読み解く

  1. 地球A：地軸の上側は太陽の方（右）へ傾く → 夏 → 満月Aは反対側＝低い。
  2. 地球B：地軸の上側は満月Bの方（右）へ傾く → 冬 → 満月Bは高い。
  3. Bの方が高い → イ。
答え：イ
コツ：地軸の線はA・B・Cで全部同じ向き（公転中に向きは変わらない）。「傾いている側の天体が高い」と1行書けば、太陽でも月でも使える。

K20 (19) 地球がCのとき最も高く通る月 資料問題・月の位置

👀 まず見るところ

【資料問題】部品は「地球がCにあるとき」と、地球Cの地軸の上側が右へ傾いていること、太陽がCの下側にあることに丸。(18)で使った「地軸が傾いている側の天体が高い」をそのまま当てはめる → 高い月は地球Cの右側にある月。あとはその位置の月の名前を決めるだけ。

📚 前提知識

  • 月の形は太陽・地球・月の位置関係で決まる。太陽の側＝新月、太陽の反対側＝満月、その中間が上弦・下弦。
  • 月は地球のまわりを、地球の公転と同じ向き（図5の矢印の向き・北極側から見て反時計回り）に回る。新月から公転の向きに90度進んだ位置が上弦の月、満月からさらに90度進むと下弦の月。

🔍 こう読み解く

  1. 地球Cの地軸は上側が右へ傾いている → 高く見えるのは地球Cの右側にある月。
