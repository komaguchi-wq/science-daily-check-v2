WS-28 ウィークリーチェック WS-28（WS-27「光と音」の復習・モノコード／屈折／平行光線とレンズ／鏡）

WC 全体像 WS-27の復習 10問（各10点・100点）

(1)はモノコードの音の高さ、(2)は空気→ガラスの屈折ととつレンズの道筋、(3)は「平行光線」をとつレンズに通したときの文字の見え方、(4)は鏡にうつる人を作図で数える問題。(3)だけは、ろうそくの像の決まりをそのまま使うと外れる。問題文の「平行光線」に丸をつけて、光が焦点に集まってから逆向きに広がる図を描けるかで3問が決まる。

今回は70／100点。落とした3問は (2)①の曲がり方、(3)①②の平行光線。(1)(4)と(3)③は取れている。

WC (1)① 図1より高い音が出るモノコード 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図1の正体「20cm・おもり1個」を余白に1行と、聞かれ方「図1より高い音・すべて」に丸。ア〜オの図に「長さ↓↑／おもり↓↑」を書きこみ、2つとも高くなる向き（短い・重い）か片方だけ変わる図を選ぶ。

📚 前提知識

  • 弦は短いほど・強く張るほど・細いほど速くふるえて高い音になる。おもりが多い＝強く張っている。
  • 長さと張りが逆向きに変わる図（長くて重い）は、どちらが勝つか決められないので「高い」と言い切れない。

🔍 こう読み解く

  1. 図1を基準に1つずつ比べる。ア 30cm・1個 → 長いだけ → 低い ×。
  2. イ 10cm・2個 → 短い＋重い → 高い ○。オ 10cm・3個 → 同じく高い ○。
  3. エ 20cm・3個 → 長さ同じで重い → 高い ○。ウ 30cm・2個 → 長い（低い）と重い（高い）が打ち消し合って決まらない ×。
答え：イ・エ・オ
今回：イ・エ・オ ○。ウを「決まらない」として外せている。

WC (1)② 長さ・おもりのほかに高い音を出す方法 知識問題

弦を細くする。音の高さを決める条件は長さ・張りの強さ・太さの3つ。①で変えたのが長さとおもり（張り）なので、残りの太さを答える。細いほど軽くて速くふるえるので高い音になる。
答え：弦を細くする。
今回：弦を細くする ○。

WC (2)① 空気からガラスに入った光の進み方 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は「空気からガラスに入って」に丸と、図2の当たった点に法線（面に垂直な線）を1本引くこと。空気→ガラスは法線に近づく向きに曲がるが、法線までは曲がらない → 法線（ア）と、そのまま（ウ）の間にあるイに決まる。

📚 前提知識

  • 光が空気からガラス（水）に入るときは、進む速さが落ちて法線に近づく向きに折れ曲がる。ガラスから空気に出るときは逆に法線から遠ざかる。
  • 曲がる角度には限りがあり、法線と重なるところ（屈折角0°）までは曲がらない。法線の向きに進むのは、まっすぐ垂直に当たったときだけ。

🔍 こう読み解く

  1. 図2の当たった点から、ななめの面に垂直な線（法線）を引く。アの矢印は、ちょうどこの法線の向き。
  2. ウはまっすぐ（曲がらない）、エは法線から遠ざかる向きなので、空気→ガラスでは×。
  3. 法線に近づくが、法線までは行かない → アとウの間のイ。
答え：イ
今回：ア ×（答案）。知識＝「法線に近づく」を「法線まで曲がる」と取りちがえた。法線は曲がる向きの目印で、光がそこに重なることはない。次は法線を引いてから「近づくがこえない」と確かめる。

WC (2)② ①のような光の進み方の名前 知識問題

屈折。ちがう物質に入るときに光が折れ曲がること。はね返るのは反射、と区別する。
答え：屈折
今回：「くっ折」○。漢字で「屈折」と書けるようにしておく。

WC (2)③ とつレンズを通る光の道筋 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は「とつレンズを通過する」に丸 → 曲がる場所は入るときと出るときの2回、向きはどちらも軸（レンズの太いほう）に寄る向き、と余白に書く。「2回・同じ向き」の図だけ残す。

📚 前提知識

  • 光が曲がるのは空気とガラスの境目だけ。レンズの中では直進する。
  • とつレンズは、上の面でも下の面でも光を厚い側（軸）に寄せる向きに曲げるので、2回とも同じ向きに曲がって集まる。

🔍 こう読み解く

  1. 曲がる回数で消す。ア・イは1回だけ、エはレンズの中（境目でない所）で曲がっている → ×。
  2. 向きで消す。ウは入るときに上へ（厚い側と逆）、カは出るときにもどる向き → ×。
  3. 入るときに下へ、出るときにさらに下へ、のオが正しい。
答え：オ
今回：オ ○。

WC (3)① すりガラスの右側から見た「妻」の形 まざり型・1つ選ぶ

👀 まず見るところ

【まざり型→条件文】部品は「左側から平行光線」と「すりガラスの右側から」に丸。平行光線は焦点に集まってから広がる、を横から見た図に置く → すりガラスの字は焦点で上下も左右も入れかわった形＝紙を180°回した形。

📚 前提知識

  • 平行な光がとつレンズに入ると、全部が焦点の1点に集まり、その先で広がる。上から来た光は焦点を通って下へ、左から来た光は右へ行くので、焦点の先では形が上下左右とも逆になる。
  • 左右だけ逆（イ）は鏡でうつした形。上下だけ逆（エ）は紙を手前にたおした形。レンズでできる逆向きは180°回した形（ウ）。

🔍 こう読み解く

  1. 厚紙の「妻」の上の部分（横線の多いほう）から出た光はレンズの上側を通り、焦点を通って下へ。女の部分は上へ行く。
  2. 同じように左右も入れかわる。すりガラスの字は、元の字を180°回したもの。
  3. ア〜オで、180°回した形はウ。オは形がゆがんでいるだけで向きは元のまま。
答え：ウ
今回：エ ×（答案）。知識＝上下だけ逆にした。レンズの像は上下と左右の両方が逆。「上下左右が逆＝紙を180°回す」と置きかえて、女の部分が上に来てななめの線も反対を向いている字を選ぶ。

WC (3)② 平行光線でできた像の正しい説明 まざり型・すべて選ぶ

👀 まず見るところ

【まざり型→条件文】部品は①と同じ「平行光線」と、聞かれ方「すべて」に丸。ろうそくの像（1点から四方八方に出る光）ではなく、1点から1本ずつの光が焦点を通る図に置く → 「レンズをかくすと像が欠ける」「Aは関係ない」の2つが決まる。

📚 前提知識

  • ろうそくの像では、1点の光がレンズ全体を通って1点に集まるので、半分かくしても像は欠けずに暗くなる。平行光線では、字の各点から出る光は1本だけなので、通る道をふさがれた点は消える。
  • 平行光線はどこに置いても平行のまま。厚紙とレンズの距離Aを変えても、レンズに入る光は変わらない。

🔍 こう読み解く

  1. ア・イ・ウ：字の上半分から出た光はレンズの上半分を通り、焦点を通って下へ行く。上半分をふさぐと、すりガラスの下半分が消える → ア ○・イ ×。残った部分は暗くならない → ウ ×。
  2. エ・オ・カ：平行光線なのでAを変えても光の道は同じ。Bはそのままでよい → エ ○。オ・カはろうそくの像の話なので ×。
答え：ア・エ
今回：ウ・カ ×（答案）。部品を拾えなかった＝「平行光線」に丸がなく、ろうそくの像の決まり（半分かくす→暗くなる／近づける→像は遠くに）で答えた。問題文に「平行光線」とあれば、光は焦点を通る1本ずつ、と図を描き直す。
コツ：「平行光線」と「ろうそく（点から広がる光）」は別の決まり。どちらの問題かを先に決めてから選択肢を読む。

WC (3)③ 同じ大きさに見えたときの焦点距離 条件文・計算

👀 まず見るところ

【条件文】部品は「同じ大きさの文字」と「どちらも10cm」に丸。平行光線は焦点で1点に集まり、そこから同じ角度で広がるので「焦点の手前と先で、同じ距離なら同じ大きさ」と直して書く → 焦点はレンズとすりガラスのまん中。

📚 前提知識

  • 平行光線はレンズから焦点までの間で小さくなり、焦点の先で同じ割合で大きくなる（三角形の形が同じ）。レンズから焦点までの距離と、焦点からすりガラスまでの距離が等しいとき、元と同じ大きさになる。

🔍 こう読み解く

  1. B＝10cmのところで元と同じ大きさ → 焦点はレンズとすりガラスのちょうどまん中。
  2. 10÷2＝5cm。Aの10cmは平行光線なので使わない。
答え：5cm
今回：5cm ○。

WC (4)① Ⓐから鏡にうつって見える人の数 条件文・作図

👀 まず見るところ

【条件文】部品は「体の一部が鏡にうつっていれば見えた」に丸と、Ⓐを鏡の向こう側に折り返した点Ⓐ′（鏡の線の2マス下）を図に置くこと。Ⓐ′と鏡の両はしを結んで延長した扇形の中にいる人が見える、と決まる。

📚 前提知識

  • 鏡で見える範囲は、目を鏡の面で折り返した点（像）と、鏡の両はしを結ぶ2本の線にはさまれた扇形。線の上にいる人も「一部がうつる」ので見える。

🔍 こう読み解く

  1. Ⓐは鏡の線から2マス上なので、Ⓐ′は2マス下に打つ。鏡は左はしから2マス右の点〜5マス右の点までの3マス分。
  2. Ⓐ′と鏡の左はしを結んで延長 → 右へ1マス進むごとに1マス上がる線。上の段の2人（左から4・5マス目）はこの線より左上にいて見えない。
  3. Ⓐ′と鏡の右はしを結んで延長 → ゆるい右上がりの線。右はしの3マス上の人、Ⓐと同じ高さの真ん中の人、右下の人の3人は2本の線の間 → 3人。
答え：3人
今回：3人 ○。図に線を引いて数えられている。

WC (4)② 5人全員を見るために右へ何マス動くか 条件文・作図

👀 まず見るところ

【条件文】部品は①と変わった「5人全員」「Ⓐより何マス右」に丸。①で見えなかったのは左上の2人なので、Ⓐ′を右へ1マスずつずらして「左の線が上の段の2人をこえるか」を図で確かめる。

📚 前提知識

  • 目が右へ動くとⒶ′も同じだけ右へ動き、扇形ごと左にかたむく。左の線は左上の人をとらえやすくなり、右の線は右下の人を外しやすくなる。両方を見る。

🔍 こう読み解く

  1. Ⓐ′を1マス右に。鏡の左はしと結んで延長すると、上の段の左の人（左から4マス目）をちょうど通る → 「一部がうつれば見えた」ので○。右の人（5マス目）はその右側で、線の内側 → ○。
  2. 右の線も確かめる。Ⓐ′（1マス右）と鏡の右はしを結んで延長すると、右下の人をちょうど通る → まだ見える。残り2人は線の内側のまま。
  3. 1マスで5人全員。2マス動かすと右下の人が線の外に出てしまう。
答え：1マス
今回：1マス ○。
コツ：「体の一部がうつっていれば」の一文は、線の上の人を見えたと数える合図。ぎりぎり線を通る人がいる問題で効く。

WC まとめ 70／100点

  • 取れた：(1)モノコードの3条件、(2)②③屈折の名前とレンズの道筋、(3)③、(4)鏡の作図。基本の決まりと作図はできている。
  • 落とした3問のうち2問が(3)の「平行光線」。問題文のこの4字に丸がつけば、「焦点で1点→その先は180°回った形」「レンズをふさぐと欠ける」「Aは関係ない」が全部そこから出る。残る(2)①は「法線に近づくが、こえない」の知識。
  • 覚え直しはこの2つ。平行光線＝焦点を通る1本ずつの光（ろうそくの像とは別）／空気→ガラスは法線に近づく、ガラス→空気は遠ざかる。
