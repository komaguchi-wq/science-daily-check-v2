WS-28 CP（コアプラス確認テスト WS-28・人体の再徹底 454〜494・621）

CP 全体像 人体の再徹底 20問（各5点・100点）

呼吸（図1・2）→消化と吸収（図3〜5）→目（図6）→血液の循環（図7）→胎児（図8）→骨と筋肉（図9）の順に、コアプラス454〜494・621の人体をひと通りなぞるテスト。図が付いた問題は、図の矢印・記号の位置を見てから答えると、覚えていなくても決まるものが多い（図1の○の向き、図7の血管の太さと向き、図9の矢印）。

今回は14／20問（70点）。落とした6問は、実験の意味を取りちがえた(10)、聞かれ方（カタカナ指定・色・動脈／静脈）を拾わなかった(6)(12)(13)、知識の(15)(17)。

CP (1) 図1 肺胞の○が表す気体 資料問題・気体の名前

👀 まず見るところ

【資料問題】部品は図の正体「肺胞のつくり」と、○についた矢印の向き（肺胞→血液）。矢印を1本なぞる → 肺胞から血液に入る気体＝酸素と決まる。

📚 前提知識

  • 肺胞では、吸った空気の酸素が血液に入り、血液の二酸化炭素が肺胞に出る。図の○は血液に入る向き、●は血液から出る向きの矢印がついている。

🔍 こう読み解く

  1. 図の下側で、○が肺胞の中から血管へ矢印で出ている → 血液にとり込まれる気体。
  2. 右側では●が血管から肺胞へ矢印で入っている → これが二酸化炭素。だから○＝酸素。
答え：酸素
今回：酸素 ○。

CP (2) 1回の呼吸で血液に入る酸素 条件文・計算

👀 まず見るところ

【条件文】部品は「21%」「16%」「500mL」と、求めるもの「血液中にとり込まれる酸素」に丸。「吸う−はく」の差 21−16＝5% に直して書く → 500mL×5%。

📚 前提知識

  • 空気の酸素約21%のうち、はく息に残るのが約16%。減った分だけが血液に入った酸素。

🔍 こう読み解く

  1. とり込まれた割合＝21−16＝5%。
  2. 500×0.05＝25mL。
答え：25mL
今回：25mL ○。余白に「500×1/20＝25」と式を書いてから答えている。

CP (3) 図2 糸を下に引くと風船は 条件文・2択

👀 まず見るところ

【条件文】部品は「糸を下に引く」に丸 → ゴム膜が下がる＝容器の中が広がる、と直して書く。中が広がれば外の空気が入って風船はふくらむ。

📚 前提知識

  • 図2は呼吸のモデル。ガラス容器＝胸、風船＝肺、ゴム膜＝横隔膜。横隔膜が下がる → 胸が広がる → 空気が入る（息を吸う）。

🔍 こう読み解く

  1. 糸を引く → ゴム膜が下がる → 容器の中の空間が広がる。
  2. 広がった分だけ管から空気が入り、風船はふくらむ。
答え：ふくらみ
今回：ふくらみ ○。

CP (4) 図2 ゴム膜にあたる人体の部分 知識問題

横隔膜。肺の下にあるドーム形の筋肉で、下がると胸が広がって息が入り、上がると息が出る。図2のモデルでは、糸で上げ下げするゴム膜がこの役。
答え：横隔膜
今回：おうかくまく ○。

CP (5) 図3 たんぱく質を消化する消化液をつくる器官 資料問題・3つ選ぶ

👀 まず見るところ

【資料問題】部品は「たんぱく質」と「3つ」に丸 → 胃・すい臓・小腸の3つと先に決めてから、図3でその位置の記号を探す。記号を先に見ない。

📚 前提知識

  • たんぱく質を消化する酵素は、胃液（ペプシン）・すい液（トリプシン）・腸液の3か所。だ液と胆汁はたんぱく質にはたらかない。

🔍 こう読み解く

  1. 図3で、食道Bの下にふくらむ袋が胃＝H。胃の後ろに横長にのびる器官がすい臓＝J。
  2. まん中で細く曲がりくねっているのが小腸＝K（まわりを囲む太い方がL＝大腸）。
答え：H・J・K
今回：H・J・K ○。

CP (6) でんぷんを消化する酵素 知識問題

アミラーゼ。だ液とすい液に含まれ、でんぷんを麦芽糖に変える。「だ液」は消化液の名前、「アミラーゼ」が酵素の名前。カタカナ指定なので、答えるのは酵素の名前だけ。
答え：アミラーゼ
今回：ダエキアミラーゼ ×。部品を拾えなかった＝「カタカナで」の指定は「酵素の名前だけを書く」の合図。消化液の名前（だ液）を付けない。

CP (7) 図3 酵素を含まないが脂肪の消化を助ける消化液をつくる器官 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は「消化酵素を含まない」と「つくる器官」に丸 → 胆汁、つくるのは肝臓（ためるのは胆のう）。図3で右上の大きな器官を探す。

📚 前提知識

  • 胆汁は酵素を持たず、脂肪を細かい粒にしてすい液のリパーゼがはたらきやすくする。肝臓でつくられ、胆のうにためられる。

🔍 こう読み解く

  1. 図3でいちばん大きく、胃の右（体の右側）にあるのが肝臓＝E。
  2. Gは肝臓の下の小さな袋＝胆のう。「つくる」と聞かれているので胆のうではなく肝臓。
答え：E
今回：E ○。「つくる」と「ためる」を分けて選べている。

CP (8) 吸収されたでんぷんのたくわえ先 知識問題

① 肝臓 ② グリコーゲン。でんぷんはブドウ糖まで分解されて小腸から吸収され、門脈を通って肝臓に運ばれ、グリコーゲンに変えてたくわえられる。「ブドウ糖→肝臓→グリコーゲン」をひとつづきで。
答え：① 肝臓　② グリコーゲン
今回：かん臓・グリコーゲン ○。

CP (9) 図4 ヨウ素液を加えると まざり型→条件文・○×

👀 まず見るところ

【まざり型→条件文】部品は「でんぷんとだ液」「37℃」「十分時間がたった」に丸 → 「袋Aのでんぷんは全部糖に変わっている」と直して書く。でんぷんがどこにも無ければ、A・Bとも変化しない。

📚 前提知識

  • ヨウ素液はでんぷんがあると青紫色。だ液のアミラーゼは体温（37℃）付近でよくはたらき、でんぷんを糖に変える。
  • セロハンは小さい粒（糖・水）だけ通し、大きい粒（でんぷん）は通さない。

🔍 こう読み解く

  1. A：だ液と37℃で十分な時間 → でんぷんは全部糖に変わった → ヨウ素液は変化なし＝×。
  2. B：でんぷんはそもそもセロハンを通れず、Aにも残っていない → 変化なし＝×。
答え：A ×　B ×
今回：A× B× ○。

CP (10) 図4 ベネジクト液を加えて加熱すると まざり型→条件文・○×

👀 まず見るところ

【まざり型→条件文】部品は(9)と変わった「ベネジクト液」（糖を調べる）に丸。(9)で決めた「Aのでんぷんは全部糖になった」に、「糖は小さいのでセロハンを通る」を足して書く → AにもBにも糖がある。

📚 前提知識

  • ベネジクト液は糖があると、加熱で赤褐色の沈殿ができる。
  • でんぷんが糖に変わると粒が小さくなり、セロハンを通りぬけて外の水Bに出ていく。これが小腸の壁での吸収と同じしくみ。

🔍 こう読み解く

  1. A：だ液ででんぷんが糖に変わっている → 沈殿ができる＝○。
  2. B：糖はセロハンを通ってBの水にも広がっている → ○。
答え：A ○　B ○
今回：A○ B× ×。部品の形を直さなかった＝「でんぷんは通らない」で止まり、「糖に変わったら通る」まで直していない。セロハン＝小腸の壁、糖＝吸収される大きさ、と1行書く。
コツ：(9)(10)はセットで「でんぷん→糖に変わる」「糖→セロハンを通る」の2段。Bの結果が(9)と(10)で変わるのは、調べる相手が変わるから。

CP (11) 図5 柔毛のXとそこに吸収されるもの 知識問題

① リンパ ② ウ・エ。柔毛のまん中を通る太い管がリンパ管で、脂肪酸とモノグリセリドはここに入る。ブドウ糖とアミノ酸はまわりの毛細血管へ。「水にとけやすい2つ＝血管、脂肪の2つ＝リンパ管」と分ける。
答え：① リンパ　② ウ・エ
今回：リンパ・ウエ ○。

CP (12) 図6 像をつくる場所と水晶体・ガラス体の色 資料問題・記号＋色

👀 まず見るところ

【資料問題】部品は「像をつくる」と「色は」に丸。像ができるのは目のいちばん奥の壁（網膜）→ 図6で奥の壁をさす記号を探す。②は「色」を聞いているので、答えは色の言葉で書く。

📚 前提知識

  • 光は 角膜→水晶体→ガラス体→網膜 と進み、網膜に像ができる。網膜につながるのが視神経。
  • 水晶体とガラス体は光をそのまま通す役なので、色がついていない＝無色。

🔍 こう読み解く

  1. 図6で視神経につながる奥の壁をさしているのはオ。ア・イ・ウ・エはどれも前側（角膜・虹彩のあたり）。
  2. ②は「〜色」と答える問題。「透明」は見えすきの話、色を聞かれたら「無色」。
答え：① オ　② 無色
今回：① ア ② とう明 ×。①は知識＝像ができる場所を前側のアと取った。「像＝奥の網膜＝視神経の根もと」で図をたどる。②は部品を拾えなかった＝「色は」の聞き方に丸が無く、色でない言葉で答えた。

CP (13) 図7 動脈と、酸素を多く含む血液の血管 資料問題・2つずつ選ぶ

👀 まず見るところ

【資料問題】部品は「動脈」と「酸素を多く含む」に丸 → 動脈＝心臓から出る血管、酸素が多い＝肺を通ったあとの血管、と2つは別の分け方だと直して書く。図7の4本に、心臓からの向きと肺とのつながりを書きこむ。

📚 前提知識

  • 動脈は心臓から出ていく血管（大動脈・肺動脈）。静脈は心臓にもどる血管（大静脈・肺静脈）。動脈＝酸素が多い、ではない。
  • 酸素が多いのは肺から心臓へもどる肺静脈と、それを全身へ送る大動脈。肺動脈は心臓から肺へ向かう血液なので、酸素は少ない。

🔍 こう読み解く

  1. 図7で、心臓の左上から大きく弓なりに出る太い管がイ＝大動脈。左右に枝分かれして肺へ向かうのがウ＝肺動脈。この2本が「心臓から出る」＝動脈 → ①イ・ウ。
  2. 上下から心臓の右側にもどる太い管がア＝大静脈。肺から心臓の左側にもどる細い管がエ＝肺静脈。
  3. 酸素が多いのは、肺を出たあとの血液が流れるエ（肺静脈）とイ（大動脈） → ②イ・エ。
答え：① イ・ウ　② イ・エ
今回：① ウ・エ ② ア・ウ ×。知識＝「動脈／静脈」を「心臓から出る／もどる」でなく血液の種類で分けた形。①は「出る」、②は「肺のあと」と、分け方を2行に分けて書く。
コツ：肺動脈と肺静脈は名前と血液の中身が逆。「肺動脈＝心臓から肺へ＝酸素が少ない」「肺静脈＝肺から心臓へ＝酸素が多い」をセットで。

CP (14) アンモニアが変えられる場所と物質 知識問題

① 肝臓 ② 尿素。たんぱく質を使ったあとに出る有害なアンモニアは、肝臓で害の少ない尿素に変えられ、じん臓でこしとられて尿になる。「肝臓でつくる→じん臓で出す」の順。
答え：① 肝臓　② 尿素
今回：かんぞう・にょうそ ○。

CP (15) 二酸化炭素以外の不要物が最も少ない血管 知識問題

腎静脈。尿素などの不要物はじん臓でこしとられるので、じん臓を出た直後の血液（腎静脈）がいちばんきれい。肝臓を出た血液（肝静脈）は尿素をつくったあとなので、尿素はむしろ多い。「つくる＝肝臓／取りのぞく＝じん臓」で分ける。
答え：腎静脈
今回：かんじょうみゃく ×。知識＝尿素を「つくる」肝臓と「こしとる」じん臓を取りちがえた。不要物が「最も少ない」＝取りのぞいた直後、と聞き方から決める。

CP (16) 図8 胎児のまわりのA・B 資料問題・名前

👀 まず見るところ

【資料問題】部品は図8のAの形（胎児のおなかから出る1本のひも）とBの位置（子宮のかべに広がる部分）。ひも＝へその緒、かべの部分＝胎盤、と形で決める。

📚 前提知識

  • 胎盤は子宮のかべにできる器官で、母親の血液と胎児の血液が混ざらずに養分・酸素と不要物を交換する。へその緒は胎児と胎盤をつなぐ管。

🔍 こう読み解く

  1. Aは胎児のおなかから出て、かべの方へのびる1本のひも → へその緒。
  2. Bは子宮のかべにはりついた、ぎざぎざの厚い部分 → 胎盤。羊膜（胎児を包む膜）とは別。
答え：A へその緒　B 胎盤
今回：へそのお・たいばん ○。

CP (17) へその緒の中の血管 知識問題

ア（胎児の血管）。へその緒を通る血管は胎児のもので、胎児の血液だけが流れる。母親の血液は胎盤までで、胎児の血液とは混ざらない。「混ざらない」が決め手。
答え：ア
今回：ウ ×。知識＝母親と胎児の血液は胎盤で「混ざらない」。へその緒は胎児側の管なので、血管も胎児のものだけ。

CP (19) 図9 筋肉の両はしのA 知識問題

腱（けん）。筋肉の両はしは「けん」になって、関節をまたいで骨についている。筋肉が縮むと、けんが骨を引いて関節が曲がる。「筋肉は関節をまたぐ」とセットで。
答え：腱（けん）
今回：けん ○。

CP (20) 図9 腕を曲げるとき縮む筋肉 資料問題・X／Y

👀 まず見るところ

【資料問題】部品は図9の矢印の向き（前腕が上に曲がる）と、XとYが腕の内側か外側か。曲がる側＝内側の筋肉が縮む、と図に書きこむ。

📚 前提知識

  • 筋肉は縮むことしかできないので、関節の内側と外側に1対ある。曲げるときは内側が縮んで外側がゆるみ、のばすときは逆。

🔍 こう読み解く

  1. 図9の矢印は、手の側が上（内側）へ曲がる向き。
  2. 曲がる側＝関節の内側にある筋肉はX。Xが縮んでけんが前腕の骨を引く。Yは外側なのでゆるむ。
答え：X
今回：X ○。
