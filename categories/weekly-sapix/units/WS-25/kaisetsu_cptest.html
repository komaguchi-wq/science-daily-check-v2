CP 全体像 てこ・ばね・滑車・浮力・ふりこ 20問（各5点・100点）

コアプラス「力学の再徹底」の確認テスト。前半(1)〜(12)は てこ・重心・ばね・滑車・輪軸の計算、後半(13)〜(20)は 密度・浮力・ふりこの決まり。計算問題はどれも「図に数字を書きこむ → つり合いの式を1本」で決まる。

今回は80／100点。落とした4問は (8)重心の向き・(9)ばねの両端・(18)単位・(20)ふりこの長さ。式の立て方はできているので、失点は「図に置く前に答えた」「mをcmに直さなかった」の型。

CP (1) ボートのオールの支点 知識問題

C。オールは水をとらえた先（C）が動かない点＝支点。手（A）が力点、オール受け（B）が作用点で、ここに力が伝わってボートが進む。「水に入っている方が支点」でおぼえる。
答え：C
今回：C ○。

CP (2) つめ切りの作用点 知識問題・2か所

AとC。つめ切りは てこが2つ重なった道具。上のレバー（支点B・力点D）が押すCが1つ目の作用点、下の刃の組（支点E・力点C）がつめを切るAが2つ目の作用点。Cは「作用点でもあり力点でもある」のが見どころ。
答え：A・C
今回：C・A ○（順番は問わない）。

CP (3) 栓抜き・力点−支点−作用点の順 知識問題

B。Aは先を栓の上にのせて（支点）、ふちに引っかけた所（作用点）を持ち手（力点）で引き上げる＝支点−作用点−力点。Bは先を栓のふちに引っかけ（作用点）、栓の上にのった所を支点にして持ち手をたたく＝力点−支点−作用点。同じ道具でも使い方で順が変わる。
答え：B
今回：B ○。

CP (4) ばねばかりでつった棒の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様な棒」と図4の「55cm／80cm／45g」。棒の重さはまん中（左から40cm）に矢印で置き、ばねばかりは左から80−55＝25cmと直して書く → 支点はばねばかり。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなせる。
  • つり合い＝支点からの距離×重さが左右で等しい。

🔍 こう読み解く

  1. ばねばかりの位置は左から25cm。45gは左端（25cm左）、棒の重さ□gはまん中（40−25＝15cm右）。
  2. 45×25＝□×15 → 1125÷15＝75。
答え：75g
今回：75g ○。図4に「25」「15」を書きこんでから式を立てている。

CP (5) ばねばかりの示す値 条件文・計算

【条件文】部品は(4)と変わった「ばねばかりの示す値」に丸。ばねばかりは棒全体を1本で支えているので、「下向きの力の合計」に直して書く。

📚 前提知識

🔍 こう読み解く

  1. 下向きの力は 45g と 棒の75g。
  2. 45＋75＝120。
答え：120g
今回：120g ○。

CP (6) 太さが一様でない棒の重心 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様でない」と図5の「90g・120g・84cm」、聞かれ方「Aから何cm」に丸。重心は棒のまん中ではないので、「距離の比＝重さの逆比」に直して書く。

📚 前提知識

  • 両端を支える力の比は、重心からの距離の逆比になる（重心に近い方が重く支える）。
  • 棒の重さ＝90＋120＝210g。

🔍 こう読み解く

  1. A:B＝90:120＝3:4 → 重心からの距離は逆の A側:B側＝4:3。
  2. 84cm を 4:3 に分ける → 84×4/7＝48。重い120g側（B）に近い所にある、で向きを確かめる。
答え：48cm
今回：48cm ○。図5に「4:3」と書いてから分けている。

CP (7) 中央でつるしてつり合わせる 条件文・計算

👀 まず見るところ

【条件文】部品は(6)と変わった「棒の中央を糸でつるした」に丸。支点＝中央（Aから42cm）、重心＝48cm（210g）を図に置く → 重心がB側に6cmずれているので、おもりはA側。

📚 前提知識

  • 棒の重さは重心に全部かかっているとみなす。つるした点を支点に、左右のモーメントをそろえる。

🔍 こう読み解く

  1. 重心は支点から 48−42＝6cm B側。B側のモーメントは 210×6＝1260。
  2. A端は支点から42cm → □×42＝1260 → □＝30。①は A。
答え：① A　② 30g
今回：① A・② 30 ○。(6)の48cmをそのまま使って、支点との差6cmで式を立てている。

CP (8) L字形の針金をAでつるす 条件文・重心の向き

👀 まず見るところ

【条件文】部品は図6の「10cm・5cm・20cm」と「Aを支点に」。針金は長さ＝重さなので、たてを1、横を2に直して書く。つるすと重心がAの真下に来る、で形が決まる。

📚 前提知識

  • ものをつるすと、重心はつるした点の真下で止まる。
  • たて10cmの針金の重心はそのまん中＝Aの位置（Aは下から5cm）。横20cmの重心はその中央。

🔍 こう読み解く

  1. 全体の重心は、Aと「横の針金のまん中」を結ぶ線の上（重さ1:2なので横のまん中寄り）。
  2. だからつるすと、横20cmの針金のまん中がAの真下に来る。
  3. 角はAの左下へ、長い針金は右下へななめに。この形はイ。ウは長い方が真下＝たての重さを無視した形。
答え：イ
今回：ウ ×。部品の形を直さなかった＝「10cmと20cm」を重さ1:2に直して重心を図に置かず、「長い方がまっすぐ下」と決めた。次は横の針金のまん中に点を打ち、その点がAの真下になるように回す。

CP (9) 両端におもりをつけたばね 条件文・計算

👀 まず見るところ

【条件文】部品は「自然長18cm・100gで20cm」と、図7で「300g」のおもりが床についていること。100g＝2cmのびと直して書き、ばねを引く力はどちらの端も200gと図に置く。

📚 前提知識

  • ばねの両端を同じ力で引くと、のびは「片方の力」の分だけ。両端200gなら、かべにつけて200gで引くのと同じ。
  • 床についたおもりは、糸を引く力がその重さより小さい。右の糸は200gで引かれ、300gのうち残り100gは床が支える。

🔍 こう読み解く

  1. 左は200gがぶら下がっているので、糸の力は200g。ばねはつり合っているので右の糸も200g。
  2. 100gで2cmのびる → 200gで4cm。18＋4＝22。
答え：22cm
今回：20cm ×。部品を拾えなかった＝のび2cm＝100g分で、「300gは床についている」を見ずに 300−200 の差で引いたと思われる。次は図7の床と糸に「200g」と書いてから式に入る。
コツ：「両端にそれぞれ200g」は足して400gにしない。ばねのどこを切っても力は200gで、のびは1回分。

CP (10) 滑車のおもりPの重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「糸や滑車の重さは考えない」と図8の「360g」。糸は1本なのでどこでも同じ力□gと直して書き、360gの動滑車から上に出ている糸の本数を数える。

📚 前提知識

  • 1本の糸は、どこを切っても引く力が同じ。動滑車は、上向きの糸の本数分だけ力が分かれる。
  • 図8の下の動滑車からは、左の糸・右の糸・ななめに結ばれた糸の3本が上に向いている。

🔍 こう読み解く

  1. 糸の力を□gとすると、下の動滑車は □×3＝360 → □＝120。
  2. 糸の端はP。Pは糸1本で引かれているので、P＝120g。
答え：120g
今回：120g ○。糸に「120」と書いて3本で数えている。

CP (11) Pを24cm引くとおもりは何cm上がるか 条件文・計算

👀 まず見るところ

【条件文】部品は(10)と変わった「24cm引いた」と聞かれ方「何cm上がる」に丸。(10)で数えた3本をそのまま使い、「力が1/3なら距離は3倍」に直して書く。

📚 前提知識

  • 滑車は力を小さくできるが、仕事の量は変わらない。力が1/3なら引く長さは3倍。

🔍 こう読み解く

  1. 360gを支える糸は3本 → 24cm引くと、3本が8cmずつ縮む。
  2. 24÷3＝8。
答え：8cm
今回：8cm ○。

CP (12) 輪軸と水中のおもりの密度 条件文・計算

👀 まず見るところ

【条件文】部品は図9の「2cm・5cm・300g・80g」と聞かれ方「密度（g/cm³）」。300gは動滑車で150gに直して小さい輪に置く → 大きい輪の糸の力が決まり、浮力→体積→密度の順。

📚 前提知識

  • 輪軸は てこと同じ。半径×力が左右で等しい。
  • 浮力＝おし出した水の重さ。水1cm³＝1gなので、浮力の数字＝水中の体積（cm³）。

🔍 こう読み解く

  1. 300gは動滑車にぶら下がっているので、小さい輪を引く糸は 300÷2＝150g。
  2. 150×2＝□×5 → 大きい輪の糸の力は 60g。これがAの水中での重さ。
  3. 浮力＝80−60＝20g → Aの体積は20cm³。密度＝80÷20＝4。
答え：4g/cm³
今回：4g/cm³ ○。図9に「150」「60」を書いてから浮力に進んでいる。

CP (13) 水の密度が最大になる温度 知識問題

大きく。水は4℃のときに体積が最小になるので、密度が最大。氷になるとふくらんで密度が小さくなる（氷が水に浮く理由）。
答え：大きく
今回：大きく ○。

CP (14) ろうが固まるときの密度 知識問題

① 大きく　② 沈み。ろうは固まるとき体積が小さくなる（まん中がへこむ）ので密度は大きくなり、固体のろうを液体のろうに入れると沈む。水↔氷と逆、とセットで。
答え：① 大きく　② 沈み
今回：① 大きく・② 沈み ○。

CP (15) 水と食塩水に浮かべた木材の浮力 知識問題

ウ。浮いているものの浮力＝その物の重さ。木材の重さは変わらないので、水でも食塩水でも浮力は同じ。ちがうのは沈む深さ（食塩水の方が浅く沈む）。
答え：ウ
今回：ウ ○。

CP (16) 坂を転がる金属球の速さ 資料問題・並べかえ

👀 まず見るところ

【資料問題】部品は図10の正体「方眼の上の坂・A〜Dの高さ」と聞かれ方「速い順・等号・不等号」に線。A〜Dはどれも床から1マス上の同じ高さ → 速さは高さだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 転がる球の速さは、出発点からどれだけ下がったかで決まる。坂の傾きや途中の山は関係ない。

🔍 こう読み解く

  1. A・B・C・Dの高さを方眼で数える → 全部同じ。
  2. だから速さも全部同じ → A＝B＝C＝D。
答え：A＝B＝C＝D
今回：A＝B＝C＝D ○。

CP (17) ふりこの長さと周期の表 資料問題・計算

👀 まず見るところ

【資料問題】部品は表1の正体「長さ(cm)と周期(秒)」。25→1.0、100→2.0、400→4.0 を見比べて「周期が2倍なら長さは4倍」と直して書く → Yは周期3.0秒の長さ。

📚 前提知識

  • ふりこの周期は長さで決まり、長さは周期×周期に比例する（25cm＝1.0秒が基準）。

🔍 こう読み解く

  1. 周期3.0秒は1.0秒の3倍 → 長さは 3×3＝9倍。
  2. 25×9＝225。625＝25×25＝5.0秒 で表と合う。
答え：225cm
今回：225cm ○。

CP (18) 長さ25mのふりこの周期 条件文・単位

👀 まず見るところ

【条件文】部品は「25m」の単位に丸。表1はcmなので「25m＝2500cm」と直して書く → 2500÷25＝100倍の長さ。

📚 前提知識

  • 長さが100倍なら、周期は10倍（10×10＝100）。

🔍 こう読み解く

  2. 周期は 1.0×10＝10.0秒。
答え：10.0秒
今回：1.0秒 ×。部品の形を直さなかった＝「25m」をcmに直さず、表の25cmの行をそのまま読んだ。次は単位に丸をつけ、表の単位とちがえば先に書きかえる。

CP (19) くぎのあるふりこ・Zの長さ 条件文・計算

👀 まず見るところ

【条件文】部品は図11の「625cm」「釘」と「周期は3.0秒」。周期を「左半分（625cm）＋右半分（短いふりこ）」に直して書く → 右半分の時間から短い方の長さが出る。

📚 前提知識

  • くぎに糸がかかると、右側は長さ 625−Z の短いふりこになる。1往復の半分ずつを別のふりこが受け持つ。
  • 表1より 625cm＝5.0秒、25cm＝1.0秒。

🔍 こう読み解く

  1. 左半分（A→B→A側）は625cmのふりこの半周期 ＝ 5.0÷2＝2.5秒。
  2. 右半分は 3.0−2.5＝0.5秒 → 1周期なら1.0秒 → 長さ25cm。
  3. Z＝625−25＝600。
答え：600cm
今回：600cm ○。余白に「3.0」「2.5」「0.5」と半分ずつ分けて出している。

CP (20) ふりこを長くしたときの木片の移動距離 条件文・選択

👀 まず見るところ

【条件文】部品は「ふれる角度を変えずに」「長さを長くした」に丸。この2つを「おもりを放す高さが高くなる」に直して書く → 最下点の速さが決まる。

📚 前提知識

  • 木片の移動距離は、ぶつかる瞬間のおもりの速さと重さで決まる。速さは放した高さで決まる。
  • 同じ角度でも、糸が長いほどおもりの位置は最下点から高くなる（図12で糸を長くした絵を描くと分かる）。

🔍 こう読み解く

  1. 角度が同じで糸が長い → 放す高さが高い。
  2. 高い所から落ちる → 最下点で速い → 木片は遠くまで動く → ア。
答え：ア
今回：イ ×。部品の形を直さなかった＝「角度を変えず長くする」を「高さが高くなる」に直さず、長い＝ゆっくり（周期が長い）で答えたと思われる。周期と速さは別、と分けてから図12に長い糸を描く。
コツ：ふりこの問題は「周期（長さだけ）」と「速さ（高さだけ）」の2本立て。聞かれているのがどちらかに丸をつける。

CP まとめ 80／100点（16／20問）

  • 取れた16問は、てこ・重心・滑車・輪軸・浮力・ふりこの計算まで、図に数字を書いてから式を立てる手順ができている。
  • 落とした4問は全部「図に置く前に決めた」型：(8)重心を点で打つ／(9)床についた300gに気づく／(18)mをcmに直す／(20)長くする＝高くなる と描く。知識不足ではなく、部品の形を直す1手の失点。
  • 覚え直しはこの3つ：つるすと重心は真下／両端に同じ力＝のびは1回分／ふりこは 周期＝長さ・速さ＝高さ。
