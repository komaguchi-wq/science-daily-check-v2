WS-25 WC（ウィークリーチェック WS-25＝WS-24 環境問題の復習・大気汚染と温暖化）

WC 全体像 環境問題 10問（各10点・100点）

WS-24「環境問題」の復習。(1)は大気汚染（酸性雨・オゾン層）の穴うめ、(2)は地球温暖化（二酸化炭素のグラフ）の読み取りと記述。環境問題は「どの物質が→何を起こすか」の組で決まる。硫黄酸化物・窒素酸化物→酸性雨／フロン→オゾン層の破壊／二酸化炭素→温暖化。この3組を分けて置けば、(1)も(2)も同じ組の中で答えが決まる。

今回は50／100点。え・お・か、(2)②③Aは取れている。落とした(1)あ・い・うは「大気汚染」の組と「温暖化」の組がまざった形、(2)①は答えを書き切る前に次へ進んだ形、③Bは「二酸化炭素」の部品が抜けた形だった。

WC (1)あ 工場や発電所から出る大気汚染の物質 素材文・穴うめ

👀 まず見るところ

【素材文】設問は「当てはまる言葉」。部品は1文目の「大気汚染」と、あとの文の「（え）として森林を枯らす」に丸 → 温暖化ではなく酸性雨の話。酸性雨のもとは2つで、「工場や発電所」から出る方が硫黄酸化物と決まる。

📚 前提知識

  • 石油や石炭には硫黄が少し混じっているので、燃やすと硫黄酸化物が出る。燃やす量が多い工場・火力発電所が主な出どころ。
  • 硫黄酸化物と窒素酸化物が雨にとけると酸性雨になる。二酸化炭素は温暖化の原因で、別の組。

🔍 こう読み解く

  1. （あ）と（い）は「物質」で、「森林を枯らす（え）」の原因 → 酸性雨のもと2つ。
  2. （あ）は「工場や発電所」、（い）は「自動車」から。燃料の硫黄が出どころ → （あ）＝硫黄酸化物。
答え：硫黄酸化物
今回：二酸化炭素 ×。部品を拾えなかった＝「大気汚染」「森林を枯らす」に丸がなく、温暖化の組の気体を書いた。文の先頭の「大気汚染」に丸をつけてから物質を決める。

WC (1)い 自動車から出る大気汚染の物質 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「（あ）と（い）は…物質」と、「自動車などの交通手段から発生」に丸 → 答えは発電の種類ではなく物質の名前で、自動車の排気ガスに多いのは窒素酸化物と決まる。

📚 前提知識

  • エンジンの中で燃料を高温で燃やすと、空気中の窒素が酸素と結びついて窒素酸化物になる。自動車が主な出どころなので「発生が避けられない」と書かれている。
  • あ＝硫黄酸化物（工場・発電所）、い＝窒素酸化物（自動車）の組で、どちらも酸性雨のもと。

🔍 こう読み解く

  1. 1文目で（あ）（い）は「物質」と確かめる。火力・水力のような発電の名前は入らない。
  2. 「自動車」から出る酸性雨のもと → 窒素酸化物。
答え：窒素酸化物
今回：火力 ×。部品を拾えなかった＝「物質」に丸がなく、（う）に入る発電の名前を（い）に書いた。1文目の「物質」で、あ・いは物質の名前と決めてから読む。

WC (1)う 硫黄酸化物を出す発電所 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「工場や（う）発電所」と、直前の「（あ）はおもに…発生していました」に丸 → 燃料を燃やして物質を出す発電所＝火力発電所と決まる。

📚 前提知識

  • 発電所の名前は、火力・水力・原子力・風力・太陽光・地熱のように「何の力で回すか」でつける。石油・石炭・天然ガスを燃やすのはまとめて火力。
  • 燃料を燃やす発電所だけが硫黄酸化物と二酸化炭素を出す。水力・原子力・風力は燃やさないので出さない。

🔍 こう読み解く

  1. 硫黄酸化物を出す＝燃料を燃やす発電所。
  2. 燃やす発電所の名前は「火力」の1つ → （う）＝火力。
答え：火力
今回：ガス ×。知識＝燃料の名前（ガス）と発電所の名前（火力）を取りちがえた。答案の横に「火力」と直した跡があるので、発電所の名前は火力・水力・原子力…の中から選ぶ、と1行置いておく。

WC (1)え 森林を枯らす原因 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「（あ）と（い）は、（え）として森林を枯らす」に丸 → 硫黄酸化物・窒素酸化物が雨にとけたもの＝酸性雨と決まる。

📚 前提知識

  • 硫黄酸化物・窒素酸化物が雨水にとけると強い酸性の雨になる。森林を枯らし、湖や川の生き物にも害が出る。

🔍 こう読み解く

  1. 「（あ）と（い）」が「（え）として」ふる → 2つの物質がとけた雨。
  2. 森林を枯らす雨 → 酸性雨。
答え：酸性雨
今回：酸性雨 ○。

WC (1)お 冷蔵庫や冷房に使われていた物質 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「以前は冷蔵庫や冷房などに使われていた」と「（か）ホールができる原因」に丸 → 冷やす道具の中身で、オゾン層をこわす物質＝フロンと決まる。

📚 前提知識

  • フロンは冷蔵庫・エアコンの冷やす液やスプレーに使われていた人工の物質。上空でオゾンをこわすことが分かり、今は使用が制限されている。

🔍 こう読み解く

  1. 「冷蔵庫や冷房」＝冷やす道具 → フロン。
  2. 次の文の「（か）ホールができる原因」でも確かめられる → フロン。
答え：フロン
今回：フロン ○。

WC (1)か 北極や南極の上空にできるホール 素材文・穴うめ

👀 まず見るところ

【素材文】部品は「上空の高いところに（か）ホール」と「紫外線の多くが地表に届く」に丸 → 紫外線を吸収する層に穴があく話＝オゾンと決まる。

📚 前提知識

  • 上空のオゾン層は太陽からの有害な紫外線を吸収している。フロンでオゾンがこわれて薄くなった所がオゾンホールで、南極の上空で大きい。
  • 紫外線が多く届くと皮ふがんが増える、と本文に書いてある。

🔍 こう読み解く

  1. 「ホール」「層の破壊」「紫外線」の3語がそろう → オゾン。
答え：オゾン
今回：オゾン ○。

WC (2)① グラフ2の気体 資料問題・気体の名前

👀 まず見るところ

【資料問題】部品は資料の正体「グラフ2＝空気中のある気体の割合・%・1985〜2010年」を1行書くことと、設問の「気体とは何ですか」に丸 → 増え続けていて、グラフ1の気温上昇と対になる気体＝二酸化炭素と決まる。答えは気体の名前を最後まで書く。

📚 前提知識

  • 二酸化炭素は熱を外へにがしにくくする（温室効果）。石油・石炭を燃やして増えたぶん、地球の気温が上がる＝地球温暖化。
  • グラフ2の目盛りは 0.03□%。空気中の二酸化炭素は約0.04%で、この大きさに合う気体は二酸化炭素。

🔍 こう読み解く

  1. グラフ1は気温が上がっている。グラフ2は割合が増え続けている → 対になるのは温暖化の原因の気体。
  2. 目盛りが 0.03〜0.04% → 空気中の割合が合うのは二酸化炭素。
答え：二酸化炭素
今回：二酸化 ×。部品を拾えなかった＝設問の「気体とは何ですか」に丸がなく、気体の名前が「二酸化」で止まっている。「二酸化」は気体の名前ではないので、答えを書く直前に設問の丸を見直す。

WC (2)② グラフ2の□に入る数字 資料問題・記号選択

👀 まず見るところ

【資料問題】部品は縦軸の「(%)」と「□3〜□9に同じ数字」に丸 → □は小数の頭の部分で、空気中の二酸化炭素の割合約0.04%に合う 0.03 と決まる。

📚 前提知識（あれば答え合わせに使う）

  • 空気の成分は、窒素が約78%・酸素が約21%で、二酸化炭素は約0.04%（0.03〜0.04%）。
  • □9 まであって次が 0.04 につながるので、1985年の 0.035% から 2010年の 0.039% あたりまで増えたグラフと読める。

🔍 こう読み解く

  1. □3〜□9 に同じ数字 → 「0.03」なら 0.033〜0.039%、「0.3」なら 0.33〜0.39%、「3」なら 33〜39%。
  2. 空気中の二酸化炭素は約0.04%なので、合うのは 0.033〜0.039% → ア。イ 0.30 とウ 0.3 は数が同じ見せかけで、どちらも10倍大きい。
答え：ア
今回：ア ○。グラフの下に「0.04」「0.033」と書いてから選んでいて、割合の大きさで決める手順ができている。

WC (2)③A 風力発電が効果のある理由 記述・25字以内

👀 まず見るところ

【素材文】設問は「グラフ2のような変化を防ぐ」理由を「25字以内」。グラフ2の変化＝二酸化炭素が増えること、と直して書く → 答えには「二酸化炭素」の語が入る。風力は燃料を燃やさない、が理由の部品。

📚 前提知識

  • 火力発電は燃料を燃やすので二酸化炭素を出す。風力・水力・太陽光は燃やさないので、発電のときに二酸化炭素を出さない。

✍️ 答案の組み立て

  1. 要素A：何を減らすか → 発電による二酸化炭素の排出。
  2. 要素B：どうなるか → 出さずにすむ（おさえられる）。「〜ため。」で結ぶ。
模範解答：発電による二酸化炭素の排出をおさえられるため。
今回：○。答案は「二酸化炭素を排出せず、風を使うので温暖化を止める。」。「二酸化炭素を排出しない」の要素が入っていて正解になっている。
コツ：「温暖化を止める」だけでは理由にならない。グラフ2の気体の名前を入れて「二酸化炭素を出さないため」と書く。

WC (2)③B 植林が効果のある理由 記述・25字以内

👀 まず見るところ

【素材文】部品はAと同じ「グラフ2のような変化を防ぐ」＝二酸化炭素が増えるのを防ぐ、と直して書く。植物が二酸化炭素を使うはたらき＝「光合成」が理由の部品で、答えは「光合成で二酸化炭素を吸収する」の形に決まる。

📚 前提知識

  • 植物は光合成で二酸化炭素を取り入れ、でんぷんと酸素を作る。森林が増えるほど、空気中から取りのぞかれる二酸化炭素が増える。

✍️ 答案の組み立て

  1. 要素A：何によって → 植物の光合成。
  2. 要素B：何をどうするか → 二酸化炭素を吸収する。「〜ため。」で結ぶ。
模範解答：植物の光合成により二酸化炭素を吸収するため。
今回：×。答案は「植物の光合成により、温暖化を止められる。」。要素A ○／要素B ×＝「二酸化炭素を吸収する」が無い。部品を拾えなかった＝「グラフ2のような変化」を二酸化炭素のことと直さず、「温暖化」で置きかえた。Aと同じく気体の名前を入れる。

WC まとめ 50／100点

  • 取れた：え・お・か、(2)②③A。酸性雨・フロン・オゾンの言葉と、二酸化炭素0.04%の読み取りは入っている。
  • 落とした5問のうち あ・い・う・③B は「大気汚染の組（硫黄酸化物・窒素酸化物→酸性雨）」と「温暖化の組（二酸化炭素）」を分けて置けば決まる失点。(2)①は答えの名前を最後まで書く。
  • 覚え直しはこの3組。硫黄酸化物（工場・火力発電所）＋窒素酸化物（自動車）→酸性雨／フロン→オゾン層の破壊→紫外線／二酸化炭素（約0.04%）→温暖化。
