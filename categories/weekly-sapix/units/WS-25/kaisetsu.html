X1 全体像 エンゲルマンの実験・光合成 4問（各25点）

1880年のエンゲルマンの実験。アオミドロ（植物性プランクトン）に光があたる→光合成で酸素が出る→呼吸に酸素がいる細菌が集まる、の1本の流れで4問とも決まる。図1は「明るい所では全体に細菌」、図2は「暗い所で光をあてた所だけ、しかも緑の部分に細菌」。

この大問は未実施。解くときは、実験1と実験2で変えた条件（明るい／暗い＋一部に光）に丸をつけてから設問に入る。

X1 (1) 細菌がアオミドロのまわりに集まった理由 まざり型・正しいもの

👀 まず見るところ

【まざり型→素材文】部品は実験1の「明るい光のもとで」と、選択肢の共通部分「細菌が呼吸に利用する」に丸。光＋緑の生き物＝光合成、呼吸に使う気体＝酸素、と2語に直して書く → 「酸素が発生」の①に決まる。

📚 前提知識

  • アオミドロは葉緑体を持つ植物性のプランクトン。光があたると光合成で酸素を出す（解答冊子）。
  • 細菌も生き物なので呼吸をする。呼吸で取りこむのは酸素、出すのは二酸化炭素。

🔍 こう読み解く

  1. ①②③はちがいが気体の名前だけ。「呼吸に利用する」気体は酸素なので、② 二酸化炭素・③ ちっ素は呼吸に使わない → ×。
  2. その酸素を出しているのは、光を受けたアオミドロの光合成 → ①。
答え：①
コツ：自分で解くときは「呼吸＝酸素を使う／光合成＝酸素を出す」を余白に1行書いてから選ぶ。

X1 (2) 実験2から分かること 資料問題・あてはまらないもの

👀 まず見るところ

【まざり型→資料問題】聞かれ方「あてはまらないもの」に線。資料の正体は図2「暗い所で光をあてた2か所だけに細菌、しかも緑の部分に多い」と1行。4つ全部に○×をつけ、図と逆のことを言う文をさがす。

📚 前提知識（あれば答え合わせに使う）

  • 光合成は葉緑体（緑の部分）で、光があるときだけ起こる。細菌は酸素が出る所に集まるので、細菌の多さ＝光合成のさかんさ。

🔍 こう読み解く

  1. 図2で、光をあてた所にだけ細菌がいる → ①「光があたらなくてはいけない」○。④「緑でない部分では光があたっても集まらない」も、光の輪の中で緑の部分にだけ細菌がいるので ○。
  2. ②「緑の部分で必要な物質がつくられる」→ 緑の部分に集まっているので ○。
  3. ③「光があたっていてもいなくてもちがいがない」→ 図2は光のある所とない所でまるでちがう → ×。これが答え。
答え：③
コツ：「あてはまらないもの」は、図と逆のことを言い切っている文（ちがいがない・集まらない）から確かめると早い。

光合成。葉緑体が光のエネルギーを使って、二酸化炭素と水からでんぷんと酸素をつくるはたらき。実験1・2で細菌が集まったのは、この酸素があったから。漢字指定なので「光合成」の3字で書く。
答え：光合成

答え：二酸化炭素

X2 (3)② 二酸化炭素が成長に関係することを確かめる実験 記述・実験と結果

👀 まず見るところ

【素材文】部品は道具の指定「密閉できる大きな透明の箱（箱G）」「成分を吸収する液体（液K）」と、答え方「実験の内容と期待される結果」に丸。液Kは「二酸化炭素をなくす道具」に直して書く → 二酸化炭素あり／なしの2つの箱を比べる対照実験、と決まる。

📚 前提知識

  • 何かのはたらきを確かめるときは、その条件だけを変えた2つを用意して比べる（対照実験）。ここで変えるのは二酸化炭素の有無だけ。
  • 箱が透明なのは光を入れるため、密閉するのは外の空気の二酸化炭素が入らないようにするため。

✍️ 答案の組み立て

  1. 要素A（実験）：箱Gを2つ用意し、植物を入れる。一方には液Kを入れて二酸化炭素をなくし、もう一方は液Kを入れずに密閉する。
  2. 要素B（何を調べるか）：しばらく置いて、植物の重さの変化を比べる。
  3. 要素C（結果）：液Kを入れていない（二酸化炭素がある）方は重くなり、液Kを入れた方は重くならない。
模範解答：（実験）植物を入れた2つの箱Gを用意し、一方には液Kを入れて密閉し、もう一方には液Kを入れずに密閉する。しばらく置いたあと、植物の重さの変化を調べる。（結果）液Kを入れていない方は重くなるが、液Kを入れた方は重くならない。
コツ：結果は「どちらが／どうなる」を両方書く。「重くなる」だけだと比べたことにならない。

X3 (1) 水に入れたロウを温めると 条件文・記号

👀 まず見るところ

【条件文】部品は図1「水の試験管でロウが浮いている」と、設問の但し書き「液体になると…1割ほど体積が増えます」に丸。体積が増える＝同じ重さでかさが増える＝もっと軽い、に直して書く → 液体になっても浮く。

📚 前提知識

  • 浮き沈みは密度（1cm³あたりの重さ）で決まる。水に浮く＝水より密度が小さい（解答冊子）。
  • 重さは変わらずに体積が増えると、密度はさらに小さくなる。だから液体のロウも水に浮く。

🔍 こう読み解く

  1. 図1：固体のロウは水に浮いている → ロウの密度＜水。
  2. とけると体積が1割増え、重さは同じ → 密度はもっと小さい → やはり浮く＝ア。
  3. ウ「水に混ざる」は、灯油には混ざった（実験2）が、ロウは油の仲間なので水とは混ざらない。
答え：ア
今回：ア ○。但し書きの「体積が増える」を「もっと軽くなる」に直せている。

答え：無
今回：無 ○。

X3 (3) とけて固まったあとの重さ 条件文・記号

👀 まず見るところ

【条件文】部品は「温める前と同じ温度になったあと」「最初にはかった時の重さと比べて」に丸。とける・固まるは状態が変わるだけで、ロウが減ったり増えたりしていない、と直して書く → 重さは変わらない。

📚 前提知識

  • 固体⇄液体の変化では体積は変わるが重さは変わらない（解答冊子）。重さが変わるのは、燃えて気体が出ていくときなど、物質が出入りしたとき。

🔍 こう読み解く

  1. 実験3はビーカーの中で温めて冷やしただけ。燃やしていないので、ロウはどこにも出ていかない。
  2. 形や体積が変わっても重さは同じ → ウ 変わりませんでした。
答え：ウ
今回：ウ ○。

X3 (4) 固まったロウの表面の形 資料問題・断面図を選ぶ

👀 まず見るところ

【資料問題】資料の正体は「固まったロウの断面図・点線＝液体のときの液面」と1行。部品は実験3の「まわりからだんだんととけて」に丸 → 固まるときもまわりから固まる、に直して書く。ロウは固まると体積が減るので、最後に固まる中央がへこむ。

📚 前提知識

  • ロウは液体→固体で体積が小さくなる。水は逆に大きくなる（氷が浮くのはこのため）。解答冊子の図「ロウと水の体積変化」。
  • ビーカーに接している外側から先に固まり、中心の液体は外側のへこみに流れこむ。これをくり返すので、中心付近の液体が足りなくなってへこむ（解答冊子）。

🔍 こう読み解く

  1. 体積が減る → 点線（液面）より下になる図を残す → ア・イ。ウ・エ（盛り上がる）は水のときの形なので ×。
  2. 外側から固まるので、外側は液面の高さのまま固まり、へこむのは中央だけ → イ。ア（全体が平らに下がる）は、全部が同時に固まったときの形で、ロウには当てはまらない。
答え：イ
今回：ア ×。知識＝「体積が減る」までは合っていて、「外側から固まる」が抜けた。実験3の「まわりからだんだんととけて」に丸をつけ、固まるときも同じ順だと直して書けば、中央だけへこむ形に行き着く。
コツ：ロウ＝中央がくぼむ／水（氷）＝中央が盛り上がる、を解答冊子の図ごと組で持っておく。

X3 (5) 温度がもどっても水面が高いままの理由 記述・15点

👀 まず見るところ

【条件文】部品は設問の「温度が実験前の温度にもどっても」と「水面が元の高さより高くなったまま」に丸。温度の話はもう済んでいる、に直して書く → 残る理由はコップ内の気体そのものが減ったこと。何が減って何が消えたかを、ロウの燃焼から考える。

📚 前提知識

  • ロウは炭素をふくむので、燃えると酸素と結びついて二酸化炭素ができる。二酸化炭素は水にとける（解答冊子）。
  • コップ内の気体が減ると、その分だけ皿の水がコップの中に入ってきて水面が上がる。

✍️ 答案の組み立て

  1. 要素A：燃焼でコップ内の酸素が使われて減った。
  2. 要素B：かわりにできた二酸化炭素は、一部が皿の水にとけた。だから気体の量が元より少なく、水面が高いまま。
模範解答：ロウの燃焼によって酸素が減り、発生した二酸化炭素の一部は水に溶けたから。
今回：×。答案「コップ内は外の熱が伝わりにくく、冷めにくいから」。部品を拾えなかった＝設問の「温度が実験前の温度にもどっても」に丸がなく、温度（冷めない）で説明してしまった。温度がもどった後の話なので、答えは「気体が減った理由」でないと成り立たない。次は設問の「〜ても」「〜のに」に丸をつけ、その条件で消えた説明を除く。

X3 (6) コップ内に起きたもう一つの変化 記述・15点

👀 まず見るところ

【条件文】部品は「コップ内で」と、ヒントの「石油ストーブ…窓ガラスやアルミサッシに見られる現象」に丸。ストーブの窓＝結露（水蒸気が冷えて水の粒になる）に直して書く → コップの内側がくもる。水蒸気の出どころはロウの燃焼。

📚 前提知識

  • ロウは水素をふくむので、燃えると酸素と結びついて水（水蒸気）ができる（解答冊子）。
  • 水蒸気が冷たい面にふれると、冷やされて小さな水の粒になる＝結露。ストーブをたいた部屋の窓も、燃焼でできた水蒸気が外気で冷えた窓につく。

✍️ 答案の組み立て

  1. 要素A：ロウの燃焼で水蒸気ができた。
  2. 要素B：それがコップの表面で冷やされて水になり、コップの内側がくもる。
模範解答：ロウの燃焼で生じた水蒸気が冷えて水になり、コップの内側がくもること。
今回：×。答案「コップの周りの水蒸気が水になり外側でけつろした」（赤線は「外側」）。部品を拾えなかった＝設問の「コップ内で」に丸がなく、外側の結露を書いた。水蒸気の出どころも「コップの周り」でなく「ロウの燃焼」。ストーブの例と合わせて、燃焼でできた水蒸気が内側で冷える、と置きかえる。
コツ：(5)(6)はセット。ロウが燃える→二酸化炭素（水にとける→水面が上がる）＋水蒸気（冷えて内側がくもる）。この2行を先に書いてから答案にする。

X3 まとめ 55／100点

  • 取れた：(1)(2)(3)。密度・液体の色・状態変化で重さが変わらない、の基本は入っている。
  • 落とした3問のうち(5)(6)は、設問の中の条件「温度がもどっても」「コップ内で」を拾わずに書いた×。記述でも設問の部品に丸をつけてから書く。(4)は「外側から固まる→中央がへこむ」の知識。
