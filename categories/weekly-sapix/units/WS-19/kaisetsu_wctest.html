WS-19 ウィークリーチェック WS-19（WS-18 滑車と輪軸の復習・10問）

WC 全体像 滑車・輪軸・てこ 10問（各10点・100点）

10問すべてが WS-18「滑車と輪軸」の復習。動滑車は「1本のひもはどこでも同じ力で引いている」、輪軸は「重さ×半径が左右で等しい」の2つで決まる。動く長さは、動滑車なら「ひもの本数」、輪軸なら「半径の比」で変わる。

今回は80／100点。(1)は7問すべて正解。落とした(2)B・Cは、棒をつるすひもの力に「棒の重さ20g」を入れ忘れた1つの見落としが、2問分の失点になった形。

WC (1)① 図1・動滑車1個のおもりA 条件文・計算

👀 まず見るところ

【条件文】部品は、ただし書きの「滑車や輪軸の重さは考えない」と図1の「250g」。250gの動滑車を支える左右2本のひもに、それぞれ「125」と書きこむ（図に置く）→ 右の1本が定滑車を回ってAにつながるので、Aはその数のまま。

📚 前提知識

  • 動滑車は左右2本のひもで支えられる。ひもは1本でつながっているので2本の力は同じ＝おもりの重さの半分。
  • 定滑車は力の向きを変えるだけで、大きさは変えない。

🔍 こう読み解く

  1. 250gを支えるのは動滑車の左右2本 → 1本あたり 250÷2＝125g。
  2. 右のひもは定滑車を回ってAへ。向きが変わるだけなので A＝125g。
答え：125g
今回：125g ○。図1の2本のひもに「125」と書きこんでから答えている。

WC (1)② 図2・ひも3本で支える動滑車 条件文・計算

👀 まず見るところ

【条件文】部品は図2の「600g」と、動滑車から上へ出ているひもの本数。ひもをたどると、左の定滑車から動滑車の上に1本、動滑車の左右に2本＝3本が600gを支えている。3本すべてに「200」と書く（図に置く）→ その続きがBなので、Bも同じ数。

📚 前提知識

  • つながった1本のひもは、どこを切っても同じ力で引いている。おもりの重さを、動滑車を支えるひもの本数で割る。
  • 定滑車を何個通っても、力の大きさは変わらない。

🔍 こう読み解く

  1. 動滑車を上に引くひもは、左1本＋真上1本＋右1本の3本。
  2. 600÷3＝200g。ひも1本の力が200g。
  3. 右のひもは右の定滑車を回ってBへ → B＝200g。
答え：200g
今回：200g ○。

WC (1)③ 図2・600gを30cm上げるとき引く長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「30cm上げる」と、②で決めた「ひも3本」。動滑車が上がると3本のひもがそれぞれ30cm短くなるので、引く長さは「30×3」に直して書く。

📚 前提知識

  • 動滑車は、力が本数分の1になるかわりに、引く長さは本数倍になる。
  • 「力×長さ」はどちら側でも同じ（600×30 と 200×90）。検算に使える。

🔍 こう読み解く

  1. 動滑車が30cm上がると、支えている3本のひもがそれぞれ30cmずつ短くなる。
  2. 短くなった分は全部Bの側に出てくる → 30×3＝90cm。
  3. 検算：600×30＝18000、200×90＝18000 で同じ。
答え：90cm
今回：90cm ○。

WC (1)④ 図2・Bの下に300gを足したとき 条件文・計算

👀 まず見るところ

【条件文】部品は「Bの下に300g」と、②と変わった求めるもの「600gのおもりの下に何g」に丸。B側は「200＋300＝500」に直して書く → ひも1本の力が500gになり、動滑車側は3本分で決まる。

📚 前提知識

  • ひも1本の力＝Bの側につるした重さの合計。動滑車の側は「ひもの本数×1本の力」で支えられる。

🔍 こう読み解く

  1. B側の合計 200＋300＝500g → ひも1本の力が500g。
  2. 動滑車を支える3本で 500×3＝1500g。
  3. すでに600gがあるので、足すのは 1500−600＝900g。
答え：900g
今回：900g ○。

WC (1)⑤ 図3・輪軸のおもりE 条件文・計算

👀 まず見るところ

【条件文】部品は「半径の比は1：2：3」と、図3でどのおもりがどの輪にかかっているか。Cは外の輪（3）、Dはいちばん内側（1）で左側、Eはまん中の輪（2）で右側。ひもの横に「重さ×半径」を書く（直して書く）→ 左右で等しくすればEが決まる。

📚 前提知識

  • 輪軸はてこと同じ。「重さ×半径」を左回りと右回りで等しくする。半径は比のまま使ってよい。

🔍 こう読み解く

  1. 左回り（C・D）：100×3＋100×1＝400。
  2. 右回り（E）：E×2＝400 → E＝200g。
答え：200g
今回：200g ○。余白に「300 100 → 400」と書いてから答えている。

WC (1)⑥⑦ 図3・Eを10cm引き下げたときのC・D 条件文・計算

👀 まず見るところ

【条件文】部品は「Eを10cm引き下げる」と、Eの半径「2」。輪軸は一体で回るので、「半径2で10cm」を「半径1あたり5cm」に直して書く → あとは各おもりの半径をかけるだけ。

📚 前提知識

  • 輪軸の3つの輪は同じ角度だけ回る。だから動く長さは半径に比例（半径1：2：3なら長さも1：2：3）。
  • Eが下がる側と反対側にあるC・Dは上がる。

🔍 こう読み解く

  1. E（半径2）が10cm下がる → 半径1あたり 10÷2＝5cm。
  2. ⑥ Cは半径3 → 5×3＝15cm上がる。
  3. ⑦ Dは半径1 → 5×1＝5cm上がる。
答え：⑥ 15cm　⑦ 5cm
今回：⑥ 15cm ○　⑦ 5cm ○。

WC (2)A 棒のつり合い・おもりA 条件文・てこ

👀 まず見るところ

【条件文】部品は「重さ20gの棒の中心をひもでつるし」と、図の「10cm・30g」「6cm・A」。支点が棒の中心なので、棒の20gは支点の真下にあって回転には効かない。ただし次のB・Cで使うので、棒のまん中に矢印20gを書いてから左右の「重さ×きょり」を出す。

📚 前提知識

  • 支点から左右の「重さ×きょり」が等しいとつり合う。
  • 支点の真上・真下にある重さは棒を回さないが、棒をつるすひもには全部かかる。

🔍 こう読み解く

  1. 左回り：30×10＝300。
  2. 右回り：A×6＝300 → A＝50g。
  3. ここで棒のまん中に「20g」の矢印を置いておく。B・Cはこの矢印から始まる。
答え：50g
今回：50g ○。

WC (2)B・C 棒ごとつるしたときのB・C 条件文・滑車の組み合わせ

👀 まず見るところ

【条件文】部品は「重さ20gの棒」「重さ20gの動滑車」と「つり合わせた棒とおもりB・Cをつるして全体がつり合う」（20gは棒と動滑車の2か所にある）。棒をつるすひもには 30＋A＋棒の20 が全部かかる → 棒のまん中に矢印20gを置き、ひもに「100」と書く（図に置く）。このひもは定滑車と動滑車を通ってCまで1本なのでC＝100、動滑車はその2本分で持ち上げられ、そこから動滑車の20gを引く。

📚 前提知識

  • 棒をつるすひもの力＝棒にぶら下がるもの全部＋棒の重さ。てこの計算で消えた20gは、ここでもどってくる。
  • 1本のひもはどこでも同じ力。動滑車は左右2本で支えられ、そこからBと動滑車の重さ20gを分け合う。

🔍 こう読み解く

  1. 棒をつるすひも＝30＋50＋20＝100g。
  2. このひもは左・中・右の定滑車と動滑車を通って1本でCまで → C＝100g。
  3. 動滑車は左右2本で 100×2＝200g 持ち上げられる。動滑車の重さ20gを引いて B＝200−20＝180g。
答え：B 180g　C 100g
今回：B 140g ×／C 80g ×。部品の形を直さなかった＝「重さ20gの棒」を図の矢印にせず、ひもの力を 30＋50＝80 で出している（図の書きこみも80・160）。動滑車の20gを引く手順（160−20）は合っているので、直すのは入口の1か所。次は棒のまん中に矢印20gを書いてからひもの力を出す。
コツ：てこの計算で使わなかった数（支点の真下の重さ）は、次の小問で使うためにある。図に矢印で残しておくと消えない。

WC まとめ 80／100点

  • 取れた：(1)①〜⑦と(2)A。動滑車の「本数で割る」、輪軸の「重さ×半径」、動く長さの「本数倍・半径の比」まで、WS-18の見方が全部使えている。
  • 落とした(2)B・Cは入口の1か所。棒の重さ20gを図に置かず、ひもの力が80gになった。100gと置ければ、あとの手順は答案どおりで180・100になった。
  • 覚え直しはこの1つ：つるすひもの力＝ぶら下がるもの全部＋棒や動滑車の重さ。てこで消えた重さも、ひもには全部かかる。
