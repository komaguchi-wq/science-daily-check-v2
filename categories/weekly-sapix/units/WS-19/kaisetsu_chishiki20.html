WS-19 知識の20題 確認テスト WS-19（電流・てこ・浮力・溶解度・天体・生物の一問一答＋計算）

K20 全体像 知識の20題 各5点×20問（100点）

物理・化学・地学・生物が順に並ぶ、全分野の総復習テスト。20問のうち計算で決まるのは(1)〜(6)・(8)〜(10)の9問、残り11問は知っていれば即答できる一問一答。計算の9問は「どの式（決まり）を使うか」を余白に1行書いてから数字を入れると、5点問題に見合う短さで解ける。

このテストはまだ解いていないので、各カードの「答え」を隠して自分で解き、答え合わせに使う。一問一答は答えの語だけでなく、「なぜそうなるか」の1行までセットで確かめる。

K20 (1)(2) 4本のニクロム線の電流と発熱 条件文・並べかえ

👀 まず見るところ

【条件文】部品は「長さ20cm…A・C、40cm…B・D」「太さは4本とも同じ」→ 図1の各線の横に抵抗 1・2・1・2 と直して書く。もう1つの部品は答え方「例にならって」（＝と＞を使う）に丸 → 3つの列の抵抗が 1・2・3 になり、電流は逆の比で決まる。

📚 前提知識

  • ニクロム線の抵抗は長さに比例する（太さが同じなら）。並列の各列には同じ電圧がかかるので、電流は抵抗に反比例。
  • 発熱量は、並列では「電流が大きい列ほど大きい」、直列（同じ電流）では「抵抗が大きい線ほど大きい」（解答冊子）。

🔍 こう読み解く

  1. 列ごとの抵抗：A＝1、B＝2、C＋D＝1＋2＝3。電流は反比例なので A：B：(C＝D)＝6：3：2。CとDは同じ列を流れる1本の電流なので等しい → (1) A＞B＞C＝D。
  2. (2) 温度上昇＝発熱量。並列の3列は電流の大きい順に A＞B＞（CとDの列）。
  3. CとDは電流が同じなので抵抗の大きいD＞C。つなげて A＞B＞D＞C。
答え：(1) A＞B＞C＝D　(2) A＞B＞D＞C
コツ：(1)と(2)でCとDの順だけが変わる。「電流は同じでも、抵抗が大きい方が熱くなる」の1行を、CとDの横に書いてから(2)へ。

K20 (3)(4) ばねばかりで支えた棒（図2） 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「棒の重さは考えません」に丸（上向きの力はばねばかりAだけ）と、図2の「12cm・12cm」を、左端からの距離 0・12・24 に直して書く。3個のおもりの合計がA、左端を支点にした回転のつり合いがB、と決まる。

📚 前提知識

  • 棒が止まっているとき、上向きの力の合計＝下向きの力の合計。上向きはばねばかりだけなので、Aはおもりの合計。
  • 回転のつり合いは「力×支点からの距離」。支点はどこに取ってもよく、力が集まっている端に取ると式が短い（解答冊子は左端）。

🔍 こう読み解く

  1. (3) A＝175＋50＋75＝300g。
  2. (4) 左端を支点にする。右回り＝50×12＋75×24＝600＋1800＝2400。左回り＝300×B。
  3. 300×B＝2400 → B＝8cm。175gは支点の真下なので式に入らない。
答え：(3) 300g　(4) 8cm
コツ：Bは「左端からばねばかりまで」の長さ。図の弧の矢印がどこからどこまでかを先に丸で確かめてから式を書く。

K20 (5)(6) 氷を浮かべたメスシリンダー（図3） 条件文・浮力

👀 まず見るところ

【条件文】部品は「10gで11cm³の氷」「100mLの水」に丸。氷が浮いている＝浮力10g＝水中にある体積10cm³、に直して書く → 目もりは水100mLに水中の体積だけ足した値になり、(6)の「すべてとけた」も同じ10cm³で決まる。

📚 前提知識

  • 浮いている物体は、重さ＝浮力。水の浮力は「水中の体積（cm³）×1g」なので、10gの氷は水中に10cm³だけ沈む。残り1cm³が水面の上に出ている。
  • 氷がとけると、10gの氷は10gの水＝10cm³の水になる（解答冊子）。

🔍 こう読み解く

  1. (5) 目もりは、水100mL＋水中の氷10cm³＝110mL。11cm³ではないことに注意。
  2. (6) とけた氷は10cm³の水になる。水100mL＋10mL＝110mLで変わらない。蒸発はないので減りもしない。
答え：(5) 110mL　(6) 110mL
コツ：「浮いている氷がとけても水面は変わらない」を1行で。(5)に11cm³をそのまま足したら、浮力の部品を直していない合図。

K20 (7) BTB液が黄色になるもの 知識問題

イ・ウ。BTB液は酸性で黄色、中性で緑、アルカリ性で青。うすい硫酸とレモン汁は酸性。オキシドールは中性、灰汁（草木の灰を水にとかした液）はアルカリ性で青になる。「すべて選びなさい」なので、4つ全部に酸・中・アルカリを書いてから答える。
答え：イ・ウ

K20 (8) 飽和ホウ酸水を冷やしたときの結晶 条件文・溶解度の計算

👀 まず見るところ

【条件文】部品は「60℃で飽和状態のホウ酸水を200g」（水ではなく水溶液の重さ）と「20℃に冷やした」に丸。表1の60℃＝14.9・20℃＝4.9を、「水100g＋14.9g＝水溶液114.9gにつき、出てくる結晶10g」に直して書く → 200gは114.9gの何倍か、で決まる。

📚 前提知識

  • 飽和水溶液を冷やすと、（高い温度の溶解度）−（低い温度の溶解度）のぶんが結晶として出る。ただし表の数値は「水100g」あたりなので、水溶液の重さで聞かれたら水溶液114.9gに直してから比べる。

🔍 こう読み解く

  1. 水100gで作った60℃の飽和水溶液は 100＋14.9＝114.9g。これを20℃にすると、14.9−4.9＝10gが結晶になる。
  2. この問題は水溶液200g。結晶は 10×200/114.9＝17.40… → 小数第2位を四捨五入して 17.4g。
答え：17.4g
コツ：「飽和水溶液○g」と「水○g」のどちらで書かれているかに丸。水200gと読むと 10×2＝20g になり、5点を落とす。

K20 (9) ふっとうさせて60℃に戻したときの沈殿 条件文・溶解度の計算

👀 まず見るところ

【条件文】部品は「60℃で飽和」「200g→150g」「60℃に戻した」に丸。減った50gは蒸発した水、に直して書く → 温度は同じなので、なくなった水50gにとけていた分がそのまま沈殿になる。

📚 前提知識

  • 飽和水溶液から水を蒸発させると、蒸発した水にとけていた分だけ結晶が出る。温度が同じなら溶解度は変わらない（解答冊子）。

🔍 こう読み解く

  1. 200−150＝50g。ふっとうで出ていくのは水なので、水が50g減った。
  2. 60℃の水100gには14.9gとける → 水50gなら 14.9×50/100＝7.45g。割り切れているので四捨五入は不要。
答え：7.45g
コツ：(8)は「温度が変わる」、(9)は「水が減る」。どちらの型かを1語で書いてから式を選ぶ。

K20 (10) 冬至と夏至の南中高度の差 条件文・南中高度

👀 まず見るところ

【条件文】部品は「南中高度の差」に丸（高さそのものではない）と「23.4度」。夏至＝90−緯度＋23.4、冬至＝90−緯度−23.4 の2本を余白に書く → 差をとると緯度が消え、23.4×2で決まる。北緯36度は答えには使わない。

📚 前提知識

  • 春分・秋分の南中高度は 90−緯度。夏至はそれより23.4度高く、冬至は23.4度低い（地軸の傾きのぶん）。

🔍 こう読み解く

  1. 夏至：90−36＋23.4＝77.4度。冬至：90−36−23.4＝30.6度。
  2. 差：77.4−30.6＝46.8度（＝23.4＋23.4）。
答え：46.8度

K20 (11) 3時ごろ南東に見える月の作図 条件文・作図

👀 まず見るところ

【条件文】部品は「3時頃」（午前3時＝真夜中と日の出の間）「南東」と、答え方「見えない部分は斜線」「傾きも考えて」に丸。「南東で3時＝あと3時間で南中する月＝下弦の月」に直して書く → 半月で、光る側は太陽のある左下、と決まる。

📚 前提知識

  • 下弦の月は真夜中（0時）に東からのぼり、午前6時ごろ南中する。だから午前3時には南東にある。
  • 月が光るのは太陽のある側。午前3時の太陽は東の地平線の下（左下）にあるので、南東の月は左下が光り、右上が暗い。

🔍 こう読み解く

  1. 時刻と方位から月の形を決める：午前3時・南東 → 下弦の月（左半分が光る半月）。
  2. 傾きを決める：南東の空では、太陽は左下にある → 光る側を左下に向けて、境目の直線を左上から右下へ引く。
  3. 右上の暗い半分に斜線を引いて完成（解答冊子の図）。
答え：左下半分が明るく、右上半分に斜線の半月（下弦の月・境目は左上から右下）
コツ：作図の順は「形（満ち欠け）→ 光る向き（太陽の側）→ 斜線」。傾きは「太陽はどっちにあるか」を矢印で1本描いてから決める。「3時頃」を午後3時と読むと、南東にあるのは上弦の月で光る側は右になる。解答冊子の図は左下が明るいので午前3時の月。両方をセットで確かめる。

K20 (12) 冬の大三角で表面温度が最も低い星 知識問題

ベテルギウス。冬の大三角は、ベテルギウス（オリオン座・赤）、シリウス（おおいぬ座・白）、プロキオン（こいぬ座・黄白）。星の色は表面温度で決まり、赤い星ほど低温、青白い星ほど高温。3つのうち赤いベテルギウスが最も低い。
答え：ベテルギウス

K20 (13) (12)の星がある星座 知識問題

オリオン座。ベテルギウスはオリオン座の左上（赤）、右下の青白い1等星がリゲル。(12)で星を取りちがえると(13)も連動して落ちるので、「ベテルギウス＝オリオン座の赤い肩」で1セットにする。解答らんの「座」は印刷済みなので「オリオン」だけ書く。
答え：オリオン（座）

K20 (14) ふりこの等時性を発見した科学者 知識問題

ガリレオ・ガリレイ。17世紀のイタリアの科学者で、ふりこの周期は振れ幅を変えても変わらない（等時性）ことを見つけた。物体の落下運動の実験や地動説でも知られる（解答冊子）。「・」を入れてフルネームで書く。
答え：ガリレオ・ガリレイ

K20 (15) 種子でふえるもの 知識問題

ア・イ。種子でふえるのは種子植物＝マツ（裸子植物）とタンポポ（被子植物）。胞子でふえるのは、イヌワラビ（シダ類）、コンブ（ソウ類）、マツタケ（菌類・植物ではない）。「すべて選ぶ」なので5つ全部に「種子／胞子」を書いてから答える。
答え：ア・イ

K20 (16) メダカのオス・メスを見分けるひれ 知識問題

背びれ・しりびれ。オスは背びれに切れこみがあり、しりびれは平行四辺形に近い形。メスは背びれに切れこみがなく、しりびれは後ろが細い三角形に近い。「すべて答えなさい」なので2つとも書く。胸びれ・腹びれ・尾びれでは区別できない。
答え：背びれ・しりびれ

K20 (17) モンシロチョウの幼虫の呼び名 知識問題

アオムシ。キャベツなどアブラナ科の葉を食べて育つ緑色の幼虫。モンシロチョウは卵→アオムシ→さなぎ→成虫の完全変態で、(18)の「さなぎの時期がある」側。「イモムシ」は毛のない幼虫のまとめた呼び名なので、モンシロチョウ専用の「アオムシ」で答える。
答え：アオムシ

K20 (18) さなぎの時期のない昆虫 知識問題

ウ・エ・カ・コ。さなぎにならない＝不完全変態は、カメムシ、ヒグラシ（セミ）、アキアカネ（トンボ）、ショウリョウバッタ（バッタ）。「セミ・トンボ・バッタ・カマキリ・カメムシ・ゴキブリ」を1セットで覚える。残りのゲンジボタル・テントウムシ・カミキリムシ（甲虫）、イエバエ・アカイエカ（ハエ・カのなかま）、クロオオアリ（ハチのなかま）は完全変態。10個全部に「完／不」を書いてから答える。
答え：ウ・エ・カ・コ

K20 (19) 握りこぶし大で左右に2つある器官 知識問題

じん臓。ソラマメのような形で腰のあたりに左右1つずつあり、血液中の不要物（尿素・アンモニア・塩類・余分な水分）をろ過して尿をつくる（解答冊子）。「左右に2つ」と「不要物をこしとる」の2語で肝臓（1つ・大きい）と区別する。
答え：じん臓

K20 (20) 太古から姿がほぼ変わらない生き物 知識問題

生きている化石。シーラカンス、メタセコイア、イチョウ、カブトガニ、オウムガイなど（解答冊子）。大昔の化石とほぼ同じ姿で今も生きているので、この呼び名。「シーラカンス」のように例を答えないよう、設問の「何と呼びますか」に丸。
答え：生きている化石

K20 自分で解くときのチェック 3つ

  • 計算9問は、式を書く前に「部品を直す」1行：(1)(2)抵抗1・2・1・2／(3)(4)左端を支点／(5)(6)浮力10g＝水中10cm³／(8)水溶液114.9gにつき結晶10g／(9)減った50gは水／(10)差なら緯度は消える。
  • 「すべて選びなさい」「すべて答えなさい」の(7)(15)(16)(18)は、選択肢ぜんぶに印をつけてから答えを書く。1つ見つけて終わりにしない。
  • (11)の作図は「形 → 光る向き（太陽の側）→ 斜線」の順。(12)(13)は連動するので、ベテルギウス＝オリオン座の赤い星、で1セット。
