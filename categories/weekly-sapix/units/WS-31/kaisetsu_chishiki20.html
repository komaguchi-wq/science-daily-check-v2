K20 (1) 電磁石の磁力の強い順 条件文・回路

👀 まず見るところ

【条件文】部品は「電磁石と豆電球1個の抵抗の大きさが同じ」。電磁石も豆電球も「抵抗1」と図に書きこみ、回路ごとの合計の抵抗を「電流＝1÷抵抗」に直して書く → 電磁石を流れる電流の順が磁力の順。

📚 前提知識

  • 電磁石はどれも同じもの（巻き数が同じ）なので、磁力は流れる電流の大きさだけで決まる。
  • 同じ豆電球2個の並列は、通り道が2本になるので合わせて抵抗1/2。直列は足し算で抵抗2。

🔍 こう読み解く

  1. ア：電磁石と豆電球オは並列。電磁石は電池に直接つながっているのと同じで、抵抗1 → 電流1。
  2. イ：電磁石＋豆電球1個の直列で抵抗2 → 電流1/2。エ：電磁石＋豆電球2個の直列で抵抗3 → 電流1/3。
  3. ウ：電磁石1＋並列の豆電球1/2で抵抗1と1/2 → 電流2/3。
  4. 大きい順に 1＞2/3＞1/2＞1/3 → ア＞ウ＞イ＞エ。
答え：ア＞ウ＞イ＞エ
自分で解くときのチェック：4つの図の横に、電磁石を流れる電流（1・1/2・2/3・1/3）を書いてから順に並べる。

K20 (2) 豆電球オ〜クの明るい順 条件文・回路

👀 まず見るところ

【条件文】部品は(1)と変わった「豆電球オ〜ク」に丸。(1)で図に書いた電流を使い、今度は豆電球1個を流れる電流に直して書く。並列のキは、ウの電流2/3を2個で分ける。

📚 前提知識

  • 同じ豆電球なら、流れる電流が大きいほど明るい。
  • 並列の2個には、もとの電流が半分ずつ分かれて流れる。直列の2個には同じ電流がそのまま流れる。

🔍 こう読み解く

  1. オ：電磁石と並列で、電池に直接つながる。電磁石の抵抗はかからない（解答冊子）→ 電流1。
  2. カ：イの回路の電流がそのまま流れる → 1/2。
  3. キ：ウの電流2/3を2個で分ける → 1/3。ク：エの電流がそのまま流れる → 1/3。
  4. オ＞カ＞キ＝ク。キとクは「＝」でつなぐ。
答え：オ＞カ＞キ＝ク
コツ：(1)は「電磁石を流れる電流」、(2)は「豆電球1個を流れる電流」。ウの回路だけ2つの数がちがう（2/3と1/3）ので、図に両方書いておく。

K20 (3) 2つの台ばかりにのせた棒（おもりが左端から10cm） 条件文・てこ

👀 まず見るところ

【条件文】部品は「太さが一様な350gの棒」と「左端から10cm」。350gは棒のまん中（左端から20cm）に矢印で置く（直して書く）。支点の間は35cmなので、きょりを「おもり10：25」「棒20：15」と図に書く。

📚 前提知識

  • 2つの支点でささえるとき、重さは支点までのきょりの逆比で分かれる。近い支点のほうが大きくなる。
  • 図1の支点は、Aが棒の左端、Bが右端から5cmの所。支点の重さは考えない。

🔍 こう読み解く

  1. おもり420g：AとBまでのきょりは10cm：25cm＝2：5 → かかる力はA：B＝5：2 → A 300g、B 120g。
  2. 棒350g：きょりは20cm：15cm＝4：3 → 力はA：B＝3：4 → A 150g、B 200g。
  3. Bは 120＋200＝320g。
答え：320g
自分で解くときのチェック：Aは300＋150＝450g。A＋B＝770g＝420＋350 になっていれば合っている。

K20 (4) おもりを棒の右端に動かしたとき 条件文・てこ

👀 まず見るところ

【条件文】部品は(3)と変わった「棒の右端」と、求めるものが「Aの台ばかり」に変わったことに丸。右端はBの支点より5cm外側と図に書く → おもりはBを支点に棒の左側を持ち上げる向きにはたらく。

📚 前提知識

  • 支点の外側にのせたおもりは、反対側の台ばかりを軽くする。逆比で分ける方法はそのまま使えないので、Bを支点にしたつり合いの式で考える。

🔍 こう読み解く

  1. Bを支点にする。Bから、棒のまん中まで15cm（左）、Aまで35cm（左）、おもりまで5cm（右）。
  2. 棒が左を下げるはたらき：350×15＝5250。おもりが右を下げるはたらき：420×5＝2100。
  3. 差の 5250−2100＝3150 をAがささえる → 3150÷35＝90g。
答え：90g
自分で解くときのチェック：Bは 770−90＝680g。おもりがBの外側にあるので、Bが合計に近い大きな数になる。

K20 (5) アルコールに浮かぶ木片の液面下の体積 条件文・浮力

👀 まず見るところ

【条件文】部品は「1Lあたりの重さが800g」と「浮かべた」。「1Lあたり」は 800÷1000＝1cm³あたり0.8g に直して図の横に書く。浮いている＝浮力は木片の重さと同じ72g、も書く。

📚 前提知識

  • 浮力＝おしのけた液体の重さ。水なら1cm³で1gだが、このアルコールは1cm³で0.8g。
  • 浮いて止まっているものは、重さと浮力がつり合っている。

🔍 こう読み解く

  1. 浮力＝木片の重さ＝72g。
  2. 72gぶんのアルコールの体積が、液面下の体積 → 72÷0.8＝90cm³。
答え：90cm³
コツ：72cm³と答えたら、水（1cm³＝1g）で計算している合図。液体の名前を見たら、先に1cm³あたりの重さを書く。

K20 (6) 木片を完全に沈めるおもり 条件文・浮力

👀 まず見るところ

【条件文】部品は(5)と変わった「完全に沈める」に丸。液面下の体積が90cm³から木片全体の120cm³に変わる、と図に書く → ふえた30cm³ぶんの浮力が、のせるおもりの重さ。

📚 前提知識

  • 全部沈めたときの浮力は、木片全体の体積ぶんの液体の重さ。それが「木片＋おもり」の重さとつり合う。

🔍 こう読み解く

  1. 今の状態からさらにおしのける体積：120−90＝30cm³。
  2. そのぶんのアルコールの重さ：30×0.8＝24g。
  3. 確かめ：全部沈めた浮力 120×0.8＝96g。96−72＝24g で同じ。
答え：24g

K20 (7) 坂を転がる金属球が0.6秒間に進むきょり 資料問題・規則

👀 まず見るところ

【資料問題】資料の正体は「0.1秒ごとの球の位置・目盛り1cm」。図3の球は5個＝0.4秒ぶんしかなく、求めるのは「0.6秒間」。球と球の間の目盛りを数えて図に書く → 1・3・5・7と2cmずつふえる決まりで先をのばす。

📚 前提知識

  • 坂を転がる球はだんだん速くなるので、同じ0.1秒でも進むきょりが一定の数ずつふえていく。

🔍 こう読み解く

  1. 図3の球の位置は、はじめから 0・1・4・9・16cm。間は 1・3・5・7cm。
  2. つづきの0.1秒は 9cm、その次は 11cm。
  3. 0.6秒間の合計：1＋3＋5＋7＋9＋11＝36cm。
答え：36cm
コツ：図の最後の球（16cm）をそのまま答えにしない。「何秒ぶんの図か」を球の数−1で先に数える。

K20 (8) プロパンの燃焼で使われた酸素 条件文・化学計算

👀 まず見るところ

【条件文】部品は「1.1g」「3.3g」「1.8g」。文のままでは式にならないので「プロパン＋酸素→二酸化炭素＋水」と書き、下に数字を置く（直して書く）→ 左と右の重さの合計が同じ、で酸素が決まる。

📚 前提知識

  • 燃焼などの化学変化では、前後で重さの合計は変わらない（解答冊子）。物質が組みかわるだけで、なくなったりふえたりしないから。

🔍 こう読み解く

  1. プロパン1.1g＋酸素□g → 二酸化炭素3.3g＋水1.8g。
  2. □＝3.3＋1.8−1.1＝4.0。
答え：4g

K20 (9) プロパンにふくまれる炭素と水素の重さの比 条件文・化学計算

👀 まず見るところ

【条件文】部品は「3gの炭素→11gの二酸化炭素」と、(8)の「炭素と水素が結合…他の物質は含まれていません」。(8)の二酸化炭素3.3gの下に「炭素は 3/11」と直して書く → 炭素が出れば、残りが水素。

📚 前提知識

  • 二酸化炭素の中の炭素は、すべてプロパンから来ている（酸素には炭素がふくまれない）。
  • プロパンは炭素と水素だけなので、プロパンの重さ−炭素の重さ＝水素の重さ。

🔍 こう読み解く

  1. 二酸化炭素11gに炭素3g。3.3gは11gの 3.3/11 なので、炭素は 3×3.3/11＝0.9g。
  2. 水素：1.1−0.9＝0.2g。
  3. 炭素：水素＝0.9：0.2＝9：2。
答え：9：2
コツ：答えの順は「炭素と水素」。比を書く直前に、設問のならび順をもう一度見る。

K20 (10) 塩酸が手についたとき 知識問題

イ（水で十分に洗い流す）。まず多量の流水で洗い流す（解答冊子）。水でうすめながら流し去るのがいちばん早くて安全。ウの水酸化ナトリウム水溶液は、それ自体が皮ふをいためるうえ、ちょうど中和する量は分からないので使わない。
答え：イ

K20 (11) カキとリンゴで子房が変化した部分 資料問題・果実の図

👀 まず見るところ

【資料問題】資料の正体は「カキとリンゴの果実の断面・①〜⑥」。聞かれ方は「子房が変化した部分」を「それぞれ1つ」。番号の横に部分の名前（食べる所・へた・種子・しん）を書いてから選ぶ。

📚 前提知識

  • 子房は種子（もとは胚珠）をじかに包む部分。カキは子房がそのまま食べる部分になる。
  • リンゴは、子房ではなく花たくが成長した部分を食べる（解答冊子）。子房は種子のまわりの「しん」になる。

🔍 こう読み解く

  1. カキ：①食べる部分、②へた（がく）、③種子 → 子房は①。
  2. リンゴ：④食べる部分（花たく）、⑤がくなどのあと、⑥種子を包むしん → 子房は⑥。
答え：カキ ①　リンゴ ⑥
コツ：リンゴで④を選びたくなったら「食べる部分」と「子房」を分けて考える。聞かれているのは子房。

K20 (12) 食用部分がリンゴと同じもの 知識問題

エ（イチゴ）とオ（ビワ）。リンゴ・ナシ・イチゴ・ビワは、子房ではなく花たくが成長した部分を食べる（解答冊子）。ブドウ・モモ・サクランボは子房が成長した部分を食べる。「2つ選びなさい」なので2つ書く（順不同）。
答え：エ・オ

K20 (13) フナの器官のうちヒトにないもの 資料問題・解剖図

👀 まず見るところ

【資料問題】資料の正体は「フナの解剖図・ア〜ケ」。聞かれ方は「ヒトにはない」を「すべて」。水中でくらすための器官＝えら・うきぶくろ・側線の3つを図でさがし、記号の横に名前を書く。

📚 前提知識

  • 魚類には、水中で呼吸するためのえら、浮力を得たりバランスを取ったりするうきぶくろ、水の圧力や流れを感じる側線がある（解答冊子）。
  • 目・口・心臓・消化管などはヒトにもある。

🔍 こう読み解く

  1. ウ：目のうしろのくし形の部分 → えら。
  2. カ：背骨の下の白いふくろ → うきぶくろ。
  3. ケ：体の横を通る点線 → 側線（(14)の問題文にも「ケは側線」とある）。
答え：ウ・カ・ケ
自分で解くときのチェック：「すべて」なので、ア〜ケの9つ全部に○×をつけてから書く。

K20 (14) 側線のはたらき 知識問題

イ（水圧や水流を感じ取る）。側線は体の横にならぶ点線状の器官で、水の圧力や流れを感じる（解答冊子）。においを感じるのは鼻、塩分の調節はえらやじん臓の仕事なので、ウ・エとは区別する。
答え：イ

K20 (15) 心臓で動脈血が流れている部屋 知識問題

左心房・左心室。肺で酸素を受け取った動脈血は、肺静脈→左心房→左心室の順に流れて全身へ送り出される（解答冊子）。右心房・右心室は全身からもどった静脈血。「すべて」なので2つとも書く。
答え：左心房・左心室

K20 (16) 棒の影の記録でA点は何時か 資料問題・影の動き

👀 まず見るところ

【資料問題】資料の正体は「7時から16時まで1時間ごとの影の先端・10個の点」。図6に方位（上＝北、左＝西、右＝東）を書きこむ。影は西から東へ動くので、左はしの点＝7時として順に時刻を書く。

📚 前提知識

  • 太陽は東→南→西と動くので、影の先は西→北→東と動く。
  • 関東地方では正午より前に太陽が南中する（解答冊子）。だから12時の影は、真北の線を少し東へすぎた所にある。

🔍 こう読み解く

  1. 左（西）はしの点から 7・8・9・10・11時。ここまでの5個が北の線より西側。
  2. 北の線のすぐ東の点が12時、次が13時。
  3. その次のA点が14時。残りの2個が15・16時で、合わせて10個になる。
答え：14時
コツ：「北の線に近い点＝12時」と決めつけず、左はしの7時から数える。右はしが16時になれば合っている。

K20 (17) 半年後の影の動き 資料問題・季節

👀 まず見るところ

【資料問題】部品は図6の線が、両はしで東西の線より南側（下）にのびていることと、設問の「半年後」に丸。影が南にものびる＝夏至ごろ、と図6に書く → 半年後は冬至ごろの線をえらぶ。

📚 前提知識

  • 夏至ごろは、太陽が真東より北からのぼり、真西より北にしずむ。朝夕の影は南側にのびる。
  • 冬至ごろは、太陽が真東より南からのぼり、昼も低い。影は一日じゅう北側にあり、長い。

🔍 こう読み解く

  1. 図6は影が南にものびている → 夏至ごろ（解答冊子）。半年後は冬至ごろ。
  2. 冬至ごろの線：棒から北へはなれた所にあり、東西の線より下には来ない。両はしは北へそる。
  3. これに合うのはエ。イのような東西にまっすぐな線は、春分・秋分のころの形。
答え：エ

K20 (18) 3か月後の同じ時刻の北斗七星 条件文・星の動き

👀 まず見るところ

【条件文】部品は「5月10日」「8月10日の同時刻」。日付の差を「3か月→30度×3＝反時計回りに90度」と直して図7の横に書く。図7は12等分＝1目盛り30度なので、アから3目盛り進める。

📚 前提知識

  • 同じ時刻に見ると、北の空の星は北極星を中心に反時計回りに1か月で約30度進む（地球の公転のため・解答冊子）。

🔍 こう読み解く

  1. 5月10日20時、Aの星は北極星Pの真上＝アの位置。
  2. 3か月で90度。反時計回り（左回り）に ア→シ→サ→コ。
答え：コ
コツ：回す向きを図7に矢印で書いてから数える。時計回りに数えるとエになってしまう。

K20 (19) 10月10日4時の北斗七星 条件文・星の動き

👀 まず見るところ

【条件文】部品は(18)と変わった「10月10日」と「4時」。日付と時刻の両方がちがうので、「①月：5か月→150度」「②時刻：20時→4時」と2段に分けて書き、1つずつ図7で動かす。

📚 前提知識

  • 月のずれ：同じ時刻なら1か月に30度、反時計回り（公転）。
  • 時刻のずれ：同じ日なら1時間に15度、反時計回り（日周運動）。前の時刻にもどすときは時計回り。

🔍 こう読み解く

  1. ①10月10日20時：5月10日から5か月 → 30×5＝150度。アから反時計回りに5目盛り → ク。
  2. ②10月10日4時は、20時の16時間前 → 15×16＝240度＝8目盛り、時計回りにもどす（解答冊子）。ク→ケ→コ→サ→シ→ア→イ→ウ→エ。
  3. 確かめ：星は1日でほぼ1周するので、4時は20時の8時間後と見てもよい。15×8＝120度、反時計回りに4目盛り。ク→キ→カ→オ→エ で同じ。
答え：エ

K20 (20) 梅雨前線に関係する気団 知識問題

オホーツク海（気団）。北の冷たいオホーツク海気団と南のあたたかい小笠原気団は、どちらも海の上でできた湿った空気。この2つがぶつかり合う境界で、東西に長くのびた前線が梅雨前線（解答冊子）。
答え：オホーツク海

K20 まとめ 解くときの入口

  • 計算の(1)〜(9)は、直して書く部品が入口。抵抗→電流／棒の重さ→まん中に矢印／1Lあたり800g→1cm³あたり0.8g／文→「プロパン＋酸素→二酸化炭素＋水」。
  • (4)(6)(19)は前の小問と変わった言葉（右端・完全に沈める・10月と4時）に丸をつけてから解く。
  • 知識の組：花たくを食べる＝リンゴ・ナシ・イチゴ・ビワ／魚だけ＝えら・うきぶくろ・側線／動脈血＝左心房・左心室／梅雨＝オホーツク海気団と小笠原気団。
