WC 全体像 メダカ・カイコガ 10問（各10点・100点）

WS-30「生物の基礎」の復習。(1)はメダカ（絶滅危惧種・ふえ方の計算）、(2)はカイコガの知識、(3)はカイコガのオスがメスに近づくしくみを調べる実験。(3)は知識がなくても、【方法】と【結果】を1行ずつ結べば決まる問題になっている。

今回は60／100点。実験の読み取りは(3)①・②A・③が取れている。落とした4問は、計算の途中の「÷2」1つ、「すべて選び」の残り1つ、あしの本数、頭部と尾部の取りちがえで、どれも直す場所がはっきりしている。

WC (1)① 絶滅危惧種になっている野生メダカ 知識問題

ウ（クロメダカ）。野生のメダカ（野メダカ）は体の色が黒っぽいのでクロメダカとよばれる。ペットショップでよく見るだいだい色のヒメダカは、人が飼うために作られた品種で、野生のメダカとは別、と分けておく。
答え：ウ
今回：ウ ○。

WC (1)② 野生メダカの絶滅を防ぐ取り組み 条件文・2つ選ぶ

👀 まず見るところ

【条件文】部品は答え方の「2つ選び」と、求めるものの「絶滅を防ぐ」に丸。ア〜カの横に「すむ場所が残る＝○／すむ場所がこわれる・敵がふえる＝×」と直して書く → 6つ全部に○×をつければ2つ残る。

📚 前提知識

  • 野生メダカが減った理由は、すむ場所がなくなったこと（水田や小川が減る・水路がコンクリートになる・水がよごれる）と、外来の魚に食べられること。
  • メダカは流れのゆるやかな水辺で、水草に卵を産みつける。水草や藻が生えないコンクリートの水路では、卵を産む場所もえさもなくなる。

🔍 こう読み解く

  1. ア「水田や用水路、小川などを残す」→ すむ場所が残る → ○。イ「生活排水の流入を少なく」→ 水がきれいになる → ○。
  2. エ「コンクリート化」→ すむ場所がこわれる → ×。オ「ブラックバスやブルーギルを放流」→ メダカを食べる外来の魚をふやす → ×。
  3. ウ「コケを取り除く」は、メダカのすむ場所を良くすることにならない → ×。カ「たくさん増やして放流」は良さそうに見えるが、解答はア・イ。減った原因（すむ場所）がそのままでは、放しても生き残れない。
答え：ア・イ（順不同）
今回：ア・イ ○。良さそうに見えるカに流されず、「減った原因をなくす」2つを選べている。

WC (1)③ メダカの総数が500匹を超える世代 条件文・計算

👀 まず見るところ

【条件文】部品は6つの条件。「20%はふ化しない」は ×0.8、「ふ化したオスとメスの数は同じ」は ÷2 に直して、世代の図の横に書く。求めるものの「総数」に丸 → 世代ごとの数を出して、500とくらべる。

📚 前提知識

  • 卵を産むのはメスだけ。だから毎回「その世代の数 ÷2 ＝メスの数」を先に出してから ×30 をする。
  • メス1匹から育つ子は 30×0.8＝24匹。この「メス1匹→24匹」を1行書いておくと、あとは「メスの数×24」のくり返しになる。

🔍 こう読み解く

  1. 1世代目：オス1・メス1の2匹。
  2. 2世代目：メス1匹×24＝24匹（オス12・メス12）。
  3. 3世代目：メス12匹×24＝288匹（オス144・メス144）。500匹以下。生き残っている親の世代（2匹と24匹）をたしても314匹で、まだ500匹以下。
  4. 4世代目：メス144匹×24＝3456匹。この世代だけで500匹を大きく超える → 4世代目。親の世代を数えても数えなくても、答えは変わらない。
答え：4世代目
今回：3世代目 ×。部品の形を直さなかった＝メモの 360×4/5＝288 までは正しい。そのあと288を÷2せずに「オス288・メス288」と置いたので、3世代目が576匹になり500を超えた。2世代目では 15×4/5＝12 とオス・メスに分けられていたので、次は「288→144と144」と世代ごとに同じ形で書く。
コツ：世代の図は「合計→÷2→メスの数→×24」を1段ずつ同じ形で書く。段ごとに形がちがうと、÷2がぬけた段に気づけない。

WC (2)① さなぎの時期があるこん虫 条件文・すべて選ぶ

👀 まず見るところ

【条件文】部品は答え方の「すべて選び」に丸。いくつあるか分からないので、ア〜カの6つ全部の横に「さなぎ あり／なし」を書く → 「あり」の記号を全部ならべたものが答え。

📚 前提知識

  • 卵→幼虫→さなぎ→成虫と育つのが完全変態。チョウ・ガ、カブトムシ、ハエ・カ、ハチ・アリのなかま。
  • 卵→幼虫→成虫で、さなぎが無いのが不完全変態。セミ、コオロギ・バッタ、トンボ、カマキリのなかま。幼虫と成虫の形が似ているか、幼虫が脱皮して成虫になる。

🔍 こう読み解く

  1. ア セミ・ウ コオロギ・オ トンボ → さなぎなし。
  2. イ モンシロチョウ（チョウ）・エ カブトムシ → さなぎあり。
  3. カ ショウジョウバエはハエのなかま。うじ（幼虫）→さなぎ→成虫と育つので、さなぎあり。
答え：イ・エ・カ
今回：イ・エ ×。知識＝選んだ2つは合っていて、カのショウジョウバエが入っていない。名前の中の「ハエ」に気づけば、ハエ・カのなかま＝さなぎあり、に入れられる。

WC (2)② カイコガの幼虫のえさ 知識問題

クワ。カイコガの幼虫（カイコ）はクワの葉だけを食べて育ち、まゆを作る。まゆから生糸をとる養蚕（ようさん）のためにクワ畑が作られた、と結びつけておく。
答え：クワ
今回：クワ ○。

WC (2)③ カイコガの幼虫のあしの数 知識問題

16本。こん虫のあしは6本だが、それは成虫の話。チョウやガの幼虫（いも虫）は、胸に成虫のあしになる6本、腹に体をささえるあしが8本、おしりに2本で、合わせて6＋8＋2＝16本。モンシロチョウの幼虫も同じ16本。
答え：16本
今回：14本 ×。知識＝2本足りない。「胸6・腹8・おしり2」と3つに分けて数えると、どこをぬかしたかが分かる。

WC (3)① 「目で見ているのではない」と言える2つの方法 まざり型・実験の比較

👀 まず見るところ

【まざり型→資料問題】部品は下線部の「目で見て」に丸。【方法】の中で目を使えなくしたものをさがす → 方法4「複眼をペンキで塗りつぶした」。これと、何もしていない方法1をならべれば決まる。知識がなくても決まる。

📚 前提知識（あれば答え合わせに使う）

  • 実験の比較は、変えた条件が1つだけの2つをならべる。方法1（何もしない）と方法4（目だけ使えなくする）は、ちがいが「目」だけ。
  • 複眼は、こん虫の頭にある小さな目の集まり。

🔍 こう読み解く

  1. 方法1：ふつうのオス → 結果1「激しく羽ばたきながら、メスに近づいた」。
  2. 方法4：目が見えないオス → 結果4も「激しく羽ばたきながら、メスに近づいた」。
  3. 目が見えても見えなくても結果が同じ → メスを目で見て動いているのではない、と言える。
答え：1 と 4
今回：1と4 ○。問題用紙の方法1と4に丸、結果1と4に線が引いてあり、方法と結果を結んでから答えている。

WC (3)②A オスが物質を受け取る部分 まざり型・実験の比較

👀 まず見るところ

【まざり型→資料問題】部品は「オスの（A）で受け取った」に丸。オスの体の一部を使えなくして、近づかなくなった方法をさがす → 方法3「触角を2本とも切り取ったオス」。使えなくすると反応が消える部分がA。

📚 前提知識（あれば答え合わせに使う）

  • こん虫の触角は、においを感じる部分。カイコガのオスの触角は、くしのように枝分かれしている。

🔍 こう読み解く

  1. 方法3：触角のないオス → 結果3「羽ばたくこともなく、メスに近づくこともなかった」。
  2. 方法4：複眼を使えなくしたオス → 近づいた。だから複眼（イ）ではない。
  3. 無くすと反応が消えたのは触角だけ → A＝触角。
答え：ア
今回：ア ○。

WC (3)②B メスが物質を出す部分 まざり型・実験の比較

👀 まず見るところ

【まざり型→資料問題】部品は「メスの（B）から出され」に丸。メスの体をこすりつけた方法5「頭部」と方法6「尾部の先端」をさがし、それぞれの横に結果を「×（近づかない）」「○（近づいた）」と書く → ○がついた方がB。

📚 前提知識（あれば答え合わせに使う）

  • ろ紙片にはメスの体から出た物質だけがうつる。メスがいなくても、ろ紙片にオスが近づけば、そこから物質が出ていたと言える。

🔍 こう読み解く

  1. 方法5：メスの頭部をこすりつけたろ紙片 → 結果5「羽ばたくこともなく、ろ紙片に近づくこともなかった」。
  2. 方法6：メスの尾部の先端をこすりつけたろ紙片 → 結果6「激しく羽ばたきながら、ろ紙片に近づいた」。
  3. オスが近づいたのは尾部の方だけ → B＝尾部。
答え：エ
今回：ウ（頭部）×。部品を拾えなかった＝方法5・6と結果5・6には印がなく、頭部と尾部の結果が入れかわっている。①のように、方法の番号と結果の番号を線で結んでから選ぶ。
コツ：Aは「無くすと反応が消える方」、Bは「こすりつけると反応が出る方」。Aは×の結果、Bは○の結果をさがす、と向きが逆になる。両方セットで見る。

WC (3)③ 物質が移動できるもの・通過できないもの まざり型・ことばを入れる

👀 まず見るところ

【まざり型→素材文】部品は「（D）を通過できない」に丸。物質が届かなかった方法をさがす → 方法2「密閉したガラス容器の中に入れたメス」。答えのことばは方法2の文の中にあるので、そのまま使う。

📚 前提知識（あれば答え合わせに使う）

  • においのもとは、目に見えない小さなつぶが空気中に広がって伝わる。密閉した容器の中からは外に出られない。

🔍 こう読み解く

  1. 方法2：ガラスはとうめいなので、オスからメスは見えている。それでも結果2は「近づくこともなかった」→ 物質がガラスを通りぬけられなかった → D＝ガラス。
  2. 方法1・6：はなれた所にいるオスが、メスやろ紙片に近づいた → 物質はメスとオスの間にあるものの中を移動してきた。間にあるのは空気 → C＝空気。
答え：C 空気　D ガラス
今回：C 空気・D ガラス ○。方法2の「密閉したガラス容器」に線を引いて、そこから答えを取れている。
