CP (1) 図1の月の名前と撮影時刻 資料問題・月の写真

👀 まず見るところ

【資料問題】部品は写真の正体「右側が光る半月」と、光る側の傾き（右上を向いている）。正体を1行「上弦・18時に南中」と書く → 右上向きは南中より前の傾きなので、18時より前の時刻に決まる。

📚 前提知識

  • 右半分が光る半月が上弦の月。12時頃に東から出て、18時頃に南中し、0時頃に西に沈む。
  • 月の光る側は、いつも太陽のある側を向く。南中前（15時頃・南東の空）は光る側が右上、南中（18時頃）は右、南中後（21時頃・南西の空）は右下を向く。

🔍 こう読み解く

  1. ①：図1は右側が光る半月 → 上弦。
  2. ②：上弦の月が空に出ているのは12時〜0時。3時と9時は地平線の下なので消える。
  3. 残る15時と21時は傾きで分ける。図1は光る側が右上向き＝南中前 → 15時。
答え：① 上弦　② 15
今回：① 上弦の月 ○　② 15 ○。写真の横に「18hに南」とメモがあり、南中の時刻を基準にして決められている。

CP (2) 図2は日食か月食か・始まりか終わりか 資料問題・月の写真

👀 まず見るところ

【資料問題】部品は写真の正体「海の模様が見える丸い月」と、暗い部分が右下にあること。模様が見える＝月そのものが写っている → 月食。月食は左から欠けて左から明るくなる、と1行書く → 暗い側が右に残るのは終わり頃。

📚 前提知識

  • 月食は満月が地球の影に入る現象。日食は太陽が月にかくされる現象で、写るのは太陽。
  • 月は星空の中を西から東（南の空では右から左）へ動くので、影には左（東）側から入り、左側から先に出てくる。

🔍 こう読み解く

  1. ①：月面の模様が写っていて、欠けた部分のふちがゆるいカーブ → 地球の影 → 月食。
  2. ②：始まる頃なら、左側が暗く右側が明るい。図2は逆で、左上が明るく右下が暗い。
  3. 先に影から出た左側が明るくなっている → 終わる頃。
答え：① 月食　② 終わる
今回：① 月食 ○　② 終わる ○。図2の右下に、地球の影にあたる大きな丸が赤で書きたしてある。影を図に置くと、月が影のどちら側にあるかが見える。

CP (3) 図2の月食を撮影した時刻 資料問題・月の模様の傾き

👀 まず見るところ

【資料問題】部品は(2)で決めた正体「月食＝満月」。満月の横に「18時に出る・0時に南中・6時に沈む」と書く。あとは月面の黒い模様（海）の傾きが、南中のときと同じかずれているかを見る。

📚 前提知識

  • 月食は太陽・地球・月が一直線に並ぶ満月のときだけ起こる。満月の南中は0時頃。
  • 月面の模様は、南中のときを基準にすると、南中の前は反時計回りに、南中の後は時計回りにかたむいて見える（コアプラス2・11）。

🔍 こう読み解く

  1. 選択肢は21時（南中の前）・0時（南中）・3時（南中の後）の3つ。
  2. 南中した満月では、丸い小さな海が右はしの少し上にある。図2では、その丸い海が右上の、真上に近い所に見える → 南中のときの向きと合っていないので、0時は消える。
  3. 丸い海が右から上へ回っている＝反時計回りのかたむき → 南中する前 → 21時。
答え：21
今回：21 ○。
コツ：模様の傾きは頭の中で回さず、コアプラスの南中した満月の写真と並べて、海がどちらに回ったかを矢印で描く。

CP (4) 月食の影の境目がぼんやりする理由 知識問題

大気。月食の影は地球の影で、地球のふちには大気の層がある。大気を通った光が影のふちに回りこむので、境目がくっきりしない。ふつうの満ち欠けの境目（月自身の昼と夜）がくっきりしているのと対にしておく。
答え：大気
今回：大気 ○。

CP (5) 図3の金星は明けの明星か、よいの明星か 資料問題・月と金星の写真

👀 まず見るところ

【資料問題】部品は金星の下に写る「月」の形。細い月の右下が光っている → 右側が光る細い月＝三日月と正体を1行書く。三日月は夕方の西の空にしか見えないので、いっしょに写る金星も夕方の金星に決まる。

📚 前提知識

  • 夕方、西の空に見える金星がよいの明星。明け方、東の空に見える金星が明けの明星。
  • 月も金星も、光る側は太陽のある側。夕方は太陽が西（右下）に沈んだ直後なので、右側が光る。明け方は左側が光る。

🔍 こう読み解く

  1. 月は右下が細く光る → 太陽は右下の地平線の下 → 日の入り後の西の空。
  2. 拡大された金星も右側が光っていて、月と同じ向き。
  3. 夕方の西の空の金星 → よいの明星。
答え：よい
今回：よい ○。

CP (6) 金星のように大きく満ち欠けする惑星 知識問題

水星。大きく満ち欠けして見えるのは、地球より内側を回る惑星（水星・金星）だけ。内側の惑星は太陽と地球の間に入ることがあり、そのとき光っていない側が地球を向く。火星・木星は地球の外側を回るので、いつも光る面のほとんどが地球を向き、大きくは欠けない。「水金地火木」と書いて、地球より左が答え。
答え：水星
今回：火星 ×。知識＝「満ち欠けする＝地球の内側」が出てこなかった。次は余白に「水金地火木」を書き、地球の位置に線を引いてから選ぶ。

🔍 こう読み解く

CP (8) 図4のア〜エからアンタレスを選ぶ 資料問題・全天写真

👀 まず見るところ

【資料問題】部品は「さそり座」と、図の上にある「カシオペヤ座」「北斗七星」。上＝北、下＝南と図のふちに書く（図に置く）→ さそり座は南の低い空・天の川のそばなので、下のふち近くで天の川の横にある星に決まる。

📚 前提知識

  • 夏の天の川は、北のはくちょう座から南のさそり座・いて座へのびる。さそり座の1等星が赤いアンタレスで、南の地平線近くに見える。
  • さそり座は、天の川がいちばん濃い所（いて座）のすぐ西どなりにある。見上げた図では右が西なので、天の川のすぐ右側をさがす。

🔍 こう読み解く

  1. エは北（上）のカシオペヤ座と北斗七星の間 → 北の空の星（北極星のあたり）なので消える。
  2. 下のふち近くに残るのはア・イ・ウ。天の川の白い帯のすぐ右（西）にあるのはイ。
  3. アは天の川の左（東）側にあり、ウは右（西）へ大きく離れている。どちらもさそり座の場所ではない。図に名前は無いが、星座早見にのっていない惑星（コアプラス21）の可能性がある。
答え：イ
今回：ア ×。知識＝「アンタレスは天の川のそば」が使えなかった。アも南の低い空の明るい星だが、天の川から離れている。次は天の川を下までたどり、その横の星を選ぶ。

CP (9) 図4でアークトゥルスが見える方角 資料問題・全天写真の方角

👀 まず見るところ

【資料問題】部品は図の中の「アークトゥルス」の位置（右のふち近く）。図のふちに方角を書く（図に置く）。見上げた空なので、上を北にすると右が西・左が東。地図と左右が逆になる。

📚 前提知識

  • 全天写真や星座早見は、空を下から見上げた図。北を上にすると、東は左、西は右になる。
  • アークトゥルスは春の星。夏の夜には西にかたむいている。

🔍 こう読み解く

  1. カシオペヤ座と北斗七星がある上が北、天の川が濃い下が南。
  2. 見上げた図なので右が西。アークトゥルスは右のふち近く → 西の空。
  3. 確かめ：春の星が夏の夜に西へ沈みかけている、で話が合う。
答え：西
今回：西 ○。図のまわりに北・西・南を書きこんでから答えている。右を「東」としなかったのは、この書きこみのおかげ。

CP (10) ひまわり・月・流れ星を地上から近い順に 知識問題

ウ→ア→イ。流れ星は、宇宙のちりが地球の大気にぶつかって光るもの。光っている場所は大気の中なので、3つの中でいちばん近い。気象衛星ひまわりは赤道上空約36000km、月はさらに遠く約38万km。流れ星は「遠くの星が落ちてくる」のではなく「大気の中の光」と置きかえる。
答え：ウ→ア→イ
今回：アイウ ×。知識＝問題文の「流れ星」に丸をつけて「おちてくる」「3」とメモしていて、流れ星をいちばん遠いものとして並べている。光る場所は大気の中＝いちばん近い、に直す。解答らんの横に「ウアイ」と書き直しがある。

CP (11) 晴天になるとされる観天望気 資料問題・写真3枚

👀 まず見るところ

【資料問題】部品は聞かれ方「晴天になる」と、3枚の正体を1行ずつ「ア うろこ雲／イ クモの巣の朝露／ウ 長く残る飛行機雲」。正体が書ければ、晴れの合図は朝露の1枚だけと決まる。

📚 前提知識

  • 朝露は、夜の間よく晴れて地面の熱が逃げ、冷えたしるし（放射冷却）。夜に雲がない → その日は晴れ。
  • うろこ雲は前線が近づくときにできる雲、飛行機雲が長く残るのは上空の空気がしめっているしるし。どちらも雨の前ぶれ。

🔍 こう読み解く

  1. ア：小さな雲が列をなして空をうめている＝うろこ雲 → 雨。
  2. ウ：暗い空に白い線がはっきり残っている＝飛行機雲 → 雨。
  3. イ：クモの巣の糸に水のつぶが並んでいる＝朝露 → 晴れ。
答え：イ
今回：イ ○。

CP (12) 図5の富士山の夕日を撮影した月 資料問題・方角と季節

👀 まず見るところ

【資料問題】部品は「富士山の真東から」と「日の入り頃」に丸。真東から見ると山頂が真西なので、写真のはしに「左＝南・右＝北」と直して書く → 太陽は山頂の左＝真西より南に沈んでいる、と決まる。

📚 前提知識

  • 日の入りの方角は、春分・秋分の頃が真西。夏至に近いほど北寄り、冬至に近いほど南寄りになる。
  • 西を向いて立つと、左手が南、右手が北。

🔍 こう読み解く

  1. 3月下旬は春分の頃 → 真西＝山頂の真上に沈むはず。図5は山頂から左にずれているので消える。
  2. 7月下旬は夏至に近い → 北寄り＝山頂の右に沈む。これも消える。
  3. 左（南寄り）に沈むのは冬至に近い11月下旬。
答え：11
今回：11 ○。問題文の「真東」に丸をつけてから答えている。方角の部品を拾えている。

CP (14) 図6の地球が撮影された月 資料問題・衛星写真

👀 まず見るところ

【資料問題】部品は写真の中の文字「北極」「南極」と、昼と夜の境目。境目に線を引き（図に置く）、北極と南極がそれぞれ明るい側か暗い側かを書く → 北極が昼の側なら北半球が夏、と決まる。

📚 前提知識

  • 地球は地軸をかたむけたまま太陽のまわりを回る。6月（夏至の頃）は北極側が太陽の方へかたむき、北極は1日中昼、南極は1日中夜になる。12月はその逆。
  • 3月・9月（春分・秋分の頃）は、昼と夜の境目が北極と南極の両方を通る。

🔍 こう読み解く

  1. 図6の境目は、上が右へ、下が左へかたむいた線になっている。まっすぐ縦ではないので3月・9月は消える。
  2. 「北極」の文字のあたりは明るい側、「南極」の文字のあたりは暗い側。
  3. 北極が昼・南極が夜 → 北半球が夏 → 6月。
答え：6
今回：12 ×。部品の形を直さなかった＝図6に境目の線は引いてあるが、「北極が明るい側＝北半球が夏」に直す一歩がなく、逆の12月を選んでいる。線を引いたら、北極と南極の横に「昼」「夜」と書く。
コツ：6月と12月は両方セットで。北極が昼＝6月、南極が昼＝12月。コアプラス65でも同じ見方を使う。

CP (15) 図6のときの東京の時刻 資料問題・衛星写真

CP (17) 石炭のもとになったもの 知識問題

植物。石炭は、大昔のシダなどの植物（樹木）が積もり、地下で長い年月おし固められて変化したもの。生き物がもとなので化石に分類されることもある。石油は大昔のプランクトンの死がいがもと、と対にしておく。

CP (18) 氷河のでき方と、氷河がつくった地形 まざり型・選択＋写真

👀 まず見るところ

【まざり型→資料問題】①は部品「押し固められて」に丸 → 押し固められるのは積もった雪。②は3枚の正体を1行ずつ書き、大きさがばらばらで角ばった石がごろごろしている写真を選ぶ。

📚 前提知識

  • 氷河は、川や海が凍ったものではない。降った雪が自分の重さで押し固められて氷になり、ゆっくり流れ下るもの。
  • 氷河は石を転がさずに運ぶので、運ばれた石は丸くならず、角ばったまま大きさもそろわない（コアプラス45）。川の石は転がって丸くなる。

🔍 こう読み解く

  1. ①：「押し固められて」に合うのは雪 → ウ。
  2. ②：アは地層が大きく曲がっている＝しゅう曲（地層をおす力でできる）。イは横じまの地層が深くけずられた谷＝グランドキャニオン（川がけずった）。
  3. 残るウは、角ばった大小の石が一面に広がる → 氷河が運んで置いていった石 → ウ。
答え：① ウ　② ウ
今回：① ウ ○　② ウ ○。イの写真に×をつけて消してから選んでいる。

CP (19) 図7のサンゴのようすと、サンゴからできる岩石 素材文・穴うめ

👀 まず見るところ

【素材文】部品は①の後ろの「をしている様子」と、②の前の「死がいが堆積してできた岩石」に丸。①は「〜をしている」に続く形の言葉、②は生き物の骨格がもとの岩石、と決めてから書く。

📚 前提知識

  • サンゴはイソギンチャクやクラゲの仲間の動物。図7の小さな丸いつぶは卵で、海中にいっせいに放つ（コアプラス60）。
  • サンゴの骨格は炭酸カルシウム。これが積もって固まった岩石が石灰岩。貝がらやフズリナの死がいからも石灰岩ができる。

🔍 こう読み解く

  1. ①：図7はサンゴから丸いつぶがたくさん出ている → 卵を産んでいる。「〜をしている」に合う形は産卵。
  2. ②：サンゴの死がい＝炭酸カルシウムの骨格 → 石灰岩。解答らんに「岩」があるので「石灰」だけ書く。
答え：① 産卵　② 石灰
今回：①「卵」・②空らん ×。知識＝②の石灰岩が出てこなかった。①は写真が卵だと分かっているので、「〜をしている」に丸をつけて「産卵」の形に直せば書けた。

CP (20) サンゴと共生するプランクトン・白く見える現象 知識問題

① 褐虫藻（かっちゅうそう）　② 白化（はっか）。サンゴの色は、体内にすむ褐虫藻の色。褐虫藻は光合成でつくった養分をサンゴにわたし、サンゴは住みかをあたえている（共生）。褐虫藻が抜け出ると白い骨格が透けて見え、これが白化現象。そのまま続くとサンゴは栄養不足で死んでしまう。
答え：① 褐虫藻　② 白化
今回：①「かっちゅうそう」○　②「はっか」○。ひらがなで正解になっている。漢字は「褐色の虫の藻」「白く化ける」と分けると書きやすい。
