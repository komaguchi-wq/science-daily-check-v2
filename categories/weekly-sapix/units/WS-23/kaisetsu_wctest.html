WS-23 WC（ウィークリーチェック WS-23＝WS-22「身のまわりの物質」の復習・5つの固体と3つの液体の判別）

WC 全体像 固体5種・液体3種の判別 10問（各10点・100点）

食塩・石灰石・銅・アルミニウム・鉄の5つと、塩酸・水酸化ナトリウム水溶液・蒸留水の3つを、実験1〜5の文だけで当てる問題。実験1〜4は1文ごとに「だけ」「泡」が手がかりで、読んだその場で1つずつ決まる（B＝食塩 → E＝銅 → D＝アルミニウム → C＝鉄 → 残ったA＝石灰石。液体は あ＝蒸留水・い＝塩酸・う＝水酸化ナトリウム水溶液）。決まったものを実験の横に「B=食塩」のように書いていけば、(1)〜(5)はその書きこみを見るだけで答えられる。

今回は70／100点。固体・液体の判別（(1)う・(3)・(4)A〜E）は全部取れている。落とした3問は、中身ではなく答えの書き方でつまずいた形（(1)あ 漢字／(2) 2と3が並んだ／(5) らんの外に書いた）。

WC (1)あ 液体あの正体 素材文・液体の判別

👀 まず見るところ

【素材文】設問は「あは何か」。部品は実験1の「Bはとけましたが、他の固体はとけませんでした」に丸 → 5つの固体のうち1つしかとかさない液体＝蒸留水と、その場で決まる。

📚 前提知識

  • 5つの固体のうち、水にとけるのは食塩だけ。石灰石と金属（銅・アルミニウム・鉄）は水にとけない。
  • 塩酸なら4つ（銅以外）、水酸化ナトリウム水溶液なら2つ（食塩・アルミニウム）をとかす。「1つだけとかす」のは水しかない。

🔍 こう読み解く

  1. 実験1は「1つだけとけた」→ とかす力がいちばん弱い液体＝蒸留水。
  2. 同時に「水にとけた固体B＝食塩」も決まる。(4)Bで使うので、実験1の横に「あ=水 B=食塩」と書く。
答え：蒸留水
今回：×（赤の斜線）。答案は「蒸留水」と書いているが、「蒸」の字の形がくずれていて、漢字の誤りで×になったと読める。知識＝漢字。中身は合っていたので、「蒸留水」の3字を1回書いて確かめる。

WC (1)う 液体うの正体 素材文・液体の判別

👀 まず見るところ

【素材文】部品は実験3の「BとDはとけ」と「Dのときはさかんに泡」に丸。とけたのが2つだけで、うち1つが泡を出す液体＝水酸化ナトリウム水溶液（泡を出す相手はアルミニウム）。

📚 前提知識

  • 水酸化ナトリウム水溶液は、金属の中ではアルミニウムだけをとかし、そのとき水素の泡が出る。鉄・銅・石灰石はとけない。
  • 食塩はどの液体にもとけるが、泡は出ない。塩酸だと石灰石・鉄・アルミニウムもとけるので「とけたのは2つ」に合わない。

🔍 こう読み解く

  1. 「とけたのは2つ」→ 塩酸（4つとける）でも蒸留水（1つ）でもない → 残った水酸化ナトリウム水溶液。
  2. 泡を出したD＝アルミニウム、とけただけのB＝食塩（実験1と合う）。実験3の横に「う=水酸化Na D=アルミ」と書く。
答え：水酸化ナトリウム水溶液
今回：水酸化ナトリウム水溶液 ○。

WC (2) 塩酸で泡を出してとけた固体の数 素材文・数える

👀 まず見るところ

【素材文】部品は設問の「実験2でとけた4種類」（A・B・C・D）と「泡を出しながら」に丸。液体い＝塩酸なので、4つの横に「塩酸で泡が出るか」の○×を書く → ○の数が答え。

📚 前提知識

  • 塩酸に入れると、石灰石は二酸化炭素、鉄・アルミニウムは水素の泡を出してとける。銅はとけない。
  • 食塩は塩酸にもとけるが、水にとけるのと同じで泡は出ない。ここが数えるときの分かれ目。

🔍 こう読み解く

  1. 実験2「Eだけとけない」→ 4つをとかす液体＝塩酸、とけないE＝銅。
  2. A 石灰石 ○（二酸化炭素）／B 食塩 ×（泡なし）／C 鉄 ○（水素）／D アルミニウム ○（水素）。
  3. ○は3つ → 3種類。食塩を数えないところが決め手。
答え：3種類
今回：×（赤の斜線）。らんには「2」の右に「3」が並んでいて、2を消さずに3を書き足し、どちらの答えか分からなくなったと読める。部品の形を直さなかった＝4つに○×をつけずに頭で数え、2と3の間で迷った形。次はA〜Dの横に○×を書いてから数え、書き直すときは前の数字を消す。

WC (3) 実験3で出た泡の気体 素材文・気体の名前

👀 まず見るところ

【素材文】部品は「実験3で出た泡」に丸 → 実験3の液体う＝水酸化ナトリウム水溶液、泡を出したD＝アルミニウム。この組み合わせで出る気体は水素と決まる。

📚 前提知識

  • アルミニウムは塩酸にも水酸化ナトリウム水溶液にもとけ、どちらのときも出る気体は水素。
  • 二酸化炭素が出るのは「石灰石＋塩酸」の組み合わせだけ。石灰石は水酸化ナトリウム水溶液にはとけないので、実験3で二酸化炭素は出ない。

🔍 こう読み解く

  1. (1)うで「う＝水酸化ナトリウム水溶液」「D＝アルミニウム」が決まっている。
  2. 金属が液体にとけて出る泡は水素。「石灰石＋塩酸」だけが二酸化炭素、と分けて置く。
答え：水素
今回：水素 ○。

WC (4)A・B・C・D・E 固体A〜Eの正体 素材文・固体の判別

👀 まず見るところ

【素材文】設問は「A〜Eは何か」。実験1〜4の1文ごとに「だけ」と「泡」に丸 → 実験1のB、実験2のE、実験3のD、実験4のCがその場で決まり、残ったAが石灰石。決まった順に実験の横へ「B=食塩」と書く。

📚 前提知識

  • 水にとけるのは食塩だけ／塩酸にとけないのは銅だけ／水酸化ナトリウム水溶液で泡を出すのはアルミニウムだけ／磁石につくのは鉄だけ。この4つの「だけ」が判別の部品。
  • 石灰石は塩酸にしかとけず、磁石にもつかないので、消去法で最後に残る。

🔍 こう読み解く

  1. 実験1「Bだけとけた」＝水にとける → B＝食塩。
  2. 実験2「Eだけとけない」＝塩酸にとけない金属 → E＝銅。
  3. 実験3「Dは泡」＝水酸化ナトリウム水溶液で泡 → D＝アルミニウム。
  4. 実験4「Cだけ磁石につく」→ C＝鉄。残ったA＝石灰石（塩酸にとけて泡を出す＝実験2でとけたことにも合う）。
答え：A 石灰石　B 食塩　C 鉄　D アルミニウム　E 銅
今回：A 石灰石 ○／B 食塩 ○／C 鉄 ○／D アルミニウム ○／E 銅 ○。4つの「だけ」から順に決める流れができている。

WC (5) 加熱して黒くなった固体 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「加熱してしばらく置く」「色が黒くなった」と、答え方の「すべて」に丸。加熱して黒くなる＝空気中の酸素と結びついて黒いさびになる金属 → A〜Eの横に○×を書き、鉄と銅に○。

📚 前提知識

  • 銅を加熱すると、表面が黒い酸化銅になる。鉄も加熱すると酸素と結びついて黒くなる。
  • アルミニウムは表面にうすい膜ができるだけで黒くならない。食塩・石灰石は加熱しても色は変わらない。

🔍 こう読み解く

  1. (4)の結果を使う。A 石灰石 ×／B 食塩 ×／C 鉄 ○／D アルミニウム ×／E 銅 ○。
  2. 「すべて選ぶ」なので、○の2つをそのまま書く → C・E。
答え：C・E
今回：×（赤の斜線）。解答らんの中は「C D …」を消した跡で、正しい「CE」はらんの右の外に書かれていた。らんの外の答えは採点されなかったと読める。中身は合っていたので、書き直すときは前の答えを消して、らんの中に書く。「すべて」に丸をつけ、5つ全部に○×をつけてから写す。

WC まとめ 70／100点（7／10問）

  • 取れた7問は、実験1〜4の「だけ」「泡」から固体と液体を1つずつ決める流れ。判別の知識はそろっている。
  • 落とした3問は知識より書き方：(1)あ「蒸」の字／(2) 2と3が並んだ／(5) らんの外。答えを書く直前に、消したか・らんの中か・丸をつけた指示に合っているかを見るだけで3問とも取れる。
  • 覚え直しはこの3つ：塩酸で泡＝石灰石（二酸化炭素）・鉄・アルミニウム（水素）／水酸化ナトリウム水溶液で泡＝アルミニウムだけ／加熱して黒＝鉄・銅。
