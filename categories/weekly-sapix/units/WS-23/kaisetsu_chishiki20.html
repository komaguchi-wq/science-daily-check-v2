K20 (1)(2) 図1の方位磁針の振れる向きと大きさ 条件文・すべて選ぶ／最も大きい

👀 まず見るところ

【条件文】部品は「N極が右側（東側）」「すべて」と、(2)で変わった「最も大きく」に丸。磁針ごとに「振れる向き＋導線の本数」を図に書きこむ → 向きは(1)、本数の数は(2)の答えになる。

📚 前提知識

  • 磁針は、南北向きに通る導線に振れる。導線が磁針の上を通るか下を通るかで、同じ向きの電流でも振れる向きは逆。カのように東西向きに通る導線は、針と同じ向きにしか力がかからず振れない。
  • 同じ向きに振らせる導線が2本なら2倍、逆向きに振らせる導線が重なれば打ち消し合う。

🔍 こう読み解く

  1. 磁針ごとに書き出す（解答冊子の図）：ア 東2／イ 東1と西1 → 振れない／ウ 西2／エ 西3／オ 西2と東1 → 西1／カ 導線が東西向き → 振れない。
  2. (1) 東に振れるのはアだけ。「すべて」と書いてあっても、1つならアだけ答える。
  3. (2) 数がいちばん大きいのはエの3。振れない磁針や打ち消し合う磁針は候補から外す。
答え：(1) ア　(2) エ
自分で解くときのチェック：6つの磁針すべてに「東／西／振れない」と本数を書いてから選ぶ。1つ見つけて止まると(2)で間違える。

K20 (3)(4) 図2 重さのある棒のてこ 条件文・計算

👀 まず見るところ

【条件文】部品は「60gで太さが一様な棒」と図の「2cm・6cm・8cm・4cm」。60gは棒のまん中（左端から10cm＝支点の右2cm）に下向きの矢印で置く（直して書く）→ 支点まわりのつり合いの式に、この矢印が入る。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなせる。
  • てこのつり合い＝支点の左回り（重さ×支点までの長さ）と右回りが等しい。支点にかかる力は、ぶら下がっているものと棒の重さの合計。

🔍 こう読み解く

  1. 棒の長さは 2＋6＋8＋4＝20cm。まん中は左端から10cm、支点（左端から8cm）の右2cm。
  2. 左回り A×6、右回り 60×2＋90×8＝120＋720＝840。A＝840÷6＝140g。
  3. (4) 支点はA・棒・90gをまとめて支える → 140＋60＋90＝290g。
答え：(3) 140g　(4) 290g
自分で解くときのチェック：(4)で棒の60gを足し忘れやすい。矢印を先に描いてあれば、足す数は図の矢印の数と同じ。

K20 (5) 図3 2本のばねでつるした棒の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「自然長20cmで60gで3cmのびる」「自然長16cmで60gで4cmのびる」と「棒は水平」。ばねの性質は「Aは20gで1cm、Bは15gで1cm」に直して書く → 水平＝2本の長さが同じ。先にBを4cmのばしてAと同じ20cmにそろえてから、残りを4：3で分ける。

📚 前提知識

  • ばねののびは重さに比例する。A：60g→3cmだから20gで1cm。B：60g→4cmだから15gで1cm。
  • 太さが一様な棒を両端でつるすと、2本のばねには棒の重さの半分ずつがかかる。

🔍 こう読み解く

  1. Bは自然長が4cm短い。まずBだけ4cmのばしてAと同じ20cmにそろえる → 15×4＝60g。
  2. そろえたあとは、水平＝2本が同じ長さだけのびる。同じ長さをのばすのに必要な重さは A：B＝20：15＝4：3（Aを④、Bを③とおく）。
  3. 両端でつるした棒は、2本に半分ずつかかる → A＝④、B＝③＋60g が等しい → ①＝60g、④＝240g、③＝180g。
  4. 棒の重さ＝240＋60＋180＝480g（解答冊子の式）。確かめ：Aは240g→12cmのびて32cm、Bも240g→4＋12＝16cmのびて32cm。
答え：480g

K20 (6) 図3 棒を水平に保つおもりの位置 条件文・計算

👀 まず見るところ

【条件文】部品は「300gのおもり」「棒は水平のまま」「左端から何cm」に丸。「水平のまま」は「AとBののびが同じだけ増える」に直して書く → 300gがA・Bに分かれる比が決まる。

📚 前提知識

  • 同じ長さだけのびるとき、ばねにかかる重さの比は「1cmあたりの重さ」の比。A：B＝20：15＝4：3。
  • おもりを2点で支えるとき、力の大きい方におもりは近い。力の比が4：3なら、距離の比はその逆の3：4。

🔍 こう読み解く

  1. 300gは A：B＝4：3 に分かれてかかればよい。
  2. Aに近いので、左端からの距離：右端までの距離＝3：4。
  3. 42×3/(3＋4)＝18cm。
答え：18cm
自分で解くときのチェック：力の比と距離の比は逆。大きい力の側に近い、と1行書いてから割り算する。

K20 (7) 図4 ぶつかるふりこ 条件文・計算

👀 まず見るところ

【条件文】部品は「長さ36cmで周期が1.2秒」「長さがAの4倍」「重さが同じ80g」「再びAが左の最高点」に丸。4倍は「周期2倍＝2.4秒」に直して書き、動きを「A 1/4周期 → B 1/2周期 → A 1/4周期」の絵にする。

📚 前提知識

  • ふりこの周期は長さで決まる。長さ4倍で周期2倍（9倍で3倍）。重さは関係ない。
  • 重さが同じふりこがぶつかると、ぶつかった方が止まり、相手がそのままの速さで動き出す（解答冊子）。

🔍 こう読み解く

  1. Bの周期＝1.2×2＝2.4秒。
  2. Aが最下点まで 1.2÷4＝0.3秒。ここでBにぶつかりAは止まる。
  3. Bが右へ上がって戻るまで 2.4÷2＝1.2秒。Aにぶつかって止まる。
  4. Aが左の最高点まで 0.3秒。合計 0.3＋1.2＋0.3＝1.8秒（解答冊子は (1.2＋2.4)×1/2）。
答え：1.8秒

K20 (8) 図5 塩酸100cm³にアルミニウム2.4g 資料問題・比例計算

👀 まず見るところ

【資料問題】部品は資料の正体「塩酸30cm³・アルミニウムの重さ(g)と水素(cm³)」と、グラフが折れる点「0.8gで960cm³」。設問の「塩酸100cm³」「2.4g」は30cm³・0.8gの何倍かに直して書く → どちらが余るかが決まる。

📚 前提知識

  • 折れ線が水平になる点＝塩酸30cm³が全部使われたところ（アルミニウム0.8gがちょうど）。それより多く入れたアルミニウムはとけ残り、水素は増えない。
  • ちょうどの組み合わせ「塩酸30cm³・アルミニウム0.8g・水素960cm³」は、何倍にしても同じ比。

🔍 こう読み解く

  1. 塩酸100cm³は30cm³の10/3倍（3倍より多い）→ とかせるアルミニウムも 0.8gの3倍＝2.4g より多い。
  2. 入れたのは2.4g → 塩酸が余り、アルミニウムは全部とける。基準にするのはアルミニウムの方。
  3. 2.4gは0.8gの3倍 → 水素も3倍：960×3＝2880cm³。
答え：2880cm³
自分で解くときのチェック：「どちらが余るか」を先に決め、余らない方を基準に何倍かを書く。

K20 (9) 蒸発させて残る固体の重さ 条件文・比例計算

👀 まず見るところ

【条件文】部品は「アルミニウム1.0g…完全にとけたあと…4.5gの白い固体」と、(8)で決めた「アルミニウムは全部とける」。1.0g→4.5gを「とけたアルミニウム×4.5」に直して書く。

📚 前提知識

  • アルミニウムが塩酸にとけてできる白い固体は、もとのアルミニウムとは別の物質。とけたアルミニウムの重さに比例してできる。
  • 余った塩酸は蒸発させても何も残らない（とけているのは気体の塩化水素）。

🔍 こう読み解く

  1. (8)より、2.4gのアルミニウムは全部とける。
  2. 4.5×2.4＝10.8g。
答え：10.8g

K20 (10) 塩酸にとけて二酸化炭素を出すもの 知識問題

ア・エ・オ。貝殻・大理石（石灰石・チョーク・卵の殻も）は炭酸カルシウムをふくみ、塩酸にとけて二酸化炭素を出す。ベーキングパウダー（重そう＝炭酸水素ナトリウム）も塩酸で二酸化炭素を出し、加熱するだけでも出る。消石灰は塩酸と反応しても気体は出ず、でんぷん・カコウ岩は塩酸にとけない。「すべて」なので3つ。
答え：ア・エ・オ

K20 (11) 胚乳がある種子 知識問題

ア・エ。養分を胚乳にためる有胚乳種子は、裸子植物（マツ・スギ・イチョウ）、単子葉植物（イネ・ムギ・トウモロコシ）、双子葉植物の一部（カキ・オシロイバナ・ホウレンソウ・トマト）。ホウセンカ・クリ・ヒマワリ・アブラナは子葉に養分をためる無胚乳種子。「すべて」なので2つ。
答え：ア・エ

K20 (12) 種子の養分が主に脂肪のもの 知識問題

ア・ウ。でんぷん＝イネ・ムギ・トウモロコシ・インゲンマメ、たんぱく質＝ダイズ、脂肪＝ヒマワリ・ゴマ・アブラナ・ラッカセイ。「油がとれる植物」と結びつけると脂肪の組が決まる。「2つ選ぶ」の指定。
答え：ア・ウ

K20 (13) モンシロチョウの卵の大きさ 知識問題

イ（1mm）。モンシロチョウの卵はとっくり形で1mmくらい。キャベツの葉の裏に1個ずつ産みつけられる。
答え：イ

K20 (14) 終齢幼虫になるまでの脱皮の回数 知識問題

4回。ふ化した幼虫は卵の殻を食べ、4回脱皮して5齢幼虫（終齢）になり、最後に皮を脱いでさなぎになる。「脱皮の回数＋1＝齢」で数える。
答え：4回

K20 (15) 消化器官だが食べ物が通らないもの 知識問題

ウ・エ・オ。食べ物が通る道（消化管）は口→食道→胃→小腸→大腸→こう門。肝臓・すい臓・胆のうは消化液を作る・ためる消化器官だが、食べ物は通らない。心臓・腎臓は消化器官ではないので選ばない。「すべて」なので3つ。
答え：ウ・エ・オ

K20 (16)(17) 図6 白夜の位置と昼が長くなる区間 資料問題・公転

👀 まず見るところ

【資料問題】部品は資料の正体「地球の公転の図・矢印が公転の向き・北極の印」と設問の「北緯66.6度で一日中太陽が沈まない」「昼が徐々に長くなる」。北極が太陽側にかたむいた地球に「夏至」と書きこむ → 残りは公転の向きで順に決まる。

📚 前提知識

  • 北緯66.6度以北（北極圏）では、夏至のころ太陽が沈まない白夜になる。北極が太陽の側にかたむいた位置＝北半球の夏至。
  • 日本で昼が長くなっていくのは冬至→春分→夏至。

🔍 こう読み解く

  1. 図6の地軸は上端が北極（Bの印）。上端が太陽に向いているのはA → 夏至。(16)はA。
  2. 反対側のCが冬至。矢印は B→C→D→A の向きなので、C＝冬至、D＝春分、A＝夏至、B＝秋分。
  3. 昼が長くなるのは冬至から夏至まで → C〜A。
答え：(16) A　(17) C〜A

K20 (18)(19) 図7 夏の大三角 資料問題・星の名前

👀 まず見るところ

【資料問題】部品は資料の正体「夏の大三角のスケッチ」と設問「Cの星の名前と星座名」「最も北寄りの空を通る」。3つの星のまわりの星座の形（十字・小さな四辺形・一直線）を図に書きこむ → 名前が決まり、北寄りは星座で決まる。

📚 前提知識

  • 夏の大三角＝こと座ベガ・わし座アルタイル・はくちょう座デネブ。はくちょう座は大きな十字、こと座は小さな四辺形、わし座はアルタイルの両わきに星が並ぶ。
  • いちばん北寄りを通るのがデネブ、いちばん南寄りがアルタイル、天頂近くを通るのがベガ（解答冊子）。

🔍 こう読み解く

  1. Bのまわりは十字 → はくちょう座デネブ。Aのそばは小さな四辺形 → こと座ベガ。
  2. 残ったCは両わきに星が並ぶ → わし座アルタイル。(18)の答え。
  3. (19) 最も北寄りはデネブ → B。
答え：(18) 星 アルタイル・わし座　(19) B

K20 (20) カコウ岩の黒い粒の鉱物 知識問題

クロウンモ。カコウ岩はマグマが地下深くでゆっくり冷えた深成岩で、白い粒のチョウセキ・透明な粒のセキエイ・黒い粒のクロウンモの3つの鉱物からできている。カタカナで書く。
答え：クロウンモ
