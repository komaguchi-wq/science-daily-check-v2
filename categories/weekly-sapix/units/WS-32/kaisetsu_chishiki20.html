WS-32 知識の20題 確認テスト（電磁石・てこ・浮力・溶解度・生物・天体ほか）

K20 全体像 知識の20題 20問（各5点・100点）

前半の(1)〜(9)と(20)は短い計算、(10)〜(19)は一問一答。計算はどれも図や表に数字を書きこめば1〜2行の式で終わる問題で、書きこむ前に式を立てると取りちがえやすい。

入口は4つ。電磁石は「電流を図に書く」、ばねばかりは「棒の重さを重心に矢印で置く」、浮力は「台ばかりの増えた分＝木片の重さ」、溶解度は「水の重さにそろえる」。

K20 (1) 巻き数と磁力を調べる組み合わせ 条件文・対照実験

👀 まず見るところ

【条件文】部品は「巻き数によって」に丸。変えるのは巻き数だけなので、「電流が同じ・巻き数がちがう」2つをさがす、と直して書く → 枝分かれのない所にあるAとDに決まる。

📚 前提知識

  • 調べたい条件を1つだけ変え、ほかの条件はそろえて比べる。
  • 直列につながった所は、どこも同じ大きさの電流が流れる。並列の所は電流が分かれる。

🔍 こう読み解く

  1. 図1の回路は、A →（BとCの並列）→ D →（EとFの並列）の順に1本につながっている。
  2. AとDは枝分かれしていないので、電流が同じ。巻き数はA 100回・D 200回でちがう → 比べられる。
  3. BとD、CとF、EとFも巻き数はちがうが、電流の大きさもちがうので、磁力の差が巻き数のせいか電流のせいか分からない。AとB、BとCは巻き数が同じ。
答え：イ

K20 (2) 電磁石A〜Fの磁力の強い順 条件文・計算

👀 まず見るところ

【条件文】部品は「巻き数と電流の大きさに比例」。これを「磁力＝巻き数×電流」に直して余白に書き、図1のA〜Fの横に電流の数字を書きこむ → かけ算6つで順番が決まる。

📚 前提知識

  • 並列に分かれるとき、同じコイルどうしなら電流は半分ずつに分かれる。
  • 解答冊子の図では、並列のEとFの電流は E：F＝4：2 になっている。巻き数が2倍のFは導線が長いぶん電流が流れにくい、と考えると合う。

🔍 こう読み解く

  1. 電流を書きこむ（解答冊子の図の数字）：A 6／B 3／C 3／D 6／E 4／F 2。BとC、EとFはそれぞれ足すと6になる。
  2. 巻き数は100回を1、200回を2として、巻き数×電流を出す：A 1×6＝6／B 1×3＝3／C 3／D 2×6＝12／E 1×4＝4／F 2×2＝4。
  3. 大きい順にならべる。同じ数は「＝」でつなぐ。D(12)＞A(6)＞E＝F(4)＞B＝C(3)。
答え：D＞A＞E＝F＞B＝C
コツ：Fは巻き数が多いのに、Eと同じ強さになる。巻き数だけで順番を決めず、電流とのかけ算までやってから書く。

K20 (3) ばねばかりを6cm動かしたとき 条件文・計算

👀 まず見るところ

【条件文】部品は図2アの「90g」「60g」。合わせた150gが棒の重さなので、Aから12cmの所に下向きの矢印150gを置く（直して書く）→ イの図にも同じ矢印を書けば、AとBまでの長さの逆比で分けるだけ。

📚 前提知識

  • 2つのばねばかりの合計＝棒の重さ。棒の重さは重心の1点にかかっているとみなせる。
  • 重心から近いばねばかりほど大きい力を受け持つ。受け持つ重さの比は、重心までの長さの逆比。

🔍 こう読み解く

  1. アで重心を出す。重さの比 A：B＝90：60＝3：2 → 長さの比は逆の2：3 → 30cmを分けて、重心はAから12cm・Bから18cm。
  2. イはAを6cm内側に動かしたので、重心までは Aから12−6＝6cm、Bから18cm。長さの比 1：3。
  3. 重さの比は逆の3：1。A＝150×3/4＝112.5g（Bは37.5g）。
答え：112.5g

K20 (4) Aの真下に96gをつるしたとき 条件文・計算

👀 まず見るところ

【条件文】部品は(3)と変わった「Aのばねばかりの下に96g」と、求めるものの「Bのばねばかり」に丸。おもりはAの真下なので、Aを支点にすると回すはたらきは0 → Bは(3)のまま変わらない。

📚 前提知識

  • 支点の真下にかかる力は、支点からの長さが0なので、棒を回すはたらきをもたない。

🔍 こう読み解く

  1. (3)のイで、Bは150−112.5＝37.5g。
  2. 96gのおもりはAの真下につるすので、全部Aのばねばかりが受け持つ。Aは112.5＋96＝208.5g。
  3. Bにかかる分は増えないので、37.5gのまま。聞かれているのはBなので、208.5gを書かない。
答え：37.5g
コツ：答えを書く直前に、設問の「Aの」「Bの」の丸をもう一度見る。(3)はA、(4)はBを聞いている。

K20 (5) 木片をすべて押しこんだときの台ばかり 条件文・計算

👀 まず見るところ

【条件文】部品は「1100g」「1148g」と「全体の2/3だけ沈み」。差の48gを「木片の重さ＝2/3沈んだときの浮力」と直して図3に書く → 全部沈めると浮力は1.5倍、その分だけ台ばかりが増える。

📚 前提知識

  • 浮かんでいる物体では、浮力＝物体の重さ。
  • 浮力は液体の中に入っている体積に比例する。台ばかりの値は、浮力の分だけはじめより増える。

🔍 こう読み解く

  1. 木片の重さ＝1148−1100＝48g。浮かんでいるので、2/3沈んだときの浮力も48g。
  2. 全部沈めると、液の中の体積は 1÷2/3＝1.5倍 → 浮力は48×1.5＝72g。
  3. 台ばかりは、アルコールと容器の1100gに浮力の72gを足して、1100＋72＝1172g。
答え：1172g
コツ：1148＋72としない。72gの中には木片の重さ48gがもう入っている（押す力は72−48＝24gで、1148＋24でも1172gになる）。

K20 (6) 木片の体積 条件文・計算

👀 まず見るところ

【条件文】部品は「1cm³あたり0.9g」。「あたり」は÷0.9に直して書く。割られる数は、木片が全部沈んだときの浮力72g（＝おしのけたアルコールの重さ）→ 体積が出る。

📚 前提知識

  • 浮力の大きさ＝物体がおしのけた液体の重さ。全部沈めたとき、おしのけた液体の体積は物体の体積と同じ。

🔍 こう読み解く

  1. (5)より、全部沈めたときの浮力は72g ＝ おしのけたアルコール72g。
  2. アルコールは1cm³あたり0.9gなので、72÷0.9＝80cm³。
  3. 確かめ：2/3沈んだときにおしのけたのは 80×2/3×0.9＝48g。木片の重さと合う。
答え：80cm³
コツ：48÷0.9で止めると、沈んでいる2/3の体積になる。聞かれているのは木片全体の体積。

K20 (7) 坂を下りたあとの金属球の位置 資料問題・運動

👀 まず見るところ

【資料問題】資料の正体は「0.1秒ごとに進んだ距離 1・3・5・7・9」。部品は「Bからは坂が水平」に丸 → 水平では速さが変わらないので、Bを通る瞬間の速さ（0.1秒で10）のまま、同じ間かくで2回進む。

📚 前提知識

  • 坂では速さがだんだん増え、0.1秒ごとの距離は2ずつ増える。水平な所では速さが一定（等速直線運動・解答冊子）。
  • ある瞬間の速さは、その前後の区間の平均で求まる（解答冊子）。

🔍 こう読み解く

  1. Bの直前の0.1秒は9。坂が続いていれば次の0.1秒は11。Bを通る瞬間の速さはその平均で、0.1秒あたり10。
  2. Bから先は水平なので、0.1秒ごとに10ずつ進む → 10・10の図。
  3. ア（9・9）は直前の区間の距離をそのまま使ったもの、ウ（11・11）は坂が続くとしたときの次の区間、エ（11・9）は速さが変わっているので合わない。
答え：イ

K20 (8) 80℃から40℃に下げて出てくるホウ酸 資料問題・計算

👀 まず見るところ

【資料問題】資料の正体は「水100gに溶けるホウ酸の重さ・g」。部品は「水240g」に丸（水溶液でなく水の重さ）→ 表の80℃と40℃の差を出し、×240/100に直して書けば終わる。

📚 前提知識

  • 溶けるだけ溶かした液を冷やすと、溶ける量の差の分が結晶になって出てくる。溶ける量は水の重さに比例する。

🔍 こう読み解く

  1. 水100gのとき：80℃で23.5g、40℃で9g → 出てくるのは 23.5−9＝14.5g。
  2. 水は240gなので 14.5×240/100＝34.8g。
答え：34.8g

K20 (9) 飽和ホウ酸水230gを20℃に冷やす 資料問題・計算

👀 まず見るところ

【資料問題】部品は(8)と変わった「飽和状態のホウ酸水を230g」に丸。230gは水ではなく水溶液の重さ → 60℃は「水100g＋ホウ酸15g＝115g」なので、「水200g」に直して書いてから表を使う。

📚 前提知識

  • 水溶液の重さ＝水の重さ＋溶けているものの重さ。表は水100gあたりなので、水の重さにそろえてから使う。

🔍 こう読み解く

  1. 60℃の水100gにホウ酸は15g溶け、飽和水溶液は115gになる。
  2. 230÷115＝2倍 → 水は200g（ホウ酸は30g）。
  3. 水100gで出てくるのは 15−5＝10g。水200gなので 10×200/100＝20g。
答え：20g
コツ：(8)は「水240g」、(9)は「ホウ酸水230g」。水か水溶液かに丸をつけてから式を書く。10×230/100＝23gとしない。

K20 (10) 刺激臭があり有毒な気体 知識問題

アンモニア・塩素・塩化水素の3つ。どれも鼻をさすにおい（刺激臭）があり有毒。プロパンはガスもれに気づけるように、わざとにおいを付けてある。一酸化炭素は有毒だが無臭（解答冊子）。「すべて選びなさい」なので、ア〜オの5つ全部に○×をつけてから書く。
答え：ア・イ・ウ

K20 (11) 発芽に光が必要な種子 知識問題

レタス。発芽に光が必要な種子を光発芽種子という（解答冊子）。ふつうの種子の発芽の条件は水・空気・適当な温度の3つで、光はいらない。レタスはその例外として覚える。
答え：ウ

K20 (12) 水に沈めても発芽するもの 知識問題

イネ。種子を水に沈めると空気（酸素）が足りなくなるので、ふつうは発芽しない。イネは少ない酸素でも発芽できるので、水の中でも芽を出す。水田で育てる作物、と結びつける。
答え：ウ

K20 (13) 両生類をすべて選ぶ 知識問題

イモリ・サンショウウオ・ウーパールーパー。ヤモリとカメはは虫類、クリオネは貝の仲間（解答冊子）。イモリ（両生類）とヤモリ（は虫類）は名前が似ているので、セットで区別する。ウーパールーパーはかっこの中の「サラマンダー」が手がかりで、サンショウウオの仲間。
答え：イ・ウ・オ

K20 (14) 酸素を運ぶ血球 知識問題

赤血球。血液の成分は4つをはたらきとセットで覚える。赤血球＝酸素を運ぶ／白血球＝殺菌作用／血小板＝傷口をふさぐ／血しょう＝二酸化炭素・栄養分・不要物を運ぶ（解答冊子）。
答え：赤血球

K20 (15) 酸素と結びつく色素 知識問題

ヘモグロビン。赤血球の中にある赤色の色素で、鉄とたんぱく質でできている（解答冊子）。酸素はこのヘモグロビンと結びついて、からだ中に運ばれる。
答え：ヘモグロビン

K20 (16) 図5の星座のAの星 資料問題・星の名前と色

👀 まず見るところ

【資料問題】資料の正体を1行：「南の低い空・S字の形にならぶ星座」＝さそり座。AはS字の上の方、頭に近い所にある明るい星 → さそり座の1等星アンタレス。解答らんは名前と色の2つ。

📚 前提知識

  • さそり座は夏の夜、南の低い空に見える。1等星アンタレスは赤色。
  • 星の色は表面温度で決まり、赤い星は表面温度が低い。

🔍 こう読み解く

  1. S字（つり針）の形と「南の低い空」の2つで、さそり座と決める。
  2. Aの星＝アンタレス。色のらんに「赤」と書く。
答え：名前 アンタレス　色 赤（色）

K20 (17) 南の低い空に見える星座 知識問題

おおいぬ座。冬の大三角をつくる星の1つシリウスをふくむ星座で、南の空の低いところを通る（解答冊子）。夏のさそり座、冬のおおいぬ座を「南の低い空」の組として覚える。
答え：エ

K20 (18) 台風の強さの階級 知識問題

猛烈。台風の強さは中心付近の最大風速で決まり、強い台風 → 非常に強い台風 → 猛烈な台風の順に強くなる。(19)の「大きさ」とは別のものさしなので、2つを分けて覚える。
答え：猛烈

K20 (19) 台風の大きさを決めるもの 知識問題

強風域。台風の大きさは強風域（強い風がふいている範囲）の半径で決まり、大型の台風 → 超大型の台風の順に大きくなる。「強さ＝最大風速」「大きさ＝強風域の半径」とセットにする。
答え：強風域

K20 (20) 三日月（月齢2）の南中時刻 条件文・計算

👀 まず見るところ

【条件文】部品は「15日後」と「12時→0時」。15日で12時間おくれるので、「1日あたり 12÷15＝4/5時間＝48分おくれる」に直して書く → 月齢2は2日分を12時に足すだけ。

📚 前提知識

  • 月の南中時刻は、毎日同じ時間ずつおそくなっていく。月が地球のまわりを公転しているため。

🔍 こう読み解く

  1. 新月の12時から満月の0時（＝24時）まで、15日で12時間おくれる。
  2. 1日あたり 12÷15＝4/5時間＝48分。
  3. 月齢2は2日後なので 48×2＝96分＝1時間36分。12時＋1時間36分＝13時36分。
答え：13時36分
コツ：解答らんは「時・分」。96分のまま足さず、1時間36分に直してから書く。

  • 聞かれているものに丸：(3)はA・(4)はB、(8)は水240g・(9)は水溶液230g、(6)は木片全体の体積。
