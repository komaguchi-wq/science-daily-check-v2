WC (1)① 10cm³と12cm³で量が変わらない理由 資料問題・記述

👀 まず見るところ

【資料問題】部品は資料の正体「石灰石1.0gに塩酸を増やしたときの二酸化炭素・cm³」と、表の右はし「225・225」。塩酸を増やしても増えない → なくなったのは石灰石のほう、と決まる。

📚 前提知識

  • 二酸化炭素は、石灰石と塩酸の両方がそろっている間だけ出る。どちらかがなくなると、もう一方をいくら増やしても増えない。

✍️ 答案の組み立て

  1. 要素A：石灰石がすべてとけている（なくなったほう）。
  2. 要素B：塩酸が余っている（残ったほう）。「どちらのときにも」に続けて、「〜から。」で結ぶ。
模範解答：（どちらのときにも）石灰石がすべてとけて、塩酸が余っているから。
自分で解くときのチェック：「なくなったもの」と「余ったもの」の2つが両方書けているか。

WC (1)② 塩酸の量と二酸化炭素の量のグラフ 資料問題・作図

👀 まず見るところ

【資料問題】部品は表の「8cm³で200」と「10cm³で225」。この間で増え方が変わるので、8と10の点を直線で結ばない。折れ曲がる点を計算で求めてから線をひく。

📚 前提知識

  • 石灰石が余っている間は、二酸化炭素は塩酸の量に比例する（原点を通る直線）。石灰石がなくなったあとは横ばいの直線になる。

🔍 こう読み解く

  1. 2・4・6・8cm³の点（50・100・150・200）を打つ。塩酸2cm³につき50cm³ずつ、つまり1cm³あたり25cm³増えている。
  2. 原点から4つの点を通る直線を、高さ225までそのままのばす。225÷25＝9 なので、折れ曲がるのは塩酸9cm³のところ。
  3. 9cm³から右は、高さ225のまま横にまっすぐひく（10・12の点を通る）。
答え：原点から（9cm³，225cm³）まで右上がりの直線、そこから右は225cm³で横ばいの直線（解答の図）
自分で解くときのチェック：折れ曲がる点が8と10のまん中の「9」の上にあるか。たてのじくの225は200と250のまん中。

WC (1)③ 石灰石1.0gをすべてとかす塩酸 資料問題・計算

👀 まず見るところ

【資料問題】部品は表の最大「225」と、増え方「2cm³で50」。増え方は「塩酸1cm³あたり25cm³」に直して表の横に書く → 225を出すのに必要な塩酸が、そのまま答えになる。

📚 前提知識

  • 「すべてとかすのに必要な量」＝石灰石と塩酸がちょうどなくなる量。グラフが折れ曲がる点の塩酸の量と同じ。

🔍 こう読み解く

  1. 塩酸1cm³あたりの二酸化炭素：50÷2＝25cm³。
  2. 石灰石1.0gから出る二酸化炭素は最大225cm³。225÷25＝9cm³。
  3. 表で225になっている「10」を答えにしない。10cm³では塩酸が1cm³余っている。
答え：9cm³
コツ：余白に「石灰石1.0g ＋ 塩酸9cm³ → 二酸化炭素225cm³」と1行書く。④はこの1行を使う。

WC (1)④ 塩酸16cm³と石灰石2.0g 条件文・計算

👀 まず見るところ

【条件文】部品は③と変わった「16cm³」「2.0g」に丸。③の1行「1.0g＋9cm³→225cm³」を2倍に直して横に書く → どちらが足りないかが決まり、足りないほうで計算する。

📚 前提知識

  • 出てくる気体の量は、先になくなるほうで決まる。両方の量が変わったときは、まず「ちょうど」の量とくらべる。

🔍 こう読み解く

  1. 石灰石2.0gをすべてとかすには、塩酸が 9×2＝18cm³ 必要。
  2. 塩酸は16cm³しかない → 塩酸が先になくなる（石灰石が余る）。
  3. 塩酸1cm³あたり25cm³なので、25×16＝400cm³。
答え：400cm³
コツ：225×2＝450 は、塩酸が18cm³以上あるときの量。「石灰石が2倍だから2倍」と決める前に、塩酸が足りるかを確かめる。

WC (2)① ビーカーの重さ まざり型・計算

👀 まず見るところ

【まざり型→条件文】部品は「石灰石3.0gをビーカーに入れ」と、表の左はし「0gで83」。83の下に「ビーカー＋石灰石3.0」と直して書く → ひき算1回で決まる。

📚 前提知識

  • 塩酸をまだ加えていないときは、反応が起きていない。はかった重さは入れた物の重さの合計そのまま。

🔍 こう読み解く

  1. 塩酸0gのときの83gは、ビーカーと石灰石3.0gの合計。
  2. 83−3.0＝80g。
答え：80g

WC (2)② 塩酸20gを加えた直後の全体の重さ まざり型・計算

👀 まず見るところ

【まざり型→条件文】部品は「気体の発生が始まる直前」に丸。表の102.6は「止まったあと」の重さなので使わない。直前＝まだ何もにげていない → 入れた物の合計に直して書く。

📚 前提知識

  • 反応の前は、重さはたした分だけ増える。気体が空気中へにげてはじめて軽くなる。

🔍 こう読み解く

  1. はじめの重さ83gに、加えた塩酸20gをたす。
  2. 83＋20＝103g。
答え：103g

WC (2)③ 直前と止まったあとの重さの差 まざり型・計算

👀 まず見るところ

【まざり型→条件文】部品は「直前」と「止まったあと」の2つに丸。直前＝②の103、止まったあと＝表の102.6。2つを上下にならべて書く → 差をとるだけ。

📚 前提知識

  • ②で出した「入れた物の合計」と、表の「はかった重さ」は別の数字。前者は計算で出し、後者は表から読む。

🔍 こう読み解く

  1. 直前：103g（②の答え）。止まったあと：102.6g（表の20gのらん）。
  2. 103−102.6＝0.4g。
答え：0.4g

WC (2)④ 塩酸20gで発生した気体の重さ まざり型・計算

👀 まず見るところ

【まざり型→条件文】部品は「発生した気体は何g」に丸。気体はビーカーの外へにげるので、「軽くなった分＝気体の重さ」に直して書く → ③の差がそのまま答え。

📚 前提知識

  • 発生した二酸化炭素はビーカーから空気中へ出ていく。そのため全体の重さは、出ていった気体の分だけ軽くなる（表の重さが、入れた合計より少ないことから分かる）。

🔍 こう読み解く

  1. ③で求めた差0.4gは、ビーカーからなくなった物の重さ。
  2. なくなったのは発生した気体だけなので、気体は0.4g。
答え：0.4g
コツ：ここで表の下に「塩酸20g → 気体0.4g」と書く。⑤はこの1行と、全体像の表の4行目を使う。

WC (2)⑤ 石灰石3.0gをすべてとかす塩酸 まざり型・計算

👀 まず見るところ

【まざり型→資料問題】部品は表の「80gで161.4」と「100gで181.2」。はかった重さを「入れた合計−はかった重さ＝気体」に直して表の下に書く → 気体が1.8gで止まるところが切れ目と決まる。

📚 前提知識

  • (1)③と同じ考え方。「すべてとかすのに最低必要な量」＝気体がちょうど最大になる塩酸の量。

🔍 こう読み解く

  1. 気体の重さを順に出す：0.4・0.8・1.2・1.6（80gまでは20gごとに0.4gずつ）→ 100gで183−181.2＝1.8、120gで203−201.2＝1.8。ここで増えなくなっている。
  2. 石灰石3.0gから出る気体は最大1.8g。塩酸20gで0.4g出るので、1.8÷0.4＝4.5。
  3. 20×4.5＝90g。
答え：90g
コツ：表で増え方が変わる80gや100gを答えにしない。切れ目は80gと100gの間にあり、割り算でしか出ない。(1)③の「9cm³」と同じ形。

WC (2)⑥ 石灰石にふくまれ、塩酸と反応する物質 知識問題

炭酸カルシウム。石灰石のおもな成分で、塩酸と反応して二酸化炭素を出す。貝がら・卵のから・大理石も同じ成分なので、塩酸をかけると同じように二酸化炭素が出る。
答え：炭酸カルシウム

WC まとめ 解く前に書く3行

  • (1)：「塩酸1cm³あたり25cm³」「石灰石1.0g＋塩酸9cm³→225cm³」。量が両方変わったら、足りないほうで計算する。
  • (2)：「入れた合計−はかった重さ＝気体」。表の下に気体の行を書き足してから小問に入る。
  • 切れ目（9cm³・90g）は表にのっていない。最大の気体÷1あたりの気体で求める。
