X1 (1) Aより明るく光る豆電球 条件文・すべて選ぶ

👀 まず見るところ

【条件文】部品は「同じ種類の乾電池と豆電球」と、答え方の「すべて選び」に丸。Aの電流を1として、B〜Gの豆電球の横に電流の数字を書く（図に置く）→ 1より大きいものが答え。

📚 前提知識

  • 豆電球は、流れる電流が大きいほど明るい。
  • 乾電池の直列は個数ぶん電流を増やし、豆電球の直列は個数ぶん電流を減らす。乾電池を並列にしても、豆電球の電流は1個のときと変わらない。

🔍 こう読み解く

  1. C：乾電池3個の直列に豆電球1個 → 3。
  2. D：乾電池2個の直列に、豆電球が1個ずつ並列でつながる → どちらも 2。
  3. 残りは B 1/2、E 1（乾電池の並列）、F 2/3（乾電池2個÷豆電球3個）、G 1/2。どれも1以下なので入らない。
答え：C・D
自分で解くときのチェック：Eは乾電池が2個あっても並列なので、明るさはAと同じ。「より明るく」には入れない。

X1 (7)② スイッチ1だけを閉じたとき まざり型・スイッチの切りかえ

👀 まず見るところ

【まざり型→条件文】部品は表の②の行「1 閉じる・2 開く」と、答えの順「（X，Y，Z）」に丸。図3のスイッチ1を線でつないで書く（図に置く）→ 上の頂点から中心への近道ができ、X・Yを通らずZだけに流れる。

📚 前提知識

  • ①（両方開く）は X→Y→Z の3個直列なので、3つとも暗い（△）。豆電球が1個だけになれば明るい（○）。
  • 閉じたスイッチは導線と同じ。豆電球と並んだ近道になると、電流はスイッチの方に流れる（解答冊子）。

🔍 こう読み解く

  1. 図3をたどる：乾電池 → 上の頂点 → X → 左下の点 → Y → 中心 → Z → 右下の点 → 乾電池。スイッチ1は上の頂点と中心を結ぶ。
  2. スイッチ1を閉じると、上の頂点から中心へ直接行ける。遠回りのX・Yには流れない → X ×、Y ×。
  3. 中心からはZを通るしかない。豆電球はZの1個だけ → Z ○。（×，×，○）はケ。
答え：ケ
自分で解くときのチェック：選択肢は（X，Y，Z）の順。○の場所が1番目か3番目かで ウ と ケ が分かれる。

X1 (7)③ スイッチ2だけを閉じたとき まざり型・スイッチの切りかえ

👀 まず見るところ

【まざり型→条件文】部品は②と変わった「1 開く・2 閉じる」に丸。図3の底辺のスイッチ2を線でつないで書く（図に置く）→ 左下の点から右下の点への近道ができ、Y・Zを通らずXだけに流れる。

📚 前提知識

  • スイッチ2は、左下の点と右下の点を結ぶ。Y→中心→Z の道と並んでいる。
  • 近道と並んだ豆電球には流れない。②とは消える豆電球が入れかわる。

🔍 こう読み解く

  1. 乾電池 → 上の頂点 → X → 左下の点、までは①と同じ。Xには流れる。
  2. 左下の点からは、スイッチ2を通って右下の点へ直接もどれる。遠回りのY・Zには流れない → Y ×、Z ×。
  3. 豆電球はXの1個だけ → X ○。（○，×，×）はウ。
答え：ウ
自分で解くときのチェック：②はZだけ、③はXだけ。スイッチ1はX・Yを、スイッチ2はY・Zをとばす近道、と図に書いておくと④にそのまま使える。

X1 (7)④ スイッチ1・2を両方閉じたとき まざり型・スイッチの切りかえ

👀 まず見るところ

【まざり型→条件文】部品は「1 閉じる・2 閉じる」に丸。導線でつながった点を同じ印でまとめる：上の頂点と中心に＋、左下と右下に−と書く（図に置く）→ X・Y・Zはどれも＋と−の間にあり、3個の並列になる。

📚 前提知識

  • 導線（閉じたスイッチ）でつながった点どうしは、同じ1つの点として考えてよい。
  • 並列の豆電球は、1個1個が乾電池に1個だけつないだときと同じ明るさで光る。

🔍 こう読み解く

  1. スイッチ1で 上の頂点＝中心、スイッチ2で 左下の点＝右下の点。乾電池は上の頂点と右下の点の間にある。
  2. Xは 上の頂点―左下、Yは 左下―中心、Zは 中心―右下。3つとも「上の頂点・中心」の側と「左下・右下」の側を結んでいる。
  3. 3個とも乾電池に直接つながる並列 → すべて明るく光る。（○，○，○）はア。
答え：ア
自分で解くときのチェック：「②でX・Yが消え、③でY・Zが消えるから、④は全部消える」としない。近道が2本そろうと、豆電球をとばす道ではなく並列の道になる。

X1 まとめ

  • 図1は、豆電球の横と乾電池の横の2か所に数字を書く。明るさ＝豆電球の数字、光っている時間＝乾電池の数字。
  • 乾電池の数字がふえるのは「豆電球の並列」（D・G）、へるのは「乾電池の並列」（E）。
  • 導線・閉じたスイッチは近道。豆電球の両はしを結ぶ近道ができたら、その豆電球は消える。つながった点を同じ印でまとめると、並列かどうかが見える。
