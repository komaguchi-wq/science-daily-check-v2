WS-22 ウィークリーチェック WS-22（WS-21「身のまわりの生き物」の復習・10問）

WC 全体像 WS-21「身のまわりの生き物」の復習 10問（各10点・100点）

メダカ(1)〜(4)、カエル(5)(6)、糸のもとになる生き物(7)、昆虫の変態(8)、冬ごし(9)、落ち葉を食べる動物(10)。どれも知識の確認だが、答え方が「間違っているもの／すべて選ぶ／カタカナで」と問ごとに変わる。設問の答え方に丸をつけてから選択肢を見る。

今回は50／100点。落とした5問のうち(1)(10)は「しりびれの形」「ムカデの食べ物」の取りちがえ、(5)は図の「尾があるか」を見落とした、(4)はカダヤシが魚だと分からなかった、(7)は「カイコ」で止めて「カイコガ」まで書かなかった。

WC (1) メダカのオスとメスの見分け方 素材文・間違っているもの

👀 まず見るところ

【素材文】聞かれ方「間違っているもの」に丸。部品は各文の「せびれ／腹／しりびれ」に丸をつけ、横に「オス＝平行四辺形・メス＝三角形」と書く（3語で書く）→ しりびれの文（エ・オ）はこのメモと見比べるだけで決まる。

📚 前提知識

  • オス：せびれに切れこみがある。しりびれは大きい平行四辺形（産卵のときメスをだきかかえるため）。
  • メス：せびれに切れこみがない。しりびれは後ろが短い三角形に近い。腹は卵でふくらんでいる。

🔍 こう読み解く

  1. ア・イ（せびれの切れこみ）、ウ（メスの腹）は正しい文。
  2. エ「メスのしりびれは後ろが短い」→ 三角形に近い＝後ろが短い → 正しい。
  3. オ「オスのしりびれは三角形に近い」→ オスは平行四辺形。メスの形と入れかわっている → これが間違い。
答え：オ
今回：エ ×（答え オ）。知識＝しりびれの形をオスとメスで取りちがえた。エとオは同じしりびれの話なので、片方が正しければもう片方が間違い。「オス＝平行四辺形・メス＝三角形」と書いてから2つを見比べる。

WC (2) メダカの産卵 素材文・間違っているもの

👀 まず見るところ

【素材文】聞かれ方「間違っているもの」に丸。部品は各文の回数や数字「早朝」「1度だけ」「1〜1.5mm」に丸 → 「1度だけ」と言い切る文は、反例（春から夏に何度も産む）が1つあれば間違いと決まる。

📚 前提知識

  • メダカは春から夏の早朝に産卵し、暖かい間はくり返し何度も産む。
  • 産んだ卵はしばらくメスの腹（はらびれとしりびれの間）についていて、その後水草に産みつける。オスはメスの前でくるっと回って求愛する。

🔍 こう読み解く

  1. ア（早朝）・ウ（卵をつけたまま泳ぐ）・エ（オスの求愛）・オ（卵の直径）はどれも正しい文。
  2. イ「1年のうち1度だけ」→ 産卵の時期には何度も産む → これが間違い。
答え：イ
今回：イ ○。

WC (3) 卵と精子が結びついたもの 知識問題

受精卵。メスの卵とオスの精子が結びつくことを受精といい、受精した卵が受精卵。受精しなかった卵は育たない。漢字3字。
答え：受精卵
今回：受精卵 ○。

WC (4) メダカと同じ方法で酸素を取り入れる生き物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「メダカと同じ方法で体内に酸素」と「すべて選び」に丸。「メダカと同じ方法」は「えらで呼吸」に直して書く → 5匹それぞれの横に えら／肺 を書いてから選ぶ。

📚 前提知識

  • 魚（メダカ・エイ・カダヤシ）はえらで水中の酸素を取り入れる。
  • イルカ（ほ乳類）・ペンギン（鳥類）・カメ（は虫類）は肺で呼吸する。水中で暮らしていても、息つぎに水面へ上がる。

🔍 こう読み解く

  1. ア イルカ＝ほ乳類 → 肺。イ ペンギン＝鳥 → 肺。ウ カメ＝は虫類 → 肺。この3つは消える。
  2. エ カダヤシ＝メダカによく似た小さな魚 → えら。オ エイ＝魚 → えら。
  3. 「すべて」なので、エとオの2つを書く。
答え：エ・オ
今回：オ ×（答え エ・オ）。知識＝カダヤシが魚だと分からず落とした。「すべて選び」に丸があれば、1つ見つけて止めずに5匹全部に えら／肺 を書いて確かめる。

WC (5)①② オタマジャクシからカエルへ 資料問題・図の順番

👀 まず見るところ

【資料問題】部品は図の正体「あしと尾の有無」。ア〜オの5枚それぞれに 後あし・前あし・尾 の有無を書く（正体を1行）→ 「後あし→前あし→尾が消える」の順に並べれば①②が決まる。①②はどちらも尾がまだある段階。

📚 前提知識

  • オタマジャクシは後あしが先に出て、次に前あしが出る。最後に尾が縮んで消え、カエルの形になる。
  • このとき呼吸も、えら呼吸から肺と皮ふの呼吸へ変わる。

🔍 こう読み解く

  1. 5枚を読む：ア＝前あしだけ・短い尾、イ＝後あしだけ・尾なし、ウ＝前あしだけ・長い尾、エ＝後あしだけ・尾あり、オ＝前後あし・尾あり。ア・ウ（前あしだけ）とイ（尾が先に消えた）は実際にはない姿。
  2. ①は後あしが出たばかりで尾はまだある → エ。
  3. ②は前あしも出て、尾がまだ残っている → オ。そのあと尾が消えて矢印の先のカエルになる。
答え：① エ　② オ
今回：①イ ②オ ×（答え ①エ ②オ）。部品を拾えなかった＝イもエも「後あしだけ」で、ちがいは尾の有無。イは尾が消えた姿なので、後あしが出たばかりの①には合わない（尾が消えるのは前あしが出たあと）。5枚に あし と 尾 の2つを書いてから選ぶ。

WC (6) カエルと同じ両生類 知識問題

エ（イモリ）。両生類は子のころはえらで水中に、おとなは肺と皮ふで呼吸して水辺で暮らす。イモリ＝両生類、ヤモリ＝は虫類と名前が似た2つを区別する。カメ・ワニもは虫類、イルカはほ乳類。
答え：エ
今回：エ ○。

WC (7)①②③ きぬ糸・毛糸・もめん糸のもとの生き物 知識問題

①カイコガ ②ヒツジ ③ワタ。きぬ糸はカイコガの幼虫（カイコ）がさなぎになるときに作るまゆの糸、毛糸はヒツジの毛、もめん糸はワタの実の綿毛から作る。カタカナ指定。
答え：① カイコガ　② ヒツジ　③ ワタ
今回：①カイコ ②ヒツジ ③ワタ ×（①が答えと異なる）。知識＝生き物の名前は成虫の「カイコガ」。「カイコ」は幼虫の呼び名なので、名前として答えるときは「ガ」まで書く。

WC (8) さなぎの時期のある昆虫 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「さなぎの時期のある」と「すべて選び」に丸。「さなぎがある」は「完全変態」に直して書き、ア〜コの10匹それぞれに 完／不 を書く → 不完全変態の5匹を消せば残りが答え。

📚 前提知識

  • 完全変態＝卵→幼虫→さなぎ→成虫。チョウ・ガ、甲虫（テントウムシ・ゲンゴロウ・カブトムシ）、ハチ・アリ、ハエ・アブ。
  • 不完全変態＝卵→幼虫→成虫。バッタのなかま（コオロギ・キリギリス・スズムシ）、トンボ、カマキリ、セミ。

🔍 こう読み解く

  1. 不完全変態を先に消す：ア カマキリ、イ トンボ、ウ コオロギ、エ キリギリス、オ スズムシ。
  2. 残った カ テントウムシ（甲虫）、キ ゲンゴロウ（甲虫）、ク アリ（ハチのなかま）、ケ ハエ、コ アブ の5つがさなぎになる。
答え：カ・キ・ク・ケ・コ
今回：カ・キ・ク・ケ・コ ○。紙面のキリギリスに印、アリに下線と、1匹ずつ確かめた跡がある。

WC (9) おとなの姿のまま冬を越す動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「おとなの姿のまま」と「冬を越す」に丸。5匹の横に「冬の姿（おとな／幼虫／さなぎ／卵）」を書く → 昆虫の2匹は何の姿で冬を越すかで決まる。

📚 前提知識

  • ヘビ・カエル・クマは、おとなの姿のまま土の中や穴で冬眠する。
  • 昆虫は種類ごとに冬を越す姿が決まっている。カブトムシは幼虫、モンシロチョウはさなぎ、カマキリは卵。

🔍 こう読み解く

  1. ア ヘビ＝冬眠、イ カエル＝土の中で冬眠、ウ クマ＝穴で冬眠 → おとなのまま。
  2. エ カブトムシ＝幼虫、オ モンシロチョウ＝さなぎ → 消える。
答え：ア・イ・ウ
今回：ア・イ・ウ ○。

WC (10) 落ち葉を食べる動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「ダンゴムシと同様に」と「落ち葉が小さくなったものをえさ」に丸。5匹の横に「食べ物（落ち葉／虫）」を書く → 落ち葉を食べるものだけ残す。

📚 前提知識

  • 落ち葉を食べて土に返す小さな動物＝ダンゴムシ・ワラジムシ・ヤスデ・ミミズ。
  • ムカデは小さな虫をおそって食べる肉食。モグラは土の中でミミズなどを食べる。どちらも落ち葉は食べない。

🔍 こう読み解く

  1. ア ミミズ＝落ち葉 ○。ウ ワラジムシ＝ダンゴムシに似た形で落ち葉 ○。オ ヤスデ＝落ち葉 ○。
  2. イ モグラ＝ミミズを食べる ×。エ ムカデ＝虫を食べる ×。
答え：ア・ウ・オ
今回：ア・ウ・エ・オ ×（答え ア・ウ・オ）。知識＝ムカデを落ち葉のなかまに入れた。ムカデとヤスデは形が似ているが、ムカデ＝肉食、ヤスデ＝落ち葉。両方セットで直す。

WC まとめ 50／100点（5／10問）

  • 取れた：(2)産卵・(3)受精卵・(6)イモリ・(8)完全変態・(9)冬ごし。「すべて選ぶ」の(8)(9)は1匹ずつ確かめられている。
  • 落とした5問は、知識の取りちがえが3つ：(1)しりびれ、(4)カダヤシ＝魚、(10)ムカデ＝肉食。(5)は図の「尾があるか」の見落とし。(7)は名前を「カイコガ」まで書く。
  • 覚え直しはこの3つ：オス＝平行四辺形・メス＝三角形／後あし→前あし→尾が消える／ムカデは肉食・ヤスデは落ち葉。
