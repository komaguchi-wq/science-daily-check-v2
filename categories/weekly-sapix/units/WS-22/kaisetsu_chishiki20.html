K20 (1) N極が西に振れる方位磁針 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図1の正体「導線が方位磁針の上か下か」（導線が円の中まで描いてあれば上・円のふちで止まっていれば下）と、電池の＋極からたどった「電流の向き」。①〜⑥ごとにこの2つを図に書きこむと、振れる向きが決まる。

📚 前提知識

  • 導線の下に方位磁針（導線が上）を置き、電流が北へ流れると、N極は西へ振れる。「導線が下」「電流が南向き」のどちらか1つが逆なら東、2つとも逆なら西にもどる。
  • 導線が東西の向きだと、電流がつくる磁力は南北向き。針が指す向きと同じなので振れない。
  • 2本の導線にはさまれた方位磁針は、1本ずつ向きを出して足し合わせる。

🔍 こう読み解く

  1. 左の回路：電池の＋極は左。①は導線が上・電流は北向き → 西。②は導線が下・電流は南向き → 2つとも逆で西。
  2. 中の回路：電池の＋極は右なので、電流は右の導線を北向きに上がる。④は導線が上・電流は北向き → 西。③は東西の導線の下 → 振れない。
  3. 右の回路：⑤は2本とも導線が上で、電流はどちらも南向き → 1つ逆で東（2本分）。⑥は左の導線が下・右の導線が上で、電流はどちらも南向き（左の電池は＋極が左、右の電池は＋極が右）→ 下の左は西・上の右は東。東と西で打ち消して振れない。
答え：①・②・④
コツ：①〜⑥の横に「上／下」と「北／南」を1語ずつ書いてから向きを決める。頭の中だけで回すと②と⑤を取りちがえる。

K20 (2) ①より大きく振れる方位磁針 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は設問の「①より大きく」に線。①は導線1本・電流1本分。(1)で書きこんだ図のうち「導線が2本で同じ向き」に振らせる磁針だけが、①より大きく振れる。

📚 前提知識

  • 振れの大きさは、方位磁針のそばを流れる電流の大きさで決まる。同じ向きに振らせる導線が2本あれば2本分。
  • 逆向きに振らせる2本は打ち消し合い、電流が2本あっても振れない（⑥）。

🔍 こう読み解く

  1. ②④は電流1本分で①と同じ大きさ。③⑥は振れない。
  2. ⑤は2本の導線がどちらも東に振らせる → 2本分で①より大きい。
答え：⑤

K20 (3) ばねばかりでつるした棒の重さ 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様な棒」と図2の「16cm・8cm」。棒の重さは棒のまん中（左端から12cm＝支点の4cm左）に下向きの矢印で置く（直して書く）→ 支点まわりのつり合いの式に入る。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなす。
  • ばねばかりをつけた点が支点。つり合い＝左回り＝右回り（重さ×支点からの距離）。

🔍 こう読み解く

  1. 棒の長さは16＋8＝24cm。まん中は左端から12cm → 支点から4cm左。
  2. 右回り：60g×8cm＝480。左回り：棒の重さ×4cm。
  3. 棒の重さ＝480÷4＝120g。
答え：120g

K20 (4) ばねばかりAの値 条件文・計算

👀 まず見るところ

【条件文】部品は「ばねばかりAの値」に丸。ばねばかりは棒とおもりの全部を支えているので、「棒120g＋おもり60g」に直して書く。

📚 前提知識

  • つり合っているとき、ばねばかりが引く上向きの力＝下向きの力の合計。

🔍 こう読み解く

  1. 下向きの力は、棒120g＋おもり60g。
  2. A＝120＋60＝180g。
答え：180g
コツ：(3)を落とすと(4)も連動して落ちる。棒の重さが出たら、先に図2の矢印の横に「120g」と書いてから(4)へ進む。

K20 (5) 2本のばねでつるした棒とおもりの位置 条件文・計算

👀 まず見るところ

【条件文】部品は「100gで4cm／100gで8cm」と「水平に」（元の長さが同じ→2本ののびが同じ）、「棒の重さは60g」。60gは棒のまん中に矢印で置き、「A・Bに30gずつ」と直して書く。

📚 前提知識

  • 元の長さが同じ2本のばねで棒が水平＝のびが等しい。のびはかける重さに比例する。
  • 棒の重さ60gはまん中にあるので、両端のばねに30gずつ。
  • おもりが両端のばねに分ける重さの比は、おもりからの距離の逆比。

🔍 こう読み解く

  1. 棒の分：Aは30g→1.2cm、Bは30g→2.4cm。Bの方が1.2cm長いので、先にAへおもりの30g（1.2cm）をかけて長さをそろえる。
  2. 残り300−30＝270gは、同じのびになるように分ける。同じのびに必要な重さの比はA：B＝2：1 → A180g（7.2cm）・B90g（7.2cm）。
  3. おもりがA・Bにかける重さ＝210g：90g＝7：3。おもりはAに近く、左端から 24×3/10＝7.2cm。
答え：7.2cm
コツ：「重さの比7：3 → 距離の比3：7」の逆比で向きをまちがえやすい。重い方を支えるばねに近い、と1行書いてから距離を出す。

K20 (6) 2本のばねの長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「2つのばねは何cm」と、(5)で図に置いた「Aに240g・Bに120g」（棒30g＋おもりの分）。長さ＝元の長さ16cm＋のび、に直して書く。どちらで計算しても同じ値になる。

📚 前提知識

  • ばねの長さ＝元の長さ＋のび。水平なので2本は同じ長さ。

🔍 こう読み解く

  1. A：240g → のび 240÷100×4＝9.6cm → 16＋9.6＝25.6cm。
  2. 検算にB：120g → のび 120÷100×8＝9.6cm → 25.6cm。同じになれば(5)の分け方も合っている。
答え：25.6cm

K20 (7) ぶつかって止まるふりこ 条件文・記号選択

👀 まず見るところ

【条件文】部品は「長さの等しい」ふりこと「Aはその位置で止まりました」に丸。「ぶつけた方が止まり、ぶつけられた方が動く」を「重さが同じ」に直して書く。

📚 前提知識

  • 同じ重さの物がぶつかると、動いていた方は止まり、止まっていた方が同じ速さで動き出す（衝突のエネルギーがそのまま伝わる）。
  • ふりこの長さが同じなら、同じ速さで動き出したBは、Aをはなした高さと同じ高さまで上がる。

🔍 こう読み解く

  1. ① Aがその場で止まった → AとBの重さは等しい → ア。
  2. ② Bはぶつかったときの速さをそのまま受け取り、長さも同じ → Aと同じだけふれる → エ。
答え：① ア　② エ

K20 (8) 石灰石1.2gをちょうどとかす塩酸 資料問題・グラフ

👀 まず見るところ

【資料問題】部品は図5の正体「石灰石1.2g・塩酸の体積と気体の量」と、折れ線が横ばいになる点（気体250cm³で止まる）。「ちょうどとかす塩酸」＝横ばいになり始める点の塩酸、に直して書く。

📚 前提知識

  • 石灰石＋塩酸 → 二酸化炭素。石灰石が全部とけると、塩酸を増やしても気体は増えない（グラフが横ばい）。
  • ななめの線の部分では、気体の量は塩酸の量に比例する。

🔍 こう読み解く

  1. 目盛りの交点にのっている点をとる：塩酸30cm³で気体200cm³。
  2. 気体の最大は250cm³。200→250は×5/4。
  3. 塩酸も×5/4 → 30×5/4＝37.5cm³。
答え：37.5cm³
コツ：横ばいの始まりを目分量で「37〜38」と読まない。目盛りにのっている点から比で出す。

K20 (9) 石灰石3.6gに塩酸90cm³ 条件文・計算

👀 まず見るところ

【条件文】部品は「3.6g」（1.2gの3倍）と「塩酸90cm³」（37.5cm³の2.4倍）。倍率を2つ並べて書き、小さい方が「全部反応する側」だと決める。

📚 前提知識

  • 石灰石と塩酸は、少ない方が全部反応して気体の量を決める。多い方は余る。
  • (8)より、石灰石1.2gと塩酸37.5cm³がちょうど。このとき気体は250cm³。

🔍 こう読み解く

  1. 石灰石3.6g（×3）を全部とかすには塩酸37.5×3＝112.5cm³が必要。あるのは90cm³ → 塩酸が足りず、石灰石が余る。
  2. 気体は塩酸で決まる：90÷37.5＝2.4倍 → 250×2.4＝600cm³。
答え：600cm³
コツ：「×3」と「×2.4」を並べて書けば、どちらが余るかは見た瞬間に決まる。3倍の方で計算しない。

K20 (10) 空気中でべとべとになり二酸化炭素を吸う固体 知識問題

ウ 水酸化ナトリウム。空気中の水蒸気を吸って表面がとけ、べとべとになる（潮解）。二酸化炭素もよく吸収する。消石灰も二酸化炭素と反応するが、べとべとにはならない。
答え：ウ

K20 (11) 単子葉植物をすべて選ぶ 知識問題

イ カキツバタ（アヤメ科）・オ オニユリ（ユリ科）。単子葉植物＝子葉1枚・平行脈・ひげ根で、イネ科・ユリ科・アヤメ科・ツユクサ科がおもな仲間。カキ・モクレンは双子葉の木、ヒノキは裸子植物（針葉樹）。
答え：イ・オ

K20 (12) イネ科の植物をすべて選ぶ 知識問題

ア ススキ・ウ エノコログサ。イネ科＝イネ・ムギ・トウモロコシ・ススキ・エノコログサ。サトイモ（サトイモ科）・ソバ（タデ科）・ハス（ハス科）はイネ科ではない。
答え：ア・ウ

K20 (13) 卵からかえって幼虫になること 知識問題

ふ化。卵→幼虫が「ふ化」、幼虫→さなぎが「よう化」、さなぎ（または幼虫）→成虫が「羽化」。3つをセットにする。
答え：ふ化

K20 (14) 幼虫やさなぎから成虫になること 知識問題

羽化。「はね（羽）が出て成虫になる」と結びつける。完全変態はさなぎから、不完全変態は幼虫から羽化する。
答え：羽化

K20 (15) 息を吸うとき上がって胸腔を広げる骨 知識問題

ろっ骨。息を吸うときは、ろっ骨が上がり、横隔膜が下がって胸腔が広がる。はくときは逆。「骨」と聞かれたらろっ骨、「膜」なら横隔膜。
答え：ろっ骨

K20 (16) 冬至の日の昼の長さの順 資料問題・地図

👀 まず見るところ

【資料問題】部品は図6の正体「緯線と経線つきの日本地図」と、聞かれ方「冬至の日・昼の長さの長い順」に線。昼の長さは緯線（南北）で決まる、と直して書き、同じ緯線上の点を（ ）にする。

📚 前提知識

  • 冬至は南へ行くほど昼が長い（夏至は逆に北ほど長い）。春分・秋分はどこでも12時間。
  • 昼の長さを決めるのは緯度だけ。東西の位置は関係ない。

🔍 こう読み解く

  1. 図6の緯線をたどる：CとDは同じ緯線の上にある → （C・D）。
  2. 南から順に E → (C・D) → B → A。
答え：E・(C・D)・B・A

K20 (17) 春分の日の南中時刻の順 資料問題・地図

👀 まず見るところ

【資料問題】部品は聞かれ方「春分の日・南中時刻を早い順」に線。南中時刻は経線（東西）で決まる、と直して書き、同じ経線上の点を（ ）にする。(16)とは見る線が変わる。

📚 前提知識

  • 日の出・日の入り・南中は、東にある地点ほど早い（地球が西から東へ回るため）。
  • 春分は昼の長さがどこも同じなので、差がつくのは東西だけ。

🔍 こう読み解く

  1. 図6の経線をたどる：BとCは同じ経線の上にある → （B・C）。
  2. 東から順に A → (B・C) → D → E。
答え：A・(B・C)・D・E
コツ：(16)は緯線、(17)は経線。余白に「昼の長さ＝南北／時刻＝東西」と書いてから並べる。

K20 (18) 地平線近くの月をスケッチした方角 資料問題・記号選択

👀 まず見るところ

【資料問題】部品は図7の月の形「左側が細く光る」と、「地平線のすぐ近く」（出たばかり）。形から月の名前を決め、名前から出る時刻と方角を出す。

📚 前提知識

  • 左側が光る細い月＝二十七日月（明け方の月）。右側が光る細い月＝三日月（夕方の西の空）。
  • 月はどれも東から出て南を通り西にしずむ。二十七日月は午前3時ごろに東から出る（解答冊子）。

🔍 こう読み解く

  1. 左が細く光る → 二十七日月。
  2. 二十七日月が地平線の近くに見えるのは、東から出たところ（午前3時ごろ）→ エ。
答え：エ

K20 (19) 図7の月をスケッチした時刻 資料問題・記号選択

👀 まず見るところ

【資料問題】部品は(18)で決めた「二十七日月」と「出たところ」。月の出の時刻は形で決まる、と直して書き、下弦（0時）から数える。

📚 前提知識

  • 月の出は1日に約50分ずつおそくなる。上弦＝正午、満月＝18時、下弦＝0時、二十七日月＝3時ごろに出る。

🔍 こう読み解く

  1. 二十七日月は下弦（0時に出る）の4〜5日あと → 出るのは午前3時ごろ。
  2. 出たところのスケッチなので 3時 → イ。
答え：イ
コツ：(18)(19)は「形→名前→時刻・方角」の一本道。形を見た瞬間に「二十七日月」と余白に書けば、2問まとめて決まる。

K20 (20) 粒が角ばり、緑や灰色・赤褐色の模様がある堆積岩 知識問題

凝灰岩。火山灰が積もってできた堆積岩で、火山灰は流水のはたらきを受けずに積もるため粒が角ばっている。れき岩・砂岩・泥岩は流水で運ばれるので粒が丸い、と区別する。
答え：凝灰岩

K20 まとめ 解くときのチェック

  • 図つきの4種類（方位磁針・てことばね・グラフ・地図）は、部品を図に書きこんでから式や順番にする。(1)は「上／下・北／南」、(3)〜(6)は棒のまん中の矢印、(8)は目盛りの交点、(16)(17)は「南北／東西」。
  • 一問一答の(10)〜(15)(20)は迷わず即答して、残った時間を(5)(9)の計算に回す。
  • 覚え直しはこの3つ。導線が上・電流が北向き → N極は西／冬至の昼＝南ほど長い・南中＝東ほど早い／二十七日月＝左が光る・3時ごろ東から出る。
