X1 全体像 実験器具の使い方 8問

電流計・ろ過・試薬びん・こまごめピペット・アルコールランプと、道具が次々に変わるが、問われていることは1つ。「なぜそう使うのか」の理由を言えるかどうか。理由が言えれば、図のどこを見ればよいかが決まる。

図を見る問題（(1)③・(2)・(3)・(4)）は、先に設問の「50mAの端子」「正しく表している」「何重」に丸をつけてから図に入る。数字を答える(1)③・(3)・(6)は、答えに単位（mA・mm）が要るかどうかも設問で確かめる。

X1 (1)①② 電流計のつなぎ方と端子 素材文・器具の使い方

👀 まず見るところ

【素材文】部品は「電流の大きさがわからないとき」と「＋極側／−極側」に丸。図1の端子の数字（50mA・500mA・5A）を「小→大」と直して書く → わからないときはいちばん大きい5Aから、と決まる。

📚 前提知識

  • 電流計は「流れる電流そのもの」をはかる道具なので、はかりたい部分に直列につなぐ（並列につなぐと、電流計に大きな電流が流れてこわれる）。
  • ＋端子は1つ（図1のd・色のうすい端子）。−端子は3つで、乾電池の−極側からの導線をつなぐ。大きさがわからないときに小さい端子（50mA）を使うと、針がふり切れてこわれるおそれがある。

🔍 こう読み解く

  1. ①：豆電球に流れる電流をはかる → 豆電球と電流計を1本の道にする → 直列。
  2. ②：＋極側 → ＋端子＝図1で1つだけ色がちがう d。
  3. −極側 → 最初は最も大きい電流をはかれる 5A＝c。針のふれが小さければ 500mA（b）→ 50mA（a）の順につなぎかえる（解答冊子）。
答え：① 直列　② ＋極側 d　−極側 c
コツ：「わからないときは大きい端子から」は、電流計も電圧計も同じ決まり。理由は「ふり切れてこわさないため」の一言で持っておく。

X1 (1)③ 50mA端子で読む針のふれ 資料問題・目盛りの読み取り

👀 まず見るところ

【資料問題】部品は設問の「50mAの端子」に丸と、図2の正体「3段の目盛り（5・50・500）」を1行。50mA端子なら、右はしが50になる段（10・20・30…の段）だけを読む → 単位は mA。

📚 前提知識

  • 電流計の目盛りは、つないだ−端子の大きさを右はし（最大）として読む。5A端子なら0〜5、500mAなら0〜500、50mAなら0〜50。
  • 単位をつけて答える指示があるので、数字だけ（15）では不十分。

🔍 こう読み解く

  1. 針は、いちばん上の段（0〜5）で1と2のまん中を指している。
  2. 50mA端子なので、まん中の段（10・20・…・50）で読み直す → 10と20のまん中＝15。
  3. 単位をつけて 15mA。（5A端子なら1.5A、500mA端子なら150mA、と段ごとに言えると読みまちがえない。）
答え：15mA
コツ：目盛りを読む前に「どの端子につないだか」を設問から拾い、読む段を指で押さえてから針を見る。段を取りちがえると 1.5 や 150 になる。

X1 (6)①② アルコールランプの量としんの長さ 知識問題

アルコールは8分目程度まで入れ、しんは5mm程度出す。アルコールが少ないと、ランプの上の空間にアルコールと空気の混合気体が多くたまり、引火しやすくて危険（解答冊子）。しんを長く出しすぎると炎が大きくなりすぎる。火は横から近づけてつけ、消すときも横からふたをかぶせる。
答え：① 8　② 5

X1 (7) 炎の温度が高いのはどちらか 知識問題

アルコールランプ。アルコールはロウソクのロウより燃えやすく、空気とよくまざって完全燃焼に近い燃え方をするので、炎の温度が高い。ロウソクの炎は、まだ燃え切っていないすすが光って見えるぶん温度が低く、ものをあたためたり加熱したりする実験ではアルコールランプを使う。
答え：アルコールランプ

X1 (8) 燃焼後にできる共通の物 知識問題

二酸化炭素と水。アルコールもロウも炭素と水素をふくむ物なので、燃えると炭素は二酸化炭素に、水素は水（水蒸気）になる。石灰水が白くにごる・集気びんの内側がくもる、で確かめられる。「すべて答える」なので2つとも書く。
答え：二酸化炭素・水
