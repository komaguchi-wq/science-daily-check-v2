(1)〜(6)は実験の文を読んで、ア〜コからグラフの形を1つ選ぶ。見るのは3つだけ。原点を通るか（0のとき0か）／まっすぐか曲がるか／途中で折れる・止まるか。この3つを文から決めれば、10個のグラフは1つにしぼれる。

(7)①〜④は「正比例A／反比例B／どちらでもないC」。正比例は「2倍にすると2倍」、反比例は「2倍にすると半分（かけ算が一定）」。増えるけれど2倍にならないもの（ふりこの周期、支点にかかる力）がC。

今回は100／100点。

WC (1) 自然に落下するボール・時間と落ちた距離 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「自然に落下」と、軸の「横＝手をはなしてからの時間／縦＝手の位置から落ちた距離」に丸。はなした瞬間は時間0・距離0なので「原点を通る」と書く → だんだん速くなる落下は、傾きが大きくなっていく曲線に決まる。

📚 前提知識

  • 落ちるボールは、時間がたつほど速さが増す。同じ0.1秒でも、あとの0.1秒ほど進む距離が長い（WS-28 グラフの問題②）。
  • 進む距離が増えていく＝グラフは右へ行くほど急になる（上に反る曲線）。

🔍 こう読み解く

  1. 0秒のとき落ちた距離は0 → 原点を通る。原点を通らないウ・オ・ク・ケ・コは消える。
  2. まっすぐ（ア）なら一定の速さ。落下は速くなるので、曲線で右ほど急＝カ。
  3. クも右ほど急だが、縦軸の途中から始まるので×。
答え：カ
今回：カ ○。

WC (2) ニクロム線の長さと電流計の値 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「電流を流すニクロム線の長さを変えて」と、軸の「横＝ニクロム線の長さ／縦＝電流計の値」に丸。長さは電流の流れにくさなので「長さ2倍 → 電流は半分」に直して書く → 反比例の曲線に決まる。

📚 前提知識

  • ニクロム線は長いほど電流が流れにくい（長さ2倍で流れにくさ2倍）。だから電流は長さに反比例する。
  • 反比例のグラフは、両方の軸に近づきながら下がる曲線で、軸にはふれない（0にはならない）。

🔍 こう読み解く

  1. 長くなるほど電流は減る → 右下がりのグラフ。キ・ケ・コにしぼる。
  2. コ（まっすぐ0まで減る）は、ある長さで電流が0になる形。長くしても流れにくくなるだけで0にはならないので×。
  3. 反比例の「2倍で半分」を満たすのは、両方の軸に近づいていくキ。ケは縦軸の途中から始まる形なので×。
答え：キ
今回：キ ○。
コツ：キとケのちがいは左端。反比例は左端が軸にくっつかずどこまでも上がる（キ）。ケは「0のときの値がある」グラフ。

WC (3) 中和と残った固体の重さ 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「体積が1：1のときに中和」「塩酸を10cm³ずつ」「水酸化ナトリウム水溶液を0cm³から20cm³まで」に丸。「中和＝10cm³のところ」と直して書く → 10cm³で折れ曲がる折れ線に決まる。

📚 前提知識

  • 塩酸＋水酸化ナトリウム水溶液 → 食塩＋水。蒸発させて残る固体は、中和するまでは食塩だけ。
  • 中和したあとにさらに加えた水酸化ナトリウム水溶液は、蒸発させると水酸化ナトリウムの固体として残る。同じ量を加えても、食塩に変わって残るときより水酸化ナトリウムのまま残るときの方が軽いので、増え方がゆるやかになる。

🔍 こう読み解く

  1. 0cm³のとき、塩酸だけを蒸発させても何も残らない → 原点を通る。
  2. 0〜10cm³：加えた分だけ食塩が増える → まっすぐ増える。
  3. 10cm³で中和。それより先は食塩は増えず、加えた水酸化ナトリウムがそのまま残る分だけ増えるので、傾きがゆるくなって増え続ける＝エ。イ（止まる）は、残るものが食塩だけなら正しいが、水酸化ナトリウムも固体で残るので×。
答え：エ
今回：エ ○。
コツ：縦軸が「残った固体」ならエ、「できた食塩の重さ」ならイ。縦軸の言葉で折れたあとの形が変わる。

WC (4) 切り取ったばねの長さとのび 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「いろいろな長さに切り」と「同じ重さのおもり」に丸。ばねはつなげたのと同じことなので「長さ2倍 → のびも2倍」に直して書く → 原点を通る直線に決まる。

📚 前提知識

  • 同じばねを2本直列につなぐと、1本のときの2倍のびる。長さ2倍のばねは2本つないだのと同じ。
  • だから、おもりが同じなら「ばねの長さ」と「のび」は正比例。長さ0なら のび0。

🔍 こう読み解く

  1. 長さが0なら のびも0 → 原点を通る。
  2. 長さが2倍・3倍で のびも2倍・3倍 → まっすぐ増える直線＝ア。
答え：ア
今回：ア ○。

WC (5) 水の温度と気体の溶ける量 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「気体A」と、軸の「横＝水の温度／縦＝溶けた気体Aの体積」に丸。気体は固体と逆で「温度が上がる → 溶ける量が減る」と直して書く → 右下がりの曲線に決まる。

📚 前提知識

  • 気体は、水の温度が高いほど溶けにくい。あたためた水からあわが出てくるのはこのため。固体（ホウ酸・食塩など）は温度が高いほど溶けやすい、と逆向きでセットにする。
  • 減り方は、はじめ大きく、温度が上がるとゆるやかになる（0になるわけではない）。

🔍 こう読み解く

  1. 温度が上がると減る → 右下がり。キ・ケ・コにしぼる。
  2. 0℃でも溶ける量には決まった値がある → 縦軸の途中から始まる。左端が軸にくっつかないキは×。
  3. コ（まっすぐ減って0）とケ（だんだんゆるやかに減る）のうち、気体の溶け方はケ。
答え：ケ
今回：ケ ○。

WC (6) 2つの台ばかりの上の棒と鉄球 条件文・グラフの形

👀 まず見るところ

【条件文】部品は「ある重さの棒」と「鉄球をAからBに向かって移動」に丸。棒の重さは図のまん中に下向きの矢印で置く（直して書く）→ 鉄球がAの真上でもBは棒の重さの分を支えているので、縦軸の途中から始まる直線に決まる。

📚 前提知識

  • 棒の上の鉄球がBに近づくほど、Bが支える分が増える。てこと同じで、Bの値は「Aからの距離」に比例して増える（まっすぐ）。
  • 棒に重さがあると、鉄球がどこにあっても棒の重さの半分はBにかかっている。これがグラフの出発点（0でない）。

🔍 こう読み解く

  1. 鉄球がAの真上（距離0）のとき、鉄球の分はAが全部支える。でもBには棒の重さの半分がのっている → 縦軸の途中から始まる。
  2. 鉄球をBへ動かすと、Bの値は距離に比例してまっすぐ増える → オ。
  3. アは棒の重さがないときの形。「ある重さの棒」の一言でオに変わる。
答え：オ
今回：オ ○。
コツ：「ある重さの棒」「棒の重さは考えない」で答えがア／オに分かれる。棒の文に丸をつけてから選ぶ。

WC (7)① ふりこの長さと周期 条件文・正比例か反比例か

👀 まず見るところ

【条件文】部品は「ふりこの長さと周期」に丸。正比例は「2倍で2倍」、反比例は「2倍で半分」と余白に書き、ふりこを当てはめる → 長さ4倍で周期2倍なので、どちらでもないと決まる。

📚 前提知識

  • ふりこの周期は長さだけで決まる（おもりの重さ・ふれはばは関係ない）。
  • 長くすると周期は長くなるが、長さ4倍で周期2倍。2倍にして2倍にはならない。

🔍 こう読み解く

  1. 長さを増やすと周期も増える → 反比例ではない。
  2. でも2倍にしても周期は2倍にならない（4倍で2倍）→ 正比例でもない → C。
答え：C
今回：C ○。

WC (7)② てこがつり合うときの距離とおもりの重さ 条件文・正比例か反比例か

👀 まず見るところ

【条件文】部品は「つり合うとき」と図1の「6cm」「おもりA 50g」に丸。左側のかたむけるはたらきを「50×6＝300」と直して図に書く → 右は「距離×重さ＝300」で一定なので、反比例と決まる。

📚 前提知識

  • てこのつり合い：重さ×支点からの距離が左右で等しい。
  • かけ算の答えが一定のとき、2つの量は反比例（片方2倍なら、もう片方は半分）。

🔍 こう読み解く

  1. 左のはたらきは 50g×6cm＝300。右も300で固定。
  2. 右の距離を2倍にすると、おもりは半分でつり合う → 「距離×重さ＝300」＝反比例＝B。
答え：B
今回：B ○。

WC (7)③ 右のおもりの重さと支点にかかる力 条件文・正比例か反比例か

👀 まず見るところ

【条件文】部品は「右のうでのおもりの重さ」と「支点にかかる力」に丸。②と変わった部分は「距離でなく支点の力」。支点にかかる力を「50＋右のおもり」と直して書く → 50が足されるだけなので、どちらでもないと決まる。

📚 前提知識

  • 支点が支える力＝棒にのっている重さの合計（おもりA 50g＋右のおもり。棒の重さは図にないので考えない）。
  • 「足し算」の関係は正比例ではない。右のおもりを2倍にしても、支点の力は2倍にならない（50＋20＝70 → 50＋40＝90）。

🔍 こう読み解く

  1. 右のおもりを重くすると、支点の力は増える → 反比例ではない。
  2. 増えるが「2倍で2倍」にはならない（はじめから50gが乗っている）→ 正比例でもない → C。
答え：C
今回：C ○。
コツ：グラフにすると(6)のオの形（縦軸の途中から始まる直線）。「まっすぐでも原点を通らなければ正比例ではない」が②③のちがい。

WC (7)④ 等速直線運動の距離と時間 条件文・正比例か反比例か

👀 まず見るところ

【条件文】部品は「等速直線運動」と図2の「0.1秒ごとに20cm」に丸。「速さが一定＝同じ時間で同じ距離」と直して書く → 時間2倍で距離2倍だから、正比例と決まる。

📚 前提知識

  • 等速直線運動＝速さも向きも変わらない動き。距離＝速さ×時間で、速さが一定なら距離は時間に正比例。

🔍 こう読み解く

  1. 図2を読む：0.1秒で20cm、0.2秒で40cm、0.5秒で100cm。
  2. 時間を2倍・5倍にすると距離も2倍・5倍、0秒で0cm → 正比例＝A。
答え：A
今回：A ○。

WC まとめ 100／100点

  • 全問正解。グラフの形は「原点を通るか／まっすぐか曲がるか／折れるか」の3点で選べている。
  • 差がつきやすいのは(2)キとケ・(5)ケとキ・(6)アとオ。左端（0のときの値）がどこから始まるかを先に決めると迷わない。
  • (7)は「2倍で2倍＝正比例」「かけ算が一定＝反比例」「足し算や4倍で2倍＝どちらでもない」の3語で分ける。
