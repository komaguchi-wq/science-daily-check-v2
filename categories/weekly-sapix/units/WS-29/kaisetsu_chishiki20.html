WS-29「実験器具」のまとめテスト。前半(1)〜(9)は実験の条件と計算（電磁石の比べ方・さおばかり・浮力・落下・金属の燃焼）、後半(10)〜(20)は一問一答と図の読み取り（とけるの意味・花と種子・メダカ・肝臓・月食・オリオン座・地層）。計算は全部「つり合った所から増えた分・減った分だけ」で解ける。

未記入の用紙なので「今回」はない。解く前に、設問の「右・左で」「さげひもから何cm」「すべて選びなさい」「整数で」の答え方の指示に丸をつけてから始める。

K20 (1) AのかわりにCを使う理由 素材文・空らん補充

👀 まず見るところ

【素材文】設問は①②に入る語。部品は「エナメル線の長さを同じ」と「巻き数の違いによる磁力の違い」に丸 → 長さが同じなら何が同じか、を「長さ→抵抗→電流」の3語で書く。

📚 前提知識

  • エナメル線は長いほど電流が流れにくい＝抵抗が大きい。同じ電池で抵抗が同じなら、流れる電流も同じ。
  • 比べる実験のきまり：調べたい条件（巻き数）以外は全部そろえる。

🔍 こう読み解く

  1. AとBをそのまま比べると、200回巻くBは線が長い。巻き数と線の長さの2つが同時に変わるので、磁力の差がどちらのせいか分からない。
  2. Cは100回巻いて、余った線をまとめておく → 線の長さはBと同じ → 抵抗が同じ（①）→ 同じ電池だから電流も同じ（②）。
  3. 残ったちがいは巻き数だけ。これで「巻き数の違いによる磁力の違い」が正しく調べられる。
答え：① 抵抗　② 電流
コツ：「余った線」の絵は、巻いていない線にも抵抗がある、という合図。巻いた部分だけで抵抗が決まるのではない。

K20 (2) AとBを何つなぎにするか 条件文・つなぎ方

👀 まず見るところ

【条件文】部品は「図1のAとBの電磁石を使って」（Cを使わない＝線の長さがちがうまま）と「何つなぎ」。線の長さがちがう2つに同じ電流を流す方法、に直して書く → 直列。

📚 前提知識

  • 直列回路では、電流はどこも同じ大きさ（解答冊子）。抵抗がちがう電磁石をつないでも、流れる電流は等しい。
  • 並列につなぐと、抵抗の小さいA（線が短い）に多く電流が流れてしまい、巻き数だけの比べ方にならない。

🔍 こう読み解く

  1. 比べたいのは巻き数だけ。だから電流はそろえたい。
  2. AとBを1つの輪にして（直列）電池につなぐ → 同じ電流が両方を通る → 磁力の差は巻き数の差だけになる。
答え：直列（つなぎ）
コツ：(1)は「長さをそろえる」、(2)は「電流をそろえる」。やり方はちがうが、ねらいはどちらも「電流を同じにする」。

K20 (3) 皿に50gをのせたときの分銅の位置 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「一様でない太さの棒」「200gの分銅でつり合わせました」と、変わった「皿に50g」に丸。棒と皿の重さはもうつり合っているので「増えた分だけ」に直して書く → 50×8＝200×□。

📚 前提知識

  • つり合っている状態から重さを足したときは、増えた分だけでつり合いを考えればよい（解答冊子）。棒や皿の重さを計算しなくてすむ。
  • 図2の数字：皿のひも〜さげひも 8cm、さげひも〜分銅 3cm、さげひも〜右はし 30cm。

🔍 こう読み解く

  1. 皿側に増えた回す力：50×8＝400。
  2. 分銅側で増やす分：200×□＝400 → □＝2cm。分銅を右へ2cm動かす。
  3. 答え方は「さげひもから何cm」。もとの3cmに足して 3＋2＝5cm。
答え：5cm
コツ：答えを書く直前に「さげひもから」の丸を見直す。動かした2cmで止まりやすい。

K20 (4) さおばかりで最大何gまで 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「最大何g」と図2の「30cm」。最大＝分銅を右はしまで動かしたとき、と直して書き、動かせる長さは 30−3＝27cm と図のとなりに置く。

📚 前提知識

  • (3)と同じ「増えた分だけ」の考え方。50gのせると分銅は2cm動く → 2cmにつき50g。

🔍 こう読み解く

  1. 分銅が動ける最大は、3cmの位置から右はし30cmまでの27cm。
  2. 2cmにつき50gなので、27cmぶんは 50×27÷2＝675g（解答冊子の式）。
  3. 別の確かめ：200×27＝5400 を皿側の8で割っても 5400÷8＝675。
答え：675g

K20 (5) Aを水に入れたら分銅はどちらへ 条件文・浮力と向き

👀 まず見るところ

【条件文】部品は「水そうの水にすべて入れた」と答え方の「右・左で」に丸。水に入れる＝浮力でAが軽くなる、と直して図3のAに「80g−浮力」と書く → 右側が軽くなる。

📚 前提知識

  • 水中の物体は浮力を受けて、見かけの重さが軽くなる。
  • 図3：100gの分銅はさげひもの左3cm、Aは右5cm。

🔍 こう読み解く

  1. Aが軽くなる → 右側の回す力が減る → 棒は左に傾く。
  2. もう一度つり合わせるには、左側の回す力も減らす → 100gの分銅をさげひもに近づける＝右へ。
答え：右
コツ：「軽くなった側の反対の分銅を、支点に近づける」。右か左かは図を見て決めるので、言葉だけで覚えない。

K20 (6) Aの体積 条件文・浮力の計算

👀 まず見るところ

【条件文】部品は「1cm動かして」「密度 1g/cm³」「体積は何cm³」に丸。分銅を1cm動かした分の減り（100×1）＝浮力×5、と直して書く → 浮力が出れば、水1g/cm³ だからそのまま体積。

📚 前提知識

  • 浮力＝押しのけた水の重さ。水は1cm³が1gなので、浮力20gなら押しのけた水は20cm³＝Aの体積。
  • (3)と同じく、変わった分だけでつり合いを考える。

🔍 こう読み解く

  1. 左側：100gが3cm→2cm に動いたので、回す力の減りは 100×1＝100。
  2. 右側：浮力×5＝100 → 浮力＝20g（解答冊子「100＝□×5」）。
  3. 20gの水の体積は20cm³ → Aの体積は20cm³。
答え：20cm³

K20 (7) 落下の表・1秒間で変化する速さ 資料問題・表の差

👀 まず見るところ

【資料問題】部品は表1の正体「直前の1秒で進んだ距離（m）」の行と、聞かれ方「1秒間で変化する速さ」。この行のとなり同士の差を表の下に書く → 全部 9.8 になる。

📚 前提知識

  • 「直前の1秒で進んだ距離」は、その1秒間の速さ（m/秒）そのもの。落ちる物体は、1秒ごとに同じだけ速くなる。

🔍 こう読み解く

  1. 4.9 → 14.7 → 24.5 → 34.3。差は 9.8、9.8、9.8。
  2. 1秒ごとに速さが9.8m/秒ずつ増える（解答冊子）。
答え：9.8 m/秒
コツ：「はじめからの落下距離」の行で差を取ると 4.9・14.7・24.5・34.3＝下の行になる。もう一度差を取れば9.8。差を2回で着く。

K20 (8) 酸化物28.5gからはじめの混合物M 条件文・燃焼の計算

👀 まず見るところ

【条件文】部品は2つの比「3g→5g（Mg）」「4g→5g（銅）」と「酸化銅が16.0g」「はじめの混合物M」。酸化物28.5gを「酸化銅16.0＋酸化マグネシウム12.5」に分けて書く → それぞれ金属にもどして足す。

📚 前提知識

  • マグネシウム：酸化マグネシウム＝3：5、銅：酸化銅＝4：5。酸化物から金属にもどすのは ×3/5、×4/5。

🔍 こう読み解く

  1. 酸化マグネシウム＝28.5−16.0＝12.5g。
  2. マグネシウム＝12.5×3/5＝7.5g。
  3. 銅＝16.0×4/5＝12.8g。
  4. M＝7.5＋12.8＝20.3g（解答冊子）。
答え：20.3g
コツ：聞かれているのは「はじめの混合物」＝金属の合計。酸化物の合計（28.5）や酸素の量で答えない。

K20 (9) 混合物15.6gの中の銅 条件文・つるかめ算

👀 まず見るところ

【条件文】部品は「混合物15.6g」「21.0gの酸化物」「銅粉は何g」。2種類がまざって合計だけ分かる形 → 「全部銅だったら」のつるかめ算に直して書く。

📚 前提知識

  • 銅は燃えると5/4倍、マグネシウムは5/3倍になる（4→5、3→5）。

🔍 こう読み解く

  1. 全部銅なら酸化物は 15.6×5/4＝19.5g。実際は21.0g → 1.5g多い。
  2. 銅1gをマグネシウム1gに取りかえると、酸化物は 5/3−5/4＝5/12 g 増える。
  3. マグネシウム＝1.5÷5/12＝3.6g → 銅＝15.6−3.6＝12g。
  4. 検算：12×5/4＝15、3.6×5/3＝6、15＋6＝21.0 で合う。
答え：12g
コツ：解答冊子は面積図（横15.6g、高さ5/4と5/3、面積21.0g）。つるかめ算と同じ中身。

K20 (10) 酸性雨の「とける」と同じ意味 知識問題

ウ。「空気中の窒素酸化物が雨にとける」は、物質が水にまじって水溶液になる溶解。ウの「食塩がとけている」も溶解。アの雪がとけるのは固体→液体の状態変化、イのアルミニウムが水酸化ナトリウム水溶液にとけるのは別の物質に変わる化学変化（解答冊子）。「とける」は 状態変化／化学変化／溶解 の3つを区別する。
答え：ウ

K20 (11) 花粉が昆虫によって運ばれる花 知識問題

ア・イ・オ（レンゲソウ・ツツジ・ウメ）。虫媒花は目立つ花びらがあり、みつやにおいで虫をよぶ（解答冊子）。トウモロコシとマツは風媒花で、花びらがなく、軽い花粉を大量に出す。「すべて選びなさい」なので3つ全部書く。
答え：ア・イ・オ

K20 (12) 種子が風によって運ばれるもの 知識問題

イ・ウ（ススキ・マツ）。ススキは綿毛、マツは羽のようなつくりで風に飛ばされる（解答冊子はススキ・マツ・カエデ）。オナモミは動物の毛にからみつく、カタバミは実がはじける（ホウセンカも）、ヤマブドウは動物に食べられて運ばれる。運ばれ方4つ（風・動物の毛・はじける・食べられる）で仕分ける。
答え：イ・ウ

K20 (13) メダカの卵の変化の順 資料問題・並べかえ

👀 まず見るところ

【資料問題】部品は4つの絵の中の「油滴」（小さな粒）と「目」。油滴が「散らばっている→1か所に集まる」で前半、「目ができる→体がはっきり」で後半、と絵の下に書く。

📚 前提知識

  • 産卵直後は油滴が卵全体に散らばっている → 胚盤が細胞分裂して、反対側に油滴が集まる → 目ができ、心臓が動き始め、ひれを動かす（解答冊子）。

🔍 こう読み解く

  1. ウ：油滴が全体に散らばっている → 産卵直後。
  2. エ：油滴が下に集まり、上で細胞分裂のつぶつぶ → 2番目。
  3. イ：体の形と目のもとができる → 3番目。
  4. ア：黒い目がはっきりし、体が卵の内側を一周 → ふ化が近い。
答え：ウ→エ→イ→ア
コツ：「目が黒くはっきり」はいちばん最後。油滴の散らばり方で前半2つを決める。

K20 (14) メダカの卵がふ化するまでの日数（25℃） 知識問題

11日目。水温25℃で産卵からおよそ11日でふ化する。水温が高いほど早く、低いと日数がのびる。答え方の指示「整数で」に丸をつけて、「約10〜11日」のような書き方にしない。
答え：11日目

K20 (15) 肝臓にたくわえられる炭水化物 知識問題

グリコーゲン。肝臓は吸収したブドウ糖をグリコーゲンに変えて一時たくわえ、必要なときにブドウ糖にもどして血液に出す。肝臓のほかのはたらきは、胆液（胆汁）をつくる・有毒なアンモニアを毒性の弱い尿素に変える（解答冊子）。植物がたくわえるデンプンと取りちがえない。
答え：グリコーゲン

K20 (16) 皆既月食が起こっている月 資料問題・影の図

👀 まず見るところ

【資料問題】部品は図4の正体「北極側から見た太陽・地球・月の軌道」と、4本の線の意味。地球のうしろでせばまる内側2本の間が「本影」、外側までが「半影」と図に書く → 本影にまるごと入る月だけが皆既。

📚 前提知識

  • 月食＝満月が地球の影に入る。本影は太陽の光がまったく届かない部分、半影は一部だけ届く部分。
  • 月が半影に入っただけでは少し暗くなるだけで欠けて見えない（解答冊子）。

🔍 こう読み解く

  1. 太陽の上はし→地球の上はし、下はし→下はしの2本は地球のうしろでせばまる → 間が本影。太陽の上はし→地球の下はし（とその逆）の2本は太陽と地球の間で交わり、地球を過ぎると広がる → 本影の外側からこの線までが半影。
  2. 月の軌道の上で、本影の中にすっぽり入っているのはウだけ。
  3. エは本影のふちにかかる（(17)）、イ・オは半影、ア・カは半影のふちか外。
答え：ウ

K20 (17) 部分月食が起こっている月 資料問題・影の図

👀 まず見るところ

【資料問題】部品は聞かれ方「部分月食」＝本影に一部だけ入る月。(16)で書いた本影の線が月を横切っている所をさがす。

📚 前提知識

  • 欠けて見えるのは本影に入った部分だけ。半影だけでは欠けない（解答冊子）ので、イ・オは部分月食ではない。

🔍 こう読み解く

  1. 本影の下側の線がエの月を横切っている → 月の一部が本影、残りが半影 → 部分月食。
  2. イ・オは半影の中だけ → 少し暗いだけ。ア・カは半影のふち → 変化なし。
答え：エ
コツ：「すべて選びなさい」でもエだけ。半影を知らないとイ・オまで選んでしまうので、本影と半影の線を先に書き分ける。

K20 (18) 地平線のすぐ上のオリオン座が動く方向 資料問題・星の動き

👀 まず見るところ

【資料問題】部品は「地平線のすぐ上」と図5の「3つ星が縦」。3つ星が縦＝東の空に出たばかり、と正体を1行書く → 東の星は右ななめ上へ動く。

📚 前提知識

  • 星の動き：東の空は右ななめ上へ、南は左から右へ、西は右ななめ下へ。
  • オリオン座は東から出るとき、ほぼ真横を向いて3つ星が縦。西へ沈むときは3つ星が横向きに近い（解答冊子）。

🔍 こう読み解く

  1. 地平線のすぐ上で3つ星が縦 → 沈む直前（3つ星が横）ではなく、出たばかり＝東。
  2. 東の空の星は右ななめ上へ → エ。
答え：エ

K20 (19) 沈むときはじめに沈む星 資料問題・星座の向き

👀 まず見るところ

【資料問題】部品は「沈むとき」「はじめに沈む」に丸。西に沈むときの形に直して書く：3つ星が横向きに近く、右上がりのななめ → いちばん低い星が先。

📚 前提知識

  • 星座の形は変わらないが、東→南→西と動くあいだに向きが時計回りに回る。東で縦だった3つ星は、南でななめ、西で横に近くなる（解答冊子）。

🔍 こう読み解く

  1. 東（図5）ではAが左、Bが右で、ほぼ同じ高さ。
  2. 西では3つ星が横向きに近い＝図5から90度近く時計回りに回った形 → AとBは上下にならび、右にあったBが下。
  3. 低い方のBが先に地平線に沈む → イ。
答え：イ
コツ：図5を時計回りに回してみる（紙を回してもよい）。ア「Aが先」は東で左にあった方＝回ると上に来る方なので逆。

K20 (20) 地層から読む隆起と沈降の順 資料問題・地層の図

👀 まず見るところ

【資料問題】部品は図6の正体「下から 砂→ねん土→レキ」（下が古い）と、聞かれ方「隆起と沈降はどのような順」。粒の大きさを「深さ」に直して書く（大きい＝浅い・小さい＝深い）→ 深くなった→浅くなった、の順が答え。

📚 前提知識

  • 粒が大きい（重い）ほど河口に近い浅い所にたまり、小さい粒ほど沖の深い所まで運ばれる（解答冊子）。レキ＞砂＞ねん土の順。
  • その場所が深くなった＝土地が沈降、浅くなった＝隆起。地層は下ほど古い。

🔍 こう読み解く

  1. 砂（中くらい）→ねん土（小さい）：深くなった → 沈降。
  2. ねん土（小さい）→レキ（大きい）：浅くなった → 隆起。
  3. 古い順に 沈降→隆起 → イ。
答え：イ
コツ：図の下から上へ読む。上から読むと順が逆（ア）になる。

K20 まとめ 解く前のチェック 3つ

  • てこ・浮力の(3)〜(6)は、つり合った所から増えた分・減った分だけで式を立てる。棒や皿の重さは計算しない。答えを書く直前に「さげひもから」「右・左で」の丸を見直す。
  • 燃焼の(8)(9)は、3→5（Mg）と4→5（銅）の2つの比を余白に書いてから。合計だけ分かる(9)は「全部銅なら」のつるかめ算。
  • 図の問題は正体を1行：月食は本影と半影の線を書き分ける（半影は欠けない）、オリオン座は3つ星が縦＝東、地層は下から読んで粒の大きさ→深さ。
