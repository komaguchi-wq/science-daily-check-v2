CP 全体像 動物の再徹底 20問（各5点・100点）

メダカとカエルの育ち（(1)〜(5)）、セキツイ動物の分類（(6)〜(8)）、節足動物と昆虫（(9)〜(15)）、顕微鏡とプランクトン（(16)〜(18)）、池の食物連鎖（(19)(20)）の順。一問一答が多いが、(5)(9)(14)(17)(18)(19)は図のどこを見るかで決まる問題で、知識はそのあとの答え合わせに使う。

今回は65／100点。落とした7問のうち(6)(7)(8)の3問は同じ9種類の動物を分類する問題で、動物の横にグループ名を書いてから選べば3問まとめて取れる。

CP (1) ふ化直後のメダカのふくらみ 知識問題

卵黄のう。卵の中で使い切らなかった養分（卵黄）が入った袋で、ふ化した直後の2〜3日はこの養分で育つので、えさを食べない。養分を使い切るとふくらみは消えて、自分でえさをとり始める。
答え：卵黄のう
今回：らん黄のう ○。

CP (2) ふ化直後のメダカの体長 知識問題

約0.5cm。メダカの卵は直径約1mm、ふ化した子メダカはその5倍ほどの約5mm。親のメダカでも3〜4cmしかないので、1cmでは生まれたてとして大きすぎる。「卵1mm → 子5mm → 親3〜4cm」の3つをセットで覚える。
答え：0.5（cm）
今回：1 ×。知識＝ふ化直後の大きさを「卵の5倍＝5mm」と結びつけていなかった。親の大きさ3〜4cmから逆算して、生まれたては1cmに届かないと考える。

CP (3) 木の枝の泡にくるまれた卵 知識問題

モリアオガエル。池の上にのびた木の枝に泡の卵を産み、かえったオタマジャクシが泡からすべり落ちて池に入る。ふつうのカエル（アマガエル・トノサマガエルなど）は水中に産むので、「木の枝・泡」の2語でモリアオガエルと決まる。
答え：モリアオガエル
今回：モリアオガエル ○。

CP (4) カエルの心臓のつくり 知識問題

2心房1心室。心臓のつくりは「魚類 1心房1心室／両生類・は虫類 2心房1心室／鳥類・ほ乳類 2心房2心室」と、グループが進むほど部屋が増える。カエルは両生類なので心房が2つ、心室は1つ。
答え：① 2　② 1
今回：① 2 ② 1 ○。

CP (5) 卵からオタマジャクシになる順 資料問題・並べかえ

👀 まず見るところ

【資料問題】部品は答え方「卵からオタマジャクシになる順」と、ア〜ウの球に入った割れ目のようす。割れ目なし→上から入り始める→全体に深く通る、と正体を1行書けば、順は図だけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 受精した卵は、1個の細胞が2つ、4つ…と分かれていく（卵割）。割れ目が多いほど育っている。
  • 分かれ終わると形ができて、尾のあるオタマジャクシになる。

🔍 こう読み解く

  1. 割れ目のないウが最初。上から割れ目が入り始めたイ、割れ目が全体に深く通ったアの順に進む。
  2. 最後が尾のあるエ。ウ→イ→ア→エ。
答え：ウイアエ
今回：ウイアエ ○。割れ目の進み方で順を決められている。

CP (6) ア〜ケのうち、は虫類 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問は「は虫類をすべて」。部品は9匹の名前。1匹ずつ横に「魚・両・は・鳥・ほ」の1字を書く（3語で書く）→ (7)(8)でも同じメモを使うので、ここで9匹全部に書く。

📚 前提知識

  • 名前にだまされない組: イモリは両生類（ヤモリがは虫類）。シャチ・コウモリ・ラッコはほ乳類。ウーパールーパーはサンショウウオのなかまで両生類。
  • は虫類＝体がうろこ、陸上に殻のある卵を産む。ウミガメ・ワニ・ヘビ・トカゲ・ヤモリ。

🔍 こう読み解く

  1. 9匹に1字を書く: ア ウミガメ＝は／イ ペンギン＝鳥／ウ イモリ＝両／エ ダチョウ＝鳥／オ シャチ＝ほ／カ コウモリ＝ほ／キ ワニ＝は／ク ラッコ＝ほ／ケ ウーパールーパー＝両。
  2. 「は」と書いたのはアとキだけ。
答え：ア・キ
今回：アウキ ×。知識＝ウ イモリを「ヤモリ」と取りちがえては虫類に入れた。「イモリは井戸（水）の守り＝両生類、ヤモリは家の守り＝は虫類」で分ける。

CP (7) 陸上に産卵する動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「陸上に」「産卵」の2語に丸。(6)で書いた1字メモを見て、「卵を産む＝魚・両・は・鳥」のうち「陸上＝は・鳥」に直して書く → 両生類と魚類は水中、ほ乳類はそもそも卵を産まない。

📚 前提知識

  • 両生類（イモリ・ウーパールーパー）は水中に殻のない卵を産む。は虫類と鳥類は陸上に殻のある卵。
  • ほ乳類（シャチ・コウモリ・ラッコ）は卵を産まず、子を産む（胎生）。

🔍 こう読み解く

  1. 「は」＝ア ウミガメ・キ ワニ、「鳥」＝イ ペンギン・エ ダチョウ。ウミガメは海にすむが、産卵は砂浜。
  2. 「両」のウ・ケは水中に産むので外す。「ほ」のオ・カ・クは卵を産まないので外す。
答え：ア・イ・エ・キ
今回：アイウエカキ ×。部品の形を直さなかった＝「陸上に産卵」を「は・鳥だけ」に直さず、ウ イモリ（水中産卵の両生類）とカ コウモリ（卵を産まないほ乳類）まで入れた。(6)の1字メモがあれば「両」と「ほ」は機械的に消せる。

CP (8) 母乳で子育てをする動物 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「母乳で子育て」に丸 → これはほ乳類だけの特ちょう、と直して書く。(6)の1字メモで「ほ」と書いた3匹がそのまま答え。見た目が魚や鳥に似ていても、メモの字で決める。

📚 前提知識

  • ほ乳類＝子を産み、乳で育てる。海にすむシャチ・ラッコ、空を飛ぶコウモリもほ乳類。
  • 鳥（ペンギン・ダチョウ）は卵を産んであたため、親がえさを運ぶ。乳は出さない。

🔍 こう読み解く

  1. 「ほ」＝オ シャチ・カ コウモリ・ク ラッコ。
  2. イ ペンギン・エ ダチョウは鳥。子育てはするが、乳ではない。
答え：オ・カ・ク
今回：イエオカ ×。部品を拾えなかった＝「母乳」でなく「子育て」で選び、鳥のイ・エを入れてク ラッコを落とした。「母乳＝ほ乳類」に丸をつけてから、メモの「ほ」を全部ひろう。

CP (9) シミに最も近い動物 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は図3のあしの本数と体の分かれ方。正体を1行＝「あし6本・頭胸腹の3つ」→ 昆虫のなかま。あとはア〜エのうちあしが6本のものを探すだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 節足動物はあしの数で分ける: 昆虫6本／クモ・ダニ8本／ダンゴムシなど甲かく類10本以上／ムカデ・ゲジはたくさん。
  • シミは紙や本を食べる、はねのない原始的な昆虫。ノミもはねのない昆虫。

🔍 こう読み解く

  1. 図3のあしは左右3本ずつ＝6本 → 昆虫。
  2. ア ダンゴムシ（あし14本・甲かく類）、ウ ダニ（8本・クモのなかま）、エ ゲジ（多数・ムカデのなかま）は本数が合わない。
  3. あし6本のイ ノミが昆虫で、シミに最も近い。
答え：イ
今回：イ ○（横にうすく消した字が残っている）。あしの本数で昆虫と決められている。

CP (10) 図4の昆虫の名前と口 資料問題・穴うめ

👀 まず見るところ

【資料問題】部品は図4の大きなあご（大あご）とかたい前ばね。正体を1行「クワガタムシ」と書けば、成虫の口は「木のしるをなめる」とセットで決まる。大あごは口ではなく、けんかの道具。

📚 前提知識

  • クワガタムシ・カブトムシの成虫は、ブラシのような口で樹液をなめる。大あごや角はエサをとる道具ではない。

🔍 こう読み解く

  1. 図4は大あごが大きく、前ばねがかたい → クワガタムシ（図はノコギリクワガタ）。
  2. クワガタの成虫は樹液をなめる → ②は「なめる」。
答え：① クワガタムシ（ノコギリクワガタ）　② なめる
今回：① クワガタ ② なめる ○。①に赤い短い線があるが誤りの印ではなく、正式には「クワガタムシ」と書く、という印と見る。

CP (11) 図5の昆虫の名前と口 資料問題・穴うめ

📚 前提知識

🔍 こう読み解く

  1. 図5はあし6本・触角あり・五角形の背中 → カメムシ。
  2. カメムシの成虫は口をさして吸う → ②は「さす」。

今回：① ダニ ② さす ×。部品を拾えなかった＝図5のあしの本数（6本）と触角を見ずに、丸い体の形だけで「ダニ」とした。あし6本＝昆虫、と先に正体を書いてから名前を考える。

CP (14) モンシロチョウの幼虫のあしのつき方 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は「幼虫」「あしのつき方」に丸。正体を1行＝「前に3対（これが本当のあし）・まん中に4対・おしりに1対」と書き、ア〜エのあしの並びとすきまをこの形と照らす。

📚 前提知識

  • チョウの幼虫は、むねに本当のあし3対（6本）、はらに4対、おしりに1対の腹あし（成虫にはならない）。

CP (15) 図6は何の幼虫で、何を食べるか 資料問題・穴うめ

👀 まず見るところ

【資料問題】部品は図6の黒くとげのある細長い体・あし6本と、設問の「主に〔②〕を食べます」。正体を1行「テントウムシの幼虫」→ 食べ物は成虫と同じ「アブラムシ」とセットで決まる。

📚 前提知識

  • テントウムシ（ナナホシテントウ）は幼虫も成虫もアブラムシを食べる肉食の昆虫。だから農業では役に立つ虫。
  • 「幼虫＝何を食べる」のセット: モンシロチョウ＝キャベツ／アゲハ＝ミカン・サンショウ／カイコ＝クワ／ゲンジボタル＝カワニナ／テントウムシ＝アブラムシ。

🔍 こう読み解く

  1. 図6は黒くて細長く、とげのような毛・あし6本 → テントウムシの幼虫。
  2. テントウムシは幼虫も成虫もアブラムシを食べる → ②は「アブラムシ」。
答え：① テントウムシ（ナナホシテントウ）　② アブラムシ
今回：① テントウムシ ② カワニナ ×。知識＝①は合っているのに、食べ物をホタルの幼虫のエサ（カワニナ）と取りちがえた。「水中の幼虫＝ホタル＝カワニナ、葉の上の幼虫＝テントウムシ＝アブラムシ」と、すむ場所とセットにして直す。

CP (16) 顕微鏡の使い方の順 知識問題

① のせる前 ② 近づけて。明るさの調整はプレパラートをのせる前に反射鏡で行う（のせたあとでは、見えているものが暗いのか明るさが足りないのか分からない）。ピント合わせは、横から見ながら対物レンズとプレパラートを近づけておき、遠ざけながら合わせる。近づけながら合わせるとレンズがプレパラートにぶつかる。
答え：① のせる前　② 近づけて
今回：① のせたあと ② 近づけて。赤の印はなく（○あつかい・記録も○）だが、①は解答冊子の「のせる前」と違う。「明るさはのせる前、ピントは近づけてから遠ざける」の順に直しておく。

CP (17) 視野のゾウリムシを中央にする動かし方 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は図7でゾウリムシが見えている位置＝左下と、設問の「プレパラートを動かす」に丸。顕微鏡の像は上下左右が逆なので「見えている方向へ動かす」と直して書く → 左下。

📚 前提知識

  • 顕微鏡では上下左右が逆に見える。左下に見えているものは、実際にはプレパラートの右上にある。
  • だから中央に持ってくるには、プレパラートを見えている向きと同じ方へ動かす（右上にあるものを左下へずらす）。

🔍 こう読み解く

  1. 図7のゾウリムシは視野の左下。
  2. 「見えている方向へ動かす」の決まりで、プレパラートは左下へ。
答え：左下
今回：左下 ○。
コツ：「動かすのはプレパラート」か「像を動かす」かで答えが逆になる。設問のどちらかに丸をつけてから答える。

CP (18) 動物性プランクトン 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は「動物性」「すべて」に丸と、ア〜オの名前を1つずつ書く（正体を1行）。名前が書ければ「自分で動く・食べる＝動物性／緑色で光合成＝植物性」で5つ全部に○×がつく。

📚 前提知識

  • 動物性＝ゾウリムシ・ミジンコ・ラッパムシ・アメーバ・ツリガネムシ（動いてえさを食べる）。
  • 植物性＝ケイソウ・イカダモ・クンショウモ・ミカヅキモ・アオミドロ（緑色で光合成）。ミドリムシは両方の性質。

🔍 こう読み解く

  1. 名前を書く: ア ラッパムシ／イ ケイソウ／ウ イカダモ／エ アメーバ／オ クンショウモ。
  2. 動物性はラッパムシとアメーバ → ア・エ。イ・ウ・オは植物性。
答え：ア・エ
今回：アウ ×。知識＝ウ イカダモ（4つ並んだ細胞がいかだの形・植物性）を動物性に入れ、エ アメーバを落とした。5つの名前を先に書いて、植物性の5種（ケイソウ・イカダモ・クンショウモ・ミカヅキモ・アオミドロ）を消す。

CP (19) 池の生物と気体X 資料問題・気体の名前

👀 まず見るところ

【資料問題】部品は「日中の気体の出入り」に丸と、矢印Aの向き＝アから気体Xへ。正体を1行「ア＝ミカヅキモ（植物性プランクトン）」→ 昼に植物が出す気体＝酸素、と決まる。

📚 前提知識

  • 植物性プランクトンは昼に光合成をして、二酸化炭素を取り入れ酸素を出す。
  • 動物（イ〜オ）は昼も夜も呼吸で酸素を取り入れ、二酸化炭素を出す。

🔍 こう読み解く

  1. Aはアから出てXへ向かう矢印。アは緑色のミカヅキモ（植物性）なので、昼に出す気体は酸素。
  2. 確かめ: Xからイ・ウ・エへ向かう矢印（B・C）は「動物が酸素を取り入れる」、イ・ウ・エからYへ向かう矢印（D・E・F）は「二酸化炭素を出す」で、Y＝二酸化炭素。アから出る気体の矢印はAの1本だけなので、Aは酸素を出す向きと決まる。
答え：酸素
今回：酸素 ○。

CP (20) 食物連鎖の消費者 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は「消費者」「すべて」に丸。消費者＝自分で養分を作れずほかの生物を食べるもの、と直して書く → 図8で白い矢印（食べられる→食べる）の出発点でない生物が全部消費者。

📚 前提知識

  • 生産者＝光合成で自分で養分を作る（植物・植物性プランクトン）。消費者＝それを食べる動物。分解者＝フンや死がいを分解する（図の下の箱に向かう流れ）。
  • 図8の白い矢印は「食べられる → 食べる」の向き。

🔍 こう読み解く

  1. 白い矢印の出発点はア（ミカヅキモ）だけ。アは(19)で酸素を出していた植物性プランクトン＝生産者。
  2. イ ミジンコ・ウ メダカ・エ（水中の昆虫）・オ フナは、矢印の先にいて何かを食べる → 全部消費者。
答え：イ・ウ・エ・オ
