CP 全体像 電磁気の再徹底 20問（各5点・100点）

前半(1)〜(13)は回路。豆電球の直列・並列、ショート、電流の大きさと乾電池の長持ち、LEDの向き、電熱線の抵抗と発熱量。後半(14)〜(20)は磁石と、電流のまわりにできる磁界（右ねじ・電磁石の極）。どの問題も、回路図に電流の数字か矢印を書きこんでから答えると決まる。

今回は70／100点。落とした6問は (3)(4)(9)(16)(17)(18)。(4)は「ア〜キのうち」の答え方、(9)はCの足の長さ、(16)は幹と枝の電流の向き、(3)(17)(18)は決まりの知識。

CP (1) ショート回路はどれか 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は資料の正体「豆電球2個と乾電池の写真4つ」と、聞かれ方「ショート回路をすべて」に線。＋から導線を指でたどり、豆電球の中（フィラメント）を通らずに−へもどれる道があるかを4つ全部に○×。

📚 前提知識

  • ショート回路＝＋と−が導線だけでつながる回路。電流がとても大きくなり、乾電池が熱くなってすぐ使えなくなる。
  • 豆電球の電気の出入り口は底と横（ねじの部分）の2か所。横から横へ抜けると、中を通らない。

🔍 こう読み解く

  1. ウ：＋の導線が上の豆電球の横につき、その横がふれた下の豆電球の横から−へもどる。どちらの中も通らない → ショート。
  2. ア：上の豆電球は同じ所に導線2本（素通り）だが、右下の豆電球の中は通る → ショートではない。イ・エ：底→横→横→底と2個の中を通る → ショートではない。
答え：ウ
今回：ウ ○。

CP (2) 豆電球が2つともつく回路 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】聞かれ方「2つともつく」「すべて」に線。部品は、それぞれの豆電球で底と横の2か所に別々の道がつながっているか。4つ全部に○×。

📚 前提知識

  • 豆電球は、底→フィラメント→横（またはその逆）と電流が通ったときだけ光る。同じ所に導線2本がつくと、その豆電球は素通りされる。

🔍 こう読み解く

  1. イ：左右の豆電球の底が乾電池の＋と−にふれ、横どうしを導線で結ぶ → 直列で2個とも光る。
  2. エ：上の豆電球の底が＋、横が2個目の横にふれ、2個目の底から−へ → これも直列で2個とも光る。
  3. ア：上の豆電球は底に2本（素通り）→ 右下の1個だけ。ウ：ショートで2個とも光らない。
答え：イ・エ
今回：イ・エ ○。

CP (3) 並列につないだときの回路全体の抵抗 知識問題

イ（小さくなります）。並列は電流の通り道が2本に増える。道が増える＝通りやすい＝回路全体の抵抗は小さい。直列は道が長くなる＝抵抗が大きい、とセットで持つ。「豆電球が増えた＝抵抗が増えた」と考えると逆になる。
答え：イ
今回：ア ×。知識＝「増える」を抵抗の増加と取った。並列は「道が増える」、直列は「道が長くなる」の2語で分ける。

CP (4) 電流が最も大きい点・最も小さい点 条件文・記号で1つずつ

👀 まず見るところ

【条件文】部品は答え方「ア〜キのうち」と「①最も大きい ②最も小さい」に丸。4つの回路図に、豆電球1個・乾電池1個のときの電流を1として各点の電流の数字を書きこむ（図に置く）→ 数字を比べるだけ。

📚 前提知識

  • 豆電球を並列にすると全体の電流は個数倍（2個で2）、直列にすると半分（1/2）。
  • 乾電池を並列にしても全体の電流は変わらず、1個の乾電池を通る電流が半分になる。

🔍 こう読み解く

  1. A：豆電球並列 → 幹のイは2、枝のアは1。B：直列 → ウは1/2。
  2. C：豆電球並列で幹のエは2、乾電池も並列なので1個を通るオは1。D：直列で幹のカは1/2、乾電池2個で分けるキは1/4。
  3. 最大はイ（2）、最小はキ（1/4）。
答え：① イ　② キ
今回：① A ② D ×。部品を拾えなかった＝「ア〜キのうち」に丸がなく、点の記号でなく回路の名前で答えた。最大のイは回路A・最小のキは回路Dにあるので、答えを書く直前に「ア〜キ」の丸を見直せば点の記号に直せる。

CP (6) 回路Aの電流計 条件文・計算

CP (7) 回路Bの電流計 条件文・計算

👀 まず見るところ

【条件文】部品は「Bの電流計」の場所＝上の枝に丸（幹ではない）。Bは「並列2個→ウ1個」の直列なので、豆電球1個の抵抗を1として全体の抵抗を先に図に書く。

📚 前提知識

  • 並列2個の部分の抵抗は1/2。それにウの1が直列で、全体は3/2。
  • 電流は全体の抵抗に反比例する。240÷(3/2)＝160mAが幹の電流。

🔍 こう読み解く

  1. 全体の抵抗 1/2＋1＝3/2 → 幹の電流 240×2/3＝160mA。
  2. 並列の枝2本は同じ豆電球なので半分ずつ → 上の枝は80mA。
  3. 電流計は上の枝にある → 80mA。
答え：80mA
今回：80 ○。回路図の横に「2/3」「1/3」の書きこみがあり、幹→枝の順に出せている。

CP (9) 光るLEDはどれか 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は資料の正体「Aは光る＝乾電池の長い線（＋）から出た電流が長い足に入る向き」を1行書く。聞かれ方「光るLEDをすべて」に線。B〜Gは1個ずつ、＋から導線をたどって長い足に先に着くかを○×。

📚 前提知識

  • LED（発光ダイオード）は決まった向きにしか電流を流さない。長い足が＋側のときだけ光る（Aの図がその向き）。
  • 逆向きのLEDは電流そのものを止める。直列につながった相手のLEDも光らない。

🔍 こう読み解く

  1. B・C：内側の輪がB、外側の輪がCの別々の回路（並列）。Bは＋→左の長い足 → ○。Cは長い足が右で、＋からの導線は左の短い足に先に着く → ×。
  2. D・E：1本の導線で直列。＋からたどると、Dは右の長い足、Eは左の長い足に先に着く → 両方○。
  3. F・G：乾電池は2組あるが、FとGは直列で向きが逆（Fは左、Gは右が長い足）。Gで電流が止まり、Fも光らない → ×。
答え：B・D・E
今回：B・C・D・E ×。部品を拾えなかった＝Cの「長い足が右」を見ずに、Bと同じ向きとみなした。LEDは1個ずつ足の長さを確かめてから○×をつける。

📚 前提知識

CP (11) 発熱量が最も大きい電熱線 資料問題・直列と並列

👀 まず見るところ

【資料問題】部品は図の正体「図1は直列・図2は並列」と、表から出る抵抗 A＝1／B＝1/2／C＝2 を各電熱線の横に書く（図に置く）。直列と並列で発熱量が大きい側が逆になる。

📚 前提知識

  • 直列：流れる電流はどこも同じ → 抵抗が大きいほど発熱量が大きい。
  • 並列：かかる電圧がどの枝も同じ → 抵抗が小さいほど電流が大きく、発熱量が大きい。

🔍 こう読み解く

  1. 抵抗：A 1、B（20cm・1.0mm²）1/2、C（40cm・0.5mm²）2。
  2. 図1（直列）→ 抵抗最大のC。図2（並列）→ 抵抗最小のB。
答え：① C　② B
今回：① C ② B ○。

CP (14) 北極付近の極・こすった鉄くぎの向き 知識問題

① S極 ② 南。方位磁針のN極が北を指すのは、北極付近がS極だから。図3は棒磁石のN極で、くぎを頭から先へこすっている。こすり終わる側（先）はこすった極と反対の極＝S極になる。水に浮かべると、S極の先は北極（S極）と反発して南を向く。
答え：① S　② 南
今回：① S ② 南 ○。

CP (15) 銅の棒のまわりの方位磁針A・B 条件文・右ねじ

👀 まず見るところ

【条件文】部品は図4の「北」の矢印と、乾電池の＋側（上のクリップ）に丸 → 銅の棒の電流は上から下と矢印で図に置く。Aは棒の北側、Bは棒の東側、と図に書く。

📚 前提知識

  • 右ねじの法則：電流の向きにねじを進めるとき、ねじを回す向きが磁界の向き。下向きの電流なら、上から見て時計回り。
  • 方位磁針のN極は磁界の向きを指す。

🔍 こう読み解く

  1. 電流は＋（上のクリップ）→棒を下へ→下のクリップ→スイッチ→−。
  2. 上から見て時計回り：棒の北側では東向き、東側では南向き。
  3. A（北側）→ 東。B（東側）→ 南。
答え：A 東　B 南
今回：A 東 B 南 ○。

CP (16) 西にふれる方位磁針 条件文・すべて選ぶ

👀 まず見るところ

【条件文】部品は「西にふれる」と「ア・イ・オは導線の上に、ウ・エは下に」に丸。回路図に電流の矢印を幹と枝に置く（直して書く）→ 枝3本は北向き、乾電池のある左の幹は南向き。上／下と電流の向きの2つで決まる。

📚 前提知識

  • 導線の下に置いた方位磁針（導線が上）：電流が北向きならN極は西へ。導線の上に置くと逆で、北向きなら東へ。
  • 東西に走る導線の上では、磁界が針と平行になるので針は動かない。

🔍 こう読み解く

  1. 乾電池の＋は下側 → 電流は左の幹を南へ、下の導線を東へ、枝3本を北へ上がり、上の導線を西へもどる。
  2. ウ・エ：導線の下・北向き → 西 ○。ア：導線の上・南向き → 西 ○。
  3. オ：導線の上・北向き → 東 ×。イ：東西の導線 → ふれない ×。
答え：ア・ウ・エ
今回：ウ・エ ×（ア抜け）。部品の形を直さなかった＝電流の矢印を幹と枝に置かず、上にあるアをオと同じ北向きで見た。幹は枝と逆向き、を矢印で先に置く。

CP (17) 針の振れが最も大きい方位磁針 条件文・1つ選ぶ

👀 まず見るところ

【条件文】部品は「振れが最も大きい」に丸 → 「流れる電流が最も大きい所」に直して書く。(16)の矢印に、豆電球1個の抵抗を1として枝ごとの電流の数字を足す。

📚 前提知識

  • 針の振れの大きさは、電流の大きさで決まる。
  • 幹（乾電池のある道）には枝の電流の合計が流れる。

🔍 こう読み解く

  1. 枝の電流：ウの枝は並列2個（抵抗1/2）で2、エの枝は1個で1、オの枝は直列2個で1/2。
  2. 幹（ア・イ）は 2＋1＋1/2＝3.5で最大。
  3. イは東西の導線で針がふれない → 最も大きいのはア。

今回：ウ ×。知識＝「幹には枝の合計が流れる」が抜け、枝の中だけで比べた。幹の数字を先に書く。

CP (18) 電磁石のまわりの方位磁針A・B 条件文・電磁石の極

👀 まず見るところ

【条件文】部品は図6の「北」と乾電池の＋側（右）に丸 → コイルを流れる電流の向きを矢印で置き、右手でにぎってコイルの左右どちらがN極かを図に書く。A・Bはどちらもコイルの外側にある。

📚 前提知識

  • 右手の4本の指を電流の向きに合わせてコイルをにぎると、親指がN極。
  • 磁力線はN極から出てS極に入る。コイルの外側ではN→S、内側ではS→N。方位磁針のN極は磁力線の向きを指す。

🔍 こう読み解く

  1. 図6では左（西）側がN極、右（東）側がS極になる。
  2. A：N極のすぐ西。N極から出る磁力線は西へ向かう → N極は西。
  3. B：コイルの上（外側）。磁力線はN（西）からS（東）へ → N極は東。
答え：A 西　B 東
今回：A 西 ○、B 北 ×。図にN・Sの書きこみがあり、極は合っている。Bの×は知識＝「外側の磁力線はN→S」。Bは北を向いたまま残らず、西のNから東のSへ向かう磁力線にそって東を向く。

CP (19) コイルの内側の方位磁針 条件文・電磁石の極

👀 まず見るところ

🔍 こう読み解く

  1. 図7のコイルも図6と同じつなぎ方で、左（西）がN極。
  2. 内側の磁力線は右（S）→左（N）＝西向き → N極は西。

今回：西 ○。

CP (20) 鉄心の材料とその性質 知識問題

① 軟鉄 ② にくい。鉄心に使うのは純度の高い軟鉄。磁石になりやすく、スイッチを切ると磁力がすぐ消える（残りにくい）。磁力が残りやすいのは鋼（はがね）で、こちらは永久磁石の材料。電磁石は「切れば消える」が役目なので、残りにくい軟鉄を選ぶ。
答え：① 軟鉄　② にくい
