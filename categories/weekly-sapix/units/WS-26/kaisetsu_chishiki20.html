K20 (1) 銅の棒に電流を流したときの方位磁針A 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は図1の正体「電池の＋が上側＝電流は棒を上から下へ」と「見る向き」の矢印、聞かれ方「Aの方位磁針」。棒を上から見た円を余白に描き、電流が下向きなら時計回りの矢印を置く（図に置く）→ 棒の奥にあるAの場所で矢印は右向き。

📚 前提知識

  • まっすぐな導線に電流を流すと、まわりに同心円の磁界ができる。右ねじの進む向きを電流の向きに合わせると、ねじを回す向きが磁界の向き（上から見て、下向き電流なら時計回り）。
  • 方位磁針のN極は磁界の向きを指す（解答冊子「方位磁針は磁界の流れの向きを示します」）。ぬりつぶした（黒い）側がN極。

🔍 こう読み解く

  1. 電池の＋は上の線につながる → 電流は棒を上から下へ流れる。
  2. 上から見ると磁界は時計回り。Aは見る向きの奥（棒の向こう側）にある → そこでの磁界の向きは右。
  3. N極（黒）が右を向く図はエ。
答え：エ
コツ：4つの磁針を一度に考えない。棒を上から見た円に矢印を1本描いてから、聞かれた磁針の場所だけ読む。

K20 (2) 電池を逆にしたときの方位磁針B 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は(1)から変わった「電池の＋−を逆に」と、聞かれた磁針が「B」の2つに丸。電流が逆なら磁界も逆 → (1)で描いた円の矢印を反時計回りに描き直す（図に置く）→ 棒の右側にあるBの場所で矢印は奥向き。

📚 前提知識

  • 電流の向きが逆になると、まわりの磁界の向きも逆になる（解答冊子）。
  • 選択肢の「上」は見る向きの奥（棒の向こう側）を表している。

🔍 こう読み解く

  1. 電流は棒を下から上へ → 上から見て磁界は反時計回り。
  2. Bは棒の右側。反時計回りの円は右側で奥向き（見る向きと同じ）。
  3. N極（黒）が奥（上）を向く図はア。
答え：ア
コツ：「逆にする」は(1)の答えを逆にするのではなく、円の矢印を逆にしてから磁針の場所を読み直す。磁針の場所が A→B に変わっているのが落とし穴。

K20 (3) 棒の重さがあるときのばねばかりA 条件文・計算

👀 まず見るところ

【条件文】部品は図2アの「水平にした」（棒の重さ130gはばねばかりの位置＝左から10cmに全部かかる）と、イの「140gのおもり」が中央（13cm・13cm）。図イに下向きの矢印を2本置く（図に置く）：130gは左から10cm、140gはまん中 → ばねばかり2本で分けて足すだけ。

📚 前提知識

  • 棒をばねばかり1本でつるして水平なら、その位置が重心。この棒は太さが一様でないので、重心は左から10cmの所。
  • 両端の2本で支えるとき、おもりの重さは距離の逆比で分かれる（近い方が多く受ける）。

🔍 こう読み解く

  1. 140gはAから13cm・Bから13cm → 1：1 → A 70g、B 70g。
  2. 130gはAから10cm・Bから16cm → A：B＝16：10＝8：5 → A 80g、B 50g。
  3. Aは 70＋80＝150g。
答え：150g
コツ：おもりと棒の重さは別々に分けてから足す。逆比は「遠い距離が自分の取り分」（Aは16、Bは10）。

K20 (5) 滑車2つでおもりAを支えるばねばかりB 条件文・計算

👀 まず見るところ

【条件文】部品は「40gの滑車を2つ」「おもりAが200g」に丸と、図3の「ひもの端が2本とも床に固定」。下の滑車から順に、ひも1本の力を図に書く（図に置く）：下のひも200g → 下の滑車の軸 200×2＋40 → 上のひも → 上の滑車の軸、と下から上へ足していく。

📚 前提知識

  • 1本のひもは、どこでも同じ力で引く。滑車の両側のひもがどちらも下向きに引くなら、その滑車の軸を支える力は「ひもの力×2＋滑車の重さ」。
  • この図は上下が逆の動滑車。床に固定した端があるので、上に行くほど力が2倍＋40gで増える（解答冊子の図）。

🔍 こう読み解く

  1. 下のひも：A 200gをつるしているので、ひもの力は200g（床側も200g）。
  2. 下の滑車の軸：200×2＋40＝440g。この440gが上のひもの力。
  3. 上の滑車の軸＝B：440×2＋40＝920g。
答え：920g
コツ：「動滑車＝半分」と決めつけない。ばねばかりが上にあって端が床なら、力は上に行くほど増える。矢印を図に書いてから式にする。

K20 (6) Bを8cm引き上げたときのAの上がる長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「Bを静かに8cm引き上げ」と求めるもの「Aは何cm」に丸。(5)で力を下から足した道を、今度は上から「×2」に直して書く（直して書く）：B 8cm → 下の滑車 16cm → A 32cm。

📚 前提知識

  • 滑車の片方の端が床に固定されていると、滑車を h cm 上げたとき、もう片方の端は2h cm 動く（固定側のたるみが全部もう一方に回る）。
  • 力が2倍＋40gで増えるのと逆に、動く長さは上から下へ2倍ずつ増える（解答冊子「8×2＝16cm」「16×2＝32cm」）。

🔍 こう読み解く

  1. 上の滑車がBと一緒に8cm上がる → その軸につながる下の滑車は 8×2＝16cm。
  2. 下の滑車が16cm上がる → Aは 16×2＝32cm。
答え：32cm
コツ：力と長さは逆。(5)で「÷2」の向きに力が減らなかった（増えた）なら、(6)の長さは「×2」で増える。

K20 (7) ①最も速い／②最も遅いふりこ 資料問題・1つずつ選ぶ

👀 まず見るところ

【資料問題】部品は5つの図の正体「ふりこの長さ・角度・おもりの重さ・最下点からの高さ（約○cm）」と、聞かれ方「最下点での速さ」。速さを決めるのは高さだけ → 各図の「約7・4・8.8・10.5・6cm」に丸をつけ、ほかの数字は見ない。

📚 前提知識

  • 最下点での速さは、はなした高さが高いほど速い。おもりの重さやふりこの長さは関係しない（解答冊子）。
  • 長さや角度は「高さ」を決めるための材料にすぎない。この問題は高さが図に書いてあるので、長さ・角度は使わない。

🔍 こう読み解く

  1. 高さだけ並べる：ア約7／イ約4／ウ約8.8／エ約10.5／オ約6cm。
  2. ①最も速い＝いちばん高いエ（10.5cm）。②最も遅い＝いちばん低いイ（4cm）。
  3. イは150gで重く、エは10gで軽い。重さにつられない。
答え：① エ　② イ
コツ：ふりこの速さは「高さ」、周期は「長さ」。聞かれているのがどちらか先に丸をつけてから数字を見る。

K20 (8) 二酸化マンガンのように反応を速めるもの 知識問題

触媒。過酸化水素水（オキシドール）に二酸化マンガンを入れると酸素が出るが、二酸化マンガン自身は減らず変化しない。「自分は変わらず、反応を速める」が触媒の決まり。漢字2字。
答え：触媒
コツ：酸素のもとは過酸化水素水の方。二酸化マンガンが酸素を出すのではない、と区別して書く。

K20 (9) BTB溶液で青色になるビーカー 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は表1の正体「水酸化ナトリウム水溶液50cm³に塩酸を10cm³ずつ・残った固体g」と、聞かれ方「青色になるものをすべて」。青＝アルカリ性＝水酸化ナトリウムが残っている、に直して書く → 固体の増え方が変わる所（完全中和）の手前が全部答え。

📚 前提知識

  • BTB溶液は、酸性で黄・中性で緑・アルカリ性で青。塩酸が足りないうちは水酸化ナトリウムが残りアルカリ性。
  • 中和でできる食塩は固体として残る。完全中和までは塩酸を足すほど食塩が増え、完全中和のあとは塩酸が余るだけなので固体は増えない。

🔍 こう読み解く

  1. 固体の増え方を表の下に書く：①→④は＋0.2ずつ、⑤で＋0.1、⑥⑦は＋0（解答冊子）。
  2. 増え方が変わったのは④と⑤の間 → ここで完全中和。④まではまだ水酸化ナトリウムが残る＝青。
  3. ⑤は塩酸10cm³のうち5cm³しか使われていない（10×0.1÷0.2＝5）ので、塩酸が余って黄。⑥⑦も黄。
答え：①・②・③・④
コツ：表はまず「となりとの差」を書く。差が変わった所が完全中和で、(10)もこの差で解ける。

K20 (10) 水酸化ナトリウム水溶液100cm³＋塩酸50cm³の固体 条件文・計算

【条件文】部品は「水酸化ナトリウム水溶液100cm³」と「塩酸50cm³」に丸。表は水酸化ナトリウム50cm³の話なので、両方を÷2に直して書く（50cm³と25cm³）→ 表の②と③の間の値を2倍すれば決まる。

  • 塩酸25cm³は完全中和（45cm³）より少ないので、塩酸は全部反応する。固体は②（2.4g）と③（2.6g）のまん中。

K20 (11) 双子葉植物の茎で発達し、単子葉植物にはほぼないつくり 知識問題

形成層。細胞分裂をして茎を太くする層で、双子葉植物では維管束が輪のように並び、その内側（道管側）と外側（師管側）の間に形成層がある（解答冊子）。単子葉植物は維管束が散らばっていて形成層がないので、茎はあまり太くならない。漢字3字。
答え：形成層
コツ：双子葉＝維管束が輪・形成層あり・主根と側根・網状脈／単子葉＝散らばる・なし・ひげ根・平行脈、と4つ1組で思い出す。

K20 (12) 双子葉植物の根のつくり①② 知識問題

主根と側根（順不同）。太い1本の主根から細い側根が枝分かれする。単子葉植物のひげ根（太さがそろった根が多数）と対にして覚える。(11)の形成層と同じ解答冊子の1行にまとまっている。
答え：① 主根　② 側根（順不同）
コツ：「主根・側根」は2語セット。片方しか書けないときは、ダイコンやニンジン（主根が太った根）を思い出す。

K20 (13) カ（蚊）のさなぎの名前 知識問題

オニボウフラ。幼虫がボウフラ、さなぎが呼吸のための気管が鬼の角のように見えるのでオニボウフラ（解答冊子）。カは完全変態で、さなぎも水中で動く。カタカナ。
答え：オニボウフラ
コツ：ボウフラ（幼虫）とオニボウフラ（さなぎ）を取り違えない。「鬼＝角＝さなぎ」で結ぶ。

K20 (14) アリジゴクは何の幼虫か 知識問題

ウスバカゲロウ。アリジゴクは砂にすりばち状の穴を作ってアリを待つ幼虫で、成虫はトンボに似た薄い羽のウスバカゲロウ（完全変態）。カゲロウ（不完全変態）とは別の昆虫。カタカナ。
答え：ウスバカゲロウ
コツ：幼虫と成虫の名前がちがう昆虫は3組で覚える。ボウフラ→カ、アリジゴク→ウスバカゲロウ、ヤゴ→トンボ。

K20 (15) 脂肪の消化にかかわる2つの消化液①② 知識問題

① たん汁（たん液）、② すい液。たん汁は肝臓でつくられ、消化酵素を持たないが、脂肪を水と混ざりやすくして（細かい粒にして）すい液がはたらきやすくする。すい液のリパーゼが脂肪を脂肪酸とモノグリセリドに分解する（解答冊子）。
答え：① たん汁（たん液）　② すい液
コツ：「酵素は持たない」が①の合図。酵素を持つ消化液はだ液・胃液・すい液・腸液で、たん汁だけ仲間はずれ。

K20 (16) 図4で上弦の月を表す位置 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は図4の正体「北極上空から見た地球A〜Eと月ア〜オ・太陽は左」と、聞かれ方「上弦の月」。各地球から太陽へ引いた線の上にある月に「新月」、反対側に「満月」と書く（図に置く）→ 新月と満月の間が上弦・下弦で決まる。

📚 前提知識

  • 月は地球から見て太陽と同じ側にあると新月、反対側にあると満月。その間（太陽と90度）が上弦・下弦。
  • 北極上空から見ると、地球の公転も月の公転も反時計回り（図ではA→Eの向き）。新月→上弦→満月→下弦の順に進む。

🔍 こう読み解く

  1. Aのアは太陽の方向にある → 新月。Eのオも太陽の方向 → 新月。Cのウは太陽の反対側 → 満月。
  2. 新月（ア）から満月（ウ）へ進む途中にあるBのイが上弦。満月から新月へもどる途中のDのエが下弦。
  3. イは地球Bから見て太陽の方向と90度の位置にある。
答え：イ
コツ：月の形は「地球と太陽を結ぶ線から何度か」で決まる。地球の位置が動いていても、太陽への線を引き直せば同じ手順。

K20 (17) AからEまで地球が動いた角度X 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は(16)で置いた「Aのアも、Eのオも新月」と、聞かれ方「何度くらい」。A→Eを「新月から次の新月＝約29.5日」に直して書く → 地球は1日に約1度公転するので、日数がそのまま角度になる。

📚 前提知識

  • 新月から次の新月まで（月の満ち欠けの周期）は約29.5日。
  • 地球は1年（365日）で太陽のまわりを360度回るので、1日に約1度進む（解答冊子）。

🔍 こう読み解く

  1. Aで新月、Eで次の新月 → 経った日数は約29.5日。
  2. 1日約1度 × 29.5日 ＝ 約30度 → ウ。
答え：ウ
コツ：月が地球のまわりを1周する27.3日と、新月→新月の29.5日は別物。地球が公転して進んだぶん（この30度）だけ、月は余分に回らないと次の新月にならない。

K20 (18) 日の入りの頃に南の空に見える月 知識問題

ウ（上弦の月）。南中する時刻で形が決まる：新月は正午、上弦は18時（日の入り）、満月は0時、下弦は6時。日の入りに南にあるのは上弦の月で、太陽のある西側（右側）が光った半月（解答冊子）。
答え：ウ
コツ：「いつ・どの方角」を聞かれたら、まず南中時刻の4つ（12・18・0・6時）を余白に書く。

K20 (19) 2日後の日の入りに見える月について正しいもの 知識問題

イ。同じ時刻に見る月は、1日に約12度ずつ東へずれる（解答冊子）ので、2日後は約24度東。形は上弦より満月に近づくので太くなる（ア×）。日の入りの頃に南の空（いちばん高い位置）にあったものが東へずれるので、高さはその分低い（ウ×・エ×）。「すべて選びなさい」だが当てはまるのはイだけ。
答え：イ
コツ：同じ時刻に月は毎日東へ12度、月の出・南中は毎日約50分おそくなる、の2つを1組で。「西へ」と書きたくなったら、月が太陽に対して東へ回っていることを思い出す。

K20 (20) 地層が一度地上に出て再び沈み、その上に堆積してできる境目 知識問題

不整合面。地層が陸地になって風化・侵食で削られ、再び水中に沈んで新しい地層が堆積すると、でこぼこの境目（不整合面）ができる（解答冊子）。境目の上に、削られたときのれきがたまっていることが多い。連続して堆積した境目は整合。
答え：不整合面
コツ：「一度地上に出た」が合図。不整合面は「地上に出た回数」を数える手がかりになる。
