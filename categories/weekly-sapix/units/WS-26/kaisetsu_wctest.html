WS-26 WC（ウィークリーチェック WS-26＝WS-25 科学の歴史①の復習・光合成の発見とロウソクの科学）

WC 全体像 科学の歴史 2大問・各10点×10問

(1)はヘルモント→プリーストリー→インゲンホウスの3人が、光合成の材料と条件を1つずつ見つけていく話。実験文のどこに「何をはかったか／何を出したか／何が必要か」が書いてあるかを拾えば、知識の出番は最後の1語（二酸化炭素・酸素・光）だけになる。(2)はファラデー『ロウソクの科学』で、ロウソクが燃えてできる水と二酸化炭素の性質と作り方。

今回は90／100点。落としたのは(1)④「光」だけで、材料（二酸化炭素）と条件（光）を取りちがえた形。

WC (1)① ヘルモントが植木ばちに植えた理由 素材文・1つ選ぶ

👀 まず見るところ

【まざり型→素材文】設問は「なぜ植木ばちか」。部品は実験文の「土とヤナギの重さをはかって」と、結果の「土の重さは56.8gしか減っていなかった」に丸 → はかりたかったのは土の重さの変化。地面では土をはかり直せないので、植木ばちに決まる。

📚 前提知識

  • ヘルモントは「植物のからだは土からできるのか」を確かめたかった。だから土が減ったかを5年前と比べる必要がある。

🔍 こう読み解く

  1. はかった2つは「土」と「ヤナギ」。ヤナギは地面に植えてもほり出せばはかれるが、土は植木ばちに入れないと前後が比べられない。
  2. ア 日なたへの出し入れ・エ 水の量は、実験文に一言もない → 消す。イはヤナギの重さの話で、植木ばちの理由にならない → ウ。
答え：ウ
今回：ウ ○。

WC (1)②ア・イ ヘルモントが気づかなかったこと 素材文・穴うめ

👀 まず見るところ

【まざり型→素材文】部品は空らんの前後「水以外にも、目には見えない（ア）を吸収して養分をつくる」と「（ア）にも（イ）がある」に丸 → アは目に見えない光合成の材料＝気体の二酸化炭素。イは「土が減らなかったのにヤナギが増えた分」の正体＝気体にも重さがある、に直して書く。

📚 前提知識

  • 光合成の材料は水と二酸化炭素。水は根から、二酸化炭素は葉の気孔から取り入れる。ヘルモントは水だけに目を向けた。
  • ヤナギが74.5kg増えたのに土は56.8gしか減っていない。増えた分の多くは、水と空気中の二酸化炭素のぶんの重さ。

🔍 こう読み解く

  1. ア：「水以外」「目に見えない」「吸収して養分をつくる」の3語がそろう → 二酸化炭素。
  2. イ：「その（気体）にも（　）がある」→ 気体は見えないが重さがある。だから土が減らなくてもヤナギは重くなれる。
答え：ア 二酸化炭素　イ 重さ
今回：ア 二酸化炭素 ○　イ 重さ ○。

WC (1)③ プリーストリーの結論で緑の葉が出す物質 素材文・物質名

👀 まず見るところ

【まざり型→素材文】設問は「緑の葉が出す物質」。部品は結論の「ものが燃えることやネズミが生きていくために必要な物質」に丸 → 燃えるのにも呼吸にも必要な気体は酸素、と決まる。

📚 前提知識

  • ものが燃えるには酸素がいる。ガラスの容器をかぶせると火が消えるのは、中の酸素を使い切るから。
  • 植物は光合成で酸素を出す。だから植物を入れると、使われた酸素が補われてロウソクは燃え続け、ネズミは生きられる。

🔍 こう読み解く

  1. ロウソクも、ネズミも、「容器の中で続かない」→ 共通して足りなくなるのは酸素。
  2. 植物を入れると続く → 植物が酸素を出している。
答え：酸素
今回：酸素 ○。

WC (1)④ インゲンホウスの「A」 素材文・条件の名前

👀 まず見るところ

【まざり型→素材文】部品は「ある条件のもとではネズミがすぐに死んでしまう」と「植物が（酸素）を出すはたらきをするには『A』が必要」に丸。聞かれているのは材料でなくあるかないかで結果が変わる条件 → 光がないと酸素を出さない、と決まる。

📚 前提知識

  • 光合成は光があるときだけ行われる。暗い所では植物も呼吸だけをして酸素を使うので、ネズミはかえって早く死ぬ。
  • 二酸化炭素は、ネズミの呼吸で容器の中にずっとある。「ある条件のもとでは」と変わるものにはならない。

🔍 こう読み解く

  1. プリーストリーと同じ実験なのに、ときどきネズミが死ぬ → ちがうのは実験のときの明るさ（昼か夜か）。
  2. 「酸素を出すには A が必要」→ A＝光。光→光合成→酸素、の順。
答え：光
今回：二酸化炭素 ×。部品を拾えなかった＝「ある条件のもとでは」と「出すはたらきをするには…必要」に丸がなく、光合成の材料（吸収するもの）を書いた。②アで二酸化炭素を書いた直後なので引きずられた形。次は「条件＝あるかないかで変わるもの」と置きかえてから答える。
コツ：3人をセットで。ヘルモント＝水／プリーストリー＝酸素を出す／インゲンホウス＝それには光がいる。

WC (2)① 煙突をかぶせた図 素材文・図を選ぶ

👀 まず見るところ

【まざり型→素材文】部品は下線aのすぐ後ろ「空気の通路が、上にも下にも開いている」に丸 → 図で下が開いているものをさがす。ねん土で下にすき間をつくったウに決まる。

📚 前提知識

  • ロウソクが燃え続けるには、下から新しい空気（酸素）が入り、上から温まった空気が出る通り道がいる。

🔍 こう読み解く

  1. ア・イは煙突の下が皿にぴったり → 下が閉じている。
  2. ウは「ねん土で下にすき間をつくる」→ 上も下も開いている → ウ。
答え：ウ
今回：ウ ○。

WC (2)② ロウソクの中の水素からできたもの 素材文・穴うめ

👀 まず見るところ

【まざり型→素材文】部品は空らんの直前「空気の作用によって、ロウソクの中の水素からできた」に丸。「水素＋空気中の酸素 → 水」に直して書く → 燃えてできるものの1つ＝水、と決まる。

📚 前提知識

  • ロウソク（ろう）は炭素と水素でできている。燃えると炭素は二酸化炭素に、水素は水になる。

🔍 こう読み解く

  1. 設問の条件「ロウソクが燃えたときにできるもの」→ 候補は水と二酸化炭素の2つ。
  2. 空らんの直前が「水素からできた」→ 水。二酸化炭素はこのあと下線bで出てくる。
答え：水
今回：水 ○。

WC (2)③ 上のはしからぬけだす気体 素材文・気体の名前

👀 まず見るところ

【まざり型→素材文】部品は下線bのあとの「凝結性のものではありません」（＝冷やしても水にならない）と、最後の「火を、まちがいなくふき消す」に丸 → 水以外で、燃えてできて、火を消す気体＝二酸化炭素。

📚 前提知識

  • 燃えてできるのは水と二酸化炭素。水（水蒸気）は冷やすと水滴になる（凝結する）が、二酸化炭素はならない。
  • 二酸化炭素にはものを燃やすはたらきがないので、煙突の上から出てくる空気に火を近づけると消える。

🔍 こう読み解く

  1. 「凝結性ではない」→ 水ではない。②との区別はここ。
  2. 「火をふき消す」→ 二酸化炭素。
答え：二酸化炭素
今回：二酸化炭素 ○。

WC (2)④ 二酸化炭素の性質 知識問題

エ（石灰水を白くにごらせる）。二酸化炭素の確かめ方はこれ1つ。アは引っかけで、二酸化炭素に火を消す力があるのではなく、ものを燃やすはたらきがないだけ（火が消えるのは酸素がなくなるから）。イの約80%はちっ素、ウの物を燃やすはたらきは酸素。
答え：エ
今回：エ ○。

WC (2)⑤A・B 二酸化炭素をつくる液体Aと固体B 資料問題・組み合わせ

👀 まず見るところ

【まざり型→資料問題】図の正体を1行「1本の試験管に液体Aと固体Bを入れ、出た気体を水の中の試験管に集める装置」。部品は設問の「下線bの気体（二酸化炭素）をつくりたい」に丸 → 二酸化炭素＝石灰石＋塩酸。液体が塩酸、固体が石灰石と、図の位置で分ける。

📚 前提知識

  • 気体の作り方3組。二酸化炭素＝石灰石＋塩酸／酸素＝二酸化マンガン＋過酸化水素水／水素＝鉄（亜鉛）＋塩酸。選択肢はこの3組の6つ。
  • 二酸化炭素は水に少しとけるが、この図の水上置換でも集められる。

🔍 こう読み解く

  1. 3組のうち二酸化炭素は「石灰石＋塩酸」。
  2. 図では1本の試験管の中で、上に液体A・底に固体B → 液体A＝塩酸（エ）、固体B＝石灰石（ウ）。AとBを逆に書かない。
答え：A エ　B ウ
今回：A エ ○　B ウ ○。

WC まとめ 90／100点

  • (1)の実験文も(2)のファラデーの文も、答えは本文の言葉のすぐそばにある。「はかって」「出す」「必要」「凝結性ではない」「ふき消す」に丸をつければ、知識なしで決まる問題がほとんど。
  • 落とした(1)④は、材料（水・二酸化炭素）と条件（光）の取りちがえ。「条件＝あるかないかで結果が変わるもの」と置きかえてから答える。
  • 覚え直しはこの2つ。ヘルモント＝水／プリーストリー＝酸素／インゲンホウス＝光。燃えてできるのは水（水素から）と二酸化炭素（炭素から）。
