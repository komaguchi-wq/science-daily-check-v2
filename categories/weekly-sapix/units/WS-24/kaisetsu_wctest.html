WC 全体像 石灰石＋塩酸／中和 10問（各10点・100点）

(1)は石灰石と塩酸、(2)は塩酸と水酸化ナトリウム水溶液。どちらも表を見て「増え方が変わる所＝ぴったり反応する点」を先に決めれば、グラフの折れ目も計算の基準も、その1点から出てくる。(1)は「塩酸50cm³＝石灰石1g＝気体200cm³」、(2)は「塩酸60cm³＝水酸化ナトリウム水溶液40cm³＝固体6g」が基準の1行。

今回は80／100点。(1)全問と(2)①②③は取れている。落とした(2)④⑤は、どちらも前の小問から変わった部品（横軸が塩酸になった／塩酸が2倍うすくなった）を数に直さないまま線を引いた形で、基準の1行を余白に置けば同じ手順で決まる。

WC (1)① 石灰石の重さと気体の量のグラフ まざり型・表からグラフ

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「塩酸50cm³に加える石灰石(g)と気体(cm³)」を1行と、表で同じ数が並ぶ「200・200」に丸 → 気体は200cm³で頭打ち。200cm³になる石灰石の重さが折れ目になる。

📚 前提知識

  • 石灰石＋塩酸 → 二酸化炭素。どちらか一方がなくなった時点で反応は止まるので、気体の量は少ない方で決まる。
  • 反応する量は比例する。0.3gで60cm³なら、1gで200cm³。

🔍 こう読み解く

  1. 表の5点（0.3,60）（0.6,120）（0.9,180）（1.2,200）（1.5,200）と原点を打つ。
  2. 0.3g→60cm³は1gあたり200cm³。気体が200cm³に達するのは石灰石1.0g。表にはない点だが、比例の線と200の水平線が交わる所として決まる。
  3. 原点から（1.0,200）まで直線、そこから右は200のまま水平。（1.2,200）（1.5,200）がこの水平線に乗る。
答え：解答冊子の図（原点から（1.0g,200cm³）まで直線、そこから右は200cm³で水平）
今回：○。原点から（1.0,200）で折れて水平になる線が引けている。折れ目を1.0gに置けたのが決め手。

WC (1)② 塩酸100cm³と過不足なく反応する石灰石 まざり型・比例の計算

👀 まず見るところ

【まざり型→条件文】部品は「塩酸100cm³」と「過不足なく」に丸。①の折れ目「塩酸50cm³＝石灰石1g」を余白に書き、100cm³は50cm³の2倍と直して書く → 石灰石も2倍。

📚 前提知識

  • 「過不足なく反応する」＝どちらも余らない組み合わせ。①のグラフの折れ目がその組み合わせ（塩酸50cm³↔石灰石1g）。

🔍 こう読み解く

  1. 塩酸50cm³ ↔ 石灰石1g。
  2. 塩酸が2倍の100cm³なら、石灰石も2倍 → 2g。
答え：2 g
今回：2 ○。

WC (1)③ 塩酸200cm³に石灰石4.5g 条件文・どちらが余るか

👀 まず見るところ

【条件文】部品は「塩酸200cm³」「石灰石4.5g」に丸。基準の「塩酸50cm³：石灰石1g：気体200cm³」を4倍に直して書く（200cm³：4g：800cm³）→ 4.5gは4gより多い。どちらが先になくなるかで気体の量が決まる。

📚 前提知識

  • 両方の量が書いてある問題は、先に「ぴったりの組」を作り、多い方が余ると決める。気体の量は足りない方（なくなる方）で決まる。

🔍 こう読み解く

  1. 塩酸200cm³は50cm³の4倍 → ぴったり反応する石灰石は4g、気体は800cm³。
  2. 石灰石は4.5gあるので0.5g余る。塩酸が全部使われた時点で反応は止まる。
  3. 4.5g×200cm³＝900cm³としない。塩酸が足りないので、気体は塩酸200cm³ぶんの800cm³。
答え：800 cm³
今回：800 ○。余白の「200 4」（塩酸200cm³↔石灰石4g）が基準の1行になっている。

WC (1)④ 石灰石と塩酸で発生した気体 知識問題

二酸化炭素。石灰石（主成分は炭酸カルシウム）に塩酸を加えると二酸化炭素が出る。同じ二酸化炭素が出る組み合わせとして、重そう（炭酸水素ナトリウム）＋塩酸、貝がら・卵のから＋塩酸もセットにしておく。
答え：二酸化炭素
今回：二酸化炭素 ○。

WC (1)⑤ 二酸化炭素と確かめる水溶液 知識問題

石灰水。二酸化炭素を通すと白くにごる（水にとけにくい炭酸カルシウムができる）。気体の確かめ方は「二酸化炭素＝石灰水が白くにごる／酸素＝線香が炎を上げて燃える／水素＝火を近づけると音を立てて燃える」の3つを1組で。
答え：石灰水
今回：石灰水 ○。

WC (2)① 残った固体の重さのグラフ まざり型・表からグラフ

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「塩酸60cm³に加えた水酸化ナトリウム水溶液(cm³)と残った固体(g)」を1行と、増え方が変わる所（10cm³ごとに＋1.5g→＋1g、40cm³の所）に丸 → そこが完全中和。グラフはここで折れる。

📚 前提知識

  • 塩酸＋水酸化ナトリウム水溶液 → 塩化ナトリウム＋水。蒸発させて残る固体は塩化ナトリウムと、余った水酸化ナトリウム。
  • 塩酸は気体（塩化水素）が水にとけたものなので、蒸発させると何も残らない。だから固体の増え方が変わるのは、塩酸がなくなった瞬間。

🔍 こう読み解く

  1. 表の増え方を見る。10→40cm³は1.5gずつ、40→100cm³は1gずつ。変わり目は40cm³・6g＝完全中和の点。
  2. 40cm³までは加えた水酸化ナトリウムが全部反応して塩化ナトリウムになる。40cm³より先は塩酸がないので、余った水酸化ナトリウムがそのまま残る（10cm³で1g）。
  3. 原点から（40,6）まで直線、そこで折れて10cm³ごとに1gの傾きで右上へ。上端まで引くと（130,15）。
答え：解答冊子の図（原点→（40cm³,6g）で折れ、そこから10cm³ごとに1gの傾きで右上へ）
今回：○。原点→（40,6）で折れて、傾きをゆるめて右上へ引けている。横軸の下に「10 30 40」と目盛りをふってから点を打った跡があり、表の点をそのまま置く手順ができている。

WC (2)② 塩化ナトリウムだけのグラフ まざり型・固体の中身を分ける

👀 まず見るところ

【まざり型→資料問題】部品は設問の「塩化ナトリウムの重さ」に丸と、①で決めた折れ目「40cm³で6g」。塩化ナトリウムは中和でできる塩なので、塩酸がなくなる40cm³より先は増えないと直して書く。

📚 前提知識

  • 塩化ナトリウムは塩酸と水酸化ナトリウムが反応してできる。片方（塩酸）がなくなれば、それ以上はできない。
  • 40cm³までの固体6gは全部塩化ナトリウム（水酸化ナトリウムは余っていない）。

🔍 こう読み解く

  1. 0〜40cm³：①と同じ線。原点から（40,6）まで直線。
  2. 40cm³より先：塩酸がないので塩化ナトリウムは6gのまま → 6gで水平。
答え：解答冊子の図（原点→（40cm³,6g）、そこから右は6gで水平）
今回：○。原点→（40,6）→水平の線が引けている。

WC (2)③ 水酸化ナトリウムだけのグラフ まざり型・固体の中身を分ける

👀 まず見るところ

【まざり型→資料問題】部品は設問の「水酸化ナトリウムの重さ」と、表の40cm³以降の増え方「10cm³で＋1g」に丸。40cm³までは全部反応して0g、40cm³より先は余った分がそのまま残る＝10cm³ごとに1gと直して書く。

📚 前提知識

  • 水酸化ナトリウム水溶液10cm³には固体の水酸化ナトリウムが1gとけている（表の40→50cm³で固体が1g増えることから決まる）。
  • 塩酸が残っているうちは、加えた水酸化ナトリウムは全部塩化ナトリウムに変わる → 残る水酸化ナトリウムは0g。

🔍 こう読み解く

  1. 0〜40cm³：水酸化ナトリウムは全部反応する → 0gで水平。
  2. 40cm³より先：余った水酸化ナトリウムが10cm³ごとに1g残る → （40,0）から右上へ。右端の150cm³で11g。
  3. 検算：②と③を足すと①になる（40cm³より先は 6＋余った分）。
答え：解答冊子の図（0〜40cm³は0gで水平、（40cm³,0g）から10cm³ごとに1gの傾きで右上へ）
今回：○。40cm³まで0、そこから右上への線が引けている。

WC (2)④ 水酸化ナトリウム水溶液60cm³に塩酸を加える 条件文・逆から加える

👀 まず見るところ

【条件文】部品は前と変わった「水酸化ナトリウム水溶液60cm³に加える塩酸の量」（横軸が塩酸）と「濃さは最初と同じ」に丸。「NaOH水溶液10cm³＝固体1g」「塩酸60cm³↔NaOH水溶液40cm³」の2行を余白に置く → 塩酸0cm³の固体6gと、中和点の塩酸90cm³が決まる。

📚 前提知識

  • 塩酸を加える前は水酸化ナトリウム水溶液60cm³だけ。蒸発させると水酸化ナトリウム6gが残る（10cm³で1g）。グラフが0gから始まらないのはこのため。
  • 中和点をすぎて余った塩酸は、蒸発させると何も残らない。だから中和点より先は固体が増えない。

🔍 こう読み解く

  1. 塩酸0cm³：固体は水酸化ナトリウム6g。紙面に打ってある点（0,6）がこれ。
  2. 中和点：塩酸60cm³↔NaOH水溶液40cm³ だから、NaOH水溶液60cm³には塩酸90cm³。できる塩化ナトリウムは6g×（60÷40）＝9g。点（90,9）。
  3. 塩酸が加わるほど水酸化ナトリウム（1g分）が塩化ナトリウム（1.5g分）に変わるので、6gから9gへゆるく増える。90cm³より先は塩酸が余るだけなので9gで水平。
答え：解答冊子の図（（0cm³,6g）から（90cm³,9g）まで直線、そこから右は9gで水平）
今回：×。答案は（0,6）から右上へ10cm³で1.5gずつ上がる線がうすく残っているだけで、(2)①の形を6gの高さに置いた形。部品の形を直さなかった＝「水酸化ナトリウム水溶液60cm³に塩酸を加える」を「塩酸0で6g／塩酸90cm³で中和／その先は増えない」に直していない。次は「NaOH10cm³＝1g」「塩酸60↔NaOH40」の2行を先に余白に置く。
コツ：横軸が塩酸に変わったら、グラフは「最初から固体がある→ゆるく増える→水平」。横軸が水酸化ナトリウム水溶液なら「0から→折れて増え続ける」。2つの形をセットで持っておく。

WC (2)⑤ 2倍にうすめた塩酸60cm³ 条件文・濃さを直す

👀 まず見るところ

【条件文】部品は変わった「2倍にうすめた塩酸60cm³」に丸 → 「もとの塩酸30cm³分」と直して書く。中和に必要な水酸化ナトリウム水溶液は40の半分の20cm³、固体は6の半分の3g。加える前（0cm³）は塩酸だけなので固体0g、原点から始まる。

📚 前提知識

  • 2倍にうすめる＝水を足して体積を2倍にする。60cm³の中の塩化水素は、もとの塩酸30cm³分と同じ。
  • 塩酸だけを蒸発させると何も残らないので、水酸化ナトリウム水溶液0cm³のときの固体は0g。

🔍 こう読み解く

  1. もとの塩酸60cm³↔NaOH水溶液40cm³・固体6g。塩酸が30cm³分なら、中和点はNaOH水溶液20cm³・固体3g。
  2. 原点から（20,3）まで直線（10cm³で1.5g、①と同じ傾き）。
  3. 20cm³より先は水酸化ナトリウムが10cm³ごとに1g余る → ①の後半と同じ傾きで右上へ。上端まで引くと（140,15）。
答え：解答冊子の図（原点→（20cm³,3g）で折れ、そこから10cm³ごとに1gの傾きで右上へ）
今回：×。答案は紙面の点（0,6）から右下がりに（60,0）まで引き、そこから右上へうすい線を足した形。部品の形を直さなかった＝「2倍にうすめた塩酸60cm³」を「もとの塩酸30cm³分→中和点はNaOH20cm³・3g」に直さず、印刷された点から線を始めている。水溶液0cm³で固体が6gになる理由はないので、まず中和点を書いてから原点を出発点にする。
コツ：⑤の紙面には（0,6）に点が打ってあるが、解答冊子のグラフは原点から始まっている。点にしばられず、「0cm³のとき何が残るか」を自分で決める。

WC まとめ 80／100点

  • 取れた8問は、表の「増え方が変わる所」を折れ目にしてグラフと計算の基準にする手順ができている。(1)③の「塩酸200↔石灰石4g→800cm³」は余白のメモどおり。
  • 落とした(2)④⑤はどちらも変わった部品を数に直す前に線を引いた失点。④は横軸が塩酸（最初から固体6g・中和点は塩酸90cm³・その先は水平）、⑤は塩酸が2倍うすい（中和点は半分の20cm³・3g）。「NaOH10cm³＝1g」「塩酸60↔NaOH40」の2行を余白に置いてから引けば、どちらも①の線の形の言いかえになる。
  • 覚え直しはこの2つ。塩酸は蒸発すると何も残らない（余っても固体は増えない）／うすめた塩酸は「もとの何cm³分か」に直す。
