K20 (1)(2) 図1の方位磁針の振れる向きと大きさ 条件文・すべて選ぶ／大きさの順

👀 まず見るところ

【条件文】部品は「右側（東側）に振れる」「すべて」と、(2)で変わった「振れの大きさの順」「例にならって」に丸。電池の＋（長い線）から出る電流の矢印を全部の導線に書きこむ（図に置く）→ 向きは矢印と「導線が針の上か下か」で、大きさは豆電球の数で決まる。

📚 前提知識

  • 電池は長い線が＋極。図1では＋から出た電流が右の道（オ）を上り、上の導線で左へ進んで、エの道と（ア・イ→ウ）の道に分かれて下り、スイッチを通って−にもどる。
  • 針の振れる向きは、電流の向きと「導線が針の上を通るか下を通るか」で決まる。同じ下向きの電流でもアは西・イは東（解答冊子の図：ア西2・イ東1・ウ東3・エ西2・オ東5）。上下がちがうと振れは逆になる。
  • 振れの大きさ＝電流の大きさ。豆電球1個の道と2個直列の道が並列なら、流れる電流は2：1。

🔍 こう読み解く

  1. アの道は豆電球1個、イの道は2個の直列 → 電流はア②：イ①。合流したウは②＋①＝③。
  2. エの道の豆電球1個は、アの豆電球1個と同じ2つの点の間につながっている（間は導線だけ）。アの1個に②流れるなら、エの1個にも②。オは全部の合計 ③＋②＝⑤。
  3. (1) 東に振れるのはイ・ウ・オ（解答冊子の図）。(2) 大きさは ⑤オ＞③ウ＞②ア＝エ＞①イ。
答え：(1) イ・ウ・オ　(2) オ＞ウ＞ア＝エ＞イ
自分で解くときのチェック：5つの針すべてに「東／西」と電流の数を書いてから答える。(1)は「すべて」なので3つ、(2)は「＝」の組（ア＝エ）を落とさない。

K20 (3)(4) 図2 2本のばねばかりでつるした棒 条件文・計算

👀 まず見るところ

【条件文】部品は「40gの太さが一様な棒」と図の「14cm・7cm」「75g・25g」。40gは棒のまん中に下向きの矢印で置く（直して書く）→ 3つの重さを1つずつ「Aに何g・Bに何g」に分けて、最後に足す。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなせる。両端でつるした棒の重さは2本に半分ずつ（20g・20g）。
  • 1つのおもりを2本で分けて支えるとき、力の比は距離の逆比。おもりに近いほうが多く受ける。

🔍 こう読み解く

  1. 棒40g：まん中なので A20g・B20g。
  2. 75gのおもり：Aから14cm・Bから7cm → 力の比は A：B＝7：14＝1：2 → A25g・B50g。
  3. 25gのおもり：Bの糸の真下 → 全部Bへ。A0g・B25g。
  4. 合計 A＝20＋25＝45g、B＝20＋50＋25＝95g。確かめ：45＋95＝140＝40＋75＋25。
答え：(3) 45g　(4) 95g
自分で解くときのチェック：重さごとに「A／B」の表を書く（解答冊子の形）。最後に AとBの合計が全部の重さと同じになるかで検算する。

K20 (5)(6) 図3 3連の滑車2組と糸Cの力 条件文・計算

👀 まず見るところ

【条件文】部品は「Aの重さ1200g」「1組が120g」「Cの糸」。下の組は「A＋滑車＝1320gを6本の糸で支える」に直して書く（図に置く）→ 糸1本の力がそのままB、Cは上の組のつり合いで決まる。

📚 前提知識

  • 1本の糸にかかる力はどこでも同じ。動く組（下の組）を支える糸が6本なら、下向きの重さの6分の1が糸1本にかかる。
  • 天井に固定した上の組は、糸に引き下げられる力と自分の重さ120gを、天井からの2本の糸（左とC）で支える。いちばん右の糸は天井に直接つながっていて、上の組は引かない。

🔍 こう読み解く

  1. 下の組にかかる重さ＝1200＋120＝1320g。支える糸は6本 → 1本 1320÷6＝220g。
  2. (5) Bはこの糸の端 → 220g。
  3. (6) 上の組を引き下げる糸は、Bにつながる1本＋下の組との間の5本＝6本 → 220×6＝1320g。それに自分の重さ120gを足して1440g。天井の糸は左とCの2本 → 1440÷2＝720g。
答え：(5) 220g　(6) 720g
自分で解くときのチェック：「滑車1組120g」は下の組にも上の組にも足す。(6)で120gを足し忘れると660gになる。

K20 (7) 図4 坂を転がる球の速さの順 資料問題・速い順

👀 まず見るところ

【資料問題】部品は資料の正体「坂の図・ア〜カの高さ」と聞かれ方「速い順」「例にならって（＝を使う）」。図の2本の点線は「同じ高さ」の印。ア〜カの横に高さの順を書きこむ（図に置く）→ 低いほど速い。

📚 前提知識

  • 転がる球の速さは、出発点からどれだけ下がったかで決まる。高低差が大きいほど速い（解答冊子）。途中の道の形は関係なく、同じ高さなら同じ速さ。

🔍 こう読み解く

  1. いちばん低いのは下の平らにあるエ → いちばん速い。次は下の坂の途中のウ。
  2. イとオは下の点線でつながっている＝同じ高さ → イ＝オ。
  3. カは上の点線の高さ、アはその点線より上でAに近い → カ＞ア。いちばん高いアがいちばんおそい。順は エ＞ウ＞イ＝オ＞カ＞ア。
答え：エ＞ウ＞イ＝オ＞カ＞ア
自分で解くときのチェック：先に点線で「＝」の組を見つけてから、残りを高さの順にならべる。

K20 (8)(9) 中和の表 緑色になるビーカーと濃度 まざり型・表の読み取り＋計算

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「塩酸50cm³に水酸化ナトリウム水溶液を10cm³ずつ・残った固体g」と聞かれ方「BTBが緑色（＝中性）」。表の下に固体の「増え方」を書く（直して書く）：0.6・0.6・0.6・0.6→0.4・0.4・0.4 → 増え方が変わる⑤が完全中和。(9)は「増え方0.4g＝水溶液10cm³にとけている水酸化ナトリウム」に直して濃度を出す。

📚 前提知識

  • 中和で残る固体は食塩。塩酸が余っているうちは、加えた分だけ食塩が増える（10cm³ごとに0.6g）。
  • 完全中和のあとは、加えた水溶液にとけている水酸化ナトリウムがそのまま残る（10cm³ごとに0.4g・解答冊子）。余った塩酸の塩化水素は気体なので、蒸発させると残らない。
  • BTB溶液は酸性＝黄・中性＝緑・アルカリ性＝青。密度1g/cm³なら10cm³＝10g。

🔍 こう読み解く

  1. 増え方は①〜⑤が0.6ずつ、⑤→⑥から0.4ずつ。変わり目の⑤で塩酸をちょうど使い切っている → (8)は⑤。
  2. (9) ⑤より後の増え方0.4gが、水溶液10cm³にとけていた水酸化ナトリウム。10cm³は10gなので、濃度＝0.4÷10×100＝4%（解答冊子の式）。
答え：(8) ⑤　(9) 4%
自分で解くときのチェック：表は値をながめず「となりとの差」を書く。差が変わる所が完全中和で、変わったあとの差が濃度の材料になる。

K20 (10) 塩酸で二酸化炭素を出す固体の成分 知識問題

イ・オ。塩酸にとけて二酸化炭素を出す固体は、炭酸カルシウムをふくむ石灰石（貝がら・卵のからも）と、炭酸水素ナトリウムをふくむふくらし粉（重そう）（解答冊子）。「炭酸」がつく2つと結びつける。水酸化〜は塩酸と中和するだけ、塩化〜は中和でできる食塩の仲間で、どちらも気体は出ない。「2つ選ぶ」の指定（順不同）。
答え：イ・オ

K20 (11) 花びらが5枚の植物 知識問題

ウ・エ。花びらのある双子葉植物は5枚のものが多く、アサガオ・ツツジは花びらがくっついていても5枚と数える。ナズナはアブラナ科で4枚（十字の形）、ツユクサ・アヤメは単子葉植物で3枚（解答冊子）。「すべて」なので2つ。
答え：ウ・エ

K20 (12) 花びらが1枚1枚取れる植物（離弁花） 知識問題

イ・オ。1枚ずつ取れる離弁花はマメ科・バラ科（ウメ・サクラ）・アブラナ科・ツバキ科（サザンカ・ツバキ）。くっついている合弁花はヒルガオ科（ヒルガオ・アサガオ）・ナス科（トマト）・キク科（タンポポ）（解答冊子）。「すべて」なので2つ。
答え：イ・オ

K20 (13) モンシロチョウの幼虫が食べない葉 知識問題

K20 (14) モンシロチョウの幼虫のあしの付き方 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】部品は資料の正体「幼虫を横から見た絵4つ・あしの位置がちがう」と聞かれ方「正しいもの」。絵の下に頭から「あしのある節・ない節」を数字で書きこむ（図に置く）→ 3・空2・4・空2・1 の並びに合う絵が答え。

📚 前提知識

  • モンシロチョウの幼虫のあしは、胸に3対6本（つめ状）、2節あけて腹に4対8本（吸盤状）、さらに2節あけて尾に1対2本（吸盤状）の合計16本（解答冊子）。
  • 成虫になって残るのは胸の6本だけ。腹と尾の吸盤状のあしは、葉につかまるための幼虫だけのあし。

🔍 こう読み解く

  1. 頭のすぐ後ろの3節にあし（胸の6本）。
  2. 2節あけて、4節つづけてあし（腹の8本）。
  3. 2節あけて、いちばん後ろの節にあし（尾の2本）。この並びになっている絵がエ。
答え：エ
自分で解くときのチェック：4つの絵それぞれに「3・2・4・2・1」の数を書いて、ちがう所に×をつけてから選ぶ。

K20 (15) たんぱく質が初めに消化される場所と酵素 知識問題

胃・ペプシン。たんぱく質は口と食道では消化されず、胃液のペプシンで初めて分解され、そのあとすい液・小腸の壁の消化酵素でアミノ酸になる。でんぷんは口のだ液（アミラーゼ）、脂肪はすい液（リパーゼ）から、と「初めの場所」をセットで覚える。
答え：場所 胃　酵素 ペプシン

K20 (16)(17) 図5 春分と夏至の正午の太陽高度の順 資料問題・高い順

👀 まず見るところ

【資料問題】部品は資料の正体「地球の断面・北極が上・A〜Eは30度ごと・太陽の光は左から」と、(17)で変わった「夏至」に丸。図5に「太陽が真上に来る緯度」を書きこむ（春分＝赤道C／夏至＝北緯23.4度＝Cより少し北でBに近い）→ そこから遠いほど正午の太陽高度は低い。

📚 前提知識

  • 正午の太陽高度＝90度−（太陽の真下の緯度との差）。春分・秋分は太陽が赤道の真上（解答冊子）、夏至は北緯23.4度（北回帰線）、冬至は南緯23.4度の真上。
  • 図5の線は30度ずつ。A北緯60度・B北緯30度・C赤道・D南緯30度・E南緯60度。

🔍 こう読み解く

  1. (16) 春分：真上はC。差はB・Dが30度、A・Eが60度 → C＞B＝D＞A＝E。
  2. (17) 夏至：真上は北緯23.4度。差はB 6.6度・C 23.4度・A 36.6度・D 53.4度・E 83.4度 → B＞C＞A＞D＞E。
答え：(16) C＞B＝D＞A＝E　(17) B＞C＞A＞D＞E
自分で解くときのチェック：「＝」が出るのは太陽が赤道の真上の春分・秋分だけ。夏至・冬至は全部にちがいがつく。

K20 (18)(19) 図6 冬の大三角 資料問題・星の名前と色

👀 まず見るところ

【資料問題】部品は資料の正体「冬の大三角のスケッチ」と設問「Bの星の名前と星座名」「青白い色」。3つの星のまわりの形を図に書きこむ（図に置く）→ C・Dは3つ星が並ぶオリオン座、Aはそばに星が1つだけのこいぬ座、残ったBがおおいぬ座。

📚 前提知識

  • 冬の大三角＝おおいぬ座シリウス（白）・こいぬ座プロキオン（黄）・オリオン座ベテルギウス（赤）。オリオン座のもう1つの1等星リゲルは青白い（解答冊子）。
  • 星の色は表面の温度の順：青白い＞白＞黄＞赤。青白いリゲルがいちばん高温。

🔍 こう読み解く

  1. C・Dをふくむ右の星座は、3つ星が並ぶ砂時計の形 → オリオン座。大三角に入るCがベテルギウス、入らないDがリゲル。
  2. Aのそばは星が1つだけ → こいぬ座プロキオン。多くの星がつながるBはおおいぬ座シリウス。(18)の答え。
  3. (19) 青白いのはリゲル → D。
答え：(18) 星 シリウス・おおいぬ座　(19) D

K20 (20) 岩石の3つの種類 知識問題

堆積岩・変成岩。岩石は堆積岩（砂・泥・火山灰・生物のからが積もって固まる）・火成岩（マグマが冷え固まる。火山岩と深成岩）・変成岩（堆積岩や火成岩が熱や圧力で変化。石灰岩→大理石、泥岩→ネンバン岩）の3種類（解答冊子）。順不同。
答え：堆積岩・変成岩
