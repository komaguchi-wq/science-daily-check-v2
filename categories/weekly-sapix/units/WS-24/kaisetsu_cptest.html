WS-24 CP（コアプラス確認テスト WS-24・気象の再徹底 20問）

CP 全体像 気象の再徹底 20問（範囲318〜355・601）

コアプラスの気象をひと通り確かめる20問。(1)〜(8)は太陽高度・気温・湿度（装置の図・気温グラフ・飽和水蒸気量の表）、(9)〜(18)は風・前線・天気図（海風の実験・梅雨前線の記号・冬型の天気図・低気圧の風）、(19)(20)は台風。図や表がある問は、正体を1行書いてから読むと迷わない。

今回は75／100点。落とした5問は (7)（表の使い方）、(12)(16)（名前の書き方）、(17)(19)（低気圧・台風の風の向き）。知識の穴というより、表や図に部品を置く前に答えを書いた形の失点が多い。

CP (1) 太陽高度をはかる装置 資料問題・角度の読み取り

👀 まず見るところ

【資料問題】部品は図の正体「つつに分度器、糸におもり」と、目盛りの「47°」。糸はいつも真下（水平と90°）と図の横に書く → つつを持ち上げた角度は 90°−47°で決まる。

📚 前提知識

  • 太陽高度＝水平面から太陽までの角度。おもりをつけた糸は、装置をどう傾けても鉛直（真下）を向く。
  • つつが水平なら、糸はつつと直角（90°）。つつを高度hだけ上げると、糸とつつの間の角は 90°−h（反対側から読めば 90°＋h）になる。

🔍 こう読み解く

  1. つつを太陽に向けると、糸の位置の目盛りが47°。この47°は「糸とつつの間の角」。
  2. 糸が真下なので、つつの高度は 90−47＝43°。
答え：43度
今回：43 ○。

CP (2) 4月下旬と同じ南中高度になる月 条件文・時期の対称

👀 まず見るところ

【条件文】部品は「4月下旬」と「南中高度や昼の長さが同じ」に丸。「同じ」は夏至（6月下旬）をはさんで反対側に直して書く → 夏至の約2か月前と対になるのは約2か月後。

📚 前提知識

  • 南中高度と昼の長さは夏至（6月下旬）に最大、冬至（12月下旬）に最小。夏至をはさんで同じ日数だけ前と後の日は、太陽の動きがほぼ同じになる。

🔍 こう読み解く

  1. 4月下旬は夏至のおよそ2か月前。
  2. 夏至のおよそ2か月後は8月下旬。選択肢の6・10・12は、それぞれ夏至そのもの・秋分すぎ・冬至なので合わない。
答え：8（月下旬）
今回：8 ○。
コツ：ペアで覚える。4月下旬⇔8月下旬、3月下旬（春分）⇔9月下旬（秋分）、2月下旬⇔10月下旬。

CP (3) 「くもり」の雲量 知識問題

9。雲量は空全体を10としたときの雲の割合で、0〜1が快晴、2〜8が晴れ、9〜10がくもり。「晴れ」の範囲が広いことに注意する。
答え：9
今回：9 ○。

CP (4) 3日間の気温グラフと放射冷却 資料問題・空らん

👀 まず見るところ

【資料問題】部品は正体「3日間の気温の1日変化・℃・時刻」と、設問の「Aの日の最低気温が最も低く」。Aは最高も最も高い＝1日の変化が最大と書く → 雲がない晴れの日で、夜に熱が逃げる。

📚 前提知識

  • 晴れの日は昼に日光で気温が大きく上がり、夜は雲がないので地面の熱が宇宙へ逃げて大きく下がる。この夜の冷え方が放射冷却。
  • くもりや雨の日は雲がふたになって、昼は上がりにくく夜は下がりにくい（Cのように平ら）。

🔍 こう読み解く

  1. Aは14時ごろ約26℃まで上がり、明け方は約15℃。B・Cより上下の幅が大きい → ①晴れ。
  2. 晴れの夜は雲がないので、地面から放射で逃げる熱が多い → ②放射（冷却）。
答え：① 晴れ　② 放射
今回：晴れ・放射 ○。

CP (5) 乾湿球湿度計の乾球と湿球 素材文・大小の選択

👀 まず見るところ

【素材文】設問は「乾球は湿球より高いか低いか」「湿度が高いと差はどうなるか」。部品は「湿球」に丸 → 湿球は水でぬれていて蒸発で熱をうばわれると直して書く。蒸発しやすいほど差が開く、で2つとも決まる。

📚 前提知識

  • 湿球は球の部分をぬれたガーゼで包んだ温度計。水が蒸発するときにまわりから熱をうばうので、湿球のほうが低くなる。
  • 湿度が高い（空気がしめっている）ほど水は蒸発しにくく、熱をうばわれる量が減る。湿度100%なら蒸発せず、差は0。

🔍 こう読み解く

  1. 湿球が下がるので、乾球は湿球より ①高く。
  2. 湿度が高い → 蒸発が少ない → 湿球があまり下がらない → 差は ②小さく。
答え：① 高く　② 小さく
今回：高く・小さく ○。

CP (6) 18℃・湿度80%の水蒸気量 条件文・計算

👀 まず見るところ

【条件文】部品は「18℃」「湿度80%」と答え方の「小数第2位を四捨五入」に丸。表の18℃の列「15.4」に丸をつけ、80%は×0.8に直して書く → 15.4×0.8 の1本の式になる。

📚 前提知識

  • 湿度（%）＝空気1m³にふくまれる水蒸気量÷その気温の飽和水蒸気量×100。だから 水蒸気量＝飽和水蒸気量×湿度÷100。

🔍 こう読み解く

  1. 表で18℃の飽和水蒸気量を読む → 15.4g。
  2. 15.4×0.8＝12.32 → 小数第2位を四捨五入して 12.3g。
答え：12.3g
今回：12.3 ○。表の「18」「15.4」に丸をつけて「15.4×0.8＝12.32」と式を書いてから答えている。部品を紙に置く手順そのもの。

CP (7) 露が発生した気温（露点を表で読む） 条件文・表の読み取り

👀 まず見るところ

【条件文】部品は「(6)のあと」＝水蒸気量は12.3gのままと、「霧や露が発生した」「何℃以下」に丸。露＝飽和水蒸気量が12.3を下回ると直して表に置く → 表を右から左へたどり、初めて12.3を下回る気温が答え。

📚 前提知識

  • 気温が下がっても、空気にふくまれる水蒸気の量は変わらない。飽和水蒸気量のほうが下がってきて、水蒸気量を入れきれなくなったところで水滴（露・霧）ができる。

🔍 こう読み解く

  1. 18℃から左へ。15℃は12.8g → 12.3gはまだ入る（露はできない）。
  2. 14℃は12.1g → 12.3gは入りきらない → ここで露 → 14℃以下。
答え：14℃
今回：15 ×。部品の形を直さなかった＝「露が発生」を「飽和水蒸気量＜12.3」に直して表に置かず、12.3をはさむ14と15のうち上を選んだ。次は表の12.8と12.1の間に「12.3」と書きこんで、入りきらない側（12.1）を選ぶ。
コツ：「何℃以下」と聞かれたら、答えは水滴ができ始める側の温度。まだ余裕がある温度（15℃）は露が出ていない。

CP (8) 水滴が発生する気温の名前 知識問題

露点。空気を冷やしていって、水蒸気が飽和して水滴ができ始める温度。(7)で表から読んだ14℃がこの空気の露点。露点が高いほど、空気にふくまれる水蒸気が多い。
答え：露点
今回：ろてん ○。

CP (9) 白熱電球と線香の煙（海風の実験） 資料問題・実験の図

👀 まず見るところ

【資料問題】部品は図の正体「電球の下に左が水・右が砂」と、設問の「煙は右の方へ」。砂＝陸、水＝海と図に書き、煙の向き＝風の向きと直す → 海から陸へ吹く風で、①も②も決まる。

📚 前提知識

  • 砂（陸）は水（海）よりあたたまりやすい。あたたまった陸の上の空気が軽くなって上がり、そこへ海の上の空気が流れこむ → 昼の海風（海→陸）。夜は逆に陸風。
  • 同じことが季節の単位で起こるのが季節風。夏は大陸より海のほうが冷たいので、海洋から大陸へ（日本では南東から）吹く。冬は逆に大陸から海洋へ。

🔍 こう読み解く

  1. 電球で照らすと砂のほうが先にあたたまり、砂の上の空気が上昇 → 水側から砂側へ空気が動く → 煙が右（砂）へ。
  2. 水＝海、砂＝陸なので、海から陸へ吹く ①海風。海から陸へ吹く季節風は ②夏。
答え：① 海（風）　② 夏
今回：海・夏 ○。

CP (10) 水と砂のあたたまり方 素材文・大小の選択

👀 まず見るところ

【素材文】設問は「(9)のように空気が動く理由」。部品は「水は砂よりも」に丸 → (9)で砂が先にあたたまったのだから、水はあたたまりにくい。冷めるときも同じ向き（にくい）とそろえて書く。

📚 前提知識

  • 水は砂や岩よりあたたまりにくく、冷めにくい（温度が変わりにくい）。だから昼は陸のほうが高温、夜は海のほうが高温になり、海風・陸風や季節風が生まれる。

🔍 こう読み解く

  1. (9)で先にあたたまったのは砂。水は ①あたたまりにくく。
  2. あたたまりにくいものは、冷めるのもおそい → ②冷めにくい。「にくく・にくい」のセット。
答え：① にくく　② にくい
今回：にくく・にくい ○。

CP (11) 天気が西から東へ変わる理由の風 知識問題

偏西風。日本の上空を1年中西から東へ吹いている風で、低気圧や高気圧がこれに流されるので天気も西から東へ移る。「西の空が晴れていれば明日は晴れ」の根拠。
答え：偏西（風）
今回：へんせい ○。

CP (12) 梅雨前線をつくる2つの気団 知識問題

暖気が小笠原気団（南の海上・あたたかくしめっている）、寒気がオホーツク海気団（北東の海上・冷たくしめっている）。2つの勢力がつり合って前線が動かないので停滞前線になる。「オホーツク海気団」は「海」までが名前。
答え：① 小笠原（気団）　② オホーツク海（気団）
今回：おがさわら・オホーツク ×。知識＝②が「オホーツク」で止まり、名前の一部の「海」が抜けている（①はほかの問と同じくひらがなでも中身は合っている）。暖気・寒気の組み合わせは合っているので、②を「オホーツク海」まで書けば取れる。

CP (13) 梅雨前線の記号 資料問題・記号の選択

👀 まず見るところ

【資料問題】部品は「梅雨前線」＝停滞前線と、決まりの「上が北」に丸。北にオホーツク海気団（寒気）、南に小笠原気団（暖気）と図の上下に書く → 半円が北側・三角が南側のものを選ぶ。

📚 前提知識

  • 前線の記号は「暖気が進む向きに半円、寒気が進む向きに三角」。停滞前線はどちらも押し切れないので、線の両側に半円と三角が交互に出る。
  • 半円と三角が同じ側にならぶのは閉塞前線（ウ・エの形）。

🔍 こう読み解く

  1. ウ・エは半円と三角が同じ側 → 閉塞前線なので消す。
  2. 残るア・イは上下が逆。暖気（南の小笠原）は北へ押すので半円は北側＝上、寒気（北のオホーツク海）は南へ押すので三角は南側＝下 → ア。
答え：ア
今回：ア ○。

CP (14) 梅雨前線の動き 知識問題

北上。6月から7月にかけて南の小笠原気団が強まり、前線を北へ押し上げていく。前線が北へぬけると梅雨明けで、日本は小笠原気団におおわれて夏になる。秋雨前線はこの逆で、9月に南下する。
答え：北上
今回：北上 ○。（正誤表の記録では不正解になっているが、原本は赤丸。記録のほうを直す）

CP (15) 天気図の季節 資料問題・季節の判定

👀 まず見るところ

【資料問題】部品は正体「日本付近の天気図・hPa」と、図の中の「高1030（西・大陸側）」「低968（東・海上）」。西に高・東に低＝西高東低と1行書く → 冬型と決まる。

📚 前提知識

  • 冬はシベリア気団が発達して大陸に強い高気圧、東の海上に発達した低気圧ができる西高東低の気圧配置。等圧線が南北にせまく並び、北西の季節風が強く吹く。
  • 夏は南の海上に太平洋高気圧（南高北低）、春・秋は移動性高気圧と低気圧が交互に通る。

🔍 こう読み解く

  1. 左（西）に「高 1030」、右（東）に「低 968」。気圧の差が大きく、等圧線が日本の上でたて（南北）にせまく並んでいる。
  2. 西高東低＋等圧線が混んでいる → 冬。
答え：冬
今回：冬 ○。

CP (16) 気圧の単位（アルファベット3字） 知識問題

hPa（ヘクトパスカル）。hは小文字、Pは大文字、aは小文字。1気圧≒1013hPa。天気図の「1030」「968」はこの単位の数値。
答え：hPa
今回：HPC ×。知識＝つづりと大文字・小文字が固まっていない。「h小・P大・a小」と3字を1つずつ書いて覚え直す。

CP (17) 北半球の低気圧の空気の流れ 資料問題・図の選択

👀 まず見るところ

【資料問題】部品は「北半球」「低気圧」に丸 → 図の横に「中心へ吹きこむ・反時計回り」の2語を書く。矢印が内向きの図（ア・イ）にしぼり、回る向きで1つに決める。

📚 前提知識

  • 低気圧はまわりより気圧が低いので、空気は中心へ吹きこむ。北半球では地球の自転のえいきょうで右へそれるため、反時計回りにうずを巻く。
  • 高気圧は逆で、中心から時計回りに吹き出す。「低＝反時計・吹きこむ／高＝時計・吹き出す」を対にしておく。

🔍 こう読み解く

  1. ウ・エは矢印が外向き（吹き出す）→ 高気圧の形なので消す。
  2. ア・イはどちらも吹きこむ。上の矢印を見ると、アは右から回りこんで中心へ（反時計回り）、イは左から回りこむ（時計回り）→ ア。
答え：ア
今回：イ ×。知識＝回る向きが逆（吹きこむところまでは合っている）。次は図の横に「反時計回り」と書いてから、上の矢印がどちらから来るかを見る。(19)の台風の風も同じ向きで決まる。

CP (18) 広い範囲に弱い雨を降らせる雲 知識問題

乱層雲。低気圧や温暖前線が近づくと空全体をおおう厚い灰色の雲で、長い時間しとしと降る「雨雲」。せまい範囲に強い雨を短時間降らせる積乱雲（寒冷前線・夕立）と対で覚える。
答え：乱層雲
今回：らんそううん ○。

CP (19) 台風が西側を通るときのA地点の風向 条件文・図に矢印

👀 まず見るところ

【条件文】部品は「北上して」「A地点の西側を通過」に丸。台風の円に反時計回りの矢印を描き、前後の図でAが中心のどちら側かを書く（図に置く）→ Aのそばの矢印がどちらから来るかが風向。

📚 前提知識

  • 台風は発達した熱帯低気圧。(17)と同じく、中心へ反時計回りに吹きこむ。風向は「風が吹いてくる方角」で言う。
  • 反時計回りでは、中心の北側では風は東から（東風）、東側では南から（南風）、南側では西から、西側では北から吹く。

🔍 こう読み解く

  1. 前の図：台風はAの南西にある → Aは中心の北東側。北側なら東風、東側なら南風、その間なので東寄りの風 → ①東。
  2. あとの図：台風が北上してAの真西を通る → Aは中心の東側 → ②南。東→南と、風向は時計回りに変わる。
答え：① 東　② 南
今回：南・西 ×。知識＝(17)と同じで回る向きが定まっていない。円のまわりに線は引いてあるが、反時計回りの矢印として読める形になっていない。次は円に反時計回りの矢印を4本描き、Aのいちばん近くの矢印の根もとの方角を読む。（正誤表の記録では正解になっているが、原本は赤斜線。記録のほうを直す）
コツ：台風が自分の西側を通ると 東→南→西 の順、東側を通ると 北→西→南 の順に風向が変わる。どちらも「台風がどちら側か」を図に書いてから。

CP (20) 台風の中心付近の風速 知識問題

ア（17.2m/秒）。熱帯低気圧のうち、中心付近の最大風速が17.2m/秒以上になったものを台風とよぶ。単位は「m/秒」。イ・ウ・エは数字は同じでも単位がちがう（km/秒は速すぎ、m/時は歩くより遅い）。
答え：ア
今回：ア ○。

CP まとめ 75／100点（×5問）

  • 取れた15問：装置の角度・気温グラフ・湿度の計算・海風の実験・前線の記号・冬の天気図など、図や表を読む問はほぼ全部合っている。
  • 落とした5問は3種類。(7)は表に「12.3」を書きこんでから入りきらない側を選ぶ／(12)(16)は名前の書き方（オホーツク「海」まで・hPa）／(17)(19)は低気圧＝反時計回りに吹きこむを図に描いてから読む。
  • 覚え直しはこの3つ：露点＝飽和水蒸気量が水蒸気量を下回り始める温度／オホーツク海気団・小笠原気団・hPa／北半球の低気圧・台風は反時計回りに吹きこむ（高気圧は時計回りに吹き出す）。
