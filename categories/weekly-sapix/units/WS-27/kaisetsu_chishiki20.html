WS-27 知識の20題（電磁石・てこ・滑車・中和・生物・天体・地学 20問）

K20 全体像 知識の20題 20問（各5点・100点）

電磁石（1・2）、さおばかり（3・4）、滑車（5・6）、ふりこ（7）、中和の表（8・9）、水溶液（10）、葉の断面（11・12）、昆虫（13・14）、消化（15）、日食（16・17）、北の空（18・19）、河岸段丘（20）の寄せ集め。計算は 3・4・6・8・9 の5問だけで、使う式はどれも1行（てこ＝重さ×うでの長さ／中和＝表の増え方の比）。残り15問は図を1か所見るか、知っていれば決まる。

解く前に、設問の「すべて答えなさい」「答え方の例」に丸をつけておく。1・2・15・16・17 は複数答える問題で、1つで止めると落とす。

K20 (1) コイルのまわりの方位磁針 条件文・図・すべて選ぶ

👀 まず見るところ

【条件文】部品は「N極が右を向くもの」と「すべて」に丸。まず電池の向きからコイルの右はしがN極と決めて、図1のコイルの両はしにN・Sを書きこむ（図に置く）→ 磁力線の向きが①〜⑤の答えになる。

📚 前提知識

  • 方位磁針のN極は、その場所の磁力線の向きを指す（解答冊子）。磁力線はコイルの外ではN極から出てS極にもどり、コイルの中ではS極からN極へ向かう。

🔍 こう読み解く

  1. コイルの中（③）は S→N の向き＝右向き。
  2. 両はしの外（①・⑤）も、N極から右へ出る線・左からS極へ入る線なので右向き。
  3. 上（②）と下（④）は、N極から出た線がぐるりと回ってS極へもどる途中＝左向き。右を向くのは ①・③・⑤。
答え：①・③・⑤
コツ：コイルの上下は中と逆向き、両はしの外は中と同じ向き。この2行を図のわきに書けば、磁力線を全部描かなくても決まる。

K20 (2) 電磁石の鉄心にむく鉄 知識問題

イ・エ（焼きなました鋼・軟鉄の棒）。鉄心は電流が流れているときだけ磁石になり、切ればもとの鉄にもどる必要がある（解答冊子）。鉄くぎのような鋼は一度磁化すると磁石のまま残るので不向き、銅はそもそも磁石につかない。「すべて」なので2つ答える。
答え：イ・エ

K20 (3) さおばかり・10gのせたら分銅は何cm 条件文・計算

👀 まず見るところ

【条件文】部品は「皿に10gの物体をのせた」（変わったのはこれだけ）と、答え方「さげひもから右に何cm」に丸。図2の皿の下に「+10g」、支点から皿まで「10cm」を書きこむ（図に置く）→ 増えた左回りの力だけで式が立つ。

📚 前提知識

  • てこのつり合い＝重さ×支点からの距離 が左右で等しい。もともとつり合っている図なら、増えた分だけを考えればよい（解答冊子）。

🔍 こう読み解く

  1. 左に増えた回転力：10g×10cm＝100。
  2. これを100gの分銅で右に増やす：100÷100g＝1cm 右へ。
  3. 分銅はもともと2cmの位置なので、2＋1＝3cm。
答え：3cm
コツ：「何cm動かす」でなく「右に何cm離れた所」と聞いている。1cmで止めず、答えを書く直前に丸を見直す。

K20 (4) さげひもにかかる力 条件文・計算

👀 まず見るところ

【条件文】部品は「一様な太さの棒」と「図2のとき」（10gはのせていない）に丸。棒の重さは書かれていないので、棒のまん中（支点から右に5cm）に矢印を1本足し（直して書く）→ つり合いの式から棒の重さを出す。

📚 前提知識

  • 一様な棒の重さは、まん中に全部かかっているとみなす。棒は10＋20＝30cmなので、まん中は左はしから15cm＝支点から右に5cm。
  • さげひもにかかる力＝ぶら下がっているもの全部の重さの合計。

🔍 こう読み解く

  1. 左回り：60g×10cm＝600。右回り：100g×2cm＋棒×5cm＝600 → 棒×5＝400 → 棒＝80g（解答冊子）。
  2. さげひも＝60＋100＋80＝240g。
答え：240g
コツ：「一様な太さの棒」は「棒に重さがある」の合図。図に矢印が無いまま足し算すると160gになる。

K20 (5) 滑車3個・滑車に重さがないとき 条件文・計算

👀 まず見るところ

【条件文】部品は「滑車に重さがない」と「A 800g」に丸。図3で、天井につながっている滑車は動かない（定滑車）、おもりといっしょに下がる2個が動滑車と書きこむ（図に置く）→ 下から順に半分にしていく。

📚 前提知識

  • 動滑車は1つごとに、ひもを引く力が半分になる（解答冊子）。定滑車は力の向きを変えるだけで大きさは変えない。

🔍 こう読み解く

  1. いちばん下の動滑車：800g を2本のひもで支える → 1本 400g。
  2. そのひもが真ん中の動滑車の軸を引く（400g）→ また2本で支えて 1本 200g。
  3. 上の定滑車は向きを変えるだけ → B＝200g。
答え：200g

K20 (6) 滑車1つの重さ 条件文・計算

👀 まず見るところ

【条件文】部品は(5)と変わった「滑車に重さがある」「Bが236g」に丸。236−200＝36g の差が滑車の重さの分、と直して書く → 滑車1個の重さの何倍がBに届くかを(5)と同じ手順でたどる。

📚 前提知識

  • 動滑車の重さも、おもりと同じようにひも2本で半分ずつ支えられる。定滑車の重さは天井が支えるのでBには関係ない。

🔍 こう読み解く

  1. 滑車1個を□gとする。下の動滑車：（800＋□）÷2 ＝ 400＋□/2。
  2. 真ん中の動滑車の軸にかかる重さ：400＋□/2＋□ → ひも1本は（400＋3/2□）÷2 ＝ 200＋3/4□。
  3. 200＋3/4□＝236 → 3/4□＝36 → □＝36÷3/4＝48g（解答冊子）。
答え：48g
コツ：(5)の答え200gが「滑車なし」の分。(6)は差の36gだけを滑車の分として考えると式が短い。

K20 (7) ふりこ・木片の動く距離 資料問題・並べかえ

👀 まず見るところ

【資料問題】図の正体は「おもりの重さ（30g/60g）」と「はなす高さ（点線の高さと比べる）」の2つ。ひもの長さ30cm/45cmはひっかけで、聞かれ方「大きい順」「ア＞イ＝ウ の形」に線を引く。

📚 前提知識

  • 木片を動かす大きさは、おもりが重いほど・高い位置からはなすほど大きい（解答冊子）。ひもの長さは往復の時間を変えるだけで、ぶつかる速さには関係ない。

🔍 こう読み解く

  1. 横の点線より上にあるのはウだけ、下にあるのはオだけ。ア・イ・エは点線の高さ。
  2. 60g はイ・ウ、30g はア・エ・オ。重くて高いウが1位、重いイが2位。
  3. 30g で同じ高さのア＝エ、30g で低いオが最下位 → ウ＞イ＞ア＝エ＞オ。
答え：ウ＞イ＞ア＝エ＞オ
コツ：高さは「ひもの長さ」でなく「おもりの位置が点線より上か下か」で見る。45cmにつられてエ・オを上にしない。

K20 (8) 水酸化ナトリウム水溶液の濃さ まざり型・表の読み取り＋計算

👀 まず見るところ

【まざり型→資料問題】表の正体は「塩酸を15cm³ふやすごとに残る固体」。左から +0.3、+0.3、+0.3、+0.2、0、0 と増え方を表の下に書く（直して書く）→ 塩酸0のときの固体＝水酸化ナトリウムの重さが逆算できる。「1cm³あたり1g」は60cm³＝60gに直して置く。

📚 前提知識

  • 水酸化ナトリウムが余っている間は、塩酸をふやすたびに同じ量ずつ固体（食塩）が増える。塩酸が0のとき残る固体は水酸化ナトリウムそのもの。
  • 濃さ(%)＝とけているものの重さ÷水溶液全体の重さ×100。

🔍 こう読み解く

  1. 15cm³のとき3.3g、増え方は0.3gずつ → 塩酸0のとき 3.3−0.3＝3.0g。
  2. 水溶液60cm³＝60g。3.0÷60×100＝5%（解答冊子）。
答え：5%

K20 (9) ちょうど中和する塩酸の体積 資料問題・計算

👀 まず見るところ

【資料問題】部品は(8)で書いた増え方の列のうち、+0.3 が +0.2 に変わる所（60→75cm³）。「0.3増えるはずが0.2しか増えていない＝途中で中和が終わった」と直して書く → 60cm³と75cm³の間のどこかが答え。

📚 前提知識

  • 中和が終わったあとは塩酸をふやしても固体は増えない（4.4gで一定）。途中で終わった区間は、増えた量の割合でその区間を分ける。

🔍 こう読み解く

  1. 60→75の15cm³で、本来0.3g増えるところが0.2g → 中和に使われたのは 15×0.2/0.3＝10cm³ 分。
  2. 60＋10＝70cm³（解答冊子）。
答え：70cm³
コツ：「増え方がくずれた区間」を見つけたら、その区間だけ比で分ける。4.4gになった75cm³を答えにしない。

K20 (10) 硫酸銅水溶液だけに当てはまること 知識問題

有色である。硫酸銅水溶液は青色透明で、ホウ酸水・塩酸・砂糖水・アンモニア水はすべて無色透明（解答冊子）。酸性・アルカリ性やにおいでは1つにしぼれないので、「色」で答える。
答え：有色である（青色をしている）

K20 (11) 葉の断面図・表側はどちら 資料問題・図

👀 まず見るところ

【資料問題】図4の正体は「葉を横に切った断面」。細長い細胞がすき間なく縦に並んでいる側（アのある左）に「さく状組織」と書く（正体を1行）→ さく状組織のある側が表。

📚 前提知識

  • 表側にさく状組織（細胞が密にぎっしり）があるのは、光をむだなく受けて光合成するため（解答冊子）。裏側は細胞がまばらな海綿状組織で、気孔が多い。

🔍 こう読み解く

  1. 左の列は細胞が細長くびっしり → さく状組織 → 左が表側。
  2. 右側は丸い細胞がまばら → 海綿状組織＝裏側、で確かめる。
答え：左

K20 (12) 根から吸った水が通る管 資料問題・図

👀 まず見るところ

【資料問題】部品は(11)で決めた「左＝表」と、設問の「根から吸収した水」（＝道管）に丸。葉脈（まん中の丸い束）の表側半分が道管と図に書く（図に置く）→ 束の左側を指す記号を選ぶ。

📚 前提知識

  • 葉脈では道管が表側、師管が裏側（解答冊子）。茎の維管束で道管が内側・師管が外側になるのと同じ並びが、葉では上下になる。

🔍 こう読み解く

  1. 束の左半分（表側）を指しているのはオ。右半分を指すエは師管。
  2. ア（左のさく状組織の細胞）・イ・ウ（右の海綿状組織の細胞）は管ではないので消える。
答え：オ
コツ：(11)と(12)はセット。表が決まらないまま(12)を見ると、エとオで迷う。

K20 (13) 刺して吸う口を持つ昆虫 知識問題

ウ（ツクツクボウシ・アカイエカ）。セミとカは針のような口で刺して吸う。チョウ・ガは刺さずに吸う口、ハエはなめる口、バッタ・キリギリス・スズメバチはかむ口、ミツバチはなめて吸う口（解答冊子）。カイコガの成虫は口が退化して何も食べない。
答え：ウ

K20 (14) 成虫も幼虫も同じものを食べる昆虫 知識問題

イ（ナナホシテントウ・カマキリ）。テントウムシはどちらもアブラムシ、カマキリはどちらも他の虫（解答冊子）。ウはゲンゴロウだけ同じ（水中の生き物）でカブトムシは幼虫が腐葉土・成虫が樹液、エはトノサマバッタだけ同じ（イネ科の葉）でモンシロチョウは幼虫がアブラナ科の葉・成虫が花のみつ。「組み合わせ」なので2匹とも当てはまる選択肢を選ぶ。
答え：イ

K20 (15) 小腸から毛細血管に入る栄養素 知識問題

ア・エ（ブドウ糖・アミノ酸）。消化しきった形のうち、水にとけやすいブドウ糖とアミノ酸は毛細血管へ、油の仲間の脂肪酸とモノグリセリドはリンパ管へ入る（解答冊子）。ペプトン・麦芽糖は消化の途中の形で、まだ吸収されない。
答え：ア・エ

K20 (16) 皆既日食が起こっている地点 資料問題・図・すべて選ぶ

👀 まず見るところ

【資料問題】図5の正体は「太陽の両はしから月の両はしを通る4本の線」。月のうしろで線が交わってできる細い三角のかげ＝本影、その外の広いかげ＝半影 と書きこむ（正体を1行）。聞かれ方「皆既」「すべて」に線。

📚 前提知識

  • 本影（太陽が月に全部かくれる場所）に入ると皆既日食、半影なら部分日食（解答冊子）。本影は月から遠ざかるほど細くなり、先がとがる。

🔍 こう読み解く

  1. 地球Ⅰ（月が近い）では、本影の三角が地表に届いている → その中のイが皆既。
  2. 地球Ⅱ（月が遠い）では、本影の先が地表の手前でとがり切ってしまう → オは本影の外（(17)参照）。皆既はイだけ。
答え：イ

K20 (17) 部分日食が起こっている地点 資料問題・図・すべて選ぶ

👀 まず見るところ

【資料問題】部品は(16)で書いた「半影」の範囲と、聞かれ方「部分」「すべて」。本影の外側で、外側の2本の線の内側にある点を全部拾う → 地球Ⅰ・Ⅱの両方を見る。

📚 前提知識

  • 半影では太陽の一部だけが月にかくれて部分日食。本影の先より遠い所では、月が太陽より小さく見えて金環日食（解答冊子）。

🔍 こう読み解く

  1. 地球Ⅰ：本影のイをはさんだウが半影の中。アは外側の線より外なので日食なし。
  2. 地球Ⅱ：エが半影の中。オは本影の先の延長上で金環日食、カは外側の線より外。
  3. 部分日食はウ・エ。
答え：ウ・エ
コツ：イ＝皆既／ウ・エ＝部分／オ＝金環 を図の横に3語で書くと、(16)(17)が同時に片づく。

K20 (18) 午後8時に北斗七星が北極星の真上に見える月 知識問題

ウ（5月）。北斗七星は春の宵に北の空の高い所にのぼり、5月5日ごろの午後8時に北極星の真上にくる（解答冊子）。11月の同じ時刻にはその反対で、北極星の真下（地平線近く）にある。
答え：ウ

K20 (19) そのときのカシオペヤ座の向き 条件文・図

👀 まず見るところ

【条件文】部品は「(18)のとき」＝北斗七星が北極星の真上。余白に北極星を1点打ち、真上に北斗七星、そこから左まわりに約150度の所にカシオペヤ座を置く（図に置く）→ 北極星の左下・低い位置にある形を選ぶ。

📚 前提知識

  • 北斗七星とカシオペヤ座は北極星をはさんでほぼ反対側（左まわりに約150度・解答冊子）。北の星は北極星を中心に左まわりに回るので、位置が決まれば向きも決まる。
  • カシオペヤ座のWのまん中の星が北極星の側を向く。北極星より下にあるときはWが上を向いた形に近い。

🔍 こう読み解く

  1. 北斗七星が真上なら、カシオペヤ座は北極星の左下、地平線に近い所。
  2. そこからWのまん中の星が北極星（右上）を向くようにかたむけた形がオ（解答冊子の図と同じ向き）。
答え：オ

K20 (20) 河岸段丘の段ができた順 資料問題・図・並べかえ

👀 まず見るところ

【資料問題】図6の正体は「川の両側の階段状の地形の断面」。各段の高さを比べて、A・B・C・Dの横に「高い・中・低い」を書く（正体を1行）。聞かれ方「できた順」「E・F・G＝H の形」に線。

📚 前提知識

  • 河岸段丘は、川が土地を少しずつけずり下げてできる。だから高い段ほど古く、低い段ほど新しい（解答冊子）。

🔍 こう読み解く

  1. いちばん高いのはA → 最初にできた。
  2. BとDは同じ高さ → 同じころ（＝で結ぶ）。川のすぐわきのCがいちばん低く、いちばん新しい。
  3. 古い順に A・B＝D・C。
答え：A・B＝D・C
コツ：川をはさんで左右に分かれていても、見るのは高さだけ。同じ高さの段は「＝」で結ぶ。

K20 まとめ 解く前のチェック

  • 計算5問（3・4・6・8・9）は式を余白に書いてから：てこ＝重さ×うでの長さ（棒の重さはまん中に矢印）／滑車＝動滑車1つで半分／中和＝増え方がくずれた区間を比で分ける。
  • 図の問題（1・7・11・12・16・17・20）は、見る所を1つに決める：コイルのN・S／おもりの高さと重さ／さく状組織の側／本影と半影／段の高さ。
  • 「すべて」「組み合わせ」の問題（1・2・13〜17）は、1つ見つけても残りを全部確かめてから書く。
