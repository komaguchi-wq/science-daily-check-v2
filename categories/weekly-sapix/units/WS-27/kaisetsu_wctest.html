WC (1)①ア 周期は糸の長さに関係がある 資料問題・表から2つ選ぶ

👀 まず見るところ

【資料問題】部品は表1の正体「重さ・長さ・振れ幅を変えて周期を調べた7回」を1行と、設問の「糸の長さに関係がある」に線。確かめたいのが長さなら、長さ以外（重さ・振れ幅）が同じで長さだけちがう2行をさがす、と決まる。

📚 前提知識

  • 実験で「○○が関係するか」を確かめるときは、○○だけを変えて、ほかの条件はそろえる（対照実験）。2つ以上ちがうと、どちらのせいか分からない。

🔍 こう読み解く

  1. 重さ20g・振れ幅20cmがそろっている行を表1から拾う → B（25cm・1.0秒）とD（50cm・1.4秒）。
  2. 長さだけちがって周期が変わっている → B・D。E（10g）とF（30g）は重さがちがうので不可。
答え：B・D
今回：B・D ○。表1の長さと周期に鉛筆で丸がついていて、「1つだけちがう行」を探せている。

WC (1)①イ 振れ幅がちがっても周期は同じ 資料問題・表から2つ選ぶ

🔍 こう読み解く

WC (1)② 表1から分かるもう1つの性質 資料問題・1文で書く

👀 まず見るところ

【資料問題】部品は設問の「ア・イの性質以外で」に線 → 表1の3つの条件（重さ・長さ・振れ幅）のうち、まだ使っていないのはおもりの重さ。重さだけちがう2行の周期を見れば、書くことが決まる。

📚 前提知識

  • ふりこの周期はおもりの重さに関係しない。重いおもりは引く力も大きいが、動かしにくさも同じだけ大きいので、速さは変わらない。

🔍 こう読み解く

  1. 長さ100cm・振れ幅20cmがそろう行 → E（10g・2.0秒）とF（30g・2.0秒）。
  2. 重さが3倍になっても周期は同じ → 「おもりの重さがちがっても周期は同じ」と1文にする。
答え：おもりの重さが違っても「ふりこ」の周期は同じになる。
今回：「ふりこの周期におもりの重さは関係ない」○。言い方はちがうが、重さと周期の関係を正しく書いている。

WC (1)③ 0.5秒で1往復するふりこの長さ 条件文・比例の計算

👀 まず見るところ

【条件文】部品は「0.5秒間に1往復」→ 周期0.5秒に直して書く。表1でいちばん近いのはA（25cm・1.0秒）。周期を半分にするには長さを何倍にするか、を表1の中から見つける。

📚 前提知識

  • 糸の長さを4倍にすると周期は2倍（表1：25cm→1.0秒、100cm→2.0秒）。2倍なら約1.4倍（50cm→1.4秒、200cm→2.8秒）。逆に周期を半分にしたいなら長さは4分の1。

🔍 こう読み解く

  1. 表1：長さ25cm → 100cm（4倍）で周期1.0 → 2.0秒（2倍）。だから「周期半分＝長さ4分の1」。
  2. 1.0秒の25cmを4で割る → 25÷4＝6.25cm → 選択肢の6.3cm。
  3. 検算：ウ12.5cmは25cmの半分なので周期は1.0÷1.4＝約0.7秒、イ8.4cmでも0.6秒くらい。0.5秒には届かない。
答え：ア
今回：ア ○。

WC (1)④ 針が進みすぎるふりこ時計 条件文・向きの判断

👀 まず見るところ

【条件文】部品は「針が進みすぎる」→「1往復が速い＝周期が短すぎる」に直して書く。周期を長くするには糸を長くする、と決まる。選択肢の重さ（ウ・エ）は①②で「関係ない」と確かめたので先に消す。

📚 前提知識

  • ふりこ時計は、ふりこが1往復するごとに針を一定だけ進める。周期が短いと進みすぎ、長いとおくれる。
  • おもりの位置を下げる＝ふりこの長さ（支点からおもりの中心まで）が長くなる → 周期が長くなる。

🔍 こう読み解く

  1. 進みすぎ → 周期を長くしたい → 長さを長くする。
  2. 長さを長くするのは「おもりの位置を下げる」→ イ。アは逆（短くなる）、ウ・エは周期に関係しない。
答え：イ
今回：イ ○。
コツ：「進む＝周期が短い＝長くする（下げる）」「おくれる＝周期が長い＝短くする（上げる）」を1組で置いておく。

WC (1)⑤ 400cm・800cmのふりこの周期 資料問題・比例の計算

👀 まず見るところ

【資料問題】部品は表2の「400cm」「800cm」を、表1の100cm（2.0秒）の4倍と8倍に直して書く。4倍→周期2倍、さらに2倍→1.4倍、と表1の決まりを2回使えば決まる。

📚 前提知識

  • 長さ4倍で周期2倍、長さ2倍で周期約1.4倍（表1の中にある数字で確かめられる）。

🔍 こう読み解く

  1. H：400cmは100cm（2.0秒）の4倍 → 周期は2倍 → 2.0×2＝4.0秒＝ウ。
  2. I：800cmは400cmの2倍 → 周期は1.4倍 → 4.0×1.4＝5.6秒＝オ。
  3. 別の道：800cmは200cm（2.8秒）の4倍 → 2.8×2＝5.6秒。同じになるので安心して書ける。
答え：H ウ　I オ
今回：H ウ　I オ ○。

WC (2)① 支点・力点・作用点の順番が同じ道具 資料問題・2つ選ぶ

👀 まず見るところ

【資料問題】部品は設問の「順番が同じもの」「2つ選び」に線。4つの絵それぞれに支・力・作の3文字を書きこむ（図に置く）→ 文字の並びが同じ2つが答え。頭の中で比べない。

📚 前提知識

  • てこの3つの型：支点がまん中（はさみ・バール・くぎぬき・ペンチ）／作用点がまん中（空き缶つぶし機・せんぬき・くるみ割り）／力点がまん中（ピンセット・トング・和ばさみ）。
  • 支点＝動かない所、力点＝手で力を加える所、作用点＝物に力がはたらく所。絵では「どこが固定されているか」を先に見つける。

🔍 こう読み解く

  1. ア 空き缶つぶし機：ちょうつがいが支点、缶が作用点、手は先たん → 支・作・力。
  2. イ はさみ：ねじが支点、持ち手が力点、刃が作用点 → 力・支・作。
  3. ウ ピンセット：つながった根もとが支点、指でつまむ所が力点、先が作用点 → 支・力・作。
  4. エ バール：床についている曲がり角が支点、くぎが作用点、持ち手が力点 → 力・支・作。イと同じ並び。
答え：イ・エ
今回：ア・エ ×（紙面のイに消す印をつけている）。知識＝はさみの支点はねじの所で「まん中」。はさみは身近すぎて図を見ずに判断した形。次は4つの絵全部に支・力・作を書いてから選ぶ。

WC (2)② 右側に1個でつり合わせる 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「真ん中から左右に等間隔で4つずつ」と「左側の2の穴に20g」。穴の番号を支点からの距離に直して図1に書く（左 4・3・2・1｜右 1・2・3・4）→ 左は20×3＝60。右も60になる1個をさがす。

📚 前提知識

  • てこのつり合い：支点の左右で「おもりの重さ×支点からの距離」が等しい。棒は太さが一様でまん中を支えているので、棒の重さは考えなくてよい。

🔍 こう読み解く

  1. 左：2の穴は支点から3つ目 → 20×3＝60。
  2. 右を60にする：20gなら距離3＝7の穴。30gなら距離2＝6の穴。10gなら距離6が必要で、穴は4までしかないので不可。
  3. 答えは「20gを7」と「30gを6」の2通り。
答え：20gを7・30gを6
今回：20gを7・30gを6 ○。図1の下に20・60と書いて左のモーメント60を出してから、右を決められている。

WC (2)③ 右側に2個でつり合わせる 条件文・てこの計算

👀 まず見るところ

【条件文】②と変わった部品は「2個」と「1つの穴に2個以上はできない」に丸。左の60はそのまま。右の2個は「重さ×距離」の合計が60で、距離がちがう組み合わせ、と直して書く。

📚 前提知識

  • 同じ側に2個あるときは、1個ずつの「重さ×距離」を足したものが、その側の回すはたらきになる。

🔍 こう読み解く

  1. 右の距離は1〜4（5の穴＝1、6＝2、7＝3、8＝4）。2個の組は 10と20／10と30／20と30 の3通り。
  2. 10と20：20gを距離1（5の穴）＝20 → 残り40を10gで → 距離4（8の穴）。10gを8と20gを5。20gを距離2にすると10gも距離2で同じ穴になり不可。
  3. 10と30：30gを距離1（5の穴）＝30 → 残り30を10gで → 距離3（7の穴）。10gを7と30gを5。
  4. 20と30：30を距離1にしても残り30は20gで割り切れず、距離2なら60で10gの出番がない → 不可。だから答えは上の2通り。
答え：10gを8と20gを5・10gを7と30gを5
今回：30gを1と20gを6／10gを4と20gを6 ×。部品の形を直さなかった＝「1」「4」は穴の番号なら左側になり、距離として読んでも20gの「6」（穴の番号）と混ざっている。余白の80（10gを距離4、20gを距離2としたときの合計とみられる）が60に合っていない。次は右の穴の下に1・2・3・4の距離を先に書き、合計60を確かめてから書く。

WC (2)④ バケツをつるした棒を両手で支える 条件文・力の向きと大きさ

👀 まず見るところ

【条件文】部品は「棒の端にバケツ」と「両手で」。図2で、バケツに近い方の手（右手）を支点と決めて図に「支」と書く → バケツが下に引くので、反対側の左手は下向きにおさえ、支点の右手が全部を受けて上向き、と決まる。

📚 前提知識

  • 棒の端に重い物があり、手が2つあるとき、重い物に近い手が支点になる。支点は棒を支える側なので上向きの力。
  • 支点にかかる力＝両側で下に引く力の合計。だから支点の手の力が、もう一方の手より大きい。

🔍 こう読み解く

  1. 図2：バケツは棒の左端、右手がバケツ寄り、左手が体の近く。右手を支点にすると、バケツの重さで棒の右側（左手側）が上がろうとする。
  2. それを止める左手は下向きにおさえる。右手は棒を支えるので上向き。
  3. 右手の力＝バケツの重さ＋左手でおさえる力 → 右手の方が大きい。
答え：右手が 上 向きの力、左手が 下 向きの力で、右 手の方が大きい力を加えている。
今回：上／下／「下」×。向きの2つは合っていて、大きさの1つで落とした（3つ目のらんは手の名前でなく「下」と書いている）。知識＝支点の手にはバケツと左手の両方の力がかかる、が置けていない。右手の下に「バケツ＋左手」と書けば大きい方が決まる。

WC まとめ 70／100点

  • (1)ふりこは5問全部○。「1つだけちがう2行をくらべる」と「長さ4倍で周期2倍」が身についている。
