(1)〜(15)は光。色の重なり、プリズム、明るさと距離、屈折・全反射、ピンホールカメラ、虹、そして鏡（うつる高さ・回転・見える人・2枚の鏡）。(16)〜(20)は音で、波形の読み方と音の速さの計算。図のある問題は、決まりを1行書いてから図に線を引くと決まる。

今回は50／100点。落とした10問は (4)(5)(7)(8)(11)(12)(14)(15)(16)(20)。(4)(15)(20)は図や式を描く前に答えた形、(11)(12)は図は描いたのに決まり（頭と目のまん中／回した角度の2倍）を置けなかった形、(5)(7)(8)(16)は決まりの知識、(14)は鏡の端の見落とし。

CP (1) 3色の光の重なり 資料問題・色

👀 まず見るところ

【資料問題】部品は資料の正体「赤・青・緑の3色の光」と、Aが「3つの円が全部重なる所」、Bが赤と青だけの所、を図に○で置く → 光は重ねるほど明るくなり、3色全部で白と決まる。

📚 前提知識

  • 光の3原色（赤・緑・青）は重ねると明るくなり、3色全部で白。2色ずつは 赤＋緑＝黄、緑＋青＝水色、赤＋青＝赤紫。
  • 図1に書いてある「黄」「水色」が、この決まりの答え合わせになる。

🔍 こう読み解く

  1. A＝赤・緑・青が全部重なる中心 → 白。
  2. B＝赤の円と青の円だけが重なる所。黄（赤＋緑）・水色（緑＋青）はもう名前があるので、残った組 赤＋青＝赤紫。
答え：A 白　B 赤紫
今回：A 白　B 赤紫 ○。

CP (2) 黄色い紙を緑のシートごしに見る 知識問題

緑。黄色い紙は赤と緑の光を反射している（黄＝赤＋緑）。色のシートは同じ色の光だけを通すので、目に届くのは緑だけ。赤いシートなら赤に見え、青いシートなら黄の中に青がないので黒く見える、と3つをセットで。
答え：緑
今回：緑 ○。

CP (3) プリズムで分かれた7色の端 資料問題・空らん

👀 まず見るところ

【資料問題】部品は図2の「Aが上・Bが下」と、光が「プリズムで折れ曲がった向き」（入ってきた右下がりより上へ起き上がっている）を矢印で図に置く → いちばん大きく曲がる色が、折れた側＝Aに来る。

📚 前提知識

  • プリズムは光を厚い側へ曲げる。曲がり方は色で違い、赤が小さく、紫が大きい。だから白色光が7色に分かれる。
  • 紫のさらに外側（もっと曲がった所）には目に見えない紫外線、赤の外側には赤外線が当たっている。

🔍 こう読み解く

  1. スリットからの光は右下がりに進み、プリズムを出てつい立てへ向かう線はそれより上へ起き上がっている。図2は光が通る2つの面にはさまれたとがった角が下、厚い側が上なので、折れ曲がった側は上＝A。
  2. いちばん曲がる紫がA、曲がりにくい赤がB。①は紫。
  3. 紫のすぐ外側 → ②は紫外線。
答え：① 紫　② 紫外線
今回：① 紫　② 紫外線 ○。

CP (4) つい立てを遠ざけたときの明るさ 条件文・計算

👀 まず見るところ

【条件文】部品は「点光源から20cm」と「40cmのところ」に丸。どちらも点光源からの距離。「明るさは距離の2乗に反比例」に直して書く → 距離2倍で面積4倍、明るさ1/4。Aの10cmは式に入らない。

📚 前提知識

  • 穴を通りぬける光の量は決まっている。つい立てBを遠ざけると、同じ量の光が広い面に散らばるので暗くなる。
  • 光の当たる面のたて・横は点光源からの距離に比例するので、面積は距離の2乗に比例 → 明るさは距離の2乗に反比例。

🔍 こう読み解く

  1. 40÷20＝2 → 距離が2倍。光の当たる面は たて2倍×横2倍＝4倍の広さ。
  2. 同じ光が4倍の面に広がるので、40cmのときの明るさは20cmのときの1/4。
  3. 聞かれているのは「20cmのときは40cmのときの何倍」→ 4倍。
答え：4倍
今回：25/4 ×（余白に 5・9・4/25）。部品を拾えなかった＝「点光源から」の2つの距離（20と40）でなく、別の長さの組で比をとっている。2つの距離に丸をつけ、「(40÷20)²」と式を先に書く。

CP (5) 空が青く、朝夕が赤い理由 知識問題

散乱。空気中の小さな粒に当たった光は四方に散らばる。青い光ほど散乱しやすいので、昼は散らばった青が空じゅうから届き、朝夕は光が空気の中を長く通るうちに青が散らされてしまい、残った赤が届く。漢字は「散らばって乱れる」で散乱。
答え：散乱
今回：散乱 ×。「乱」の字形がくずれて「故」のように見える。知識＝漢字の形。「乱」は舌＋乚（右にかぎ）と確かめて書く。

CP (6) 空気→水、水→空気の屈折 資料問題・記号

👀 まず見るところ

【資料問題】部品は図4の光の向き「A＝空気から水へ」「B＝水から空気へ」を矢印で確かめる。決まり「水に入る→法線に近づく／水から出る→法線から遠ざかる」に直して書く → まっすぐ進む線（ウ）より法線側か外側かで決まる。

📚 前提知識

  • 光は空気と水の境目で折れ曲がる（屈折）。空気→水は法線（面に垂直な点線）に近づく向き、水→空気は法線から遠ざかる向き。
  • 曲がり方は「そのまままっすぐ進んだときの線」と比べると見やすい。図4ではどちらもウがその線。

🔍 こう読み解く

  1. A：まっすぐ進む線はウ。水に入るので法線（ア）に近づく → ウとアの間のイ。エは逆に遠ざかっているので×。
  2. B：まっすぐ進む線はウ。水から空気へ出るので法線（ア）から遠ざかる → ウより外側のエ。
答え：A イ　B エ
今回：A イ　B エ ○。

CP (7) 水から出られなくなる角度 知識問題

① 大き（く） ② 全反射。水→空気では光は法線から遠ざかる向きに折れる（(6)のB）。入射角Pを大きくしていくと屈折した光が水面すれすれになり、それより大きいと光は空気へ出られず全部水の中へ反射する。これが全反射で、光ファイバーはこの性質を使う。
答え：① 大き　② 全反射
今回：空らん ×。知識＝(6)のBの続きとして「角度を大きく → 出られなくなる＝全反射」を1組で覚える。

CP (8) 平行なガラス板と三角プリズム 資料問題・記号

👀 まず見るところ

【資料問題】部品はガラスの形「A＝向かい合う面が平行な板」「B＝下ほど厚い三角」を正体として1行。決まり「平行な板→入った向きと平行に出る／三角→厚い側へ曲がる」に直して書く → Aは横向きのまま、Bは下向き。

📚 前提知識

  • 平行なガラス板では、入るときと出るときの折れ曲がりが打ち消し合い、光は少し横にずれるだけで元と平行に進む。
  • 三角プリズムでは2回の屈折が同じ向きに重なり、光は底（厚い側）へ曲がる。(3)の図2と同じ決まり。

🔍 こう読み解く

  1. A：平行な板 → 出てくる光は入ってきた光（横向き）と平行 → 横向きのウ。
  2. B：右の面が垂直、左の面が斜めで下ほど厚い → 光は厚い側＝下へ曲がる → いちばん下向きのオ。
答え：A ウ　B オ
今回：A エ　B オ ×（Aが誤り）。知識＝「平行な板は平行に出る」が置けていない。Aの横に「平行」と書けば、下向きのエには進まない。

CP (9) ピンホールカメラのスクリーンを遠ざける 知識問題

ア・ウ。針穴を通った光はまっすぐ進んで広がるので、スクリーンを針穴から遠ざけるほど像は大きく、暗くうつる（ウ・ア）。同じ量の光が広い面に散らばるぶん暗くなる。「遠ざける＝大きく・暗く」「近づける＝小さく・明るく」を1組で。
答え：ア・ウ
今回：ア・ウ ○。

CP (10) 虹が見えるときの日光と内側の色 知識問題

① 後ろ ② 紫。虹は、自分の後ろから差しこむ日光が前方の雨つぶの中で屈折・反射して返ってきたもの。だから太陽を背にしたときに見える。色は外側が赤、内側が紫。朝は西の空、夕方は東の空に出る、までセットで。
答え：① 後ろ　② 紫
今回：① 後ろ　② 紫 ○。

CP (11) 鏡にうつる頭のてっぺんの高さ 条件文・計算

👀 まず見るところ

【条件文】部品は「身長150cm」「目が140cm」と、聞かれ方「頭のてっぺんは鏡の何cmの高さにうつって」に丸。頭・目・鏡を図に置き、頭から出た光が鏡で折り返して目に入る線を描く → 折り返す点は頭と目のまん中の高さ。

📚 前提知識

  • 鏡では入射角＝反射角。頭のてっぺん（150cm）から出た光が目（140cm）に届くとき、鏡で反射する点は2つの高さのちょうどまん中になる。
  • 全身をうつすのに必要な鏡の長さが身長の半分、というのも同じ図から出てくる。

🔍 こう読み解く

  1. 鏡の面を縦線で描き、頭150・目140を横に書きこむ。
  2. 頭から鏡へ、鏡から目へ、同じ角度で折り返す → 反射点の高さ＝(150＋140)÷2＝145cm。
  3. 足もとが見える点は 140÷2＝70cm。145と70の間の75cmが、全身をうつすのに必要な鏡の長さ（身長の半分）。
答え：145cm
今回：70cm ×。部品の形を直さなかった＝余白に頭・目・鏡・像の図は描いているのに、線が鏡を横切る高さを読まず、「半分」の決まりで 140÷2 の70（足もとが見える高さ）を書いた。描いた図に150と140を書きこめば「頭と目のまん中＝145」が見える。

CP (12) 鏡を10度回したときの反射光 条件文・角度

👀 まず見るところ

【条件文】部品は「鏡をアの方向に10度」と、答え方の「イ・ウ」「何度ずれる」に丸。図6に、回したあとの鏡の線と法線を薄く描く（図に置く）→ 入射光はそのままなので、法線が動いた分だけ入射角が変わる。

📚 前提知識

  • 鏡を θ 度回すと法線も θ 度回る。入射角が θ 増え、反射角も θ 増えるので、反射光は 2θ 度ずれる。
  • ずれる向きは法線が動いた向きと同じ。鏡を右へ倒す（ア）と反射光も鏡に近づく側（ウ）へ動く。

🔍 こう読み解く

  1. 鏡をアの方向（右端が下がる向き）に10度 → 法線も10度右へ傾く。
  2. 入射光は変わらないので、入射角は10度大きくなり、反射角も10度大きくなる。
  3. 反射光は 法線の10度＋反射角の10度＝20度、鏡に近づく側のウへずれる。
答え：① ウ　② 20度
今回：① イ　② 10 ×。知識＝「鏡を回した角度の2倍」が置けていない。図6に回したあとの線は描いているので、次は法線も描いて10度を2回たす。

CP (13) 自分の姿が鏡に見える人 資料問題・すべて答える

👀 まず見るところ

【資料問題】部品は資料の正体「方眼・鏡は上から半マス〜4マス半の範囲」を1行と、聞かれ方「自分の姿が見える人」に線。自分を見るには、自分から鏡へ垂直に引いた線が鏡の上に当たればよい → 各人の高さの横線を鏡まで伸ばして○×。

📚 前提知識

  • 自分の像は鏡をはさんで反対側の同じ高さにできる。像と自分を結ぶ線は鏡に垂直なので、真横に鏡があれば見える。鏡の端より上や下にいる人は見えない。

🔍 こう読み解く

  1. 鏡の上端はAの行より半マス下、下端はDの行より半マス上。
  2. B（上から1マス目）・C（2マス目）は真横に鏡がある → 見える。
  3. Aは鏡の上端より上、D・Eは下端より下 → 見えない。
答え：B・C
今回：B・C ○。

CP (14) Eから鏡の中に見える人 資料問題・すべて答える

👀 まず見るところ

【資料問題】部品は聞かれ方「Eが鏡の中に見える人」に線と、置き方「A〜Dの像を鏡の反対側の同じマス数に打つ」（図に置く）。Eと像を結んだ線が鏡の上を通る人だけ見える → 4人全部に○×。

📚 前提知識

  • 鏡にうつって見える＝その人の像とEを結ぶ直線が鏡の上を通る。像は鏡から同じマス数だけ反対側。
  • 鏡の端ぎりぎりの線は、通ったか外れたかを端のマス数で確かめる。

🔍 こう読み解く

  1. 鏡は左から4マス目の線上、Eは左から3・上から6。像は A'（左から6・上から0）、B'（7・1）、C'（5・2）、D'（6・5）。
  2. E→A'：鏡の線を上から4マスの所で横切る → 鏡の上（半マス〜4マス半）→ 見える。E→C'：同じく4マス → 見える。
  3. E→B'：鏡の線を約4.7マスで横切る → 下端（4マス半）より下 → 見えない。E→D'：約5.7マス → 見えない。
答え：A・C
今回：A・B・C ×。部品を拾えなかった＝鏡の下端（4マス半）を正体に書かず、Bの像への線が鏡の下をかすめて外れているのを見のがした。線を引いたら「鏡の上を通ったか」を端で確かめる。

CP (15) 2枚の鏡の部屋から光が出る位置 資料問題・記号

👀 まず見るところ

【資料問題】部品は差しこむ光の進み方「右へ3マス・下へ2マス」を正体として1行、聞かれ方「出て行く位置」に線。反射のたびに「3マス・2マス」の組は変えず、鏡と垂直な向きだけ裏返して図に置く → 出口はマス目を数えるだけで決まる。

📚 前提知識

  • 入射角＝反射角。方眼では「横◯マス・縦◯マス」の組をそのまま使い、鏡に当たるごとに鏡と垂直な向きだけ逆にすると反射光が引ける。

🔍 こう読み解く

  1. 光は上の辺の左から6マス目の点から入り、右3・下2で進んで右の鏡の上から2マス目に当たる。
  2. 右の鏡で左右だけ裏返す → 左3・下2。右端から 左へ3・下へ2 を2回で、下の鏡の左から3マス目に当たる。
  3. 下の鏡で上下だけ裏返す → 左3・上2。左の辺の上から4マス目に出る ＝ オ。
答え：オ
今回：ア ×（図8に途中の線あり）。部品の形を直さなかった＝「右3・下2」の組を数えず、鏡からの線を目分量で引いたので角度がずれた。1本目の線のマス数を書き、それを裏返して使う。

CP (16) 波形で音の高さ・大きさを比べる 資料問題・空らん

👀 まず見るところ

【資料問題】部品は波形の正体「波の数＝高さ／たての大きさ＝音の大きさ」を1行、比べる組「AとB」「AとC」に丸。①は波の数、②はたての大きさだけを見る → 言葉を分ければ数えるだけ。

📚 前提知識

  • 同じ時間に波の数が多い（振動数が多い）ほど高い音。波のたての高さ（振幅）が大きいほど大きい音。
  • 「高い・低い」は数、「大きい・小さい」はたての高さ、と言葉を分けておく。

🔍 こう読み解く

  1. AとB：たての高さは同じで、Bの方が波の数が多い → Aの方が低い音。
  2. AとC：波の数は同じで、Cの方がたてが小さい → Aの方が大きい音。
答え：① 低　② 大き
今回：空らん ×。知識＝「波の数＝高さ／たての高さ＝大きさ」の2語が置けていない。波形の問題は、先にこの2語を余白に書いてから数える。

CP (17) 20000Hzより高い音 知識問題

超音波。ヒトに聞こえる音は約20〜20000Hz（Hz＝1秒間の振動の数）。それより振動数が多くて高すぎる音が超音波で、コウモリやイルカが使い、魚群探知機や医療の検査にも使われる。
答え：超音波
今回：ちょう音波 ○。

CP (18) 水の量とビーカーをたたいた音 知識問題

① しにくく ② 低い。水が多いほどビーカーは重くなって振動しにくく、低い音になる。水の少ないBは高い音。ふいて鳴らすときは中の空気が振動するので、水が多いほど空気が短くて高い音、と逆になることをセットで。
答え：① しにくく　② 低い
今回：① しにくく　② 低い ○。

CP (20) 岸壁に向かう船と汽笛の反射音 条件文・計算

👀 まず見るところ

【条件文】部品は「20m/秒で岸壁に向かって」「6秒後」「音の速さは(19)と同じ＝340」に丸、聞かれ方「反射音を聞いたときの位置」に線。音と船の矢印を線分図に描く（図に置く）→ 音の道のり＋船の道のり＝はじめの距離の2倍。

📚 前提知識

  • 音は岸壁まで行って返る。そのあいだに船も進むので、音の道のり＋船の道のり＝鳴らした位置から岸壁までの距離×2。
  • 聞かれているのが「鳴らしたとき」か「聞いたとき」の位置かで答えが変わる。

🔍 こう読み解く

  1. 6秒で音は 340×6＝2040m、船は 20×6＝120m。
  2. 2040＋120＝2160 がはじめの距離の2倍 → 鳴らした位置は岸壁から 1080m。
  3. 聞いたときの位置は 1080−120＝960m。
答え：960m
今回：空らん ×（余白に 360）。部品の形を直さなかった＝「向かって進む」を線分図にせず、340＋20 の数字だけで止まった。音と船の矢印を1本ずつ描くと「2つの道のりの合計＝2倍」が見える。
