K20 (1) 電流の大きさと磁力の関係を調べる組み合わせ 資料問題・対照実験

👀 まず見るところ

【資料問題】部品は図1の正体「A〜Dで変えているもの」を1行で書くこと＝巻き数（100／200）・電池の個数（1／2）・余った線（Bだけ）。聞かれ方は「電流の大きさ」→ 電池の個数だけがちがう2つを選ぶ。

📚 前提知識

  • 調べたいこと以外の条件は全部そろえる（対照実験）。電磁石の磁力は、電流の大きさ・巻き数・導線の長さでも変わる。
  • 導線が長いほど電流は流れにくい。Bの「余った線」は、巻き数を減らしても導線の長さをC・Dとそろえるための部品。

🔍 こう読み解く

  1. 電池の個数だけがちがう組を探す。AとB＝100回巻きどうしだが、Bにだけ余った線がある → 導線の長さがちがうので×。
  2. CとD＝200回巻き・導線の長さも同じ・電池だけ1個と2個 → これが答え。
答え：CとD
自分で解くときのチェック：「余った線」に丸をつけたか。これを見落とすとAとBを選んでしまう。

K20 (2) 巻き数と磁力の関係を調べる組み合わせ 資料問題・対照実験

👀 まず見るところ

【資料問題】(1)と変わった部品は聞かれ方「コイルの巻き数」に丸。巻き数だけがちがい、電池の個数も導線の長さも同じ2つを選ぶ → 余った線のあるBが候補に入る。

📚 前提知識

  • 巻き数を比べるときは、導線の長さをそろえないと「巻き数が減ったから」なのか「導線が短くなって電流が増えたから」なのか区別できない。

🔍 こう読み解く

  1. B（100回巻き＋余った線・電池2個）とD（200回巻き・電池2個）→ 導線の長さも電池も同じで、巻き数だけちがう。
  2. AとCは電池が1個どうしだが、Aに余った線がなく導線の長さがちがう → ×。
答え：BとD

K20 (3) 棒の重心の位置 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「A側を持ち上げると57g」「B側を持ち上げると33g」と、求めるもの「Aから何cm」に丸。2つの値は図2の棒の上に矢印で置く → 足した90gが棒の重さ、と直して書く。

📚 前提知識

  • 棒の両はしを片方ずつ持ち上げたときの値の合計が、棒の重さになる（解答冊子）。
  • 重心は、重さが全部かかっているとみなす1点。重心の位置は、持ち上げた値の逆比で決まる（重い方の近くに重心がある）。

🔍 こう読み解く

  1. 棒の重さ＝57＋33＝90g。これを重心に下向きの矢印で置く。
  2. Bを支点にして回転のつり合い：57×30＝90×（Bから重心まで）→ Bから19cm。
  3. Aからは 30−19＝11cm。確かめ：Aを支点にすると 33×30＝90×11＝990 で合う。
答え：11cm
自分で解くときのチェック：A側のばねばかり（57g）はA側が重い印なので、重心はAに近い側。11cmと19cmを逆に書いていないか、最後に見る。

K20 (4) おもりをつけたときのAのばねばかり 条件文・てこの計算

👀 まず見るところ

【条件文】(3)と変わった部品は「両端をばねばかりで支え」「Aから8cmに120g」に丸。120gはAから8cmに、棒の90gは(3)で出したAから11cmに、2本の下向き矢印で図に置く → Bを支点にした式が1本で書ける。

📚 前提知識

  • 両はしを支えるとき、2つのばねばかりの合計＝のっている重さの合計（120＋90＝210g）。
  • 片方の値は、もう片方を支点にした回転のつり合いで出す。

🔍 こう読み解く

  1. Bを支点にする。120gはBから22cm、90gはBから19cm。
  2. A×30＝120×22＋90×19＝2640＋1710＝4350 → A＝145g。
  3. 確かめ：B＝210−145＝65g。解答冊子の図も「57＋88＝145」「33＋32＝65」で同じ。
答え：145g
自分で解くときのチェック：「Aから8cm」をBからの長さ（22cm）に直してから式に入れたか。

K20 (5) 金属球の体積 条件文・浮力の計算

👀 まず見るところ

【条件文】部品は図3の4つの値「68g・128g・171g・86g」と、3つ目の図では金属球だけが水の中、4つ目では両方が水の中、という絵のちがい。「ただし水の密度は1g/cm³」は「浮力の数＝体積の数」に直して書く。

📚 前提知識

  • 浮力＝押しのけた水の重さ。水1cm³が1gなので、浮力（g）がそのまま水中にある部分の体積（cm³）になる。
  • つないで水に入れた値が減ったぶんが浮力。空気中の合計（68＋128）から引く。

🔍 こう読み解く

  1. 金属球だけ水の中：128＋68−171＝25gの浮力。
  2. 金属球が押しのけた水が25g → 体積は25cm³。
答え：25cm³
自分で解くときのチェック：3つ目の図は木片が水面より上。171gに木片の浮力は入っていない。

K20 (6) 木片の密度 条件文・密度の計算

👀 まず見るところ

【条件文】(5)と変わった部品は「木片の密度」に丸。密度＝重さ÷体積と余白に書く → 重さは68g、体積は171−86（木片も沈めたときに減った分＝木片の浮力）で出す。

📚 前提知識

  • 木片は水に浮く物だが、金属球とつないで沈めれば全部が水の中。減った重さがそのまま木片の浮力＝木片の体積になる。
  • 密度1より小さい物は水に浮く。0.8が出たら「浮く木」として納得できる。

🔍 こう読み解く

  1. 木片の浮力＝171−86＝85g → 木片の体積85cm³。
  2. 密度＝68÷85＝0.8g/cm³。
答え：0.8g/cm³

K20 (7) 0.1秒あたりに速くなる量 資料問題・表の計算

👀 まず見るところ

【資料問題】部品は表1の正体「直前の0.1秒で進んだ距離（cm）」の行と、聞かれ方「0.1秒あたり何cm/秒」。4・12・20・28はcmなので、cm/秒に直して書く（÷0.1）→ そのあと差をとる。

📚 前提知識

  • 速さ（cm/秒）＝進んだ距離÷かかった時間。0.1秒で進んだ距離を0.1で割る＝10倍すると、その区間の速さになる。
  • 坂を転がる球は、一定の割合で速くなる。表では「直前の0.1秒で進んだ距離」が等しい差（8cm）で増えている。

🔍 こう読み解く

  1. 直前の0.1秒で進んだ距離は 4→12→20→28 で、8cmずつ増える。
  2. 8cm÷0.1秒＝80cm/秒ずつ速くなる（各区間の速さは40・120・200・280cm/秒）。
答え：80cm/秒
自分で解くときのチェック：答えに「8」と書きそうになったら、単位がcmかcm/秒かを見直す。

K20 (8) プロパン5Lと酸素5Lを燃やしたあとの体積 条件文・燃焼の計算

👀 まず見るところ

【条件文】部品は決まり「プロパン1：酸素5：二酸化炭素3」を余白に書き出すことと、入れた量「5Lと5L」に丸。「水蒸気の体積は考えない」は、水は数えない、に直して書く → 足りない方（酸素）に合わせて反応させる。

📚 前提知識

  • 燃焼は決まった比でしか進まない。少ない方が使い切られ、多い方は残る。残った気体も容器の中にある。
  • 二酸化炭素は気体として残るが、水は冷えると液体になり体積はほぼ0とみなす。

🔍 こう読み解く

  1. 酸素5Lで燃えるプロパンは 5÷5＝1L。できる二酸化炭素は 1×3＝3L。
  2. 残ったプロパンは 5−1＝4L。容器の中は 3＋4＝7L。
答え：7L
自分で解くときのチェック：「5Lのプロパンが全部燃えた」と思って15Lの酸素が必要、と進めていないか。入れた酸素は5Lしかない。

K20 (9) 入れた酸素の体積 条件文・燃焼の計算

👀 まず見るところ

【条件文】(8)と変わった部品は「プロパン2L」「酸素は何L」「水酸化ナトリウム水溶液を入れた→5L」に丸。水酸化ナトリウムは「二酸化炭素を全部吸う」に直して書く → 残った5Lは余った酸素と決まる。

📚 前提知識

  • 水酸化ナトリウム水溶液は二酸化炭素を吸収する。入れたあとに残る気体は、二酸化炭素以外（ここでは酸素）。
  • 酸素が余った＝プロパン2Lは全部燃えた。燃えた分の酸素は 2×5＝10L。

🔍 こう読み解く

  1. プロパン2Lが全部燃えるのに使った酸素＝2×5＝10L（できた二酸化炭素6Lは吸収されて消える）。
  2. 残った5Lは余った酸素。入れた酸素＝10＋5＝15L。
答え：15L

K20 (10) 塩酸にとけて水素が発生する物 知識問題

ア（鉄）・オ（マグネシウム）。塩酸と反応して水素を出す金属は鉄・マグネシウム・アルミニウム・亜鉛。銅と銀は塩酸と反応しない。石灰岩は塩酸にとけるが出る気体は二酸化炭素、イオウは金属でなくとけない。「すべて選びなさい」なので、6つ全部に○×をつけてから書く。
答え：ア・オ

K20 (11) ②が⑥につくこと 資料問題・漢字2字

👀 まず見るところ

【資料問題】部品は図4の「②＝やくから出た花粉」「⑥＝めしべの先（柱頭）」を図の横に名前で書くこと（正体を1行）と、答え方「漢字2字」に丸 → 花粉が柱頭につく＝受粉。

📚 前提知識

  • 花粉はおしべのやくでつくられ、めしべの先の柱頭につく。これが受粉（解答冊子）。
  • 図4は①やく・②花粉・⑥柱頭・⑧子房の中の胚珠、と番号を名前に置きかえてから設問を読む。

🔍 こう読み解く

  1. ②は①（やく）のそばに点々でかかれた粒＝花粉。⑥はめしべのいちばん上＝柱頭。
  2. 「花粉が柱頭につく」の名前は受粉。漢字2字で書く。
答え：受粉

K20 (12) 花粉管がのびて⑧に届くと起こること 資料問題・漢字2字

👀 まず見るところ

【資料問題】(11)と変わった部品は「管を伸ばして」「⑧に到達」に丸。⑧は子房の中の胚珠と正体を書く → 花粉の中身が胚珠に届いて1つになる＝受精。

📚 前提知識

  • 受粉のあと、花粉から花粉管が胚珠までのび、花粉の精細胞と胚珠の卵細胞が1つになる。これが受精（解答冊子）。
  • 受精した胚珠は種子に、子房は果実になる。「受粉→受精→種子」の順で1本にしておく。

🔍 こう読み解く

  1. (11)の受粉は「つく」だけ。(12)は「管がのびて中身が届く」なので、1段あとの受精。
  2. 字がにているので、「粉がつく＝受粉」「精細胞が届く＝受精」と字で区別して書く。
答え：受精

K20 (13) 図5のプランクトンで光合成をするもの 知識問題

ウ（イカダモ）・エ（ツノモ）。光合成をするのは葉緑体をもつ植物プランクトン。ツノモは葉緑体をもちながら自由に動ける（解答冊子）ので、「動く＝動物」と決めつけない。ミジンコ・ゾウリムシ・ツボワムシは動物プランクトン。
答え：ウ・エ

K20 (14) 図5の生物を大きい順に 知識問題

ア→オ→イ→エ→ウ。解答冊子の大きさは、ミジンコ約1mm・ツボワムシ約0.4mm・ゾウリムシ約0.3mm・ツノモ約0.1mm・イカダモ約0.04mm。ミジンコだけが肉眼で見える大きさで、植物プランクトンの2つ（ツノモ・イカダモ）が小さい側、と覚えると並びが残りやすい。
答え：ア→オ→イ→エ→ウ

K20 (15) 肝臓でつくられ消化酵素をもたない消化液 知識問題

たん汁（たん液）。古くなった赤血球をこわしたものを材料に肝臓でつくられ、たんのうにたくわえられて十二指腸に出る。消化酵素はもたないが、脂肪を細かくして、すい液が脂肪を脂肪酸とモノグリセリドに分けるのを助ける（解答冊子）。
答え：たん汁（たん液）

K20 (16) 東の空の皆既日食の欠け方 資料問題・記号

👀 まず見るところ

【資料問題】部品は聞かれ方「日食」に丸と、ア〜エの正体を2つに分けて書くこと＝右からかくれる（ア・ウ）／左から（イ・エ）、かくす影が太陽と同じ大きさ（ア・イ）／太陽より大きい（ウ・エ）。日食は「右から・同じ大きさ」。

📚 前提知識

  • 月は西から東へ公転するので、日食では月が太陽の右（西）側からかくし始める（解答冊子）。
  • 太陽と月は見かけの大きさがほぼ同じ。だから欠けた部分のふちは、太陽と同じ丸さのカーブになる（アの形）。

🔍 こう読み解く

  1. 右から欠けるのはアとウ → イ・エを消す。
  2. アは欠けたふちが太陽と同じ丸さ、ウはふちがゆるい（大きい影）。日食は月の大きさ＝太陽 → ア。
答え：ア

K20 (17) 東の空の皆既月食の欠け方 資料問題・記号

👀 まず見るところ

【資料問題】(16)と変わった部品は「月食」「満月」に丸。かくすのは月でなく地球の本影と正体を書き直す → 月は影に左から入る・影は月より大きいので、(16)と両方逆になる。

📚 前提知識

  • 月食は、月が地球の本影の中に入る現象。月は公転で東へ動くので、月の左（東）側から影に入っていく（解答冊子）。
  • 地球の影は月よりずっと大きい。だから欠けたふちのカーブは月よりゆるくなる（エの形。イは同じ大きさの影なので×）。

🔍 こう読み解く

  1. 左から欠けるのはイとエ → ア・ウを消す。
  2. 影が月より大きい＝ふちがゆるいのはエ。
答え：エ
自分で解くときのチェック：「日食は右から・同じ大きさ」「月食は左から・大きい影」と2行で書いてから、ア〜エを見る。

K20 (18) 20時ごろ南の空高くにオリオン座が見える時期 知識問題

ア（2月中旬）。オリオン座が20時に南中するのは2月15日ごろ。真夜中0時に南中するのは12月15日ごろ（解答冊子）。星は1か月で同じ時刻に約30度（2時間分）西にずれるので、12月の0時南中から2か月あとの2月に20時南中になる、とつなぐ。
答え：ア

K20 (19) オリオン座の3つ星が動く様子の順 資料問題・並べかえ

👀 まず見るところ

【資料問題】部品は「東の空から西の空にかけて」と答え方「観察した順」に丸。ア〜エの正体を「横（ア）・たて（イ）・右上がり（ウ）・ゆるい右上がり（エ）」と1行で書く → 東ではたて、西では横と決まれば、間は傾きの順。

📚 前提知識

  • オリオン座の3つ星は、東の空ではたてに並び、南の空でななめ、西の空では横に並ぶ（解答冊子）。星座全体が回るように見えるため。
  • 東からのぼった星は右上へ、南を通って、西へ右下にしずむ。3つ星の傾きは、たて→ななめ→横と少しずつ変わる。

🔍 こう読み解く

  1. 最初（東）はたて並びのイ、最後（西）は横並びのア。
  2. 間は傾きが大きい順。ウ（急なななめ）→エ（ゆるいななめ）。
  3. イ→ウ→エ→ア。
答え：イ→ウ→エ→ア

K20 (20) シソチョウが生息していた時期 知識問題

イ（1億4千万年前）。シソチョウは中生代の示準化石で、中生代は約2億5000万年前〜約6600万年前（解答冊子）。選択肢の中で中生代に入るのはイだけ。ア4千万年前は新生代、ウ・エは古生代。
答え：イ
