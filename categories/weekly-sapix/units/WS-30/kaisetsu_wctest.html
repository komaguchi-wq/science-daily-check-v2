WS-30 ウィークリーチェック WS-30（WS-29 実験器具の復習・顕微鏡／ガスバーナー／ろ過）

WC 全体像 実験器具 10問（各10点・100点）

WS-29「実験器具」の復習。顕微鏡（名前・使う順・プレパラート）、ガスバーナー（つける順と消す順・炎が消えたとき）、ろ過（ろ紙のつけ方・ろ液）の3つのまとまり。並べかえは記号の暗記でなく、「なぜその順か」を1行で言えるかどうかで決まる。

今回は90／100点。落としたのは(1)②の顕微鏡の順だけで、「明るさの調節」と「プレパラートをのせる」の前後を逆にした。他の9問は理由ごと身についている。

WC (1)①A・B・C・D 顕微鏡のA〜Dの名前 知識問題

A 接眼レンズ（目をつける方）／B ステージ（のせ台）／C 反射鏡／D 対物レンズ（物に近い方）。上から 接眼レンズ→対物レンズ→ステージ→反射鏡 の順。光はこの逆向き（反射鏡→ステージ→対物→接眼）に通る。図のどこを指しても言えるようにしておく。
答え：A 接眼レンズ　B ステージ（のせ台）　C 反射鏡　D 対物レンズ
今回：接眼レンズ・ステージ・反射鏡・対物レンズ ○（4つとも）。

WC (1)② 顕微鏡の使い方の順 素材文・並べかえ

👀 まず見るところ

【素材文】設問は「正しい順」。部品は各文の動作の言葉「Aをはめる」「適当な明るさにする」「Bにのせ」「横から見ながら近づける」に丸 → 「準備（はめる・つける・明るさ）→ のせる → 近づける → 合わせる」と4段に直して書けば、ウとオの前後が決まる。

📚 前提知識

  • 接眼レンズを先にはめるのは、鏡筒の中にほこりが入らないようにするため。だから ア→エ。
  • 反射鏡で明るさを合わせるのは、ステージに何ものせていないうち。プレパラートがあると視野全体の明るさが決めにくい。だから ウ→オ。
  • 対物レンズとプレパラートを近づけるときは横から見る（ぶつけて割らないため）。ピント合わせは、のぞきながら遠ざける向きで行う。だから イ→カ。

🔍 こう読み解く

  1. 準備の3つ：ア（接眼）→エ（対物）→ウ（明るさ）。
  2. のせる：オ。近づける：イ。合わせて観察：カ。
  3. つなげて ア→エ→ウ→オ→イ→カ。
答え：ア→エ→ウ→オ→イ→カ
今回：ア→エ→オ→ウ→イ→カ ×。知識＝「明るさの調節はプレパラートをのせる前」の理由が入っていなかった形で、ウとオだけが逆（採点の赤矢印もこの2つの入れかえ）。次は「何ものせていないうちに明るさ」と1行書いてから並べる。
コツ：ア→エ（ほこり）、ウ→オ（何もないうちに明るさ）、イ→カ（横から近づけて、のぞきながら遠ざける）。前後の理由を3組で持つ。

WC (1)③ プレパラートのつくり方の順 素材文・並べかえ

👀 まず見るところ

【素材文】設問は「正しい順」。部品は「スライドガラスの上にのせる」（はじめ）と「まわりの水を吸い取る」（かぶせたあと）に丸 → 真ん中は「水をたらす→カバーガラス」の順と決まる。

📚 前提知識

  • 水を1滴たらしてからカバーガラスをかぶせるのは、気泡を入れないため（かぶせてから水を入れると空気が残る）。
  • はみ出た水はカバーガラスのまわりからろ紙で吸い取る。対物レンズをぬらさないため。

🔍 こう読み解く

  1. のせる（ウ）→ 水をたらす（イ）→ かぶせる（エ）→ 吸い取る（ア）。
答え：ウ→イ→エ→ア
今回：ウ→イ→エ→ア ○。

WC (2) ガスバーナーを使い始めてから終わるまで 素材文・並べかえ

👀 まず見るところ

【素材文】設問は「使い始めてから終わるまで」＝つける手順と消す手順の両方。部品は各文の「開く／閉じる」に丸 → 「開く」の4つ（C・A・H・F）が前半、「閉じる」の3つ（E・D・B）が後半、間にG と直して書く。消すときはつけた順の逆。

📚 前提知識

  • つける：元栓を開く → マッチに火 → ガス調節ねじを開く → 空気調節ねじを開いて青い炎に。火を先につけてからガスを出すのは、出たガスにすぐ火がついて、ガスがたまらないようにするため。
  • 消す：空気調節ねじ → ガス調節ねじ → 元栓。外側（空気）から順に閉じる＝開けた順の逆。
  • 炎の色：空気が足りないとオレンジ色（すすが出る）。空気を足して青い炎にする。

🔍 こう読み解く

  1. 前半：C（元栓を開く）→ A（マッチに火）→ H（ガス調節ねじを開く）→ F（空気調節ねじで青い炎に）。
  2. 真ん中：G（実験）。
  3. 後半は逆順：E（空気調節ねじを閉じる）→ D（ガス調節ねじを閉じる）→ B（元栓を閉じる）。
答え：C→A→H→F→G→E→D→B
今回：C→A→H→F→G→E→D→B ○。前半・後半を分けて逆順にする手順ができている。

WC (3) 空気調節ねじを開きすぎて炎が消えたとき 素材文・正しいもの

👀 まず見るところ

【素材文】部品は「炎が消えてしまいました」と「このあとどのようにすれば」に丸 → 炎は消えたがガスは出たまま、に直して書く。危ないのはガスなので、先にガスを止める。

📚 前提知識

  • 空気を入れすぎると炎が吹き消されることがある。火が無くてもガス調節ねじ・元栓が開いていればガスは出続ける。
  • ガスが出ている所にマッチの火を近づけると、たまったガスに一気に火がついて危険。だから「すぐに点火」はしない。

🔍 こう読み解く

  1. ア 元栓を閉じる → ガスを止める。これが先 → ○。
  2. イ 水をかける → 火は無いので意味がなく、器具をぬらすだけ → ×。ウ すぐ点火 → 出ているガスに火がつく → ×。エ 分解して調べる → ガスが出たまま分解はしない → ×。
答え：ア
今回：ア ○。

WC (4) ろうととろ紙のつけ方 資料問題・正しいもの

👀 まず見るところ

【資料問題】部品は図の正体「ろうとに対するろ紙の大きさ（同じ／少し小さい／少し大きい／手でへこませる）」を1行と、聞かれ方「正しくつけているもの」に線 → 「ろ紙はろうとより少し小さく、ぴったりつける」に当てはまる1つを選ぶ。

📚 前提知識

  • ろ紙は4つ折りにして円すいに開き、ろうとより少し小さい大きさで、水でぬらしてろうとにぴったりつける。すきまがあると液がろ紙を通らずに落ちる。
  • ろ紙がろうとより大きいと、ふちから液がこぼれる。手でへこませるとろ紙がやぶれたりすきまができたりする。

🔍 こう読み解く

  1. ア 同じ大きさ → ろ紙のふちがろうとのふちと重なり、液がこぼれやすい → ×。
  2. ウ 少し大きい → ろ紙がはみ出る → ×。エ 手でへこませる → 円すいに折っていない → ×。
  3. イ 少し小さい → ○。
答え：イ
今回：イ ○。

WC (5) 食塩水をろ過したろ液 知識問題

エ（元と同じ濃さの食塩水）。水にとけた食塩の粒は水の粒と同じくらい小さく、ろ紙の穴をそのまま通る。だからろ過では水と食塩を分けられず、濃さも変わらない。とけ残りや泥のようにとけていないものだけがろ紙に残る。食塩を取り出したいときはろ過でなく「水を蒸発させる」と区別する。
答え：エ
今回：エ ○。

WC まとめ 90／100点

  • 取れた9問：顕微鏡の名前、プレパラート、ガスバーナーの前半→逆順の後半、炎が消えたら元栓、ろ紙は少し小さく、ろ液は同じ濃さ。理由ごと言えている。
  • 落とした(1)②は、「明るさの調節は何ものせていないうちに」の1行が無かった分のウ・オの入れかえ。順を記号で覚えるのでなく、前後の理由（ほこり／明るさ／横から近づけて遠ざける）を3組で持つ。
  • 解き直すなら WS-29 の顕微鏡の使い方の文を、ア〜カの理由を声に出しながら並べ直す。
