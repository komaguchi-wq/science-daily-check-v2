WS-30 CP（コアプラス確認テスト WS-30・植物の再徹底 20問）

CP 全体像 植物の再徹底 20問（各5点・100点）

コアプラス545〜588・624・625の植物を、種子→発芽の呼吸→光合成→茎と葉のつくり→花と実→蒸散→分類→開花、の順にひと回りする確認テスト。図を見て決める問題（(2)(3)(7)(10)(12)(13)）と、数字を引き算する問題（(4)(5)(14)(15)）が半分、残りは一問一答。

今回は85／100点。落とした3問は (10)葉緑体、(13)リンゴのC、(19)①夏至。計算4問と図の照合はできているので、「矢印の先は何か」「C・Dの線はどこへのびているか」を図で確かめてから書くのが次の一手。

CP (1) カキの種子のX 知識問題

子葉。カキの種子は、養分を胚乳にたくわえる「有胚乳種子」。白くて大きい部分が胚乳で、その中にある小さな芽の形がX＝子葉（胚の一部）。インゲンマメのように子葉が大きくふくらんでいないのは、養分が胚乳にあるから。
答え：子葉
今回：子葉 ○。

CP (2) インゲンマメの胚にあたる部分 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「胚に当てはまる部分をすべて」に線。胚＝「これから植物の体になる部分ぜんぶ」と1行書く → 外側の皮（ア）だけが胚でない、と決まる。

📚 前提知識

  • インゲンマメは無胚乳種子。養分は子葉にあり、種皮の内側は 幼芽・胚軸・幼根・子葉 で、この4つをまとめて胚という。

🔍 こう読み解く

  1. ア＝いちばん外側の皮＝種皮。胚ではない。
  2. イ＝幼芽、ウ＝胚軸、エ＝幼根、オ＝子葉。どれも胚 → イ・ウ・エ・オ。
答え：イ・ウ・エ・オ
今回：イウエオ ○。種皮だけ外す判断ができている。

CP (3) アズキの発芽の様子 資料問題・写真の選択

👀 まず見るところ

【資料問題】部品は「アズキ」に丸と、写真の正体「子葉が地上に出るか、土の中に残るか」を1行。アズキは子葉が土に残る仲間 → 地中に黒い子葉がある写真を探せば決まる。

📚 前提知識

  • 子葉が地上に出ない植物の代表がアズキ・エンドウ・ソラマメ・クリ。子葉の養分を使って本葉がいきなり出てくる。
  • ア・ウ・エ・オのように、子葉が土の上に持ち上がる形（オは種皮をかぶったまま）はインゲンマメ・ヒマワリ・ダイズなどの型。

🔍 こう読み解く

  1. 5枚の写真で、土の中に黒い粒（子葉）が残っているのはイだけ。
  2. イは地上に出ているのが本葉。アズキの型と合う。
答え：イ
今回：イ ○。

CP (4) ダイズが吸収した酸素の量 条件文・計算

👀 まず見るところ

【条件文】部品は図1の「水酸化ナトリウム水溶液」と「左に8cm³」に丸。水酸化ナトリウムは「出た二酸化炭素を全部吸う」に直して書く → 図1の減り8cm³＝酸素の減りそのもの。

📚 前提知識

  • 発芽しかけた種子は呼吸をして、酸素を吸い、二酸化炭素を出す。
  • 水酸化ナトリウム水溶液は二酸化炭素をよく吸収する。図1のびんの中では、出た二酸化炭素が消えるので、気体の減り＝吸った酸素の量。

🔍 こう読み解く

  1. インクが左に動く＝びんの中の気体が減った。
  2. 図1は二酸化炭素が吸われて残らない → 減った8cm³は酸素の分 → 8cm³。
答え：8 cm³
今回：8 ○。

CP (5) ダイズが放出した二酸化炭素の量 条件文・計算

👀 まず見るところ

【条件文】部品は(4)と変わった図2の「水」と「左に1.6cm³」に丸。水は二酸化炭素をほとんど吸わないので、図2の減り＝「酸素の減り−二酸化炭素の増え」に直して書く → 8−□＝1.6 の式が立つ。

📚 前提知識

  • 図2の水は二酸化炭素を吸わない。だから出た二酸化炭素がびんに残り、吸った酸素との差だけ気体が減る。

🔍 こう読み解く

  1. 余白に「酸素の減り − 二酸化炭素の増え ＝ 1.6」と書く。
  2. 酸素の減りは(4)の8cm³ → 8 − 二酸化炭素 ＝ 1.6 → 二酸化炭素 ＝ 8 − 1.6 ＝ 6.4cm³。
答え：6.4 cm³
今回：6.4 ○。図1→図2の引き算の形ができている。
コツ：この2本セットは「水酸化ナトリウム側＝酸素」「水側＝差」とだけ押さえれば、数字が変わっても同じ引き算。

CP (6) ヨウ素液をつける前の順番 素材文・並べかえ

👀 まず見るところ

【素材文】設問は「どの順番でつけていけば」。部品はアルコールの役目「葉の緑をぬいて色を見やすくする」を3語で書く → 熱湯でやわらかく→アルコールで緑ぬき→水で洗う、の順が決まる。

📚 前提知識

  • 熱湯：葉をやわらかくし、はたらきを止める。
  • あたためたアルコール：葉緑素（緑の色）をとかし出して葉を白くする。緑のままではヨウ素液の青紫が見えない。
  • 水：アルコールでかたくなった葉をもどし、ヨウ素液がしみこみやすくする。

🔍 こう読み解く

  1. 色をぬく（アルコール）のは、やわらかくした（熱湯）あと。
  2. ヨウ素液の直前は水 → イ→ウ→ア。
答え：イ・ウ・ア
今回：イウア ○。

CP (7) ヨウ素液で青紫になる部分 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は図3の正体「ふ（白い部分）とアルミはく（光をさえぎる）」を1行と、聞かれ方「すべて選び」に線。でんぷんができる条件＝「緑」かつ「光あり」なので、緑で、はくの外の部分だけを拾う。

📚 前提知識

  • 光合成でできるでんぷんにヨウ素液をつけると青紫になる。光合成には葉緑体（緑の部分）と光の両方が必要。
  • 「一晩置く」のは、前の日のでんぷんを葉から出しておくため。これで昼にできた分だけを調べられる。

🔍 こう読み解く

  1. ア＝緑・はくの外 → ○。オ＝緑・はくの外 → ○。
  2. ウ＝緑だが、はくの下（光なし）→ ×。イ・エ＝ふ（緑なし）→ 光が当たってもでんぷんはできない → ×。
  3. 残るのはア・オ。
答え：ア・オ
今回：アオ ○。「緑」と「光」の2条件を両方見られている。

CP (8) 図4のA・Bの集まりの名前 知識問題

維管束。図4の引き出し線は、A＝それぞれの束の外側の白い部分＝師管の集まり（葉でできた養分の通り道）、B＝内側の黒い部分＝道管の集まり（根から吸った水の通り道）。この2つが1組になったものが維管束。左の図のように全体に散らばるのが単子葉類、右のように輪に並ぶのが双子葉類。
答え：維管束
今回：いかんそく ○。

CP (9) 図4のCと、そこで行われること 知識問題

①形成層 ②細胞分裂。輪に並ぶ維管束のあいだ（道管と師管のあいだ）にある層が形成層で、ここで細胞分裂をくり返して茎が太くなる。形成層があるのは双子葉類だけ。単子葉類（左の図）には無いので、茎はあまり太らない。
答え：① 形成層　② 細胞分裂
今回：けいせいそう・さいぼうぶんれつ ○。

CP (10) 図5の矢印の●は何か 資料問題・名前

👀 まず見るところ

【資料問題】部品は設問の「矢印で示した●」に丸。図5の正体「葉の断面・1つ1つの箱が細胞」を1行 → 矢印は細胞の中の小さな粒を指していて、太い管（維管束）ではない、と決まる。

📚 前提知識

  • 葉の細胞の中にある緑の粒が葉緑体。ここで光合成をする。表側のさく状組織に特に多い。
  • 道管・師管は、図5のまん中の丸い束（維管束＝葉脈の断面）の中にある。

🔍 こう読み解く

  1. 矢印の先は、左の細長い細胞の中の●1つ。細胞の中に何個も並んでいる。
  2. 「細胞の中の粒」で、上下の細胞にも全部ある → 葉緑体。
答え：葉緑体
今回：道管 ×。部品を拾えなかった＝「●」に丸をつけず、矢印の近くにある丸い束（維管束）を見て答えた。次は矢印の先が細胞の中か外かを先に見る。中なら葉緑体、束の中なら道管・師管。

CP (11) 図5のBの組織と、葉のどちら側か 知識問題

①海綿 ②裏。葉の断面は、表側に細長い細胞がぎっしり並ぶさく状組織（A）、裏側に丸い細胞がすき間だらけに並ぶ海綿状組織（B）。すき間は気体の通り道で、裏側に多い気孔とつながる。「さく＝柵のように縦にそろう」「海綿＝スポンジのようにすき間」と形で結びつける。
答え：① 海綿　② 裏
今回：海めん・裏 ○。

CP (12) カキのA・Bは花のどこだったか 資料問題・記号

👀 まず見るところ

【資料問題】部品はカキの図で「Aの線の先＝へたの黒い部分」「Bの線の先＝食べる部分と種をつつむ全体」を1行ずつ。図6で「がく」と「子房」の記号を探せば決まる。

📚 前提知識

  • 実（果実）は子房が育ったもの、種子は子房の中の胚珠が育ったもの。
  • 図6の記号：ア 花びら／イ がく／エ 柱頭／オ やく／カ 子房／キ 胚珠／ク 花の軸（花柄）。カキのへたはがくが残ったもの。

🔍 こう読み解く

  1. A＝へた。花のときのがくがそのまま残っている → イ。
  2. B＝実の本体。子房がふくらんだもの → カ。
答え：A イ　B カ
今回：A イ・B カ ○。

CP (13) リンゴのC・Dは花のどこだったか 資料問題・記号

👀 まず見るところ

【資料問題】部品はリンゴの図で「Cの線の先＝上につき出た細い軸」「Dの線の先＝まん中のしん（種のまわり）」を1行ずつ。リンゴは食べる部分が子房でない、と知っていても、まず線の先の形を見る。

📚 前提知識

  • リンゴ・ナシは、花の軸の先の花たくがふくらんで食べる部分になる。子房は中心のしん（種を包む部分）。
  • 上につき出た細い棒は、実を枝につないでいた軸（花柄）＝図6のク。

🔍 こう読み解く

  1. C＝実の上の細い棒＝枝につながる軸 → 図6で軸にあたるのはク。
  2. D＝まん中のしん。種（胚珠が育ったもの）をつつむ部分＝子房 → カ。
  3. 柱頭（エ）やがく（イ）が残るのは、リンゴでは反対側（下のくぼみ）。Cの側ではない。
答え：C ク　D カ
今回：C エ ×・D カ ○（1問としては×）。知識＝「リンゴのしんの反対側に残るのが柱頭やがく」を、軸のある上側と取りちがえた。Cの線の先が「細い棒」なら柱頭でなく軸、と形で決めれば防げる。
コツ：カキは「食べる＝子房」、リンゴは「食べる＝花たく、しん＝子房」。この2つを対にして持つと(12)(13)はセットで決まる。

CP (14) 葉の裏側から蒸散した水の量 条件文・計算

👀 まず見るところ

【条件文】部品は図7の「ワセリン＝ぬった面から蒸散しない」と、求めるもの「裏側から」に丸。A〜Cを「どこから出たか」に直して図の下に書く：A＝表＋裏＋茎、B＝裏＋茎、C＝表＋茎 → 裏＝A−C。

📚 前提知識

  • 蒸散は気孔から起こり、気孔は葉の裏側に多い。ワセリンは気孔をふさぐので、ぬった面からは水が出ない。
  • 油は水面からの蒸発を止める。だから減った水は、すべて植物から出た分。

🔍 こう読み解く

  1. A（そのまま）＝表＋裏＋茎＝7.3。C（裏にワセリン）＝表＋茎＝2.6。
  2. 裏＝A−C＝7.3−2.6＝4.7cm³。
  3. 検算：B（表にワセリン）＝裏＋茎＝5.4 → 表＝7.3−5.4＝1.9。表1.9＋裏4.7＋茎0.7＝7.3で合う。
答え：4.7 cm³
今回：4.7 ○。余白に「お1.9 う4.7 く0.7」と表・裏・茎を全部出してから答えている。この書き方がそのまま(15)の答えになる。

CP (15) Dで減った水の量 条件文・計算

👀 まず見るところ

【条件文】部品は(14)と変わった「D＝葉の両面にワセリン」に丸。「両面ふさぐ＝茎だけ」に直して書く → 茎＝A−表−裏、または B＋C−A で決まる。

📚 前提知識

  • 葉の両面をふさいでも、茎の表面からわずかに蒸散する。だからDは0にはならない。

🔍 こう読み解く

  1. 茎＝A−表−裏＝7.3−1.9−4.7＝0.7cm³。
  2. 別の出し方：B＋C＝（裏＋茎）＋（表＋茎）＝7.3＋茎 → 5.4＋2.6−7.3＝0.7。同じになる。
答え：0.7 cm³
今回：0.7 ○。

CP (16) クローバーの科と和名 知識問題

①マメ ②シロツメクサ。クローバーはマメ科で、和名はシロツメクサ（白い詰め草）。葉が3枚1組の複葉、花は小さな花が集まって丸くなる。マメ科の仲間は、根に根粒菌がつく・花びら5枚のちょう形、で結びつける。
答え：① マメ　② シロツメクサ
今回：マメ・シロツメクサ ○。

CP (17) アブラナ科の野菜・果物 知識問題

ア（ブロッコリー）。ブロッコリーは、つぼみの集まりを食べるアブラナ科の野菜。アブラナ科はほかにキャベツ・ダイコン・ハクサイ・コマツナ。花びら4枚が十字に並ぶ。
答え：ア
今回：ア ○。

CP (18) キク科の植物を2つ 知識問題

イ（ゴボウ）・カ（レタス）。キク科は、小さな花がたくさん集まって1つの花のように見える仲間で、タンポポ・ヒマワリ・コスモスのほか、食べるものではゴボウ（根）・レタス（葉）・シュンギク。残りは、エンドウ＝マメ科、イチゴ＝バラ科、ジャガイモ＝ナス科、サツマイモ＝ヒルガオ科。
答え：イ・カ
今回：イ・カ ○。

CP (19) アサガオが咲きはじめる時期・しぼんだ花 知識問題

①夏至 ②イ。アサガオは夜の長さが長くなっていくと花芽をつける短日植物。夜がいちばん短い夏至を過ぎて夜がのびはじめると咲きはじめる。「早朝に開いて昼にしぼむ」は毎日の話、「夏至を過ぎたころ」は1年の中でいつ咲きはじめるかの話で、問われているのは後者。一度しぼんだ花は二度と開かない（イ）。
答え：① 夏至　② イ
今回：① 日の出 ×・② イ ○（1問としては×）。知識＝空らんを「1日の中のいつ」と読んで日の出と書いたが、文は「〜を過ぎたころに咲きはじめ」で、1年の中の時期を聞いている。「早朝に花が開いて」が後ろにあるので、①はそれより前の季節の話、と切り分ける。

CP (20) タンポポの綿毛は何が変化したものか 知識問題

がく。タンポポの1つ1つの小さな花にはがくがあり、それが細い毛（冠毛）に変化して、実（種子）を風で飛ばす。「綿毛＝がく」はキク科の決まりとして一語で持っておく。
答え：がく
今回：がく ○。

CP まとめ 85／100点（17／20）

  • 取れた：種子・発芽の呼吸の引き算（(4)(5)）、ヨウ素液の手順と条件（(6)(7)）、蒸散の表・裏・茎の分け方（(14)(15)）、分類（(16)〜(18)）。計算と図の照合は手順どおりにできている。
  • 落とした3問の型：(10)は矢印の先を「細胞の中の●」として見なかった、(13)は線の先の「細い棒」を柱頭と取りちがえた、(19)は「1日の中」と「1年の中」の切り分け。線や矢印の先の形を1行で言ってから記号や名前を書くと、(10)(13)は防げる。
  • 覚え直しはこの3つ：細胞の中の緑の粒＝葉緑体／リンゴは食べる＝花たく・しん＝子房・上の棒＝軸（ク）／アサガオ＝短日植物＝夏至を過ぎて咲きはじめる。
