X3 全体像 モノコード・音の高さと大きさ 6問

音の高さを決めるのは振動の速さ（振動数）の1つだけ。弦なら「短い・細い・強く張る」ほど速くふるえて高い音、木きんなら短い板、びんの空気なら少ない空気、コップのガラスなら水が少ないほど高い音になる。音の大きさは別もので、振れ幅で決まる。

(3)だけ計算。表のA・B・Cを「太さが何倍のとき、おもりは何倍か」で見ると、太さ2倍→おもり4倍、3倍→9倍の決まりが見える。(4)(5)は「何がふるえているか」を先に決めると、高い方も自然に決まる。

【まざり型→条件文】部品は「2オクターブ上」と、答え方の「図3を例として、矢印と振動している弦の様子」に丸。2倍を2回で振動数4倍 → 波長は1/4 に直して書く → 振動する部分は弦の右端から 1/4 だけ。

📚 前提知識

  • (4)より、1オクターブ上がるごとに振動数は2倍。2オクターブなら 2×2＝4倍。速さが同じなので波長は 1/4。
  • 図3の書き方：押さえた所に下向きの矢印、押さえた所から右端までだけ、上下にふくらんだ弦（実線と点線）をかく。

🔍 こう読み解く

  1. 弦の長さの 1/4 を右端から測り、その場所を押さえる（左端から 3/4 の所）。解答冊子の図では弦が12目盛りに分かれ、矢印は右端から3目盛り（左から9目盛り）の所。
  2. 押さえた所に下向きの矢印。
  3. 押さえた所から右端までの短い区間だけ、図3と同じ形のふくらみ（上に実線・下に点線）をかく。左側 3/4 は振動しないので弦の直線のまま。
答え：解答冊子の図（12目盛りの弦の右端から3目盛り＝全長の1/4の所に下向きの矢印をかき、そこから右端までの区間だけが振動している図）
コツ：押さえる位置を「真ん中のさらに真ん中」（左から 1/4）にしないこと。図3で振動しているのは右側なので、右端からの長さで 1/4 を取る。

Z1 (6) ヘリウムの中で弦を振動させると まざり型・選択

👀 まず見るところ

【まざり型→素材文】部品は「この弦を図2のように振動させる」に丸 → 振動しているのは空気でなく弦。(2)の「気柱の空気が振動」と見比べ、「振動するもの：弦／まわりの気体は伝えるだけ」と直して書く。

📚 前提知識

  • 音の高さを決めるのは振動しているものの振動数。弦の振動数は、弦の長さと張りの強さで決まる。まわりがヘリウムでも、弦のゆれ方そのものは変わらない。
  • リコーダーで音が変わったのは、振動しているもの（気柱の気体）自体が空気からヘリウムに入れかわったから（解答冊子）。

🔍 こう読み解く

  1. 図2の弦の振動数は、空気中でもヘリウム中でも同じ。
  2. 振動数が同じなら、音の高さも同じ → ウ。
答え：ウ
コツ：(2)で「ヘリウムは高くなる」と覚えたまま(6)に進むと ア を選びやすい。小問ごとに「振動しているのは何か」を1語書いてから選ぶ。

反射板の問題は、音の道すじを線で1本かくと全部決まる。直接音は「船→船」、反射音は「船→反射板→船」。2回聞こえる時間の差は「反射音が直接音より余分に進んだ距離 ÷ 340」。

Z2 (1)① 船どうしの間隔 条件文・計算

👀 まず見るところ

【条件文】部品は「等間隔」「船う→船おに4秒後」に丸。図1で う から お までは間隔2つぶんと数えて図に書きこむ → 1つぶんは 2秒で進む距離。

🔍 こう読み解く

  1. う→お は間隔2つぶんで 4秒 → 1つぶんは 2秒。
  2. 340×2＝680（m）。

Z2 (1)② 船あが2回目の汽笛を聞くまでの時間 条件文・計算

👀 まず見るところ

【条件文】部品は「船あが」「1回目を聞いてから2回目まで」と、図1の「1190m」に丸。図に直接音（う→あ）と反射音（う→反射板→あ）の2本の線をかく → ちがいはあと反射板の往復だけ。

📚 前提知識

  • 2回聞こえる時間の差は、反射音が直接音より余分に進んだ距離÷340。う→あ の部分は2本の線に共通なので消える（解答冊子の図）。

🔍 こう読み解く

  1. 反射音は あ を通りすぎて反射板まで行き、もどってくる。余分な距離は 1190×2＝2380（m）。
  2. 2380÷340＝7（秒）。
答え：7秒
コツ：「う→反射板→あ」の全体を計算してから直接音を引いても同じ答えになるが、線をかけば「あ〜反射板の往復」だけで済むと見える。

Z2 (1)③ 汽笛の聞こえ方の説明 条件文・選択

👀 まず見るところ

【条件文】部品は選択肢の「うより反射板から遠い船／近い船」に丸。②と同じ線を、う より遠い船（え・お）でかく → 余分な距離が「うと反射板の往復」で全部同じになる。

📚 前提知識

  • う より反射板に近い船（あ・い）：余分な距離は「その船と反射板の往復」なので、船ごとに変わる。
  • う より遠い船（え・お）：直接音も反射音も う から同じ向きに進むので、余分な距離は「う と反射板の往復」＝どの船でも同じ（解答冊子の2つ目の図）。

🔍 こう読み解く

  1. あ の差は7秒（②）。い なら (1190+680)×2÷340＝11秒。近い船どうしでちがう → ア・エ は×。
  2. え・お の差は、どちらも (1190+680×2)×2÷340＝15秒で同じ → イ は×、ウ が正しい。
答え：ウ

Z2 (2)① 鳴らし始めたときの船から反射板までの距離 条件文・計算（動く船）

👀 まず見るところ

【条件文】部品は「秒速20mで反射板に向かう」「10秒間鳴らし」「鳴らし終えてから8秒後に反射音が聞こえ始め」に丸。「聞こえ始め＝鳴らし始めの音の反射」なので、鳴らし始めから 10+8＝18秒 に直して書く。

📚 前提知識

  • 船が音に向かって進むとき、音が進んだ距離と船が進んだ距離を合わせると「はじめの距離の往復」になる。だから（340+20）×時間＝距離×2。

🔍 こう読み解く

  1. 聞こえ始めた音は、鳴らし始めの音。鳴らし始めから聞こえるまで 10+8＝18秒。
  2. 18秒間に、音は 340×18、船は 20×18 進み、合わせて はじめの距離の2倍。(340+20)×18÷2＝3240（m）。
答え：3240m
コツ：「8秒後」をそのまま式に入れると 1440m になってしまう。「鳴らし終えてから」の部品を「鳴らし始めから18秒」に直してから式に入れる。

Z2 (2)② 反射音が聞こえる時間 条件文・計算（四捨五入）

👀 まず見るところ

【条件文】部品は「船上では何秒間」と答え方の「小数第2位を四捨五入」に丸。聞こえ始め（18秒）は①で決まっているので、求めるのは鳴らし終わりの音がもどる時刻。船は10秒で 20×10＝200m 近づいている、と図に書く。

📚 前提知識

  • 鳴らし終わりの音が出た瞬間、船と反射板の距離は 3240−200＝3040m。この音も①と同じ考え方で（340+20）で割る。

🔍 こう読み解く

  1. 鳴らし終わりの音が船にもどるまで：3040×2÷(340+20)＝16.88…（秒）。
  2. 鳴らし始めから数えると 10+16.88…＝26.88… → 26.9秒後に聞こえ終わる。
  3. 反射音は 18秒後から 26.9秒後まで → 26.9−18＝8.9（秒間）。
答え：8.9秒間
コツ：鳴らした10秒より短い8.9秒になるのは、船が音に向かって進んでいるぶん、反射音が縮まって聞こえるから。10秒より長くなったら、200mを引き忘れている。

Z3 (2) Cにいる人にサイレンが聞こえる時間 条件文・計算

👀 まず見るところ

【条件文】部品は「Cで止まっている人」「AB間 340m・BC間 510m」に丸。「鳴らし始め＝0秒・Aから」「鳴らし終わり＝17秒・Bから」の2本の矢印をCまでかく → 聞こえ始めと終わりの時刻の差が答え。

📚 前提知識

  • 最初の音は A から出て 850m、最後の音は B から出て 510m を進む。最後の音のほうが近い所から出るので、聞こえる時間は鳴らした17秒より縮む。

🔍 こう読み解く

  1. 聞こえ始め：A→C は 340+510＝850m → 850÷340＝2.5秒。
  2. 聞こえ終わり：17秒に B から出た音が 510÷340＝1.5秒かけて届く → 17+1.5＝18.5秒。
  3. 18.5−2.5＝16（秒間）。
答え：16秒間
コツ：「聞こえ終わり」を 17秒のままにすると 14.5 になる。鳴らし終わりの音も C まで届く時間がかかる、と矢印をかけば抜けない。

Z3 (5) 近づく救急車の音の高さ 条件文・選択

👀 まず見るところ

【条件文】部品は「(1)〜(4)のことから」「近づいてくるとき」に丸。(4)の 722.5 と元の 680 を並べて書く → 1秒間の振動数が増えている＝高い音。

📚 前提知識

  • Z1と同じで、振動数が大きいほど高い音。近づく音源からの音は振動数が増えて高く、遠ざかると減って低く聞こえる（ドップラー効果）。

🔍 こう読み解く

  1. 止まっているときは 680回/秒、近づくときは 722.5回/秒。
  2. 振動数が多い → 音は高くなる → イ。救急車は一定の速さなので エ（不規則）は×。
答え：イ
コツ：遠ざかるときは逆に、聞こえる時間が17秒より長くなって振動数が減り、低く聞こえる。「近づく＝高い／遠ざかる＝低い」をセットで置く。

Z1〜Z3 まとめ 音の高さと速さ

  • 式は1本に集約。速さ＝振動数×波長。速さが一定なら「波長が短い→振動数が大きい→高い音」。Z1(3)(4)(5)はこの式で、1オクターブ＝2倍、2オクターブ＝4倍。
  • 反射・移動の問題（Z2・Z3）は、音の道すじを1本ずつ線でかく。直接音と反射音のちがい＝余分な距離÷340、動く船＝（340+20）で割る、鳴らし始めと鳴らし終わりは別の矢印。
  • 「何が振動しているか」を小問ごとに1語（空気／弦）。Z1(2)はヘリウムで音の速さが変わる、(6)は弦なので変わらない。
