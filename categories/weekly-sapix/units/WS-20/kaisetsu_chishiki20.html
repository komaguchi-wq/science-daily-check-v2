WS-20 K20 知識の20題確認テスト（磁石・てこ・ばね・ふりこ・鉄と塩酸・生物・川・天体）

K20 全体像 知識の20題 各5点×20問

一問一答が12問、計算が8問。計算は (3)(4)てこ・(5)(6)ばね・(7)ふりこ・(8)(9)鉄と塩酸・(19)経度差で、どれも「余白に式か図を1つ置く」だけで決まる型。てこは棒の重さをまん中に矢印、ばねは「同じのび＝力は逆比」、ふりこは「長さ4倍で周期2倍」、鉄と塩酸は「表の比がくずれた所」、経度差は「1度＝4分」。

知識問題は、ひっかけの入口が決まっている。(10)酸素は過酸化水素水から出る、(11)(12)イチョウ・ソテツは種子植物、ヤドリギは光合成する、(13)ミジンコ・フナムシ・ワラジムシは甲殻類、(18)公転も自転も左回り。この単元のまとめカードで4つを確かめてから解く。

K20 (1) 釘の山に棒磁石を入れて取り出したときの様子 知識問題

ウ。棒磁石の磁力は両端（N極とS極）で強く、まん中はほとんど無い。だから釘は両端だけに、鎖のようにつながってつく。アはまん中にも釘がついていて×、イは全体に均等で×、エはまん中にだけついていて×（まん中は磁力が弱い）。
答え：ウ

K20 (2) 2本並んでくっついていた釘の先端 知識問題

ウ。磁石についた釘は磁石になる（磁化）。2本とも先端は棒磁石のふれている極と同じ極になるので、先端どうしが同じ極で反発して先端が開く（解答冊子）。頭が閉じて先端が開いた「ハ」の字のウ。イは先端が閉じているので逆。
答え：ウ

K20 (3) 重さのある棒のてこ・Aのおもり 条件文・計算

👀 まず見るところ

【条件文】部品は「太さが一様で重さが50g」「長さ24cm」。50gは棒のまん中＝左端から12cmに下向きの矢印で置く（直して書く）。図1の4cm＋8cm＝12cmなので、ばねばかりBはちょうどまん中。Bを支点にすると棒の重さは回転に効かず、Aと72gだけの式になる。

📚 前提知識

  • 太さが一様な棒の重さは、まん中に全部かかっているとみなせる。
  • 支点の真下にある力は、うでの長さ0なので回転させるはたらきが0。

🔍 こう読み解く

  1. Bを支点に、左うで＝Aまで8cm、右うで＝72gまで12cm を図に書く。
  2. 左回り＝右回り：A×8＝72×12＝864。
  3. A＝864÷8＝108g。
答え：108g
コツ：自分で解くときは、まず「Bの位置＝棒のまん中か」を4＋8＝12で確かめてから式を立てる。図の左端の4cmは、Aより外側の余りの部分で式には入らない。

K20 (4) ばねばかりBの値 条件文・計算

👀 まず見るところ

【条件文】(3)と変わった部品は「Bのばねばかりの値」。棒をつるしているのはBだけなので、Bは下向きの力を全部受ける。図に置いた矢印3本（A・棒50g・72g）を足すだけ。

📚 前提知識

  • つり合っているとき、上向きの力の合計＝下向きの力の合計。棒の重さも下向きの力に入る。

🔍 こう読み解く

  1. 下向き＝A 108g＋棒 50g＋72g。
  2. B＝108＋50＋72＝230g。
答え：230g
コツ：(3)で棒の重さを回転の式から外したぶん、(4)では足し忘れやすい。図の矢印を数えて3本と確かめる。

K20 (5) 2本のばねでつるした棒・おもりの位置 条件文・計算

👀 まず見るところ

【条件文】部品は「50gで4cmのびるA」「50gで6cmのびるB」「水平につり合わせた」「左端から何cm」に丸。「水平」は2本ののびが同じに直して書く → 同じのびに必要な力は A：B＝6：4＝3：2（逆比）。ここから400gの分け方と位置が決まる。

📚 前提知識

  • 元の長さが同じ2本のばねが同じのびになるとき、力の比は「同じ力でののびの比」の逆比（解答冊子）。
  • 棒の重さがないので、400gはA・Bの2本で分けて支える。おもりは、力の大きい方のばねに近い所につるす。

🔍 こう読み解く

  1. Aののび：Bののび＝4：6＝2：3 → 同じのびにする力は A：B＝3：2。
  2. 400gを3：2に分ける → A＝400×3/5＝240g、B＝160g。
  3. おもりから各ばねまでの距離は力の逆比 → Aまで：Bまで＝2：3。20cm×2/5＝8cm（左端＝A側から）。
答え：8cm
コツ：逆比を2回使う（のび→力、力→距離）。「大きい力のばねに近い」で向きを確かめてから答える。

K20 (6) 2つのばねの長さ 条件文・計算

👀 まず見るところ

【条件文】(5)と変わった部品は「何cmになっている」＝のびではなく長さ。「元の長さ20cm＋のび」に直して書く。のびは(5)で出したA＝240gから、4cm×(240÷50)で決まる。

📚 前提知識

  • ばねののびは力に比例する（50gで4cm → 240gなら4×240/50）。
  • 水平につり合っているので、AとBののびは等しい。片方で出せば両方の答え。

🔍 こう読み解く

  1. Aののび＝4×240/50＝19.2cm。
  2. 長さ＝20＋19.2＝39.2cm。
  3. 検算：Bののび＝6×160/50＝19.2cm。同じなので水平で合っている。
答え：39.2cm
コツ：答えを書く直前に「のび」か「長さ」かの丸を見直す。19.2と書いて終わるのがいちばん多い失点。

K20 (7) ふりこの長さと周期の表 資料問題・計算

👀 まず見るところ

【資料問題】正体を1行「ふりこの長さ(cm)と周期(秒)」。表の中で 25→100（4倍）で 1.0→2.0（2倍） の組を見つける → 「長さ4倍で周期2倍、9倍で3倍」の決まりを表の横に書く。AもBもこの決まりに当てはめるだけ。

📚 前提知識

  • ふりこの周期は長さだけで決まり、長さを（2×2）倍にすると周期は2倍、（3×3）倍にすると3倍になる（解答冊子）。

🔍 こう読み解く

  1. A：200cmは50cmの4倍（2×2）→ 周期は1.4×2＝2.8秒。
  2. B：周期3.0秒は25cmの1.0秒の3倍 → 長さは25×3×3＝225cm。
答え：A 2.8　B 225
コツ：表の中に「きれいな倍」の組（25と100、25と225）をさがす。1.4や1.7から計算しようとしない。

K20 (8) 鉄粉3gをちょうどとかす塩酸の量 資料問題・計算

👀 まず見るところ

【資料問題】正体を1行「鉄粉3gに入れた塩酸(cm³)と気体(cm³)」。25→375、50→750、75→1125 は1：15で増え続けるのに、100→1200 だけ1500にならない → ここで鉄が全部とけて塩酸が余った。「気体1200cm³＝鉄3g分」に直して書く。

📚 前提知識

  • 鉄＋塩酸→水素。気体の量は「少ない方」で決まる。塩酸が少ないうちは塩酸に比例し、鉄がなくなると気体はそれ以上増えない。

🔍 こう読み解く

  1. 塩酸25cm³ → 気体375cm³ なので、塩酸1cm³あたり気体15cm³（1：15）。
  2. 鉄3gが全部とけたときの気体は1200cm³ → 塩酸は 1200÷15＝80cm³。
答え：80cm³
コツ：表は「比がくずれた所」をさがすために見る。100cm³の1200が「余った」の合図。

K20 (9) 塩酸100cm³に鉄粉4gを入れたときの気体 条件文・計算

👀 まず見るところ

【条件文】(8)と変わった部品は「塩酸100cm³」「鉄粉4g」に丸。先に「どちらが余るか」を決める。(8)の「鉄3g＝塩酸80cm³」を横に置き、鉄4gに必要な塩酸（80×4/3＝約107cm³）が100より多い → 塩酸が足りない側、気体は塩酸で決まる。

📚 前提知識

  • ちょうど反応する組は「鉄3g：塩酸80cm³：気体1200cm³」。2つの材料があるときは、比べて少ない方に合わせて気体が出る（解答冊子の図：鉄×4/3、塩酸×5/4 → 小さい倍率の塩酸に合わせる）。

🔍 こう読み解く

  1. 鉄：3g→4g は×4/3。塩酸：80→100 は×5/4。小さいのは塩酸の5/4。
  2. 気体＝1200×5/4＝1500cm³（鉄が余る）。塩酸1cm³あたり15cm³で 100×15＝1500 と出しても同じ。
答え：1500cm³
コツ：「4g」を見て1200×4/3＝1600と書きたくなる。先に塩酸が足りるかを確かめる1行を入れる。

K20 (10) 酸素はどちらから出るか 知識問題

イ（うすい過酸化水素水）。酸素は過酸化水素→酸素＋水の分解で、過酸化水素水の中から出る。二酸化マンガンは反応を速める触媒で、自分は変化せず減らない（解答冊子）。「二酸化マンガンは何回でも使える」とセットで覚える。
答え：イ

K20 (11) 種子植物ではないもの 知識問題

エ・オ。ヒジキは海そう（ソウ類）、ワラビはシダ類で、どちらも胞子でふえるので種子植物ではない。ソテツとイチョウは花がめだたないが種子でふえる裸子植物なので、ひっかけ。チューリップは被子植物。
答え：エ・オ

K20 (12) 光合成をしないもの 知識問題

イ・エ。アオカビとシイタケは菌類（カビ・キノコの仲間）で、胞子でふえるが葉緑体がなく光合成をしない（解答冊子）。ゼニゴケ（コケ類）とワカメ（ソウ類）は緑色で光合成する。ヤドリギは他の木に寄生するが、緑の葉をもち光合成もするのでひっかけ。
答え：イ・エ

K20 (13) 昆虫をすべて選ぶ 知識問題

ウ・オ・カ。アブラムシ・ゴキブリ・ノミは昆虫（あし6本・体が頭・胸・腹）。ミジンコ・フナムシ・ワラジムシは名前に「ムシ」がついてもエビやカニと同じ甲殻類（解答冊子）。「ムシ」の名前で決めないで、あしの数で分ける。
答え：ウ・オ・カ

K20 (14) エビ・カニと昆虫が同じ（　）動物 知識問題

節足動物。体やあしに節があるのが共通の特徴で、昆虫類・甲殻類（エビ・カニ）・クモ類・多足類（ムカデ）をまとめた大きなグループ。漢字2字指定。
答え：節足

K20 (15) 胸と腹の間にある、肺を動かす筋肉の膜 知識問題

横隔膜。肺と胃の間にある筋肉の膜で、息を吸うときは下がり（胸が広がって空気が入る）、はくときは上がる（解答冊子）。肺そのものは筋肉がなく自分では動けない、とセットで覚える。
答え：横隔膜

K20 (16) 川の曲がり・外側と内側の作用 知識問題

① ア（侵食と運搬）、② イ（堆積）。曲がった所では外側は流れが速く、けずって運ぶ（侵食・運搬）はたらきがさかん。内側は流れがおそく、土砂がたまる（堆積）。「速い＝けずる、おそい＝たまる」の1組で決まる。
答え：① ア　② イ

K20 (17) 川の曲がったところの川底 知識問題

イ。外側は流れが速いので深くけずられ、小さい石は下流へ運ばれて大きな石が残る。内側はおそいので浅く、小さな石がたまる（解答冊子）。「外側が深い＋外側に大きい石」の両方を満たす図がイ。エは内側が深いので逆。アは外側が深いが大きい石が内側の岸に寄っていて、ウは左右が同じ形。
答え：イ

K20 (18) 北極側から見た公転と自転の向き 知識問題

エ（公転も自転も左回り）。北極の上から見おろすと、地球の自転も太陽のまわりの公転も反時計回り＝左回り。太陽が東からのぼるのは自転が西→東（左回り）だから、と結びつける。「自転と公転は同じ向き」なのでアかエにしぼり、右か左かは日の出の向きで決める。
答え：エ

K20 (19) 福岡市と水戸市の南中時刻の差 条件文・計算

👀 まず見るところ

【条件文】部品は「東経130度」「東経140度」と、答え方の「どちらの方が何分早く」に丸。北緯34度・36度は南中時刻に関係ないので使わない。「経度差10度」を「1度＝4分」に直して書く → 差は40分。早いのは東側。

📚 前提知識

  • 地球は24時間で360度自転するので、経度1度で4分ずれる（360÷24＝15度で1時間）。
  • 太陽は東からのぼるので、東にある町ほど南中が早い。緯度は南中高度を変えるが、時刻は変えない。

🔍 こう読み解く

  1. 経度差＝140−130＝10度（解答冊子）。
  2. 時刻の差＝4×10＝40分。東経の大きい水戸市が東 → 水戸市が早い。
答え：水戸市が40分
コツ：緯度の数字は消して、経度だけ丸をつける。「東が早い」を余白に書いてから町の名前を書く。

K20 (20) 海岸付近で昼間に吹く風 知識問題

海風。昼は陸の方が海より温まりやすく、陸の空気が上がって海から陸へ風が吹く。夜は逆に陸が冷えて陸から海への陸風（解答冊子）。風の名前は「吹いてくる方」でつける、と覚える。
答え：海風
