WC 全体像 火山と地震 10問（各10点・100点）

前半(1)〜(3)は火山の知識、(4)は地震の穴うめ、(5)は地震計の記録を読む問題。(5)は「初期微動の始まり＝P波の到着、主要動の始まり＝S波の到着」と決めて、2地点の時刻を読めば、発生時刻も80km地点の秒数も同じ手順で出せる。

今回は80／100点。落とした2問は (1)② 有珠山の形（知識）と (4)② 活断層（本文の「内陸」を拾えなかった）。計算の(5)は全問正解。

WC (1)① ハワイ島の火山のマグマのねばりけ 知識問題

ウ（最も小さい）。ハワイ島の火山は、ねばりけの小さいマグマが遠くまで流れて平らに広がった形（盾状火山）。ねばりけは 小＝ハワイ島／中＝浅間山／大＝有珠山 の3つを一組で覚える。
答え：ウ
今回：ウ ○。

WC (1)② 有珠山に最も近い断面図 資料問題・図を選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「Cの火山」（＝有珠山）に丸と、3つの図の正体「ねばりけのちがいで変わる火山の形」を1行。①で「ハワイ＝ねばりけ最小＝平ら」と決めているので、残りは「浅間山＝中＝円すい／有珠山＝大＝盛り上がる」→ いちばん盛り上がった形が答え。

📚 前提知識

  • ねばりけが大きいマグマは流れにくく、火口のすぐそばで固まってドーム状に盛り上がる（有珠山・昭和新山）。
  • ねばりけが中くらいだと、噴火をくり返して溶岩と火山灰が重なり、円すい形になる（浅間山・富士山）。小さいと、うすく広がって平らになる（ハワイ島）。

🔍 こう読み解く

  1. ウ＝平らに広がる → ねばりけ最小のハワイ島（A）。
  2. ア＝急な円すいに何層も重なる → ねばりけ中くらいの浅間山（B）。
  3. イ＝火口にねばいマグマが盛り上がったドーム → 有珠山（C）。
答え：イ
今回：ア ×。知識＝「有珠山＝ねばりけが大きい」が出てこず、円すい形のアを選んだ。①でハワイを「最小」と決められているので、次は残りの2つを「浅間山＝中・有珠山＝大」と書いてから図を見る。
コツ：図は「平ら／円すい／盛り上がり」の3段で、ねばりけ 小→中→大 と対応する。ねばりけが大きいほど高く盛り上がる、と向きをそろえておく。

WC (2) 火山ガスに最も多く含まれる気体 知識問題

オ（水蒸気）。火山ガスの大部分は水蒸気で、二酸化炭素や二酸化硫黄、硫化水素は残りの少しの部分。「火山ガス＝有毒な気体」と思うと二酸化硫黄を選びたくなるが、量でいちばん多いのは水蒸気。
答え：オ
今回：オ ○。

WC (3) マグマが冷えてできたのではないもの 知識問題

オ（石灰岩）。石灰岩はサンゴや貝の死がいが海底に積もってできた堆積岩。火山灰・軽石は噴火でふき出したマグマのかけら、カコウ岩・アンザン岩はマグマが固まった火成岩なので、どれもマグマ由来。石灰岩だけが仲間外れ。
答え：オ
今回：オ ○。

WC (4)①② 地震の文の穴うめ 素材文・用語

👀 まず見るところ

【素材文】設問は「当てはまる言葉」。部品は①の直前「地震の規模をあらわす」と、②の直前「内陸で発生する」「ずれる」に丸 → 規模＝マグニチュード、内陸でずれるもの＝活断層と決まる。

📚 前提知識

  • マグニチュード＝地震そのものの規模（エネルギーの大きさ）。震度＝その場所のゆれの強さ。「規模」と来たらマグニチュード、「ゆれの強さ」なら震度。
  • 活断層＝過去にくり返しずれて、これからもずれるおそれのある断層。本文は「プレートがもぐりこむ部分で起こる海溝型」と「内陸で活断層がずれる地震」の2種類を対比している。

🔍 こう読み解く

  1. ①：「震源が深く」「規模」「海溝型」→ 海溝型は規模の大きい地震 → マグニチュードが大きくなる。
  2. ②：本文は前半（プレート・海溝型）と後半（内陸）を分けて書いている。「内陸で」「ずれる」のは活断層。プレートは前半の言葉なので②には入らない。
  3. 例の兵庫県南部地震・熊本地震は、どちらも内陸の活断層で起きた地震。
答え：① マグニチュード　② 活断層
今回：① マグニチュード ○　② プレート ×。部品を拾えなかった＝「内陸で発生する」に丸がなく、前の文に出た「プレート」を持ってきた。「内陸」「ずれる」の2語に丸をつければ、プレートは消えて活断層に決まる。

WC (5)①② 地震計の記録のA・Bのゆれ 資料問題・用語

👀 まず見るところ

【資料問題】部品は図の正体「震源距離120kmと200kmの2地点の地震計の記録・横軸は時刻」を1行と、矢印Aが「小さなゆれの区間」、Bが大きなゆれの始まり。先に来る小さいゆれ＝初期微動、あとの大きいゆれ＝主要動。

📚 前提知識

  • 地震のゆれは速いP波が先に届いて小さくゆれ（初期微動）、おそいS波が届くと大きくゆれる（主要動）。
  • Aの長さ＝初期微動継続時間。震源から遠い地点ほど長い（200km地点のAは120km地点より長い）。

🔍 こう読み解く

  1. 200km地点の記録：20時46分35秒ごろから小さくゆれ始め（A）、47分00秒から大きくゆれる（B）。
  2. 先に届くP波のゆれ＝初期微動、あとから届くS波のゆれ＝主要動。
  3. 120km地点の記録も同じ形で、近いぶんAが短い。
答え：① 初期微動　② 主要動
今回：しょきびどう ○　主ようどう ○。ひらがなでも正解になっているが、テストでは「初期微動」「主要動」と漢字で書けるようにしておく。

WC (5)③ 地震が発生した時刻 資料問題・計算

👀 まず見るところ

【資料問題】部品は図の正体「震源距離120kmと200kmの2地点」と、目盛りの正体「破線1本＝5秒」（30秒が6つに分かれている）を1行。2地点の初期微動の始まり（P波の到着時刻）を読み、その差からP波の速さを出す → 120km地点から逆算すると発生時刻が決まる。

📚 前提知識

  • P波の速さ＝距離の差÷到着時刻の差。2地点あれば出せる。
  • 発生時刻＝到着時刻−（震源距離÷速さ）。余白に「速さ→かかった時間→引く」と書いてから計算する。

🔍 こう読み解く

  1. 初期微動の始まりを読む：120km地点＝20時46分25秒、200km地点＝20時46分35秒。
  2. P波は80kmを10秒で進む → 8km／秒。
  3. 120km地点まで 120÷8＝15秒。46分25秒の15秒前 → 20時46分10秒。
  4. 検算：200km地点は 200÷8＝25秒 → 46分35秒−25秒＝46分10秒。合う。
答え：20時46分10秒
今回：20時46分10秒 ○。
コツ：主要動の始まり（120km＝46分40秒、200km＝47分00秒）でS波の速さを出しても同じ。80km÷20秒＝4km／秒、120÷4＝30秒 → 46分10秒。P・Sどちらで出しても発生時刻が一致するのが検算になる。

WC (5)④ 80km地点の初期微動の長さ 条件文・計算

👀 まず見るところ

【条件文】部品は「震源距離が80km」と、求めるもの「Aのゆれは何秒間」（＝初期微動継続時間）に丸。図から「120kmで15秒」を読んで横に書く → 初期微動継続時間は震源距離に比例、で決まる。

📚 前提知識

  • 初期微動継続時間＝S波の到着−P波の到着。P波もS波も同じ距離を進むので、この差は震源距離に比例する。

🔍 こう読み解く

  1. 120km地点：初期微動46分25秒〜主要動46分40秒 → 15秒。200km地点：46分35秒〜47分00秒 → 25秒。120：200＝15：25＝3：5 で比例を確かめる。
  2. 80kmは120kmの3分の2 → 15×2／3＝10秒。
  3. 検算：P波は 80÷8＝10秒後（46分20秒）、S波は 80÷4＝20秒後（46分30秒）に届く。差は10秒。
答え：10秒間
今回：10 ○。
