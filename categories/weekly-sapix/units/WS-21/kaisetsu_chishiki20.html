K20 全体像 知識の20題 各5点×20問（100点）

物理（(1)〜(7)）・化学（(8)〜(10)）・生物（(11)〜(15)）・地学（(16)〜(20)）が5問ずつ。計算は(3)〜(9)の7問で、どれも「使う式を余白に書いてから数字を入れる」だけで決まる（てこ＝力×うでの長さ、ばね＝のび÷1gあたり、ふりこ＝長さ1/4で周期1/2、中和＝比例）。

知識問題は(11)〜(15)と(20)。用語は漢字で書けるようにしておく（胚珠・気管・触角・肺胞）。まだ解いていないテストなので、下の各カードは「自分で解くときのチェック」として使う。

K20 (1) S極とS極の間の方位磁針 資料問題・図を読む

👀 まず見るところ

【資料問題】部品は図1の正体「向かい合っているのはSとS」を1行書くこと。同じ極が両側にあるので、針のN極は左右から同じ力で引かれて打ち消し合う → 針は左右を向かない、と決まる。

📚 前提知識

  • 方位磁針の黒い方がN極。N極はS極に引かれ、N極とは反発する。
  • 左右の引く力が同じ大きさで逆向きなら、針を回す力は残らない。残るのは地球の磁力なので、針は方位磁針本来の向き（N極が北）で止まる。

🔍 こう読み解く

  1. 左の磁石は右端がS、右の磁石は左端がS。針のN極（黒）は左のSにも右のSにも同じ強さで引かれる。
  2. 左右の力が打ち消し合うので、針は磁石と直角の向き（上下）で止まる → ウかエ。
  3. 図に方角は書かれていないが、上を北と見る。黒（N極）が上を向いたウ。
答え：ウ
コツ：磁石の間に方位磁針を置く問題は、まず「向かい合う極が同じか、ちがうか」を書く。ちがう極なら針はN→Sに向かって横を向き、同じ極なら直角。

K20 (2) S極どうしの磁力線 資料問題・図の選択

👀 まず見るところ

【資料問題】部品は「図1の方位磁針を取り」（＝(1)と同じSとSの向かい合わせ）と、3つの図の2つのSの間の線の形。同じ極どうしは線がつながらず、間があいた図だけが残る。

📚 前提知識

  • 磁力線はN極から出てS極に入る。NとSが向かい合うと線が2つの極をつなぎ、SとS（同じ極）ではたがいに反発して線が曲がって離れる。

🔍 こう読み解く

  1. ア：2つのSの間を線が太くつないでいる → NとSのときの形 → ×。
  2. イ：間を横に線が通っている → やはりつながっている形 → ×。
  3. ウ：それぞれのSから出た線が、間でおし返されるように上下へ曲がり、真ん中に線のないすき間がある → ○。
答え：ウ

K20 (3) 3本の棒のつり合い・①のおもり 条件文・てこの計算

👀 まず見るところ

【条件文】部品は「どの棒も10gで、真ん中にひも」と「1個10g」。棒の重さは棒のまん中に矢印10gで置く（直して書く）。真ん中でつるした棒は左右のおもりが同じ重さになる → いちばん下の棒から順に上へ計算する。

📚 前提知識

  • 棒の真ん中を支点にすると、左右のうでの長さが同じなので左の重さ＝右の重さ。
  • ひもにかかる重さ＝その棒にぶら下がっている全部（おもり＋棒）。

🔍 こう読み解く

  1. いちばん下の棒：左に2個（20g）、右に2個（20g）。ひもにかかる重さは 20＋20＋10（棒）＝50g。
  2. 真ん中の棒：左に下の棒ごと50gがかかる。真ん中でつるしているので右の①も50g。
  3. 50÷10＝5個。
答え：5個
コツ：図の各ひもの横に「50g」「110g」と合計を書きこみながら上へ進むと、(4)がそのまま続きになる。

K20 (4) 3本の棒のつり合い・②のおもり 条件文・てこの計算

👀 まず見るところ

【条件文】部品は(3)で書いた「①のひも＝50g」と、真ん中の棒の「棒10g」。真ん中の棒全体の重さを上のひもに置く（直して書く）→ いちばん上の棒の左が決まり、右の②は同じ重さ。

📚 前提知識

  • 真ん中の棒のひもにかかる重さ＝左50g＋右50g＋棒10g。棒の重さを足し忘れると10gずれる。

🔍 こう読み解く

  1. 真ん中の棒のひも：50＋50＋10＝110g。
  2. いちばん上の棒は真ん中でつるしているので、右の②も110g。
  3. 110÷10＝11個。
答え：11個

K20 (5) 2本のばねでつるした棒・おもりの重さ 条件文・ばねの計算

👀 まず見るところ

【条件文】部品は「自然長18cm」「ばねが25.5cm」と、AとBで別々の「40gで5cm／40gで3cm」。まず 25.5−18＝7.5cm を図のA・Bの横に書く（直して書く）→ のびが同じでも、かたいBの方が大きい力を受けている。

📚 前提知識

  • ばねののびは力に比例。力＝40g×（のび÷40gあたりののび）。
  • おもりの重さ＝2本のばねが引き上げる力の合計（棒の重さはない）。

🔍 こう読み解く

  1. のびは 25.5−18＝7.5cm（A・B同じ）。
  2. A：40×7.5/5＝60g。B：40×7.5/3＝100g。
  3. おもり＝60＋100＝160g。
答え：160g
コツ：「25.5cm」をそのまま式に入れない。ばねの式に入るのは「のび」なので、最初に自然長を引く。

K20 (6) ばねBをつけた位置 条件文・てこの計算

👀 まず見るところ

【条件文】部品は(5)で出した「A 60g・B 100g」と「棒の真ん中におもり・15cm」。答え方は「右端から何cm」に丸。図のA・Bの上に60g・100gの矢印を置く（図に置く）→ おもりを支点にしたてこの式で決まる。

📚 前提知識

  • 棒が水平なら、おもりの位置を支点にして左回り＝右回り（力×うでの長さ）。
  • 大きい力の方が支点に近い。Bは100gなので、Aの15cmより近い。

🔍 こう読み解く

  1. おもりを支点に、A：60×15＝900。
  2. B：100×□＝900 → □＝9cm（おもりからBまで）。
  3. 右端はおもりから15cmなので、右端からは 15−9＝6cm。
答え：6cm
コツ：9cmと書いて終わりにしない。答え方の「右端から」に丸をつけておくと、最後にもう一段の引き算に気づける。

K20 (7) くぎに当たるふりこの1往復 条件文・ふりこの計算

👀 まず見るところ

【条件文】部品は「周期2.4秒」「天井からくぎまでは長さの3/4」。くぎの下の短いふりこの長さは 1−3/4＝1/4 と直して書く → 長さ1/4なら周期は1/2＝1.2秒、と決まる。

📚 前提知識

  • ふりこの周期は長さで決まる。長さが1/4倍になると周期は1/2倍（4倍で2倍）。
  • A→BとB→A（1往復の前半と後半）は長いふりこ、B→C→Bは短いふりこの動き。それぞれの周期の半分ずつを足す。

🔍 こう読み解く

  1. Aのふりこの長さを4とすると、くぎの下のふりこは 4−3＝1。長さ1/4なので周期は 2.4×1/2＝1.2秒。
  2. A→B→Aは長いふりこの半周期 2.4÷2、B→C→Bは短いふりこの半周期 1.2÷2。
  3. (2.4＋1.2)×1/2＝1.8秒。
答え：1.8秒

K20 (8) 石灰石1.0gをちょうどとかす塩酸 資料問題・表の比例

👀 まず見るところ

【資料問題】部品は表1の正体「石灰石1.0g・塩酸cm³→気体cm³」を1行書き、気体が「増えなくなる値220」に丸。20→50、40→100と比例している間は石灰石が余っている → 220に達したところが「ちょうど」。

📚 前提知識

  • 塩酸が足りない間は、気体は塩酸の量に比例（20cm³で50cm³）。石灰石を使い切ると、塩酸を増やしても気体は増えない。

🔍 こう読み解く

  1. 表の最後、80→100で気体が200→220と伸びが止まっている。最大は220cm³。
  2. 比例している区間で「塩酸20cm³：気体50cm³」。220は50の4.4倍。
  3. 塩酸も4.4倍で 20×4.4＝88cm³。
答え：88cm³
コツ：表の右端の数字（220）が「限界」の合図。限界の値から比例で戻ると、ちょうどの量が出る。

K20 (9) 塩酸40cm³のとき残る固体 条件文・比例の計算

👀 まず見るところ

【条件文】部品は「塩酸100cm³で固体1.1g」と「残った液を取り出して」。100cm³は(8)の88cm³より多い＝石灰石は全部とけている、と直して書く → 1.1gは石灰石1.0gが全部変わった固体（塩化カルシウム）の量と決まる。

📚 前提知識

  • 石灰石＋塩酸 → 二酸化炭素＋塩化カルシウム（水にとける固体）。液を蒸発させると塩化カルシウムだけが残る。塩酸は蒸発して残らない。
  • 塩酸40cm³では石灰石が余るが、「液を取り出す」ので余った石灰石は固体に入らない。

🔍 こう読み解く

  1. 塩酸88cm³ ⇔ 固体1.1g（石灰石1.0gがすべて反応したとき）。
  2. 40cm³は88cm³の 5/11倍。反応した石灰石も5/11。
  3. 固体＝1.1×5/11＝0.5g。
答え：0.5g
コツ：「100cm³で1.1g」を「100：1.1」の比例に使わない。基準にするのは、ちょうど反応する88cm³。

K20 (10) 豆電球が明るくつく水溶液 素材文・2つ選ぶ

👀 まず見るところ

【素材文】部品は設問の「明るくついた」と「2つ」に丸。「電気を通す」ではなく「とても通しやすい」水溶液を聞いている → 食塩水と強い酸・強いアルカリだけが候補。

📚 前提知識

  • 電気を通すのは、酸・アルカリ・食塩の水溶液（電解質）。砂糖水は通さない。
  • その中でとくに通しやすいのは食塩水と、強い酸・強いアルカリ（塩酸・水酸化ナトリウム水溶液）。炭酸水・重そう水・アンモニア水は弱い。

🔍 こう読み解く

  1. イ 砂糖水は通さない → 消す。
  2. 残り5つのうち、弱い酸（炭酸水）・弱いアルカリ（重そう水・アンモニア水）は暗くしかつかない。
  3. 明るくつくのは ア 食塩水と エ 水酸化ナトリウム水溶液。
答え：ア・エ（順不同）

K20 (11) 裸子植物を選ぶ 知識問題

ア（モミ）。裸子植物はマツ・スギ・イチョウ・ヒノキ・モミ・ソテツなど、針のような葉の木が中心。クスノキ・シイ・クリは双子葉類、タケは単子葉類で、どれも被子植物。「すべて選ぶ」だが当てはまるのはモミ1つだけ。
答え：ア

K20 (12) 裸子植物で「むき出し」のもの 知識問題

胚珠。裸子植物は胚珠が子房に包まれず、むき出しになっている植物。被子植物は胚珠が子房の中にあり、子房が果実になる。裸＝はだか＝むき出し、と字で結びつける。漢字2字。
答え：胚珠

K20 (13) 昆虫の呼吸をする部分 知識問題

気管。昆虫は胸や腹にある気門（穴）から空気を取りこみ、体の中に張りめぐらされた気管で呼吸する。穴＝気門、管＝気管、と字で分ける。設問は「穴からつながっている部分」なので気管。漢字2字。
答え：気管

K20 (14) 昆虫がにおいや味を感じる部分 知識問題

触角。頭についている触角でにおいや味を感じ取る。昆虫の体は頭・胸・腹の3つ、足は6本で胸につく、と一緒に思い出す。「触覚」（感覚の名前）ではなく体の部分の「触角」。漢字2字。
答え：触角

K20 (15) 肺の中の小さな袋 知識問題

肺胞。肺の中で毛細血管に囲まれた小さな袋で、ここで酸素と二酸化炭素を交換する。数が多く（解答冊子では3億〜5億個）表面積が大きいので、効率よく交換できる。小腸の柔毛と同じ「表面積を大きくする仕組み」。漢字2字。
答え：肺胞

K20 (16) 8月22日の日の出の位置 資料問題・図を読む

👀 まず見るところ

【資料問題】部品は図5の正体「毎月22日の日の出の位置・7つ」を1行書き、両端を先に決める。ア＝6月22日（夏至・北寄り）、キ＝12月22日（冬至・南寄り）→ 8月はアから2つ目と決まる。

📚 前提知識

  • 夏至をはさんで同じ月数だけ離れた月は同じ位置。5月と7月＝イ、4月と8月＝ウ、2月と10月＝オ、1月と11月＝カ。

K20 (18) 図6の月は新月から何日目 資料問題・月の形

👀 まず見るところ

【資料問題】部品は図6の正体「右側が少し欠けた、ほぼ満月」を1行書くこと。満月（15日）より少し過ぎ、下弦の月（22日）にはまだ遠い → 選択肢で15と22の間は18日だけ、と決まる。

📚 前提知識

  • 月齢の目安：新月0 → 三日月3 → 上弦7〜8 → 満月15 → 下弦22 → 新月29〜30。
  • 満月のあとは右側から欠けていく（下弦は左半分が光る）。右が欠けた丸に近い月は15〜22の間。

🔍 こう読み解く

  1. 図6は丸に近く、右のふちだけ点線＝右側が少し欠けている。
  2. 満月（15）を過ぎて下弦（22）の前 → 選択肢ではオ 18日だけ。
答え：オ
コツ：「どちら側が欠けているか」を先に書く。左が欠けていれば満月前（11日ごろ・ウ）と取りちがえる。

K20 (19) 図6の月は何時ごろ 条件文・月の時刻

👀 まず見るところ

【条件文】部品は(18)の「月齢18」と、設問の「地平線のすぐ近く」に丸。月齢18の南中は3時ごろ、と直して書く → 地平線の近く＝のぼる直前後なら南中の6時間前、と決まる。

📚 前提知識

  • 月の南中時刻は月齢1につき約50分（12日で約10時間）遅れる。満月（15）は0時ごろ、下弦（22）は6時ごろ、月齢18は3時ごろ。
  • 東からのぼるのは南中の約6時間前、西にしずむのは約6時間後。

🔍 こう読み解く

  1. 月齢18 → 南中は3時ごろ。
  2. 地平線近くの月＝東からのぼってきたところ（解答冊子の説明）→ 3−6＝−3 → 前日の21時ごろ。
  3. 選択肢に「しずむ側」の9時はないので、のぼる側の21時で決まる → カ。
答え：カ

K20 (20) 水の侵食でできる地形 知識問題

イ（V字谷）・エ（三日月湖）。V字谷は流れの速い上流で川底をけずってできる谷。三日月湖は中流〜下流で川が大きく蛇行し、侵食と堆積で流れが変わって取り残された湖。扇状地（谷の出口）と三角州（河口）は運ばれた土砂が積もる堆積の地形。順不同。
答え：イ・エ

K20 まとめ 解くときのチェック3つ

  • 計算7問は式を先に余白に書く。てこ＝「真ん中でつるす＝左右同じ重さ」「力×うでの長さ」／ばね＝まず自然長を引いて「のび」にする／ふりこ＝長さ1/4で周期1/2／中和＝限界の値（220）から比例。
  • 答え方の指示に丸：(6)「右端から」・(10)(20)「2つ」・(11)「すべて」。合っている計算を最後の1行で落とさない。
  • 用語は漢字で：胚珠・気管・触角・肺胞。図5は7つの○に月を書きこみ、図6は「どちら側が欠けているか」を先に書く。
