L (1)吸収・放出量 図1を表に写す 資料問題・グラフの読み取り

👀 まず見るところ

【資料問題】部品は図1の正体「光の強さに対する1時間あたりの二酸化炭素の吸収量もしくは放出量」を1行、それと※の「放出量が2のとき「−2」」に丸。0より下は放出、上は吸収、と決めてから目もりを読む。

📚 前提知識（あれば答え合わせに使う）

  • たて軸の目もりは2きざみ。0の線より上が「吸収」、下が「放出」で、放出はマイナスで書く決まり（※印）。
  • 折れ線が水平になったところから先は、どれだけ光を強くしても値が変わらない。

🔍 こう読み解く

  1. 光の強さ0 → −2（本文に書いてある）。2 → 0（本文「吸収も放出もしていません」）。
  2. 4 → 2、6 → 4、8 → 6。ここまで2ずつ増える直線。
  3. 8から先は水平なので、10 → 6、12 → 6。
答え：0・2・4・6・6・6（光の強さ2〜12の順）
自分で解くときのチェック：8より右が水平になっているか。10と12は直線をのばして「8」「10」とせず、6のままにする。

L (1)呼吸 呼吸による放出量の行 素材文・本文の決まり

👀 まず見るところ

【素材文】部品は本文2行目「光の強さに関係なく、一日中呼吸を行い、一定量の二酸化炭素を放出」に丸 → 3語で「呼吸＝ずっと−2」と書く。この行は光の強さが変わっても全部同じ値と決まる。

📚 前提知識

  • 呼吸は昼も夜も、明るくても暗くても同じ速さで続く。光の強さ0のときの値（−2）が、そのままこの植物の呼吸量になる。

🔍 こう読み解く

  1. 光の強さ0の欄に「−2」と書いてある。これが呼吸だけのときの値。
  2. 「関係なく」「一定量」なので、2〜12もすべて −2。
答え：−2・−2・−2・−2・−2・−2（すべて−2）
自分で解くときのチェック：「放出量」の行なので、−の記号をつけているか。※印の決まりを見て「−2」と書く。

L (1)光合成 光合成による吸収量の行 まざり型・引き算

👀 まず見るところ

【まざり型→条件文】部品は本文「この二酸化炭素の量は、光合成と呼吸の両方のはたらきを合わせた量」→ 式に直して書く：光合成の吸収量＝グラフの値＋2。上の2行から、この行は全部決まる。

📚 前提知識

  • グラフの値＝光合成で吸う量 − 呼吸で出す量。呼吸の2はいつも引かれているので、光合成そのものはグラフより2だけ大きい。本文の「光の強さ8のとき、呼吸で2放出・光合成で8吸収、グラフでは6」がその見本。

🔍 こう読み解く

  1. 使う式：光合成 ＝ 吸収・放出量 ＋ 2。
  2. 光の強さ2 → 0＋2＝2。4 → 2＋2＝4。6 → 4＋2＝6。8 → 6＋2＝8。
  3. 10・12はグラフが6のままなので、どちらも 6＋2＝8。
答え：2・4・6・8・8・8（光の強さ2〜12の順）
自分で解くときのチェック：光の強さ8の欄が本文の「8吸収」と一致しているか。1か所合えば式が正しい。

L (2)図2・図3 表をグラフに表す 資料問題・作図

👀 まず見るところ

【資料問題】部品は表の正体「光の強さに対する二酸化炭素の吸収・放出量」（植物A・B）と、表の中で値が変わらなくなる場所（Aは16から12のまま、Bは10から4のまま）。ここが折れ点になる。点を全部打ってから直線でつなぐ。

📚 前提知識

🔍 こう読み解く

  2. 図3（植物B）：0で−1から出発し、2ごとに1ずつ上がる。10で4に着き、その先は4の水平線。
  3. 2本とも「右上がり → 折れ点 → 水平」の形になっているかを最後に見る。
答え：図2＝(0,−4)から右上がりに(16,12)まで直線、以後12で水平／図3＝(0,−1)から右上がりに(10,4)まで直線、以後4で水平
自分で解くときのチェック：0の線を横切る点（Aは4、Bは2）と折れ点（Aは16、Bは10）の4か所に点が打ってあるか。この4点は(3)(4)でそのまま使う。

L (3)① 植物Aが成長する光の強さ 資料問題・0を横切る点

👀 まず見るところ

【資料問題】部品は聞かれ方「成長するには」「いくつより強ければ」に線。本文の最後「放出より吸収が多いため…成長できる」を3語で「成長＝0より上」と書く → 図2で線が0を横切る光の強さが答え。

📚 前提知識

  • グラフが0＝呼吸で使う分と光合成でつくる分が同じ。この点（光補償点）より光が強いと、つくる分が余って成長に回る。

🔍 こう読み解く

  1. 植物Aの表で、値が0になる光の強さをさがす → 4。
  2. 4より強いと値がプラス（吸収のほうが多い）→ 成長できる。
答え：4
自分で解くときのチェック：「4以上」でなく「4より強い」。ちょうど4では枯れも成長もしない、と本文の光の強さ2の説明と同じ形で確かめる。

L (3)③ AとBが同じように成長する光の強さ 資料問題・2本の交わる点

👀 まず見るところ

【資料問題】部品は聞かれ方「同じように成長する」に線 → 直して書く：「吸収・放出量が同じ」＝2本のグラフが交わる点。図2と図3を重ねるか、2つの表で同じ値の列をさがす。

L (4)陽生・陰生 陽生植物と陰生植物 素材文＋資料問題

👀 まず見るところ

【素材文】設問の定義を3語で書く：「日光がよく当たるところでよく成長」＝陽生＝強い光で大、「日光があまり当たらないところでも成長」＝陰生＝弱い光でも＋。あとは③で見た「6より左はB、右はA」にあてはめる。

📚 前提知識

  • 陰生植物は0を横切る点が小さく（弱い光でもプラス）、頭打ちも低い。陽生植物は0を横切る点が大きいかわりに、強い光で大きく伸びる。

🔍 こう読み解く

  1. 弱い光（2〜6）：Bは2でもう0を超えるが、Aは4まで放出のほうが多い → 日陰でも成長できるのはB＝陰生。
  2. 強い光（6より上）：Aは12まで伸びるがBは4で頭打ち → 日光がよく当たると大きく成長するのはA＝陽生。
答え：陽生＝植物A　陰生＝植物B
自分で解くときのチェック：「頭打ちが高いほう＝陽生」「0を横切る点が小さいほう＝陰生」の2つが同じ答え（A・B）を指しているか。片方だけで決めない。

L まとめ 未解答（自分で解くときの順番）

  • 本文から3つの決まりを3語で書く：「呼吸＝ずっと−2」「グラフ＝光合成−呼吸」「成長＝0より上」。(1)〜(4)の全部がこの3行から出る。
  • グラフでは0を横切る点と折れ点（頭打ち）の2か所に点を打つ。(3)は横切る点と交点、(4)は横切る点の小ささと頭打ちの高さで決まる。
  • 聞かれているのが「光の強さ」（横）か「吸収・放出量」（たて）かを、答えを書く直前にもう一度見る。

光合成を、光を使うしくみ㋐（水 → 酸素と◎）と、二酸化炭素を使うしくみ㋑（◎と△ → デンプン）の2段に分けた図が出発点。知識で答えるより、図1の矢印をたどって「何がそろえば動くか」を書き出す問題である。

H・光合成のしくみ (1)①② AとBの時間帯で起こっているしくみ まざり型・選択

👀 まず見るところ

【まざり型→条件文】部品は「実験開始時には△のみ」と、図2の各時間帯の「光あり／なし」「二酸化炭素あり／なし」。上の表に当てはめて、㋐と㋑に○×を1つずつ書く（直して書く）→ 選択肢が決まる。

H・光合成のしくみ (2) 光がないCで二酸化炭素を吸収した理由 記述

👀 まず見るところ

【まざり型→資料問題】部品は図2のCの「わずかな時間」と、すぐ前のBで㋐だけ動いていたこと。Bでたまった◎をCで使った、と1行で書く → 答案の骨組みが決まる。

📚 前提知識

  • ㋑に必要なのは光そのものではなく、㋐がつくった◎と二酸化炭素。◎が残っていれば、暗くても㋑は動ける。

✍️ 答案の組み立て

  1. 要素A：Bの時間帯に㋐で◎がつくられた（Bは光あり・二酸化炭素なしなので、◎が使われずにたまる）。
  2. 要素B：その◎を使って、Cでしくみ㋑が起こった（Cは二酸化炭素ありなので㋑が動ける）。
  3. 吸収が「わずかな時間」で止まるのは、光がなく新しい◎がつくられず、たまった◎がなくなるから。答案には入れなくてよいが、理由がそろっているかの確認に使える。
模範解答：Bの時間帯でしくみ㋐によりつくられた◎を利用して、しくみ㋑が起こったから。
自分で解くときのチェック：「光がないのに」と聞かれたら、光の代わりになる「前の時間帯でたまったもの」を図の上で探す。

H・光合成のしくみ (3)ア・イ ㋐と㋑はどちらが先か 資料問題・○×

👀 まず見るところ

🔍 こう読み解く

ブナの陽葉（上の層）と陰葉（下の層）のちがいと、葉を食べる虫の話。長い本文だが、答えの部品は3か所に集まっている。図1の2本のグラフと矢印、図2の葉の大きさ・厚さ、本文の「陰葉から食べ始める」。

H・光環境と光合成 (1)① 図1のAとBはどちらが陽葉か 資料問題・グラフ

👀 まず見るところ

【資料問題】部品はグラフの正体「同じ面積あたり・光の強さと二酸化炭素の吸収量」と、右の「強」の側の高さ。光が強いほど多く吸収し続けるAが、日当たりのよい陽葉と決まる。

📚 前提知識（あれば答え合わせに使う）

  • 陽葉は上の層で強い光を受ける葉、陰葉は下の層で弱い光しか受けない葉。

🔍 こう読み解く

  1. 光が強い側で、Aは高いところまで上がり、Bは低いところで横ばいになる → 強い光を使いこなせるのはA。
  2. 矢印でも確かめられる：矢印にAやBの名前はないが、右の矢印（強い光）はAの線の上、左の矢印（弱い光）はBの線の上をさしている。日中に強い光を受けるA＝陽葉、弱い光しか受けないB＝陰葉。
答え：陽葉 A　陰葉 B

H・光環境と光合成 (1)② 図2のアとイはどちらが陽葉か 資料問題・図

👀 まず見るところ

【資料問題】部品は図2の表の「葉の大きさ」「葉の厚さ」の2行。光をたくさん受ける葉は厚く、少ない光を集める葉は大きく広げる → 小さく厚いイが陽葉と決まる。

📚 前提知識

  • 陽葉は強い光でしっかり光合成をするため、さく状組織が発達して分厚い。
  • 陰葉は日当たりが悪いので、葉を大きく広げて少しでも多くの光を受ける。

🔍 こう読み解く

  1. イ：小さい・厚い → 陽葉。
  2. ア：大きい・薄い → 陰葉。大きさと厚さの2行がそろって同じ向きを指すので、葉の色の行は決め手にしなくてよい。
答え：陽葉 イ　陰葉 ア

H・光環境と光合成 (2) 葉が食べられたときの吸収量の変化 素材文＋グラフ選択

👀 まず見るところ

【まざり型→素材文】部品は本文の「陽葉よりも陰葉から食べ始める」に丸と、(1)①で分かった陰葉Bの吸収量の少なさ。はじめは減り方が小さく、陽葉に進むと大きく減る形が決まる。

📚 前提知識

  • 木全体の二酸化炭素の吸収量は、残っている葉の吸収量の合計。吸収量の少ない葉が食べられても、合計はあまり減らない。

🔍 こう読み解く

  1. 図1の矢印の位置で比べると、日中の吸収量は陽葉Aのほうが陰葉Bよりずっと多い。
  2. 最初は陰葉が食べられる → 吸収量はゆっくり減る（グラフはゆるやか）。
  3. 陰葉を食べ終わると陽葉に移る → 急に大きく減る（グラフが急に下がる）。

H・光環境と光合成 (3)①②③ 生産者・消費者の区別 素材文・語句

👀 まず見るところ

【素材文】部品は本文の「ブナの葉をえさとする」「この幼虫をえさとする」「この蛹を栄養源とする」に丸。ブナ → 幼虫 → オサムシ・サナギタケと矢印を1本ずつ書けば、それぞれの段が決まる。

📚 前提知識

  • 生産者＝光合成をする植物。それを食べるのが一次消費者、一次消費者を食べるのが二次消費者（設問の定義どおり）。
  • サナギタケは菌類（キノコのなかま）。光合成はしない。

🔍 こう読み解く

  1. ブナ＝生産者。その葉を食べるブナアオシャチホコの幼虫 → 一次消費者。
  2. クロカタビロオサムシはその幼虫をえさにする → 二次消費者。
  3. サナギタケは幼虫が育った蛹から栄養を得る。蛹も同じブナアオシャチホコなので、相手は一次消費者 → 二次消費者。
答え：① 一次消費者　② 二次消費者　③ 二次消費者
自分で解くときのチェック：③は「キノコだから生産者か分解者」と決めず、本文でだれから栄養をとるかを矢印にしてから答える。
