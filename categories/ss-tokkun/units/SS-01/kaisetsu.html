SS-01 X1・X2（3つの気体の発生と二酸化炭素の捕集）

X1 全体像 気体の発生3つ・4問

「何に何を加えると、どの気体が出るか」を3組そろえて確かめる大問である。実験1〜3を読んだ時点で、下の表の右2列（気体の名前と、固体の正体）を書き出しておくと、(1)〜(4)はすべてこの表から決まる。

実験固体＋液体出る気体固体の正体（同じ気体が出る仲間）
1二酸化マンガン＋うすい過酸化水素水酸素触媒（自分は変化せず反応を助ける）
2石灰石＋うすい塩酸二酸化炭素炭酸カルシウム
3鉄＋うすい塩酸水素塩酸にとける金属

(2)は「すべて選ぶ」なので、ア〜サの11個ぜんぶに○×をつける。1つ見つけて次へ進まない。

X1 (1) 実験1〜3で発生した気体 知識問題

二酸化マンガン＋過酸化水素水→酸素。石灰石＋塩酸→二酸化炭素。鉄＋塩酸→水素。「塩酸を加える」実験が2つあるので、相手が石灰石（炭酸カルシウム）なら二酸化炭素、金属なら水素、と固体のほうで区別する。漢字指定。
答え：実験1 酸素　実験2 二酸化炭素　実験3 水素

X1 (2) 3つの気体の性質 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は聞かれ方「それぞれすべて選びなさい」に丸。ア〜サを3つの気体それぞれについて11個ぜんぶ○×にする。入口は数字のク〜サ「空気中に約○%」で、80%は窒素・20%は酸素・0.04%は二酸化炭素と決まる。

📚 前提知識

  • 空気の体積の約80%が窒素、約20%が酸素、二酸化炭素は約0.04%。0.4%（コ）はどの気体にもあてはまらない数字。
  • 酸素はものを燃やすのを助ける（助燃性）が、自分は燃えない。水素は自分が燃える（可燃性）。二酸化炭素は燃えも助けもしない。
  • 空気より重いのは酸素（少し重い）と二酸化炭素。水素はいちばん軽い気体。3つとも無色でにおいがなく、水にとけにくいのは酸素と水素。

🔍 こう読み解く

  1. 酸素：イ 水にとけにくい ○／エ 助燃性 ○／カ 無色 ○／キ 空気より重い ○／ケ 20% ○。ウ・オ・ア・ク・コ・サは×。
  2. 二酸化炭素：ア 温室効果 ○／カ 無色 ○／キ 空気より重い ○／サ 0.04% ○。水に少しとけるのでイは×、燃えないのでウ・エも×。
  3. 水素：イ 水にとけにくい ○／ウ 可燃性 ○／カ 無色 ○。空気より軽いのでキは×。空気中にはほとんどないのでク〜サも×。
答え：実験1 イ・エ・カ・キ・ケ　実験2 ア・カ・キ・サ　実験3 イ・ウ・カ
コツ：「無色」のカは3つとも○。落としやすいのは酸素のキ（空気より少し重い）と、水素のキが×になること。重い・軽いを3つ横にならべて書いてから選ぶ。

X1 (3) 代わりに使える固体 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問は「同じ気体が発生する固体」。部品は①〜③の固体の正体で、余白に3語で書く：①触媒 ②炭酸カルシウム ③塩酸にとける金属。ア〜コをこの3つの箱に入れ、どこにも入らないものが残る。

📚 前提知識

  • 二酸化マンガンは触媒（自分は変化せず反応を助ける）。生のレバーや生の野菜にふくまれる酵素「カタラーゼ」も同じはたらきをするので、過酸化水素水から酸素が出る。
  • 石灰石の主成分は炭酸カルシウム。貝殻・大理石・チョーク・卵の殻も同じ。重そう（炭酸水素ナトリウム）は成分はちがうが、塩酸と反応して二酸化炭素を出す。
  • 塩酸にとけて水素を出す金属は鉄・アルミニウム・マグネシウム・亜鉛。銀と銅は塩酸と反応しない。

🔍 こう読み解く

  1. ①触媒の箱：ク 生のレバー・ケ 生のピーマン（生であることが条件。加熱すると酵素がはたらかない）。
  2. ②炭酸カルシウムの箱：ア 貝殻・イ 大理石・キ チョーク。重そうのコも二酸化炭素が出るのでここに入る。
  3. ③金属の箱：ウ マグネシウム・エ アルミニウム。オ 銀・カ 銅は塩酸と反応しないので、どの箱にも入らない。
答え：① ク・ケ　② ア・イ・キ・コ　③ ウ・エ
コツ：金属は「塩酸と反応する／しない」で2つに分けて書く。銀・銅は反応しない側、と先に外しておくと③で迷わない。

X1 (4) 残った液を蒸発させると 素材文・1つ選ぶ

👀 まず見るところ

【素材文】部品は「上ずみ」と「加熱」に丸。上ずみ＝とけていないもの（二酸化マンガン・余った固体）は入らない。残るのは液にとけているものだけ、と決めてから3つの実験を見る。

📚 前提知識

  • 実験1：過酸化水素水は水と酸素に分かれる。二酸化マンガンは変化せず底に残るが、上ずみには入らない。液は水だけなので、蒸発させると何も残らない。
  • 実験2：石灰石＋塩酸では、二酸化炭素のほかに水にとける塩化カルシウム（白い固体）ができる。
  • 実験3：鉄＋塩酸では、水素のほかに水にとける塩化鉄（黄色い固体）ができる。

🔍 こう読み解く

  1. 実験1 → 液の中身は水だけ → ア 何も残らない。
  2. 実験2 → 塩化カルシウムが残る → イ 白い固体。
  3. 実験3 → 塩化鉄が残る → エ 黄色の固体。鉄そのものは光沢があるが、とけて別の物質になっているのでオではない。
答え：実験1 ア　実験2 イ　実験3 エ
コツ：「気体が出た」で終わりにせず、「液に何がとけて残ったか」まで1行書く。塩酸の反応は「気体＋塩化○○」のセットで覚える。

X1 まとめ 4問

  • 実験1〜3を読んだら、「気体の名前」と「固体の正体（触媒／炭酸カルシウム／金属）」の表を先に書く。(1)〜(4)はこの表を見るだけで決まる。
  • 「すべて選ぶ」は11個・10個ぜんぶに○×。無色のカは3つとも○、空気より重いキは酸素と二酸化炭素だけ。
  • 塩酸の反応は「気体＋塩化○○」のセット。石灰石→塩化カルシウム（白）、鉄→塩化鉄（黄）。

X2 全体像 二酸化炭素の捕集・7問

石灰石＋うすい塩酸で二酸化炭素を発生させ、水上置換（(2)〜(5)）と下方置換（(6)）の2つの集め方を比べる大問である。図を2つかく問題があるので、器具の名前と「なぜその形か」をセットで押さえる。

集め方使える気体利点注意
水上置換水にとけにくい気体（二酸化炭素は少しとけるが可）混じり気がない・量が目で見える最初に出る気体は装置内の空気なので捨てる
下方置換空気より重い気体水にとけやすい気体でも集められる管をびんの底まで入れる

X2 (1) 反応する物質の名前 知識問題

石灰石の主成分は炭酸カルシウム、塩酸は塩化水素という気体が水にとけた水溶液。「石灰石」「塩酸」は材料の名前で、聞かれているのは中身の物質名。「それぞれ」なので2つとも答える。
答え：石灰石 炭酸カルシウム　塩酸 塩化水素

X2 (2) 気体を発生させて集める装置の図 条件文・作図

👀 まず見るところ

【条件文】部品は器具の一覧。「水の入った水槽」と「集気びん」があるので集め方は水上置換と決まる。8つの器具を1つずつ図に置き、置き終えたら一覧に✓をつけて使い残しがないか確かめる。

📚 前提知識

  • コック付きろうと：うすい塩酸を少しずつ加えるための器具。足はフラスコの底近くまで下ろす。
  • ゴム栓に通すL字ガラス管の先は栓のすぐ下で止める（気体の出口）。液面につけると気体が出ていかない。
  • 集気びんは水で満たして水槽に逆さに立て、もう1本のL字ガラス管の先をびんの口の中に入れる。ガラス板はびんを取り出すときのふた。

🔍 こう読み解く

  1. 三角フラスコに石灰石を入れ、ゴム栓にコック付きろうととL字ガラス管を通す。ろうとの足は下まで、ガラス管は栓のすぐ下まで。
  2. L字ガラス管→ゴム管→もう1本のL字ガラス管とつなぎ、その先を水槽の水の中に入れる。
  3. 水で満たした集気びんを水槽の中で逆さにし、ガラス管の先をびんの口の真下に置く。ガラス板は水槽の中に立てかけておく（びんを取り出すときのふた）。
答え：解答冊子の図のとおり（三角フラスコ＋コック付きろうと＋L字ガラス管→ゴム管→L字ガラス管→水槽中の逆さの集気びん）
コツ：かき終えたら「ろうとの足は下まで・出口の管は短く・集気びんは水で満たして逆さ」の3か所を見直す。

X2 (3) この捕集方法の名前 知識問題

水上置換法。水の入った水槽で、水と気体を置きかえて集める方法。解答らんの末尾に「法」が印刷されているので「水上置換」と書く。
答え：水上置換（法）

X2 (4) 水上置換の利点 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は聞かれ方「利点」「すべて」に丸。ア〜オの5つ全部に○×。手がかりの言葉は「混じり気のない」「目で確認」で、この2つが水と置きかえる方法ならではの利点。

📚 前提知識

  • 水上置換は集気びんの中が最初は水だけなので、空気が混ざらない（純粋な気体が集まる）。水面の下がり方で集まった量も見える。
  • 空気より重いか軽いかは関係ない（それは上方・下方置換の話）。気体の種類は集めただけでは分からない。危険な気体を吸いこまない工夫（換気・においを直接かがない）は、集め方の利点とは別の話。

🔍 こう読み解く

  1. ア 混じり気のない気体 → ○。オ 量を目で確認 → ○。
  2. イ 空気より重い気体 → 下方置換の利点であって水上置換のことではない → ×。
  3. ウ 種類の確認 → 集めただけでは分からない → ×。エ 吸い込まない → 水と置きかえるしくみとは関係がなく、この方法の利点とはいえない → ×。
答え：ア・オ
コツ：イを見たら「それは下方置換の話」と一言書いて消す。重い・軽いの言葉が出たら、水上置換とは別の集め方を思い出す合図。

X2 (5) 最初の気体を捨てる理由 記述

👀 まず見るところ

【素材文】部品は「最初に出てくる気体」「集気びん1本分ほど」に丸。装置の中で最初にあったものは何か、を1語で書く → 「空気」。この1語が答えの中心になる。

📚 前提知識

  • 反応が始まる前、三角フラスコやガラス管の中は空気で満たされている。発生した気体はその空気を押し出しながら出てくるので、最初に集気びんに入るのは空気。
  • 装置の中の空気の量が集気びん1本分くらいなので、その分を捨てれば純粋な気体になる。

✍️ 答案の組み立て

  1. 要素A：最初に集まる気体は「三角フラスコやガラス管の中にあった空気」だと書く。
  2. 要素B：「〜だから」で終える（理由を聞かれている）。
模範解答：最初に集まる気体は三角フラスコやガラス管内の空気だから。
コツ：「空気」の1語が入っているか、書いたあとに確かめる。「純粋でないから」だけでは、何が混ざるのか書いていないので足りない。

X2 (6)①②③ 別の集め方（下方置換） まざり型・作図＋性質＋確認方法

👀 まず見るところ

【まざり型→素材文】部品は「(2)とは別の方法」と、③の「気体検知管を用いてはいけません」に丸。別の方法は上方か下方かの2択で、二酸化炭素は空気より重いので下方置換に決まる。①②③はここから続けて決まる。

📚 前提知識

  • 水にとけやすい気体は水上置換で集められないので、空気より重ければ下方置換、軽ければ上方置換を使う。二酸化炭素は水に少しとけるだけなので、水上置換と下方置換のどちらでも集められる。
  • 下方置換の図：集気びんを立てて口を上に向け、管をびんの底近くまで差しこむ。ガラス板を口に軽くのせ、管の分だけすき間をあける。
  • 二酸化炭素の確かめ方：石灰水に通すと白くにごる。

🔍 こう読み解く

  1. ①：びんを口が上のまま立て、管の先を底まで入れる（重い気体が下からたまるので、上の空気が押し出される）。ふたのガラス板は管をよけて少しずらす。
  2. ②：この集め方ができる理由は、二酸化炭素が空気より重い性質があるから。
  3. ③：気体は二酸化炭素。確かめ方は、集気びんに石灰水を入れてふると白くにごる。検知管が使えないので、この方法を書く。
答え：① 集気びんを立て、管を底近くまで入れ、ガラス板を少しずらしてふたをした図　② 空気より重い性質　③ 気体：二酸化炭素　方法：石灰水を入れて白くにごればよい
コツ：①の図は「管の先がびんの底」「口は上」の2点で決まる。上方置換とちがう所をその2点で確かめる。

X2 (7)①② 亜鉛と塩酸で発生した気体の体積 知識問題

亜鉛＋うすい塩酸で出る気体は水素。①気体の体積をはかる器具はメスシリンダー（水で満たして逆さに立て、水上置換で集めながら目盛りを読む）。②水素を燃やすと酸素と結びついて水になる。「石灰石」から「亜鉛」に変わった＝気体が二酸化炭素から水素に変わった、に気づくのが入口。
答え：① メスシリンダー　② 水

X2 まとめ 7問

  • 集め方は「水にとけやすいか」→「空気より重いか軽いか」の順で決める。二酸化炭素は水上置換・下方置換の両方が使える。
  • 水上置換の利点は「混じり気がない」「量が見える」の2つ。「重い・軽い」の言葉が出たら別の集め方の話。最初の気体は装置内の空気なので捨てる。
  • 図をかく問題は、ろうとの足は下まで・出口の管は短く・集気びんは水で満たして逆さ（水上）／口は上で管は底まで（下方）、の形で見直す。

SS-01 X3（6種類の気体の見分けと捕集法）

X3 全体像 気体の性質の表・10問

決め手は列ごとに1つで足りる。表の横に、決めた気体の名前を書き足しておくと、あとの問いで表を読み直さずにすむ。

気体決め手（表のどこ）正体
A空気中に「最も多く含まれる」窒素
B「ごく少量」＋青→赤（酸性）二酸化炭素

X3 (1) 気体A〜Fの名前 資料問題・表から気体を決める

👀 まず見るところ

【資料問題】部品は正体「A〜F 6種類の気体・5つの性質の表」。たてに1列ずつ読み、その列だけにある言葉（Aの「最も多く」、Dの「約0.07倍」）に丸を置く → 1列に決め手1つで、6つとも決まる。

📚 前提知識

  • 空気の成分は窒素が約78%、酸素が約21%。「最も多く」が窒素、「約20%」が酸素。
  • 湿らせたリトマス紙が青→赤なら酸性の気体、赤→青ならアルカリ性の気体。気体の中でアルカリ性はアンモニアだけ。
  • 刺激臭がある気体はアンモニアと塩化水素。空気より軽いほうがアンモニア、重いほうが塩化水素。水素はいちばん軽い気体。

🔍 こう読み解く

  1. A「最も多く含まれる」→ 窒素。C「約20%含まれる」→ 酸素。割合の行だけで2つ決まる。
  2. B「ごく少量含まれる」＋青→赤（酸性）→ 二酸化炭素。
  3. D 重さ「約0.07倍」＝空気の1割もない → 水素。
  4. EとFはどちらも刺激臭。Eは軽くて赤→青（アルカリ性）→ アンモニア。Fは重くて青→赤（酸性）→ 塩化水素。
答え：A 窒素　B 二酸化炭素　C 酸素　D 水素　E アンモニア　F 塩化水素
チェック：決めた気体の名前を表のA〜Fの上に書き足してから(4)以降へ進む。あとの問いは全部この名前を使う。

X3 (2) 気体のにおいを調べる方法 知識問題

手であおいで、空気でうすめてかぐ。容器に鼻を近づけて直接かがないのは、アンモニアや塩化水素のような刺激臭の気体で鼻や目をいためるから。「手であおぐ」と「うすめる」の2つを入れて書く。
答え：手であおいで空気でうすめてかぐ。

X3 (3) 二酸化炭素の空気中の割合 知識問題

【まざり型→条件文】部品は「炭酸カルシウムの重さの44%の気体」と「純度とは石灰石中の炭酸カルシウムの割合」。44%は「炭酸カルシウム＝気体÷0.44」に直して書く → 気体0.96gから炭酸カルシウムの重さが出て、2.40gで割れば純度になる。

📚 前提知識

  • 石灰石＝炭酸カルシウム＋反応しない不純物。気体を出すのは炭酸カルシウムだけなので、気体の量から炭酸カルシウムの量が逆算できる。

  1. 使う式：純度＝（気体÷0.44）÷石灰石×100。
  2. 石灰石2.40gから気体0.96g。炭酸カルシウムは 0.96÷0.44＝24/11 g（約2.18g）。
  3. 純度は 24/11÷2.40×100＝90.9… → 四捨五入して91%。
答え：91%
コツ：24/11は割り切れないので分数のまま次の式へ運ぶ。先に2.18と丸めると90.8になり、答えは同じでも見当がずれやすい。

Z (9) 酸化を防ぐために缶や袋に詰める気体 知識問題

窒素。空気の約8割をしめ、他の物質と結びつきにくい気体。酸素のかわりに袋の中を満たしておけば、食品が酸素にふれず酸化しない。「燃えない・ものを燃やさない」と同じ性質からくる使いみち。

Z (10) 酸素を減らす、風味と色以外の利点 素材文・記述

  2. 要素B：防ぐことができる。設問が「利点」なので「〜点。」で結ぶ。

Z (11) 熱くなったあとの脱酸素剤の重さ 素材文・選択

👀 まず見るところ

【素材文】部品は設問の「一時的に熱くなる」と、成分表の「鉄粉：さびることにより発熱する」に丸 → 熱くなった＝鉄がさびた＝鉄が酸素と結びついた、と決まる。あとは「結びついた分」の向きだけ。

📚 前提知識

  • さびる＝鉄＋酸素→酸化鉄。結びついた酸素の重さの分だけ、固体は重くなる（スチールウールを燃やすと重くなるのと同じ）。

🔍 こう読み解く

  1. 熱が出た → 鉄粉がさびた → 空気中の酸素が鉄にくっついた。
  2. くっついた酸素の分だけ重くなる → ア。
  3. 「熱で何かが飛んで軽くなる」と考えるのは逆。飛んでいったのではなく、酸素が入ってきた。
答え：ア

Z (12) 乾燥剤といっしょだと効きが弱くなる理由 素材文・記述

👀 まず見るところ

【素材文】部品は成分表の「水・塩類：鉄粉のさびる速度をはやめる」と、乾燥剤のはたらき「水分を吸収する」に丸 → 乾燥剤が水を取る → 鉄がさびにくい → 酸素を吸えない、と3段で決まる。

📚 前提知識

  • 鉄は乾いた空気の中ではほとんどさびない。水があるとさびが速く進む（ぬれた自転車がさびるのと同じ）。脱酸素剤はわざと水と塩を入れて、さびを速くしている。

✍️ 答案の組み立て

  1. 要素A：乾燥剤が水分を吸収する（脱酸素剤に必要な水がなくなる）。
  2. 要素B：だから鉄がさびにくくなる＝酸素を吸えなくなる。「〜から。」で結ぶ。
模範解答：乾燥剤が水分を吸収して、脱酸素剤の鉄がさびにくくなるから。
コツ：成分表の4行は、(11)(12)の答えの部品置き場。「鉄粉＝発熱」「水・塩類＝速くする」の2行に丸をつけてから設問へ進む。
