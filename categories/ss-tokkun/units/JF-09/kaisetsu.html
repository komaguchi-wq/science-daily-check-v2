Ⅰ 2(2) 身長が最も大きく変化した1か月 表の読み取り・単位に注意

👀 まず見るところ

【資料問題】部品は聞かれ方の「何倍になったか」（ふえた長さではない）と、表の単位。はじめだけ「0.1mm」で、あとはcm。0.6cm＝6mmに直して書く → 0.1mm→6mmで60倍と決まる。

📚 前提知識（あれば答え合わせに使う）

  • 「何倍」は、後の数÷前の数。「どれだけふえたか」（ひき算）とは答えが変わる。ひき算なら最大は5ヶ月後→6ヶ月後の9cmだが、聞かれているのはわり算のほう。

🔍 こう読み解く

  1. 単位をmmにそろえる：はじめ0.1mm、1ヶ月後0.6cm＝6mm。
  2. ア はじめ→1ヶ月後：6÷0.1＝60倍。
  3. イ 1→2ヶ月後：5÷0.6＝約8倍。ウ 11÷5＝約2倍。それよりあとは2倍より小さい。
  4. 60倍がずばぬけて大きい → ア。
答え：ア
今回：イ ×。部品の形を直さなかった＝問題用紙の表に矢印をかいてくらべてはいるが、「0.1mm」をcmとそろえずに0.1→0.6の6倍と見て、イの約8倍を最大にしたと考えられる。次は、表の単位がまざっていないかを先に見て、そろえた数字を表の横に書く。

Ⅰ 2(4) 卵円孔と動脈管は何のためにあるか 図＋記述 10点

👀 まず見るところ

【まざり型→素材文】部品は「右心房と左心房を結ぶあな」「肺動脈と大動脈を結ぶ管」に丸。ふつうの血液の道すじにこの2つを置くと、どちらも肺を通らない近道になっている → 肺に血液を送らないため、と決まる。

📚 前提知識

  • 生まれた後の血液の道すじ：右心房→右心室→肺動脈→肺→肺静脈→左心房→左心室→大動脈→全身。
  • 胎児は子宮の中で羊水という液体につつまれていて、肺で呼吸できない。酸素は母親の血液から胎盤を通して受け取る。だから肺にすべての血液を送る必要がない。

✍️ 答案の組み立て

  1. 要素A（あなのはたらき）：卵円孔があると、右心房の血液が肺へ回らず、直接左心房へ行く。
  2. 要素B（管のはたらき）：動脈管があると、右心室から肺動脈に出た血液が、肺へ行かず大動脈へ流れる。
  3. 2つに共通するのは「肺を通らない」こと。「何のために」と聞かれているので「〜ため。」で終える。
模範解答：肺にすべての血液が行かないようにするため。
今回：「母から栄養をもらうため。」×。部品を拾えなかった＝「結ぶ」の前にある2組の場所を使っていない（母親から栄養をもらうのは、へその緒と胎盤のはたらき）。次は、図の卵円孔と動脈管に血液の向きの矢印をかいてから書く。

Ⅰ 2(5) 胎児の下大静脈を流れる血液 記述 10点

👀 まず見るところ

【素材文】部品は「生まれた後の下大静脈を流れる血液と比べる」に丸。くらべるものさしは血液の中身＝酸素。本文の「へその緒で母親の胎盤とつながっている」から、胎児では酸素が多い側と決まる。

📚 前提知識

  • 生まれた後の下大静脈は、全身に酸素をわたし終えた血液が心臓へもどる管。酸素は少ない。
  • 胎児は胎盤で酸素と養分を受け取る。その血液はへその緒の中の血管を通って胎児の体に入り、下大静脈に合流する。

✍️ 答案の組み立て

  1. 要素A（何が）：酸素（や養分）。
  2. 要素B（どちら向きか）：生まれた後は少ない ⇔ 胎児は多い。両方をセットでならべてから、聞かれている胎児の側を書く。
  3. 「どんなことですか」なので「〜こと。」で終える。
模範解答：酸素が多くふくまれていること。
今回：空らん ×。血液をくらべる問題は「酸素が多いか少ないか」から書き始め、胎児の酸素がどこから来るか（胎盤）をたどって向きを決める。

Ⅰ 2(6) ヒトの卵が小さい理由 記述 10点

👀 まず見るところ

【素材文】部品は「メダカの卵とヒトの卵とニワトリの卵」をくらべていることと、本文の「へその緒で母親の胎盤とつながっている」に丸。卵の大きさ＝中にたくわえた養分の量、に直して書く → 養分を母親からもらえるかどうかのちがいと決まる。

📚 前提知識

  • メダカやニワトリは、うみ出された卵の中だけで育つ。子がある程度育つまでの養分を、はじめから卵に入れておく必要がある。だから卵が大きい。
  • ヒトなどのほ乳類は、母親の体の中で、胎盤を通して養分や酸素をもらいながら育つ。卵に養分をたくわえる必要がほとんどない。

✍️ 答案の組み立て

  1. 要素A（くらべる相手）：メダカやニワトリの卵には、胚が育つまでの養分が必要。
  2. 要素B（ヒト）：ヒトは胎盤を通して母親から養分を受け取ることができる。
  3. 「Aだが、Bから。」の形でつなぐ。くらべる問題なので、ヒトの側だけでなく相手の側も書く。
模範解答：メダカやニワトリの卵では胚がある程度育つまでの養分が必要だが、ヒトは胎盤を通して母親から養分を受け取ることができるから。
今回：空らん ×。2(4)に書いた「母から栄養をもらう」は、この問いで使う内容。「ヒトは母親から養分をもらえるから」と1文目を書き、そのあとにメダカやニワトリの側を足す。

Ⅱ 1問1 積算温度と花が咲くまでの日数 条件文・計算

👀 まず見るところ

【条件文】部品は「積算温度が1000℃」と「20℃である場合、50日」。20×50＝1000 と式に直して書く → 積算温度＝温度×日数 と決まり、あとは温度を入れかえるだけになる。

📚 前提知識（あれば答え合わせに使う）

  • 積算温度は、問題文のとおり「どのくらいの温度がどのくらいの期間続いたか」を合計した量。毎日同じ温度なら、温度×日数になる。知らなくても、20℃・50日・1000℃の3つの数から決まる。

🔍 こう読み解く

  1. 「10℃低い」は、そのままでは式に入らない。20−10＝10℃ と直して書く。
  2. 1000÷10＝100日。温度が半分になったので日数は2倍、と確かめられる。
答え：100日
今回：100 ○。「20−10＝10」も書いてあり、「10℃低い」を10℃に直してから割れている。

Ⅱ 1問2 この地点の暖かさ指数 まざり型・表の計算

Ⅲ 1問1 円柱Bの1cm³あたりの重さ まざり型・グラフと浮力

👀 まず見るところ

【まざり型→資料問題】部品はグラフの折れ目2つ。円柱Aは水位「5.0」cm、円柱Bは「4.0」cm。図1の円柱に、5cm＝高さ、4cm＝うき始めたとき水に入っていた深さ、と書きこむ → 体積と重さが決まる。

📚 前提知識

  • 折れ目の前は、水が円柱のまわり（40−20＝20cm²）にだけたまるので水位が速く上がる。しずんだままのAは、水位が円柱の上の面をこえると底面積が40cm²にもどり、上がり方がゆるくなる。だからAの折れ目＝円柱の高さ。
  • うくBは、浮力が重さと同じになった所でうき始める。うき始めると水に入っている深さは変わらないので、Bの折れ目＝水に入っている深さ。参考のとおり、水に入っている体積1cm³につき1gの浮力を受ける。

🔍 こう読み解く

  1. Aの折れ目は5cm。AとBは同じ形なので、Bの高さも5cm。体積は 20×5＝100cm³。
  2. Bの折れ目は4cm。水に入っている体積は 20×4＝80cm³ → 浮力は80g分。ういているので、Bの重さも80g。
  3. 1cm³あたりの重さ＝80÷100＝0.8g。
答え：0.8g/cm³
今回：0.8 ○。メモに「5cm分の4cmしずむ」とあり、高さ5cmのうち4cmが水に入っている、という関係をグラフから取り出せている。

Ⅲ 1問2 くりぬいたコップがうくとき 条件文・浮力

  2. 水面より上に出ている体積：100−90＝10cm³。

答え：0.5cm

Ⅲ 2問3 L字型の棒をBCが水平になるようにつるす 条件文・てこ

👀 まず見るところ

【条件文】部品は「重さのある棒」と図5の「12cm」「24cm」。重さは長さに比例するので、ABに①、BCに②の矢印を、それぞれのまん中に置く（直して書く）→ 2本の矢印がつり合う点がPと決まる。

📚 前提知識

  • 同じ棒を折り曲げただけなので、12cmの部分の重さを①とすると、24cmの部分は②。それぞれの重さは、その部分のまん中に全部かかっているとみなせる。
  • つり合いで使うのは、支点から矢印までの水平の距離。図6のABはBの真下に下がっているので、①の矢印はBの真下を通る。
  • 2つの重さの間の支点は、重さの逆の比に分ける点。重いほうの近くになる。

🔍 こう読み解く

  1. 図6に矢印を置く。②はBCのまん中（Cから12cm、Bから12cm）、①はBの位置。
  2. 2本の矢印の間は12cm。重さの比が②：①なので、距離は逆の1：2に分ける。12×1÷3＝4cm。Pは②の矢印から4cm、Bから8cm。
  3. CP＝12＋4＝16cm。確かめ：②×4＝8、①×8＝8 でつり合う。
答え：16cm
今回：18 ×。式は「24−6＝18」で、図6に線の書きこみはあるが、PBに「6」（ABの半分の12÷2と読める）と置いて長さだけで引き算をしている。部品の形を直さなかった＝棒の重さ①・②が式に入っていないので、次は、まん中に矢印を2本かいて①・②と書いてから式を立てる。
