サンデーチェック-02 X復習（気体の性質・亜鉛と塩酸のグラフ・炭酸カルシウムの発生量）

X復習 全体像 10問（各10点）・70点

SS-01 Xの復習。(1)は気体の性質の一問一答、(2)は亜鉛と塩酸のグラフ、(3)は炭酸カルシウムと塩酸の表と装置。(2)(3)はどちらも気体の発生計算で、やることは1つ、「金属（固体）と塩酸のどちらが先になくなるか」を先に決めること。グラフや表で頭打ちが始まる点（折れ曲がる点）がその境目で、ここが「ちょうどの組」になる。

問先になくなるのは気体の量を決めるもの
(2) 亜鉛1.8g・塩酸150cm³で折れる塩酸150cm³より少なければ塩酸、多ければ亜鉛少ないほうの量
(3) 炭酸カルシウム1.0g・塩酸48mLで頭打ち塩酸48mLより少なければ塩酸、多ければ炭酸カルシウム少ないほうの量

今回は10問中7問。落とした3問は、知識1つ・数字の直し方1つ・設問の読み方1つで、型がばらけている。

X復習 (1)① 空気中で燃える気体 知識問題

水素だけ。ア〜カのうち自分が燃えるのは水素で、酸素は「ものを燃やす」側、ほかの4つは燃えもしないし燃やしもしない。「においがある」（アンモニア・塩化水素）と「燃える」は別の性質なので混ぜない。
答え：イ
今回：イ・ウ・カ ×。知識＝アンモニアと塩化水素は燃えない。「においがある」の組（ウ・カ）を「燃える」にも入れてしまった形。性質ごとに当てはまる気体を1つずつ思い出してから書く。

X復習 (1)② においがある気体 知識問題

アンモニアと塩化水素。どちらも水にとけやすく、鼻をさすにおいがある。塩化水素の水溶液が塩酸、アンモニアの水溶液がアンモニア水、と液体の名前とセットで覚える。
答え：ウ・カ
今回：ウ・カ ○。

X復習 (1)③ 赤いリトマス紙を青に変える気体 知識問題

アンモニア。赤→青はアルカリ性の合図で、水にとけてアルカリ性になる気体はアンモニアだけ。塩化水素と二酸化炭素は水にとけて酸性（青→赤）。「水で湿らせた」は、気体が水にとけて初めて色が変わるという意味。
答え：ウ
今回：ウ ○。

X復習 (1)④ 空気よりも軽い気体 知識問題

窒素・水素・アンモニア。軽いものから順に 水素→アンモニア→窒素（空気よりほんの少し軽い）。酸素・二酸化炭素・塩化水素は空気より重い。窒素を落としやすいので、「空気の約8割が窒素なのに、空気より少し軽い」と覚える。
答え：ア・イ・ウ
今回：ア・イ・ウ ○。

X復習 (2)① 亜鉛1.8gをすべてとかす塩酸 資料問題・グラフの折れ曲がる点

👀 まず見るところ

【まざり型→資料問題】部品は図1の正体「亜鉛1.8g・塩酸の体積と気体の体積」（正体を1行）と、設問の「すべてとかす」。すべてとけた＝それ以上気体が出ない＝グラフが水平に折れ曲がる点。その点の横の目もりを読めば決まる。

📚 前提知識

  • 右上がりの間は塩酸が足りない側（塩酸を足すぶんだけ気体が出る）。水平になったら亜鉛が足りない側（亜鉛を使いきった）。

🔍 こう読み解く

  1. 図1の折れ曲がる点は 横150・たて600。
  2. 塩酸150cm³で亜鉛1.8gがちょうどとけきり、気体は最大600cm³。
答え：150cm³
今回：150 ○。

X復習 (2)② 亜鉛1.4gに塩酸100cm³ 条件文・どちらが先になくなるか

👀 まず見るところ

【まざり型→条件文】①と変わった部品は「亜鉛1.4g」「塩酸100cm³」に丸。この2つを図1の「1.8g＝150cm³」の組と比べて、どちらが先になくなるかを決める。塩酸100cm³でとける亜鉛は何gか、と直して書く。

📚 前提知識

  • 気体の量は、少ないほう（先になくなるほう）で決まる。
  • 図1の直線部分は「塩酸50cm³で気体200cm³」の比例。

🔍 こう読み解く

  1. 塩酸100cm³でとける亜鉛＝1.8×100÷150＝1.2g。
  2. 亜鉛は1.4gあるので0.2g余る → 先になくなるのは塩酸。
  3. 気体は塩酸100cm³ぶん＝600×100÷150＝400cm³。図1の横100の高さを読んでも同じ。
答え：400cm³
今回：400 ○。

X復習 (2)③A 亜鉛1.2g・半分の濃さ 条件文・グラフの形を選ぶ

👀 まず見るところ

【まざり型→条件文】変わった部品は「亜鉛1.2g」と「半分の濃さ」の2つ。亜鉛の量→頭打ちの高さ、濃さ→折れる横の位置、と分けて直して書く。半分の濃さは「同じ量をとかすのに塩酸が2倍いる」＝横の位置×2。

📚 前提知識

  • 気体の最大量は亜鉛の量に比例する。濃さは最大量を変えず、折れる位置（必要な塩酸の体積）だけを変える。
  • 選択肢のグラフは図1と同じ目もりで、たて1目もり200・横1目もり50。

🔍 こう読み解く

  1. 高さ：亜鉛1.2gの気体＝600×1.2÷1.8＝400。
  2. 横：もとの濃さなら1.2gに塩酸100cm³。半分の濃さなら×2で200。
  3. 400で頭打ち、折れるのは横200 → エ。
答え：エ
今回：エ ○。

X復習 (2)③B 亜鉛2.4g・2倍の濃さ 条件文・グラフの形を選ぶ

👀 まず見るところ

【まざり型→条件文】変わった部品は「亜鉛2.4g」と「2倍の濃さ」。Aと同じ手順で、先に「亜鉛2.4gをとかすのに、もとの塩酸なら何cm³か」を直して書き、そのあと濃さで÷2にする。順番を逆にしない。

📚 前提知識

  • 2倍の濃さは「同じ量をとかすのに塩酸が半分ですむ」＝折れる横の位置÷2。高さは変わらない。

🔍 こう読み解く

  1. 高さ：亜鉛2.4gの気体＝600×2.4÷1.8＝800。
  2. 横：もとの濃さなら2.4gに塩酸200cm³（150×2.4÷1.8）。2倍の濃さなら÷2で100。
  3. 800で頭打ち、折れるのは横100 → ウ。カ（高さ800・横50で折れる）は高さは合うが、折れる位置がさらに半分。÷2のもとを200cm³でなく100cm³（亜鉛1.2gの量）にすると、ここを選んでしまう。
答え：ウ
今回：カ ×。部品の形を直さなかった＝頭打ち800は合っていて、折れる位置だけが半分（50）になっている。÷2のもとの「亜鉛2.4gに塩酸200cm³」が余白に無く、別の数を半分にした形（途中式が無いので何を割ったかは答案からは分からない）。次は「2.4g→200cm³」を1行書いてから半分にする。

X復習 (3)① メスシリンダーに集まった気体 資料問題・装置の図を読む

👀 まず見るところ

【まざり型→資料問題】部品は設問の「気体は何ですか」（名前を聞いている）に丸と、図2のまん中の「500(mL)の三角フラスコ」。通り道を「100mL→500mL→メスシリンダー」と1行に書く → 集まるのは500mLのフラスコから押し出されたもの。

📚 前提知識

  • 実験を始める前、フラスコとゴム管の中は空気で満ちている。あとから来た気体は、先にあった空気を押し出す。
  • 発生する二酸化炭素は表の最大でも240mL。500mLのフラスコを満たしきれないので、押し出されてメスシリンダーに来るのは、フラスコにもともとあった空気のほう。

🔍 こう読み解く

  1. 装置を左から右へたどる：炭酸カルシウム＋塩酸 → 二酸化炭素が出る → 500mLのフラスコへ。
  2. フラスコの中の空気が、同じ体積だけ押し出されて水そうのメスシリンダーに集まる。
  3. 二酸化炭素は240mL以下で、500mLの中に収まったまま。集まった気体は空気。
答え：空気
今回：48 ×。部品を拾えなかった＝設問の「何ですか」（気体の名前）と、図2の500mLのフラスコを見ていない。48は②の途中で出した「1.0gがとけきる塩酸の量」で、①では聞かれていない数。次は設問の聞き方に丸をつけ、装置を左から右へ指でたどる。

X復習 (3)② 塩酸60mLに炭酸カルシウム3.0g 条件文・どちらが先になくなるか

👀 まず見るところ

【まざり型→条件文】部品は「塩酸60mL」「炭酸カルシウム3.0g」に丸。表の正体は「炭酸カルシウム1.0gのとき」なので、3.0gをとかすのに塩酸が何mLいるかに直して書き、60mLと比べる。

📚 前提知識

  • 表の右2列（50mL・60mL）が同じ240mLになっているのは、1.0gを使いきった合図。それより手前は塩酸10mLにつき気体50mLの比例。
  • 気体の量は少ないほう（先になくなるほう）で決まる。

🔍 こう読み解く

  1. 使う式：気体（mL）＝塩酸（mL）×5（10mL→50mLの比例）。
  2. 1.0gの頭打ち240mLに必要な塩酸＝240÷5＝48mL。
  3. 3.0gをとかすには 48×3＝144mL いる。塩酸は60mLしかない → 先になくなるのは塩酸。
  4. 気体＝60×5＝300mL（炭酸カルシウムは余る）。
答え：300mL
今回：300 ○。

X復習 まとめ 7／10問・70点

  • (2)(3)の計算は5問中4問。「どちらが先になくなるか」を余白に1組書いてから決める手順（1.8−150／1.0−48−240）が身についている。
  • 落とした3問は型がちがう。(1)①は知識（燃える気体は水素だけ）、(2)③Bは直す順番（先に「2.4g→塩酸200」を書いてから÷2）、(3)①は設問の読み方（「何ですか」＝名前・装置を左から右へたどる）。
  • 次に同じ形が出たら、条件を変える問題は「高さ（金属の量）と横（濃さ）を分けて書く」、装置の問題は「設問の聞き方に丸→図を左から右へ」の2つを先にやる。

サンデーチェック-02 ABC復習（石灰石・アルミニウムと塩酸の気体計算）

ABC復習 全体像 10問（各10点）・気体の発生

前半は石灰石＋塩酸（二酸化炭素）、後半はアルミニウム＋塩酸（水素）。知識の一問一答が4問（(1)(2)(6)(7)）、残り6問は表とグラフから「過不足なく反応する1組」を取り出して比例で動かす計算である。

計算問題は、表かグラフで頭打ちになる点をさがし、その1組を先に余白へ書く。ここから先は全部この1組の倍数で決まる。

題材過不足なく反応する1組どこから読むか
石灰石＋塩酸塩酸150cm³ ＝ 石灰石0.6g → 気体180cm³表1で気体が180で止まる最初の列（エ）
アルミニウム＋塩酸アルミニウム0.125g ＝ 塩酸7.5cm³ → 気体125cm³図1で線が水平に折れ曲がる点（125cm³）

今回は10問中7問、70点。落とした3問は (3)(6)(10)。

ABC復習 (1) 二酸化炭素の重さは空気の何倍か 知識問題

約1.5倍。空気より重いので下方置換でも集められる。水素は空気の約0.07倍（いちばん軽い）、酸素は約1.1倍、と3つ並べて覚える。
答え：エ（1.5倍）
今回：エ ○。

ABC復習 (2) 二酸化炭素と確かめる方法 知識問題

石灰水を白くにごらせる。これが二酸化炭素だけの性質。アの「炎が消える」はちっ素でも起きるので決め手にならず、イは酸素、ウは水素、エはアンモニアや塩化水素の確かめ方。
答え：オ
今回：オ ○。

ABC復習 (3) 石灰石を足しても気体が出ない列 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「石灰石を加えても気体が発生しない」。これは「塩酸がもう残っていない」に直して書く。資料の正体は「塩酸150cm³に石灰石を足したときの気体の体積」→ 表1で気体が180で頭打ちになった列が答え。

📚 前提知識

  • 気体は、石灰石と塩酸のうち少ないほうがなくなった時点で止まる。表の値が増えている間は塩酸が余っていて、頭打ちになったら塩酸を使いきっている。

🔍 こう読み解く

  1. 気体の行を横に見る。0→60→120→180 と増え、180・180 で止まる。
  2. 止まった列＝エ・オ・カ。塩酸を使いきっているので、石灰石を足しても反応する相手がない。
  3. ア（石灰石0g）は塩酸150cm³がまるごと残っている。気体が0なのは、まだ何も入れていないだけ → 足せば発生する。
答え：エ・オ・カ
今回：ア・オ・カ ×。部品の形を直さなかった＝「気体が発生しない」を「塩酸が残っていない」に直さず、表の気体「0」につられてアを入れた形。次は聞かれ方を言いかえてから表を見る。エも頭打ちの最初の列なので入る。

ABC復習 (4) 塩酸200cm³と過不足なく反応する石灰石 条件文・比例

👀 まず見るところ

【条件文】部品は「過不足なく」と「塩酸200cm³」。表1から過不足なくの1組「塩酸150cm³＝石灰石0.6g」を余白に書く → 200cm³はその 200÷150 倍で決まる。

📚 前提知識

  • 頭打ちが始まる列（エ）が、塩酸150cm³をちょうど使いきる石灰石の量。0.6gで180cm³、0.8gでも180cm³なので、0.6gが境目。

🔍 こう読み解く

  1. 使う式：石灰石＝0.6×（塩酸÷150）。
  2. 0.6×（200÷150）＝0.6×4/3＝0.8g。
答え：0.8g
今回：0.8 ○。

ABC復習 (5) 塩酸100cm³に石灰石1.0g 条件文・どちらが先になくなるか

👀 まず見るところ

【条件文】部品は「塩酸100cm³」「石灰石1.0g」の2つ。(4)の1組「150cm³＝0.6g」のとなりに置き、塩酸100cm³がとかせる石灰石を先に出す → 0.4g。1.0gはそれより多いので塩酸が先になくなると決まる。

📚 前提知識

  • 2つの量が両方与えられたら、まず「どちらが先になくなるか」。気体の量は先になくなるほうで決まる。

🔍 こう読み解く

  1. 使う式：気体＝180×（塩酸÷150）（塩酸が足りない側なので塩酸で決める）。
  2. 塩酸100cm³がとかせる石灰石は 0.6×（100÷150）＝0.4g。1.0g入れても0.4gしかとけない。
  3. 気体は 180×（100÷150）＝120cm³。
答え：120cm³
今回：120 ○。

ABC復習 (6) 塩酸で水素が出る金属 知識問題

亜鉛・鉄・マグネシウム。塩酸にとける金属は「マグネシウム・アルミニウム・亜鉛・鉄」で、銅と銀はとけない。すべて選ぶ問題なので、4つ全部に○×をつける。
答え：ア・イ・エ
今回：ア・エ ×。知識＝鉄を落とした。「とけないのは銅・銀だけ」と、とけない側で覚えると残りが全部答えになる。

ABC復習 (7) 水上置換法で集められない気体 知識問題

アンモニアと塩化水素。水上置換ができないのは水によくとける気体。アンモニアは上方置換（空気より軽い）、塩化水素は下方置換（空気より重い）。二酸化炭素は少しとけるが、水上置換でも集められる。
答え：ウ・エ
今回：ウ・エ ○。

ABC復習 (8) 塩酸15cm³と過不足なく反応するアルミニウム 資料問題・折れ曲がる点＋比例

👀 まず見るところ

📚 前提知識

🔍 こう読み解く

  1. 図1の線は（6cm³、100cm³）を通るので、125cm³になるのは 6×125÷100＝7.5cm³。ここが折れ曲がる点。

  3. 15÷7.5＝2倍 → 0.125×2＝0.25g。

今回：0.25 ○。

ABC復習 (9) アルミニウム0.3gに塩酸12cm³ 条件文・どちらが先になくなるか

👀 まず見るところ

【条件文】部品は「アルミニウム0.3g」「塩酸12cm³」。塩酸12cm³がとかせるアルミニウムを1組から出す → 0.2g。0.3gはそれより多いので塩酸が先になくなる。気体は塩酸12cm³ぶんで決まる。

  2. 塩酸12cm³がとかせるアルミニウムは 0.125×（12÷7.5）＝0.2g。0.3g入れても0.2gしかとけない。

ABC復習 (10) 半分の濃さの塩酸48cm³ととけ残るアルミニウム 条件文・濃さの直し＋引き算

👀 まず見るところ

【条件文】部品は「半分の濃さの塩酸48cm³」と求めるもの「とけ残ったアルミニウム」。半分の濃さ48cm³は「もとの濃さ24cm³」に直して書く。「とけ残った」に丸 → 答えは 1.0−（とけた量）の引き算で終わる。

📚 前提知識

  • 濃さが半分なら、同じ体積にふくまれる塩酸のはたらきも半分。体積を半分にして、もとの濃さで考えると、図1の1組がそのまま使える。
  • 1組を「アルミニウム1g＝塩酸60cm³」と直しておくと計算が軽い（0.125g＝7.5cm³ を8倍）。

🔍 こう読み解く

  1. 使う式：とけるアルミニウム＝1×（もとの濃さの塩酸÷60）。
  2. 半分の濃さ48cm³ → もとの濃さ24cm³。
  3. 24÷60＝0.4g がとける。アルミニウムは1.0gあるので、塩酸が先になくなる。
  4. とけ残り＝1.0−0.4＝0.6g。
答え：0.6g
今回：4 ×。部品を拾えなかった＝求めるもの「とけ残った」に丸がなく、余白の「24」から濃さの直しはできていたのに、最後の 1.0−0.4 に進んでいない。「4」が0.4gのことか別の値かは答案から判断できない。次は答えを書く直前に「とけ残った」の丸を見直し、1.0からひく。
コツ：「濃さが半分」は体積を半分に直す。直した24cm³を図1の横軸の数として使えば、あとは(8)(9)と同じ1組の問題になる。
