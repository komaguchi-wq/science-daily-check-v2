X1 (1) 長さと20往復の時間のグラフ 資料問題・グラフ選び

📚 前提知識（あれば答え合わせに使う）

  2. 比例（イ）なら、25cmで20秒だから100cmは80秒のはず。表は40秒 → ×。
  3. 25cmごとの増え方を引き算で出す：20→28→35→40で、＋8、＋7、＋5。増え方がだんだん小さくなる。
  4. 上がり方がゆるやかになっていく曲線はエ。ウは増え方が大きくなっていく形なので逆。
答え：エ
コツ：グラフ選びは、表のとなりどうしの差を書き出す。差が同じなら直線、差が小さくなればエの形、大きくなればウの形。

Z2 (3)①② 固体と液体のエタノール 条件文・空らん補充

👀 まず見るところ

【条件文】部品は「液体100gの体積は117cm³」「固体100gの体積は107cm³」。聞かれているのは「同じ体積」。同じ重さで体積が小さい＝同じ体積なら重い、に直して書く → 固体は重く、沈むと決まる。

📚 前提知識

  • 同じ重さで体積が小さいものほど、中身がつまっている。同じ体積で比べると重い。
  • 液体に入れたとき、同じ体積の液体より重いものは沈み、軽いものは浮く。

🔍 こう読み解く

  1. 100gの体積は、固体107cm³・液体117cm³。固体のほうが小さい。
  2. 同じ体積にそろえると、固体のほうが重い → ①はア。
  3. 液体より重いので、固体のエタノールを液体のエタノールに入れると沈む → ②はエ。
答え：① ア　② エ
コツ：数字が小さいほうを「軽い」と決めない。紙面の数字は体積で、空らんは重さ。「同じ重さ→同じ体積」に直す一歩を書いてから選ぶ。

Z2 (3)③④ 氷と水 素材文・空らん補充

👀 まず見るところ

【素材文】部品は手がかりの言葉「また、水は」に丸。「また」で話がエタノールから水に変わる。水には数字が書かれていないので、氷は水に浮くという知っている事実から逆にたどって決める。

📚 前提知識

  • 氷は水に浮く。浮くということは、同じ体積の水より軽いということ。
  • 水はこおると体積が増える。同じ重さで体積が大きくなるので、同じ体積なら軽くなる。エタノールとは逆である。

🔍 こう読み解く

  1. ④から先に決める。氷を水に入れると浮く → ④はウ。
  2. 浮くのは同じ体積の水より軽いから → ③は軽（イ）。
  3. ①②（重・沈む）と③④（軽・浮く）が逆の組になっていることを確かめる。
答え：③ イ　④ ウ
コツ：エタノールは「固体が重くて沈む」、水は「固体が軽くて浮く」。逆の組として両方セットで書いておく。
