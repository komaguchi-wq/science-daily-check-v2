JF-04 Ⅰ 日時計と夏の星の動き・Ⅱ 南中時刻と星座早見

Ⅰ 全体像 日時計5問＋夏の星5問（各10点）

前半（1〜5）は、地面に垂直に立てた板に棒をつけた日時計。ふつうの日時計とちがい、影は地面でなく板にうつる。だから「太陽が上にあれば影は下にのびる」「太陽が板の裏にあれば影はうつらない」の2つで、5問とも決まる。横から見た図を1つ描けるかどうかが入口になる。

後半（6〜10）は、太陽と星の道すじを12個の図から選ぶ。図は全部同じ向きで、手前が東（矢印の出発点＝出る側）、左が南、右が北。横の直線が南北線、ななめの線が東西線で、出・入りの点がこの線から右にずれていれば北寄り、左なら南寄りである。この1行を書いてから、次の表の4つの型に当てはめる。

聞かれたもの出るいちばん高い所しずむ図
東京・7月の太陽北東南の空・高い北西シ
ニュージーランド・7月の太陽（冬）北東北の空・低い北西ケ
星H（アンタレス）・東京南東南の空・低い南西オ
星H・ニュージーランド南東北の空・高い南西コ

今回は10問中4問（3・6・7・8）、40点。落とした6問のうち4問は日時計で、どれも「板にうつる影」を横から見た図にしていない失点。星の2問は、星の道すじが季節で変わらないことを知っていれば6と同じ図で取れた。

Ⅰ 1 指時針を向ける方位 条件文・漢字1字

👀 まず見るところ

【条件文】部品は「地面に垂直に立てた板」と「できるだけ長く」。影は板にうつるので、板が太陽の側を向いている時間しかはかれない → 太陽が長くいる方位に棒を向ける、と決まる。

📚 前提知識

  • 東京では太陽は東からのぼり、南の空を通って西にしずむ。1日のうち長い時間、太陽は南側の空にある。
  • この日時計は、棒（指時針）の影を板で読むしくみ。太陽が板の裏側にあると、影は板にうつらない。

🔍 こう読み解く

  1. 板は地面に垂直なので、表と裏がある。表に影ができるのは、太陽が表側の空にあるときだけ。
  2. 太陽がいちばん長くいるのは南の空 → 板の表を南に向ける。棒は板に垂直だから、棒も南向き。
  3. 漢字1字なので「南」。
答え：南
今回：北 ×。知識＝北極星の方に棒を向ける日時計（地面に影を落とすもの）と混ざった形。この日時計は「板にうつる影」を読むので、板の表が太陽を向く方位＝太陽が長くいる南と決める。「地面に垂直な板」に丸をつけてから方位を考える。

Ⅰ 2 正午の影の向き 条件文・横から見た図に直す

👀 まず見るところ

【条件文】部品は「正午」と、図の注「正面から見た棒」。正午の太陽は南の高い所にある → 板を横から見た図に直して書く（太陽は棒の先の上、影は根もとの下）→ 向きが決まる。

📚 前提知識

  • 正午（南中）の太陽は真南の高い所。南向きの板から見れば、太陽は正面の上にある。
  • 影は光と反対の側にできる。上から光が来れば、影は下にのびる。

🔍 こう読み解く

  1. 横から見た図を描く。板は縦の線、棒は南へ横にのびる線、太陽は右上。
  2. 光は右上から左下へ。棒の影は、根もとから板の真下へのびる。
  3. 正面の図では下＝C。太陽が真南なので、左右にはずれない。
答え：C
今回：A ×。部品の形を直さなかった＝「地面に垂直な板」を横から見た図にせず、地面にできる影（正午は北にのびる）と同じに考えた形。板にうつる影は、太陽が上にあれば下にのびる。横から見た図を1つ描けば向きは決まる。

Ⅰ 3 影が回る向き 条件文・3つの時刻を置く

👀 まず見るところ

【条件文】部品は選択肢の「BからCの時計回り」「CからBの反時計回り」。朝・正午・夕方の太陽を図に置く → 影の3点がA〜Dのどこかで、回る向きが決まる。

📚 前提知識

  • 太陽は東→南→西と動く。南向きの板を正面から見るとき、自分は北を向いているので、右手が東、左手が西。
  • 影は太陽と反対側にできる（問2）。

🔍 こう読み解く

  1. 朝：太陽は東（図の右・B側）→ 影は左のD。
  2. 正午：太陽は南の高い所 → 影は下のC。
  3. 夕方：太陽は西（図の左・D側）→ 影は右のB。
  4. D→C→B の順に動く。左→下→右は反時計回り。
答え：反時計（回り）
今回：反時計 ○。朝・昼・夕の3点を置いて向きを決められている。

Ⅰ 4 1時間ごとの影の向き 資料問題・影は横線より下

👀 まず見るところ

【資料問題】部品はア〜エの正体「1時間ごとの影の向き」。日が出ているあいだ太陽はいつも地平線より上 → 板にうつる影はいつも横線より下。下半分だけに広がる図から選ぶ。

📚 前提知識

  • 太陽が上にあるかぎり、棒の影は根もとから下向きにのびる（問2）。影が上を向くのは太陽が地面より下にあるときで、ありえない。
  • 朝夕は太陽が低いので影は横に近く、正午は太陽が高いので影は真下に近い。

🔍 こう読み解く

  1. イ・エは上にも線がある → 太陽が地面の下にあることになり×。
  2. アは線が全部上向き → これは太陽のある向きを描いた図で、影はその反対。
  3. ウは真下を中心に下半分だけ → 朝は左横近く、正午は真下、夕方は右横近く、と合う。
答え：ウ
今回：ア ×。部品の形を直さなかった＝太陽のある向きをそのまま線にして、「影は反対向き」に直していない。問2でCと決めたのだから、正午の線が真下にある図を選ぶ。

Ⅰ 5 影が観察できない時間帯 条件文・完答

👀 まず見るところ

【条件文】部品は「7月」と「日が出ていても観察できない」。7月の太陽は北東から出て北西にしずむ → 日の出・日の入りのころは太陽が板の裏（北側）にある、と決まる。

📚 前提知識

  • 夏（7月）の日の出は真東より北寄り、日の入りは真西より北寄り。春分・秋分は真東・真西、冬は南寄り。
  • 南向きの板は、太陽が真東〜真西の線より北にあるあいだ、裏から照らされる＝表に影ができない。

🔍 こう読み解く

  1. 問1で板の表は南向き。表に影ができるのは太陽が南側の空（真東〜南〜真西）にあるとき。
  2. 7月の日の出直後、太陽は北東＝板の裏側 → 影は見えない（ア）。
  3. 日の入り前、太陽は北西＝裏側 → 見えない（イ）。
  4. 午後2時の太陽は南西で表側 → ウはちがう。エは「ずっと見えた」で×。答えは2つ。
答え：ア・イ（完答）
今回：ウ ×。部品を拾えなかった＝「7月」に丸がなく、日の出・日の入りの方位が北寄りになることを使っていない。次は「7月」を見たら日の出＝北東と書いてから、板の向きと重ねる。

Ⅰ 6 東京とニュージーランドの太陽の動き 資料問題・図の向きを決める

👀 まず見るところ

【資料問題】部品は12個の図の正体。横の直線が南北線、ななめの線が東西線。矢印の出発点（出る側）が手前なので、手前＝東、左＝南、右＝北。この1行を書けば、出る方位・山の高さと左右・矢印の向きで選べる。

📚 前提知識

  • 東京の7月：北東から出て、南の空の高い所を通り、北西にしずむ。昼が長い。
  • ニュージーランドは南半球で、7月は冬。北東から出て、北の空の低い所を通り、北西にしずむ。昼が短い。
  • 南半球でも太陽は東から出て西にしずむ。北の空を通るので、動きは左右が逆に見える。

🔍 こう読み解く

  1. 出・入りの点が東西線から右（北）にずれている図＝北東から出る → カ・ク・ケ・シ。
  2. 東京は山が左（南）で高い → シ。カは矢印が逆向き（奥＝西から出ている）。
  3. ニュージーランドは山が右（北）で低い → ケ。クは矢印が逆向き。
答え：東京 シ　ニュージーランド ケ
今回：シ・ケ ○。図のアに「南」「北」と書きこんで向きを決めてから選べている。

Ⅰ 7 天の川の位置 資料問題・夏の大三角

👀 まず見るところ

【資料問題】部品は図の正体「7月22時の空・E〜Hの星」。E・F・Gは夏の大三角。天の川ははくちょう座（E）の中を通り、こと座（F）とわし座（G）の間を流れる → Eを通ってFとGを分ける帯が答え。

📚 前提知識

  • 夏の大三角＝こと座ベガ・わし座アルタイル・はくちょう座デネブ。図の形で見分ける：十字（はくちょう座）の先がE、小さな平行四辺形のそばがF、3つ並びのまん中がG。
  • 七夕の織姫（ベガ）と彦星（アルタイル）は天の川をはさんで向かい合う。はくちょう座は天の川の中を飛ぶ。
  • 天の川は、はくちょう座からわし座を通って、南の地平線近くのさそり座・いて座の方へ流れる。南に近いほど濃い。

🔍 こう読み解く

  1. ウ・エは帯がF（ベガ）を通っている → ×。
  2. 残るア・イはどちらもFが外。イは帯がEのはしをかすめてまっすぐ下へ流れ、図の右下にあるHの方へ向かっていない。
  3. アは帯がEとGを通り、図の右下にあるH（さそり座）の方へ流れている → ア。
答え：ア
今回：ア ○。ベガが川の外、デネブとアルタイルが川の中、で選べている。

Ⅰ 8 最もしずむのがおそい星 資料問題＋知識・完答

👀 まず見るところ

【資料問題】部品は聞かれ方「最も沈むのが遅い」とE〜Hの正体。しずむのがおそい＝北極星に近い星（地平線の上にいる時間が長い）。4つのうちいちばん北寄りの星を正体から決める。

📚 前提知識

  • 星は北極星を中心に回る。北極星に近い星ほど地平線の上を回る時間が長く、十分近い星は1日中しずまない。
  • E＝デネブ（はくちょう座）、F＝ベガ（こと座）、G＝アルタイル（わし座）、H＝アンタレス（さそり座）。この中で北極星にいちばん近いのがデネブ、いちばん南にあるのがアンタレス。

🔍 こう読み解く

  1. Hは図でも地平線のすぐ上（南の低い空）→ 最初にしずむ。
  2. 残りは夏の大三角。はくちょう座は3つの中でいちばん北寄りで、東京では1日の大半を地平線の上で過ごす → 最後にしずむのはE。
  3. 記号E・星の名前デネブの両方で1問。
答え：記号 E　星の名前 デネブ（完答）
今回：E・デネブ ○。地平線に近いHを先に外し、残る3つから北寄りのはくちょう座を選べている。

Ⅰ 9 星Hの動き（東京とニュージーランド） 資料問題・6の図を使い回す

👀 まず見るところ

【資料問題】部品は「右上の図のH」＝地平線のすぐ上にあるさそり座アンタレスと、聞かれ方「6のア〜シから」。Hは東京で南の低い空しか通らない星 → 6で決めた向き（左＝南）で、山が左で低い図を探す。

📚 前提知識

  • さそり座（アンタレス）は夏の夜、南の地平線近くに見える。東京では南東から出て、南の空の低い所を通り、南西にしずむ＝冬の太陽とほぼ同じ道すじ。
  • 南半球（ニュージーランド）では同じ星が北の空の高い所を通る。出る方位・しずむ方位（南東・南西）は変わらない。

🔍 こう読み解く

  1. 東京：出・入りが東西線より左（南）にずれ、山が左（南）で低く、矢印が手前（東）から出ている図 → オ。キは矢印が逆向き。
  2. ニュージーランド：出・入りは左（南）ずれのまま、山が右（北）で高い → コ。サは矢印が逆向き。
  3. 「近いものがない場合は×」とあるが、どちらも図の中にある。
答え：東京 オ　ニュージーランド コ
今回：東京 ×・ニュージーランド エ で ×。部品を拾えなかった＝「Hは地平線のすぐ上」から南の低い空を通る星と決められず、東京を「近いものがない」にした。エは出・入りが真東・真西の図で、南寄りの出・入りになっていない。次は6で書いた「左＝南」をそのまま使い、Hを冬の太陽に置きかえて選ぶ。

Ⅰ 10 半年後の星Hの動き 条件文・前と変わった言葉

👀 まず見るところ

【条件文】9と変わった部品は「7月から半年後」だけ。星の道すじは季節で変わらない（変わるのは見える時刻だけ）→ 答えは9と同じ、と決まる。

📚 前提知識

  • 太陽の道すじは季節で変わる（地球の軸がかたむいたまま公転するから）。星の道すじは、その星の位置（北極星からの角度）だけで決まり、1年中同じ。
  • 季節で変わるのは「何時に南中するか」で、1か月に2時間ずつ早くなる。半年後のアンタレスは昼間に南中して夜には見えないが、通る道すじは同じ。

🔍 こう読み解く

  1. 半年後＝1月。太陽は冬の低い道に変わるが、星Hはもともと「冬の太陽と同じ道」を1年中通っている。
  2. 東京はオ、ニュージーランドはコのまま。
  3. 「見えないから×」ではない。聞かれているのは動き（道すじ）。
答え：東京 オ　ニュージーランド コ
今回：東京 ア・ニュージーランド × で ×。知識＝太陽の道すじが季節で変わることを、星にも当てはめた形。「星の道すじは1年中同じ。季節で動くのは太陽だけ」と1行覚えれば、9と同じ答えを書くだけになる。

  • 取れたのは 3・6・7・8。12個の図の向きを自分で書きこんで決めた6、夏の大三角と天の川の7・8は知識がしっかりしている。
  • 落とした6問は2つの型。①日時計の1・2・4・5＝「地面に垂直な板」を横から見た図に直していない（太陽が上なら影は下、太陽が裏なら影なし）。②星の9・10＝Hの正体（南の低い空のアンタレス）と、星の道すじは季節で変わらないこと。

1は表から南中時刻と南中高度を出す計算、2は星座早見の回し方と南中時刻。どちらも「1度＝何分」「1か月＝何度」の決まりを1つ書いてから、差を足すか引くかを決めるだけである。計算そのものは1〜2行で終わる。

使う決まり数向き

Ⅱ 1問1 明石の南中時刻 条件文・経度1度＝4分

👀 まず見るところ

【条件文】部品は「明石 東経135.0度」と答え方「何時何分何秒」。表のどれか1つの都市の南中時刻を出し、経度の差×4分で明石に直して書く。

📚 前提知識

  • 南中時刻＝（日の出＋日の入り）÷2。
  • 地球は24時間で360度回るので、経度1度＝4分。東にある地点ほど南中が早い。明石は札幌より西（経度が小さい）なので、おそくなる＝足す。
  • 「分」の小数は秒に直す。0.6分＝36秒。

🔍 こう読み解く

  1. 札幌：(4:23＋18:57)÷2＝23:20÷2＝11:40。
  2. 経度の差 141.4−135.0＝6.4度 → 6.4×4＝25.6分。明石は西なので足す。
  3. 11:40＋25.6分＝12時5.6分＝12時5分36秒。
答え：12時5分36秒
今回：12時5分36秒 ○。答案はさいたま（経度差4.4度＝17分36秒）を使い、日の出と日の入りをそれぞれおくらせてから÷2。別の筋道だが、答えは一致している。

Ⅱ 1問2 那覇の南中高度 条件文・緯度1度＝高度1度

👀 まず見るところ

【条件文】部品は「札幌で65.3度」と那覇の「北緯26.1度」。南中高度は緯度が1度低いほど1度高い → 緯度の差を65.3に足す向き、と先に決める。

📚 前提知識

  • 太陽の南中高度＝90度−緯度＋（その日の太陽のかたむき）。夏至なら＋23.4度。同じ日なら最後の数はどこでも同じなので、ちがうのは緯度の分だけ。
  • 緯度が低い（南にある）ほど太陽は高い。那覇は札幌より17度南。

🔍 こう読み解く

  1. 緯度の差 43.1−26.1＝17度。
  2. 那覇のほうが南＝高くなる → 65.3＋17＝82.3度。
  3. 検算：札幌の式 90−43.1＋□＝65.3 → □＝18.4。那覇 90−26.1＋18.4＝82.3 で一致。
答え：82.3度
今回：48.3 ×（65.3−43.1＝22.2、26.1＋22.2）。知識＝南中高度の式は「90−緯度＋□」で、緯度は引く向き。答案は「緯度＋22.2」と足す形で、緯度が大きいほど高くなる式になっている。次は式を 90−緯度＋□ と先に書き、札幌で□を出してから那覇に入れる。

Ⅱ 2問3 星Xを南中させる回し方 資料問題・日付の目盛りが分度器

👀 まず見るところ

🔍 こう読み解く

  1. 中心とXを結んで外の目盛りまでのばすと10月15日ごろ。中心と地平盤の「南」を結ぶと12月15日ごろ。
  2. 差は2か月＝60度。Xは南中したあと60度動いたところ（南から西へ向かう側）にいる。

Ⅱ 2問4 8月15日に星Xが南中する時刻 条件文・2つとも「前」にずらす

👀 まず見るところ

【条件文】部品は「8月15日」と答え方「24時制」。問3の「南中後60度」を時間に直して書く（60÷15＝4時間前）→ 6月15日の南中時刻が出て、2か月後はさらに早くなる。

  1. 6月15日：午前0時に南中後60度 → 南中は4時間前の20時。
  2. 8月15日は2か月後 → 2×30＝60度＝4時間早い。20−4＝16時。

  • 取れたのは問1。経度1度＝4分を、日の出・日の入りの両方に当ててから÷2という自分の筋道で通している。計算力は足りている。

JF-04 Ⅲ てこのつり合い（重さのある棒・バットの重心）

Ⅲ 全体像 4問（各25点）

1は太さが一様な棒、2はバット。どちらも棒そのものに重さがあるてこで、やることは1つ。棒の重さを重心の1点に矢印で置いてから、支点まわりの式を立てる。ふつうのてこと同じ式に、矢印が1本足されるだけである。

差がつくのは「重心がどこか」を先に1行書けるかどうか。1は重心が棒のまん中にある（太さが一様）、2は重心がまん中にない（バット）ので、問3に入る前に図3から重心の位置を出しておく。問3も問4も、その1つの数を使い回す。

図3で支えているもの支える重さ重心までの距離
床（A）360−240＝120g30cm（遠い）
ばねばかり（B・中央45cm）240g15cm（近い）
支える重さの比 120:240＝1:2 → 重心までの距離は逆の 2:1 → 45cmを 30cm と 15cm に分ける

今回は4問中1問、25点。落とした3問はいずれも重心の位置がずれた失点で、式の立て方そのものは3問とも合っている。

Ⅲ 1問1 棒の重さ 条件文・式を2本立てる

👀 まず見るところ

【条件文】部品は「太さが一様な棒」と、図1→図2で変わった「6.4cmのC点」「12.5gのコイン」。棒の重さは棒のまん中に矢印○gで置く（直して書く）→ ひもを支点にした式が図1・図2で2本立ち、支点のずれ 8.0−6.4＝1.6cm が決め手になる。

📚 前提知識

  • 太さが一様な棒の重さは、まん中（重心）1点に全部かかっているとみなせる。ひもで持つ点が支点、そこから左回り＝右回りで式を立てる。
  • 重心の位置は棒を動かしても変わらない。支点だけが動いたとき、支点から重心までの距離は支点が動いた分だけ変わる。

🔍 こう読み解く

  1. 図1：支点B、Bから重心までを□cmとして、8.0×30＝□×○ → □×○＝240。
  2. 図2：支点Cは1.6cmだけAに近いので、重心までは□＋1.6。コップは30＋12.5＝42.5g。6.4×42.5＝（□＋1.6）×○ → □×○＋1.6×○＝272。
  3. 2本の差をとると 1.6×○＝272−240＝32 → ○＝20g。
答え：20g
今回：20 ○。答案は「8.0×30＝棒×□（240）」「42.5×6.4＝棒×□＋棒×1.6（272）」「32＝棒×1.6」と、解答・解説と同じ2本の式を立てて差をとれている。重心を□で置いて消す筋道が身についている。

Ⅲ 1問2 棒の長さ 条件文・前問の□を使う

👀 まず見るところ

【条件文】設問は「棒の長さ」。部品は図1の「A点から8.0cmのB点」と、問1で置いた□（Bから重心まで）。□はBからの長さなので、Aから重心までは 8.0＋□ に直して書く → 重心はまん中だから、それを2倍したものが棒の長さ。

📚 前提知識

  • 太さが一様な棒は重心がまん中。だから「はしから重心までの距離×2＝棒の長さ」。
  • 問1で□を消して○を出したら、こんどは○を使って□にもどる。前の問いの式はそのまま残しておく。

🔍 こう読み解く

  1. 問1の式 □×20＝240 から、□＝12cm（Bから重心まで）。
  2. Aから重心までは 8＋12＝20cm。
  3. 重心はまん中なので、棒の長さは 20×2＝40cm。
答え：40cm
今回：24 ×。答案は「8×30＝20×□ → □＝12 → 12×2＝24」。□＝12まで正しい。部品の形を直さなかった＝□はBから重心までの長さで、棒のはしAからは 8＋12＝20。Aからの長さに直す前に2倍してしまった。次は図に「Aから重心＝8＋□」と書いてから2倍する。

Ⅲ 2問3 バットを水平にするおもり 条件文・重心を先に出す

👀 まず見るところ

【条件文】部品は「中央B」「ばねばかりの目もりは240g」と、バットの「360g」。360−240＝120gを床の支えとしてAに上向きの矢印で置く（直して書く）→ 2つの支え120:240からバットの重心の位置が決まり、その1つの数が問3・問4の両方で使う部品になる。

📚 前提知識

  • バットは太さがちがうので、重心はまん中ではなく太いほう（A側）に寄っている。だからまず図3で重心の位置を求める。
  • 2か所で支えられた棒は、支える重さの合計＝棒の重さ。支える重さの比と、重心までの距離の比は逆になる（重い側が重心に近い）。

🔍 こう読み解く

  1. 床が支える重さは 360−240＝120g。支えの比 A:B＝120:240＝1:2。
  2. 重心までの距離は逆の2:1。AからBまでの45cmを 30cm と 15cm に分ける → 重心はAから30cm、Bから15cm（Aまわりの式 360×□＝240×45 でも同じ30cm）。
  3. 問3：Bを支点にすると、左15cmに360g、右20cmにおもり。360×15＝おもり×20 → おもり＝270g。
答え：270g
今回：162 ×。答案は「360×9＝20×おもり」。式の形（Bを支点に 360×重心までの距離＝おもり×20）は合っていて、重心までを15cmでなく9cmとしたのが原因である。部品の形を直さなかった＝「ばねばかり240g」から 360−240＝120g の床の支えを作ってAに置かず、重心の位置を出す段が抜けた。次は図3に120gの矢印を描き、重心の位置を1行書いてから問3に入る。

Ⅲ 2問4 両端に90gをつけてつるす位置 条件文・重心を受けつぐ

👀 まず見るところ

【条件文】前と変わった部品は「両端に90g」と、答え方「Aから何cm」。90gを両はしに矢印で置き、問3で出した重心（Aから30cm・360g）の矢印もそのまま残す → ひもの位置をAから□cmと置けば、Aまわりの式1本で決まる。

📚 前提知識

  • ひもで持つ力＝全部の重さの合計。90＋360＋90＝540g。
  • 支点をA（はし）にとると、Aについた90gは距離0で式から消える。計算する矢印が2本に減る。

🔍 こう読み解く

  1. Aのまわりで、下向きの矢印のモーメント：バット 30×360＝10800、右はしの90g 90×90＝8100。Aの90gは距離0。
  2. 上向きはひもの540gだけ。540×□＝10800＋8100＝18900。
  3. □＝18900÷540＝35cm。
答え：35cm
今回：答えらん空らん ×。答案は「36×360＋90×90＝540×?」まで書けていて、Aまわりの式の形は解答・解説と同じである。重心をAから36cm（Bから9cm。問3で使った9cmと同じ位置）としたうえ、足し算も 21660 とずれて 540 で割り切れず、答えを書けなかった。部品の形を直さなかった＝問3と同じ重心のずれ。重心を30cmに直せば、この式のまま35cmが出る。
コツ：重さのある棒の問題は、最初に「重心はどこ・何g」を1行書く。その1行が小問ぜんぶの共通の部品になる。ずれたまま進むと、式が合っていても全部ずれる。

Ⅲ まとめ 1／4問・25点

  • 取れたのは問1。式を2本立てて差をとる、この大問でいちばん手数の多い問題を通している。問3・問4も式の形は正しく、てこの式の立て方は分かっている。
  • 落とした3問は全部「重心の位置」のずれ。問2は Bからの□をAからの長さに直さず2倍した。問3・問4は 床の支え120gを置かずに重心を出したため、30cmが36cmにずれた。
  • 次に同じ形が出たら、式を立てる前に図へ2つ置く。①棒の重さを重心に矢印（まん中か、支えの比から出した位置か）②聞かれている長さの起点（Aから／Bから）を矢印の根もとに書く。
