JF-05 Ⅰ 熱（沸騰石・複層ガラス・熱の伝わり方）

Ⅰ 全体像 熱・7題10問（各10点）

「熱」を題材にした小問集合である。沸騰石、複層ガラス、非接触式温度計、ロウをぬった金属板、氷がとける時間、金属棒とロウソク、さわった物の温度、と場面は7つあるが、背すじは1本で、熱の伝わり方3つ（伝導・対流・放射）と「熱は温度の高い方から低い方へ、同じ温度になるまで動く」という決まりである。

問場面使う決まり
1沸騰石と突沸穴の中の空気が沸騰の「きっかけ」になる
2複層ガラス動かない空気は熱を伝えにくい／動くと対流で熱を運ぶ
3非接触式温度計物は温度に応じて赤外線を出す（放射）
4・6金属板・金属棒伝導は熱源から同じ速さで広がる／金属の種類で伝わりやすさがちがう
5氷がとける時間伝わる熱の速さは温度差に比例 → 温度差×時間が一定
7さわった物の温度同じ部屋の物は同じ温度。冷たく「感じる」のは熱がにげる速さの話

今回は10問中6問、60点。計算と作図（4・5）と文章の読み取り（1・2）は取れている。落とした4問のうち3問（3・7(1)・7(2)）は知識の問題（物が自分で出す光＝赤外線、「冷たく感じる」と「温度が低い」は別）で、残り1問（6）はグラフに線を置かずに数えた失点である。

Ⅰ 1(1) 沸騰石が突沸を防ぐ仕組み 素材文・正しいもの

👀 まず見るところ

【素材文】設問は「突沸を防ぐ仕組み」。部品は本文の「沸騰が始まるきっかけ」と「小さな穴がたくさん」に丸 → 穴が「きっかけ」を作る、と言っている選択肢を選ぶ。

📚 前提知識

  • 突沸＝100℃を過ぎても沸騰が始まらない水（過熱）が、きっかけを得て一気に沸騰すること。きっかけ＝泡の種になる小さな気体。
  • 沸騰石は穴の中に空気をふくんでいる。その空気の粒が水蒸気の泡の種になり、100℃でおだやかに沸騰が始まる。

🔍 こう読み解く

  1. ア「大きな泡を小さくする」→ できてしまった泡を小さくする話。本文の「きっかけ」と合わない → ×。
  2. ウ・エ「熱をゆるやかに伝える」「温度上昇がゆるやか」→ 沸騰石は熱の伝わり方を変える道具ではない。温度の上がり方をゆるめても、きっかけがなければ突沸は起こる → ×。
  3. イ「穴から空気の泡が出て、それを中心に水蒸気の泡が成長」→ これがきっかけそのもの → ○。
答え：イ
今回：イ ○。本文の「きっかけ」を選択肢にあてはめて選べている。

Ⅰ 1(2) 沸騰や沸騰石の使い方 素材文・正しいもの（2つ）

👀 まず見るところ

【素材文】聞かれ方は「正しいもの」で、1つとは限らない。部品は選択肢ごとの決め手「100℃にして」「直前に」「穴がたくさんあいた固体」「穴に水が残っている」に丸 → 4つ全部に○×をつけてから書く。

📚 前提知識

  • 蒸発（液体→気体）は100℃でなくても起こる。洗濯物がかわくのがその例。沸騰は100℃で水の中からも気体になること。
  • 沸騰石は加熱する前に入れる。熱くなった水に入れると、それ自体がきっかけになって突沸する。一度使って穴に水が入ったものは空気がないので、きっかけを作れない。

🔍 こう読み解く

  1. ア「100℃にしないと気体にならない」→ 蒸発は100℃未満でも起こる → ×。
  2. イ「沸騰する直前に入れる」→ 入れるのは加熱前。直前に入れると突沸のもと → ×。
  3. ウ「小さな穴がたくさんあいた固体なら代わりになる」→ 本文の条件は「穴がたくさん」なので、同じ性質の固体（素焼きのかけらなど）で代用できる → ○。
  4. エ「穴に水が残ったままの沸騰石は使わない」→ 空気がない＝きっかけが作れない → ○。
答え：ウ・エ
今回：ウ・エ ○。2つとも拾えている。

Ⅰ 2(1) 複層ガラスと同じ仕組みのもの 素材文・もっとも近いもの

👀 まず見るところ

【素材文】部品は図の「中空層」（2枚のガラスにはさまれた空気）と設問の「もっとも近い仕組み」に丸 → 「空気をとじこめて熱を伝えにくくする」と同じ仕組みをさがす。

📚 前提知識

  • 熱の伝わり方は3つ。伝導（物の中を伝わる）・対流（気体や液体が動いて運ぶ）・放射（光として飛ぶ）。
  • 空気は熱を伝えにくい。動かないようにとじこめると断熱材になる。発泡スチロール・羽毛・二重窓は全部この仕組み。

🔍 こう読み解く

  1. ア 魔法瓶の鏡のメッキ → 熱の光をはね返す＝放射を防ぐ話。
  2. ウ 冷房の風を上向き → 冷えた空気が下へ降りる動きを使う＝対流の話。エ ストーブの正面だけ暖かい → 放射の話。
  3. イ 発泡スチロール → 小さな泡に空気をとじこめた材料。中空層と同じ仕組み → ○。
答え：イ
今回：イ ○。伝導・対流・放射の仕分けができている。

Ⅰ 2(2) 中空層を厚くしすぎると効果が下がる理由 記述

👀 まず見るところ

【素材文】部品は設問の「空気が入っている中空層」と「厚くしすぎると」に丸 → 空気はじっとしていれば熱を伝えにくいが、動けば熱を運ぶ。「厚い → 動ける」が答えの中心。

📚 前提知識

  • 気体や液体が動いて熱を運ぶことを対流という。すき間がせまいと空気は動けないが、広くなると温かい側で上がり冷たい側で下がる流れができる。

✍️ 答案の組み立て

  1. 要素A：中空層が厚いと、中の空気が動きやすくなる。
  2. 要素B：動いた空気が熱を運ぶ＝対流が起こる。
  3. 出力の形：「（中の空気が動きやすくなり）（対流が起こる）から。」
模範解答：中の空気が動きやすくなり、対流が起こるから。
今回：「対流できるように空気が入るから」○。要素チェック＝A（空気が動く）○／B（対流）○。「空気が入る」より「空気が動ける」のほうが、厚さとのつながりがはっきりする。

Ⅰ 3 非接触式温度計がはかる光 知識問題

赤外線。すべての物は温度に応じて赤外線（目に見えない光）を出していて、温度が高いほど多く出す。非接触式温度計はその量を読んで温度にしている。太陽光は太陽が出す光で、物が自分で出す光ではない。漢字指定。
答え：赤外線
今回：太陽光 ×。知識＝「物から出る光」を「物に当たる光」と取りちがえた。放射＝物が赤外線を出すこと、とセットで覚え直す。

Ⅰ 4 ロウが透明になった場所 条件文・作図

👀 まず見るところ

【条件文】部品は「1つの角に細い金属棒」と「点Pのロウが透明になったとき」に丸。熱の入口は角の1点 → その角を中心に、Pを通る円を図にかく（図に置く）。

📚 前提知識

  • 一様な板の中を伝導で広がる熱は、熱源から同じ距離の点に同じ時間で届く。だからとけた範囲は熱源を中心とした円になる。

🔍 こう読み解く

  1. 熱の入口は棒をつけた左の角。板の中をそこから円形に広がる。
  2. Pまで届いたなら、角からPと同じ距離の点にも届いている → 角を中心、角〜Pを半径とする円。
  3. 円の内側で板にかかる部分（角に近い側）に斜線。角の外には板がないのでかかない。
答え：棒をつけた角を中心に点Pを通る円弧をかき、角とその弧の間に斜線（別紙の図のとおり）
今回：○。角を中心にした弧で区切った範囲に斜線がかけている。

Ⅰ 5 外側350℃のとき氷がとけるまでの時間 資料問題・表の計算

👀 まず見るところ

【資料問題】表の正体を1行「外側の温度と、氷がすべてとけるまでの時間」。内側は0℃で変わらないので外側の温度がそのまま温度差 → 上下の数をかけてみると全部25200、反比例と決まる。

📚 前提知識

  • 1秒に伝わる熱の量は温度差に比例する。氷をとかすのに必要な熱は毎回同じ量なので、温度差×時間＝一定（反比例）。
  • 氷がとけている間、内側は0℃のまま。だから温度差＝外側の温度−0。

🔍 こう読み解く

  1. 表で確かめる：630×40＝25200、560×45＝25200、105×240＝25200。どの列も同じ。
  2. 350℃なら 25200÷350＝72。
  3. 割り切れたので四捨五入はいらない。「割り切れない場合は」の一文は、割り切れないと思いこませる書き方。
答え：72秒
今回：72 ○。表の積が一定になることを見つけて計算できている。

Ⅰ 6 金属棒に残るロウソクの本数 まざり型・グラフの読み取り

Ⅰ 7(1) 室内の金属とプラスチックの温度 素材文・選択

👀 まず見るところ

【素材文】部品は「室内に置いてある」と設問の「温度はどちらが高いか」に丸。聞かれているのはさわった感じではなく温度 → 同じ部屋に置いてある物は同じ温度、で決まる。

📚 前提知識

  • 熱は温度の高い方から低い方へ動き、同じ温度になると止まる。長く同じ部屋に置かれた物は、材料に関係なくまわりの空気と同じ温度になる。

🔍 こう読み解く

  1. 20℃の部屋なら、金属もプラスチックも20℃。
  2. 「金属は冷たい」は手の熱のにげ方のちがいで、温度のちがいではない → 同じ温度＝ウ。
答え：ウ
今回：イ ×。知識＝「冷たく感じる＝温度が低い」と取りちがえた。「感じ方」と「温度」を別の言葉として持ち、設問がどちらを聞いているかに丸をつける。

Ⅰ 7(2) 5分握ったあとの温度 素材文・選択

👀 まず見るところ

【素材文】部品は「握り、5分経つと」に丸。手（36℃ほど）に5分ふれた小さな球は、材料に関係なく手と同じ温度に落ち着く → 同じ、で決まる。

📚 前提知識

🔍 こう読み解く

  1. 握った直後：金属のほうが速く手の熱をもらい、プラスチックはゆっくり。
  2. 5分後：小さな球なので両方とも手の温度に追いついている → 同じ温度＝ウ。

今回：ア ×。知識＝「伝わりやすい＝より熱くなる」と考えた。伝わりやすさは速さの話で、行きつく温度は手の温度でそろう。(1)と(2)は「最初も最後も同じ温度」の組で覚え直す。

Ⅱ 1問1 1分間に加えられた熱 まざり型・グラフの水の区間で計算

👀 まず見るところ

【まざり型→条件文】部品は「水1gの温度を1℃上げる＝1cal」と「氷が100g」。calの決まりは水の話なので、グラフの0℃より上の区間（18〜20分で0→10℃）に丸 → 100g×10℃÷2分 で1分あたりが決まる。

📚 前提知識

  • 熱の量（cal）＝水の重さ（g）×上がった温度（℃）。1分あたりが聞かれているので、最後に分で割る。
  • 0℃より下の区間は氷のまま温度が上がっている所。氷は水より温まりやすいので、同じ熱でもかたむきが急になる。ここをcalの式に使うと2倍の値が出てしまう。

🔍 こう読み解く

  1. グラフの右上がりの区間のうち、水になっている所を読む。18分で0℃、20分で10℃ → 2分で10℃。
  2. 100g×10℃＝1000cal を2分で受け取った → 1000÷2＝500cal。
  3. 解答・解説は「1分間で5℃」と読んでから100×5。どちらでも同じ値になる。
答え：500カロリー
今回：500 ○。答案は「2分で10°」「10×100÷2」と、水の区間を選んで式を立てられている。

Ⅱ 1問2 氷をとかす熱は水を100℃上げる熱の何倍か 資料問題・平らな区間の長さ

👀 まず見るところ

【資料問題】部品は正体「0℃で平らな区間＝氷がとけている時間」と答え方「整数または小数」。熱は1分500calで一定なので、かかった時間の比がそのまま熱の比になる → 平らな区間の分数と、水が100℃上がる分数の2つを書く。

📚 前提知識

  • 氷がとけている間は、加えた熱がとかすことに使われて温度が上がらない。だからグラフが平らになる。
  • 一定の割合で熱を加えているので、「何分かかったか」＝「どれだけ熱を使ったか」。cal に直さなくても、時間の比で答えられる。

🔍 こう読み解く

  1. 平らな区間は2分から18分 → 氷をとかすのに16分。
  2. 水は2分で10℃上がる → 100℃上げるには20分。
  3. 16÷20＝0.8倍。calで確かめると、とかす熱＝500×16＝8000cal（1gあたり80cal）、水100℃分＝100×100＝10000cal、8000÷10000＝0.8。
答え：0.8倍
今回：4/5 ○。答案は 500×16÷100＝80cal と1gあたりまで出して、80÷100 の比で考えている。筋道は正しい。ただし設問の答え方は「整数または小数」なので、書くのは0.8。今回は○がついたが、入試では「小数で」と指定されたら分数は×になることがある。答え方の指示に丸をつけてから書く。

Ⅱ 2問3 175mのときの反射音の時間 資料問題・比例のグラフを読む

👀 まず見るところ

【資料問題】部品は正体「反射してくる音が聞こえるまでの時間（往復の時間）」と「175m」「小数第2位まで」。グラフは原点を通る直線＝距離と時間は比例 → 読みやすい点（100mで0.60秒）を1つ取って、175m に直す。

📚 前提知識

  • 音の速さは一定なので、距離が2倍なら時間も2倍。原点を通る直線のグラフは「比例」の合図で、どの点を使っても同じ答えになる。
  • グラフの目盛りの交点に乗っている点を選ぶ。100mで0.60秒、150mで0.90秒、200mで1.20秒。

🔍 こう読み解く

  1. 100mで0.60秒 → 1mあたり 0.60÷100＝0.006秒。
  2. 175m なら 0.006×175＝1.05秒。
  3. 別の道：200mで1.20秒。175mは200mの 7/8 なので 1.20×7/8＝1.05秒。
答え：1.05秒
今回：1.05 ○。答案は「200mで1.2秒、175mで ×7/8」と比の形で出している。比例のグラフだと見ぬいて、計算しやすい点を選べている。

Ⅱ 2問4 音が1秒間に伝わる距離 条件文・往復を×2に直す

👀 まず見るところ

【条件文】部品は「1秒間に伝わる距離」と「四捨五入して小数第1位まで」。グラフの時間は往復の時間なので、横軸の距離は×2に直して書く（100m → 往復200m）→ 200÷0.60 で速さが決まる。

Ⅲ 1問1 横浜の経度 資料問題・南中時刻の差×4分

👀 まず見るところ
