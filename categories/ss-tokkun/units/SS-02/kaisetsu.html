X1 全体像 実験の条件 5問

前半は種子の発芽、後半はアサガオの成長。どちらも問われているのは同じことで、何を変えて、何をそろえたかを書き出せるかどうか。条件を1つだけ変えた2つを比べる（対照実験）、が全問の土台になる。

(3)の表は8つの鉢が「明るさ／水道水か肥料水か／たっぷりか少量か」の3つの組み合わせでできている。解く前に、表の横に3つの見出しを書いておくと比べやすい。

X1 (1) AとBでそろえる条件 対照実験・記述

👀 まず見るところ

【まざり型→素材文】部品は「Aには水を与え」「Bには水を与えません」に丸。変えたのは水だけ → 発芽の3条件の残り（空気・温度）がそろえる側。答えは温度を書く。

📚 前提知識

  • 発芽の3条件は水・空気・適当な温度。光と肥料はいらない。インゲンマメは子葉に養分をたくわえているので、肥料を含まない土でも発芽できる。
  • 2つを比べて「水のせい」と言えるのは、水以外の条件が同じときだけ。

🔍 こう読み解く

  1. 問題文で、すでにそろえてあるもの：ビーカーの大きさ・土の量・種子の数（5個）・うめる深さ。
  2. 変えてあるもの：水だけ。
  3. 残りは空気と温度。このうち置き場所しだいでずれやすいのが温度なので、AとBを同じ適当な温度にする（解答も温度）。
答え：適当な温度にすること。
コツ：自分で解くときは、問題文の「同じ」を全部丸で囲み、発芽の3条件のうち丸が付いていないものを書く。

X1 (2)A Aが発芽しなかった原因 発芽の条件・記述

👀 まず見るところ

【素材文】部品は「いつも土の表面まで十分にぬれている」に丸。水は足りている。水が多すぎると土のすきまがふさがる → 足りなかったのは空気と決まる。

📚 前提知識

  • 種子も呼吸をしていて、発芽のときは特にさかんに酸素を使う。だから空気が発芽の条件に入っている。
  • 土の中の空気は、つぶとつぶのすきまにある。すきまが水で満たされると、種子は空気にふれられない。

🔍 こう読み解く

  1. Aは水を与えた側なのに発芽しない → 水以外の条件が欠けている。
  2. (1)の温度はそろえた前提なので、残るのは空気。
  3. 「表面まで十分にぬれている」＝水びたしで、空気が十分になかった。
答え：空気が十分になかったこと。

X1 (2)B Bが発芽しなかった原因 発芽の条件・記述

👀 まず見るところ

【素材文】部品は「Bには水を与えません」に丸。それだけで決まる → 足りなかったのは水。

📚 前提知識

  • 種子は水を吸ってはじめて発芽を始める。水がなければ休んだまま。

🔍 こう読み解く

  1. Bは水を与えていない → 発芽の条件の水が欠けている。
  2. A（多すぎ）とB（なし）は、ちょうど両はしになっている。この実験では「水の有無」を調べるつもりが、Aでは別の条件（空気）まで欠けてしまった。
答え：水が十分になかったこと。
コツ：「それぞれ書きなさい」はA・Bに1つずつ。AとBで同じ答えにならないか、書いたあと見比べる。

X1 (3) 比べる鉢の組み合わせ 表の読み取り・2組

📚 前提知識（あれば答え合わせに使う）

答え：明るさ ③と⑦　水の量 ⑤と⑥

  1. 試験管はAと同じ だ液1cm³＋でんぷんのり(0.3%)1cm³。
  2. ビーカーは40℃から大きくはなれた温度 → 氷水や80℃のお湯。

X4 (1) 吸う息の集め方 実験の方法・選択

👀 まず見るところ

【素材文】部品は「吸う息」に丸。吸う息＝まわりの空気そのもの、と3語で直して書けば、口を通さずに空気を入れる方法を選べばよいと決まる。

📚 前提知識

  • 吸う息は、これから体に入るまわりの空気。一度でも肺を通れば、それははく息に変わる。

🔍 こう読み解く

  1. ア・ウは、どちらも口から息を出している → 入るのははく息 → ×。
  2. イは袋の中の気体を吸いこむだけで、袋に集まらない → ×。
  3. エは袋の口を広げて走る → まわりの空気がそのまま袋に入る → ○。
答え：エ
自分で解くときのチェック：選択肢ごとに「袋に入るのは口を通った空気か」を○×で書く。

X4 (2) 袋の内側が白くなる 現象の説明・語句

👀 まず見るところ

【素材文】部品は「白く見えるもの」に丸。目に見えるのは液体の粒で、気体の水蒸気は見えない。だから答えは「水」（水滴）と決まる。

📚 前提知識

  • はく息には、体から出た水蒸気が多くふくまれている。
  • 水蒸気はビニール袋にふれて冷やされ、水滴になって内側につく。これが白くくもって見える。

🔍 こう読み解く

  1. はく息の水蒸気 → 袋で冷える → 水滴になる。
  2. 「見える」ものを聞かれているので、気体の名前（水蒸気）ではなく液体の水を答える。
答え：水
自分で解くときのチェック：「見える」と聞かれたら、答えが気体の名前になっていないか確かめる。

X4 (3) 石灰水を入れてふった結果 実験の結果・記述

👀 まず見るところ

【条件文】部品は「吸う息とはく息」と「それぞれ」に丸。答えは2つ書く。石灰水が見分けるのは二酸化炭素なので、二酸化炭素の多いはく息だけがにごる。

📚 前提知識

  • 石灰水は二酸化炭素にふれると白くにごる。
  • 空気（吸う息）の二酸化炭素はごくわずかなので、少し入れてふった程度ではにごらない。はく息は呼吸で出た二酸化炭素が増えている。

🔍 こう読み解く

  1. 吸う息の袋 → 二酸化炭素がわずか → 変化しない。
  2. はく息の袋 → 二酸化炭素が多い → 白くにごる。
答え：吸う息　変化しない。　はく息　白くにごる。
自分で解くときのチェック：「それぞれ」とあれば、答えらんの2つとも書いたかを見直す。

X4 (4)記号 空気の交換をする場所 図の記号

X4 (5)結果② 日光に当てたあとの割合 資料問題・グラフ選択

👀 まず見るところ

【資料問題】部品は基準の(C)「二酸化炭素2%・酸素18%」と、②の「日光に当てた」。(C)の横に「CO₂↓ O₂↑」と直して書き、両方がその向きに動いたグラフを選ぶ。

📚 前提知識

自分で解くときのチェック：選ぶ前に、二酸化炭素と酸素の両方に↑↓を書いたか。

X4 (5)結果③ 暗い所に置いたあとの割合 資料問題・グラフ選択

自分で解くときのチェック：②と③の答えが「二酸化炭素と酸素が逆向き」のペアになっているか見くらべる。

SS-02 X5（蒸散の量とでんぷんのでき方）

X5 全体像 実験2つ・10問

Ⅰは蒸散、Ⅱは光合成でできるでんぷんの実験。どちらも「ふさいだ所／おおった所」と「そのままの所」をくらべる対照実験である。

Ⅰは表を「茎・葉の表・葉の裏」の3つの出口に分ければ、あとは引き算と足し算だけ。Ⅱは手順ひとつひとつに「何のため」を1語でつけられるかで、(4)〜(10)がまとめて決まる。

試験管水が出ていく所減った水の量
A そのまま茎＋葉の表＋葉の裏？
B 表にワセリン茎＋葉の裏17cm³
C 裏にワセリン茎＋葉の表8cm³
D 葉を全部とる茎だけ2cm³

X5 (1) Bの葉の裏から出た水 表の読み取り・計算

👀 まず見るところ

【まざり型→資料問題】部品は「葉の表にワセリン」「葉を全部とって」。A〜Dの横に「茎＋裏」「茎だけ」と出口を書きこむ（直して書く）→ BからDの茎の分を引けば裏の分が出る。

📚 前提知識

  • 蒸散は主に葉の気孔から水が水蒸気で出ていくはたらき。ワセリンをぬると気孔がふさがり、そこからは出ていかない。
  • 葉をとっても茎からは少し蒸散する。Dの2cm³がその量。

🔍 こう読み解く

  1. Dは葉が無いので、2cm³＝茎から出た量。
  2. Bは表をふさいだので、17cm³＝茎＋葉の裏。
  3. 葉の裏＝17−2＝15cm³。
答え：15cm³
自分で解くときのチェック：Bの17をそのまま答えにしていないか。茎の2を引いたかを見直す。

X5 (2) Aで減った水の量 表の読み取り・計算

👀 まず見るところ

【まざり型→資料問題】部品は「そのまま」に丸。Aの横に「茎＋表＋裏」と書く（直して書く）。3つ全部から出る。3つの出口の量を1つずつ出して足す。

📚 前提知識

  • ワセリンをぬった所はふさがるので、Cは茎＋葉の表の分だけが減る。

🔍 こう読み解く

  1. 葉の表＝C−D＝8−2＝6cm³。葉の裏は(1)の15cm³、茎は2cm³。
  2. A＝2＋6＋15＝23cm³。
  3. たしかめ：B＋C−D＝17＋8−2でも23。BとCの両方に茎が入っているので、1回分引く。
答え：23cm³
自分で解くときのチェック：B＋C＝25にしていないか。茎の2cm³を2回数えていないかを見る。

X5 (3) 試験管に油を入れる理由 実験の条件・記述

👀 まず見るところ

【まざり型→素材文】部品は「水の減る量を調べ」に丸。調べたいのは枝から出た水だけなのに、試験管の水面からも水は減る。油はそのじゃまを止めるふた。

📚 前提知識

  • 水は水面からも蒸発する。油は水にとけず水面に広がり、水より蒸発しにくいので、水面をおおうふたになる。

🔍 こう読み解く

  1. 油が無いと、減った水＝蒸散の量＋水面からの蒸発の量、になってしまう。
  2. 油でふたをすれば、減った水は枝からの蒸散だけになる。
  3. 理由の形にまとめる →「水面からの水の蒸発を防ぐため。」
答え：水面からの水の蒸発を防ぐため。
自分で解くときのチェック：「蒸発を防ぐ」だけでなく「水面からの」と場所まで書けているか。

X5 (4) 実験の手順の順番 手順の並べかえ・選択

👀 まず見るところ

【まざり型→素材文】部品は手順ごとの手がかり1語「暗室」「日光」「湯であたためた」。各手順の横に「でんぷんを消す」「でんぷんをつくる」「色をぬく」と目的を1語で書く → 目的の順に並ぶ。

📚 前提知識

  • 光合成で葉にできたでんぷんは、夜のあいだに別の形に変わって葉から運び出される。だから暗い所に置くと、葉のでんぷんがなくなる。

🔍 こう読み解く

  1. 最初は、前からあるでんぷんを消す (d) 暗室。ここでウが消える。
  2. 次に (a) アルミはくでおおい、(c) 日光に当てる。光を当ててからおおうと、おおった所にもでんぷんができてしまうので (a)→(c) の順。ここでイが消える。
  3. (f) アルミはくをとり、(b) あたためた液で色をぬいてから (e) で色を見る。色をぬく前に色を見てもわからないので (b)→(e)。ここでアが消える。
答え：エ
自分で解くときのチェック：選択肢の最初と最後だけを先にくらべる。最初は(d)、最後は(e)で、アとウが消える。
