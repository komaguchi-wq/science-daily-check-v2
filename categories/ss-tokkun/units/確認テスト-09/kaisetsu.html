M① 全体像 溶解度の計算 5問（各20点）

表は「水100gにホウ酸が何gとけるか」である。5問とも、やることは1つ。問題文の「g」が水の重さなのか水溶液の重さなのかを先に決めて、表の「水100g」とくらべる。

問題文の言葉その数字の正体表とくらべる相手
(1)「水100g」・(3)「水200g」・(2)「水が50g蒸発」水の重さ水100g（そのまま何倍かする）
(4)「飽和水溶液を100g」・(5)「飽和水溶液を200g」水＋ホウ酸の重さ100＋とける量（80℃なら123.5g、60℃なら114.9g）

今回は80点。(1)〜(4)は○で、(5)も式は正しく立っていた。落としたのは最後のわり算の1けただけである。

M① (1) とけ残りをとかす水の量 条件文・計算

👀 まず見るところ

【条件文】部品は「47gのホウ酸」と求めるもの「あと何g」に丸。表の80℃は23.5gなので、47gは23.5gの何倍かを余白に書く → 必要な水の全体が決まり、そこから今ある100gをひく。

📚 前提知識

  • 同じ温度なら、とける量は水の重さに比例する。水が2倍なら、とける量も2倍になる。

🔍 こう読み解く

  1. 80℃の水100gにとけるのは23.5g。47−23.5＝23.5gがとけ残る。
  2. とけ残った23.5gは、ちょうど80℃の水100gにとける量である。
  3. だから加える水は100g。47÷23.5＝2倍 → 水は全部で200g → 200−100＝100g と考えても同じになる。
答え：100g
今回：100 ○。問題文の「47gのホウ酸」と表の23.5に丸をつけ、加える水の重さで答えを出せている。

M① (2) 水を蒸発させたときの結晶 条件文・計算

👀 まず見るところ

【条件文】部品は「40℃に保ったまま」と「水が50g蒸発」に丸。温度が変わらないので、出てくるのは蒸発した水50gにとけていた分だけ → 「飽和水溶液を200g」は式に入らない数字と決まる。

📚 前提知識

  • 飽和水溶液は、どの部分をとっても「水100gあたり8.9g（40℃）」の割合でとけている。水がなくなれば、その水にとけていた分が行き場をなくして結晶になる。

🔍 こう読み解く

  1. 40℃の水100gにとけるホウ酸は8.9g。
  2. 蒸発した水は50gで、100gの半分。8.9×50／100＝4.45g。
  3. 割り切れているので四捨五入はしない。「小数第1位まで」は割り切れないときだけの指示である。
答え：4.45g
今回：4.45 ○。メモは「8.9÷2＝4.45」の1行。問題文の「水が50g蒸発」に丸をつけ、200gを使わずに決められている。

M① (3) あたためると、あと何gとけるか 条件文・計算

👀 まず見るところ

【条件文】部品は「20℃の水200g」と「水は蒸発しない」に丸。水の量が変わらないので、表の60℃と20℃の差をとり、水200gぶんの×2に直して書く → あととける量が決まる。

📚 前提知識

  • ホウ酸は温度が高いほど多くとける。あたためて増えた「とける量」の分だけ、あとからとかすことができる。

🔍 こう読み解く

  1. 水100gで考えると、60℃で14.9g、20℃で4.9g。差は14.9−4.9＝10g。
  2. 水は200gなので2倍する。10×200／100＝20g。
  3. 先に水200gぶんに直してからひいても同じ。29.8−9.8＝20g。
答え：20g（解答の表記は20.0）
今回：20 ○。メモに「200g」と「14.9−4.9＝10」があり、水の量を先に書いてから差を2倍にできている。

M① (4) 飽和水溶液の濃度 条件文・濃度の計算

👀 まず見るところ

【条件文】部品は「飽和水溶液を100g」と答え方「小数第1位まで」に丸。100gは水でなく水溶液の重さ。ただし飽和水溶液の濃度は量によらないので、水100gの場合に直して書く → 23.5÷123.5 で決まる。

📚 前提知識

  • 濃度（%）＝とけているものの重さ÷水溶液全体の重さ×100。わる数は水だけの重さではない。
  • 同じ温度の飽和水溶液は、100gでも200gでも、とけている割合が同じなので濃度も同じになる。

🔍 こう読み解く

  1. 80℃の水100gに、ホウ酸は23.5gとける。水溶液は100＋23.5＝123.5g。
  2. 23.5÷123.5×100＝19.02…。
  3. 小数第2位の0を四捨五入して19.0。小数第1位まで求めるので、0も書いて「19.0」とする。
答え：19.0%
今回：19.0 ○。メモは「23.5／123.5＝47／247」で、わる数を水溶液全体の123.5gにできている。筆算も19.02まで出してから四捨五入していて、手順どおりである。

M① (5) 飽和水溶液200gを冷やしたときの結晶 条件文・計算

👀 まず見るところ

【条件文】部品は「飽和水溶液を200g」。水200gではないので、そのまま×2はできない。60℃の飽和水溶液を「114.9gあたり結晶10g」に直して書く → 200gが114.9gの何倍かで決まる。

📚 前提知識

  • 冷やすと、とける量が減った分だけ結晶になる。水100gなら、60℃の14.9gから20℃の4.9gに減る。
  • 水100gでつくった60℃の飽和水溶液は、100＋14.9＝114.9g。表の数字を水溶液の重さとくらべるときは、この形に直す。

🔍 こう読み解く

  1. 水100g（水溶液114.9g）のとき、出てくる結晶は14.9−4.9＝10g。
  2. 水溶液は200gなので、10×200／114.9＝2000÷114.9。
  3. 小数第2位まで計算する。17.40…となり、小数第2位の0を四捨五入して17.4。
答え：17.4g
今回：17.3 ×。計算。式「20000／1149」は正しいが、筆算の3けた目で4670から1149×3＝3447をひいた。1149×4＝4596もひけるので、ここの商は4である。次は、ひいた残りがわる数より小さいかを1けたごとに確かめ、四捨五入に使う小数第2位まで出してから答えを書く。
