SS-09 X1（種子のつくりと発芽・成長の条件）

X1 全体像 種子のつくり・発芽 10問

4つの種子の断面図から、養分をたくわえている部分と、将来からだになる部分を見分ける大問である。入口は1つ、「胚乳があるか、ないか」。これが決まれば(1)から(3)まで続けて決まる。

図種子養分をたくわえている部分種子の呼び名
Aイネ胚乳（イ）有胚乳種子
Bトウモロコシ胚乳（オ）有胚乳種子
Cカキ胚乳（ク）有胚乳種子
Dインゲンマメ子葉（タ）無胚乳種子

後半の(4)(5)は「発芽」と「成長」で条件が変わる。(6)はダイズにヨウ素液をつけても色が変わらない理由を答える。

X1 (1)①A イネの種子で養分をたくわえている部分 図の読み取り・記号と名前

👀 まず見るところ

【資料問題】部品は図の正体「Aは細長く、外側に毛のある皮＝イネ」と、求めるもの「養分をたくわえている部分」に丸。イネは中身のほとんどが胚乳なので、いちばん広い部分を指す線をさがす。

📚 前提知識

  • イネは有胚乳種子。養分は胚乳にあり、胚は種子のはしに小さくついている。白米として食べている部分が胚乳にあたる。

🔍 こう読み解く

  1. アは外側の皮、ウは下のはしの小さな部分（胚）を指している。
  2. まん中の広い部分を指しているイが胚乳。
答え：イ・胚乳

X1 (1)①B トウモロコシの種子で養分をたくわえている部分 図の読み取り・記号と名前

👀 まず見るところ

【資料問題】部品は図の正体「Bは上が広く下が細い形で、下半分にだ円の部分＝トウモロコシ」。だ円の部分（カ）は胚。養分は、その外に広がっている部分にある。

📚 前提知識

  • トウモロコシもイネと同じ有胚乳種子。胚の形は目立つが、養分をたくわえているのは胚ではなく胚乳。

🔍 こう読み解く

  1. エはふちの線＝外側の皮。カはだ円の部分＝胚。
  2. 残ったオが、胚のまわりに広がる胚乳。目立つカを選ばない。
答え：オ・胚乳

X1 (1)①C カキの種子で養分をたくわえている部分 図の読み取り・記号と名前

👀 まず見るところ

【資料問題】部品は図の正体「Cは平たい種の中に、葉のような形のものが1つ入っている＝カキ」。葉のような形（ケ・コ・サ）は胚。養分は、それをつつんでいる広い部分にある。

📚 前提知識

  • カキは双子葉類だが有胚乳種子。双子葉類の多くは無胚乳種子なので、カキは例外として問われやすい。

🔍 こう読み解く

  1. キはふちの線＝外側の皮。ケ・コ・サは中にある葉のような形の各部分＝胚。
  2. 胚をつつむ広い部分を指しているクが胚乳。
答え：ク・胚乳

X1 (1)①D インゲンマメの種子で養分をたくわえている部分 図の読み取り・記号と名前

👀 まず見るところ

【資料問題】部品は図の正体「Dはマメの形＝インゲンマメ」。A〜Cとちがって胚乳がない。中身のほとんどをしめる子葉が養分をたくわえているので、名前は「胚乳」と書かない。

📚 前提知識

  • インゲンマメは無胚乳種子。種子ができるとちゅうで、養分が胚乳から子葉へ移るため、胚乳は残らない。

🔍 こう読み解く

  1. シ・ス・セは上のはしに集まった小さな部分。ソはふちの線＝外側の皮。
  2. いちばん広い部分を指しているタが子葉。A〜Cの3つは「胚乳」、Dだけ「子葉」になる。
答え：タ・子葉

X1 (1)② 将来植物のからだになる部分 図の読み取り・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「すべて選びなさい」に丸。からだになる部分＝胚。ア〜タの16個から「外側の皮」と「胚乳」を消し、残りが全部答えになる。Dの子葉（タ）は胚の一部なので消さない。

📚 前提知識

  • 胚＝幼芽・胚軸・幼根・子葉をまとめた呼び名。発芽すると葉・くき・根になる。
  • 胚乳は養分をわたすだけで、からだにはならない。外側の皮も同じ。

🔍 こう読み解く

  1. 外側の皮を消す：ア・エ・キ・ソ。
  2. ①で答えた胚乳を消す：イ・オ・ク。タは子葉なので消さない。
  3. 残りを種子ごとに確かめる。A＝ウ、B＝カ、C＝ケ・コ・サ、D＝シ・ス・セ・タ。合わせて9個。
答え：ウ・カ・ケ・コ・サ・シ・ス・セ・タ／胚
コツ：①で選んだ4つのうち、②にも入るのはタだけ。「養分をたくわえる部分」と「からだになる部分」が重なるのは、無胚乳種子の子葉だけである。

X1 (2) 胚乳に養分をたくわえている種子の呼び名 知識問題

有胚乳種子。Aのイネは胚乳（イ）に養分をたくわえている。胚乳が「有る」種子なので有胚乳種子、子葉にたくわえていて胚乳が「無い」種子は無胚乳種子、と字の意味で区別する。
答え：有胚乳種子

X1 (3) 有胚乳種子の仲間 分類・すべて選ぶ

👀 まず見るところ

【条件文】部品は答え方の指示「すべて選びなさい」に丸。8つを「単子葉類・裸子植物・双子葉類」に分けて書く。前の2つはそのまま有胚乳、双子葉類は例外のオシロイバナだけ拾う。

📚 前提知識

  • 有胚乳種子：イネ・コムギ・トウモロコシなどの単子葉類、マツ・イチョウなどの裸子植物。
  • 双子葉類の多くは無胚乳種子。ただしカキ・オシロイバナなどは有胚乳種子。

🔍 こう読み解く

  1. 単子葉類はア（コムギ）→ 有胚乳。裸子植物はカ（マツ）・キ（イチョウ）→ 有胚乳。
  2. 残りの双子葉類5つのうち、例外はイ（オシロイバナ）だけ。
  3. ウ（ダイズ）・エ（アブラナ）・オ（アサガオ）・ク（サクラ）は無胚乳種子なので選ばない。
答え：ア・イ・カ・キ

X1 (4) インゲンマメの発芽に必要な条件 条件・すべて選ぶ

👀 まず見るところ

【条件文】部品は「発芽させるのに」と「すべて」に丸。発芽に使う養分は子葉にたくわえてあるので、外から取り入れるのは水・適当な温度・酸素の3つだけと決まる。

📚 前提知識

  • 発芽の3条件＝水・適当な温度・酸素（空気）。酸素がいるのは、呼吸をして養分からエネルギーを取り出すため。
  • 日光と肥料がいらないのは、種子の中の養分だけで芽を出せるから。

🔍 こう読み解く

  1. イ（水）・エ（適当な温度）・オ（酸素）に○。
  2. ア（日光）・ウ（肥料）・カ（二酸化炭素）は光合成をして育つときに使うもの。発芽の段階ではまだ使わないので×。
答え：イ・エ・オ

X1 (5) 発芽した後、成長に必要な条件 条件・すべて選ぶ

👀 まず見るところ

【条件文】部品は(4)と変わった言葉「発芽させた後、成長していくために」に丸。子葉の養分を使い切ったあとは自分で養分をつくる → 光合成の材料と肥料が加わり、6つ全部が答えになる。

📚 前提知識

  • 成長には、発芽の3条件に加えて日光と肥料が必要。
  • 光合成は、日光を受けて水と二酸化炭素からでんぷんをつくるはたらき。だから二酸化炭素も成長に必要な条件に入る。

🔍 こう読み解く

  1. (4)の3つ（イ・エ・オ）は、成長するときも続けて必要。
  2. そこにア（日光）・ウ（肥料）を足す。
  3. 最後にカ（二酸化炭素）を確かめる。光合成の材料なので、これも入る。
答え：ア・イ・ウ・エ・オ・カ
コツ：「全部が答え」は不安になりやすい。1つずつ「これが無いと育たない理由」を言えれば、そのまま書いてよい。

X1 (6) ダイズの断面とヨウ素液 穴うめ・3つ

👀 まず見るところ

【素材文】部品は手がかりの言葉「ほとんど含まれていない」に丸。ヨウ素液で調べるのはでんぷん → ③＝でんぷんが先に決まる。でんぷんが少ないなら色は変わらず、①はヨウ素液そのものの色になる。

📚 前提知識

  • ヨウ素液はもともと茶褐色。でんぷんと反応すると青紫色になる。
  • ダイズの種子に主に含まれる栄養素はたんぱく質。でんぷんはほとんど含まれていない。

🔍 こう読み解く

  1. うしろの空らんから決める。「ほとんど含まれていない」ものをヨウ素液で調べている → ③はでんぷん。
  2. ダイズに主に含まれる栄養素 → ②はたんぱく質。
  3. でんぷんがほとんど無いので反応しない → ①は茶褐色。「種子にヨウ素液＝青紫色」と決めつけない。
答え：① 茶褐　② たんぱく質　③ でんぷん

X1 まとめ 自分で解くときのチェック

  • 図を見たら、種子ごとに「胚乳がある／ない」を先に書く。イネ・トウモロコシ・カキ＝ある、インゲンマメ＝ない（子葉）。
  • 「すべて選びなさい」は、消すものを先に決めてから残りを全部書く。(1)②は皮と胚乳を消す。
  • 発芽＝水・適当な温度・酸素。成長＝それに日光・肥料・二酸化炭素を足す。

X2 (1)①A・B 地上の葉が2枚ではない2つ 資料問題・植物名

👀 まず見るところ

【資料問題】部品は資料の正体「8種類の植物の発芽の様子」。図の横に正体を1行書き、地上の葉の数を数える。Aは細い葉が1本、Bは細い葉がたくさん → 2枚ではないこの2つから先に決まる。

📚 前提知識

  • トウモロコシは単子葉植物。子葉は1枚で、葉は細長い。養分は胚乳にたくわえている。
  • マツは子葉が2枚より多く、針のように細い子葉が輪になって開く。

🔍 こう読み解く

  1. 名前の候補8つのうち、子葉が2枚でないのはトウモロコシとマツだけ。図でも2枚でないのはAとBだけ。
  2. Aは細長い葉が1本まっすぐのび、土の中に種子が残っている → トウモロコシ。
  3. Bは細い葉がかさの骨のように広がっている → マツ。
答え：A トウモロコシ　B マツ
自分で解くときのチェック：名前を書く前に、8つの図の上に地上の葉の数（1・たくさん・2）をメモする。

X2 (1)①C・D マメのなかまの2つ 資料問題・植物名

👀 まず見るところ

【資料問題】部品は名前の候補「エンドウ、インゲンマメ」。マメのなかまの子葉は厚い。図に「厚い」と書きこめるのは、Cの土の中の丸い種子とDの地上のふくらんだ部分 → 子葉が地中か地上かで2つが分かれる。

📚 前提知識

  • エンドウやインゲンマメは無胚乳種子。養分を子葉にたくわえているので、子葉が厚い。
  • 無胚乳種子はふつう子葉が地上に出るが、エンドウ・ソラマメ・アズキ・クリなどは子葉が地中に残る（解答冊子の解説）。

🔍 こう読み解く

  1. Cは土の中に丸い種子が残り、地上には茎と小さな芽だけ → 子葉が地中に残るエンドウ。
  2. Dは茎の先に厚くふくらんだ子葉がついて、土の上に持ち上がっている → インゲンマメ。
答え：C エンドウ　D インゲンマメ
コツ：AもCも土の中に種子が残る。Aで残っているのは胚乳、Cで残っているのは子葉。ここを区別しておくと②で使える。

X2 (1)①E・F・G・H 子葉が2枚開いている4つ 資料問題・植物名

📚 前提知識

  • アブラナの子葉は、先が少しへこんだハート形で小さい。

🔍 こう読み解く

  1. Eは子葉の先が深く切れこんでいる → アサガオ。
  2. Fは小さく丸い子葉で、先が少しへこんでいる → アブラナ。
  3. GとHはだ円形。Gは葉脈が白くはっきりかかれている → ヘチマ。残ったHがヒマワリ。

X2 (1)② 子葉をすべて選ぶ 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は聞かれ方「子葉をすべて」に丸。ア〜シの12個全部に○×をつける。E〜Hのケ・コ・サ・シはすぐ○。差がつくのはA〜Dの8個で、1つの図に記号が2〜3個ある所は子葉と本葉を分ける。

🔍 こう読み解く

  4. D（インゲンマメ）：クは厚くふくらんだ部分＝子葉 → ○。キはその間から出た小さな葉＝本葉 → ×。

自分で解くときのチェック：土の中の種子はAのイとCのオの2つ。イは胚乳で×、オは子葉で○。同じ「土の中」でも答えが分かれる。

X2 (3) 双子葉植物をすべて選ぶ 資料問題・すべて選ぶ

X2 (4) 双子葉植物の特徴 素材文・すべて選ぶ

  • 分類の数：恒温動物は鳥類・哺乳類の2種類、卵生は哺乳類以外の4種類。両方にあてはまるのが鳥類。
  • 卵：気室は丸いほうに1つ。保管は丸いほうを上。からは炭酸カルシウムで、塩酸をかけると二酸化炭素。
