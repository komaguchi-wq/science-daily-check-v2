昼テスト-01 L・H応用（気体の発生量のグラフ 基本と応用）

L 全体像 グラフの作図・条件の逆算 9問

石灰石と塩酸から出る気体（二酸化炭素）のグラフは、「過不足なく反応する点」＝●さえ決まればかける。●の前は原点からの直線、●の後は横ばい。やることは、図2の●（塩酸200cm³・気体200cm³）を基準に、条件が何倍になったかを2本の数に直すことだけ。

●の座標決めるもの直し方
たて（気体の量）石灰石の量だけ200×（石灰石が何倍か）
よこ（塩酸の量）石灰石の量と塩酸の濃さ200×（石灰石が何倍か）÷（濃さが何倍か）

(1)はこの表を上から使ってグラフをかく問題、(2)はグラフの●を読んで表を下から逆にたどる問題。

L (1)A 石灰石1.5g・同じ濃さ 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「石灰石：1.5g」と「同じ濃さ」。図2と比べて「石灰石×1.5、濃さ×1」と直して書く → ●のたても横も1.5倍と決まる。

📚 前提知識

  • 塩酸はいくらでも足せるので、出る気体の量は石灰石の量で決まる。石灰石が1.5倍なら気体も1.5倍。
  • 濃さが同じなら、石灰石1.5倍をとかすのに塩酸も1.5倍いる。

🔍 こう読み解く

  1. 気体：200×1.5＝300cm³。塩酸：200×1.5＝300cm³。
  2. ●を（塩酸300、気体300）に打つ。原点から●まで直線、●から右は300cm³で横ばい。
  3. 検算：濃さが同じなので、直線の傾きは図2と同じ（塩酸100で気体100）。●がその線の上をのびた位置にあれば合っている。
答え：原点から●（塩酸300cm³・気体300cm³）まで直線、そのあと300cm³で横ばい
今回：●（300・300）の線 ○

L (1)B 石灰石0.75g・同じ濃さ 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「石灰石：0.75g」と「同じ濃さ」。Aと変わったのは石灰石だけ。「石灰石×0.75、濃さ×1」と書く → ●は図2の直線の上で手前に止まる。

📚 前提知識

  • 気体の量は石灰石に比例する。石灰石が0.75倍なら気体も0.75倍。濃さが同じなので、必要な塩酸も0.75倍。

🔍 こう読み解く

  1. 気体：200×0.75＝150cm³。塩酸：200×0.75＝150cm³。
  2. ●を（塩酸150、気体150）に打ち、原点から●まで直線、そのあと150cm³で横ばい。
答え：原点から●（塩酸150cm³・気体150cm³）まで直線、そのあと150cm³で横ばい
今回：●（150・150）の線 ○

L (1)C 石灰石1g・2倍の濃さ 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「石灰石：1g」（図2と同じ）と「2倍の濃さ」。「石灰石×1、塩酸÷2」と直して書く → 気体は200のまま、塩酸だけ半分の100と決まる。

📚 前提知識

  • 濃さが2倍＝同じ量の塩酸に、とけている塩化水素が2倍。だから石灰石1gをとかすのに、塩酸は半分の量ですむ。
  • 石灰石は変わらないので、出る気体の量も変わらない。

🔍 こう読み解く

  1. 気体：石灰石が同じなので200cm³のまま。塩酸：200÷2＝100cm³。
  2. ●を（塩酸100、気体200）に打ち、原点から●まで直線、そのあと200cm³で横ばい。
  3. 検算：図2より傾きが急（塩酸100で気体200）。濃いほど少ない塩酸で多く出るので、向きが合っている。
答え：原点から●（塩酸100cm³・気体200cm³）まで直線、そのあと200cm³で横ばい
今回：●（100・200）の線 ○

L (1)D 石灰石1g・2倍にうすめる 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「2倍にうすめる」。Cの「2倍の濃さ」と逆向きなので、「塩酸÷2」ではなく「塩酸×2」と直して書く → 気体200のまま、塩酸は400と決まる。

📚 前提知識

  • 2倍にうすめる＝濃さが2分の1。同じ量にとけている塩化水素が半分なので、石灰石1gをとかすには塩酸が2倍いる。

🔍 こう読み解く

  1. 気体：石灰石が同じなので200cm³。塩酸：200×2＝400cm³。
  2. ●を（塩酸400、気体200）に打つ。原点から●まで、図2よりゆるやかな直線。●から右は200cm³で横ばい。
  3. 「濃い→塩酸が少なくてすむ」「うすい→塩酸が多くいる」を両方セットで書いておくと、CとDを取りちがえない。
答え：原点から●（塩酸400cm³・気体200cm³）まで直線、そのあと200cm³で横ばい
今回：鉛筆の線なし ×（赤で正しい線に直してある）。同じ「2倍にうすめる」のFと(2)Hは正解なので、直し方は分かっている。Dだけ条件に丸も線も無く、手を付けずに飛ばしたまま戻らなかった形＝部品を拾えなかった。次は飛ばす問題も条件の「うすめる」に丸だけ先につけ、番号に印をして戻る。

L (1)E 石灰石1.5g・2倍の濃さ 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は2つとも変わっている「1.5g」と「2倍の濃さ」。1つずつ「×1.5」「÷2」と直して書く → 気体は×1.5だけ、塩酸は×1.5と÷2の両方を使う。

📚 前提知識

  • 気体の量は石灰石だけで決まる。塩酸の量は石灰石の量と濃さの両方で決まる。

🔍 こう読み解く

  1. 気体：200×1.5＝300cm³。
  2. 塩酸：200×1.5×1/2＝150cm³。
  3. ●を（塩酸150、気体300）に打ち、原点から●まで直線、そのあと300cm³で横ばい。傾きはCと同じ急さになる（濃さが同じ2倍だから）。
答え：原点から●（塩酸150cm³・気体300cm³）まで直線、そのあと300cm³で横ばい
今回：●（150・300）の線 ○

L (1)F 石灰石0.75g・2倍にうすめる 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「0.75g」と「2倍にうすめる」。「×0.75」「塩酸×2」と直して書く → 気体は150、塩酸は200×0.75×2で決まる。

📚 前提知識

  • うすめると塩酸は多くいる。石灰石が減ると塩酸は少なくてすむ。2つの向きが逆なので、かけ算で順に計算する。

🔍 こう読み解く

  1. 気体：200×0.75＝150cm³。
  2. 塩酸：200×0.75×2＝300cm³。
  3. ●を（塩酸300、気体150）に打ち、原点から●まで直線、そのあと150cm³で横ばい。傾きはDと同じゆるやかさになる。
答え：原点から●（塩酸300cm³・気体150cm³）まで直線、そのあと150cm³で横ばい
今回：●（300・150）の線 ○

L (2)G ●が（塩酸50・気体200）のグラフ 資料問題・条件の逆算

👀 まず見るところ

【資料問題】部品はグラフの●の座標「塩酸50cm³・気体200cm³」。図2の●（200・200）の横に並べて書き、たて→石灰石、よこ→濃さの順に決める。

📚 前提知識

  • (1)の表を下から逆にたどる。気体の量から石灰石が決まり、そのあと塩酸の量から濃さが決まる。

🔍 こう読み解く

  1. 気体が200cm³で図2と同じ → 石灰石も同じ1g。
  2. 石灰石が同じなのに、塩酸は200→50で4分の1ですんでいる → 塩酸の濃さは4倍。
  3. 検算：傾きは塩酸50で気体200、図2の4倍の急さ。濃さ4倍と合う。
答え：石灰石〔1〕g　塩酸〔4倍の濃さ〕
今回：1g・4倍のこさ ○

L (2)H ●が（塩酸300・気体200）のグラフ 資料問題・条件の逆算

👀 まず見るところ

【資料問題】部品は●の座標「塩酸300cm³・気体200cm³」。気体は図2と同じ、塩酸は図2より多い → 石灰石はそのまま、塩酸はうすめた側と決まる。

📚 前提知識

  • 同じ石灰石をとかすのに塩酸が多くいる＝塩酸がうすい。何倍いるかが、何倍にうすめたかになる。

🔍 こう読み解く

  1. 気体200cm³ → 石灰石は1g。
  2. 塩酸は200→300で1.5倍いる → 塩酸は1.5倍にうすめたもの。
答え：石灰石〔1〕g　塩酸〔1.5倍にうすめる〕
今回：1g・1.5倍にうすめる ○

L (2)I ●が（塩酸150・気体50）のグラフ 資料問題・条件の逆算

👀 まず見るところ

【資料問題】部品は●の座標「塩酸150cm³・気体50cm³」。GとHとちがい、気体が200でない。先に気体から石灰石を決め、その石灰石に同じ濃さなら何cm³いるかを書いてから150と比べる。

📚 前提知識

  • 石灰石が変わると、必要な塩酸の「基準」も変わる。濃さは、その新しい基準と比べて決める。

🔍 こう読み解く

  1. 気体50cm³は図2の200の1/4 → 石灰石も1/4の0.25g。
  2. 同じ濃さなら、0.25gに必要な塩酸は200の1/4＝50cm³。
  3. 実際は150cm³で、50の3倍いる → 塩酸は3倍にうすめたもの。200と150を直接比べて「0.75倍」としない。
答え：石灰石〔0.25〕g　塩酸〔3倍にうすめる〕
今回：0.25g・3倍にうすめる ○

H・応用 全体像 グラフの作図 2問

Lと同じ「●を決めてグラフをかく」問題だが、表の数をそのまま使えない。表は「メスシリンダー内の気体の体積」、グラフのたて軸は「発生した気体の体積」。この名前のちがいが、この大問の入口になる。

H・応用 (1) 塩酸30mLのときのグラフ 資料問題・グラフの作図

👀 まず見るところ

【資料問題】部品は表の正体「メスシリンダー内の気体の体積」と、問題文の「30mLの塩酸を入れ」。表の数から30を引いて「発生した気体」に直して書く → 240・480・600で●が決まる。

📚 前提知識（あれば答え合わせに使う）

  • 三角フラスコに塩酸を30mL注ぐと、その体積の分だけフラスコの中の空気が押し出され、メスシリンダーに集まる。だから表の数には空気30mLがまざっている。
  • 表だけでも気づける：1.0gで270なら2.0gは540のはずが510。2×270−510＝30mLが、重さに関係なく入っている分。

🔍 こう読み解く

  1. 30mLずつ引く → 1.0g：240、2.0g：480、3.0g：600。1.0gと2.0gはちょうど2倍なので、ここまでは炭酸カルシウムが全部とけている（1gで240mL）。
  2. 3.0gなら720mL出るはずが600mL → 塩酸30mLが先になくなった。塩酸30mLで出る気体の上限は600mL。
  3. 600mL出すのに必要な炭酸カルシウムは 600÷240＝2.5g。●は（2.5g、600mL）。
  4. 原点から●まで直線（1gで240mLの傾き）、●から右は600mLで横ばい。
答え：原点から●（炭酸カルシウム2.5g・気体600mL）まで直線、そのあと600mLで横ばい
今回：×。鉛筆の線は無く、赤で引かれた線は1gで200・2gで400、2.5gで折れて500mLの横ばい。折れる2.5gは合っているが、1gあたりが240でなく200＝部品の形を直さなかった（表の数を240・480・600に直して点を打っていない）。次は表の下に30を引いた行を書いてから点を打つ。

H・応用 (2) 3倍の濃さの塩酸20mLのときのグラフ 条件文・グラフの作図

👀 まず見るところ

【条件文】部品は「濃さが3倍」と「20mL」。2つを1つにまとめ「もとの濃さなら20×3＝60mL分」と直して書く → (1)の30mLの2倍なので、●のよこもたても2倍と決まる。

📚 前提知識

  • 濃さ3倍の塩酸20mLには、もとの濃さの塩酸60mLと同じだけ塩化水素がとけている。
  • 炭酸カルシウム1gから出る気体は、塩酸の濃さが変わっても240mLのまま（(1)で出した値）。変わるのは●の位置だけで、直線の傾きは(1)と同じ。

🔍 こう読み解く

  1. もとの濃さ60mL分＝(1)の30mLの2倍 → とかせる炭酸カルシウムは2.5×2＝5g。
  2. そのとき出る気体は 240×5＝1200mL（(1)の600の2倍でも同じ）。●は（5g、1200mL）。
  3. 原点から●まで(1)と同じ傾きの直線、●から右は1200mLで横ばい。グラフは「発生した気体」なので、ここでは空気の分を足さない。
答え：原点から●（炭酸カルシウム5g・気体1200mL）まで直線、そのあと1200mLで横ばい
今回：グラフなし ×。余白に「60」とあり、「3倍の濃さ20mL＝もとの濃さ60mL分」に直す一歩はできている。部品を拾えなかった＝その60を(1)の「30mLで2.5g・600mL」と結びつける部品が紙に置かれていなかった。(1)の●が決まれば、2倍するだけで答えになる。

L・H応用 まとめ 8／11問

  • 取れた：L の8問（(1)A・B・C・E・F、(2)G・H・I）。●の座標2つでグラフが決まる考え方は、かく向きも逆算の向きもできている。
  • 落とした3問：L (1)Dは条件に丸が無く、手を付けずに飛ばしたまま。H・応用は表の数を「発生した気体」に直す一歩（30を引く）が抜け、(2)は(1)の●が無いまま止まった。どれも部品を紙に置く前で止まった失点。
  • 表の数をグラフに移す前に、表の名前と軸の名前をくらべる。「メスシリンダー内」と「発生した」のちがい＝押し出された空気30mL。

昼テスト-01 H 半減期（岩石の年齢／過酸化水素水の濃度）

H・半減期 全体像 グラフと表・4問

半減期＝物質が半分になるまでの時間。問題文にあるとおり、はじめの量によらず、半分になるたびに同じ時間がかかる。(1)は図1のグラフ、(2)は表を使うが、やることは同じで、問題文の数字を「残りの割合」や「半減期の回数」に直してからグラフや表を見る。

小問直す前の部品直した形
(1)①K：A＝4：1Kの残り80%
(1)②K：A＝1：4Kの残り20%
(2)①60mLで1%減少・4%→2%120mL発生した時間
(2)②濃度0.5%4%→2%→1%→0.5%＝半減期3回

H・半減期 (1)① K：A＝4：1の岩石の年齢 グラフの読み取り＋比

👀 まず見るところ

【まざり型→条件文】部品は「K：A＝4：1」と「生まれたときに物質Aは含まれていなかった」。K＋Aがはじめの量なので、Kの残りは4÷5＝80%と直して書く → 図1で80%の時間が決まる。

📚 前提知識

  • Kは減った分だけAに変わる。はじめAは0なので、今のK＋AがはじめのKの量になる。
  • 図1は半減期1年のグラフ。横軸の「1年」を「半減期1回分」と読みかえれば、半減期が13億年の物質にもそのまま使える。

🔍 こう読み解く

  1. Kの残り＝4÷（4＋1）＝80%。
  2. 図1で縦軸80%の所を横にたどると、0.33年ほど。半減期1回分の約0.33倍の時間がたったことになる。
  3. 半減期は13億年なので、13億年×0.33＝4.29億年。5億年単位なので5億年。
  4. 検算：80%は半分（50%）まで減っていないので、半減期1回分の13億年より前。5億年はこれに合う。
答え：5億年
今回：5億年 ○

H・半減期 (1)② K：A＝1：4の岩石の年齢 グラフの読み取り＋比

👀 まず見るところ

【まざり型→条件文】①と変わった部品は「K：A＝1：4」。Kの残りは1÷5＝20%と直して書く（4分の1＝25%ではない）→ 図1で20%の時間を読み、13億年をかける。

📚 前提知識

  • 半減期1回で50%、2回で25%、3回で12.5%。20%は2回と3回のあいだにある。

🔍 こう読み解く

  1. Kの残り＝1÷（1＋4）＝20%。比の「1」と「4」をそのまま分数にせず、合計の5で割る。
  2. 図1で縦軸20%の所を横にたどると、2.33年ほど。半減期の約2.33倍の時間。
  3. 13億年×2.33＝30.29億年。5億年単位なので30億年。
  4. 検算：半減期2回分は26億年、3回分は39億年。30億年はそのあいだに入る。
答え：30億年
今回：21億年 ×。計算メモが無く道すじは分からないが、21は5の倍数でなく「5億年単位」が答えに入っていない＝部品を拾えなかった（20%を2.33年と読めていれば30前後になる）。次は「Kの残り20%」を1行書き、答えを書く直前に「5億年単位」の丸を見直す。

H・半減期 (2)① 濃度が2%になる時間 表の読み取り＋換算

👀 まず見るところ

【まざり型→条件文】部品は「気体が60mL発生すると濃度が1%減少」。「1%＝60mL」と直して書くと、4%→2%の2%減少は120mL。表で体積120mLの時間を読む。

📚 前提知識

  • 過酸化水素水に二酸化マンガンを加えると酸素が出る。出た酸素の分だけ過酸化水素が減るので、発生した気体の体積から濃度の下がり方がわかる。

🔍 こう読み解く

  1. 4%→2%は2%の減少。1%で60mLなので、60mL×2＝120mL。
  2. 表で体積が120mLになるのは180秒。これがこの実験の半減期。
答え：180秒後
今回：180秒後 ○

H・半減期 (2)② 濃度が0.5%になる時間 半減期の回数

👀 まず見るところ

【まざり型→条件文】①と変わった部品は「0.5%」。4%→2%→1%→0.5%と矢印で書く（直して書く）→ 半減期3回分と決まり、①の180秒を3倍する。

📚 前提知識

  • 半減期は「はじめの量によらず、半分になるまで同じ時間」。4%→2%も、2%→1%も、1%→0.5%も、それぞれ180秒かかる。

🔍 こう読み解く

  1. 0.5%は4%を3回半分にした濃度。半減期3回分なので、180秒×3＝540秒。
  2. 0.5%は3.5%の減少＝210mLで、表（420秒で192mL）の外にある。表の増え方をのばして読まず、半減期の回数で決める。
  3. 検算：1%（3%減少＝180mL）になるのは半減期2回分の360秒のはず。表の360秒は180mLで、一致する。
答え：540秒後
