X復習 (1) 昇華の例 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は問題文の定義「固体が直接気体」「気体が直接固体」と、聞かれ方「すべて選び」に丸。6つの文それぞれに「何が→何に」を3語で書く（氷→水蒸気 など）と、液体を通っているものが消えて答えが決まる。

📚 前提知識

  • 昇華＝固体⇄気体を液体を通らずに行き来する変化。ドライアイス（固体の二酸化炭素）が代表。
  • 霜は空気中の水蒸気が直接氷になったもの（気体→固体）。霜柱は地中の水がこおって持ち上がったもの（液体→固体）。名前は似ているが中身がちがう。
  • 冷凍庫の氷が小さくなるのは、0℃以下でも氷の表面から水蒸気が出ていくから（固体→気体）。

🔍 こう読み解く

  1. ア 洗濯物＝水→水蒸気（液→気・蒸発）×。エ つらら＝水→氷（液→固）×。ウ 霜柱＝地中の水→氷（液→固）×。
  2. イ 霜＝水蒸気→氷（気→固）○。オ ドライアイス＝固体→気体の二酸化炭素（泡）○。カ 冷凍庫の氷＝氷→水蒸気（固→気）○。
  3. 液体を1度も通らないのは イ・オ・カ。
答え：イ・オ・カ
今回：ウ・オ ×。部品を拾えなかった＝「何が→何に」を書かずに、「霜」の字で霜柱を選び、霜と冷凍庫の氷を落とした。次は6つ全部に（固→気）（液→固）の3語を書いてから選ぶ。

X復習 (2) 体積が大きくなる例 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「体積が大きくなる」（問題文に本人の丸あり）と「すべて選び」。5つの文それぞれに、温度が上がるか下がるか／状態が変わるかを矢印で書く。ふつうは「温度が上がれば大きくなる」、例外は水の0〜4℃とろうの固体化だけ、と決めておくと速い。

📚 前提知識

  • 固体・液体・気体とも、温度が上がると体積はふえる（膨張）。氷も固体なので、−20℃→−5℃なら少しふくらむ。
  • 例外は水。4℃で体積が最小なので、0℃→4℃はかえって縮む。また、ろうは固体になるとき縮む（まん中がへこむ）。
  • ドライアイスが気体になると体積は数百倍。液体→気体、固体→気体は体積が大きくふえる。

🔍 こう読み解く

  1. ア −20℃→−5℃の氷：固体のまま温度が上がる → 膨張 ○。
  2. イ ろうの液体→固体：ろうは固まると縮む ×。エ 0℃→4℃の水：4℃が最小なので縮む ×。
  3. ウ 丸底フラスコを加熱：ガラスも中の空気も温度が上がって膨張 ○。オ ドライアイス→気体：大きくふえる ○。
答え：ア・ウ・オ
今回：ウ・オ ×。知識＝氷も「温度が上がれば膨張する」ふつうの固体だと見ず、水の例外（エ）とまとめてアも消したと思われる。例外は「水の0〜4℃」と「ろうの固体化」の2つだけ、と線を引き直す。

X復習 (3)① 伝導に関係のある文 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「①伝導」と「すべて選び」。6つの文に、熱が「さわって伝わる＝伝導」「動いて運ぶ＝対流」「はなれて届く＝放射」のどれかを1語ずつ書く。ものがふれている文が伝導である。

📚 前提知識

  • 伝導＝ふれているものの間を熱が移る。金属は伝えやすく、木・空気は伝えにくい。
  • 対流＝あたたまった液体や気体が上へ動いて熱を運ぶ。放射＝日光やストーブのように、間に何もなくても熱が届く。

🔍 こう読み解く

  1. ウ 木のおわんは熱を伝えにくいので冷めにくい → 伝導 ○。カ 裸足が砂にふれて熱い → 伝導 ○。
  2. オ クーラーを上部に＝冷たい空気が下へ下りる → 対流。ア・イ・エは日光やストーブの熱が届く話 → 放射。
答え：ウ・カ
今回：ウ・カ ○。イ「砂浜が熱い」とカ「歩くと熱い」を、熱くなる原因（放射）と足に伝わる方法（伝導）で切り分けられている。

X復習 (3)② 放射に関係のある文 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「②放射」。①で6つの文に書いた「伝導／対流／放射」の1語をそのまま使う。「日光」「反射板」「黒いもの」が出てきたら放射の合図である。

📚 前提知識

  • 放射の熱は光と同じように進む。みがいた金属板ははね返し、黒いものや灰は吸収する。
  • 雪に灰をまくと、黒い灰が日光の熱を吸収して、まわりの雪が早くとける。

🔍 こう読み解く

  1. ア 反射板で熱をはね返す → 放射 ○。イ 日光で砂浜が熱くなる → 放射 ○。エ 灰が日光の熱を吸収 → 放射 ○。
  2. 残りのウ・カは伝導、オは対流で、放射ではない。
答え：ア・イ・エ
今回：ア・イ・エ ○。①②を合わせて6つの文が伝導2・対流1・放射3にきれいに分かれていて、迷いが見えない。

X復習 (4) 食塩水を熱したときの変化の順 素材文・並べかえ

👀 まず見るところ

【素材文】部品は「温度の低い方から順番に」と「1つ選び」。①〜⑤のそれぞれに「何が出てきたか（水てき／空気／水蒸気）」を1語で書く。外側のくもりは加熱したすぐあと、大きな泡は水蒸気で沸とうの合図、と決まれば最初と最後がそろう。

📚 前提知識

  • 加熱したすぐあと、炎から出た水蒸気がまだ冷たいフラスコの外側で水てきになる → ③のくもり。温まると消える。
  • 水にとけていた空気が小さな泡で出る（④）→ 温まった水が動く対流が見える（①）→ 底から水蒸気の大きな泡が上がる（⑤）→ 全体がボコボコ煮立つ（②）。

🔍 こう読み解く

  1. 最初は③（くもり）、最後は②（煮立つ）。この2つだけで選択肢はオかカにしぼれる。
  2. 残りは「小さな泡（空気）④ → 水の動き① → 大きな泡（水蒸気）⑤」。小さな泡が先なのは、空気は低い温度でもとけきれずに出てくるから。
  3. ③→④→①→⑤→② は オ。
答え：オ
今回：オ ○。問題用紙でオに丸、カの③に下線が引いてあり、最初と最後で2つにしぼってから中を決めた手順が残っている。

X復習 (5) 90℃の水200gと10℃の水をまぜる 条件文・熱量の計算

👀 まず見るところ

【条件文】部品は「90℃の水200g」「10℃」「30℃になりました」と、求めるもの「何g」に丸。90℃側は60℃下がり、10℃側は20℃上がる、と温度差に直して書く。「水と水の間だけ」は、失った熱量＝もらった熱量の合図である。

📚 前提知識

  • 熱量（カロリー）＝水の重さ(g)×温度変化(℃)。熱い水が失った熱量＝冷たい水がもらった熱量。
  • 重さと温度変化は逆比になる。重い方が少ししか動かない。

🔍 こう読み解く

  1. 90℃の水が失った熱量＝200×（90−30）＝200×60＝12000カロリー。
  2. 10℃の水がもらった熱量＝□×（30−10）＝□×20。これが12000に等しい。
  3. □＝12000÷20＝600g。検算：温度変化60：20＝3：1だから重さは1：3、200gの3倍で600g。
答え：600g
今回：600 ○。余白に「12000÷20＝600」と式が残っていて、失った熱量を先に出してから割る手順で通している。

X復習 (6) モノコードで音が高くなるもの 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「音が高くなる」と「すべて選び」。各文は前半（弦の条件）と後半（はじく力）の2つでできている。高さを決めるのは前半だけ、後半の「強い／弱い」は大きさの話、と線で区切ってから読む。

📚 前提知識

  • 音の高さ＝弦の振動数。弦を短く・細く・強く張る（おもりを重く）と振動数がふえて高くなる。
  • はじく力の強さは振れはば＝音の大きさを変えるだけで、高さは変わらない。

🔍 こう読み解く

  1. 各文を／で切る。ア 長く／同じ強さ、イ 細く／同じ強さ、ウ おもり2個／強い力、エ 短く／弱い力。
  2. 後半は全部無視して前半だけ見る。長く→低い ×、細く→高い ○、おもり2個→張りが強い→高い ○、短く→高い ○。
  3. 答えは イ・ウ・エ。エの「弱い力」は音が小さくなるだけで、高さは短くした分だけ上がる。
答え：イ・ウ・エ
今回：イ・ウ ×。部品の形を直さなかった＝文を前半／後半に切らずに読み、エの「弱い力」を高さが下がる向きに取ってしまった。問題用紙ではイ・ウに丸、アに波線があり、エだけ印がない。次は「高さは前半、大きさは後半」と区切ってから4つ全部に印をつける。

X復習 (7)図3 水から空気へ出る光 資料問題・図の道すじ

👀 まず見るところ

【資料問題】図の正体を1行「水→空気へ出る光・境目でア〜エに分かれる」。境目に垂直な線（法線）を1本たしてから、空気に出る光は「法線からはなれる向きに折れる」を当てはめる。

📚 前提知識

  • 屈折の向きは「水やガラスの中では法線に近づく、空気へ出るときは法線からはなれる」の1組で覚える。
  • そのまままっすぐ進む道（ウ）は、境目で何も起きなかった場合。屈折する問題では選ばない。

🔍 こう読み解く

  1. 光は水の中から右上に向かって境目に当たる。進む向きは右上のままなので、左上へ行くアは×。
  2. ウはもとの線の延長（屈折なし）、イは法線に近づく向き → どちらも×。
  3. 法線からはなれて水面に近づく向きに折れるのは エ。
答え：エ
今回：エ ○。「空気に出るときは水面に近づく」向きが身についている。

X復習 (7)図4 三角のガラスを通る光 資料問題・図の道すじ

👀 まず見るところ

【資料問題】図の正体を1行「空気→ガラス→空気、三角のガラス（プリズム）を2回通る光」。1回目は法線に近づき、2回目は法線からはなれる。まとめると光はガラスの厚い側（底辺）へ2回曲がる、と書いてから選ぶ。

📚 前提知識

  • 三角のガラスでは、入るときも出るときも、光はとがった側からはなれて底辺側へ折れる。出てきた光はもとの向きより下向きになる。
  • 凸レンズが光を集めるのも、この「厚い側へ曲がる」性質を丸い形にしたものである。

🔍 こう読み解く

  1. 左からほぼ水平に入った光は、もとの向きより下に出てくるはず。上向きのア・イは×。
  2. ウはもとの線をそのままのばした向き（曲がっていない）→ ×。
  3. 下向きに折れた エ が正しい。
答え：エ
今回：エ ○。図3と合わせて、屈折の向きを両方とも正しく決めている。

X復習 (8) 凸レンズの像の位置と高さ 条件文・レンズの計算

👀 まず見るところ

【条件文】部品は「焦点距離8cm」「左側10cm」「高さ6cm」と、求めるもの「レンズから何cm」「像の高さ」に丸。図5に、ろうそくと焦点の間の2cmが書かれている。「ろうそくは焦点のすぐ外側」と図の横に書くと、像が遠く大きくなる見当がつく。

📚 前提知識

  • 焦点の外側に物を置くと、反対側に倒立の実像ができる。焦点に近いほど像は遠く・大きくなる。
  • 位置は作図か公式。公式は「1／物の距離＋1／像の距離＝1／焦点距離」。像の高さは、物の高さ×（像の距離÷物の距離）。

🔍 こう読み解く

  1. 1／10＋1／□＝1／8 → 1／□＝1／8−1／10＝（5−4）／40＝1／40 → 像の位置は 40cm。
  2. 倍率は 40÷10＝4倍。像の高さは 6×4＝24cm。
  3. 作図で確かめるなら、光軸に平行な光→焦点を通る線と、レンズの中心を通る直線の2本。交わるのはレンズの右40cm・下向き24cmで合う。
答え：距離 40cm　高さ 24cm
今回：40・24 ○。図5に作図の線が引いてあり、光軸に平行な光とレンズの中心を通る光の2本で交点を出している。計算と作図のどちらでも出せる状態である。

  • 計算の(5)(8)と図の(7)は満点。熱量もレンズも光の屈折も、余白に式や作図が残っていて、手順が安定している。
  • 落とした(1)(2)(6)は3問とも「すべて選び」。(2)(6)は正しい2つを選べていて3つ目を拾いもれ、(1)は霜柱を霜と取りちがえた。選択肢を全部○×にする前に、見つかった2つで答えを書いている。
  • 次に「すべて選び」が出たら、①聞かれ方に丸 ②6つ全部に3語か○×を書く ③書き終えてから答えらんへ、の順に固定する。合わせて、霜と霜柱のちがい／水の4℃とろうの例外／音の高さは弦の条件だけ、の3つを言い直しておく。

ABC復習 (1) 湯気と同じ状態変化 素材文・すべて選ぶ

👀 まず見るところ

【素材文】部品は「湯気ができるときと同じ状態変化」と「すべて選び」。湯気の正体を1行で書く（水蒸気→水のつぶ＝気体→液体）→ 選択肢を「何から何へ」で1つずつ分ければ決まる。

📚 前提知識

  • 湯気は水蒸気そのものではなく、水蒸気が空気中で冷やされてできた小さな水のつぶ。だから白く見える（水蒸気は目に見えない）。
  • 気体→固体（霜）、固体→液体（とける）、液体→気体（蒸発）は別の状態変化。

🔍 こう読み解く

  1. ア 息の中の水蒸気が冷えて水のつぶに → 気体→液体 ○。
  2. イ 霜は水蒸気が直接氷になる → 気体→固体 ×。ウ つららがとけて水滴 → 固体→液体 ×。エ 水滴が消える → 液体→気体 ×。
  3. オ 空気中の水蒸気が冷たいコップで水滴に → 気体→液体 ○。
答え：ア・オ
今回：ア・オ ○。余白に「気→液」と書いてから選んでいて、正体を1行にする手順ができている。

ABC復習 (2) 氷200gを加熱したグラフ 条件文・作図

👀 まず見るところ

【条件文】図1と変わった部品は「200g」だけ（−20℃も22分もそのまま）。余白に「量が2倍 → かかる時間も2倍」と直して書く → 図1の折れ目の時刻を2倍にすれば線が決まる。

📚 前提知識

  • 熱は毎分1000カロリーで同じ。量が2倍なら、同じ変化に2倍の熱＝2倍の時間がかかる。
  • 折れ目の温度（0℃で止まる）は量に関係なく同じ。変わるのは横（時間）だけ。

🔍 こう読み解く

  1. 氷が −20℃→0℃：図1で1分 → 2分。(0分, −20℃)から(2分, 0℃)へ。
  2. とける：図1で8分 → 16分。2分から18分まで0℃の横線。
  3. 残り22−18＝4分で水200gが温まる：4000÷200＝20℃。(18分, 0℃)から(22分, 20℃)へ。
答え：(0分, −20℃)→(2分, 0℃)→(18分, 0℃)→(22分, 20℃) を結んだ折れ線

ABC復習 (3) −40℃の氷50gを6分加熱 まざり型→条件文・熱の計算

👀 まず見るところ

【まざり型→条件文】部品は「−40℃」「50g」「6分」。6分は熱の量に直して書く（6×1000＝6000カロリー）→ 氷を温める→とかす→水を温める、の順に引いていけば残りで温度が決まる。

📚 前提知識

ABC復習 (5) 最も高い音の弦のふるえ方 資料問題・1つ選ぶ

👀 まず見るところ

【資料問題】資料の正体を1行で書く：「1000分の1秒ごとに撮った、1往復の写真」。つまり線の本数＝1往復にかかった時間。聞かれ方「最も高い音」に線を引く → 本数が少ない（速くふるえる）ものが答えで、ふくらみの大きさは関係ない。

📚 前提知識

  • 音の高さは1秒間にふるえる回数（振動数）で決まる。多いほど高い。
  • 音の大きさはふるえのはば（振幅）で決まる。大きくふくらむほど大きい音。高い・大きいは別の軸。

🔍 こう読み解く

  1. 1往復の間に写った線を数える。ア 上下2本ずつ、イ 3本ずつ、ウ 1本ずつ、エ 2本ずつ。
  2. ウは1往復が最も短い時間で終わっている＝1秒間のふるえる回数が最も多い → 最も高い音。
  3. イは線が多く、ふくらみも大きい → 1往復に時間がかかる低い音で、ただし大きい音。
答え：ウ
今回：イ ×。知識＝「高い」を「大きい」と取りちがえ、いちばんふくらんだイを選んだ。資料の正体「1000分の1秒ごと」を書けば、見るのは線の本数だと決まる。

🔍 こう読み解く

  2. 太さ：細くする → エ ○（ウは低くなる）。

今回：イ・エ ○。

ABC復習 (7) 岸壁から船までの距離 条件文・反射音の計算

👀 まず見るところ

【条件文】部品は「毎秒10mで岸壁に向かいながら」「6秒後」「毎秒340m」と、求めるもの「音が聞こえたときの距離」。船と音が向かい合って進む図を描き、船が動いた10×6＝60mを図に置く → 鳴らしたときの距離から60を引いた所が答え。

📚 前提知識

  • 音は岸壁まで行って帰ってくる。船も近づくので、音が往復した道のりと船が進んだ道のりを合わせると、鳴らしたときの距離の2倍になる。
  • 「鳴らしたとき」と「聞こえたとき」で船の位置がちがう。設問がどちらを聞いているかに丸をつける。

🔍 こう読み解く

  1. 6秒で音が進んだ道のり 340×6＝2040m、船が進んだ道のり 10×6＝60m。
  2. 合わせて 2100m＝鳴らしたときの距離の2倍 → 鳴らしたとき 1050m。
  3. 聞こえたときは船が60m近づいている → 1050−60＝990m。
答え：990m
今回：1050 ×。部品を拾えなかった＝「音が聞こえたとき」に丸がなく、鳴らしたときの距離で止まった。余白の「350×6×1/2＝1050」まで正しいので、船が進んだ60mを図に置いていれば届いた。

ABC復習 (8) スクリーンにうつる像の高さ 条件文・凸レンズの作図と相似

👀 まず見るところ

📚 前提知識

  • 凸レンズの光の進み方：①軸に平行な光は反対側の焦点を通る、②中心を通る光は直進、③手前の焦点を通った光は軸に平行に出る。

  1. ろうそくは左の焦点より 18−6＝12cm 外側。ろうそくの先（高さ6cm）から左の焦点を通る光を引く。
  2. この光は焦点から6cm先のレンズで、軸の下側に出る。三角形の相似で、その高さ＝6×6÷12＝3cm。
  3. レンズを出た光は軸に平行に進むので、像の高さも3cm（上下さかさまの実像）。

今回：4 ×。部品の形を直さなかった＝焦点の位置を図に正確に置かず、交点を目分量で決めている（像が12cmの位置なら高さ4cmになる計算で、(9)の12cmと連動したずれ）。焦点を点で置いて、比で出す。

ABC復習 (10) 像を小さくする方法 条件文・すべて選ぶ

👀 まず見るところ

【条件文】部品は「図3の状態から」「はっきりうつる像を小さくする」「すべて選び」。像の大きさを決めるのはろうそくから焦点までの遠さ、と1行で直して書く → 焦点から遠ざかる変え方を選べば決まる。

📚 前提知識

  • ろうそくが焦点から遠いほど、像はレンズに近い所に小さくできる。焦点に近づくほど、像は遠く大きくなる。
  • 厚いレンズは光を強く曲げるので焦点距離が短い。うすいレンズは焦点距離が長い。
  • レンズの半分をおおっても、残り半分を通る光で像は同じ大きさ・同じ形にできる。暗くなるだけ。

🔍 こう読み解く

  1. ア 厚いレンズ → 焦点距離が短くなり、18cmのろうそくは焦点から遠くなる → 像は小さい ○。イ うすいレンズ → 焦点距離が長くなり、焦点に近づく → 像は大きい ×。
  2. ウ 近づける → 焦点に近づく → 大きい ×。エ 遠ざける → 焦点から遠ざかる → 小さい ○。
  3. オ・カ 半分をおおう → 大きさは変わらず暗くなるだけ ×。
答え：ア・エ
今回：イ・エ ×。知識＝「うすいレンズ＝焦点距離が長い＝焦点に近づく＝像が大きい」の向きが逆。エは取れているので、レンズの厚さと焦点距離の関係を1行で直せば両方そろう。
注意：解答一覧の印刷は「イ・エ」だが、先生が青ペンで「ア・エ」に訂正している。正しいのはア・エ。
