X復習 (1)① においのある水溶液 まざり型・すべて選ぶ

👀 まず見るところ

【まざり型→素材文】部品は実験2の「何も残らなかった」B・C・Eに丸。残らない＝とけているのが気体。においは、気体がとけた3つの中からさがすだけでよい。

  2. 炭酸水のBを外す → 残るのはCとE。
答え：C・E
今回：C・E ○。余白のメモでB・C・Eに「気」と書いてから選んでいる。

ABC復習 (4) 塩酸の量と食塩の重さのグラフ 資料問題・グラフ選択

👀 まず見るところ

【資料問題】表2の正体を1行「水酸化ナトリウム水溶液50cm³＋塩酸・残った固体g」。固体が30cm³から3.6gで変わらない → 30cm³でちょうど中和。縦軸は「食塩の重さ」に丸。

📚 前提知識

  • 塩酸と水酸化ナトリウム水溶液が中和すると食塩ができる。残った固体は、中和でできた食塩＋あまった水酸化ナトリウムの合計。
  • 塩酸があまっても、蒸発させると気体（塩化水素）がにげるので固体は残らない。だから30cm³をこえると固体はふえない。

🔍 こう読み解く

  1. 塩酸0cm³（A）では中和が起きていないので、食塩は0g。グラフは0から始まる。
  2. 塩酸を加えるほど食塩はふえ、30cm³でちょうど中和して3.6g。
  3. 30cm³から先は相手の水酸化ナトリウムが無いので、ふえずに横ばい。0から上がって途中から水平になるのはア。
答え：ア
今回：ア ○。設問の「食塩の重さ」を丸で囲んでいて、表2の「残った固体」（2.4gから始まる）と取りちがえていない。

ABC復習 (5) 塩酸の量と水酸化ナトリウムの重さのグラフ 資料問題・グラフ選択

👀 まず見るところ

【資料問題】(4)と変わった部品は縦軸の「水酸化ナトリウムの重さ」。表2のAの2.4gは塩酸0cm³なので全部が水酸化ナトリウム → 2.4gから始まり、へっていくグラフに決まる。

📚 前提知識

  • 水酸化ナトリウムは、加えた塩酸の量に比例して中和で使われてへる。ちょうど中和した所で0gになり、そのあとは0gのまま。

🔍 こう読み解く

  1. はじめは2.4g。塩酸30cm³で全部なくなるので、10cm³ごとに0.8gずつへる（B 1.6g、C 0.8g、D 0g）。
  2. 30cm³から先は0gのまま。はじめから下がって、途中から0で水平になるのはウ。
  3. エは、はじめに水平の部分がある。塩酸を入れてもへらない時期は無いので合わない。
答え：ウ
今回：ウ ○。(4)のアと対になる形（食塩がふえる間、水酸化ナトリウムはへる）を選べている。
コツ：固体の内わけを表にすると確かめられる。Bは水酸化ナトリウム1.6g＋食塩1.2g＝2.8g、Cは0.8g＋2.4g＝3.2gで、表2と合う。

ABC復習 (6) 塩酸60cm³＋水酸化ナトリウム水溶液150cm³ 条件文・中和の計算

👀 まず見るところ

【条件文】部品は「塩酸60cm³」「水酸化ナトリウム水溶液150cm³」。150は表2の50cm³の3倍なので、両方を÷3して「塩酸20：50」に直して書く → 表2のC（3.2g）の3倍で決まる。

📚 前提知識

  • 2つの水溶液を同じ割合のまま全体を何倍かにすると、残る固体の重さも同じ倍になる。

🔍 こう読み解く

  1. 150÷50＝3。塩酸も3でわると60÷3＝20cm³。表2のCと同じ割合。
  2. Cの固体は3.2g。全体が3倍なので3.2×3＝9.6g。
  3. 確かめ：塩酸60cm³と中和する水酸化ナトリウム水溶液は100cm³で、食塩は3.6×2＝7.2g。あまった50cm³から水酸化ナトリウム2.4g。7.2＋2.4＝9.6g。
答え：9.6g
今回：9.6 ○。表2の上に「60−150、20−50」と書き、Cの列を丸で囲んでいる。表にある割合に直してから3倍する解き方ができている。

ABC復習 (7) 酸化銅の色 知識問題

黒色。赤茶色の銅を空気中で加熱すると、酸素と結びついて黒色の酸化銅になる。エの青緑色は銅のさび（緑青）の色で、加熱してできる酸化銅とは別のもの。
答え：イ
今回：イ ○。

ABC復習 (8) 酸化せずに残った銅 条件文・グラフ＋計算

👀 まず見るところ

【条件文】部品は「銅6.0g」「粉末が7.0g」。ふえた分は結びついた酸素なので「7.0−6.0＝酸素1.0g」に直して書く → 図1の「銅4.0g→酸化銅5.0g」と比べれば、酸化した銅が決まる。

📚 前提知識

  • 図1から、銅4.0gが全部酸化すると酸化銅5.0g。結びつく酸素は1.0gで、銅：酸素＝4：1。
  • 加熱が不十分なときの粉末は、酸化銅と残った銅がまざっている。重さがふえた分だけが酸素。

🔍 こう読み解く

  1. ふえた重さ＝7.0−6.0＝1.0g。これが結びついた酸素。
  2. 酸素1.0gと結びつく銅は4.0g。酸化した銅は4.0g。
  3. 残っている銅＝6.0−4.0＝2.0g。
答え：2.0g
今回：2.0 ○。問題文の下に「1.0」と書いてあり、ふえた分＝酸素を先に出してから、残った銅まで引けている。
コツ：全部酸化すれば6.0×5/4＝7.5g。足りない酸素0.5gから、0.5×4＝2.0gと出すこともできる。

ABC復習 (9) 酸素の中でろうそくを燃やす 正しいものをすべて選ぶ

👀 まず見るところ

【素材文】部品は「酸素の入った集気びん」と答え方の「すべて選び」に丸。ア〜ウは燃え方、エ・オは燃えたあとにできるものの話 → 2つに分けて、5つ全部に○×をつける。

📚 前提知識

  • 酸素にはものを燃やすはたらきがある。空気中より酸素が多いので、ろうそくは激しく明るく燃える。
  • ろうには炭素と水素がふくまれる。燃えると二酸化炭素と水ができる。これは酸素の中でも空気の中でも同じ。

🔍 こう読み解く

  1. ア：激しく燃えて炎は大きくなる → ○。イ：炎は明るくなるが、青くはならない → ×。
  2. ウ：黒い煙（すす）は酸素が足りないときに出る。酸素が十分あるので出ない → ×。
  3. エ：できた水（水蒸気）がびんの内側について白くくもる → ○。オ：できた二酸化炭素で石灰水が白くにごる → ○。
答え：ア・エ・オ
今回：ア・エ・オ ○。燃え方のアだけで止めず、できるもの（水・二酸化炭素）のエ・オも選べている。

ABC復習 まとめ 次も同じ手順で

  • ホウ酸：表は水100gの数。水の量を何倍かに直してから、差（冷やす）か、へった水の分（蒸発）を求める。
  • 中和：固体がふえなくなる所がちょうど中和。残った固体は食塩＋あまった水酸化ナトリウム。
  • 銅の酸化：ふえた重さ＝酸素。銅：酸素＝4：1 で、酸化した銅と残った銅を分ける。
