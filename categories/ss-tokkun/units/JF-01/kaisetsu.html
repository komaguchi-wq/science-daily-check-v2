Ⅰ 1 表1の①・② 装置のちがい・完答

👀 まず見るところ

図1と図2を見比べて、ちがうのは三角フラスコが1つ多いか少ないかだけだと確かめる。図2は発生した気体がそのまま水をくぐってメスシリンダーに入る。図1は途中にもう1つフラスコがはさまっている。ここがこの大問全部の入口になる。

📚 前提知識

  • 図1では、発生した気体は大きな三角フラスコにたまり、そこにあった空気が押し出されてメスシリンダーに集まる。押し出される空気の体積は発生した気体の体積と同じなので、水にとけるかどうかに関係なく300cm³になる。
  • 酸素は水にほとんどとけない。二酸化炭素は水に少しとける（だからふつうは下方置換で集める）。

🔍 こう読み解く

  1. ①は酸素を図2の方法で集めた場合。水をくぐってもほとんど減らない → 300のまま → ア。
  2. ②は二酸化炭素を図2の方法で集めた場合。水にとけた分だけ減る → イ（300より小さい）。
答え：① ア　② イ
今回：①イ ②イ ×。解答らんが太わくの完答なので、②が合っていても点にならない。①でも「水を通れば減る」と考えたのが原因で、酸素と二酸化炭素のとけやすさのちがいがこの問題の全部だった。

Ⅰ 2 ビーカーにそそいだときのろうそく 装置のちがい・選択

👀 まず見るところ

問題文の「図1の方法で」。そそぐのはメスシリンダーに集まった気体で、図1ではそれは押し出された空気である。二酸化炭素ではない。

📚 前提知識

  • 二酸化炭素には物を燃やすはたらきがなく、空気より重い。本物の二酸化炭素をビーカーにそそげば、下にたまって火は消える。
  • 図1でメスシリンダーに来るのは、途中のフラスコに入っていた空気。二酸化炭素はそのフラスコの中にとどまっている。

🔍 こう読み解く

  1. 集まった気体の正体を先に決める → 空気。
  2. 空気を空気の中にそそいでも、ビーカーの中身は変わらない → ウ（特に変化はない）。
答え：ウ
今回：イ ×。「二酸化炭素なら火が消える」という知識そのものは正しい。ただ、集まっているのが何かを確かめていない。問1で図1のしくみを使ったのだから、その見方をここでも続けたかった。

Ⅰ 3 水のかわりにアンモニア水 中和・選択

👀 まず見るところ

変えたのは水槽の液だけ。②は「水をくぐって残った二酸化炭素の体積」だったので、液が変われば吸収されやすさが変わる。二酸化炭素は酸性の気体、アンモニア水はアルカリ性。ここが結びつく。

📚 前提知識

  • 二酸化炭素は水にも少しとけるが、アルカリ性の液にはよく吸収される。酸性とアルカリ性が打ち消し合う中和が起こるからで、石灰水が白くにごるのも同じ理由による。

🔍 こう読み解く

  1. アンモニア水を通ると、水のときより多くの二酸化炭素が吸収される。
  2. メスシリンダーまで届く量はそのぶん少なくなる → ウ（減る）。
答え：ウ
今回：イ（増える）×。液を変えれば二酸化炭素はとけにくくなる、と逆向きに考えたのだと思う。酸性の気体＋アルカリ性の液＝中和でよく吸収される、と一組にして覚えておきたい。

Ⅰ 4 気体の発生をすぐ止められる装置 装置の図・答えが複数

👀 まず見るところ

見るのは1点だけ。固体薬品を液体薬品から引きはなせるか。そして解答らんは1マスに「ウ・エ」と2つ入る形なので、1つ見つけても手を止めず、ア〜エを全部確かめる。

📚 前提知識

  • 反応は固体と液体がふれている間だけ続く。ふたを閉じても、ふれたままなら止まらない。
  • 発生した気体をとじこめると、その気体が液面を押し下げる。この力で固体を液から出すのがキップの装置の考え方。

🔍 こう読み解く

  1. ア：フラスコの底に固体、その上に液体。ピンチコックを閉じても固体はひたったまま → 止まらない。
  2. イ：ふたまた試験管に似ているが、固体を引っかけるくぼみがない。かたむけても固体が液といっしょに動いてしまう → 止まらない。
  3. ウ：2本の管がゴム管でつながっている。固体の入った側を高く持ち上げれば液が反対側へ流れ、液面が下がって固体が出る → 止まる。
  4. エ：布袋の固体を糸でつるして液にひたしてある。ピンチコックを閉じると気体がにげられず、たまった気体が液面を押し下げる → 止まる。
答え：ウ・エ
今回：エ ×。エは正しく選べていて、ピンチコックのはたらきは分かっている。落としたのはウで、「持ち上げると液面が下がる」という動きを図から想像するところだった。答えが複数入る形の問題は、1つ見つけたあとに残りを見直す時間を決めておきたい。

Ⅰ 5あ Eに入れた固体薬品の重さ 表2の比例計算

👀 まず見るところ

表2を「とけた重さ」に直す。Bは6g入れて2g残っているので、とけたのは4g。これが濃さ①・体積5cm³のときの量で、A〜Eすべての基準になる。

📚 前提知識

  • とける固体の量は、液体薬品の濃さ×体積に比例する。濃さが2倍なら2倍、体積が2倍ならまた2倍とける。

🔍 こう読み解く

  1. EはBと比べて、濃さが3倍、体積が5cm³→25cm³で5倍 → 3×5＝15倍とかせる。
  2. とける量は 4×15＝60g。
  3. 入れた重さ＝とけた量＋とけ残り → 60＋24＝84g。
答え：84（g）
今回：84 ○。余白のメモに「60」が出ていて、Bの4gを基準に何倍かをたどる道すじができている。

🔍 こう読み解く

Ⅰ 6 Bと Cで発生した二酸化炭素の量 表2・比べる

👀 まず見るところ

ここでも見るのはとけた重さ。B＝4g、C＝2g。発生する気体の量を決めるのは、濃さでも体積でもなく、とけた固体薬品の量である。

📚 前提知識

  • 二酸化炭素は、石灰石（炭酸カルシウム）が塩酸にとけることで出てくる。だからとけた石灰石が2倍なら、出る気体も2倍になる。

🔍 こう読み解く

  1. C：6g入れて4g残り → とけたのは2g。B：とけたのは4g。
  2. 4÷2＝2 → イ（2倍の量）。
答え：イ
今回：イ ○。とけ残りの数字にまどわされず、とけた量どうしで比べられている。

Ⅰ 7 Bと Cで発生が終わるまでの時間 反応の速さ・選択

👀 まず見るところ

6と同じBとCだが、聞かれているのは量ではなく時間。ここで足すのは「濃いほど速い」の一つだけ。量は「とけた重さ」、速さは「濃さ」と、見る場所を分ける。

📚 前提知識

  • 反応の速さは液体薬品の濃さで決まる。濃いほど速く進む。
  • 反応が進むにつれて塩酸は使われてうすくなるので、後半ほど遅くなる。

🔍 こう読み解く

  1. BはCの2倍の濃さ。Bで最初の2gがとけるまでは、Cで2gとけるより速い。
  2. そのころBの塩酸は半分使われていて、ちょうどCの濃さくらいになっている。残り2gにかかる時間は、Cの全体とほぼ同じ。
  3. 合わせると「Cより長く、Cの2倍よりは短い」 → イ。
答え：イ
今回：エ（2倍より長い時間）×。「とける量が2倍だから時間も2倍以上」と、6の答えをそのまま時間に置きかえたのだと思う。濃さが2倍なら前半は速い、というひと手間がここで入る。
コツ：BとCを比べる問題が続くときは、量は「とけた重さ」／速さは「濃さ」と余白に2行書いてから読むと、6と7を続けて解ける。

👀 まず見るところ

113gが2回出てくること。キャップをしめたままなら、あわが出ても全体の重さは変わらない。減ったのはキャップをゆるめたあとで、113−112.364＝0.636gが出ていった二酸化炭素の重さになる。
もう一つ、体積はこの文章のどこにも書いていない。「図1の方法で二酸化炭素を発生させたときと同じ量の薬品」とあるので、表1へ戻って300cm³を持ってくる。

📚 前提知識

  • 密閉した容器の中では、気体が発生しても全体の重さは変わらない。にげ場がないから。

🔍 こう読み解く

  2. その体積：表1より300cm³＝0.3L。
  3. 0.636÷0.3＝2.12 → 2.12 g/L。（解説の式は 0.636÷300×1000）
答え：2.12 g/L
今回：空らん ×。聞かれているのが密度なので、まず余白に「密度＝重さ÷体積」と書き、上の行に0.636g、下の行に「体積＝？」と置くところから始めたい。そこまで書けば、体積を探しに表1へ戻れる。

Ⅰ 9 蒸発して残る白い固体の重さ 表2・比べる

👀 まず見るところ

「残った液だけを取り出し」の一言。とけ残った固体は取り出さないので関係ない。比べるのは、AとBでとけた石灰石の量だけになる。

📚 前提知識

  • 余っている塩酸は蒸発してしまうので、あとには残らない。だから残る量はとけた石灰石の量で決まる。

🔍 こう読み解く

  1. A：2g入れてとけ残りなし → とけたのは2g。
  2. B：6g入れて2g残り → とけたのは4g。
  3. 4÷2＝2倍。
答え：2（倍）
今回：2 ○。とけ残りが2gあるBで、それを足さずに「とけた4g」だけで比べられている。

Ⅰ まとめ 4／10正解・40点

  • 取れたのは5あ・5い・6・9。表2を「とけた重さ」に直す計算はひととおりできている。この4問は同じ道具で解いていて、後半の土台はある。
  • 落とした1・2・3は、ばらばらの3問に見えてもとは一つ。図1は空気を押し出して集めるので水にとけても減らない、図2は気体そのものが水を通る。この1行を最初に書いておけば、3問まとめて取れた30点だった。
  • 残りは、4がウの見落とし（答えが2つ入る形）、7が「濃さ＝速さ」のひと手間、8が体積300cm³を表1から持ってくること。覚え直しは酸素は水にほとんどとけない／二酸化炭素はアルカリ性の液に中和で吸収される／密閉したビンは気体が出るまで重さが変わらないの3つ。

JF-01 Ⅱ 気体の発生計算（鉄と塩酸）

Ⅱ 全体像 計算 4問（各25点）

4問とも「式や求め方」を書く欄つきで、1問25点と重い。表が3つ出てくるが、やることはどれも同じで、①この表は何を変えて何を固定したか ②1あたりいくつか ③比例が止まるのはどこかの順に見る。

表変えたもの／固定したもの1あたり
表1塩酸10〜50cm³を変える／鉄粉3.0gで固定塩酸10cm³で水素250cm³
表2鉄粉1.2〜4.8gを変える／塩酸200cm³で固定鉄粉1.2gで水素480cm³
表3塩酸20〜80cm³を変える／鉄粉12gで固定塩酸20cm³で水素300cm³

そして全体をつらぬく考え方は一つ、鉄と塩酸のうち、先になくなったほうで水素の量が決まるということである。表1ではそれが50cm³のところで表に現れている。表2と表3はまだ比例している途中までしか書かれていないので、自分で両方を計算して小さいほうを取ることになる。始める前に「鉄1.2g→水素480cm³」「塩酸20cm³→水素300cm³」の2本を余白に書こう。問3と問4はこの2本だけで解ける。

Ⅱ 問1 塩酸を80cm³加えたときの水素 表1・比例の打ち止め

👀 まず見るところ

表1の横の並びを、まず割り算で確かめる。10→250、20→500、30→750、40→1000 はすべて25倍。ところが50は1250にならず1200で止まっている。この比例が崩れた1か所が問題の中心で、80cm³はそのさらに先にある。

📚 前提知識

  • 鉄＋塩酸 → 水素。どちらかがなくなれば、そこで発生は終わる。
  • この実験で鉄粉は3.0gに固定されている。塩酸をいくら増やしても、鉄が全部とけてしまえばそれ以上は出ない。

🔍 こう読み解く

  1. 50cm³で1200止まり → 鉄粉3.0gから出る水素の上限が1200cm³だと分かる。
  2. 80cm³は塩酸が余るだけで、鉄はもう残っていない。
  3. よって水素は1200cm³のまま。
答え：1200 cm³
今回：1200 ○（25点）。求め方の欄に「1200cm³が限界」と書き、30・40・50と750・1000・1200を並べて「250ではなく200で止まる」と確かめている。比例が崩れる場所を自分で見つけて書いたので、そのまま満点になっている。

Ⅱ 問2 水素の発生が止まる塩酸の量 表1・逆算

👀 まず見るところ

「発生が止まる」を言いかえる。鉄粉3.0gがちょうど全部とけた瞬間で、そのとき水素は問1で出した1200cm³。つまり水素1200cm³を出すのに必要な塩酸は何cm³かという問題になる。

📚 前提知識

  • 逆算に使えるのは比例している範囲（40cm³まで）の割合だけ。塩酸10cm³で水素250cm³を使う。
  • 40cm³より後ろの数字を割合に使うと、打ち止めの1200が混ざってしまい合わなくなる。

🔍 こう読み解く

  1. 1200は250の何倍か → 1200÷250＝4.8倍。
  2. 塩酸も同じだけ要る → 10×4.8＝48cm³。（解説の式は 10×1200/250＝48）
  3. 検算：48cm³は表の40と50の間にあり、50では止まっていたという話とも合う。
答え：48 cm³
今回：48 ○（25点）。答案は「40＋10×4/5」。40cm³ですでに1000cm³出ているので、残り200cm³ぶんを10cm³の5分の4として足した形で、模範の式とは違うが考え方は正しい。比例している40cm³までの割合を使うという一番大事なところを外していない。

Ⅱ 問3 表2で鉄粉12gを加えたときの水素 表2・表3／少ないほうで決まる

👀 まず見るところ

表2は塩酸200cm³が固定で、鉄粉は4.8gまでしか試していない。聞かれている12gは表の外にある。鉄を増やしていけば、いつかは塩酸のほうが足りなくなる――ここに気づけるかどうかがすべてで、表2だけを見ていると気づけない。表3が同じ濃さの塩酸の表であることが手がかりになる。

📚 前提知識

  • 鉄と塩酸のうち、先になくなったほうで発生量が決まる。だから両方を別々に計算して、小さいほうを答えにする。
  • 表3から、この濃さの塩酸は20cm³で水素300cm³ぶんのはたらきをする。

🔍 こう読み解く

  1. 鉄側：鉄粉12gが全部とけたとすると 12÷1.2×480＝4800cm³。
  2. 塩酸側：塩酸200cm³が全部使われたとすると 200÷20×300＝3000cm³。
  3. 小さいのは3000 → 塩酸が先になくなり、鉄粉はとけ残る。答えは3000cm³。
答え：3000 cm³
今回：空らん ×（0点）。表2だけで考えると12÷1.2×480＝4800まで進んでしまい、そこから先に進めなくなる。表2と表3が同じ濃さの塩酸でつながっていると気づくのが入口だった。25点の問題なので、鉄側と塩酸側の2本の式を書くだけでも部分点をねらう価値がある。
コツ：「どちらかが足りるか」を聞く問題は、紙に2行そろえて書く。上の行に鉄側、下の行に塩酸側、その下に丸をつけて小さいほう。これだけで形が決まる。

Ⅱ 問4 鉄粉12gを過不足なくとかす塩酸 表3・逆算

👀 まず見るところ

「過不足なくとかす」＝鉄も塩酸もどちらも余らず、ちょうど使いきる。つまり鉄粉12gが全部とけきる量の塩酸を聞かれている。問3で出した鉄側の数字4800cm³が、そのまま使える。

📚 前提知識

  • 鉄の量から塩酸の量は直接は出せないので、水素の量を橋わたしにする。鉄 → 水素 → 塩酸の順にたどる。

🔍 こう読み解く

  1. 鉄粉12gが全部とけると水素は 12÷1.2×480＝4800cm³（問3の鉄側と同じ）。
  2. 表3より、塩酸20cm³で水素300cm³。
  3. 4800cm³を出すのに必要な塩酸は 4800÷300×20＝320cm³。
  4. 検算：320cm³は問3の200cm³より多い。問3で塩酸が足りなかったという話と合っている。
答え：320 cm³
