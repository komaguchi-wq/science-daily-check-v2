SS-07 X1（ろうそくの炎・燃焼でできる物質）

X1 全体像 ろうそくの炎・観察・燃焼 10問

図1のろうそく1本で、炎の3つの部分 → ガラス管を入れたときの変化 → ろうの液体の動きと固まり方 → 燃えてできる物質、と順にたどる大問である。入口は図1の炎の3層の名前と温度で、(1)(2)はここだけで決まる。(3)〜(5)は「ろうは固体→液体→気体と変わってから燃える」という流れを図に当てはめる。(6)(7)は「ろう＝炭素＋水素」から決まる。

図1の記号名前そこで起きていること温度・明るさ
ア（外側の点線）外炎空気にふれて完全燃焼温度がいちばん高い。うすくて見えにくい
イ（まん中）内炎空気が足りず不完全燃焼。炭素の粒（すす）が熱で光るいちばん明るい
ウ（芯のすぐ上）炎心ろうの気体がまだ燃えていない温度がいちばん低い。暗い

X1 (1)①②③ 炎の3つの部分と温度・明るさ 図の読み取り＋名前

👀 まず見るところ

【資料問題】部品は図1の正体「炎の3層＝ア 外側・イ まん中・ウ 芯のすぐ上」。余白に「ア外炎・イ内炎・ウ炎心」と3語で書く → 聞かれ方「最も温度が高い／明るい／低い」に線を引けば、外側から順に 高温・明るい・低温 と決まる。

📚 前提知識

  • 外炎は空気（酸素）にじゅうぶんふれるので完全燃焼し、温度がいちばん高い。ただし光る粒がないので、うすくて見えにくい。
  • 内炎は酸素が足りず不完全燃焼。燃え残った炭素の粒（すす）が熱で光るので、いちばん明るい。
  • 炎心は芯から出たろうの気体がまだ燃えていない部分。燃えていないので温度がいちばん低い。

🔍 こう読み解く

  1. 図1の記号を名前に直す。ア＝外側の点線の層＝外炎、イ＝まん中の層＝内炎、ウ＝芯のすぐ上の小さな層＝炎心。
  2. ① 最も温度が高い＝完全燃焼している外炎（ア）。② 最も明るい＝すすが光る内炎（イ）。③ 最も温度が低い＝燃えていない炎心（ウ）。
  3. 「明るい＝熱い」ではない。明るさは光る粒があるかどうか、温度は完全燃焼しているかどうかで決まる。この2つを分けておく。
答え：① ア・外炎　② イ・内炎　③ ウ・炎心
コツ：解答らんは記号と名前の2か所。記号だけ書いて名前を空けないよう、書いたあとに「ア→外炎」と声に出して確かめる。

X1 (2)① 内炎から出る黒いけむり 観察＋物質名

X1 (2)② 炎心から出る白いけむり 観察＋選択

👀 まず見るところ

【素材文】部品は「ウでは白いけむり」と、(2)①と変わった「ウ」に丸 → ウ＝炎心＝ろうの気体がまだ燃えていない場所。燃えていないので出てくるのは水や二酸化炭素ではなく、ろうそのものと決まる。

📚 前提知識

  • 炎心では、芯を上ってきたろうの液体が熱で気体になっている。まだ燃えていないので、燃焼でできる水はここにはない。

🔍 こう読み解く

  2. ウ「ろうの気体」は、気体は透明で白く見えない → ×。白く見えるのは冷えて粒になったろうの液体や固体 → エ。
  3. 検算：この白いけむりに火を近づけると燃えて炎が飛び移る（ろうだから）。すすは燃えない黒、ろうは燃える白、と対で覚える。
答え：エ

X1 (3) チョークの粉の動き 図＋選択

👀 まず見るところ

【資料問題】部品は図の正体「上から見た芯とろうの液体・端にチョークの粉」と設問の「ろうの液体の動き」。液体がどこへ向かって動いているかを1語で書く（芯へ）→ 粉は液体に運ばれて芯に向かうと決まる。

📚 前提知識

  • ろうそくは、炎の熱でとけたろうの液体が芯に吸い上げられ、芯の先で気体になって燃える。液体は外側から芯に向かって流れ続けている。

X1 (4) ろうの液体が固まった形 状態変化＋選択

👀 まず見るところ

【資料問題】部品は「ろうの液体がかたまって固体になる」と、図の点線（もとの液面）。液体→固体で体積が「減る」と1語で書く → 元の液面より中心が下がった形を選ぶと決まる。

📚 前提知識

  • ろうは液体から固体になると体積が減る。多くの物質がこうで、固体になると体積が増える水のほうが例外。

🔍 こう読み解く

  1. 設問は「固体になるとどうなるか」。体積が減るので、元の液面（点線）より下がる。点線より上にふくらむイ（体積が増えた形）と、点線と同じ高さのエ（変わらない形）を先に消す。
  2. 減り方は中心ほど大きい。ふちは土手のように残り、中心がくぼむ形 → ウ。
  3. 火を消す前の「土手」は、燃えているあいだずっと外側のろうが固体のまま残ることでできる。これが次の(5)につながる。

X1 (5) 外側が土手のように残る理由 記述

👀 まず見るところ

【素材文】設問の「なぜ」に丸 → 答えは「〜ため。」で結ぶ。部品は(4)の「外側が土手のように」＝外側だけとけないということ。炎の熱がとどいているのに外側がとけない理由は、空気の流れ（対流）で決まる。

📚 前提知識

  • 炎であたためられた空気は軽くなって上にのぼる。すると下から冷たい空気が流れこむ。これが対流。
  • 流れこむ冷たい空気はろうそくの外側をなでて上がっていくので、外側のろうは温度が上がりにくく、固体のまま残る。

✍️ 答案の組み立て

  1. 要素A：炎の熱で対流が起こる。
  2. 要素B：まわりの空気が下から上に流れる。
  3. 要素C：その空気が外側を冷やす（だからとけない）。A→B→Cの順につなぎ、「〜ため。」で結ぶ。
模範解答：ろうそくの炎の熱によって対流が起こり、まわりの空気が下から上に流れ、外側を冷やすため。
コツ：「外側は炎から遠いから」だけでは足りない。遠いだけなら少しずつとけるはずで、とけないのは冷たい空気が流れてくるから。「対流」「下から上」「冷やす」の3語がそろっているか見直す。

X1 (6) 燃焼でできる物質とろうの成分 物質名・2組

👀 まず見るところ

【素材文】設問は2つ。「燃焼するとできる物質を2つ」と「ろうに何という物質が含まれる」に丸。できる物質（水・二酸化炭素）を先に書き、その中の酸素以外＝水素・炭素、とできる物質から逆算すれば2問目が決まる。

📚 前提知識

  • 燃焼＝物質が酸素と結びつくこと。ろうに含まれる水素が酸素と結びつくと水（水蒸気）、炭素が酸素と結びつくと二酸化炭素になる。
  • 確かめ方：ろうそくの上に冷えたコップをかぶせると水滴（水）、石灰水を入れると白くにごる（二酸化炭素）。

🔍 こう読み解く

  1. できる物質：水と二酸化炭素。
  2. 水＝水素＋酸素、二酸化炭素＝炭素＋酸素。酸素は空気から来るので、ろうに含まれていたのは水素と炭素。
  3. 解答らんは「できる物質」2つと「含まれる物質」2つ。水↔水素、二酸化炭素↔炭素の対応で書く。
答え：できる物質 水・二酸化炭素　含まれる物質 水素・炭素

X1 (7) 水と二酸化炭素の両方ができるもの 選択・すべて選ぶ

👀 まず見るところ

【素材文】部品は「ろうそくと同じ2つの物質」と「すべて選び」に丸。(6)から、同じ2つ＝水と二酸化炭素＝水素と炭素の両方を含むものと言いかえて書く → ア〜オを「水素と炭素があるか」で1つずつ○×。

📚 前提知識

  • 炭素と水素の両方を含んで燃えるもの：アルコール、都市ガス（主成分メタン＝炭素と水素が結びついたもの）、でんぷん・砂糖などの植物からできたもの。燃やすと水と二酸化炭素ができる。
  • 備長炭（木炭）は主に炭素だけ → 二酸化炭素はできるが水はできない。スチールウールは鉄 → 酸素と結びついて酸化鉄になるだけで、気体は出ない。

🔍 こう読み解く

  1. ア アルコール：炭素と水素を含む → 水・二酸化炭素 → ○。
  2. イ 都市ガス：主成分はメタン（炭素＋水素） → ○。エ でんぷん：植物がつくった養分で炭素・水素を含む → ○。

答え：ア・イ・エ
コツ：「すべて選び」はア〜オの5つ全部に○×をつけてから答えを書く。ウは「二酸化炭素は出る」で○にしがちなので、「2つとも」の条件をもう一度見る。

X1 まとめ 10問

  • ろう＝炭素＋水素 → 燃えると二酸化炭素＋水。「同じ2つができる」は炭素と水素の両方を含むもの。

C 鉄粉が塩酸に化学反応別の物質になる（水素＋塩化鉄）——

X4 (1) あ〜うにあてはまる物質 素材文・空らん補充

👀 まず見るところ

【素材文】部品は表の（　）の中、「実験室で観察できる」と「い、う とも液体」に丸。あ＝氷と同じ分類（固体があたためられて液体になる）、い＝水にとける液体、う＝水にとけない液体、と3語で書いてから物質名を決める。

📚 前提知識

  1. あ：固体→液体の状態変化で、実験室で観察できるもの → ろう。ろうそくの炎のまわりで、固体のろうが液体になって流れる。

  3. う：水にとけない液体 → 食用油。水に入れても混ざらず、上に浮いて層になる。
答え：あ ろう　い アルコール　う 食用油
別紙の補足：あは他にバター、いは他に酢酸、うは他に水銀でもよい。

X4 (2) 氷がとける前後の重さと体積 条件文・選択

👀 まず見るところ

Z2 (1) ガス漏れ報知器を上につける気体 条件文・密度の比べ方
