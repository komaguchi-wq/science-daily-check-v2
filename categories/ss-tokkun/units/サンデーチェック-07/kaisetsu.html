X復習 (1)① 図1より明るい豆電球のある回路 条件文・すべて選ぶ

👀 まず見るところ

【条件文】部品は「図1の豆電球より明るく」と「すべて選び」に丸。明るさは豆電球を流れる電流の大きさなので、図1を1として6つの図の豆電球に電流の数字を書きこむ（図に置く）→ 1より大きい図だけが答えになる。

📚 前提知識

  • 豆電球を直列にすると電流が流れにくくなり、2個なら1/2、3個なら1/3。並列にすると、それぞれの豆電球に1ずつ流れる。
  • 乾電池を直列に2個つなぐと押す力が2倍で、電流は2倍。並列に2個つないでも、豆電球を流れる電流は1個のときと同じ。

🔍 こう読み解く

  1. 図3：豆電球が並列で、乾電池が直列2個。それぞれの豆電球に2が流れる → 図1より明るい。
  2. 図2は1/2、図4は1/2、図5は2/3。図6は手前の豆電球が2/3で、並列の2個は1/3ずつ。どれも1より小さい。
  3. 1より大きいのは図3だけ。
答え：3
今回：3 ○。図の横に「1・1/2・4・1/2・2/3・2/3」と電流を書きこんでから答えている。この書きこみが①〜④の全部で効いた。

X復習 (1)③ 東にふれる方位磁針 条件文・電流の向きと磁界

👀 まず見るところ

【条件文】部品は「ア〜ウは導線の上、エ〜カは導線の下」と、各図の乾電池の長い線（＋極）がどちら側か。＋極から出る電流の向きを6つの図の左の導線に矢印で置く → 上か下か・北向きか南向きかの2つで、ふれる向きが決まる。

📚 前提知識

  • 導線の上に置いた方位磁針は、電流が北向きなら東にふれる。下に置くと逆の西。電流の向きが逆なら、それぞれ逆になる。
  • 図の北は上。左の導線の電流が上向き＝北向き、下向き＝南向き。

🔍 こう読み解く

  1. 図1・2・3・5は＋極が左 → 電流は左の導線を北向きに上がり、右の導線を南向きに下りる。図4・6は＋極が右 → 左の導線を南向きに下りる。
  2. 上に置いたア・ウ（北向き）→ 東。イは右の導線（南向き）の上 → 西。
  3. 下に置いたオ（北向き）→ 西。エ・カ（南向き）→ 東。
答え：ア・ウ・エ・カ
今回：ア・ウ・エ・カ ○。＋極が右にある図4・図6で向きを反転できている。

👀 まず見るところ

【条件文】部品は「ふれ方の大きい順」と「等号や不等号を使って」に丸。ふれ方の大きさは方位磁針が乗っている導線の電流の大きさなので、①で書きこんだ数字をア〜カの横にそのまま置く → 大きい順に並べるだけで決まる。向きは関係ない。

  • ア〜カはすべて乾電池につながる導線の上にあるので、乗っているのは回路全体の電流（豆電球に分かれる前の電流）。

🔍 こう読み解く

  2. 大きい順に 4、1、2/3、2/3、1/2、1/2。同じ数は等号でつなぐ。

今回：ウ＞ア＞オ＝カ＞イ＝エ ○。図4で一度書いた数字を消して1/2に直したあとがあり、並列の乾電池でも豆電球の電流は変わらないと確かめ直している。

X復習 (2)①② スイッチを閉じたときにつく豆電球 条件文・ショートの回路

👀 まず見るところ

【条件文】部品は「スイッチAだけ」と、②で変わった「AとB」に丸。閉じたスイッチを図7で導線になぞり、乾電池の＋から−までたどれる道を線で置く → 「導線だけの道」と並んだ豆電球はつかない（ショート）。

📚 前提知識

  • 電流は、豆電球のある道と導線だけの道が並んでいると、導線だけの道を通る。並んだ豆電球には流れない（ショート）。
  • 図7の形：左下の点と上のまん中の点をつなぐのがA、上のまん中と右上をつなぐのがB、下のまん中と右上をつなぐのがC。乾電池は底辺の左寄り。

🔍 こう読み解く

  1. ①：Aを閉じると、左下の点から上のまん中まで導線だけで行ける。豆電球1→2の道はこれと並んでいるので1・2はつかない。上のまん中から下へ、豆電球3を通って乾電池に戻る → 3がつく。4はBもCも開いていて道がない。
  2. ②：Bも閉じると、上のまん中から右上へも行ける。右上→豆電球4→右下→底辺→乾電池、という道が3の道と並んでできる → 3と4がつく。1・2は①と同じくショートされたまま。
答え：① 3　② 3・4
今回：① 3 ○　② 3・4 ○。図7に電流の道を鉛筆で何本もなぞっていて、閉じたスイッチを導線として扱えている。

X復習 (2)③ 豆電球1と2だけがつくスイッチ 条件文・逆向きに考える

👀 まず見るところ

【条件文】部品は「1と2だけ」と「閉じているスイッチをすべて」。「だけ」を「3と4は消す＝ショートさせる」に直して書く → 1・2を生かすにはAは開いたまま、3と4を消すのに使えるのはBとCだけ、と決まる。

📚 前提知識

  • Aを閉じると1・2がショートされて消える（①で確かめた）。1・2をつけたいならAは開く。
  • 豆電球を消すには、その両はしを導線だけでつなぐ。

🔍 こう読み解く

  1. Aは開く。電流は左下→豆電球1→豆電球2→上のまん中まで来る。
  2. そこから乾電池に戻る道は、豆電球3か、B→右上→C→下のまん中。BとCを閉じると導線だけの道ができ、3はショートされて消える。
  3. 4は右上と右下の間にあるが、Cで右上と下のまん中が導線でつながり、右下も底辺で同じ点になる → 4も両はしが導線でつながって消える。1・2だけが残る。
答え：B・C
今回：B・C ○。「つける」でなく「3と4を消す」から考えられている。

X復習 (2)④ すべて点灯しないスイッチの入れ方 条件文・場合を全部調べる

👀 まず見るところ

【条件文】部品は「1〜4すべてが点灯しない」と「何通り」。「すべて点灯しない」を「乾電池の両はしが導線だけでつながる（回路全体のショート）」に直して書く → それができる閉じ方は1つしかない、と決まる。

📚 前提知識

  • スイッチ3個の入れ方は 2×2×2＝8通り。全部開いていても、豆電球1→2→3の道があるので豆電球はつく（「全部開く」は答えにならない）。
  • どれか1つでも豆電球を通る道しか残らなければ、その豆電球はつく。全部消えるのは、豆電球を通らずに乾電池の＋から−へ戻れるときだけ。

🔍 こう読み解く

  1. 導線だけで乾電池の両はしをつなぐ道は、左下→A→上のまん中→B→右上→C→下のまん中 の1本。A・B・Cの3つ全部を閉じるときだけ。
  2. 念のため8通りを表でつぶす。全部開：1・2・3がつく／Aだけ：3／Bだけ：1・2・3・4／Cだけ：1・2・3／A・B：3・4／A・C：3／B・C：1・2／A・B・C：なし。
  3. 「なし」は最後の1つだけ → 1通り。
答え：1通り
今回：2通り ×。部品の形を直さなかった＝「すべて点灯しない」を「乾電池を導線だけでつなぐ」に直さず、頭の中で数えた。どの2つを数えたかは紙面に無い。次は8通りを表に書いて、1行ずつ「つく豆電球」を書き出してから数える。
コツ：「何通り」と聞かれたら、スイッチの表（開／閉を全部並べる）を先に書く。8行なら2分で終わる。

X復習 (3)① 電流による発熱を利用している道具 知識問題

答え：イ・ウ
今回：イ・ウ ○。豆電球を「発熱」に入れられている。

X復習 (3)② 電流による磁界の発生を利用している道具 知識問題

ア 扇風機・イ ドライヤー・エ スピーカー・オ リニアモーターカー。コイルに電流を流すと電磁石になる、を使う道具はこの4つ。扇風機とドライヤーの風はモーター（電磁石と磁石で回す）、スピーカーはコイルと磁石で板をふるわせる、リニアモーターカーは電磁石で浮いて進む。ドライヤーは「熱」と「モーター」の両方を使うので①にも②にも入る。
答え：ア・イ・エ・オ
今回：オ ×。知識＝「モーター＝電磁石」が結びついていなかった。モーターで動くもの（扇風機・ドライヤーの風）とスピーカーが抜けた。「回るもの・音を出すものは電磁石」と1行で覚え直す。

X復習 まとめ 8／10問・80点

  • (1)の4問と(2)の①〜③は全部正解。図に電流の数字と向きを書きこみ、閉じたスイッチを導線としてなぞる、という回路の読み方は身についている。
  • 落とした2問は型がちがう。(2)④は「すべて点灯しない＝乾電池をショート」に言いかえず、頭の中で数えた。(3)②は「モーター＝電磁石」の知識。
  • 次に同じ形が出たら：「何通り」は表を書いて全部つぶす／電流の利用は「熱（ニクロム線・フィラメント）」「磁界（モーター・スピーカー・リニア）」の2つの箱に道具を入れる。

ABC復習 (2)図5 豆電球2個の並列・乾電池2個の直列 条件文・記号

👀 まず見るところ

【条件文】部品は図5の「豆電球が2本の枝に分かれる」と「乾電池2個が直列」。枝1本ずつの電流と、合流したあと乾電池を通る電流を、図の別の場所に書く → 聞かれている「1つの豆電球」と「乾電池」は別の数になる。

📚 前提知識

  • 乾電池2個直列は押す力が2倍。豆電球1個なら電流は2。

🔍 こう読み解く

  1. 乾電池2個直列なので、枝1本（豆電球1個）の電流は2。
  2. 枝が2本あるので、乾電池を通るのは 2＋2＝4。

今回：キ・キ ×。部品の形を直さなかった＝合流後の4を豆電球にも入れた。枝1本に「2」、合流点のあとに「4」と図の別の場所に書いてから答えらんへ写す。

ABC復習 (2)図6 豆電球2個の直列・乾電池2個の並列 条件文・記号

👀 まず見るところ

【条件文】部品は図6の「豆電球2個が1本の線に並ぶ」と「乾電池2個が並列」。直列の豆電球には「分け合う→1/2」、並列の乾電池には「分担→その半分」と図に書く → 豆電球と乾電池で数がちがう。

  2. その1/2を乾電池2個で分担 → 1個あたり 1/4。

ABC復習 (2)図7 豆電球3個の直列・乾電池2個の直列 条件文・記号

👀 まず見るところ

【条件文】部品は図7の「豆電球3個が直列」と「乾電池2個が直列」。上に「流れにくさ3」、下に「押す力2」と書く → 2÷3。一本道なので豆電球も乾電池も同じ電流になる。
