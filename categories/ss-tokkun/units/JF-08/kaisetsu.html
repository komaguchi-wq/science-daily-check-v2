Ⅰ 1あ 振れ幅が大きいときの最下点の速さ 選択 5点

👀 まず見るところ

【素材文】部品は「振れ幅が大きく」と、聞かれている「最下点を通るときの速さ」に丸。振れ幅が大きい＝高いところから放す、と言いかえれば速さが決まる。

📚 前提知識

  • 振り子の最下点での速さは、放す高さで決まる。高いところから放すほど速い。
  • 等時性は「周期が変わらない」という決まりで、「速さが変わらない」という決まりではない。周期が同じでも、振れ幅が大きければ長い道のりを同じ時間で動くので速い。

🔍 こう読み解く

  1. 同じ長さで振れ幅を大きくする → おもりを放す位置が高くなる。
  2. 高いところから下りてくるので、最下点での速さは速くなる。
答え：速くなり
今回：速くなり ○。

Ⅰ 1い 振れ幅が大きいときの周期 選択 5点

👀 まず見るところ

【素材文】部品は「等時性が成り立たないとき」に丸。等時性＝周期が変わらないこと。それが成り立たないのだから「変わりません」は消え、長いか短いかの2択になる。

📚 前提知識

  • 振れ幅がとても大きいときは、振れ幅が大きいほど周期は長くなる（解答・解説の説明）。動く道のりがのびる分を、速さの増え方では取り返しきれなくなる。

🔍 こう読み解く

  1. 問題文の最初に「振れ幅がある程度小さい場合は」周期は長さだけで決まる、とある。条件つきの決まりである。
  2. 条件から外れた大きな振れ幅では、周期は長くなる。
答え：長くなります
今回：長くなります ○。

Ⅰ 2の1つ目 周期を正確に測る工夫（押す位置） 記述 10点

👀 まず見るところ

【条件文】部品は今の測り方の3語「しばらくして」「左端に到達したと同時に」「一往復して」に丸。すでにやっていることは工夫にならない。変えられるのは「一往復」と「左端」の2か所で、ここは左端を最下点に変える。

📚 前提知識

  • 振り子は端でいったん止まり、最下点でいちばん速い（1あで使った見方）。
  • 速く通りすぎる場所のほうが「今、通った」という瞬間がはっきりする。端は止まりかけの時間が長いので、押すタイミングがずれやすい。

✍️ 答案の組み立て

  1. 変える部品：「左端」→ 最下点。
  2. 書く形：「振り子が最下点にきたときにストップウォッチを押す。」
模範解答：振り子が最下点にきたときにストップウォッチを押す。
今回：「ふりこをはなして2回ほどふれてから時間をはかる。」×（答案の1行目）。部品を拾えなかった＝問題文の「動き始めてからしばらくして」と同じ内容で、すでにやっている。今の測り方の言葉に丸をつけ、まだ変えていない「左端」を変える。

Ⅰ 2の2つ目 周期を正確に測る工夫（往復の回数） 記述 10点

👀 まず見るところ

【条件文】部品は今の測り方の3語「しばらくして」「左端に到達したと同時に」「一往復して」に丸。すでにやっていることは工夫にならない。こちらは「一往復」を変える工夫。

📚 前提知識

  • ストップウォッチを押す手は、毎回少しずれる。1往復だけ測ると、そのずれがそのまま周期のずれになる。
  • 10往復をまとめて測って10で割れば、押すときのずれも10分の1にうすまる。

✍️ 答案の組み立て

  1. 変える部品：「一往復して」→ 10往復の時間を測る。
  2. 仕上げ：測った時間を10で割る（割るところまで書いて、周期の求め方になる）。
模範解答：10往復の時間を測って10で割る。
今回：「10回ふれた時の時間を10でわる。」○（10点。答案の2行目）。回数を増やすことと、10で割ることの両方が入っている。

Ⅰ 3 ブランコの立ちこぎ 選択 5点

👀 まず見るところ

【素材文】部品は図1・図2の「しゃがむ」「立ち上がる」。立つ＝重心が上がる＝振り子の長さが短くなる、と直して図の横に書く。短くなると速くなるので、動いている最下点で立つと決まる。

📚 前提知識

  • 振り子の長さは、支点からおもりの重心までの長さ。人が立てば短く、しゃがめば長くなる。
  • 短い振り子ほど周期が短い（表1でも10cmは0.61秒、90cmは1.89秒）。

🔍 こう読み解く

  1. 最下点で立ち上がる → 長さが短くなり、進む速さが速くなる → 振れ幅が大きくなる。
  2. 次のためにどこかでしゃがむ必要がある。最高点では振り子は止まっているので、しゃがんで長くしても速さは変わらない（遅くならない）。
  3. 「最高点でしゃがみ、最下点で立ち上がる」はア。
答え：ア
今回：ア ○。

Ⅰ 4 ブランコの座りこぎ 記述 10点

👀 まず見るところ

【条件文】部品は3と変わった言葉「立たずに座ったまま」に丸。立つ・しゃがむの代わりに重心を動かせるのは足。3の答えの「最高点」「最下点」はそのまま使い、動作だけ足に直して書く。

📚 前提知識

  • 足を上げる（前にのばす）と重心が上がり、足を下げる（曲げる）と重心が下がる。立つ・しゃがむと同じはたらきになる。

✍️ 答案の組み立て

  1. 3の答えを写す：最高点でしゃがみ、最下点で立ち上がる。
  2. 動作を足に直す：しゃがむ → 足を下げる／立ち上がる → 足を上げる。
  3. 書く形：「（最高点）で（足を下げ）、（最下点）で（足を上げる）。」いつ・どうする、を2組そろえる。
模範解答：最高点にきたときに足を下げ、最下点にきたときに足を上げる。
今回：「前に行く時に足も前にして後ろにいく時は足をまげる。」×。部品を拾えなかった＝足の動きは書けているが、いつ動かすかに3の選択肢の「最高点」「最下点」が入っていない。3で選んだアの文を土台にして、動作だけ足に書きかえる。

Ⅰ 5 スケートのスピン 記述 10点

👀 まず見るところ

【条件文】部品は「腕を」「回転を速く」に丸。3・4と同じ流れの問題で、速くするには中心までの長さを短くする。腕なら「縮める」と決まる。

📚 前提知識

  • ブランコは立って振り子を短くすると速くなった。回転も同じで、重さが回転の中心に近づくほど速く回る。

✍️ 答案の組み立て

  1. はじめ：腕を伸ばして回り始める（重さが中心から遠い）。
  2. 速くするとき：腕を縮める（重さが中心に近づく）。
  3. 書く形：「回転を始めるときは腕を伸ばしておき、回転するときに腕を縮める。」
模範解答：回転を始めるときは腕を伸ばしておき、回転するときに腕を縮める。
今回：「右うでを左かたに、左うでを右かたにつける。」○（10点）。腕を体に引きよせる＝縮める動きが具体的に書けている。「はじめは腕を伸ばしておく」まで書くと模範解答と同じ形になる。

Ⅰ 6① 距離40になるPの高さ 表の決まり・数値 5点

👀 まず見るところ

【まざり型→資料問題】表の正体は「Pの高さ・上った高さ・Q点の下からの距離（cm）」。(1)(2)(4)を縦に見ると、高さ2→8→32は4倍ずつ、距離5→10→20は2倍ずつ。表の横に「高さ×4→距離×2」と書く。

📚 前提知識（あれば答え合わせに使う）

  • 高いところから下りるほど速くなるが、高さを2倍にしても速さは2倍にならない。速さを2倍にするには高さが4倍いる。この問題は、知らなくても表から読み取れる。

🔍 こう読み解く

  1. (5)の距離は40。(4)の距離20の2倍である。
  2. 距離が2倍 → 高さは4倍。32×4＝128。
  3. ①は「上った高さ」のらんにもある。(1)〜(4)はAとB（同じ100g）で、上った高さがPの高さと同じ。(5)もAとBなので、どちらの①も128で合う。
答え：128
今回：128 ○。表の(2)〜(4)を線で結んで決まりをさがした跡があり、この読み方が6②・7・8の入口になる。

Ⅰ 7(4) 同じ重さの玉の衝突 表を読む・選択 5点

👀 まず見るところ

【まざり型→資料問題】(4)の行の正体は「A→B・同じ100g・Pの高さ32・上った高さ32」。当てられた玉が元と同じ高さまで上った＝エネルギーを全部受け取った。当てた玉には何も残らないので止まる。

📚 前提知識（あれば答え合わせに使う）

🔍 こう読み解く

  2. 当てた玉は止まり、当てられた玉だけが勢いよく上る → ウ「一方の玉は止まり、他方の玉は勢いよく上っていく」。
答え：ウ
今回：空らん ×。入口は(4)の行の「32と32」で、「高さが同じ＝全部わたした」と言葉にするところから始める。

Ⅰ 7(6) 軽い玉を重い玉に当てる 表を読む・選択 5点

👀 まず見るところ

【まざり型→資料問題】(6)の行の正体は「A(100g)→D(300g)・距離は当てた玉10、当てられた玉10」。2つの玉の距離が同じ＝衝突後の速さが同じ。「勢いよく」と「ゆっくり」に分かれるイは、ここで消える。

📚 前提知識

  • 軽い玉が重い玉に当たると、軽い玉ははね返る（解答・解説の説明）。壁にボールを当てるのに近い。
  • 同じ速さでQ点を出た玉は、重さがちがっても同じ高さまで上る。

🔍 こう読み解く

  1. Aははね返って左へ、Dは右へ動く。速さはどちらも距離10ぶん。
  2. 同じ速さなので、左右のレールを同じ高さ（8cm）まで上り、同じようにもどってくる。
  3. 左右に分かれて、またQ点付近で出会う → オ。
答え：オ
今回：空らん ×。入口は(6)の行の右はしに並ぶ「10と10」で、同じ数に丸をつけると「同じ速さで別れる」が見えてくる。

Ⅰ 8ウ ぶつかってきた玉はおそくなるか止まる 表で確かめる・正誤 5点

👀 まず見るところ

【まざり型→資料問題】文の「ぶつかってきた玉」に丸 → 当てた玉のこと。7で調べた(4)(6)(8)の当てた玉だけを縦に並べ、当たる前（距離20ぶん）より速くなった行が無いかを見る。

📚 前提知識（あれば答え合わせに使う）

  • 当てる玉は、止まっている玉を動かすためにエネルギーをわたす。わたした分だけ自分はおそくなる。

🔍 こう読み解く

  1. (4)同じ重さ：当てた玉は止まる。
  2. (6)軽い→重い：距離20ぶん → 10。おそくなる。
  3. (8)重い→軽い：距離20ぶん → 10。おそくなる。
  4. 3つの場合とも、おそくなるか止まるかのどちらか → 正しい。
答え：A
今回：空らん ×。入口は表の「当てた玉」の列で、7で出した3つの答え（止まる・はね返る・ゆっくり）を並べればそのまま判定できる。

Ⅰ 8エ 同じ速さなら軽い玉のほうが高く上るか 表で確かめる・正誤 5点

👀 まず見るところ

【まざり型→資料問題】文の「Q点での速さが同じ」に丸 → 距離が同じ行をさがす、に直す。距離が同じで重さがちがう2行を見つけ、上った高さを比べれば決まる。

📚 前提知識（あれば答え合わせに使う）

  • 玉が上る高さは、Q点での速さだけで決まり、重さには関係しない。振り子の周期が重さに関係しないのと同じ仲間の決まりである。

🔍 こう読み解く

  1. 距離10の行：(2)は当てられた玉がB（100g）で上った高さ8。(6)はD（300g）で上った高さ8。
  2. 距離20の行：(4)はB（100g）で32。(7)はD（300g）で32（6②の答え）。
  3. 速さが同じなら、軽くても重くても同じ高さ → 「軽い玉の方が高く上る」は間違い。
答え：B
今回：空らん ×。入口は(2)と(6)の2行で、距離10と上った高さ8がどちらにも並び、ちがうのは玉の重さだけである。

Ⅰ まとめ 次に同じ型が出たら

  • 工夫を答える記述は、今の方法の言葉に丸をつけてから書く。すでにやっていることは答えにならない。
  • 前の小問の続きの記述（3→4）は、前の答えの文を土台にして、変わった言葉（立つ→足）だけ書きかえる。
  • 表つきの実験は、同じ数が並ぶ行・倍になっている行に線を引いて決まりを先に書く。6①でできた読み方で、7・8まで進める。

JF-08 Ⅱ 浮力・板のつり合い／Ⅲ 中和と気体の発生計算・pH

Ⅱ 全体像 4問（各25点）

前半の1は水にうくおもり、後半の2は机からはみ出す板。別の話に見えるが、どちらも「重さを矢印1本にして図に置く」と式が決まる大問である。1は「うくものの重さ＝沈んだ部分がおしのけた水の重さ」、2は「机のはしを支点にした、てこのつり合い」を使う。

2の板は、次の3つを図に書いてから計算に入る。

Ⅱ 1問1 重ねたおもりの水面より上の割合 浮力・割合

👀 まず見るところ

【条件文】部品は求めるもの「水面より上にある」と「合わせた体積の何%」。「水面より上」に丸をつける。式で先に出るのは沈んだ側の体積なので、答えを書く直前に丸を見直して、上の側に直す。

📚 前提知識

  • ういて止まっているものは、全体の重さ＝沈んだ部分がおしのけた水の重さ。水は1cm³が1gなので、重さ（g）の数がそのまま沈んだ体積（cm³）になる。
  • 重さ＝体積×密度。立方体1個の体積は4×4×4＝64cm³。

🔍 こう読み解く

  1. 重さを出す。A＝64×0.65＝41.6g、B＝64×0.85＝54.4g。合わせて96g。
  2. 96gをささえるには水96cm³ぶんをおしのける → 沈んでいるのは96cm³。全体は64×2＝128cm³。
  3. 水面より上は128−96＝32cm³。32÷128×100＝25%。
  4. 別の見方（解答の式）：水面より上の割合は、Aだけなら1−0.65、Bだけなら1−0.85。同じ体積の2個なので平均して（0.35＋0.15）÷2×100＝25。
答え：25%
今回：75 ×。部品を拾えなかった＝「水面より上」に丸がなかった。式は「96/128→3/4」まで全部正しく、この3/4は沈んでいる側の割合なので、100−75＝25と1回引けば正解だった。

Ⅱ 2問3 2枚重ねの重石で板をはみ出させる てこのつり合い・逆比

👀 まず見るところ

【条件文】部品は「2枚の板を完全に重ねて」「重石」「できるだけ」。重石は400gの矢印1本にして、下の板の左はしの真上に置く（直して書く）。下の板の200gはまん中 → 2本の矢印の間は30cmと決まる。

📚 前提知識

  • 板がかたむくときは机のはしを中心に回る。だから机のはしが支点。支点の左右で「重さ×支点からのきょり」が等しいところが限界になる。
  • 重石は机の奥にあるほどよくきく。ただし重石の重さのまん中が下の板の外に出ると、板をおさえられない。だから限界は「重石のまん中＝下の板の左はしの真上」（解説の図）。

🔍 こう読み解く

  1. 下の板に矢印を2本かく。左はしに重石の400g、まん中（左はしから60÷2＝30cm）に板の200g。
  2. 重さの比は400：200＝2：1。支点からのきょりは逆比の1：2。分けるのは矢印と矢印の間の30cm → 重石側10cm、板のまん中側20cm。
  3. 板のまん中は机のはしから20cm外。そこから右はしまで30cm。20＋30＝50cm。
  4. 検算：400×10＝4000、200×20＝4000。つり合っている。
答え：50cm
今回：40 ×。部品の形を直さなかった＝2本の矢印の間の長さ（30cm）を図に書かず、式は「60×2/3＝40」で、2/3をかけた相手が60だった。図3の②・①・③の書きこみで重さ2：1と逆比までは使えているので、分ける相手を30cmに変えれば合う。
コツ：逆比を使う前に、2本の矢印の間に「何cm」と書く。この数が書けないときは、矢印の場所がまだ決まっていない。

Ⅱ 2問4 3枚を少しずつずらして積む てこのつり合い・上から1段ずつ

Ⅲ 1問1 A液120cm³とB液50cm³を混ぜて蒸発 中和・残るものをすべて
