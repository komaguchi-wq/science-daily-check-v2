X復習 全体像 SS-04 Xの復習・10問（各10点）

SS-04 の X1〜X10 から、北の空の星（図1）・夏の大三角（図2）・星座早見（3）・棒のかげと経度（4）〜(6) を1問ずつ取り直した大問である。全部に共通する道具は1つ、図に東西南北を先に置くこと。北の空なら北極星が中心、頭の真上のスケッチなら「左が北」、星座早見なら「窓のまん中が天頂」、棒のかげなら「かげは太陽の反対側」。

問題材先に置くもの
(1)北の空・北斗七星と北極星北極星を中心に「1か月30度・反時計回り」。3か月前なら逆向きに90度
(2)夏の大三角のスケッチベガ上・デネブ左下・アルタイル右下 → 左が北
(3)星座早見の持ち方窓のまん中＝天頂。その真下の窓のふちが見ている方角
(4)〜(6)長野の棒のかげ・南中時刻・秋分の光線かげは太陽の反対側／4分で1度／秋分の光線は地軸と垂直

今回は10問中6問、60点。落とした4問のうち (2)②・(3)・(4) は図の向きを置く前に答えを書いた形で、知識が足りなくて止まった問題ではない。(1)② は位置の考え方は合っていたが、答えの「×」の印をかかずに星座の形をかいていた。

X復習 (1)① 星Aをふくむ星座 資料問題・星座名

👀 まず見るところ

【資料問題】部品は図1の正体「北の空・北極星が右下」と、Aをふくむ7つの星の形「ひしゃく」。北極星の近くの大きなひしゃく、と1行書けば北斗七星＝おおぐま座と決まる。答えるのは星座の名前。

📚 前提知識

  • 北斗七星は7つの星がつくる大きなひしゃくで、おおぐま座の一部（しっぽと腰）。「北斗七星」は星座の名前ではない。
  • ひしゃくの口の2つの星（Aはその1つ）を結んでのばすと北極星。小さなひしゃく（こぐま座）の柄の先が北極星。

🔍 こう読み解く

  1. 図1でAは、7つの星のひしゃくの口のはし。北極星との間に線が引いてあるのは、口の星を北極星へのばす「北極星のさがし方」そのもの。
  2. 解答らんに「座」が印刷されているので、北斗七星ではなくおおぐまと書く。
答え：おおぐま（座）
今回：おおぐま ○。解答らんの「座」を見て星座の名前で書けている。

X復習 (1)② 3か月前の午後8時の星A 条件文・作図

👀 まず見るところ

【条件文】部品は「3か月前」「午後8時」（同じ時刻）と「×でかき表す」「線は消さない」。3か月前は「30度×3＝90度、過去だから時計回り」に直して書く → 北極星を中心に、Aを時計回りに90度回した点に×。

📚 前提知識

  • 北の空の星は北極星を中心に反時計回りに回る。同じ時刻で見ると、1か月に約30度ずつ反時計回りに進む（地球の公転）。
  • 「前」は逆向き。3か月前の同じ時刻なら、時計回りに90度もどした位置にある。北極星からの距離は変わらない。

🔍 こう読み解く

  1. Aと北極星を線で結ぶ。図1ではAは北極星の左（西側）、ほぼ同じ高さにある。
  2. 北極星のところで時計回りに90度曲げる。左にある点を時計回りに90度回すと、北極星の真上に来る。
  3. 北極星から、A〜北極星と同じ長さだけ真上に進んだ所に×。直角の印と2本の線は残す。
答え：図に記入（北極星の真上、A〜北極星と同じ距離の所に×。Aと北極星を結ぶ線と、北極星から真上へのびる線を直角に残す）
今回：図1に記入 ×。答案は北極星から真上に線を引き、A〜北極星と同じ長さ（⑤のメモ）の所に星をかいているので、位置は正解の印と同じ所にある。ただし答えとして求められた「×」の印がなく、そこから北斗七星の形と番号をかき足しているため、採点は不正解（記録も不正解）。次は答えの点に×だけをはっきりかき、Aと北極星を結ぶ線と北極星からの線は残して、星座の形はかき足さない。

X復習 (1)③ 札幌で見た北極星の高さ 条件文・高度

👀 まず見るところ

【条件文】部品は横浜と変わった所「北緯43度」（横浜は北緯36度）。緯度は「北極星の高度」に直して書く → 36度から43度へ、7度高くなる。東経141度（経度）は高さに関係しない。

📚 前提知識

  • 北極星の高度は、その土地の緯度に等しい。北へ行くほど北極星は高く見え、北極では頭の真上（90度）になる。
  • 経度がちがうと変わるのは時刻（星が同じ位置に来る時刻）で、北極星の高さは変わらない。

🔍 こう読み解く

  1. 横浜：北極星の高度36度。札幌：43度。
  2. 43＞36 なので、札幌のほうが北極星は高い。選択肢の中では「少し高い位置」のウ。
答え：ウ
今回：ウ ○。緯度を北極星の高度に直せている。

X復習 (2)② 北極星のある方を示す矢印 資料問題・方角

👀 まず見るところ

【資料問題】部品は図2の形「ベガ上・デネブ左下・アルタイル右下」＝南を向いて見上げた形（デネブ左上・ベガ右上・アルタイル下）を左に90度回した形なので、左が北と置く → 北極星は北の空にあるから、左向きの矢印（オ・カ）までしぼれる。

📚 前提知識

  • 頭の真上あたりのスケッチは、南を向いて見上げたときの形と比べて回す。南向きの形で「右＝西」だった向きが、図2では上になる → 上＝西、下＝東、左＝北、右＝南。
  • 夏の大三角の中で、北極星にいちばん近いのがデネブ、次がベガ。アルタイルは3つの中でずっと南寄り。だから北極星は、アルタイルから見てベガとデネブの間を通りこした先、つまりベガとデネブを結ぶ辺の外側にある。

🔍 こう読み解く

  1. 左が北なので、右向き（イ・ウ）と上下（ア・エ）は消える。残りはオとカ。
  2. オはAからBへ向かう向きで、デネブそのものの方向。北極星はデネブより先、A〜Bの辺の外側にある。アルタイル（C）からA・Bの間を通ってのばした先＝左上。
  3. 左上の矢印はカ。
答え：カ
今回：ア ×。部品を拾えなかった＝図2の「上」を北と置いた形。図2は上が西で、北は左。SS-04 X2 (4) で決めた「上＝西・左＝北」を、同じ図を見た時点で余白に書き直しておく。

X復習 (2)③ 天の川の向き 資料問題・正しい図

👀 まず見るところ

【資料問題】聞かれ方は「天の川の向きが正しいもの」。見る部品は「ベガが川の外にあるか」と「デネブが川の中にあるか」の2つ。4つの図に○×をつけてから答える。

📚 前提知識

  • 天の川はベガとアルタイルの間を流れる。ベガは川の外、アルタイルは川のふち、デネブは川の中。織姫（ベガ）と彦星（アルタイル）が川をはさむ、という七夕の話そのもの。
  • はくちょう座は天の川の中を飛ぶ形。デネブ（B）は川の中にある。

🔍 こう読み解く

  1. イ・ウ・エは川がAの近くを通り、ベガが川の中に入る → ×。エはさらにデネブ（B）が川の外。
  2. アは川がB（デネブ）からC（アルタイル）へ流れ、ベガは川の外。デネブは川の中 → ○。
  3. (2)②の「左＝北、右＝南」とも合う。天の川は北東のはくちょう座から南のさそり座へ流れる川なので、左下から右へ流れる形になる。
答え：ア
今回：ア ○。ベガを川の外に置く見方ができている。

X復習 (3) 「東の空」を見ている星座早見 資料問題・持ち方

👀 まず見るところ

【資料問題】部品は図の正体「星座早見を手に持った図」と、聞かれ方「東の空」。見ている方角は、窓のまん中（天頂）からまっすぐ下におりた窓のふちの方角。だから「東の印が窓のいちばん下に来ている図」をさがす。

📚 前提知識

  • 星座早見は、見たい方角の文字を下にして頭の上にかざす。窓（だ円）のふちが地平線、窓のまん中が天頂、円盤の中心（点）が北極星。北極星は天頂ではなく、窓の北寄りにある。
  • 見上げて使うので東西は地図と逆。北を上にすると、東は左、西は右。図の点線は北と南を結ぶ線（北の文字がある方の線）と、東と西を結ぶ線（それと直角の線）。

🔍 こう読み解く

  1. ア：北が上で、窓のいちばん下は南の端 → 南の空。イ：北が右なので、下に来るのは西寄り → ×。ウ：北が右下で、東西の線の端（西）が窓のいちばん下 → 西の空。
  2. エ：北が真横（左）。東西の線はたてになり、下の端が東。ただし窓はそこからさらに右下（南側）へふくらんでいて、天頂の真下にある窓のふちは東より南にずれる → 東と南の間を見ている形で ×。北極星が天頂ではないので、「北を真横にすれば東が真下」にはならない。
  3. オ：北が左下。東西の線は左上から右下へ走り、北から反時計回りに90度の東の端が、窓のいちばん下にちょうど来ている → 東の空。
答え：オ
今回：エ ×。知識＝「北を真横にすれば東が真下」と考えた形で、答案のエにはたての線と窓の形が書きこまれている。星座早見の中心（北極星）は天頂ではないので、見ている方角は窓のまん中の真下で決める。東の印が窓のいちばん下にあるのはオ。

X復習 (4) 棒のかげの先を結んだ線 条件文・かげの動き

👀 まず見るところ

【条件文】部品は「8月20日」「長野県」「1時間ごとのかげの先」。8月20日は夏至と秋分の間なので、「日の出・日の入りは真東・真西より北寄り」に直して書く。かげは太陽の反対側だから、朝夕のかげは南寄りへのびる。

📚 前提知識

  • かげは太陽の反対側にできる。正午の太陽は南にあるので、正午のかげは北向きで、1日でいちばん短い。日本は北回帰線より北にあるので、正午の太陽が頭の真上に来ることはなく、かげの長さが0になる日はない。
  • 春分〜秋分（夏側）は日の出が北東寄り、日の入りが北西寄り。だから朝のかげは南西寄り、夕方は南東寄りにのび、かげの先の線は両はしが南へ下がる山形（北へふくらむ形）。秋分・春分は東西の直線、冬は両はしが北へ上がる谷形。

🔍 こう読み解く

  1. 正午のかげは北向きで短い → 線は棒の北側を通る。4本とも北側にあるので、ここでは決まらない。
  2. 8月20日は夏側 → 両はしが南へ下がる山形 → ウかエ。イ（直線）は春分・秋分、ア（谷形で棒から遠い）は冬。
  3. エは線が棒の根もとを通る＝正午のかげの長さが0。日本ではあり得ない。正午に北へ短いかげが残るウ。
答え：ウ
今回：エ ×。部品の形を直さなかった＝「8月20日」を「日の出は北寄り → 朝夕のかげは南寄り」に直す前に、棒に近い（かげが短い）線を選んだ形。エは正午にかげが消える線で、日本の正午の太陽は必ず南にあるので消えない。次は図5の横に「夏＝山形・両はし南」と書いてから選ぶ。

X復習 (5) 南中時刻のちがいから経度を求める 条件文・計算

👀 まず見るところ

【条件文】部品は「地点P 午前11時52分」「銚子 午前11時40分」と図3の「銚子＝東経141度」。時刻の差12分を「4分で1度」で経度に直して書く → 3度。Pのほうが遅いので、Pは銚子より西。

📚 前提知識

  • 太陽は地球の自転で1時間に15度、つまり4分で1度、東から西へ動いて見える。東の地点ほど南中が早い。
  • 東経は東へ行くほど数字が大きい。南中が遅い＝西にある＝東経の数字が小さい。

🔍 こう読み解く

  1. 11時52分−11時40分＝12分。12÷4＝3度。
  2. Pは銚子より12分遅い → 西に3度。141−3＝138度。
  3. 確かめ：図3で地点Pは銚子（東経141度の線の上）より左（西）にある。数字が小さくなる向きで合う。
答え：ウ（東経138度）
今回：ウ ○。「4分で1度」と「遅い＝西」の両方を正しく使えている。

X復習 (6) 秋分の南中時、太陽光線と垂直な直線OQ 条件文・地軸との関係

👀 まず見るところ

【条件文】部品は「秋分の日」「南中したとき」「OQは太陽光線と垂直」。秋分の太陽光線は「地球の赤道の面に平行＝地軸と垂直」に直して書く。地軸と垂直な光線に、さらに垂直な線OQは、地軸と平行になる。

📚 前提知識

  • 春分・秋分の日は、太陽が赤道の真上にある。だから太陽光線は赤道の面に平行で、地軸とは垂直に交わる。
  • 地軸をのばした先が北極星。地軸と平行な線は北極星の方を向き、地面との角度はその土地の緯度（＝北極星の高度）になる。秋分の南中高度は 90−緯度 なので、たとえば北緯36度の地点では光線は地面と54度、それと垂直なOQは地面と36度で、ちょうど緯度と同じになる。

🔍 こう読み解く

  1. 秋分 → 光線は地軸と垂直。OQも光線と垂直。南北を通る同じ面の中で、同じ線に垂直な2本は平行 → OQは地軸と平行。
  2. ウ「北極と南極を結んだ線（＝地軸）に平行」→ ○。
  3. ア：Qの先にあるのは北極星（地軸の延長の向き）で、地球の北極そのものは通らない → ×。イ：Oの先に地球の中心があるのは地面に垂直な棒のほう → ×。
答え：ウ
今回：ウ ○。「秋分の光線は地軸と垂直」から平行まで進めている。

ABC復習 (1) 最も昼が長い地点 資料問題・地球のかたむき

👀 まず見るところ
