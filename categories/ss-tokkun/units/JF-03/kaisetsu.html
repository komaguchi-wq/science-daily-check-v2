Ⅰ 1図1 てこで10kgを5cm持ち上げる 条件文・力と距離

👀 まず見るところ

【条件文】部品は「10kgのおもりを5cm」と、図1の支点の両側「20cm・80cm」。求めるのは力と距離の2つなので、答えらんの「力」「距離」に丸。80÷20＝4倍 を図の支点の横に書く → 力は1/4、距離は4倍と決まる。

📚 前提知識

  • てこのつり合いは重さ×支点からの距離が左右で等しい。うでが4倍長ければ力は1/4でよい。
  • そのかわり動かす距離は4倍になる。支点を中心に棒が回るので、支点から遠い点ほど大きく動く（解答冊子の図では、OAA′とOBB′の扇形が相似）。

🔍 こう読み解く

  1. 使う式：10×20＝力×80。
  2. 力＝200÷80＝2.5kg。
  3. 距離：おもり側1に対して力点側は4。5cm×4＝20cm。
答え：力 2.5kg　距離 20cm
今回：2.5kg・20cm ○。

Ⅰ 1図2 輪軸で10kgを5cm持ち上げる 条件文・力と距離

👀 まず見るところ

【条件文】部品は図2の2つの半径「4cm」（おもりの糸）と「20cm」（力点の糸）。どちらの糸がどちらの輪に巻いてあるかを図に○で置く → 力は 4：20＝1/5、動く距離は5倍、と決まる。

📚 前提知識

  • 輪軸は、中心が支点のてこ。重さ×半径が内と外で等しい。
  • 糸の動く距離は輪の大きさに比例する。輪が1回転すると、小さい輪の糸は4cm×2×3.14、大きい輪の糸は20cm×2×3.14 だけ動く。

🔍 こう読み解く

  1. 使う式：10×4＝力×20。
  2. 力＝40÷20＝2kg。
  3. 距離：おもり側4に対して力点側は20＝5倍。5cm×5＝25cm。
答え：力 2kg　距離 25cm
今回：2kg・25cm ○。

Ⅰ 1図3 動滑車で10kgを5cm持ち上げる 条件文・力と距離

👀 まず見るところ

【条件文】部品は図3の滑車がおもりといっしょに上がること（動滑車）と、「滑車の重さはない」。滑車の両側の糸に同じ力の矢印を2本置く → 力は1/2、動く距離は2倍と決まる。

📚 前提知識

  • 動滑車は、おもりを2本の糸で分けて支える。1本あたりの力は半分。
  • おもりを5cm上げるには、左右の糸が5cmずつ短くなる必要があるので、引く糸は2倍の10cm動く。

🔍 こう読み解く

  1. 使う式：力×2＝10。力＝5kg。
  2. 距離＝5cm×2＝10cm。
答え：力 5kg　距離 10cm
今回：5kg・10cm ○。

Ⅰ 2 A×□＝□×□ の関係 素材文・仕事の原理

👀 まず見るところ

【素材文】設問は「A〜Dの間に成り立つ式」。部品は定義「A…おもりの重さ B…力点に加える力 C…おもりの動いた距離 D…力点の動く距離」を 図1の数で「A=10 B=2.5 C=5 D=20」と3語で書く → 積が同じになる組み合わせ（10×5＝2.5×20）がそのまま答えになる。

📚 前提知識

  • てこ・滑車・輪軸で力を小さくしても、力×動かす距離は変わらない。これを仕事の原理という（解答冊子3の説明）。楽をした分だけ長く動かす。

🔍 こう読み解く

  1. 図1：おもり側 10×5＝50、力点側 2.5×20＝50。
  2. 図2：2×25＝50、図3：5×10＝50。3つとも同じなので、おもり側の積＝力点側の積。
  3. A（おもりの重さ）×C（おもりの動いた距離）＝B（力）×D（力点の動く距離）。空らんの順に C・B・D。
答え：A × C ＝ B × D
今回：C・B・D ○。

Ⅰ 3 板の長さと押し上げる力 条件文・斜面

👀 まず見るところ

【条件文】部品は「その3倍長いB」と聞き方「どちらが何倍大きい」に丸。荷台の高さは同じなので、動かす距離が3倍 → 2の式から、力は1/3。「AがBの何倍」の向きに直してから書く。

📚 前提知識

  • 斜面も道具の1つ。持ち上げる高さが同じなら、板が長いほど力は小さくてすむ（力×距離は同じ）。

🔍 こう読み解く

  1. 持ち上げる高さは同じなので、力×板の長さ はAとBで等しい。Aの力を□とすると、□×1＝Bの力×3。
  2. Bの力は□÷3。つまりAの力はBの3倍。
  3. 答えらんは「（A）が（B）の（3）倍になる」の形。短い板のほうが力が大きい、と向きを確かめてから書く。
答え：AがBの3倍になる。
今回：A・B・3 ○。

Ⅰ 4(1) つめきりのP・Q・Rにかかる力の順 条件文・てこ2本

👀 まず見るところ

【条件文】部品は「2つのてこでできています」と「かかる力が大きい順」。図5に支点の●を2つ打つ（直して書く）：てこAの支点＝上のピン、てこBの支点＝右はしのつなぎ目。Qはどちらのてこでも支点にいちばん近い → Qが最大と決まる。

📚 前提知識

  • 1本のてこの中では、支点に近い点ほど大きな力がかかる（重さ×距離が同じだから）。
  • つめきりは、上のレバー（A）がQを押し、その力で下の刃（B）のRが閉じる。Qは「Aの作用点」であり「Bの力点」でもある。

🔍 こう読み解く

  1. てこA：支点ピンからQまで5mm、Pまで5＋50＝55mm。Q＞P（Qは Pの11倍）。
  2. てこB：支点（右はし）からQまで40mm、Rまで40＋5＋10＝55mm。Q＞R。
  3. RとP：R＝Q×40/55、P＝Q×5/55 なので R＞P。合わせて Q・R・P。
答え：Q・R・P
今回：P・R・Q ×。部品を拾えなかった＝「大きい順」に丸をつけずに、小さい順で書いた（並び自体は逆に読めば合っている）。答えを書く直前に、聞かれ方の丸をもう一度見る。

Ⅰ 4(2) Rに12kgかけるためのPの力 条件文・てこ2本の計算

👀 まず見るところ

【条件文】部品は「Rに12kg」「Pに何kg」。図の 5・50・10・5・40mm は「支点からの距離」に直して書く：てこBは 右はしから Q 40・R 55、てこAは ピンから Q 5・P 55。R→Q→P の順に、てこ1本ずつ通せば決まる。

📚 前提知識

  • てこが2本つながった道具は、つなぎ目の点（Q）の力を仲立ちにして、1本ずつ順にてこの式を使う。

🔍 こう読み解く

  1. 使う式：重さ×支点からの距離＝重さ×支点からの距離（てこごとに1本）。
  2. てこB（支点は右はし）：12×55＝Q×40 → Q＝660÷40＝16.5kg。
  3. てこA（支点はピン）：16.5×5＝P×55 → P＝82.5÷55＝1.5kg。
  4. 検算：Aで11倍、Bで40/55倍。合わせて8倍なので 12÷8＝1.5。
答え：1.5kg
今回：24 ×。部品の形を直さなかった＝図5の長さ（5・50・10・5・40）を「支点からの距離（5・55・40・55）」に直さずに計算したと見られる（答えらんに式は無い）。次は支点の●2つと4つの距離を図に書いてから、B→Aの順に式を1本ずつ書く。
コツ：つめきり・ペンチのような2段の道具は、「今どちらのてこの話か」を式のとなりに書く。1本目の答えが2本目の材料になる。

Ⅰ 5 3本の棒がつり合う位置 X・Y 条件文・つり合いの計算

👀 まず見るところ

【条件文】部品は「重さ10gのおもり10個」「外側の端がそろう」「棒の重さは考えない」。図6のおもりの数を各点に 1・4・3・2 と数字で書く（図に置く）→ 下の棒2本を先に、それぞれの糸にかかる重さを出してから上の棒、の順に決まる。

📚 前提知識

  • 棒がつり合う糸の位置は、両はしの重さの逆比に内分した点。1個と4個なら 4：1 の位置。
  • 下の棒をつるす糸には、その棒にのっている重さ全部がかかる。

🔍 こう読み解く

  1. 左の10cm棒：1個と4個 → 左はしから 4：1 → X＝10×4/5＝8cm。糸にかかる重さは50g。
  2. 右の10cm棒：3個と2個 → 左はしから 2：3 → 4cm（右はしから6cm）。糸にかかる重さも50g。
  3. 30cm棒：左の糸は左はしから8cm、右の糸は 30−6＝24cm。どちらも50gなので、Yはそのまん中 （8＋24）÷2＝16cm。
答え：X 8　Y 16
今回：8・16 ○。

Ⅰ 6 図7のZと図6のYの関係 条件文・重心の位置

👀 まず見るところ

【条件文】部品は 前の問と変わった所「図7」＝図6から下の棒2本を外し、同じおもりを直接つるした形。図7の各点に 1・4・3・2 個と書く（図に置く）→ おもりの横の位置が図6と同じなら、重心も同じと決まる。

📚 前提知識

  • つり合いは重さ×支点からの距離の合計で決まる。おもりが下の棒を通ってぶら下がっていても、直接ぶら下がっていても、横の位置が同じなら合計は同じ。

🔍 こう読み解く

  1. 図7の左はしを0cmとして、10g×1個＝0cm、4個＝10cm、3個＝20cm、2個＝30cm。
  2. Z＝（0×1＋10×4＋20×3＋30×2）÷10＝160÷10＝16cm。
  3. 5で出したYも16cm。同じ値なのでウ。計算しなくても「おもりの横位置が同じ＝重心が同じ」で決められる。
答え：ウ
今回：ウ ○。

Ⅰ 7 積み木と板の重ね方 条件文・重心が支えの上にあるか・完答

👀 まず見るところ

【条件文】部品は「板は重さを考えなくてよい」「一辺が10cm」。各段の頂点の位置を、いちばん左の頂点を0cmとして 0・10・20… と図に書く（図に置く）→ 板ごとに「上にのっている積み木ぜんぶの重心」が「下の頂点と頂点の間」にあるかを、上の板から順に確かめる。

📚 前提知識

  • 板は下の積み木の頂点で支えられている。上にのるもの全部の重心が、いちばん左の頂点といちばん右の頂点の間（はしの真上まで）にあれば倒れない。
  • 積み木の重さは全部同じなので、重心の位置は頂点の位置の平均で出せる。

🔍 こう読み解く

  1. ア：1段目 0・10・20、2段目 10・20・30・40、3段目 20・30。2枚目の板の上は7個で、重心＝（30＋100）÷7＝18.6cm。支える3段目の頂点は20〜30cm → 左にはみ出す → ×。
  2. イ：段ごとに5cmずつ左へずれる。1段目 15・25・35、2段目 10・20・30、3段目 5・15・25、4段目 0・10・20。3枚目の板の上は9個で、重心＝（75＋60＋45）÷9＝20cm。支える4段目の頂点は0〜20cm → 右はしの真上でぎりぎり → ○（点線がその位置）。上の2枚も間に入る。
  3. ウ：1段目 5・15・25、2段目 0・20、3段目 15・30。2枚目の板の上は5個で、重心＝（45＋20）÷5＝13cm。支える3段目の頂点は15〜30cm → 左にはみ出す → ×。
答え：ア ×　イ ○　ウ ×
今回：ア×・イ○・ウ○ ×（完答問題。ウだけ逆）。部品の形を直さなかった＝ウの頂点の位置を数字にせず、見た目で判断した。ウは2枚目の板の上の5個の重心が、3段目の左の頂点より2cm左に出る。次は「板ごとに、上の全部の重心 と 下の頂点の間」を数字で確かめる。
コツ：1枚の板だけ見て安心しない。上の板がつり合っていても、その下の板では「上の全部」を合わせた重心で判定する。

Ⅰ まとめ 7／10問・70点

  • 取れた7問で、てこ・輪軸・動滑車の力と距離、仕事の原理、逆比でのつり合い、重心が同じという見方まで通っている。考え方の穴はない。
  • 落とした3問は同じ型。4(1)は聞き方「大きい順」の丸、4(2)は支点2つと距離を図に直す一手、7は頂点の位置を数字にする一手。どれも計算の前に紙に置くものが抜けた。

Ⅱ 1問1 金属球Mの重さ 条件文・増えた分のつり合い

👀 まず見るところ

【条件文】部品は「コップに何も入れないで…棒はつり合いました」→ 棒の重さがコップ20gと打ち消し合っている、と直して書く。だから考えるのは「30gのおもりを入れ」て増えた分と、Mで増えた分だけ。

📚 前提知識

  • 棒に重さがあるとき、その重さは重心に矢印1本で置ける。ここでは値を出さなくてよい。つり合っていた所からの増えた分どうしが等しい、で式が立つ。

🔍 こう読み解く

  1. 使う式：左回りに増えた分＝右回りに増えた分。
  2. 左：30g×8.0cm＝240。右：M×6.0cm。
  3. M＝240÷6.0＝40g。
答え：40g
今回：40 ○。答案は「400−160＝240、240÷6.0＝40」。コップ全部（50×8＝400）から、棒の重さとつり合っていたコップ20gの分（20×8＝160）を引く形で、棒の重さをきちんと数に入れている。

Ⅱ 1問2 ひもをDに移したときのDE 条件文・前と変わった条件

👀 まず見るところ

【条件文】部品は問1と変わった「A点から6.4cmのD点」と「10gのコインを入れてつり合わせました」。この一文で、ひもを移したあとの棒とコップは打ち消し合っている、と直して書く → 式に入るのは、そのあと増えた30gとMだけ。

📚 前提知識

  • 支点を動かすと棒の重さのはたらき方は変わるが、「コインでつり合わせた」時点でそれは全部ふくまれている。だから問1と同じ「増えた分どうし」で解ける。

🔍 こう読み解く

  1. 使う式：増えた左回り＝増えた右回り。
  2. 左：30×6.4＝192。右：40×DE。
  3. DE＝192÷40＝4.8cm。
答え：4.8cm
今回：9.6 ×。部品の形を直さなかった＝「コインを入れてつり合わせた」を「ここまでは打ち消し合っている」に直さず、答案は (10＋30＋20)×6.4 とコップの中身全部を入れて、棒の重さを抜いた。次は「つり合いました」の文に線を引き、その後に足したものだけを式に入れる。

Ⅱ 2問3 バットを水平にするおもり 条件文・重心を先に出す

👀 まず見るところ

【条件文】部品は「重さ720g」と「目もりは288g」。720gの矢印はバットのまん中ではなく重心に置くので、先に 288×90＝720×□ で重心はAから36cmと直して書く → 問3も問4もこの矢印1本から始まる。

📚 前提知識

  • 太さがちがう棒の重心はまん中にない。片はしを床につけて反対側をばねばかりで持ち上げると、床の点を支点にしたてこになり、目もりから重心の位置が出せる。

🔍 こう読み解く

  1. 使う式：Aのまわりで 720×（重心までの距離）＝288×90。重心＝25920÷720＝36cm（Aから）。
  2. ひもは中央＝Aから45cm。重心はひもから 45−36＝9cm 左。おもりはひもから20cm右。
  3. 720×9＝x×20 → x＝6480÷20＝324g。
答え：324g
今回：324 ○。答案は「6480×1/20＝324」。重心36cmを出して、ひもからの距離9cmと20cmで式を立てている。

Ⅱ 2問4 両端に140gをつけたときのひもの位置 条件文・全体の重心

👀 まず見るところ

【条件文】部品は「両端に140gのおもりをそれぞれ」と「Aから何cm」。図に矢印を3本置く：A（0cm）に140、36cmに720、B（90cm）に140。ひもの位置を□とせず、Aを回転の中心にして「全体の重心」を出す形に直すと、式が1本で決まる。

📚 前提知識

  • いくつかの重さをまとめて支える点＝全体の重心は、（重さ×Aからの距離）の合計 ÷ 重さの合計で出せる。

🔍 こう読み解く

  1. 使う式：ひもの位置＝（720×36＋140×0＋140×90）÷（720＋140＋140）。
  2. 分子：25920＋12600＝38520。分母：1000。
  3. 38520÷1000＝38.52cm。重心36cmより少し右に寄るのは、両はしの140gがまん中（45cm）へ引き寄せるから。
答え：38.52cm
今回：答えらんは空らん（式の途中で止まった・赤の×あり） ×。部品の形を直さなかった＝問3で出た「重心はAから36cm」を図に置かずに □×140＝140×(90−□)＋720×… と式を書き始め、720の項が決まらずに止まった。次は3本の矢印を先に描き、Aのまわりの合計÷1000 で1本の式にする。
コツ：ひもの位置を求める問題は、ひもを□にするより「Aのまわりの合計÷全体の重さ」のほうが短い。□が式の両側に出てこない。

JF-03 Ⅲ（蒸散の引き算と、光の強さ・二酸化炭素の吸収量の表）

Ⅲ 全体像 植物のはたらき 4問

前半はホウセンカの蒸散、後半は光の強さと二酸化炭素の吸収量の表。どちらも表を1つ作れば、あとは引き算と割り算で決まる。

今回は4問中3問、75点。落とした問3は、表の数を線に直さずに「＋になった最初の列」を下限にした失点で、計算の3問は通っている。

小問型紙に置く部品
1 問1・問2まざり型→条件文「ワセリン」をぬった所＝蒸散しない、を表に直す
2 問3資料問題吸収量が＋なら育つ、−なら枯れる

Ⅲ 1問1 葉の裏と表の蒸散量 条件文・計算

👀 まず見るところ

【まざり型→条件文】部品は「裏側にワセリン」「表側にワセリン」と82g・91g・86g。ぬった所は蒸散しないので、A〜Cを表・裏・茎の表に直して書く → 引き算で表と裏が別々に出る。

📚 前提知識

  • ワセリンは気こうをふさぐ。ぬった面からは水が出ていかない。
  • ホウセンカは葉の裏側に気こうが多い。だから裏からの蒸散量のほうが大きくなる。

🔍 こう読み解く

  1. 使う式：減った水の量＝100g−2時間後の水の量。A＝100−82＝18g、B＝100−91＝9g、C＝100−86＝14g。
  2. Aは表＋裏＋茎（と水面）、Bは表＋茎、Cは裏＋茎。表にするとちがいが1か所ずつになる。
  3. 裏＝A−B＝18−9＝9g。表＝A−C＝18−14＝4g。
  4. 9÷4＝2.25（倍）。
答え：2.25倍
今回：9/4 ○（別紙は2.25。分数でも正解）。紙面に「18−9＝9」「18−14＝4」と減った量からの引き算が書けていた。

Ⅲ 1問2 葉からの蒸散量（1分あたり） 条件文・計算

👀 まず見るところ

【条件文】部品は求めるもの「葉からの」と「1分あたり」。葉＝表＋裏の13g、2時間は120分に直して書く → 13÷120。答え方の指示「小数第3位を四捨五入」にも丸。

📚 前提知識

  • Aの18gには茎（と水面）から出た5gもふくまれる。「葉からの」と聞かれたら、この5gは入れない。

🔍 こう読み解く

  1. 使う式：葉からの蒸散量＝表＋裏。問1の表から 4＋9＝13g（2時間ぶん）。
  2. 2時間＝120分。13÷120＝0.108…
  3. 小数第3位を四捨五入して 0.11（g/分）。
答え：0.11（g/分）
今回：0.11 ○。途中式の0.108…から小数第3位を四捨五入できている。

Ⅲ 2問3 Bは育つがAは枯れる光の強さ 資料問題・範囲

👀 まず見るところ

【資料問題】部品は表の正体「光の強さと1時間あたりの二酸化炭素の吸収量」。吸収量が＋なら育つ、−なら枯れると直して書き、A・Bそれぞれ0になる光の強さをさがす。

📚 前提知識

  • 表の吸収量は「光合成で取りこむ量−呼吸で出す量」。＋なら養分がたまって育ち、−なら養分が減っていく。
  • 光の強さを0から少しずつ強くすると、吸収量もなめらかに変わると考える。表の数と数の間は直線でつなぐ。

🔍 こう読み解く

  1. 植物Aは1000でちょうど0。1000より弱いと−なので枯れる。
  2. 植物Bは0で−4、500で＋4。−4から＋4へ直線で変わるので、0になるのはまん中の250。250より強いと育つ。
  3. 2つが重なるのは 250〜1000。
答え：250〜1000
今回：500〜1000 ×。上限の1000は合っている。部品の形を直さなかった＝表の数を線に直さず、Bが＋になった最初の列の500を下限にした。次は0と500の間を線でつなぎ、吸収量が0を横切る所から見る。

Ⅲ 2問4 植物Aが枯れない光の時間 条件文・計算

👀 まず見るところ

【まざり型→条件文】部品は「1日のうち」「光の強さを1500」「枯れないように」。1日＝24時間、枯れない＝1日の吸収の合計が0以上、と直して書く → 光の時間と暗い時間の式が立つ。

📚 前提知識

  • 光を当てない時間は光の強さ0と同じ。植物Aは表から1時間に−8、光の強さ1500では1時間に＋4。

🔍 こう読み解く

  1. 使う式：4×（光を当てた時間）−8×（暗い時間）≧0。
  2. 24時間ずっと暗いと、8×24＝192だけ二酸化炭素が出ていく。
  3. 暗い1時間を光の1時間に変えるごとに、−8が＋4になるので 8＋4＝12ずつ取りもどせる。
  4. 192÷12＝16（時間）。たしかめ：4×16＝64、8×8＝64 で合計0。
答え：16時間
今回：16 ○。全部暗い日の192を先に出し、「192÷12」で取りもどす形の式が書けていた。
