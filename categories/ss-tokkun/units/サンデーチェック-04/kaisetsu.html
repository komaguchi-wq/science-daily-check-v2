X復習 (1)① 重さのある動滑車を引く力 条件文・計算

👀 まず見るところ

【条件文】部品は「重さ50gの滑車」と「おもりの重さが100g」。50gは滑車のまん中に下向きの矢印で置く（直して書く）→ 動滑車を持ち上げている糸は2本なので、(100＋50)を2で割る形が決まる。

📚 前提知識

  • 動滑車は、左右2本の糸で持ち上げられている。1本の糸の中はどこも同じ力なので、2本で半分ずつ支える。
  • 滑車に重さがあるときは、おもりに滑車の重さを足してから割る。

🔍 こう読み解く

  1. 動滑車にぶら下がっている重さ＝おもり100g＋滑車50g＝150g。
  2. これを2本の糸で支えるので、1本は150÷2＝75g。糸の端を引く力も75g。
答え：75g
今回：75 ○。滑車の重さを足してから割る順番ができている。

X復習 (1)② 10cm引くとおもりは何cm上がるか 条件文・長さ

👀 まず見るところ

【条件文】①と変わった部品は「10cm上に引く」と答えの単位「cm」に丸。力の話から長さの話に変わった。動滑車は糸2本で支えているので、引いた長さの半分だけ上がる、と決まる。

📚 前提知識

🔍 こう読み解く

  1. 糸の端を10cm引く → 動滑車の左右の糸が5cmずつ短くなる。
  2. 動滑車ごとおもりが5cm上がる。
答え：5cm
今回：5 ○。

X復習 (1)③ 引く長さを2倍にすると 条件文・比例

👀 まず見るところ

【条件文】部品は「引く長さを2倍」と答え方の指示「整数か分数で」に丸。②で「引いた長さの半分だけ上がる」と決めたので、引く長さが2倍なら上がる長さも2倍、と比例で決まる。

📚 前提知識

  • 引く長さと上がる長さは、いつも「2：1」の関係。割合が変わらないので、片方を2倍にすればもう片方も2倍。

🔍 こう読み解く

  1. 10cm引けば5cm、20cm引けば10cm。
  2. 上がる距離は2倍。「半分になる」と答えないように、②の答えを使って具体的な数で確かめる。
答え：2倍
今回：2 ○。

X復習 (2)① 図2 定滑車と輪軸の荷物 条件文・糸をたどる

👀 まず見るところ

【条件文】部品は「A（重さ1200g）」と図の「3cm」「10cm」。Aの糸を指でたどって図に置く → 左の滑車は棒で天井についた定滑車、糸はそのまま輪軸の小さい輪（3cm）の上を通って荷物につながる。1本の糸なので、荷物の重さはAと同じと決まる。

📚 前提知識

  • 定滑車は糸の向きを変えるだけで、力の大きさは変えない。棒で天井についている滑車の重さ100gは、天井が支えていて式に入らない。
  • 輪軸は「力×半径」が左右で等しければつり合う。同じ輪にかかる2本の糸なら、半径が同じなので力も同じ。

🔍 こう読み解く

  1. Aの糸：A → 左の定滑車の上 → 横に進んで輪軸の小さい輪の上 → 荷物。途中に動滑車はない。
  2. 1本の糸の中はどこも1200g。小さい輪に、左から1200g・右から荷物がかかっている → 1200×3＝荷物×3 → 荷物＝1200g。
  3. 「10cm」の大きい輪には糸がかかっていないので、この問いでは使わない。
答え：1200g
今回：1200 ○。糸がどの輪にかかっているかを図で確かめられている。

X復習 (2)② 図3 糸3本でつった動滑車の荷物 条件文・糸の本数

👀 まず見るところ

【条件文】部品は「それぞれの重さが100g」とA 1200g。動滑車の重さ100gは動滑車の中心に下向き矢印で置く（直して書く）。次に動滑車を上に引いている糸の本数を数える → 左・右・上の棒につながる糸で3本。

📚 前提知識

  • 糸は A → 左の定滑車 → 動滑車の下 → 右の定滑車 → 動滑車の棒、と1本でつながっている。1本の糸の中はどこも1200g。
  • 動滑車につながる糸が3本なら、上向きの力は1200×3。これが「荷物＋動滑車100g」とつり合う。定滑車2つの100gは天井が支えていて式に入らない。

🔍 こう読み解く

  1. 動滑車を上に引く力＝1200×3＝3600g。
  2. 下に引く重さ＝荷物＋100g。3600−100＝3500g。
答え：3500g
今回：3500 ○。3本と数えたうえで動滑車の100gを引けている。

X復習 (2)③ 荷物を30cm上げるにはAを何cm下げるか 条件文・長さ

👀 まず見るところ

X復習 (3)① 自分で自分を引き上げる力 条件文・糸の本数

👀 まず見るところ

【条件文】部品は「自分で引き、自分自身を」と「体重90kg」「重さを考えなくてもよい」。人・荷台・動滑車を1つのかたまりとして線で囲み、かたまりから上に出ている糸を数える（図に置く）→ 動滑車の2本＋手でにぎっている1本＝3本。90を3で割る形が決まる。

📚 前提知識

  • ロープは、天井の滑車の棒に固定 → 荷台の動滑車の下 → 天井の定滑車の上 → 人の手、と1本。1本の中はどこも同じ力。
  • 人がロープを下に引くと、ロープも同じ力で人を上に引き返す。だから手でにぎっている糸も自分を持ち上げる1本に数える。これが「自分で引く」型のちがいである。

🔍 こう読み解く

  1. かたまり（人＋荷台＋動滑車）の重さは90kg（荷台と滑車は考えなくてよい）。
  2. かたまりを上に引く糸は3本で、どれも同じ力F。F×3＝90 → F＝30kg。
  3. 検算：動滑車の2本で60kg、手の1本で30kg、合わせて90kg。
答え：30kg
今回：30 ×（答案45）。部品を拾えなかった＝「自分で引き」。動滑車の2本だけで90÷2としていて、手でにぎっている3本目が式に入っていない。次は人ごと線で囲んで、囲みから出ている糸を数える。

X復習 (3)② 自分を2m上げるにはロープを何m下げるか 条件文・長さ

👀 まず見るところ

【条件文】①と変わった部品は「自分自身を2m引き上げる」と単位「m」に丸。①で数えた糸3本をそのまま使う → 3本がそれぞれ2m短くなるので、手でたぐるロープは2×3と決まる。

📚 前提知識

  • 長さの倍率は、力を割った本数と同じ。(2)③の「30×3」と同じ形である。
  • 別の見方：動滑車の糸2本で4mのロープが手の側に来る。ただし自分も2m上がっているので、手は4＋2＝6mたぐることになる。どちらで考えても同じ6m。

🔍 こう読み解く

  1. かたまりが2m上がる → かたまりから出ている3本の糸がそれぞれ2m余る。
  2. 2×3＝6m。
答え：6m
今回：6 ×（答案4）。部品を拾えなかった＝「自分自身を」。動滑車の2本分（2mが2本で4m）までは合っていて、自分が上がる2mを足していない。①で3本と数え直せば、②も自動的に6mになる。
コツ：(3)の2問は1組。①で「糸は何本か」を決めれば、②は「その本数×上がる長さ」で終わる。①の数え方を直すと②も直る。

X復習 (4)① 太さのちがう棒の重心の位置 条件文・逆比

👀 まず見るところ

【条件文】部品は図6の「250gと150g」と「36cm」。図6の両端の力の合計250＋150＝400gは、図5の「400g」と同じ＝棒の重さ。棒の重さ400gを重心の位置に下向き矢印で置く（直して書く）→ 重心は両端の力の逆比で決まり、その位置が図5の糸の位置＝アである。

📚 前提知識

  • 棒の重さは、重心1点に全部かかっていると考える。両端で支えたとき、重心に近い側の力が大きい。
  • 両端の力が250：150＝5：3なら、重心は左端から3：5の位置（力の逆比）。

🔍 こう読み解く

  1. 250：150＝5：3 → 重心は左から 3／(5＋3)。
  2. 36×3÷8＝13.5cm。これが図5のア。
  3. 検算：右端まわりで 150×36＝400×13.5＝5400。合う。
答え：13.5
今回：13.5 ○。余白に「4.5」「22.5」とあり、36÷8＝4.5を1つ分として5つ分・3つ分に分けている。逆比の使い方が身についている。

X復習 (4)② 重心で切ったAとBの重さ 条件文・選択

👀 まず見るところ

【条件文】部品は「糸でつるした位置で棒を2つに切り」と、図5のAが短く太い・Bが長く細いこと。切った後のAとBを、それぞれの重さがまん中あたりに集まった2つのおもりと考えて図に置く → 糸からの距離は A が近く B が遠い。

📚 前提知識

  • 糸の位置でつり合っているので、糸を支点にして「Aの重さ×Aの重心までの距離＝Bの重さ×Bの重心までの距離」。
  • 距離が短い側ほど重い。重心で切っても重さは半分ずつにならない（半分ずつになるのは「真ん中で切る」とき）。

🔍 こう読み解く

  1. Aは13.5cmの中に重心があり、Bは22.5cmの中に重心がある。糸からの距離はA＜B。
  2. 積が等しくて距離が短いAのほうが重い → イ。
  3. 図でも、Aは太い側で短く、Bは細い側で長い。「重い側ほど支点に近い」と向きが合う。
答え：イ
今回：イ ○。「つり合っている＝同じ重さ」に引っぱられずに答えられている。

X復習 まとめ 8／10問・80点

  • 取れた8問は、動滑車2本・糸3本・輪軸・逆比と、この回の決まりを一通り使えている。糸の本数で割る、長さは本数倍の型は入っている。
  • 落とした(3)①②は同じ1つの原因。「自分で自分を引く」と、手でにぎった糸が自分を持ち上げる1本になり、本数が2本から3本にふえる。①で3本と数えれば、②の6mもついてくる。
  • 次に同じ形が出たら、人・荷台・滑車を線で囲み、囲みから上へ出ている糸を数えてから式を書く。

サンデーチェック-04 ABC復習（てこ・重心・滑車・輪軸の復習・10問）

ABC復習 全体像 SS-03 A・B・Cの復習 10問（各10点）

てこ3図、太さが一様でない棒、滑車3図、滑車の距離、輪軸と題材は5つに分かれるが、使う式は2本しかない。上向きの力の合計＝下向きの力の合計と、支点のまわりで左回り＝右回り。どの図でも、先に「分からない力がかかっている点」を支点に選ぶと、その力が式から消えて短くなる。

図支点にする点先に図に置く部品
図1・図3ばねばかりの点上向きのばねばかりは↑、おもりは↓
図2三角の支点右はしの100gは↑（③と反対回り）
図5・図6ばねばかりの点図4で分かった棒の重さ200gを重心に↓
図7〜図9滑車そのもの滑車の重さ20gを滑車の下に↓
図10輪軸の中心半径 45・30・15 をひもの根もとに

今回は10問中9問、90点。落とした1問は図2の③④で、式は合っていたのに 10000÷20 を 50 と書いた計算のずれ。考え方で落とした問題はない。

ABC復習 (1)①② ばねばかり1本で支えたてこ（図1） 条件文・計算

👀 まず見るところ

【条件文】部品は「おもり以外の重さは考えない」と「ばねばかり」の位置。棒の重さの矢印はいらない。ばねばかりの点を支点にして左右の長さを図に置く → ①は上下のつり合い、②は回転のつり合いで決まる。

📚 前提知識

  • つり合いの式は2本。上向きの合計＝下向きの合計／支点のまわりで 左回り＝右回り（重さ×支点からの距離）。
  • 支点は「分からない力がかかっている点」に置く。その力は距離0なので式から消える。

🔍 こう読み解く

  1. ①はばねばかりが全部を支えている → 30＋60＋270＝360g。
  2. ばねばかりの点を支点に。右回り＝270×10＝2700。左回り＝60×20＋30×（②＋20）。
  3. 2700−1200＝1500 → 30×（②＋20）＝1500 → ②＋20＝50 → ②＝30cm。
答え：① 360　② 30
今回：360・30 ○。余白に「2700」「1200」「1500」と書き、1500÷30＝50 から 20 をひく手順が通っている。

ABC復習 (1)③④ 支点の上のてこと上向きのばねばかり（図2） 条件文・計算

👀 まず見るところ

【条件文】部品は「④g」が支点にかかる力であることと、右はしの「100g」が上向きに引くばねばかりであること。上向きの力は図に↑で置く → 支点まわりの式で、100gは③と反対回り（左回り）に入る。

📚 前提知識

  • 上向きに引く力は、同じ側のおもりと逆向きに棒を回す。右はしで上に引くと、左のおもりと同じ左回りになる。
  • 支点が受ける力＝下向きの合計−上向きの合計。支点のまわりで式を立てれば消えるので、最後に足し引きで出す。

🔍 こう読み解く

  1. 支点のまわり。左回り＝200×10＋100×80＝2000＋8000＝10000。右回り＝③×20。
  2. ③＝10000÷20＝500g。大きさの見当: ③は10cmの200gを20cmで受けるだけでも100gいる。50はありえない。
  3. ④＝下向き（200＋500）−上向き100＝600g。
答え：③ 500　④ 600
今回：500・600 ×（答案 50・150）。計算＝余白の「2000」「8000」「10000」までは合っていて、10000÷20 を 50 と書いた桁の落ち。④は 200＋50−100＝150 と、その50を正しく使っている。割り算のあとに「③は100より大きいはず」と大きさの見当を一度つけると、ここで止まれる。

ABC復習 (1)⑤⑥ 両はしをばねばかりで支えたてこ（図3） 条件文・計算

👀 まず見るところ

【条件文】部品は左はしの「100g」のばねばかり（上向き）と、左から15cmの「100g」のおもり（下向き）。同じ100でも向きがちがうので図に↑↓で置く → 上下のつり合いから ⑤＝⑥ が先に決まる。

📚 前提知識

  • 分からない数が2つあるときは、上下のつり合いで2つの関係を出し、回転のつり合いで決める。
  • 支点は左はし（ばねばかり100gの点）に置くと、その力が消えて式が短い。

🔍 こう読み解く

  1. 上向き 100＋⑤ ＝ 下向き 100＋⑥ → ⑤＝⑥。
  2. 左はしを支点に。右回り＝100×15＋⑥×30、左回り＝⑤×50。
  3. ⑤＝⑥ なので 1500＋30×⑤＝50×⑤ → 20×⑤＝1500 → ⑤＝⑥＝75g。
答え：⑤ 75　⑥ 75
今回：75・75 ○。右はしを支点にしても同じ75になる。どちらの支点でも通る。

ABC復習 (2)③④ 重心の反対側におもりをつるす（図6） 条件文・計算

👀 まず見るところ

【条件文】部品は図4から持ってくる「200g」の重心の矢印と、図6の「④g」の位置（左から2つ目の印）。重心の矢印を図6にも書く（直して書く）→ 支点④のまわりで、左2目もりの③と右1目もりの200gがつり合う。

📚 前提知識

🔍 こう読み解く

  2. ③＝200÷2＝100g。

ABC復習 (5) 輪軸のつり合いと上がる距離（図10） 条件文・計算

👀 まず見るところ

【条件文】部品は「それぞれ15cm」と、3本のひもがどの輪にかかっているか。半径を外から 45・30・15 と書き、図のひもの根もとに 40gは外の輪・60gは内の輪・矢印はまん中の輪 と書く（図に置く）→ 中心を支点にした回転のつり合いの式になる。

📚 前提知識

  • ひもを引く長さと上がる長さは半径に比例する。半径の比がそのまま動く長さの比。

🔍 こう読み解く

  1. 半径: 外45・中30・内15。40gと60gは中心の左側で左回り、矢印は右側で右回り。
  2. 左回り＝40×45＋60×15＝1800＋900＝2700。右回り＝力×30 → 力＝90g。
  3. 距離: まん中の輪（30）を10cm引くと、内の輪（15）にかかる60gは半分の 5cm 上がる。
答え：力 90　距離 5
今回：90・5 ○。余白の「1800」は外の輪の40gのモーメント。そこから式を立てられている。
