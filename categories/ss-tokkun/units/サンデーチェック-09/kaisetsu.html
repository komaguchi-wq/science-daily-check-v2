X復習 (1)① Qを通るときの速さが最も速いふりこ 表の読み取り・記号

👀 まず見るところ

【資料問題】部品は聞かれ方「Qを通るときのおもりの速さ」。時間の話ではない。余白に「速さ＝はなす高さ」と直して書く → 表1で長さと角度がどちらも最大の列をさがす。

📚 前提知識

  • 最も低い位置での速さは、手をはなした位置の高さで決まる。高い所からはなすほど速い。おもりの重さは関係ない。
  • 同じ角度なら、ふりこが長いほどはなす位置は高い。同じ長さなら、角度が大きいほど高い。

🔍 こう読み解く

  1. 角度が大きいのは20°のC・E・F・G。
  2. その中で長さを比べる。C 60cm、E 60cm、F 90cm、G 120cm。いちばん長いGが、いちばん高い位置からはなしている。
  3. 重さ（200g・400g・500g）は速さに関係しないので、比べなくてよい。
答え：G
今回：C,E ×。知識＝表の20°に丸をつける所までは合っていたが、そのあと長さが短い60cmのほうを選んでいる。短いふりこは「往復の時間が短い」だけなので、速さは「はなす高さ」と別の行に書き分ける。

ABC復習 (1) ふりこの長さと10往復の時間 表のきまり・計算

👀 まず見るところ

【資料問題】資料の正体を1行「ふりこの長さ(cm)と10往復の時間(秒)」。25→100で長さ4倍、時間は10→20で2倍。この「長さ4倍で時間2倍」を表の上に矢印で書けば、XもYも決まる。

📚 前提知識

  3. 確かめ：900cmは25cmの36倍（6×6）で、時間は10×6＝60秒。表の右はしと合う。

今回：225・40 ○。表の上に「×4」「×2」の矢印を書いてから求めている。この書きこみがあると、XとYで倍の向きを取りちがえない。

📚 前提知識

今回：ア ○。①の「速さは同じ」と②の「時間はちがう」を分けて答えられている。

ABC復習 (5)① 浮いているおもりにはたらく浮力 条件文・浮力

👀 まず見るところ

【条件文】部品は「浮きました」。浮いて止まっているなら、下向きの重さと上向きの浮力がつり合っている。図4に上下の矢印をかけば、浮力はおもりの重さと同じと決まる。96cm³や1.2g/cm³は①では使わない。

📚 前提知識

  • 浮いている物体では、浮力＝物体の重さ。液体の種類が変わっても、浮いているかぎりこれは変わらない。

🔍 こう読み解く

  1. おもりの重さは60g。
  2. 浮いて止まっている → 浮力も60g。
答え：60g
今回：60g ○。

ABC復習 (5)② 液面から上に出ている部分の体積 条件文・計算

👀 まず見るところ

【条件文】求めるものは「液面から上に出ている部分」。浮力の式で出るのは液面より下の体積なので、図4の下の部分に出した数字を書き、最後に96からひく。密度「1.2g/cm³」は ÷1.2 に直す。

📚 前提知識

  • 浮力＝液体の密度×液体にしずんでいる部分の体積。食塩水は1cm³が1.2gなので、しずんだ体積1cm³あたり1.2gの浮力になる。

🔍 こう読み解く

  1. ①より浮力は60g。しずんでいる体積＝60÷1.2＝50cm³。
  2. 全体は96cm³ → 上に出ている部分＝96−50＝46cm³。
答え：46cm³
今回：46cm³ ○。図4のしずんだ部分に「50」と書きこんでから、全体からひいている。50のまま答えにしなかったのは、図に置いたおかげ。

ABC復習 (6)① ばねA・Bをつないだときの長さ グラフ＋ばねの計算

👀 まず見るところ

【まざり型→条件文】図6の部品は「ばねBが2本ならんでいる」こと。90gを2本で分けるので、Bの横に「45g」と直して書く。Aは1本で全部ささえるので90gのまま。あとは図5から、もとの長さとのびを読む。

📚 前提知識

  • グラフの左はし（0g）の長さがもとの長さ。ばねののびは、おもりの重さに比例する。
  • ならべてつるした同じばねは、重さを等分してささえる。たてにつないだばねには、下のおもりの重さがそのままかかる。

🔍 こう読み解く

  1. 図5を読む。A：0gで18cm、60gで22cm → 60gで4cmのびる。B：0gで12cm、60gで22cm → 60gで10cmのびる。
  2. A：90gがかかる。のびは4×90÷60＝6cm → 18＋6＝24cm。
  3. B：1本に45gがかかる。のびは10×45÷60＝7.5cm → 12＋7.5＝19.5cm。
答え：A 24cm　B 19.5cm
今回：24cm・19.5cm ○。グラフのたて軸に「18」「12」「22」と読んだ値を書き、余白に「45gで7.5」と置いてから足している。

ABC復習 (6)② 半分に切ったばねCの長さ 条件文・ばねの計算

👀 まず見るところ

【条件文】部品は「ばねAを半分に切ったもの」。図7のCの横に「もとの長さ9cm・のびも半分」と直して書く。Aの数字（18cm、60gで4cm）をそのまま使うと合わない。

📚 前提知識

  • ばねを半分に切ると、もとの長さが半分になる。同じ重さをつるしたときののびも半分になる（のびる部分が半分しかないから）。

🔍 こう読み解く

  1. Cのもとの長さ：18÷2＝9cm。
  2. Aは60gで4cmのびるので、30gでは2cm。Cはその半分で1cmのびる。
  3. 9＋1＝10cm。
答え：10cm
今回：10cm ○。図7の「ばねAを半分に切ったもの」に線を引いてから計算している。
