H落下 (1)速さ パラシュートの有無と落下の速さ 表の読み取り・短い説明

👀 まず見るところ

【資料問題】部品は表1の正体「同じ高さから落としたときの着地までの時間・なし／あり」。どの高さでも「あり」の行の方が数字が大きい（4mで0.9秒と2.0秒）→ 時間が長い＝落ちる速さがおそい、で決まる。

📚 前提知識

  • 同じ距離を落ちるのに時間が長いほど、速さはおそい。パラシュートは空気の抵抗を大きくして、落ちる速さをおさえる。

🔍 こう読み解く

  1. 表1を縦に見る。4m：0.9秒と2.0秒、20m：2.0秒と10.0秒。すべての高さで「あり」が長い。
  2. 「同じ高さなのに時間が長い」を速さの言葉に直す → ありの方がおそい。
答え：パラシュートなしよりもありの方が落下する速さは遅くなっている。
コツ：「速さ」と「速さの変化」の2つの空らんは別の問い。この欄には「どちらが速いか」だけを書き、「だんだん」の話は次の欄へ分ける。

H落下 (1)速さの変化 落ちるにつれて速さはどう変わるか 表の読み取り・短い説明

👀 まず見るところ

【資料問題】部品は表1の高さ「4mと16m（4倍）」の列。なしは0.9秒→1.8秒で時間は2倍だけ、ありは2.0秒→8.0秒で4倍、と倍率を表の横に書く（直して書く）。高さと時間が比例するかどうかが、速さが一定かどうかの分かれ目になる。

📚 前提知識

  • 速さが一定なら、落ちる距離と時間は比例する（4倍の高さなら4倍の時間）。4倍の高さを2倍の時間で落ちたなら、後半ほど速くなっている。
  • パラシュートありは、空気の抵抗と重さがつり合って、落ちはじめてすぐ一定の速さになる（表では20m÷10.0秒＝毎秒2m）。

🔍 こう読み解く

  1. なし：4m→16mで0.9秒→1.8秒。高さ4倍で時間2倍 → 比例していない → 落ちるほど速くなっている。
  2. あり：4m→16mで2.0秒→8.0秒。高さ4倍で時間4倍 → 比例 → 速さは一定。
  3. 2つを「〜が、〜」で1文につなぐ。
答え：パラシュートなしだとだんだん速くなっているが、ありだと一定の速さである。

H落下 (2) 表2のAに当てはまる時間 表の読み取り・倍率の計算

👀 まず見るところ

【まざり型→資料問題】部品は表2で1つの条件だけがちがう2列の組。「重さ40・直径20→40」で時間5.0→10.0、「直径40・重さ10→40」で時間20.0→10.0。この2組から直径×2で時間×2、重さ×4で時間×1/2の決まりを余白に書く（直して書く）。

📚 前提知識

  • パラシュートが大きいほど空気の抵抗が大きく、ゆっくり落ちる（時間が長い）。重いほど速く落ちる（時間が短い）。表2はその倍率を調べるための表。
  • 2つの条件が同時に変わるときは、1つずつ順に倍率をかける。

🔍 こう読み解く

  1. 直径の決まり：40g・20cmが5.0秒、40g・40cmが10.0秒 → 直径×2で時間×2（比例）。
  2. 重さの決まり：10g・40cmが20.0秒、40g・40cmが10.0秒 → 重さ×4で時間×1/2。
  3. Aの列（80g・80cm）を、20g・20cm＝7.1秒の列と比べる。重さ20→80は×4 → 時間×1/2。直径20→80は×4 → 時間×4。
  4. 7.1×1/2×4＝14.2秒。
答え：14.2
コツ：表2の5列は、どの2列を組にすれば「1つだけちがう」になるかを先に線で結ぶ。結べない列（8枚・80cm）が、求める側である。

H落下 (3) 36kgの人が同じ速さで降りるパラシュートの直径 条件文・倍率の計算

👀 まず見るところ

【条件文】部品は「体重36kg」「10gのコインと同じ落下速度」「直径何m」。36kgは表とそろえて36000gに直して書く → 10gの3600倍＝60×60倍。同じ速さ＝同じ高さで着地までの時間が同じ、と言いかえて(2)の決まりに入れる。

L まとめ L・H 共通の型

  • LもH落下も、「1つの条件だけがちがう2列」を表から選び、横軸が何倍で縦軸が何倍かを言葉にすれば決まる。比例＝A・F、4倍で2倍＝D・H、変わらない＝E・J。
  • H落下(2)(3)・H摩擦は、表から出した決まり（重さ×4で時間×1/2、摩擦＝床を押す力×0.4）を余白に書いてから、1回ずつ倍率をかける。
  • H速さは、移動距離の曲線から速さの直線へ。区間の平均の速さは区間のまん中の時刻に置く。
