JF-02 Ⅰ 植物のはたらき（ダイズの呼吸・発芽）

Ⅰ 全体像 実験3つ・10問（各10点）

発芽したダイズを3つの角度から追いかける大問である。1は呼吸で出入りする気体の体積、2は発芽してからの重さの変化、3は葉からの蒸散量。題材はばらばらに見えるが、やることは1つ、条件のちがいを書き出して、引き算で目当てのものだけ取り出すことである。

とくに1は、図1と図2のちがいがそのまま答えになる。ここを表にできるかどうかで、(1)も(2)も決まる。

装置水そうに入っている液色水が動いた分が表すもの
図1こい水酸化ナトリウム水溶液（二酸化炭素を吸収する）吸収した酸素
図2水（二酸化炭素はほとんど吸収しない）吸収した酸素 − 放出した二酸化炭素

今回は10問中2問、20点。ただし落とした8問を見ていくと、知識が足りなくて止まったものはほとんどない。答えを出す直前の一手——単位をそろえる、条件を1つ言葉にする——が抜けた失点が並んでいる。

Ⅰ 1(1)①② 呼吸で出入りする気体 空らん補充・完答

👀 まず見るところ

②のすぐ後ろの一文、「（②）は液体になり」。気体として出てきたものが、冷えて液体になった、という意味である。つまり空らんに入るのは気体の名前でなければならない。

📚 前提知識

  • 呼吸＝酸素を取り入れて養分を分解し、二酸化炭素と水蒸気を出すはたらき。動物も植物も、昼も夜も続けている。
  • 発芽したばかりの種子はまだ本葉が出ていないので光合成ができない。しているのは呼吸だけで、種子の中の養分をけずって使っている。

🔍 こう読み解く

  1. 「酸素を吸収し、二酸化炭素を放出する」はたらきの名前 → ①は呼吸。
  2. いっしょに出るものは水。ただし出るときは気体なので、②は水蒸気。「液体になり」と書いてあるのは、気体で出たという合図である。
答え：① 呼吸　② 水蒸気
今回：呼吸・水 ×（①②は完答で1問）。①は取れている。②は「水」と書いたため、気体として放出されたことが表せていない。空らんを埋めたら、そのあとの一文といっしょに読み返す。「水は液体になり」では文がおかしいと気づける。

Ⅰ 1(1)③④ 酸素と二酸化炭素の体積 体積の計算・完答

👀 まず見るところ

問題文の「ダイズ1個あたり、1日に」。実験のほうはダイズ5つ・6時間後の結果である。数がそろっていない。→ 余白に「÷5、×4（24÷6）」と先に書いておこう。最後に必ず使う。

📚 前提知識

  • ガラス管の内側の断面積は0.1cm²。色水が1cm動けば、ビンの中の気体は0.1cm³変わったことになる。
  • 図1は二酸化炭素が吸われて消えるので、減った体積＝吸収した酸素。図2は二酸化炭素が残るので、減った体積＝酸素 − 二酸化炭素。

🔍 こう読み解く

  1. 図1：6cm×0.1＝0.6cm³。これが5つのダイズが6時間で吸収した酸素。
  2. 図2：1.2cm×0.1＝0.12cm³。これが「酸素 − 二酸化炭素」だから、二酸化炭素＝0.6−0.12＝0.48cm³。
  3. ここで最初に書いた「÷5、×4」を使う。③＝0.6÷5×4＝0.48、④＝0.48÷5×4＝0.384。
答え：③ 0.48　④ 0.384
今回：0.6・0.48 ×。この0.6と0.48は、どちらも計算そのものは正しい。ただし5つぶん・6時間ぶんの合計で、1個・1日に直す最後の一手だけが抜けている。紙面のメモも「6−1.2＝4.8」「0.1×4.8」まで正確だった。問題文の「1個あたり、1日に」に印をつけてから計算を始める。

Ⅰ 1(2) ダイズにふくまれる養分 割り算＋選択・複数解答

👀 まず見るところ

「放出する二酸化炭素の量÷吸収する酸素の量」は、(1)で出した2つの数をそのまま割るだけ。0.48÷0.6＝0.8（1個1日に直した0.384÷0.48でも同じ0.8）。設問が「考えられるもの」と複数をふくむ言い方であることにも印をつけておく。

📚 前提知識

  • 問題文にある値は、でんぷん1.0・たんぱく質0.8・脂肪0.7。これが3つの目盛りになる。
  • 2種類が混ざっていれば、その値は2つの値のあいだになる。混ぜる割合しだいで、あいだのどこにでもなれる。

🔍 こう読み解く

  1. 0.8はたんぱく質そのものの値 → イ（たんぱく質のみ）。
  2. 次に、0.8をはさむ組み合わせをさがす。1.0と0.7なら0.8をつくれる → オ（でんぷんと脂肪）。でんぷん1に対して脂肪2の割合でちょうど0.8になる。
  3. エ（でんぷんとたんぱく質）は0.8〜1.0、カ（たんぱく質と脂肪）は0.7〜0.8。どちらも0.8になるのはたんぱく質だけのときで、2種類ふくむことにならない。
答え：イ・オ
今回：イ ×（完答で1問）。0.8までは出せていて、イも正しい。足りなかったのは「混ざっている場合」を調べる一段。設問の言い方が複数形だったら、値をはさむ2つの組をさがす、と決めておく。

Ⅰ 2(1) 重さをはかる前にすること 実験の条件・語句記述

👀 まず見るところ

設問の「重さの変化を正しく調べられません」。調べたいのは養分の減り方なのに、じゃまをして混ざってくるものが1つある。図3の「水でしめらせただっしめん」がそれを教えている。

📚 前提知識

  • 種子は水を吸ってふくらんでから発芽する。吸う水の量は日によってちがうので、ぬれたまま量ると、水の重さの変化まで一緒に量ってしまう。
  • だから発芽の実験では、乾燥させて水分を飛ばしてから量る。残るのは養分の重さだけになる。

🔍 こう読み解く

  1. 取り出したダイズはだっしめんの水でぬれている。
  2. そのまま量ると、養分が減ったのか水が増えたのか区別できない。
  3. 空らんは「（　①　）重さをはかった」の形なので、そこに入れて読める言い方にする → 乾燥させてから。
答え：乾燥させてから
今回：「よくふいて」 ×。向いている方向は合っていて、水分をとばす話だと分かっている。おしいのは言い方で、「かわいて」は種子がひとりでにかわる意味になり、自分がする操作になっていない。書いたあと空らんに入れて読み返す（「よくふいて重さをはかった」）と、ずれに気づける。

Ⅰ 2(2) 10日目から重さが増える理由 グラフの傾き＋選択

👀 まず見るところ

アとエはよく似ている。ちがいは「10日目に光合成がはじまった」か「つくる量が使う量を上回った」か。見分けるのは図4の8日目あたりの傾きである。

📚 前提知識

  • 種子の重さ＝（光合成でつくった養分）−（呼吸で使った養分）の積み重ね。減っているのは使うほうが勝っているときで、光合成が0とはかぎらない。
  • 植物が根からとるのは水と肥料分で、重さをふやすもとの養分は葉が自分でつくる。「養分を吸収する」という言い方は誤り。

🔍 こう読み解く

  1. 図4は8日目ごろから減り方がゆるやかになり、10日目で底になって上を向く。
  2. 減り方がゆるくなった時点で、光合成はもう始まって減る分を打ち消しはじめている。だからアの「10日目からはじまって」は×。
  3. イは水分の吸収の話。2(1)で乾燥させてから量っているので、水は重さに関係しない → ×。ウは「養分を吸収する」で言い方が誤り → ×。
  4. 残るエ。「つくる量が使う量を上回った」なら、底になって上向きに変わる説明になる。
答え：エ
今回：エ ○。アとのちがいをグラフの傾きで切れている。2(1)で「乾燥させてから量る」と答えたことが、そのままイを消す根拠にもなっていた。

Ⅰ 2(3)① 暗い所で育てたグラフ 条件を変えたグラフ作図

👀 まず見るところ

図4の線を減る部分と増える部分に分ける。条件を変えたとき、どちらが変わるかを一言で決めてから線を引く。暗い所なら「増える部分が消える」である。

📚 前提知識

  • 光合成には光がいる。呼吸は明るくても暗くても続く。だから暗い所では、減らす力だけが残る。
  • ダイズの発芽に光は必要ない（必要なのは水・空気・適当な温度）。暗くても発芽はする。

🔍 こう読み解く

  1. 発芽はするので、はじめのうちは点線と同じように減っていく。
  2. 本葉が出ても光合成ができないので、上向きに変わるところが来ない。
  3. そのまま減り続け、養分がなくなるにつれて底ばいに近づく線を書く。点線の谷より下まで下がる。
答え：はじめは点線と同じように減り、そのあとも増加に変わらず、点線の谷より下まで下がって横ばいに近づく線
今回：× 。書いた線は10日目あたりで水平になり、点線の谷と同じ高さで止まっていた。「増えない」ところまでは正しい。ただし光合成がないので、その高さで支える力はなく、さらに減っていく。

Ⅰ 2(3)② 温度の少し高い所で育てたグラフ 条件を変えたグラフ作図

👀 まず見るところ

変わるのは「何が起きるか」ではなく「どれくらいの速さで起きるか」である。形は図4と同じまま、進み方が速い線になる。

📚 前提知識

  • 呼吸も光合成も、はたらきの速さは温度で変わる。ある範囲までは温度が高いほど速い（もとが25℃なので、少し高い程度なら速くなる側）。
  • 速くなるのは減るほうだけではない。発芽も成長も光合成も同じように速くなる。

🔍 こう読み解く

  1. 呼吸が速い → 養分の減り方が急になり、谷が点線より深く、左（早い日数）に来る。
  2. 成長も速い → 上向きに変わるのも早く、増え方も急になる。
  3. 結果として、最後は点線より上に出る線になる。
答え：点線より早く深く減って谷が左にずれ、そのあと点線より急に増えて最後は上に出る線
今回：× 。書いた線は点線にほぼ重なっていた。「温度が少し高い」で何が変わるかを言葉にしないまま線を引いたのだと思う。速くなると一言決めてから、谷の位置と最後の高さの2か所をずらす。

Ⅰ 2(3)③ 水をまったく与えずに育てたグラフ 条件を変えたグラフ作図

👀 まず見るところ

発芽の3条件は水・空気・適当な温度。水がなければ発芽そのものが起こらない。グラフが動く理由が最初からなくなる、という問題である。

📚 前提知識

  • 種子は水を吸ってはじめて発芽し、そこから呼吸で養分を使いはじめる。水がなければ休眠したままで、養分は減らない。
  • 発芽しなければ葉も出ないので、光合成による増加も起きない。

🔍 こう読み解く

  1. 発芽しない → 養分が使われない → 減らない。
  2. 葉が出ない → つくられない → 増えない。
  3. 減りも増えもしないので、はじめの高さのまま横一直線。
答え：はじめの高さのまま変わらない横一直線
今回：× 。書いた線は点線と同じように10日目まで減って、そのあと横ばいになっていた。3つの中でいちばん短く決まる問題で、「水がない＝発芽しない」に気づいた時点で、線を引く前に答えが決まっていた。
コツ：2(3)は3問とも、書いた線が点線の形に引きずられていた。線を引く前に「この条件で消えるのはどれか、速くなるのはどれか」を一言メモしてから鉛筆を置く。

Ⅰ 3(1) ①の減った水の量 蒸散の引き算

👀 まず見るところ

①〜④の「どこをふさいだか」を表にする。入口は④で、葉の表も裏もふさいであるから、残っているのは茎だけ。ここが決まると、あとは引き算が続く。

📚 前提知識

  • 蒸散は葉の裏（気孔が多い）がいちばん多く、次に葉の表、茎からもわずかに出る。
  • セロハンテープでふさいだ面からは蒸散しない。ガラス管は水で満たしてゴム管でつないであるので、水面からの蒸発は考えなくてよい。

🔍 こう読み解く

  1. ④（表も裏もふさぐ）＝茎だけ＝0.5。
  2. ②（裏をふさぐ）＝表＋茎＝2.1 → 表＝2.1−0.5＝1.6。
  3. ③（表をふさぐ）＝裏＋茎＝3.5 → 裏＝3.5−0.5＝3.0。
  4. ①（何もしない）＝表＋裏＋茎＝1.6＋3.0＋0.5＝5.1。
答え：5.1cm³
今回：5.1 ○。問題用紙のはしに「うら3／おもて1.6／くき0.5」と書き出せていた。ふさいだ場所を1つずつ取り出す手順が身についている。

Ⅰ 3(2) 葉のおもて側の面積 方眼の面積・最も近いものを選ぶ

👀 まず見るところ

図6の右下にある「5mm」。1目もりが5mm＝0.5cmなので、1マス＝0.5×0.5＝0.25cm²。この1行を先に余白に書いてから数えはじめる。

📚 前提知識

  • 方眼で面積を出すときは、①1マスの面積を決める、②全部入っているマスと半分ほど入っているマスを数える、の順で進める。
  • 選択肢が大きくとびとび（2・4・6・8・16・20・40）のときは、こまかく数えなくてよい。おおよその見当で1つに決まる。

🔍 こう読み解く

  1. 葉を囲む正方形を見る。たて6マス・よこ6マス＝3cm×3cm＝9cm²。
  2. 葉はこの正方形の対角線にそった形で、囲みの半分弱をうめている。9の半分弱なら4くらい。
  3. マスで数えても、葉の中はおよそ16マス。16×0.25＝4cm²。選択肢ではイ。
答え：イ（4cm²）
今回：エ（8cm²）×。紙面に「3×3＝9」と書けていて、ここまでは正しい。ただしその9cm²は葉を囲む正方形の面積で、葉そのものではなかった。9に近い8を選んでしまっている。囲みを出したら「葉はそのうちどれくらいか」をもう一段考える。半分と見るだけで4にたどり着いた。
コツ：方眼の面積は「1マス何cm²」と「囲みは何マス」の2つを先に書く。この2行があれば、あとは割合の見当だけで足りる。

Ⅰ まとめ 2／10問・20点

  • 取れたのは 2(2) と 3(1)。どちらもグラフの傾きを見る／引き算で取り出すという、この大問の中心になる読み方ができている問題である。実験の意味は分かっている。
  • 落とした8問の型は3つに分かれる。①単位や条件をそろえる一手が抜けたもの（1(1)③④の「1個・1日」、3(2)の「囲みの半分」）。②言葉の精度（1(1)②の「水」、2(1)の「かわいて」）。③グラフを書く前に条件を言葉にしていないもの（2(3)の3問）。知識不足の失点は見当たらない。
  • 次に同じ形が出たら、この3つを先に紙に書く。「1個あたり・1日あたり → ÷5、×4」／「1マス＝0.25cm²、囲み＝9cm²」／「この条件で消えるもの・速くなるものはどれか」。

JF-02 Ⅱ 蒸散と光合成の計算

Ⅱ 全体像 4問（各25点）

前半の1はホウセンカの蒸散、後半の2は光の強さとデンプンのグラフ。別の話に見えるが、どちらも「表やグラフから2つの数を取り出して、その差や境目を使う」だけの大問である。計算そのものは割り算1回で終わる。

差がつくのは、取り出す数をまちがえないことのほうにある。1なら「葉から出た分」と「全部の分」、2なら「0の線をどちら側に読むか」。今回落とした2問は、どちらもこの取り出しでずれた。

1のA〜Dは、次の表にしてから解きはじめる。この表は問1と問2の両方で使う。

試験管水が減る場所10時→12時の減り
A（何もしない）葉の表＋葉の裏＋茎＋水面88−65＝23
B（表にワセリン）葉の裏＋茎＋水面91−73＝18
C（裏にワセリン）葉の表＋茎＋水面94−83＝11
D（ガラス棒）水面だけ99−97＝2

今回は4問中2問、50点。

Ⅱ 問1 葉の裏は葉の表の何倍か 蒸散の引き算・割合

👀 まず見るところ

Dのガラス棒。葉も茎もないのに2g減っている。つまり水面からの蒸発がA〜Cの全部に混ざっている。ワセリンをぬった場所と合わせて、上の表を作ってから計算に入る。

📚 前提知識

  • ワセリンをぬった面からは蒸散しない。だから「ぬった試験管」と「何もしない試験管」の差が、ぬった場所からの蒸散量になる。
  • 葉の裏に気孔が多いので、ふつう裏＞表になる。出た数が逆向きなら、どこかで読みちがえている。

🔍 こう読み解く

  1. Bは表をふさいだので、A−Bが葉の表＝23−18＝5。
  2. Cは裏をふさいだので、A−Cが葉の裏＝23−11＝12。
  3. 12÷5＝2.4倍。裏のほうが多いので、向きも合っている。
答え：2.4倍
今回：2.4 ○。「88−65＝23／94−83＝11／91−73＝18」と3本ぶん書き出し、そこから12と5を取り出せている。この大問でいちばん手数の多い問題を正面から通している。

Ⅱ 問2 1分あたりの葉からの蒸散量 最大の区間をさがす＋単位そろえ

👀 まず見るところ

設問の「葉からの蒸散量」。茎と水面は入れない。問1で出した 表5・裏12 がそのまま使える数である。ここに線を引いてから計算を始める。

📚 前提知識

  • 2時間＝120分。「1分あたり」と言われたら、最後に120で割る。
  • いちばん蒸散がさかんなのは、気温が上がって日ざしも強い昼前後。表でもそうなっているかを確かめると安心できる。

🔍 こう読み解く

  1. Aの2時間ごとの減りを出す。8→10時＝100−88＝12、10→12時＝23、12→14時＝65−47＝18。いちばん多いのは10時〜12時。
  2. その23gの内わけは、葉の表5＋葉の裏12＋茎4＋水面2。葉から出たのは5＋12＝17g。
  3. 17÷120＝0.1416… → 小数第3位を四捨五入して0.14g/分。
答え：0.14 g/分
今回：0.19 ×。答案には「23÷120＝0.191」とあり、区間のえらび方も割り算も正確だった。使った23が「葉＋茎＋水面」の合計だったことだけが原因である。問1で表を作ってあるのだから、そこから17を拾えば0.14になった。設問の「葉からの」に印をつける。
コツ：同じ表を続けて使う問題は、問1で作った表を消さずに残す。問2はその表から数を1つ拾うだけの問題だった。

Ⅱ 問3 Bは育つがAは枯れる光の強さ グラフの0の線・範囲で答える

👀 まず見るところ

たて軸は「増加・減少」で、0の線が生死の境目である。育つ＝0より上、枯れる＝0より下。2本の線が0を横切る点を先に読み、その2つを答えの両はしにする。

📚 前提知識

  • グラフは1時間あたりのデンプンの増減。プラスならたくわえがふえて育ち、マイナスなら減り続けていつか枯れる。
  • 植物Bは弱い光でも0を上回る（日かげに強い植物）。植物Aは強い光がいる代わりに、光が十分なら大きくふえる。

🔍 こう読み解く

  1. 植物B（点線）は光の強さ1で0を通る → 1より強ければ育つ。
  2. 植物A（実線）は光の強さ6で0を通る → 6より弱ければ枯れる。
  3. 両方を満たすのは、読み取った2つの数にはさまれた1〜6。
答え：1〜6
今回：2〜5 ×。答案の余白には「A 6から／B 1から」と、読み取りが正しく書かれていた。それなのに答えを2〜5と、両はしを1ずつ内側に縮めてしまっている。グラフから読んだ数は、そのまま範囲の両はしになる。書いたメモの数字をそのまま答えらんへ運ぶ。

Ⅱ 問4 植物Bが枯れない光の時間 1日の合計で考える計算

👀 まず見るところ

グラフから拾う数はたった2つ。植物Bの、光の強さ0のとき −2 と 光の強さ3のとき +4。→ 余白に「暗い −2／明るい +4」と書く。あとは1日24時間の中での足し引きになる。

📚 前提知識

  • 枯れないとは、1日の合計が減らないこと。つまり「増えた分 − 減った分 ≧ 0」。
  • 明るい時間と暗い時間を合わせて24時間。片方を決めればもう片方も決まる。

🔍 こう読み解く

  1. まず極端な場合を置く。24時間ずっと暗いと、2×24＝48減る。
  2. そのうち1時間を明るいほうへ移すと、−2だったものが+4になる。1時間あたり6ずつ得をする。
  3. 48の損を取り返すのに必要な時間は 48÷6＝8時間。それ以上なら減らない。
  4. 検算：明るい8時間で4×8＝32、暗い16時間で2×16＝32。差し引き0で、ちょうど枯れない。
答え：8時間以上
今回：8 ○。答案も「2×24＝48」「48÷6＝8」と、解説とまったく同じ筋道で通している。グラフから−2と+4を正しく拾えたことが効いた。
コツ：「何時間以上」型は、いちばん悪い場合（ずっと暗い）から始めて、1時間ずつ得する量で割る。□時間とおいて式を立てるより速く、まちがえにくい。

Ⅱ まとめ 2／4問・50点

  • 取れたのは問1と問4。手数の多い引き算も、1日の合計で考える計算も通っている。考え方で落とした問題は1つもない。
  • 落とした2問はどちらも「数は合っているのに、答えらんへ運ぶところでずれた」型である。問2は表から17ではなく23を拾い、問3は読み取った1と6を2と5に縮めた。
  • 次に同じ形が出たら、この2つ。①設問の「葉からの」「1分あたり」など、範囲と単位を指す言葉に必ず印をつける。②余白にメモした数字は、加工せずそのまま答えらんへ運ぶ。

JF-02 Ⅲ 気体の発生計算（鉄と塩酸）

Ⅲ 全体像 4問（各25点）・全問正解

鉄粉と塩酸から水素が出る、気体の発生計算の定番である。この型の問題は、聞かれ方がどう変わっても「鉄と塩酸のどちらが先になくなるか」を見分けるところに全部が集まっている。先になくなったほうの量で、発生する水素が決まる。

1は表からそれを読み取る問題。表1の水素を横に見ていくと、途中までは塩酸に比例してふえ、ある所から1500cm³で頭打ちになる。頭打ちは「鉄粉5.0gを使いきった」という合図である。

塩酸（cm³）1020406080
水素（cm³）300600120015001500
先になくなるもの塩酸塩酸塩酸鉄鉄

2は表がなく、2つの実験の文だけが与えられる。ここでも同じで、どちらの実験で鉄が全部とけたかを見分けてから比を使う。今回は4問とも正解、100点。

Ⅲ 問1 水素の発生が止まる塩酸の量 比例と頭打ち

👀 まず見るところ

表1の下の行。10→300、20→600、40→1200 とここまではきれいに比例している。ところが60でも80でも1500で止まる。この1500が、鉄粉5.0gを全部使いきったときの水素の量である。

📚 前提知識

  • 鉄と塩酸は決まった割合で反応し、少ないほうがなくなった時点で止まる。
  • 比例している間は塩酸が足りない側、頭打ちになったら鉄が足りない側。グラフでいえば、右上がりの直線が水平に折れる点をさがしている。

🔍 こう読み解く

  1. 比例の割合は、塩酸10cm³で水素300cm³。
  2. 水素が上限の1500cm³になるのに必要な塩酸は 10÷300×1500＝50cm³。
  3. 表の続きをたどっても同じ。40cm³で1200だから、あと300ふやすには塩酸10cm³。40＋10＝50。
答え：50cm³
今回：50 ○。答案は「40＋10＝50」。表の値をそのまま延長する解き方で、比の式を立てるより速く、まちがえにくい。

Ⅲ 問2 Eで残る固体はAの何倍か 反応した量に比例させる

👀 まず見るところ

「黄色い固体」は、とけた鉄が塩酸と結びついてできたもの（塩化鉄）である。できる量は反応が進んだ量に比例する。反応の進み具合をそのまま表しているのが、発生した水素の量である。

📚 前提知識

  • 鉄＋塩酸 → 水素＋塩化鉄。塩化鉄は水にとけているので見えないが、水分を蒸発させると固体で残る。
  • 余った塩酸は蒸発してしまうので、固体としては残らない。だから「塩酸を多く入れた＝固体が多い」ではない。

🔍 こう読み解く

  1. A（塩酸10cm³）の水素は300cm³、E（塩酸80cm³）の水素は1500cm³。
  2. 固体の量は水素に比例するので 1500÷300＝5倍。
  3. 別の見方でも確かめられる。Eで実際に反応した塩酸は50cm³（問1）なので、50÷10＝5倍。
答え：5倍
今回：5 ○。答案は「10 →（5倍）→ 50」で、入れた80ではなく実際に反応した50で比べている。問1の答えをそのまま次の問題に使えていた。
注意：ここで80÷10＝8倍としないこと。余った30cm³の塩酸は蒸発して残らない。「入れた量」ではなく「反応した量」で比べる。

Ⅲ 問3 水素300cm³に必要な鉄粉 2つの実験を見分ける

👀 まず見るところ

2つの実験のうち、鉄が全部とけたのはどちらかを先に決める。塩酸24cm³に鉄10gも入れて水素が300cm³しか出ていないのだから、後の実験は塩酸が足りない側。鉄の量がそのまま効いているのは前の実験（塩酸100cm³・鉄1.2g）である。

📚 前提知識

  • 「最低何g必要か」＝入れた鉄が余らずに全部とける場合のこと。だから鉄が全部とけた実験の比を使う。
  • 塩酸が余っている実験では、鉄1gあたり何cm³の水素が出るかがそのまま読める。

🔍 こう読み解く

  1. 前の実験から、鉄1.2g ＝ 水素480cm³。
  2. 水素300cm³にするには 1.2÷480×300＝0.75g。
  3. 見当でも確かめられる。300は480の約6割強、1.2gの6割強は0.75gあたりで合う。
答え：0.75g
今回：3／4（＝0.75g）○。分数のままでも値は正しく、正解になっている。ただし答えらんの単位がgで、問題文の数値も小数で書かれているので、0.75gと小数に直しておくほうが安全である。

Ⅲ 問4 鉄粉10gを過不足なくとかす塩酸 前問の答えを受けつぐ

👀 まず見るところ

後の実験「塩酸24cm³＋鉄10g → 水素300cm³」。鉄が10gもあるのに300cm³で止まったということは、塩酸24cm³が使いきられた。その24cm³がどれだけの鉄と過不足なく反応するかは、問3ですでに出ている。

📚 前提知識

  • 「過不足なく」＝どちらも余らない組み合わせ。この1組が分かれば、あとは比例で何倍にでもできる。
  • 気体の発生計算は、前の問いの答えが次の問いの材料になることが多い。出した数には単位をつけて残しておく。

🔍 こう読み解く

  1. 水素300cm³ぶんの鉄は0.75g（問3）。よって 塩酸24cm³ ＝ 鉄0.75g がちょうどの組。
  2. 鉄10gなら 24÷0.75×10＝320cm³。
  3. 検算：鉄0.75gの約13.3倍が10g。24cm³の13.3倍も320cm³で合う。
答え：320cm³
今回：320 ○。問3で出した0.75gを、そのまま次の問題の材料として使えている。この受けわたしができると、気体の発生計算は最後まで止まらない。

Ⅲ まとめ 4／4問・100点

  • 4問とも正解。とくに問2で「入れた塩酸80」ではなく「反応した塩酸50」を選べたこと、問4で問3の0.75gを受けついだことが大きい。この単元の考え方は完成している。
  • 残る課題は書き方だけである。問3の答えを分数（3／4）のまま書いていた。単位がgや cm³ で示されている答えらんは、小数に直してから書く。
  • この型をほかの問題でも使えるよう、次の順番で通す。①表やグラフで比例が止まる点をさがす ②止まる前は塩酸不足、止まったあとは鉄不足と決める ③過不足なく反応する1組を書き出す ④そこから比例で求める。
