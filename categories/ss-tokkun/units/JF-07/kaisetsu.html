pH（ピーエイチ）という、ふだんの教材にはあまり出ない数を使う大問である。ただし必要な決まりは、本文に全部書いてある。「10倍にうすめるとpHが1動く」「7が中性で、酸性は7を超えない」の2つを読み取れば、1〜3は本文の数だけで決まる。4はpHを使わない、ふつうの中和の表の問題である。

Ⅰ 1 pH14にするための水酸化ナトリウムの重さ 濃度の計算

👀 まず見るところ

【まざり型→条件文】部品は「水100mL」と「濃度が3.85%」。濃度は（とかしたもの）÷（水＋とかしたもの）なので、「100gの3.85%」ではなく「□÷（100＋□）＝3.85%」に直して書く → 水のほうを96.15%と置けば割り算1回で決まる。

📚 前提知識

  • 水1mLは1gなので、水100mL＝100g。濃度の分母は水溶液全体（水＋とかしたもの）である。
  • とかしたものが3.85%なら、残りの水は100−3.85＝96.15%。水100gがこの96.15%にあたる。

🔍 こう読み解く

  1. 水100g＝水溶液の96.15%。水溶液全体は 100÷0.9615。
  2. 水酸化ナトリウムはその3.85%なので、100×3.85÷96.15＝4.004…。
  3. 小数第1位までで 4.0g。
答え：4.0g
今回：3.9g ×。部品の形を直さなかった＝「濃度3.85%」を100gの3.85%（＝3.85→3.9）として計算したと考えられる（3.85を小数第1位にすると3.9）。とかしたものが入ると水溶液は100gより重くなるので、分母は100＋□。濃度の問題は「水は何%にあたるか」を先に書く。

Ⅰ 2 pH0の塩酸を10倍ずつ8回うすめたpH 本文の決まりを使う

👀 まず見るところ

【まざり型→条件文】部品は決まりの言葉「10倍ずつうすめるとpHは1ずつ大きくなって、0から7に近づいていきます」。「7に近づく」に丸 → 塩酸はいくらうすめても7を超えない。0＋8＝8と足す前に、この上限が決まる。

📚 前提知識

  • pH7が中性。塩酸を水でうすめても、酸がうすくなるだけで、アルカリ性に変わることはない。
  • だから酸性の液をうすめたpHは「7に近づく」だけで、7をこえて8や9にはならない。

🔍 こう読み解く

  1. 1回うすめるごとに 0→1→2→…。7回うすめたところでpH7（中性）に達する。
  2. 8回目は、中性の液をさらにうすめるだけ。中性のまま変わらない。
  3. 答えは pH7。
答え：pH 7
今回：pH8 ×。部品を拾えなかった＝「0から7に近づいていく」の7が上限であることを拾わず、0＋8をそのまま書いた。本文の「近づく」は「そこで止まる」の合図。酸性の液はうすめてもアルカリ性にならない、と知識で止めることもできた。

Ⅰ 3 pH3の塩酸15mLを中和するpH10の水酸化ナトリウム水溶液 うすめた液どうしの中和

👀 まず見るところ

【まざり型→条件文】部品は「pH0の塩酸10mL＝pH14の水酸化ナトリウム水溶液10mL」と、求める組「pH3の塩酸15mL」「pH10」。7からの距離に直して書く（3は7まで4、10は7まで3）→ 塩酸のほうがこく、水酸化ナトリウムのほうが1段うすい。

📚 前提知識

  • pHが1動くごとに液は10倍うすくなる。7からの距離が同じ組（pH3とpH11、pH2とpH12…）は、同じ体積で中和する。
  • 相手が10倍うすい液なら、中和に必要な体積は10倍になる。

🔍 こう読み解く

  1. pH3の塩酸と同じ体積で中和するのは、7から同じ距離のpH11の水酸化ナトリウム水溶液。15mLなら15mLでよい。
  2. pH10はpH11より1段うすい＝10倍うすい。だから体積は10倍いる。
  3. 15×10＝150mL。
答え：150mL
今回：150mL ○。pH3の相手はpH11、と7をはさんだ組を作れている。

Ⅰ まとめ 3／5問・60点

Ⅲ 1問1 水酸化ナトリウム水溶液の濃さ 資料問題・濃度の計算

👀 まず見るところ

【資料問題】資料の正体は「残った固体の重さ・g・加えた水酸化ナトリウム水溶液cm³」。正体を1行書いたら、折れ曲がるC（60cm³・12.0g）を見る。折れ曲がりの後に増える分だけが、あまった水酸化ナトリウムそのものの重さ → 1cm³あたりの重さが決まる。

📚 前提知識

  • 塩酸に水酸化ナトリウム水溶液を加えると中和して食塩ができる。完全中和までは加えた分だけ食塩が増え、中和が終わるとあまった水酸化ナトリウムが固体として残る。グラフの折れ曲がりが完全中和の点である。
  • 濃さ（%）＝とけているものの重さ÷水溶液の重さ×100。問題文の「1cm³あたり1g」より、1cm³に何gとけているかが、そのまま%になる。

🔍 こう読み解く

  1. 0〜Cは1cm³あたり 4.0÷20＝0.2g の食塩が増える。C〜Dは (14.4−12.0)÷20＝0.12g、D〜Eも同じ。増え方が変わる60cm³が完全中和。
  2. 60cm³より後の0.12gは、反応相手の塩酸がもう無いので、水酸化ナトリウムがそのまま残ったもの。つまり水溶液1cm³に水酸化ナトリウム0.12g。
  3. 1cm³＝1g だから、0.12÷1×100＝12%。
答え：12%
今回：18 ×。部品の形を直さなかった＝「残った固体」を、60cm³までの食塩と、それより後にあまった水酸化ナトリウムに分けていない。濃さに使えるのは後半の0.12gだけ。次は余白に「60で中和・その後は1cm³で0.12g」と書いてから%にする。

Ⅲ 1問2 BとDをまぜて蒸発させる 条件文・中和の計算

Ⅲ 1問3 塩酸のこさを半分にしたグラフ 条件文・作図
