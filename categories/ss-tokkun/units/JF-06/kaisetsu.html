Ⅰ 2 温度を測る前の操作 X 素材文・実験操作

👀 まず見るところ

【素材文】設問は「Xに当てはまる言葉」。部品はXの前後「5分間電流を流し」「後、水の温度を測り」に丸 → 温め終わってから測るまでの間にする操作。電熱線のそばだけ熱い水を全体に広げる＝かき混ぜる。

📚 前提知識

  • 水は電熱線のまわりから温まるので、5分後の容器の中は場所によって温度がちがう。温度計で測る前にかき混ぜて全体を同じ温度にしないと、どこに温度計を入れたかで値が変わる。
  • 発泡ポリスチレンの容器は熱を外ににがしにくい。「水の温度の上がり方＝電熱線の発熱」とみなすための道具である。

🔍 こう読み解く

  1. 空らんに入れて読む：「5分間電流を流し、（X）後、水の温度を測りました」→ 測る直前にする操作が入る。
  2. 「電流を止める」は「5分間流し」の中に入っている。しかもこの回路は電源装置で、乾電池はつながっていない。
  3. 温度を正しく測るための操作 → かき混ぜた。
答え：かき混ぜた
今回：「かん電池をとった」×。知識＝「測る前にかき混ぜる（水の温度にむらがある）」が出てこなかった。文に乾電池は出てこない（図1は電源装置）ので、空らんに入れて読み返せば合わないことに気づける。次は「温度を測る」の直前の操作は何か、と考える。

  3. 答えらんの単位はΩ → 6.25Ω。分数なら25/4で、値は同じ。
答え：6.25Ω
今回：25/4 ○。「0.24A＝240mA」と直したうえで、150÷24と整数にしてから割っている。値は正しいが、問題の数値が小数で書かれ、答えらんの単位がΩなので、6.25と小数に直して書くほうが安全である。

Ⅱ 2問4 スイッチを入れた電気機器の消費電力 条件文・WをAに直す

Ⅲ 1問1 20℃の水250gを沸騰させる時間 グラフから熱量・計算

👀 まず見るところ

【まざり型→資料問題】部品はグラフの正体「水100g・18〜22分の4分間で0→20℃」。これを「1分あたり500cal」に直して書く → 問1の「20℃の水250gを沸騰」は80℃上昇＝20000calなので、÷500で分が決まる。問題文の「氷100g」はグラフの実験の量で、250gとは別物。

📚 前提知識

  • 1cal＝水1gを1℃上げる熱（問題文に定義がある）。水の熱量＝重さ×上がった温度。
  • グラフの0℃で平らな部分（2〜18分）は氷がとけている時間で温度は上がらない。水としてあたたまっているのは18分より右の右上がりの部分だけ。沸騰＝100℃。

🔍 こう読み解く

  1. 右上がりの部分：水100gが4分で20℃上昇 → 100×20＝2000cal を4分 → 1分あたり500cal。
  2. 求める熱：250g×（100−20）℃＝20000cal。
  3. 20000÷500＝40分。解答冊子の「4分×4×2.5」は、温度が4倍（20℃→80℃）・重さが2.5倍（100g→250g）だから時間も4×2.5倍、という同じ計算。
答え：40分
今回：40分 ○。問題面のグラフに「18・22」を書きこみ、答案は「1分500cal」を先に書いてから 20000÷500。資料を数に直して置く手順がそのままできている。

Ⅲ 1問2 80℃の水に0℃の氷を入れて20℃にする 熱の移動・計算

👀 まず見るところ

【条件文】部品は「0℃の氷」と「20℃になる」。氷は「とける80cal＋0→20℃の20cal＝1gあたり100cal」の2段に直して書く → 水が失う熱6000calとつり合う式 6000÷100 に入る。

📚 前提知識

  • 混ぜたときは、高温側が失った熱＝低温側が得た熱。
  • 氷1gがとけるのに80cal。このグラフからも出せる：0℃で平らな16分×500cal＝8000cal を氷100gで割って80cal/g。
  • 氷は「とける」と「水になってからあたたまる」の2段階で熱を受け取る。どちらか片方だけで式を立てると合わない。

🔍 こう読み解く

  1. 水が失う熱：100g×（80−20）℃＝6000cal。
  2. 氷1gが20℃の水になるまでに受け取る熱：80＋20＝100cal。
  3. 6000÷100＝60g。
答え：60g
今回：60g ○。答案は「6000cal、6000÷100＝60」の2行。氷1gあたり100calをひとまとめにできている。

Ⅲ 2問3 動く車が聞く反射音 音の反射・往復の計算

👀 まず見るところ

【条件文】部品は「南向きに毎秒10m」（ビルCから遠ざかる向き）と「鳴らし始めた3秒後に」。3秒で車は30m進む、を図1の道路に書く（直して書く）→ 音の道のり1020mは「行き□＋帰り□＋30」で決まる。

📚 前提知識

  • 反射音の道のりは往復ぶん。止まっている車なら 340×3÷2 だが、動く車は行きと帰りの長さがちがう。

  1. 3秒で音が進む道のり：340×3＝1020m。
  2. その3秒で車Aは 10×3＝30m 南へ。はじめの距離を□mとすると、行き□m・帰り（□＋30）m。
  3. □＋□＋30＝1020 → □＝（1020−30）÷2＝495m。
答え：495m
今回：495m ○。答案に道路の図と「30m」があり、1020−30 を先にしてから÷2。部品を図に置く手順そのもの。

Ⅲ 2問4 遠ざかる車のサイレンの無音の長さ 音のおくれ・計算

👀 まず見るところ

【条件文】部品は求めるものの「無音の時間は何秒」に丸、数字は「17秒の無音」と「毎秒10m」。無音の17秒で車Aは170m遠ざかる、を図2に書く（直して書く）→ Bが聞く無音は「17秒＋170mぶん音がおくれる時間」で決まる。

📚 前提知識

  • 音源が遠ざかると、あとに出た音ほど遠くから届くので聞こえる間隔は長くなる。近づくなら短くなる（両方セットで）。
  • 遠くなった分の道のりだけ、音がおくれる。おくれ＝増えた距離÷340。

🔍 こう読み解く

  1. 無音の始まり（サイレンが止まった瞬間）から終わり（次に鳴り始める瞬間）まで17秒。この間に車Aは 10×17＝170m 遠ざかる。
  2. 終わりの音は170m余分に進んでからBに届くので、170÷340＝0.5秒おくれる。
  3. Bが聞く無音＝もとの17秒＋おくれ0.5秒＝17.5秒。遠ざかるので17秒より長い、で向きの検算になる。
答え：17.5秒
今回：0.5秒 ×（正解17.5秒）。部品の形を直さなかった＝「17秒の無音」を「17＋おくれ」の形に直さず、おくれの0.5秒だけを答えにした。答案は 170÷340＝0.5 まで正しい。答えを書く直前に、丸をつけた「無音の時間は何秒」を見直せば、0.5秒が無音そのものでないことに気づける。
コツ：答えが17秒より短ければ、どこかで引き算にしている合図。遠ざかる→長く、近づく→短く。

Ⅲ まとめ 3／4問・75点

  • 熱の2問は、グラフを「1分500cal」に、氷を「1gあたり100cal」に直して置けている。この型は完成している。
  • 問4は 0.5秒を出したところで止まった。おくれは「のびた分」で、無音そのものはもとの17秒に足す。求めるものの丸を書く直前に見直す。
  • 音の問題は向きで式が変わる：遠ざかる→帰りの道のりが長い（問3）・間隔が長い（問4）。近づくなら逆。
