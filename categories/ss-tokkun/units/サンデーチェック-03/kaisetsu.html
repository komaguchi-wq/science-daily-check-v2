サンデーチェック-03 X復習（消化・呼吸・種子・蒸散・光合成）

X復習 全体像 SS-02 Xの復習・10問（各10点）

消化（(1)(2)）、呼吸（(3)）、種子のつくり（(4)）、蒸散（(5)）、光合成（(6)）と、SS-02 Xの単元を1問ずつたどる。知識で即答できる問と、図や表から部品を拾って決める問がまざっている。

計算は(5)だけ。表の数は「実験後の水の量」なので、先に減った量に直して書くところから始まる。

X復習 (1)① 胃の消化液が分解する栄養素 知識問題

図1のウは胃。胃液にふくまれる消化酵素ペプシンは、たんぱく質を分解する。でんぷんは口（だ液）、脂肪はすい液、と消化液と栄養素をセットで覚える。
答え：たんぱく質
今回：たんぱく質 ○。

X復習 (1)② 食べ物の通り道 図・すべて選んで順に並べる

👀 まず見るところ

【資料問題】聞かれ方「すべて選び」「通る順に」に線。図1の管を口から指でたどり、通った記号だけを書く → 肝臓・胆のう・すい臓は管の外なので入らず、小腸（キ）→大腸（カ）の順が決まる。

📚 前提知識

  • 消化管＝口→食道→胃→小腸→大腸→こう門。肝臓・胆のう・すい臓は消化液を出す側で、食べ物は通らない。
  • 小腸は腹のまん中で折りたたまれ、大腸はそのまわりをふちどるように囲む。

🔍 こう読み解く

  1. 口から下へ：ア（食道）→ウ（胃）。イ（肝臓）・エ（胆のう）・オ（すい臓）は管からはずれているので外す。
  2. 胃の先は、まん中で曲がりくねったキ（小腸）。そのあと外側を囲むカ（大腸）を通ってこう門へ。記号の順ではなく通る順で書く。
答え：ア・ウ・キ・カ
今回：アウキカ ○。

X復習 (1)③ 肝臓でつくられる、消化酵素を持たない消化液 知識問題

図1のイは肝臓。胆汁（胆液）は肝臓でつくられ、エの胆のうにたくわえられる。消化酵素はふくまないが、脂肪を細かくしてすい液のはたらきを助ける。
答え：胆液（胆汁）
今回：たん液 ○。

X復習 (2) だ液のはたらきの正誤 文の正誤・間違っているもの

👀 まず見るところ

【素材文】聞かれ方「間違っているもの」に丸。部品はウとエの主語「だ液は」「でんぷんは」。熱に弱いのはだ液（消化酵素）の側 → 主語をすりかえたエが誤りと決まる。

📚 前提知識

  • だ液の消化酵素（アミラーゼ）は体温くらいでよくはたらき、高温にすると性質が変わって、冷ましてももどらない。
  • でんぷんそのものは熱でこわれない。だ液がはたらけば麦芽糖に分解される。

🔍 こう読み解く

  1. ア：でんぷん→麦芽糖 ○。イ：かみくだいて混ぜると効率よく分解 ○。ウ：だ液は熱に弱く、もどしてもはたらかない ○。
  2. エは「熱に弱い」の主語がでんぷんになっている。高温にしたでんぷんでも、ふつうのだ液と混ぜれば分解される → ×。
答え：エ
今回：エ ○。

X復習 (3) 吐く息の方が割合の大きい2つの気体 知識問題

二酸化炭素と水蒸気。呼吸で酸素を使い、二酸化炭素と水を出すので、吐く息ではこの2つが増え、酸素が減る。ちっ素はほとんど変わらない。漢字指定・順不同。
答え：二酸化炭素・水蒸気
今回：水蒸気・二酸化炭素 ○（順不同なので順番は問わない）。

X復習 (4) 発芽後にからだの一部になる部分 図・すべて選ぶ

👀 まず見るところ

【資料問題】部品は「からだの一部になる」と「すべて」。図の正体を1行「インゲン＝胚乳なし、カキ・トウモロコシ＝胚乳あり」と書く → 胚乳（ウ・オ）だけを外せば決まる。

📚 前提知識

  • 胚（幼芽・胚軸・幼根・子葉）が育って植物のからだになる。胚乳は発芽のための養分をたくわえる所で、使われてなくなる。
  • インゲンマメは胚乳がなく、養分は子葉にたくわえる。子葉も胚の一部なので、からだの一部になる。

🔍 こう読み解く

  1. インゲンマメ：ア（子葉以外の胚＝幼芽・胚軸・幼根のまとまり）もイ（子葉）も胚 → 両方入る。
  2. カキ：外側の大きいウが胚乳、中のエが胚。トウモロコシ：大きいオが胚乳、カが胚。胚乳のウ・オを外す。
答え：ア・イ・エ・カ
今回：ア・イ・エ・カ ○。

X復習 (5)① 茎から出された水の量 蒸散の引き算

👀 まず見るところ

【まざり型→条件文】部品は「水100cm³」と表の「実験後の水の量」。100から引いて減った量に直して書く（A24・B18・D3・E1）→ Eのガラス棒は水面からの蒸発だけなので、茎＝D−Eと決まる。

📚 前提知識

  • ワセリンをぬった面からは蒸散しない。水は葉の表・裏・茎と、水面からの蒸発で減る。
  • Eは茎と同じ太さのガラス棒。植物がなくても減る分＝水面からの蒸発をはかるための比べる実験。

🔍 こう読み解く

  1. どこから減るかを表にする。D（葉なし）＝茎＋水面、E＝水面だけ。
  2. 茎＝D−E＝3−1＝2cm³。
答え：2cm³
今回：2 ○。表の下に「24 18」と減った量を書き出してから引き算に入れている。

X復習 (5)② 裏にワセリンをぬったCの水の量 蒸散の計算・表の空らん

👀 まず見るところ

【まざり型→条件文】部品はCの「裏にワセリン」＝残るのは表・茎・水面。表の空らんは「実験後の水の量」なので、減った量を出したら最後に100から引いてもどす → Cの空らんが決まる。

📚 前提知識

  • 葉の表から減る量＝A−B（Bは表をふさいだだけちがう）。葉の裏＝B−D。ふつう気孔は裏に多く、裏の方が多く減る。

🔍 こう読み解く

  1. 減った量はA24・B18・D3・E1。表＝A−B＝24−18＝6、裏＝B−D＝18−3＝15。
  2. Cで減る量＝表6＋茎2＋水面1＝9。
  3. 空らんは「実験後の水の量」 → 100−9＝91。9のまま書かない。
答え：91
今回：91 ○。表の下のメモは6・3・15と読め（表6、裏＝18−3＝15）、面ごとの量を出してから組み立てている。

X復習 (6)① でんぷんを調べる実験の手順 手順の並べかえ

👀 まず見るところ

【素材文】部品は「12時間暗室」と「ヨウ素液」。6つの手順を目的で3つに分けて書く（でんぷんを消す→つくらせる／色をぬく／調べる）。先頭は暗室、最後は「ヨウ素液」と決まり、間は脱色の順だけになる。

📚 前提知識

  • 暗室に置くのは、前の日にできたでんぷんを葉からなくすため。そのあと光に当てた部分だけにでんぷんができる。
  • 熱湯で葉をやわらかくし、湯であたためたアルコールで緑色（葉緑素）をぬく。アルコールは燃えやすいので直接火にかけない。水で洗ってからヨウ素液につける。

🔍 こう読み解く

  1. 準備：オ（暗室）→カ（光に当てる）。
  2. 色をぬく：エ（熱湯）→ウ（アルコール）→イ（水で洗う）。
  3. 調べる：ア（ヨウ素液）。
答え：オ・カ・エ・ウ・イ・ア
今回：オカエウイア ○。

X復習 (6)② 調べた光合成の条件 実験の条件・語句

👀 まず見るところ

【資料問題】図の正体を1行「葉の一部をアルミはくでおおう」。おおった所とおおわない所で変わるのは光の当たり方だけ → 調べた条件は光と決まる。

📚 前提知識

  • アルミはくは光を通さない。1枚の葉の中で比べるので、水・二酸化炭素・温度などほかの条件はそろっている。

🔍 こう読み解く

  1. ヨウ素液で、光が当たった部分だけ青むらさき色になり、アルミはくの部分は変わらない。
  2. ちがいを生んだのは光のあるなし → 光合成には光が必要。
答え：光
今回：光 ○。

サンデーチェック-03 ABC復習（種子・蒸散・消化と呼吸・心臓）

ABC復習 全体像 10問（各10点）

SS-02のA・B・Cの復習。前半は植物（種子・呼吸・蒸散・茎のつくり）、後半はヒトのからだ（消化・吸収・呼吸・心臓）。半分は一問一答の知識で、差がつくのは(3)(4)の蒸散の計算と、(9)(10)の心臓の図の向き。

(3)(4)は「どこから水が出ているか」を表にしてから引き算する。(9)(10)は図の左右がからだの左右と逆になることを先に確かめる。

ABC復習 (1) カキの種子の矢印の部分 知識問題

子葉。カキは有胚乳種子で、まわりの大きな部分が胚乳（養分をたくわえる）、矢印の葉の形をした薄い部分が子葉。胚乳が無い無胚乳種子（インゲンマメなど）では、子葉が厚くなって養分をたくわえる、と区別する。
答え：子葉
今回：子葉 ○

ABC復習 (2) 植物の呼吸で生み出される物質 知識問題

呼吸は「養分（でんぷんなど）＋酸素 → 二酸化炭素＋水（＋エネルギー）」。生み出されるのは矢印の右側の二酸化炭素と水。酸素とでんぷんは矢印の左側＝呼吸で使うもの（光合成では逆に生み出される）。2つ選ぶ問題。
答え：エ・オ
今回：ア・ウ ×（正解はエ・オ）。部品を拾えなかった＝「呼吸」に丸をつけずに、光合成で生み出される酸素とでんぷんを選んだ。次は「呼吸」「生み出される」の2語に丸をつけ、呼吸の式の矢印の右側から選ぶ。

ABC復習 (3) 表のBに入る水の量 蒸散の計算

👀 まず見るところ

【まざり型→条件文】部品は「Bは葉の表にワセリン」「Cは葉の裏」「Dは葉を全部取って」。A〜Dごとに「表・裏・茎」のどこから水が出るかを表に直して書く → 引き算で表・裏・茎が1つずつ決まる。

📚 前提知識

  • ワセリンをぬった面は気孔がふさがれ、そこからは蒸散しない。水面の油は、水面からの蒸発を止めるため。
  • 葉を取ったDでも、茎から少し蒸散する。

🔍 こう読み解く

  1. 表に直す：A＝表＋裏＋茎＝25、C＝表＋茎＝7、D＝茎＝1、B＝裏＋茎＝□。
  2. 茎＝1。C−D で表＝7−1＝6。A−C で裏＝25−7＝18。
  3. B＝裏＋茎＝18＋1＝19。
答え：19
今回：19 ○。表の下にA〜Dと表・裏・茎のどこから水が出るかの表を書いてから引き算していて、部品を紙に置けている。

ABC復習 (4) 葉の裏と表の蒸散量の比 蒸散の計算・何倍

👀 まず見るところ

【条件文】部品は「葉の裏から」「葉の表から」「何倍」。(3)の表で出した裏＝18・表＝6をそのまま使う。「裏は表の何倍」なので裏÷表の順に直して書く。

📚 前提知識

  • 多くの植物では、気孔は葉の裏に多い。だから裏からの蒸散量のほうが大きくなる。

🔍 こう読み解く

  1. (3)より、裏から18cm³、表から6cm³。
  2. 18÷6＝3。裏が表より大きいので、答えが1より大きいことも理由と合う。
答え：3倍
今回：3 ○

ABC復習 (5) 赤く染まる茎の断面 図の選択

👀 まず見るところ

【資料問題】部品は「赤い色水」＝根から吸った水の通り道。4つの図は黒い（染まった）所の位置がちがう。道管は維管束の内側（中心側） → 内側だけ黒い図を選ぶ。

📚 前提知識

  • ホウセンカ（双子葉類）の茎は、維管束が輪の形にならぶ。維管束の内側が道管（水の通り道）、外側が師管（養分の通り道）。

🔍 こう読み解く

  1. エは中心全体が黒い → 維管束以外が染まっているので×。ウは維管束全体が黒い → 師管まで染まっているので×。
  2. アは内側だけ、イは外側だけが黒い。道管は内側なのでア。
答え：ア
今回：ア ○

ABC復習 (6) でんぷんを最初に消化する消化液が出る場所 知識問題

だ液腺（図3のA）。口の中に出るだ液にふくまれるアミラーゼが、でんぷんを最初に分解する。図のAは口のそばのつぶつぶした部分。記号と名前の2つを答える。
答え：記号 A　名前 だ液腺
今回：A・だ液せん ○

ABC復習 (7) 柔毛の毛細血管で吸収される栄養素 知識問題

ブドウ糖とアミノ酸は毛細血管へ、脂肪酸とモノグリセリドはリンパ管へ入る。タンパク質は分解される前の形なので、そのままでは吸収されない。「すべて選ぶ」問題。
答え：ア・イ
今回：ア・イ ○

ABC復習 (8) 図4の矢印の部分 知識問題

気管支。気管が肺の入り口で左右2本に分かれた管で、肺の中でさらに細かく枝分かれし、先が肺胞になる。図4の矢印は気管が左右に分かれたところを指している。図には「気管」と「肺胞」が書いてあるので、答えはその間の部分の名前。
答え：気管支
今回：毛細血管 ×（正解は気管支）。部品を拾えなかった＝矢印の先が気管の分かれ目を指していることを読まず、肺胞のまわりの語を答えた。次は矢印の先がどこで止まっているかを先に見て、書いてある「気管」「肺胞」との位置関係で決める。

ABC復習 (9) 心臓の図の肺動脈 図の読み取り・記号

👀 まず見るところ

【資料問題】部品は図の正体「ヒトの心臓」と聞かれ方「肺動脈」。正面から見た図なので図の左がからだの右。肺動脈は右心室から出る血管なので、右心室（B）から上へのびる管をたどる。

📚 前提知識

  • 動脈＝心臓から出る血管、静脈＝心臓にもどる血管。肺動脈は右心室から肺へ、大動脈は左心室から全身へ。
  • 大静脈は右心房へ、肺静脈は左心房へもどる。

🔍 こう読み解く

  1. 上下2か所のあはAに入る＝大静脈。つまりAは右心房、その下のBは右心室。
  2. Bから上にのびて外へ出る管がう＝肺動脈。えはDに入る＝肺静脈なので、候補からはずれる。
答え：う
今回：う ○

ABC復習 (10) Aと同時に縮む部屋 図の読み取り・記号

👀 まず見るところ

【資料問題】部品は(9)で決めた「A＝右心房」。心房どうし・心室どうしが同時に縮む → もう1つの心房を図でさがす。

📚 前提知識

  • 心房が縮んで血液を心室へ送り、次に心室が縮んで血液を心臓の外へ送り出す。左右の心房は同時に、左右の心室も同時に縮む。

🔍 こう読み解く

  1. (9)より、A＝右心房、B＝右心室、C＝左心室、D＝左心房（肺静脈えが入る部屋）。
  2. Aと同じ心房はD。
答え：D
今回：D ○
