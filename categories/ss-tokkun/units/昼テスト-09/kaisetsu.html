豆苗A〜Cの重さを12時間ごとに量った表1を、グラフにし、比率に直し、最後に水分の割合を考える大問。知識で止まる所はほとんどなく、表の数字を別の形に直して紙に置く作業が中心になる。

表が2つ、図が2つある。先に組にしておくと取りちがえない。

小問使う数字書く場所

(2)表表1の豆苗Cを、0時間の1.01gで割る表2（最初を100とした比率）

L (1) 豆苗Cの重さを図2にかく 資料問題・グラフ作図

👀 まず見るところ

【資料問題】部品は図2の正体「たて軸はg・1目もり0.2（点線は0.1）」と、設問の「豆苗C」。表1のCの列に丸をつけ、5つの数字をそのまま点に移す → 点を順に直線で結べば決まる。

📚 前提知識

  • 折れ線グラフは、点を打ってから、となりどうしを定規で直線で結ぶ。なめらかな曲線にはしない（図2のA・Bも直線で結んである）。

🔍 こう読み解く

  1. 表1のCの列を上から読む。0時間 1.01g、12時間 0.49g、24時間 0.33g、36時間 0.21g、48時間 0.17g。
  2. たて軸は実線が0.2ごと、点線がその間の0.1。1.01は1.0の線のほんの少し上、0.49は0.5の点線のすぐ下、0.33は0.3の点線の少し上、0.21は0.2の線のすぐ上、0.17は0.2の線の少し下に打つ。
  3. 5つの点を左から順に直線で結ぶ。Cは最初がいちばん軽いので、AとBの線より下を通る。
答え：（0時間, 1.01g）（12時間, 0.49g）（24時間, 0.33g）（36時間, 0.21g）（48時間, 0.17g）の5点を打ち、順に直線で結んだ折れ線
自分で解くときのチェック：線を引いたあと、Cの線がA・Bより下にあるかを見る。交わっていたら、となりの列の数字を写している。

L (2)表 最初の重さを100としたときの豆苗C 条件文・比率の計算

👀 まず見るところ

【まざり型→条件文】部品は「最初の重さを100として」と「四捨五入した整数」。「100として」は 100×（その時間の重さ）÷（0時間の重さ）に直して書く → 豆苗Cは割る数が1.01に決まる。

📚 前提知識

  • 最初の重さがちがうものどうしは、gのままでは減り方をくらべられない。最初を100にそろえると、何割残っているかでくらべられる。

🔍 こう読み解く

  1. 問題文の例は豆苗A。100×0.60÷1.45＝41.3…→41。割る数はその豆苗の0時間の重さで、豆苗CならAの1.45ではなく1.01を使う。
  2. 余白に式を書く：100×（重さ）÷1.01。
  3. 12時間：100×0.49÷1.01＝48.5…→49。24時間：100×0.33÷1.01＝32.6…→33。
  4. 36時間：100×0.21÷1.01＝20.7…→21。48時間：100×0.17÷1.01＝16.8…→17。
答え：12時間 49　24時間 33　36時間 21　48時間 17
自分で解くときのチェック：1.01で割るので、答えは「gの数字を100倍したもの」より少し小さくなる（0.49g→49より少し小さい48.5）。大きくずれていたら割る数がちがう。四捨五入は小数第1位で行う。

L (2)グラフ 豆苗Cの比率を図3にかく 資料問題・グラフ作図

👀 まず見るところ

【資料問題】部品は図3の正体「最初の重さを100としたときの重さ・1目もり20（点線は10）」。(1)の図2とは軸がちがう。移すのは表1のgではなく、表2にうめたCの列 → 100から始まる折れ線になる。

📚 前提知識

  • 比率のグラフは、どの豆苗も0時間が100。3本とも左上の同じ点から出発する。

🔍 こう読み解く

  1. 表2のCの列を読む。100、49、33、21、17。
  2. たて軸は実線が20ごと、点線がその間の10。49は50の点線のすぐ下、33は30の点線の少し上、21は20の線のすぐ上、17は20の線の少し下に打つ。
  3. 5つの点を直線で結ぶ。Cの数字はどの時間もA（41・28・17・14）とB（54・35・24・19）の間なので、Cの線はAとBの間を通る。
答え：（0時間, 100）（12時間, 49）（24時間, 33）（36時間, 21）（48時間, 17）の5点を打ち、順に直線で結んだ折れ線
自分で解くときのチェック：図2ではCがいちばん下、図3ではAとBの間。同じ豆苗でも、gでくらべるか比率でくらべるかで線の位置が変わる。

L (3) 豆苗Aにふくまれていた水分 表の読み取り＋知識・空らん3つ

👀 まず見るところ

【まざり型→条件文】部品は「すべて水の蒸発だとすると」と「豆苗A」。表2のAの48時間「14」に丸 → 減った分は 100−14 に直して書く。「しかし」のあとは、水の蒸発のほかに重さを減らすはたらきをさがす。

📚 前提知識

  • 植物は生きているかぎり呼吸を続ける。呼吸では、たくわえた養分が使われて減っていく。
  • 暗いところでは光合成ができないので、養分は使われる一方になる（問題文に「暗いところに置いておく」とある）。

🔍 こう読み解く

  1. 表2で、豆苗Aは最初が100、48時間後が14。減った分は 100−14＝86。全部が水だとすると、水分は少なくとも86%。
  2. ところが48時間の間、豆苗は呼吸を行っている。減った86の中には、呼吸で使われた養分の分もまじっている。
  3. 86＝（蒸発した水）＋（呼吸で使われた養分）。水だけを取り出すと86より小さくなる → 水分は86%よりも少ないとも考えられる。
答え：86　呼吸　少ない
自分で解くときのチェック：1つ目の空らんは「残った14」ではなく「減った86」。「ふくまれていた水分」＝出ていった分、と言いかえてから引き算する。

H短距離 全体像 100m走・3問

100m走の選手A・Bについて、10mごとの通過時間から区間の速さを出し、グラフにして、Bが速い理由を説明する大問。入口は表1の時間の読み方で、時間（秒）はスタートからの合計になっている。1区間にかかった時間は、となりどうしの引き算で出す。ここを取りちがえると(1)(2)(3)が全部くずれる。

(1)で出した10個の速さが、そのまま(2)のグラフの点になり、(3)の記述の材料にもなる。

H短距離 (1) 選手Bの10mごとの速さ 条件文・速さの計算

👀 まず見るところ

【まざり型→条件文】部品は「10mごとの区間の平均の速さ」と「小数第1位まで」。表の時間はスタートからの合計なので、「区間の」は（となりの時間との差）に直して書く → 式は 10÷（時間の差）に決まる。

📚 前提知識

  • 速さ＝距離÷時間。区間の速さなら、距離はその区間の10m、時間はその区間だけにかかった時間を使う。
  • 選手Aの行で確かめられる。20mのらん：10÷（2.88−1.84）＝9.6…で、表の9.6と合う。20÷2.88としていないことが分かる。

🔍 こう読み解く

  1. 先に、Bの時間の行の下に区間の時間（差）を書きこむ。1.89、0.99、0.90、0.86、0.83、0.82、0.81、0.82、0.83、0.83。
  2. 10mのらん：10÷1.89＝5.29…→5.3。20mのらん：10÷（2.88−1.89）＝10÷0.99＝10.10…→10.1。
  3. 同じように割って四捨五入する。10÷0.90→11.1、10÷0.86→11.6、10÷0.83→12.0、10÷0.82→12.2、10÷0.81→12.3、10÷0.82→12.2、10÷0.83→12.0、10÷0.83→12.0。
  4. 「小数第1位まで」なので、12.04…は12.0と書く。12ではなく0をつける。
答え：左から 5.3、10.1、11.1、11.6、12.0、12.2、12.3、12.2、12.0、12.0
自分で解くときのチェック：区間の時間10個をたすと、100mの時間9.58になる。合わなければ引き算のどこかがちがう。

H短距離 (2) 選手Bの距離と速さのグラフ 資料問題・グラフ作図

👀 まず見るところ

【資料問題】部品は点を打つ位置の決まり「その中間の5mの距離」。0〜10m区間の速さは10mの所ではなく5mの所に打つ。横は5、15、25…95に直して(1)の表の上に書く → たてに(1)の速さを取れば決まる。

📚 前提知識

  • スタートの瞬間は止まっているので、選手Aの線は（0m, 0）から始まっている。選手Bも同じ点から始める。

🔍 こう読み解く

  1. 横の位置を直す。10mのらん→5m、20mのらん→15m、…、100mのらん→95m。
  2. たて軸は実線が2ごと、点線がその間の1。（5m, 5.3）（15m, 10.1）（25m, 11.1）（35m, 11.6）（45m, 12.0）（55m, 12.2）（65m, 12.3）（75m, 12.2）（85m, 12.0）（95m, 12.0）に点を打つ。
  3. （0m, 0）から順に直線で結ぶ。最初の5mの点はAより少し下、15mから先はずっとAの線の上を通る。
答え：（0m, 0）から、（5m, 5.3）（15m, 10.1）（25m, 11.1）（35m, 11.6）（45m, 12.0）（55m, 12.2）（65m, 12.3）（75m, 12.2）（85m, 12.0）（95m, 12.0）を順に直線で結んだ折れ線
自分で解くときのチェック：最後の点が95mで止まっているかを見る。100mまで点があったら、横の位置を5mずらし忘れている。

H短距離 (3) 選手Bが100mを短い時間で走れる要因 資料問題・記述

👀 まず見るところ

【資料問題】部品は制約の言葉「各区間での速さが選手Bの方が速いこと以外に」に丸。線の高さの話は使えない。見るのは2本の線の形＝山の頂上がどこにあるかと、頂上のあとの下がり方。

📚 前提知識

  • 短距離走では、速さのピークをおそくして、ゴールするまで速さを維持することが重要（解答冊子の説明）。早くピークが来ると、残りの長い距離を落ちていく速さで走ることになる。

✍️ 答案の組み立て

  1. 要素A（ピークの位置）：選手Bの最高は12.3m/秒で、60〜70mの区間＝グラフでは65mの点。選手Aの最高は11.6m/秒で、表では60mと70mのらん＝グラフでは55mと65mの点。選手Aは55mでもう最高に届いていて、選手Bのほうが最高になるのがおそい。
  2. 要素B（ピークのあと）：選手Bは最後の区間でも12.0m/秒で、最高との差は0.3。選手Aは11.6→11.1で0.5下がっている。Bは最後まで速さを維持できている。
  3. 「要因を1つ説明しなさい」なので、文末は「〜点。」「〜こと。」で止める。グラフの数字（65m）を入れると、図1を見て書いたことが伝わる。
模範解答：速さが最高になるのが65mと遅く、最後まで速さが維持できている点。
自分で解くときのチェック：書いた文に「Bのほうが速い」という意味しか入っていなければ、設問の「以外に」に答えていない。「どこで最高になるか」「そのあとどうなるか」のどちらかが入っているかを見る。

H電車 全体像 電車の速さ・4問

ある区間を走る電車の、5秒ごとの速さの表をグラフにし、いちばん大きく加速・減速した所をさがし、最後に走った距離を求める大問。100m走の表とは数字の意味がちがう。こちらの速さはその瞬間の速さで、単位はkm/時、時間は秒。(3)はこの単位のちがいが決め手になる。

時間電車のようす
0〜30秒加速（0→68km/時）
30〜60秒68km/時のまま
60〜90秒減速（68→0km/時）

H電車 (1) 時間と速さの折れ線グラフ 資料問題・グラフ作図

👀 まず見るところ

【資料問題】部品は図1の正体「横は時間（秒）・たては速さ（km/時）・実線は10ごと、点線はその間の5」。表1の「その瞬間の電車の速さ」なので、100m走とちがって横はずらさない → 19個の点を表の時間のまま打つ。

📚 前提知識

  • たての目もりは、点線まで数えても5きざみ。12や68のような数は、目もりの間のどのあたりかを決めて打つ（12は10と15の間で10寄り、68は70の線のすぐ下）。

🔍 こう読み解く

  1. 加速の部分：（0, 0）（5, 12）（10, 21）（15, 35）（20, 50）（25, 62）（30, 68）。
  2. 一定の部分：30秒から60秒まで、5秒ごとの7つの点がすべて68。横にまっすぐならぶ。
  3. 減速の部分：（65, 57）（70, 44）（75, 30）（80, 20）（85, 5）（90, 0）。
  4. 点を順に直線で結ぶ。上が平らな台形に近い形になる。
答え：（0, 0）（5, 12）（10, 21）（15, 35）（20, 50）（25, 62）、30〜60秒は68、（65, 57）（70, 44）（75, 30）（80, 20）（85, 5）（90, 0）を順に直線で結んだ折れ線
自分で解くときのチェック：点の数は19個。最初と最後の点がどちらも0km/時にあるかを見る。

H電車 (2)①② 最も大きく加速・減速した時間 条件文・表の差の計算

👀 まず見るところ

【まざり型→条件文】部品は「最も大きく加速」と「1秒あたり」。「最も大きく」は速さそのものでなくとなりとの差がいちばん大きい所。「1秒あたり」は ÷5（5秒ごとの表だから）に直して書く。

📚 前提知識

  • 加速・減速の大きさ＝速さがどれだけ変わったか。グラフでは線のかたむきがいちばん急な所にあたる。速さがいちばん大きい所（68km/時）ではない。

🔍 こう読み解く

  1. 表1の速さの行の下に、となりとの差を書きこむ。加速の側は 12、9、14、15、12、6。いちばん大きい15は35→50、つまり15秒〜20秒。
  2. 5秒間で15km/時速くなったので、1秒あたりは 15÷5＝3km/時。
  3. 減速の側の差は 11、13、14、10、15、5。いちばん大きい15は20→5、つまり80秒〜85秒。
  4. こちらも5秒間で15km/時おそくなったので、1秒あたり 15÷5＝3km/時。
答え：① 15　20　3　② 80　85　3
自分で解くときのチェック：3つ目の空らんに15と書いていないかを見る。15は5秒間の変化で、聞かれているのは1秒あたり。

H電車 (3) この区間の距離 条件文・グラフの面積

👀 まず見るところ

【まざり型→条件文】部品は単位の「km/時」と「秒」、答え方の「整数で」。68km/時は 68÷3600（km/秒）に直して書く → 図1を台形とみて面積を出せば距離になる。整数なので、おおよその形でよい。

📚 前提知識

  • 距離＝速さ×時間。速さが変わっていくときは、時間と速さのグラフの面積が距離になる。
  • 1時間＝3600秒。km/時の速さを秒とかけるには、3600で割って「1秒に何km進むか」にそろえる。

🔍 こう読み解く

  1. 図1を台形とみる。下の辺は0〜90秒で90、上の辺は68km/時で走っている30〜60秒で30、高さは68km/時。
  2. 高さの単位を直す。68km/時＝1秒に 68÷3600 km。
  3. 台形の面積＝（上の辺＋下の辺）×高さ÷2 なので、（30＋90）×（68÷3600）÷2＝1.1…km。
  4. 実際の線は台形から少しずれているが、答えは整数でよいので 1km。
答え：1km
自分で解くときのチェック：3600で割らずに（30＋90）×68÷2 とすると4080になる。90秒で4080kmは進めないので、単位を直し忘れたと気づける。
