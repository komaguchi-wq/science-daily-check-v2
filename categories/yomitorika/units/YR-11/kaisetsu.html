3問とも割合の計算で、決め手は「何に対する割合か」を紙に置くこと。(1)は体積の50%を重さに直す、(2)は30億個の0.1%、(3)は「98%が同じ」が全体でなく残った82%の中の話だと読む。もとにする量を1行書けば、あとは解答冊子どおりのかけ算と割り算になる。

今回は(1)○・(2)(3)×で、配点から数えると40／100点（得点らんは未記入）。(2)(3)とも式の入口は合っていて、落としたのは(2)が答えのけた、(3)が残りの数（8200を7200）と最後に割る数だった。

大問1 (1) 水素と酸素の混合気体・酸素の質量%濃度 条件文・割合の計算

👀 まず見るところ

【条件文】部品は「体積%濃度が50%」と「同体積で比べて酸素は水素の16倍の重さ」、答え方「小数第2位を四捨五入」に丸。体積50%ずつ＝体積①と①、重さは水素1・酸素16 に直して書く → 酸素の重さ÷全体の重さ で決まる。

📚 前提知識

  • 質量%濃度＝その物の重さ÷全体の重さ×100。体積%濃度は同じ式を体積で計算したもの（問題文の定義）。聞かれているのは重さのほうなので、体積を重さに直してから割る。
  • 体積が同じでも、重い気体のほうが重さの割合は大きくなる。だから体積で50%の酸素が、重さでは50%よりずっと大きくなる。

🔍 こう読み解く

  1. 体積%濃度が50%ずつ → 水素の体積①・酸素の体積①。
  2. 同じ体積の重さは 水素1・酸素16 → 全体の重さは 1＋16＝17。
  3. 16÷17×100＝94.11… → 小数第2位を四捨五入して94.1%（解答冊子：(①×⓰)÷(①×❶＋①×⓰)×100＝94.11…）。
答え：94.1%
今回：94.1 ○（40点）。「体積%濃度が50%」に丸、「重さ」に丸をつけ、⑯と①を書いてから 16/17 → 1600÷17 と進めている。部品を紙に置いてから式にする手順がそのままできている。

大問1 (2) ヒトのゲノムの個人差は塩基何個分か 条件文・割合の計算

👀 まず見るところ

【条件文】長い説明の中で式に入る部品は「30億個」と「個人差は約0.1%」の2つだけ。0.1%は ×0.001（÷1000）に直して書く → 30億個×0.001 で決まる。A・T・G・Cやたんぱく質の説明は計算に使わない。

📚 前提知識

  • 1%＝0.01、0.1%＝0.001＝1000分の1。%は小数に直してからかける。
  • 30億＝3000000000（3のあとに0が9個）。÷1000 は0を3つ消すだけなので、0を数えてから消す。億→万の言いかえなら 30億÷1000＝300万。

🔍 こう読み解く

  1. ゲノム＝30億個の塩基。個人差＝そのうちの0.1%。
  2. 3000000000×0.001＝3000000個（解答冊子）。
  3. 解答らんの単位は「個」。300万個＝3000000個で、「万」をつけるか0を6個書く。
答え：300万個（3000000個）
今回：300 ×（30点・赤で3000000と訂正）。筆算は「30億コ このうちの0.1%」→ 3000000000×1/1000 と式まで合っている。計算（けた）＝答えらんに書いたのは300だけで、「万」（0なら4個ぶん）が足りない。次は「30億÷1000＝300万」と単位つきで1行書き、解答らんの「個」の前に万を入れたかを見る。
コツ：0が多い数は、数字を全部書くより「億・万」のまま計算するほうが数えまちがいが起きにくい（1億÷1000＝10万、30億÷1000＝300万）。

大問1 (3) ヒトとチンパンジーの違いは個人差の何倍か 条件文・割合の割合

👀 まず見るところ

【条件文】部品は「約98%が同じ」「18%を切り捨てて」「残った部分を比較した」と、求めるもの「個人差に対して何倍」に丸。98%は残った82%の中の話 → 違いは 18%＋82%×0.02 に直して書き、個人差0.1%で割る。

📚 前提知識

  • 割合はもとにする量で大きさが変わる。「98%が同じ」のもとは全体（100%）ではなく、切り捨てたあとの82%。全体で見た違いは 82%×0.02。
  • 「AはBに対して何倍」＝A÷B。割る数はB＝ヒトの個人差0.1%（(2)で使った数）。
  • ヒトもチンパンジーも30億個なので、個数に直さず%どうしで割ってよい。

🔍 こう読み解く

  1. 切り捨てた部分＝大きく異なる部分：全体の18%。残りは 100−18＝82%。
  2. 残った82%のうち、違うのは 100−98＝2% → 全体に対して 82%×0.02＝1.64%。
  3. 違いの合計：18%＋1.64%＝19.64%。
  4. 個人差0.1%の何倍か：19.64÷0.1＝196.4倍（解答冊子）。
答え：196.4倍
今回：270 ×（30点・赤で196.4と訂正）。筆算は「18%→1800」「×0.02」「144＋1800＝1944」と、18%と残りの2%を足す流れまで解答冊子と同じ。計算＝残りを8200でなく7200として 7200×0.02＝144 とした（赤で8に訂正）。さらに最後を個人差の0.1%（全体を10000とすると10）でなく7.2で割っている。次は「全体10000・切り捨て1800・残り8200・個人差10」と4つ並べて書いてから式にする。
コツ：割合の問題で全体を10000のような数に置いたら、出てくる%をすべて同じ10000をもとに直してから並べる。途中でもとにする数が変わると、最後の割り算がずれる。

大問1 まとめ 配点から40／100点

  • (1)は部品（体積①①・重さ1と16）を紙に置いてから式にして正解。同じ置き方を(2)(3)でも使う。
  • (2)は式は合っていて、けたで落とした。0が多い数は「30億÷1000＝300万」と単位つきで計算する。
  • (3)は「98%が同じ」のもとが残った82%。全体・切り捨て・残り・個人差の4つを同じもとの数で並べてから、違い÷個人差。

  • 行事と食べ物：1月＝七草がゆ・お雑煮／5月＝柏餅（端午の節句）／7月＝うなぎ（土用の丑の日）／9月＝月見団子（お月見）／12月＝ケーキ・ローストチキン（クリスマス）。行事は日が決まっているので、旬よりも月を決めやすい。

(1)〜(4)は1本の筋でつながっている。電流を流した円形コイルは、片面がN極・もう片面がS極の磁石になる（解答冊子の図）。(1)はその磁石のまわりの方位磁針、(2)は磁石になったコイルが2つ並んだときの動き、(3)はバネ＝輪がたくさん並んだコイル、(4)は縮んだバネが回路を切る、という順に1段ずつ積み上がる。

大問3 (1) 円形コイルのまわりA〜Cの方位磁針 まざり型・記号3つ

👀 まず見るところ

【まざり型→資料問題】部品は図1の正体「下の図は真上から見たとき」と、A・Cはコイルの面の正面、Bはコイルの輪の外側（横）という位置。コイルを「左がN・右がS」の短い棒磁石に直して図に書く → A・Cは同じ向き、Bだけ逆向きと決まる。

📚 前提知識

  • 電流を流したコイルは磁石になり、片面がN極・反対の面がS極。解答冊子の(2)の図では、同じ向きに電流を流したコイルの左側がN・右側がSになっている。
  • 方位磁針のN極は、磁石のN極から出てS極へ入る向きを指す。棒磁石の両はしの外では同じ向き、横では逆向きになる。
  • 選択肢の針は黒くぬった側をN極として読む（ア＝左向き・イ＝下向き・ウ＝右向き・エ＝上向き）。

🔍 こう読み解く

  1. 真上から見た図のコイルに「左＝N・右＝S」と書きこむ。A・コイル・Cは横一列に並んでいる。
  2. A（N極の正面）：N極から出る向き＝左向き→ア。C（S極の正面）：S極へ入る向き＝これも左向き→ア。
  3. B（コイルの横・輪の外側）：外側ではNからSへもどる向き＝右向き→ウ。A・Cと逆になる。
  4. 針が上下を向くイ・エは、A〜Cのどの位置にも当てはまらない。
答え：A ア／B ウ／C ア
自分で解くときのチェック：AとCはコイルをはさんで反対側にあるが、答えは同じ記号になる。「反対側だから逆向き」と決めず、磁石のはしから出る向き・入る向きを矢印で1本につなげて確かめる。

大問3 (2) つり下げた2つの円形コイル・右側の動きと理由 まざり型・記述

👀 まず見るところ

【まざり型→条件文】設問の条件「右側のコイルはどのように動きますか」「理由も含めて」に丸。部品は図2の2本の矢印「電流」が同じ向きであること。2つのコイルに N・S を書きこむ（図に置く）→ 向かい合う面がSとNになり、引き合うと決まる。

📚 前提知識

  • 同じ向きに電流を流したコイルは、同じ側が同じ極になる。解答冊子の図は左から N・S／N・S。
  • 磁石はちがう極どうしが引き合い、同じ極どうしはしりぞけ合う。向かい合うのは左のコイルのSと右のコイルのN。

✍️ 答案の組み立て

  1. 要素A（動き）：右側のコイルは左側のコイルに引かれるように動く。聞かれているのは右側なので、主語を右側にして書く。
  2. 要素B（理由）：円形コイルに磁力が生じ、お互いに引き付け合うため。「電流が流れるから」で止めず、磁石になることまで書く。
  3. A→Bの順に2文でつなぐ。
模範解答：左側のコイルに引かれるように動く。これは円形コイルに磁力が生じ、お互いに引き付け合うため。
自分で解くときのチェック：「動き」と「理由」の2つがそろっているか。解答冊子の考え方は「コイルが磁化し、S極とN極が引かれ合います」。

大問3 (3) 電流を流した金属製のバネの長さ まざり型・記述

👀 まず見るところ

大問3 (4) 水銀につけたバネ・スイッチを入れるとどうなるか まざり型・記述

👀 まず見るところ

【まざり型→条件文】部品は「端を水銀（液体の金属で電気をよく通す）につけ」と図4の回路。バネの下の端がスイッチの役目をしていると図に書きこむ → (3)の「縮む」で端が水銀から離れ、回路が切れると決まる。そこで止めず、切れたあとを追う。

📚 前提知識

  • 回路は1か所でも切れると電流が流れない。図4ではバネの端と水銀がふれている所が回路の一部になっている。
  • バネが縮むのは電流が流れている間だけ。電流が止まれば磁力がなくなり、バネは元の長さに戻る。

✍️ 答案の組み立て

  1. 要素A：電流が流れるとバネは縮み、バネの端が水銀から離れる。
  2. 要素B：離れると電流が流れなくなり、バネは元の長さに戻り水銀にふれる。
  3. 要素C：すると再び電流が流れてバネが縮む。これを繰り返し、上下に振動する。
  4. 「縮む→切れる→戻る→流れる」を矢印で図4の横に書いてから、結論の「振動する」まで文にする。
模範解答：電流が流れるとバネは縮み、バネの端が水銀から離れると電流が流れなくなり、バネは元の長さに戻り水銀にふれる。すると、再び電流が流れてバネが縮む。このことを繰り返し、バネは上下に振動すると考えられる。
