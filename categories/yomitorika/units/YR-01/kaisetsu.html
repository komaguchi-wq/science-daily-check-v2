大問1 (1) 20%水酸化ナトリウム水溶液 1L にとけている量 条件文・濃度の計算

👀 まず見るところ

【条件文】部品は求めるもの「水酸化ナトリウムは何g」に丸と、「1mLあたり1.22g」「1L」。1L＝1000mL と直して書く → 水溶液全体の重さ 1.22×1000＝1220g が決まり、その20%が答え。%は体積でなく重さの割合なので、先に L を g に直す。

📚 前提知識

  • 質量%濃度＝とけているものの重さ÷水溶液全体の重さ×100。だから「とけているもの＝全体の重さ×0.2」。
  • 「1mLあたり1.22g」は、体積（mL）を重さ（g）に変えるための数。1000mL なら ×1000。

🔍 こう読み解く

  1. 1L＝1000mL。全体の重さは 1.22×1000＝1220g。
  2. その20%が水酸化ナトリウム：1220×0.2＝244g（解答ページ：1220×0.2＝244(g)）。
答え：244g
今回：244 ○。筆算は「200/1000」「200→244」＝1000mL の20%の200 を先に出し、1.22倍で244 に直したと読める。順番は解答ページと逆でも、「体積→重さ」と「20%をとる」の2段を両方通っている。

大問1 (2) 定規はマイクロプラスチック何個分か 条件文・体積と単位の計算

👀 まず見るところ

【条件文】部品は「1cm³あたり1.5g」「9.3g」「1個あたり4mm³」。「あたり」は ÷ に直す：定規の体積＝9.3÷1.5。ここで単位が cm³ と mm³ でちがう ので、1cm³＝1000mm³ と直して書く → 6.2cm³＝6200mm³ を 4 で割れば個数が決まる。

📚 前提知識

  • 1cm＝10mm なので、体積は 10×10×10 で 1cm³＝1000mm³。長さの10倍が体積では1000倍になる。
  • 「1cm³あたり1.5g」は 体積→重さ の数。重さから体積にもどすのは 割り算（9.3÷1.5）。

🔍 こう読み解く

  1. 定規の体積：9.3÷1.5＝6.2cm³。
  2. 単位をそろえる：6.2cm³＝6200mm³。
  3. 1個 4mm³ だから 6200÷4＝1550個（解答ページ：6200÷4＝1550(個)）。
答え：1550個
今回：1.55 ×（正解 1550）。筆算は 9.3→6.2cm³ まで合っていて、そのまま 6.2÷4＝1.55 と割った。部品の形を直さなかった＝「4mm³」の mm³ を cm³ にそろえず、6.2cm³ を mm³ に直さないまま割った。次は「cm³」「mm³」の両方に丸をつけ、ちがえば 1cm³＝1000mm³ を先に書く。個数が「1.55個」と小数になった時点でも止まれる。
コツ：答えの単位が「個」なら整数になるはず。小数が出たら、単位のそろえ忘れを疑う。

👀 まず見るところ

  2. キャップの個数：4000/3÷2.66＝501.2…個（解答ページと同じ）。

今回：502 ○。筆算は 1kg×4/3→4000/3→×100/266＝400000/798→商501 あまり1000 で、501個では足りないと見て 502 にしている。途中「4000/3 kg」と単位が kg のまま書かれているが、数は g として正しく進んでいる。切り上げの判断もできている。

大問1 まとめ 3問中2問 ○

大問2 (1) A〜Eの水温（0〜80℃か×） 資料問題・長さの順に温度を当てる

👀 まず見るところ

【資料問題】部品は資料の正体「12g中何%溶けたか・横線は等間隔＝1本10%・下の線まで＝溶け残りなし」を1行で書く。聞かれ方「判断できない場合は×」に線 → つららの長さの順に温度を当て、同じ長さが2本あればそこが×と決まる。

📚 前提知識

  • ホウ酸は水温が高いほど多く溶ける。だから、たくさん溶けた（つららが長い）ほど水温が高い。
  • 5本のつららに5つの温度（0・20・40・60・80℃）。1本に1つずつ当てるが、見分けがつかない2本があれば、その2本は「判断できない」。

🔍 こう読み解く

  1. 横線を上から数える。上の線から下の線まで10区切りなので1本＝10%。長さは A＝2本と少し（20%台）、D＝4本ちょうど（40%）、C＝7本と少し（70%台）、B・E＝下の線まで（100%）。
  2. 短い順に A＜D＜C＜B＝E。温度は低い順に 0・20・40・60・80℃ なので、A＝0℃、D＝20℃、C＝40℃。
  3. BとEはどちらも全部溶けていて長さが同じ。60℃と80℃のどちらがどちらか、グラフからは決められない → 2本とも×。
答え：A 0℃　B ×　C 40℃　D 20℃　E ×
今回：A〜E すべて× ×。部品を拾えなかった＝「いずれか」の5つの温度を、つららの短い順に当てはめる手を置かず、5本とも「判断できない」にした。次は、つららの下に短い順の番号①〜⑤を書いてから温度を当てる。
コツ：「判断できない場合は×」は、×がどこかにあるはずという合図ではなく、同じ長さの棒があるときだけ使う指示。先に長さの順を作る。

大問2 (2) グラフから読み取れる文 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】聞かれ方「すべて選びなさい」に線。部品は選択肢の数字「40%未満」「8g以上」「7〜8g」「半分以上」→ 1本＝10%の目盛りと「12gの○%＝○g」（12×0.7＝8.4g など）に直して書く → 5つ全部に○×をつけてから答える。

📚 前提知識

  • %とgの行き来：12gの○%＝12×0.○。半分＝50%＝6g、40%＝4.8g、70%＝8.4g、75%＝9g。
  • 「未満」はちょうどをふくまない（40%ちょうどは40%未満ではない）。「以上」はふくむ。

🔍 こう読み解く

  1. ア「全部溶けた水温は1つ」→ 下の線まで届いた棒はBとEの2本 → ×。グラフだけで決まる。
  2. イ「40%未満は2つ」→ 40%の線より上で終わるのはA（20%台）だけ。Dはちょうど40%で未満に入らない → 1つ → ×。
  3. ウ「最も溶け残った水温で8g以上」→ いちばん短いAの先は20%と30%の線の間（溶けたのは25%以下） → 溶け残りは75%以上 → 12×0.75＝9g。8g以上で ○。
  4. エ「Cは7〜8g」→ Cは70%の線を越えている → 溶けたのは12×0.7＝8.4gより多い → 7〜8gの間ではない → ×。
  5. オ「半分以上溶け残った水温は2つ」→ 溶けたのが50%以下の棒はA（20%台）とD（40%）の2本 → ○。
答え：ウ・オ
今回：イ・エ ×（正解はウ・オ）。部品の形を直さなかった＝「40%未満」「7〜8g」を、1本＝10%の目盛りと 12×0.7＝8.4g の形に直して置かなかった。余白の 4.8・2.4 は12gの40%・20%で合っているが、「Dはちょうど40%＝未満でない」「Cは70%を越える＝8.4g以上」まで届いていない。次は選択肢ごとに「○%＝○g」を横に書いてから○×。
コツ：「すべて選ぶ」は5つ全部に○×。棒の先が線にぴったり乗っているD（40%）は、「未満」「以上」のどちらに入るかで答えが変わるので、そこに丸。

大問2 まとめ 0/2 正解

  • 入口は資料の正体「12g中何%・1本＝10%・下の線まで＝全部溶けた」を1行書くこと。これだけで(1)は長さの順、(2)は目盛り数えで決まり、知識は「温度が高いほど溶ける」の1つで足りる。
  • (1)の×は、「5つの温度のいずれか」を順位に直さず全部×にした＝部品を拾えなかった。(2)の×は、「40%未満」「7〜8g」を目盛りとgに直さず選んだ＝部品の形を直さなかった。
  • 解き直しは、つららの下に短い順①〜⑤と「0・20・40・?・?」を書き、選択肢の横に「40%＝4.8g」「70%＝8.4g」を置いてから、5つ全部に○×をつける。

大問3 (5) Yに当てはまらない液体 資料問題・(4)の続き

👀 まず見るところ

【資料問題】部品は「(4)のときの」「Yに当てはまらない液体」に丸。(4)で決めたX＝ア・Y＝オをそのまま使い、図2の右下の箱に名前を書きこむ → Yに進む液体はXで残った2つだけなので、答えはその中から。

📚 前提知識

  • Yで調べるのはXに当てはまった液体だけ。10種類全部をYにかけるのではない。

🔍 こう読み解く

  1. X（アルミニウムがとける）に当てはまるのは水酸化ナトリウム水溶液と塩酸。この2つがYへ進む。
  2. Y（固体が残る）：水酸化ナトリウム水溶液は○、塩酸は× → 「Yに当てはまらない液体」は塩酸。「すべて答えなさい」とあるが、ここでは1つ。
答え：塩酸
今回：砂糖水、食塩水、石灰水、ホウ酸水 ×。答案の4つは、X＝オで残る5種類から水酸化ナトリウム水溶液を除いたものと一致する。(4)のX・Yが逆のまま持ちこされた形で、(5)の筋道そのものは合っている。部品の形を直さなかった（(4)と同じ）。(4)の図2に数を書いてから(5)へ進む。

大問3 まとめ 3/5 正解・60点

  • 取れた：(1)(2)(3)。表づくりと、行の見比べ・列の見比べは読めている。
  • 落とした(4)(5)は原因が1つ：「Yで調べる種類が最も少なく」を図2の数に直さなかった。アとオの組までは正しいので、次は候補ごとに残る液体の数を箱に書く。
  • 覚え直し：アルミニウムは塩酸と水酸化ナトリウム水溶液の両方にとける／鉄は塩酸だけ。
