大問1 (1) 20%の水酸化ナトリウム水溶液は何L 条件文・濃度と体積の計算

👀 まず見るところ

【条件文】部品は「1mLあたり1.22g」「20%」「30.5g」と、答え方「何L」に丸。「1mLあたり1.22g」は 1mLに水酸化ナトリウム 1.22×0.2＝0.244g と直して書く → 30.5÷0.244 で mL が出て、最後に L に直す。

📚 前提知識

  • 質量%濃度＝とけているものの重さ÷水溶液全体の重さ×100。20%なら、水溶液1gのうち0.2gが水酸化ナトリウム。
  • 「1mLあたり○g」は、体積（mL）と重さ（g）を行き来するための数。式に入れるときは、1mLあたり何gの水酸化ナトリウムかに直すと一発で割り算になる。

🔍 こう読み解く

  1. 水溶液1mLは1.22g。そのうち20%が水酸化ナトリウム → 1.22×0.2＝0.244g（1mLあたり）。
  2. 水酸化ナトリウムは全部で30.5g。1mLに0.244gずつ入るので、30.5÷0.244＝125mL（解答冊子どおり）。
  3. らんの単位は L。125mL÷1000＝0.125L。
  4. 別の道：30.5÷0.2＝152.5g（水溶液全体の重さ）→ 152.5÷1.22＝125mL。どちらでも同じ所に着く。
答え：0.125 L
今回：125 ×（0点）。筆算は 305/244、30.5×5＝152.5、152.5→125 と、解答冊子と同じ 125mL まで出ている。部品の形を直さなかった＝「何L」に線は引いてあるが、1.22gが「1mLあたり」なので出てくる数は mL。mL→L（÷1000）の一歩を置かずに、125 を L のらんにそのまま書いた。答えを書く直前に、らんの単位「L」と自分の数の単位「mL」を見比べる。
コツ：「1mLあたり」「1gあたり」で始まる問題は、出てくる答えの単位を先に余白に書く（この問題なら「→ mL」）。らんの単位とちがえば、そこで直す。

大問1 (2) 1人分の二酸化炭素を吸収するスギの本数 条件文・「〜あたり」の計算

👀 まず見るところ

【条件文】部品は「1人あたり1年間で9.9トン」「1000本のスギが1年間に8.8トン」と、求めるもの「何本のスギ」に丸。「1000本で8.8トン」は 1本あたり 8.8÷1000 と直して書く → 本数＝9.9÷（1本あたり）で決まる。木の成長の話（2〜3行目）は答えに使わない。

📚 前提知識

  • 1年間どうしで比べているので、時間の単位はそろっている。トンのまま計算してよい。

🔍 こう読み解く

  1. 1本あたりの吸収量：8.8÷1000＝0.0088トン。
  2. 9.9÷0.0088＝1125本（解答冊子：1000×9.9÷8.8＝1125）。
  3. 比で短く：9.9÷8.8＝9/8 倍 → 8.8トンに1000本なら、9.9トンには 1000×9/8＝1125本。
答え：1125 本
今回：1125 ○。筆算は 9/8 → 125 → 1125 と、9.9÷8.8 を約分して 1000本の 9/8 倍にした短い道。「1000本のまとまり」を1つの部品として使えている。

大問1 (3) 接眼レンズを15倍にしたときの赤血球の個数 条件文・2乗の反比例

👀 まず見るところ

【条件文】部品は「面積は、倍率の比の2乗に反比例」「倍率＝接眼×対物」「接眼10倍→15倍（対物40倍はそのまま）」「108個」と、求めるもの「何個」に丸。変わったのは接眼だけなので、倍率の比は 10:15＝2:3 と直して書く → 面積は 2乗の逆＝9:4 で、個数は 108×4/9 に決まる。

📚 前提知識

  • 倍率を上げると見える範囲はせまくなる。縦も横も縮むので、面積は倍率の2乗に反比例する（問題文がそう決めている）。
  • 赤血球がプレパラート全体に同じように散らばっていれば、見える個数は見える面積に比例する。だから面積の倍率をそのまま個数にかけてよい。

🔍 こう読み解く

  1. 全体の倍率：10×40＝400倍 → 15×40＝600倍。比は 400:600＝2:3（対物が共通なので 10:15 でも同じ）。
  2. 面積は2乗に反比例：2²:3²＝4:9 の逆 → 新しい面積は元の 4/9 倍（解答冊子：1/10×1/10 と 1/15×1/15 を比べて 4/9）。
  3. 個数も4/9倍：108×4/9＝48個。
答え：48 個
今回：48 ○。筆算は 400・600（全体の倍率）、1600→3600・160000（2乗）、16/36 → 48。全体の倍率を2乗して比べた、解答冊子と同じ筋道。16/36 は先に 4/9 に約分すると計算が軽い。

大問1 まとめ 60／100点

  • (2)(3)は「〜あたり」「2乗に反比例」を正しく式に直せている。(1)も 125mL までは同じ。
  • 落としたのは単位を直す最後の一歩：(1)はらんの「L」と自分の「mL」を見比べれば止まれた。答えを書く直前に、設問の丸（求めるもの・単位）をもう一度見る。
  • 覚え直しはこの2つ：濃度は「全体＝とけているもの÷割合」／顕微鏡は「倍率が k 倍 → 面積と個数は 1/k² 倍」。

大問2 (1) ダイコンについて正しい文をすべて選ぶ 素材文・正しいものをすべて

👀 まず見るところ

【素材文】設問の「すべて選びなさい」に丸＝4つ全部に○×をつける。部品は本文の「アブラナの仲間」「花を咲かせることはあまりありません」「あたたかくなり日が長くなると…花を咲かせます」に1語ずつ丸 → ウ・エは本文で決まり、アは「アブラナの仲間」＋モンシロチョウの知識、イは花の色の知識で決める。

📚 前提知識

  • モンシロチョウはアブラナ科の葉に卵を産み、幼虫（アオムシ）が葉を食べる。だからアブラナの仲間のダイコンでは害虫。
  • ダイコン（すずしろ）は春の七草の1つで合っているが、花は白〜うすむらさき。黄色の花はアブラナやキャベツ。
  • 花が咲くまで成長しすぎると、根にためた養分の一部が花や茎に使われてしまう（解答冊子）。

🔍 こう読み解く

  1. ア：「アブラナの仲間」＋モンシロチョウ＝アブラナ科につく → ○。
  2. エ：本文の「低温で花芽がつくられ、あたたかくなり日が長くなると花が咲く」＝咲くのは春。「7〜8月」は夏なので → ×。本文だけで切れる。
  3. ウ：「食用にするときは花を咲かせない」の理由が、根の養分が使われてすかすかになるから → ○。
  4. イ：七草・すずしろまでは正しいが、花びらは黄色でない → ×。「正しい文」は1か所でもちがえば×。
答え：ア・ウ
今回：ア・イ・ウ ×。知識＝ダイコンの花の色を黄色と思った（アブラナの仲間＝黄色、と結びつけた形）。次は「アブラナ科でも花の色はちがう：アブラナ・キャベツは黄、ダイコンは白」を1組で置く。ア・ウ・エは合っていた。
コツ：「すべて選ぶ」は、1つの選択肢の前半が合っていても後半で切れることがある。文を「、」で区切って、区切りごとに○×をつける。

YR-02 大問3（2ページ・水面近くに集まる生物＝仮説と確認実験の記述）

大問3 全体像 仮説→確認実験→結果の記述2問（各50点）

答えを「知っている」かでなく、仮説から確認実験と結果を組み立てる記述。お手本は本文のK君の実験＝3本の試験管で光の向きだけを変え、全部同じ結果だったから「光は関係ない」と決めた、という流れそのもの。

(1)(2)とも書く形は1つ。比べる2本を用意し、仮説の「〜だから」の条件だけを変える（対照実験）→ 結果は「Aは○○、Bは△△」と対にして書く。1本だけ・条件が2つ同時に変わる答案は、結果が出ても仮説の証拠にならない。

大問3 (1) 「酸素に集まる説」を確かめる実験 記述・確認実験と結果（50点）

👀 まず見るところ

【まざり型→素材文】設問は「確認するための実験」と「どのような結果になると説が正しくなるか」の2らん。部品は仮説の中の「酸素が多いから」と、K君の確認実験の形（3本の試験管・光の向きだけ変える）。この形を「酸素あり／なしの2本」に直して書く → 変える条件は酸素だけ、と決まる。

📚 前提知識

  • 確認実験は対照実験にする（解答冊子の注意）。比べる2本を用意し、変える条件は仮説の「〜だから」の1つだけ、ほかは全部同じにする。1本だけでは「酸素のせい」とも「ほかのせい」とも言えない。
  • 「酸素なし」の側は、密閉した容器の中の空気を窒素に入れかえる。窒素は生物が呼吸に使わない気体なので、「酸素だけが無い」相手になる。
  • K君の実験がお手本。光の向きだけを変えた3本を比べ、全部で同じ結果だったから「光は関係ない」と言えた。

✍️ 答案の組み立て

  1. 要素A（比べる2本）：試験管A・Bにこの生物を水ごと入れ、Aは酸素、Bは窒素を入れた密閉した容器に置く。「密閉」で外の空気が入らないようにそろえる。
  2. 要素B（結果の書き方）：説が正しいなら、酸素のあるAだけ水面近くに集まり、Bは集まらない。「どちらに集まるか」をAとBで対にして書く。
  3. 書き終えたら、「変えた条件は1つか」「比べる相手はあるか」の2つを読み直す。
模範解答：確認実験＝2本の試験管A、Bを用意し、それぞれにこの生き物を水ごと入れる。試験管Aは酸素を入れた密閉した容器に入れ、試験管Bは窒素を入れた密閉した容器に入れて置いた。／結果＝試験管Aだけ、この生物が水面近くに集まった。
今回：×（答案 確認実験「全ての場所をふさいだ状態の容器も用意する。」／結果「まんべんなく広がったら正しい。」）。部品の形を直さなかった＝「酸素が多いから」を「酸素あり／なしの2本」に直さず、ふさいだ容器を1本足しただけ。ふさいでも中の空気に酸素は残るので「酸素なし」にならず、比べる「酸素あり」の相手も答案に無いため、広がっても酸素のせいとは言えない。次はK君と同じく試験管を2本並べてから、条件を1つだけ変える。

大問3 (2) 新しい仮説と確かめ方 記述・仮説名／内容／確認実験／結果（50点）

👀 まず見るところ

【まざり型→素材文】設問は4らん「説に名前」「説の内容」「確認実験」「結果」。部品は本文の観察「水の一番上の部分（水面近く）に白っぽい層」。「上に集まる理由」を1行の仮説にしたら、(1)と同じ「条件を1つだけ変えた2本」に直して書く。

📚 前提知識

  • 仮説は解答のものに限らない（解答冊子の注意）。「水より軽い説」のほか、空気や温度に集まる説でもよいが、確かめる実験が書ける仮説を選ぶ。
  • 「水より軽い」を確かめるなら、変えるのは試験管の向きだけ。空気が入らないようにゴム栓をするのは、(1)の酸素や空気の影響を消して「軽さ」だけを残すため。
  • 水より軽いものは、試験管の向きに関係なく上（水面側）へ行く。口が上なら口に、逆さまなら底に集まる、と向きで集まる場所が入れかわるのが証拠になる。

✍️ 答案の組み立て

  1. 仮説名・内容：「水より軽い説」＝この生物は水より軽いため水面近くに集まる。名前は内容の中心の言葉をそのまま使う。
  2. 要素A（確認実験）：2本の試験管に生物を水ごと入れ、ゴム栓で空気を入れず、Aは口が上・Bは逆さまに置く。変える条件は向きだけ。
  3. 要素B（結果）：Aは口の方、Bは底の方（どちらも上）に集まる。「上の方」とだけ書かず、どちらの試験管でどこに集まるかを対にして書く。
模範解答：仮説名＝水より軽い説／仮説内容＝この生物は水より軽いため水面近くに集まる。／確認実験＝2本の試験管A、Bを用意し、それぞれにこの生き物を水ごと入れ、空気が入らないようにゴム栓をする。試験管Aは口が上、試験管Bは逆さまにして置いた。／結果＝試験管Aは口の方に、試験管Bは底の方にこの生物が集まった。
今回：×（答案 仮説名「軽いから浮いてしまう説」／確認実験「水より密度が低い液体とまぜたものも用意する。」／結果「それで白い層がしずんだら正しい」）。仮説名と内容は模範と同じ向きで書けている。落としたのは部品の形を直さなかった＝「軽い」を「比べる2本・変える条件1つ」に直さず、液をまぜた1本だけ。液をまぜると液の重さと生物のすむ液の2つが同時に変わり、元の水の試験管との対照も答案に無いので、しずんでも「軽さのせい」とは言えない。次は液を変えず、向きを逆にした2本で比べる。

大問3 まとめ 0/2 正解

  • 2問とも仮説の方向は読めていた。落としたのは実験の形＝「ふさいだ容器を1本」「液をまぜた1本」で、比べる相手が答案に無かった。
  • 確認実験の型：2本（A・B）→ 変える条件は1つ → 結果はAとBを対にして書く。K君の3本の実験をそのまま写せば形は作れる。
  • 「〜も用意する」と書いたら、もう1本（元の条件）が何かを答案に書く。書いていなければ対照になっていない。
