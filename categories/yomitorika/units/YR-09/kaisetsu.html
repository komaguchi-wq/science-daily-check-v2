大問1 (1) 糖度55%のイチゴジャムで蒸発させる水 条件文・濃度の計算

👀 まず見るところ

🔍 こう読み解く

今回：205 ○（40点）。筆算は「いちご→50gの砂糖」「300gの糖」→ 300×20/11 →（8250−6000）/11＝2250/11＝205 と、解答ページと同じ道筋。糖分300gを先に置けている。

大問3 (1) 対流圏と成層圏の温度の変わり方 資料問題・記述

自分で解くときのチェック：「違い」を聞かれたら、片方だけ書いて終わりにしない。対流圏と成層圏の両方について「高さが高くなると温度が○○」と書けているか。

大問3 (3) 自転がないときの北半球の大気の流れ まざり型・作図（矢印4つ）

👀 まず見るところ

【まざり型→条件文】部品は「自転の影響を受けないとすると」と「北半球の対流圏」に丸、答え方は「矢印をかく」。自転がないなら、残る原因は図3の「赤道はあたたまる・極は冷える」だけ → 赤道で上がって極で下りる1つの輪が決まる。

📚 前提知識

  • あたためられた空気は軽くなって上がり、冷やされた空気は重くなって下りる。上がった分を埋めるように、地表付近では空気が横に流れこむ。
  • 解答らんの図：太い弧が地表、横線が赤道、弧の上のはしが北極。内側の細い弧が地表付近、外側の細い弧が上空。

🔍 こう読み解く

  1. 赤道の【 】（右下・横向き）：赤道はいちばんあたたまる → 空気が上がる → 地表から上空へ向かう矢印「→」。
  2. 外側の弧の【 】（右上・上空）：上がった空気は上空を極の方へ進む → 弧にそって左上（極の方）へ向かう矢印「←」。
  3. いちばん上の【 】（極の上空・縦向き）：極は冷える → 空気が下りる → 上から下への矢印「↓」。
  4. 内側の弧の【 】（地表付近）：下りた空気は地表付近を赤道へもどる → 弧にそって右下（赤道の方）へ向かう矢印「→」。4本で1周する輪になっているかを最後に確かめる。
答え：赤道で上昇 → 上空を極の方へ → 極で下降 → 地表付近を赤道の方へ（解答らんの4つの【 】に、この順で矢印）
自分で解くときのチェック：矢印の向きは「赤道で上」から決める。1本決まれば残り3本は輪をたどるだけ。4本が輪にならない（途中でぶつかる）なら、どれかが逆向き。

大問3 (4) 図3の読み取り ①正しいもの ②太陽からもらうエネルギーの理由 資料問題・すべて選ぶ×2

👀 まず見るところ

【資料問題】図3の正体を1行「緯度（0°赤道〜90°極）とエネルギーの量・実線＝太陽からもらう・点線＝地球から出ていく」。聞かれ方「すべて選びなさい」に線 → ①は3つ全部に○×をつける。②は「太陽からもらう」の実線が右下がりになる理由なので、知識は②だけに使う。

📚 前提知識（②で使う）

  • 極ほど太陽高度が低い → 同じ量の光が広い面積に広がるので、1か所あたりの受け取る量が減る。
  • 太陽高度が低いと、光がななめに大気を通る分だけ大気を通る距離が長くなり、図2の「反射」「吸収」で地表に届く量がさらに減る。
  • 昼の長さは、1年を通して平均すればどの緯度でも大きな差はない。「極の方が昼が長い」は夏だけの話で、年間のエネルギーの理由にはならない。

🔍 こう読み解く

  1. ①ア「もらうエネルギーは極がもっとも小さい」→ 実線は右端（90°）がいちばん低い → ○。
  2. ①イ「出ていくエネルギーは赤道がもっとも大きい」→ 点線のいちばん高い所は赤道より少し右（20°〜30°あたり）→ 赤道は最大ではない → ×。
  3. ①ウ「差は極より赤道の方が大きい」→ 赤道の差（実線が上）と極の差（点線が上）はほぼ同じ幅で、赤道の方が大きいとは読めない → ×。①の答えはアだけ。
  4. ②ア「極の方が昼が長い」→ ×。イ「太陽高度が低い」→ ○。ウ「大気を通る距離が長く届く量が減る」→ ○。②の答えはイ・ウ。
答え：① ア　② イ・ウ
自分で解くときのチェック：「すべて選ぶ」は1つ見つけて終わりにしない。①はイとウに×をつけた理由（点線の山の位置・差の幅）をグラフに書きこんでから答えを書く。

大問3 (5) 低緯度が上がり続けず高緯度が下がり続けない理由 素材文＋資料問題・記述

👀 まず見るところ

【まざり型→素材文】設問の「なぜですか」に丸。手がかりは本文の最後「このグラフだけを見ると…実際はそうはなっていません」と、図3の「あたたまる」「冷える」。余った熱が低緯度から高緯度へ運ばれている、と決まる。運ぶものは(3)の矢印（大気の循環）と海流。

📚 前提知識

  • 図3の赤道側は「もらう＞出ていく」であたたまり、極側は「出ていく＞もらう」で冷える。差し引きが合うのは、熱が低緯度から高緯度へ移動しているから。
  • 熱を運ぶのは、(3)で描いた大気の循環と、海流（暖流が低緯度の熱を高緯度へ運ぶ）。解答ページの補足では、台風も同じはたらきをするとある。

✍️ 答案の組み立て

  1. 要素A（何が起きているか）：低緯度から高緯度へ熱エネルギーが運ばれる。
  2. 要素B（何によって）：大気の循環や海流によって。
  3. 要素C（その結果）：赤道付近のあたたまりすぎと極付近の冷えすぎをやわらげている。A＋Bだけでも理由にはなるが、Cまで書くと設問の「上がり続けず・下がり続けない」の両方に答えた形になる。
模範解答：低緯度から高緯度の地域へ、大気の循環や海流によって熱エネルギーが運ばれ、赤道付近のあたたまりすぎと極付近の冷え過ぎをやわらげているから。
自分で解くときのチェック：「熱が運ばれる」と、運ぶもの（大気の循環・海流）の両方が入っているか。「地球が丸いから」「大気があるから」では、運ばれる向きが書けていない。

大問3 まとめ 記述・作図・記号

  • 図1は「上にいくほど温度が上がるか下がるか」、図3は「もらう／出ていくのどちらが上か」。グラフの線の向きを1語にすると、記述の部品がそろう。
  • (3)の矢印は、図3の「赤道はあたたまる・極は冷える」から赤道で上→上空を極へ→極で下→地表を赤道への輪。1本決めて輪をたどる。
  • 「すべて選ぶ」は3つ全部に○×。①イは点線の山の位置、①ウは差の幅をグラフで確かめてから切る。
