大問1 (1) 河川や湖沼の水は地球全体の何% 条件文・割合の計算

👀 まず見るところ

【条件文】部品は求めるもの「地球全体の水に対して何%」に丸と、「淡水は3500万km³」「淡水のうち約99.6%は氷や地下水」。残りは 100−99.6＝0.4%＝0.004 と直して書く → 河川や湖沼の水＝3500万×0.004 で決まり、それを14億で割る。

📚 前提知識

  • 「〜のうち○%」は、何を全体にした割合かがちがう。99.6%は淡水の中の割合、答えは地球全体の水に対する割合。全体がちがうので、いったん体積（km³）にしてから割り直す。
  • %を式に入れるときは÷100。0.4%＝0.004、2.5%＝0.025。

🔍 こう読み解く

  1. 河川や湖沼の水は淡水のうち 100−99.6＝0.4%。
  2. 体積にする：35000000×0.004＝140000km³（解答ページ）。
  3. 地球全体の水で割る：140000÷1400000000×100＝0.01%。
  4. 別の見方：淡水は全体の 3500万÷14億＝1/40＝2.5%。その0.4%だから 2.5×0.004＝0.01%。
答え：0.01%
今回：1 ×（40点）。筆算は 1/40→2.5/100 と「淡水は全体の2.5%」まで出ていて、その横に 2.5×0.4 と見える式がある。部品の形を直さなかった＝「0.4%」を 0.004 に直さず 0.4 のままかけた（2.5%×0.4＝1%）。%に%をかけるときは、片方を÷100して小数にしてから。

大問1 (2) 太陽の密度 条件文・密度の計算

👀 まず見るところ

【条件文】部品は「体積は地球の130万倍」「重さは地球の33万倍」「地球の密度5.5g/cm³」と答え方「小数第2位を四捨五入」に丸。地球を 1cm³・5.5g と直して書く → 太陽は 130万cm³・5.5×33万g で、密度＝重さ÷体積が決まる。

📚 前提知識

  • 密度（g/cm³）＝重さ÷体積。倍率しか書いていないときは、もとの物（地球）を「1」と置く。
  • 体積は130万倍なのに重さは33万倍しかない → 太陽の密度は地球より小さい。先に見当をつけると、桁のまちがいに気づける。

🔍 こう読み解く

  1. 地球を 1cm³ とおく → 重さは 5.5g。
  2. 太陽：体積 1300000cm³、重さ 5.5×330000＝1815000g。
  3. 1815000÷1300000＝1.39… → 四捨五入で1.4（解答ページ）。万を落として 5.5×33÷130 と計算しても同じ。
答え：1.4g/cm³
今回：1.4 ○（30点）。筆算は「1cm³」「130万cm³」と地球を1と置く所から始まり、5.5×33÷130＝1.39… と万を落として計算している。

大問1 (3) ISSの速さ 条件文・速さの計算

👀 まず見るところ

【条件文】部品は求めるもの「毎分何km」と「一周約90分」「半径6400km」「地上400km上空」「円周率3」。地球の円の外に ISS の円を描き、半径を 6400+400＝6800km と直して書く → 速さ＝円周÷90分。

📚 前提知識

  • 速さ＝道のり÷時間。一周の道のり＝円周＝半径×2×円周率。
  • 「地上400km上空」は地面からの高さ。円の半径は地球の中心からなので、6400に400を足す。

🔍 こう読み解く

  1. ISS の円の半径：6400+400＝6800km。
  2. 一周の道のり：6800×2×3＝40800km。
  3. 40800÷90＝453.33… → 小数第1位まで四捨五入して 453.3km/分（解答ページ：(6400+400)×2×3÷90）。
答え：453.3km/分
今回：453.3 ○（30点）。筆算は「6400→6800」「13600×3×1/90」と、半径に400を足し、直径にしてから円周率をかけている。

大問1 まとめ 60／100点

  • 取れた(2)(3)は、「地球を1と置く」「半径に400を足す」という直して書く一手が筆算に残っている。

  • 覚え直しはこの2つ：密度＝重さ÷体積／%を式に入れるときは÷100（0.4%＝0.004）。

YR-05 大問2（二酸化炭素の温室効果・四字熟語と具体例の選択）

大問2 全体像 文章の読み取り 2問（各50点・100点）

4行の短い文章から「言えること」を選ぶ問題。文章は温室効果とは何か（熱を吸収して一部を地球表面へ戻す）→ 二酸化炭素が増えて悪影響 → その増加は人間が原因の3段でできている。(1)はこの3段を「原因→結果」の形にできれば決まり、(2)は「文章と関係がある」＝二酸化炭素の温室効果の話かを選択肢1つずつに問えば決まる。

落とし穴は(2)。オゾン層の破壊や酸性雨も「環境問題」ではあるが、二酸化炭素の温室効果とは別の話。「すべて選びなさい」なので、選択肢ごとに○×をつけてから書く。

大問2 (1) 文章から言える四字熟語 素材文・四字熟語の選択

👀 まず見るところ

【素材文】設問は「この文章から言える四字熟語」。部品は手がかりの言葉「我々に悪影響を及ぼしています」と「増加は我々人間が原因でもある」に丸 → 人間の行い（原因）が人間に返ってくる（結果）＝因果応報と決まる。

📚 前提知識

  • 因果応報＝よい行いをすればよい結果が、悪い行いをすれば悪い結果がもたらされること（解答ページ）。「因」＝原因、「果」＝結果、と字から読める。
  • 無為無能＝何もしない・何かをする能力がないこと（解答ページ）。馬耳東風＝人の意見を聞き流すこと。温故知新＝古いことを学び直して新しい知識を得ること。どれも「原因と結果」の話ではない。

🔍 こう読み解く

  1. 文章を2つに分ける。結果＝「二酸化炭素が増加し、我々に悪影響」。原因＝「その増加は我々人間が原因」。
  2. 「人間がしたこと → 人間に悪い結果が返ってくる」の形になっている。この形に合う四字熟語を選ぶ。
  3. ア（何もしない）・イ（聞き流す）・ウ（古いことから学ぶ）はこの形に合わない → エ 因果応報。
答え：エ
今回：エ ○。「原因でもある」の1語から原因→結果の形に気づけている。

大問2 (2) 文章と関係のある具体例 素材文・すべて選ぶ

👀 まず見るところ

【素材文】設問は「この文章と関係があり」「すべて選びなさい」。部品は文章の話題「二酸化炭素には温室効果」→ 余白に「話題＝二酸化炭素の温暖化」と1行書く → 選択肢ごとに「温暖化の原因／温暖化の結果／別の問題」の3語で仕分ける。別の問題（オゾン層・酸性雨）が外れて、残りを文章と照らす。

📚 前提知識

  • オゾン層の破壊や酸性雨は、二酸化炭素の温室効果とは関係がない（解答ページ）。オゾン層をこわすのはフロンなどのガス、酸性雨のもとは工場や車から出る硫黄や窒素の酸化物。
  • 温暖化の具体例＝化石燃料を燃やして二酸化炭素が出る（原因側）、海面が上昇して島が沈む（結果側）。原因と結果のどちらも「関係がある」。

🔍 こう読み解く

  1. ア：「燃やす際に二酸化炭素が出る」「節電すると地球温暖化を抑制」→ 二酸化炭素の増加は人間が原因、という文章の中身そのもの → ○。
  2. イ：「温室効果は…害でしかない」→ 文章には「熱の一部を地球表面へ戻すこと」とあり、悪影響なのは増えすぎたときの話。「しかない」は言いすぎ → ×。
  3. ウ：オゾン層・紫外線・皮膚がん → 原因はフロン → 別の問題 → ×。エ：酸性雨 → 原因は硫黄や窒素の酸化物 → 別の問題 → ×。
  4. オ：氷が融ける・海水面が上昇 → 気温が上がった結果＝温暖化の結果 → ○。ア（原因）・オ（結果）の2つ。
答え：ア・オ
今回：ア・オ ×（答案 ア・エ・オ＋判読できない1字）。知識＝酸性雨を二酸化炭素の温室効果と同じ環境問題としてまとめてしまった。イの「害でしかない」には印をつけて外せている。次は選択肢ごとに「温暖化の原因／結果／別の問題」の3語を書いてから選ぶ。
コツ：「すべて選びなさい」は1つずつ○×。環境問題は 温暖化＝二酸化炭素／オゾン層＝フロン／酸性雨＝硫黄・窒素の酸化物 と原因の気体でセットにして覚えると、混ざらない。

大問2 まとめ 1/2 正解・50点

  • (1)は「原因でもある」の1語で原因→結果の形がつかめていた。四字熟語は字の意味（因＝原因・果＝結果）から当たりをつける。
  • (2)の失点は知識の混同。環境問題は原因の気体でセット（温暖化＝二酸化炭素・オゾン層＝フロン・酸性雨＝硫黄や窒素の酸化物）にして分ける。
  • 「関係がある」を選ぶ問題は、文章の話題を1行（今回は「二酸化炭素の温暖化」）で書き、選択肢を「原因／結果／別の問題」で仕分けてから○×をつける。

YR-05 大問3（2ページ・サンゴ礁と褐虫藻の共生＝実験①②と調査の読み取り）

大問3 全体像 サンゴ礁と褐虫藻 記述3問＋記号2問（各20点）

本文は「サンゴの体内に褐虫藻がすみついて共生している」「サンゴ礁は温暖化の原因の気体の濃度をコントロールする」「水温が上がると褐虫藻を放出して白化し、続くと死ぬ」の3段。(1)(4)(5)の記述はこの3段のどれかを、本文の言葉のまま組み立てれば書ける。

大問3 (1) 気体の濃度をコントロールするしくみ 記述・20点

👀 まず見るところ

【まざり型→素材文】設問は「気体の濃度をコントロールするしくみ」を具体的に。気体の正体を「二酸化炭素」と1行書く。部品は本文の「炭酸カルシウム」の骨格と、図1の「酸素発生」＝褐虫藻の光合成 → 海水の二酸化炭素を使う場所が2つある、と決まる。

📚 前提知識

  • 地球温暖化の原因の1つである気体＝二酸化炭素（大問2と同じ）。図1で光が強いほど酸素が出ている＝褐虫藻は光合成をする生き物で、光合成は二酸化炭素を取りこむ。
  • 炭酸カルシウムは「炭」の字のとおり炭素をふくむ → 骨格の材料も海水にとけた二酸化炭素から来る。
  • 海水の二酸化炭素が減ると、空気中の二酸化炭素がそのぶん海水にとけこむ（空気と海水のやりとり）。

✍️ 答案の組み立て

  1. 要素A：海水にとけた二酸化炭素を褐虫藻が光合成に使う。
  2. 要素B：サンゴが炭酸カルシウムの骨格をつくるためにも使われる。
  3. 要素C：海水の二酸化炭素が減るので、空気中の二酸化炭素がより多く海水にとける → 空気中の濃度を下げる。「具体的に」とあるので、AとBの2つの使い道を両方書く。
模範解答：海水に溶け込んだ二酸化炭素を、褐虫藻が吸収して光合成に使うだけでなく、サンゴが炭酸カルシウムの骨格をつくるためにも利用されるので、空気中の二酸化炭素がより多く海水に溶けることにつながり、二酸化炭素濃度を下げるはたらきがある。
自分で解くときのチェック：「褐虫藻の光合成」だけで終わっていないか。本文が「炭酸カルシウムも褐虫藻の活動が大きく関係」とわざわざ書いているのは、骨格も二酸化炭素の行き先だから。使い道2つ＋「空気中から海水へ」の1文でそろう。

大問3 (2) 実験①②を行った目的 まざり型・記号（すべて選ぶ）

👀 まず見るところ

【まざり型→資料問題】部品は実験①の「ア・イの条件」（図1＝光の強さ）と実験②の「含まないサンゴと含むサンゴ」。それぞれ「変えたもの＝光の強さ／褐虫藻の有無、見たもの＝骨格の成長／カルシウムの取り込み」と1行ずつ書く → どちらも「褐虫藻のはたらきと骨格づくりの関係」を調べる実験と決まる。

📚 前提知識

  • 図1で光が強い（イ）ほど酸素発生が多い＝褐虫藻の光合成が盛ん。実験①は「褐虫藻のはたらきの強さ」を光で変えている。
  • 実験の「目的」は、変えた条件と見た結果の組み合わせから決まる。結果がどうだったか（速かった・多かった）ではなく「何と何の関係を見たか」。

🔍 こう読み解く

  1. 実験②：褐虫藻を含むと含まないでカルシウムの取り込みが大きくちがう（図2で約50と約4）→ 骨格づくりに褐虫藻が関係しているかを確かめる実験 → ウ ○。
  2. 実験①：光を強くして褐虫藻のはたらきを盛んにすると骨格の成長が速い → はたらきが盛んなほど骨格がつくられるかを確かめる実験 → エ ○。
  3. イ「骨格は褐虫藻がつくる」→ 取り込みが増えたことは分かるが、褐虫藻が直接つくっているとまでは断定できない（解答ページ）→ ×。ア「いなくてもつくれる」→ 2つの実験は褐虫藻のはたらきを変えて比べる組み立てで、「いなくても」を確かめるためのものではない → ×。
答え：ウ・エ
自分で解くときのチェック：「すべて選ぶ」は4つ全部に○×。イは「関係している」（ウ）より一歩言いすぎ。実験で分かるのは「関係」と「盛んなほど」までで、「つくる主体が褐虫藻」までは言えない。

大問3 (4) サンゴが褐虫藻に与える利益 記述・20点

👀 まず見るところ

自分で解くときのチェック：「すみか」だけで終わらせず、「光合成に必要なものを出している」の向きで1つ足す。褐虫藻は植物のなかまと同じ光合成をする、と図1から読めていれば、材料＝二酸化炭素に気づける。

大問3 (5) 「温暖化でサンゴの海が広がる」考えの誤り 記述・20点

👀 まず見るところ

【まざり型→素材文】設問は「この考えの誤りを説明」。部品は本文3段目の「水温の上昇などの環境ストレス」「褐虫藻を放出」「白化」「死んでしまう」に丸 → 温暖化は海を広げる前にサンゴを白化させて殺すので、吸収量は増えない、と決まる。

📚 前提知識

  • 誤りの説明は「相手の考えの前提（温暖な海が広がる＝サンゴが増える）がくずれる理由」→「だから結論（吸収が増える）が成り立たない」の2段で書く。
  • 本文に「短いうちに環境ストレスが除かれれば…健康な状態に戻ります」とある。温暖化は元に戻らない水温上昇なので、白化が続いて死ぬ側に進む。

✍️ 答案の組み立て

  1. 要素A（前提がくずれる理由）：急激な水温上昇は環境ストレスになり、サンゴは褐虫藻を放出して白化し、やがて死ぬ。
  2. 要素B（だから結論が成り立たない）：温暖な海が増えて生息域が広がっても、温室効果ガスの吸収量の増加は見込めない。
  3. 「白化」「環境ストレス」は本文の言葉をそのまま使う。
模範解答：急激な水温上昇は環境ストレスとなり、サンゴは褐虫藻を放出するので、白化してしまい、やがて死んでしまう。そのため、温暖な海が増えてサンゴの生息域が広がったとしても、温室効果ガスの吸収量の増加は見込めない。
自分で解くときのチェック：「白化する」で止めず、「だから吸収量は増えない」まで書いて設問の「誤り」に答える。前半だけでは、相手の考えのどこが誤りかを言っていない。

大問3 まとめ 各20点×5問

  • 記述3問は本文の3段（共生／気体の濃度／白化）にそれぞれ対応。「炭酸カルシウム」「環境ストレス」「白化」など本文の言葉をそのまま使う。
  • (2)は「変えたもの／見たもの」を1行ずつ書けば目的が決まる。「関係している・盛んなほど」までは言えて、「褐虫藻がつくる」は言いすぎ。
  • (3)は積み上げグラフの区分ごとの帯の高さで比べる。合計が減っても、増えている区分（エサ場とねぐら）がある。
