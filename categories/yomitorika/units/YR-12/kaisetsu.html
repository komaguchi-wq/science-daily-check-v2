YR-12 大問1（気体の濃度・脂肪の種類・遺伝子の並び）

大問1 全体像 条件文の読み取り 3問（(1)40点・(2)(3)各30点）

3問とも知識はいらず、「ただし」「〜と考えると」のあとの決まりを紙に置けるかで決まる。(1)は「同体積で酸素は水素の16倍の重さ」、(2)は「上下を逆さまにして同じものは1種類」、(3)は「1回変化した記号はもう一度変化しない」。

今回は100／100点。余白に比・書き出し・□の印が残っていて、3問とも決まりを紙に置いてから答えている。

大問1 (1) 水素25%の混合気体・酸素の質量%濃度 条件文・割合の計算

👀 まず見るところ

【条件文】部品は「体積%濃度25%」と「酸素は水素の16倍の重さ」、答え方「小数第1位まで」に丸。体積の比 水素①：酸素③ を、重さの比 1：48 に直して書く → 酸素の重さ÷全体の重さ で決まる。

📚 前提知識

  • 体積%濃度＝その気体の体積÷気体の合計体積。水素が25%なら、残りの75%が酸素。体積は 水素①：酸素③。
  • 質量%濃度は重さで比べる。同じ体積で酸素は水素の16倍なので、体積の比にそれぞれの重さをかけてから割合を出す。

🔍 こう読み解く

  1. 重さに直す：水素 ①×1＝1、酸素 ③×16＝48。全体は 1＋48＝49。
  2. 酸素の質量%濃度：48÷49×100＝97.95…（解答冊子：(③×⓰)÷(①×❶＋③×⓰)×100）。
  3. 小数第2位を四捨五入して 98.0。「98」でなく 98.0 まで書く。
答え：98.0%
今回：98.0 ○（40点）。余白に「酸：水＝3：1 → 48：1」と、48/49 を100倍する式を書き、筆算の 97.95 を消して 98.0 に直している。体積の比を重さの比に直す1行と、答え方の指示の見直しの両方ができていた。

大問1 (2) 脂肪酸A・B・Cでできる脂肪は何種類 条件文・書き出して数える

👀 まず見るところ

【条件文】部品は「AとBの2種類は少なくとも1個ずつ」と「上下を逆さまにしたときに同じになるものは1種類」。3つの席に上から書き出し、逆さ読みが同じ組（AAB と BAA）は片方に線 → 残った数が答え。

📚 前提知識

  • 図の脂肪は、グリセリンの上・中・下の3つの席に脂肪酸が1つずつ入る形。並びがちがえば別の脂肪だが、上下を逆さまにして重なるものは同じ。
  • 「少なくとも1個ずつ」なので、使う3個の組は A・A・B／A・B・B／A・B・C の3通りだけ。

🔍 こう読み解く

  1. A・A・B：まん中がAの AAB（逆さは BAA で同じ）と、まん中がBの ABA の2種類。
  2. A・B・B：同じ考え方で ABB と BAB の2種類。
  3. A・B・C：まん中で分ける。ABC・ACB・BAC の3種類（逆さの CBA・BCA・CAB は同じもの）。
  4. 2＋2＋3＝7（解答冊子：AAB、ABA、ABB、BAB、ABC、ACB、BAC）。
答え：7種類
今回：7 ○（30点）。余白にグリセリンの形の図と、たて3文字の書き出しがあり、下の3列には斜線が引いてある。頭の中で数えず、書き出してから数える置き方ができていた。
コツ：逆さで同じものを消す問題は、「まん中に何が入るか」で分けると、数えもれと二重数えがなくなる。

大問1 (3) ①に当てはまる遺伝子の並び 条件文・図の矢印を数える

👀 まず見るところ

【条件文】部品は「矢印1つにつき記号が1つ変化」「1回変化した記号はもう一度変化することはない」と聞かれ方「すべて」。①は AGGTTAACTG から矢印2本 → ちがう文字に□をつけ、ちょうど2か所で3番目がGのままのものが残る。

📚 前提知識

  • 図は下から上へ進む。①の2つ下は、矢印Ⅰで3番目のCがGに変わった AGGTTAACTG。ここから「？」を1つはさんで①なので、変化は2回分。
  • 3番目のGは矢印Ⅰですでに1回変化している。だから①でも3番目はGのまま。

🔍 こう読み解く

  1. AGGTTAACTG と1文字ずつ見比べ、ちがう文字に□をつける。ア＝1・2番目の2か所、イ＝1・2・9番目の3か所、エ＝10番目の1か所。
  2. ウ CGCTTAACTG は1番目と3番目の2か所だが、3番目がCにもどっている。3番目が2回変化したことになるので当てはまらない（解答冊子）。
  3. ちょうど2か所で、3番目がGのままなのはアだけ。
答え：ア
今回：ア ○（30点）。選択肢のちがう文字を□で囲み、イとウを消してから答えている。もとの並びと見比べて印をつける置き方ができていた。

大問1 まとめ 100／100点

  • 3問とも、決まりの言葉を比・書き出し・□の印に直して紙に置いたことが正解につながった。この置き方を大問2・大問3でも同じように使う。
  • (1)は「体積の比→重さの比」に直す1行、(2)は「まん中で分けて書き出す」、(3)は「何本の矢印ぶんか数えてから見比べる」。
  • 答え方の指示（小数第1位まで・すべて選ぶ）は、答えを書く直前にもう一度見る。

YR-12 大問2（顕微鏡の手順の並べかえ）

大問2 全体像 表の説明から手順を並べる（100点・15ます）

ふだん覚えている顕微鏡の手順を、この顕微鏡の表の説明に合わせて細かく並べ直す問題。解答らんは15ますで、1番目のP・8番目のO・15番目のEが印字されている。Pの次からOの前までが「見る準備」の6ます、OのあとからEの前までが「ピント合わせ」の6ますと分けると、一度に考える量が半分になる。

「使わないものや2度以上使うものがあってもよい」ので、I（接眼レンズを覗きながら）とB（調節ねじをまわし）は2回入り、G・H・L は使わない。

大問2 手順 光学顕微鏡の正しい手順 資料問題・並べかえ

👀 まず見るところ

【資料問題】部品は表の「低倍率のものから使う」（接眼・対物の2行）と、解答らんの印字 P・O・E。ますを「Oの前6つ＝準備」「Oのあと6つ＝ピント」に区切って書く → 前半はKとF、後半は「〜ながら」で終わるA・Iの置き場所で決まる。

📚 前提知識

  • レンズは接眼レンズ→対物レンズの順に取りつける。先に上をふさぐと、筒の中にほこりが落ちて対物レンズにつくのを防げる。
  • ピント合わせは、まず真横から見ながら近づけ、次に覗きながら遠ざける。覗いたまま近づけると、対物レンズがプレパラートに当たっても気づけない。
  • この顕微鏡は表の「調節ねじ＝ステージを上下させる」型。だから選択肢は「プレパラートを対物レンズに近づける／遠ざける」という言い方になっている。

🔍 こう読み解く

  1. 準備の6ます：レンズをつける。低倍率からなので K（10倍の接眼レンズ）→ M（対物レンズを取りつける）。次に N（レボルバーをまわす）→ F（4倍の対物レンズに合わせる）。
  2. 明るさ：I（接眼レンズを覗きながら）→ J（反射鏡で視野を明るくする）。ここまでで K M N F I J、次が印字のO（プレパラートをのせる）。
  3. ピントの6ます・前半：A（真横から確認しながら）→ B（調節ねじをまわし）→ C（対物レンズに近づける）。
  4. 後半：I（覗きながら）→ B（調節ねじをまわし）→ D（対物レンズから遠ざける）。これで A B C I B D、最後が印字のE（ピントが合ったら観察する）。
答え：P K M N F I J O A B C I B D E
自分で解くときのチェック：「〜ながら」「〜まわし」で終わるA・I・Bは、それだけでは手順にならない言葉。A→B→C、I→B→D のように、3つで1つの動作になる組を先に作ってから、ますに入れる。

YR-12 大問3（豆電球とLEDの電圧・電流のグラフ）

大問3 全体像 グラフの読み取り 4問（各25点）

図2は、豆電球（●）とLED（■）にかかる電圧を0.05Vずつ変えたときの電流のグラフ。先に目もりの正体（よこ1目もり0.05V・たて1目もり0.01A）を書いておけば、4問ともグラフから読むだけで決まる。

(1)は点の並びの「曲がり方」、(2)(3)は「2つの電圧計の値を足すと1.5V」「同じ強さの電流」を使って、グラフのどの点を読むかを決める。オームの法則のような計算の知識は使わない。

大問3 (1)①② 温度が上がると抵抗はどう変わるか 資料問題・グラフの曲がり方

👀 まず見るところ

【資料問題】部品はグラフの正体「電圧と電流・●豆電球／■LED」と設問の「流れる電流が大きくなるほど温度が上がります」。「温度が上がる」をグラフの右側に直して書く → 右へ行くほど電流がふえにくい（①）か、ふえやすい（②）かで決まる。

📚 前提知識

  • 抵抗＝電流の流れにくさ。同じだけ電圧を上げたのに電流がふえにくくなる＝抵抗が大きくなった、ふえやすくなる＝抵抗が小さくなった。
  • 抵抗が変わらなければ、電圧が2倍・3倍になると電流も2倍・3倍になり、点はまっすぐな線に並ぶ。

🔍 こう読み解く

  1. ①豆電球：0.5Vで0.1A。電圧を2倍の1Vにしても、電流は0.2Aにとどかない。3倍の1.5Vでも0.2Aくらいで、2倍3倍より小さい（解答冊子）→ 流れにくくなっている。
  2. ②LED：0.5Vあたりまではほぼ0A。そこから先は電圧を少し上げるだけで電流が大きく上がる（1Vで0.1A）→ 豆電球とは逆に、流れやすくなっている。
答え：① 大きくなる　② 小さくなる
自分で解くときのチェック：点の並びが右へ行くほど「ねてくる」なら抵抗は大きくなる、「立ってくる」なら小さくなる。①と②で向きが逆になることを両方セットで確かめる。

大問3 (2) 同じ豆電球2個と1.5Vの乾電池 まざり型・条件からグラフを読む

👀 まず見るところ

【まざり型→資料問題】部品は「同じ豆電球」「2つの電圧計の値を足すと1.5V」。同じものが2個なので、1個あたり 1.5÷2＝0.75V に直して図3の電圧計の横に書く → 図2の●で0.75Vの点を読めば決まる。

📚 前提知識

  • 図3は豆電球2個が1本道につながっている。「2つの豆電球に同じ強さの電流が流れ」とあるので、豆電球1個の電流＝電流計の値。
  • 同じ豆電球に同じ電流が流れているなら、かかる電圧も同じ。だから1.5Vは半分ずつに分かれる。

🔍 こう読み解く

  1. 豆電球1個の電圧：1.5÷2＝0.75V（解答冊子）。
  2. 図2のよこ軸は1目もり0.05V。0.5Vから5目もり右が0.75V。
  3. そこの●の高さを読む。たて軸は1目もり0.01Aで、0.1Aから4目もり上＝0.14A。
答え：0.14A
自分で解くときのチェック：1.5Vの点（約0.2A）を読んで半分にしない。グラフがまっすぐでないので、先に電圧を半分にしてから読む。

大問3 (3) 豆電球とLEDと1.5Vの乾電池 まざり型・条件に合う点をさがす

👀 まず見るところ

【まざり型→資料問題】部品は「豆電球とLEDに同じ強さの電流」「足すと1.5V」と、(2)から変わった言葉「LED」。今度は半分ずつにならない。同じ高さの●と■に丸をつけ、よこ軸の値を足して1.5Vになる高さをさがす。

📚 前提知識

  • 同じ強さの電流＝図2で同じ高さ（よこ1本の線の上）にある●と■の組。
  • 豆電球とLEDは電流の流れ方がちがうので、同じ電流でもかかる電圧はちがう。(2)のように 1.5÷2 はできない。

🔍 こう読み解く

  1. 目もりの数字がついている 0.1A の線でためす。●（豆電球）は0.5V、■（LED）は1V。
  2. 0.5＋1＝1.5V。条件にぴったり合う（解答冊子：電圧の和が1.5Vになる電流の大きさをグラフから探す）。
  3. たしかめ：もっと大きい電流では●も■も右にずれるので、和は1.5Vをこえる。合うのは0.1Aだけ。
答え：0.1A
自分で解くときのチェック：「さがす」問題は、0.1Aや0.2Aのような読みやすい線から先にためす。合わなければ、和が大きすぎるか小さすぎるかを見て上下にずらす。

大問3 まとめ 未解答（自分で解くとき用）

  • グラフを読む前に、目もりの正体「よこ0.05V・たて0.01A」を余白に書く。
  • (2)は同じもの2個＝電圧を半分にしてから読む。(3)はちがうもの2個＝同じ高さの2点の電圧を足して1.5Vになる所をさがす。変わった言葉は「LED」の1語。
  • 抵抗の大小は、点の並びがねてくる（大きくなる）か立ってくる（小さくなる）かで決める。
