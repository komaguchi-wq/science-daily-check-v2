大問1 (1) 35%の濃塩酸を3%にうすめる 条件文・濃度の計算

👀 まず見るところ

【条件文】部品は求めるもの「濃塩酸は何㎤」に丸と、「35%」「1㎤あたり1.2g」「3%の塩酸700g」。㎤で聞かれているのに濃度は g の話なので、「1㎤＝1.2g＝塩化水素0.42g」と直して書く → 必要な塩化水素の重さ÷0.42 で㎤が決まる。

📚 前提知識

  • 水でうすめても、とけている塩化水素の重さは変わらない。だから「うすい塩酸に入っている塩化水素」＝「濃塩酸から持ってくる塩化水素」。
  • 質量%濃度は重さの割合。体積（㎤）で聞かれたら、「1㎤あたり○g」で先に重さへ直す（または最後に重さから㎤へもどす）。

🔍 こう読み解く

  1. うすい塩酸700gの中の塩化水素：700×0.03＝21g。これが必要な塩化水素の全部。
  2. 濃塩酸1㎤の中の塩化水素：1.2×0.35＝0.42g。
  3. 21÷0.42＝50㎤（解答冊子：21÷0.42＝50）。
答え：50㎤
今回：50 ○（40点）。筆算は「21g／700g」と書いて一度×をつけてやり直し、「21g×100/35×5/6＝50」で出している。これは 21÷0.35（塩化水素21gをふくむ濃塩酸の重さ60g）→÷1.2（㎤に直す）と同じ道すじで、解答冊子とは順番がちがうだけ。㎤と g の橋を自分で2回かけ直せている。
コツ：「1㎤あたり1.2g」は、㎤と g を行き来する橋。式を書く前に「濃塩酸1㎤＝1.2g＝塩化水素0.42g」と1行置くと、どちらの順でも迷わない。

大問1 (2) 100枚の葉が30日で減らす二酸化炭素 条件文・割合と単位の計算

👀 まず見るところ

【条件文】部品は求めるもの「30日で何kg」に丸と、「3L分」「3.0%→1.8%」「30分後に」「100枚」「1日あたり10時間」「1Lあたり2g」。「30分で1.2%減」は1時間なら2.4%に直して書く → 1時間で減る体積（L）→重さ（g）→×100枚×10時間×30日→÷1000 でkg、と単位の橋が4本決まる。酸素の数字は使わない。

📚 前提知識

  • 光合成で減るのは二酸化炭素。袋の中の「%」は3Lのうちの割合なので、減った体積は 3L×（減った%）で出す。
  • 「1Lあたり2g」は体積→重さの橋。「ただし」のあとの数字は、最後の一歩で使う部品。

🔍 こう読み解く

  1. 30分で 3.0−1.8＝1.2% 減 → 1時間なら ×2 で 2.4%。
  2. 1時間に減る二酸化炭素：3×2.4÷100＝0.072L → 重さは 2×0.072＝0.144g（葉1枚・1時間）。
  3. 0.144×100枚×10時間×30日＝4320g → ÷1000＝4.32kg（解答冊子：0.144×100×10×30÷1000＝4.32）。
答え：4.32kg
今回：4.32 ○（30点）。筆算は「3L×12/1000×600×2＝43.2」→「43.2×100×1/1000＝4.32」。10時間×30日＝300時間を「300h×1/2h」で30分が600回に直し、30分あたり1.2%のまま掛けている。解答冊子の「1時間で2.4%」と形はちがうが、「30分→何回分か」を先に紙に置いた正しい直し方。

大問1 (3) 細菌が1個→2個に分かれる時間 条件文・倍々の回数

👀 まず見るところ

【条件文】部品は求めるもの「1個が2個に分かれるのにかかる時間」に丸と、「決まった時間間隔で1個が2個に」「4000個」「12時間」「256000個」。「4000→256000」は256000÷4000＝64倍に直して書き、64を 2×2×2… に分ける → 分かれた回数が決まり、12時間÷回数で答えになる。

📚 前提知識

  • 1個が2個に分かれるので、1回ごとに全体が2倍になる。n回なら 2をn回かける（2、4、8、16、32、64…）。
  • 聞かれているのは「1回分の時間」。全体の時間÷回数、で出す。

🔍 こう読み解く

  1. 256000÷4000＝64倍に増えた。
  2. 2→4→8→16→32→64 と数えると、2を6回かけて64。つまり12時間で6回分かれた（解答冊子：(2×2×2×…)＝64 で6回）。
  3. 12÷6＝2時間。
答え：2時間
今回：2時間 ○（30点）。筆算は「×64 → ×2⁶ → 12÷6＝2」。64倍を先に出して2の個数に直す、という解答冊子と同じ道すじ。余白の「2⁸」は256000の256から2の8乗を考えた跡と見えるが、4000で割ってから6回に直せている。
コツ：「何倍になったか」を先に1つの数にしてから、2で何回割れるかを数える。256000をそのまま2で割り始めると回数がずれる。

大問1 まとめ 100／100点

  • 3問とも、問題文の数字に丸をつけてから「直した形」を式のとなりに置いている：(1)「1㎤＝1.2g」の橋／(2)「300時間＝30分が600回」／(3)「256000÷4000＝64＝2⁶」。設計カードの手順が紙に残る答案だった。
  • 次に同じ型が出たら、(2)の「ただし 1Lあたり2g」のような「ただし」のあとの部品に先に丸をつける。最後に使う橋を忘れるのが、この型の一番多い落とし方。
  • 覚え直しはこの2つ：うすめても とけているものの重さは同じ／1個→2個は「何倍か」を先に出して2の個数を数える。

YR-03 大問2（ベン図の読み取り・正誤選択と7種類の生き物の数）

大問2 全体像 資料問題（ベン図） 2問（各50点・100点）

3つの円 A（水の中で生活する時期がある）・B（からだが外骨格）・C（親と子で姿形が大きく異なる）のベン図に、7種類の生き物の「捕まえた数」が1区分ずつ置かれている。入口は問題文の1行、「各区分はそれぞれ1つの種類の生き物の数」。これを読めば、(1)は足し算だけ、(2)は生き物1種類ごとに A・B・C の○×を3つ決めるだけ、と見通しが立つ。

(1)は知識がなくても決まる。(2)は3つの条件に生き物の知識を当てはめる問題で、○×の組み合わせが区分を1つに決める。今回は(1)○・(2)×で 50/100。(2)はトンボとザリガニの数だけが入れかわっていた。

大問2 (1) ベン図の数字の正誤 資料問題・正しいものをすべて

👀 まず見るところ

【資料問題】部品は資料の正体「7種類の生き物をA〜Cの条件で仲間分け・○の数字＝捕まえた数・×＝いない」を1行で書き、聞かれ方「正しいと判断できるものをすべて」に線。ア〜エは全部ベン図の数字だけで○×がつく。生き物の知識はいらない。

📚 前提知識（あれば答え合わせに使う）

  • 「Aの条件を満たす」＝Aの円の中ぜんぶ。重なりの区分もAに入る。「少なくとも2つの条件」＝円が重なっている区分。
  • 「Cは満たすがAとBは満たさない」＝Cの円のうち、ほかの円と重なっていない部分。ここが×なら「いなかった」。

🔍 こう読み解く

  1. ア 合計：1＋2＋3＋4＋5＋6＋7＝28。29ではない → ×。
  2. イ 2つ以上の条件＝重なりの区分 ①②③⑤：1＋2＋3＋5＝11。10ではない → ×。
  3. ウ A＝6＋5＋3＋1＝15、B＝4＋5＋2＋1＝12。Aのほうが大きい → ×。
  4. エ Cだけの区分は「×」＝いなかった → ○。4つ全部に○×をつけて、答えはエだけ。
答え：エ
今回：エ ○。余白に薄く「15」「12」「28」と読める数字があり、ウ・アを足し算で消してから選んだ形（薄いので断定はしない）。
コツ：「すべて選びなさい」は、1つ見つけても止まらず4つ全部に○×。ア・イは合計、ウは円ごとの合計、エは1区分、と見る場所がちがう。

大問2 (2) 7種類の生き物の数 資料問題＋知識・数で答える

👀 まず見るところ

【資料問題】部品は正体「各区分はそれぞれ1つの種類の生き物の数」（8区分に7種類＋×が1つずつ）と、A〜Cの条件の3語「水の中・外骨格・姿形が異なる」。7つの名前の横に A・B・Cの○×を3つ書く（3語で書く）→ ○×の組み合わせが区分を1つに決める。

📚 前提知識

  • A「水の中で生活する時期がある」：メダカ（一生）・カエル（おたまじゃくし）・トンボ（幼虫のヤゴ）・ザリガニ。ミミズ・チョウ・クモは水の中では生活しない。
  • B「からだが外骨格でおおわれている」：昆虫（トンボ・チョウ）・クモ・ザリガニ。からだの外側がかたい殻で、脱皮して大きくなる仲間。ミミズ・カエル・メダカは外骨格ではない。
  • C「親と子で大きく姿形が異なる」：カエル（おたまじゃくし→カエル）・チョウ（幼虫→さなぎ→成虫）・トンボ（ヤゴ→成虫）。ザリガニの子は親を小さくした形で、メダカやクモも同じ。

🔍 こう読み解く

  1. 条件が1つもない生き物 → ⑦の区分（円の外）。ミミズ＝7。
  2. 条件が1つだけ：メダカ＝Aだけ→⑥＝6。クモ＝Bだけ→④＝4。Cだけ（親と子で姿がちがうのに、水にも入らず外骨格でもない）はいないので「×」。
  3. 条件が2つ：ザリガニ＝A・B→⑤＝5。カエル＝A・C→③＝3。チョウ＝B・C→②＝2。
  4. 条件が3つそろうのはトンボだけ（ヤゴは水の中・外骨格・姿が変わる）→①＝1。7種類で7つの区分が1回ずつ埋まり、×だけが残れば確かめ終わり。
答え：ミミズ 7　トンボ 1　カエル 3　メダカ 6　チョウ 2　クモ 4　ザリガニ 5
今回：トンボ 5・ザリガニ 1 ×（ほかの5種は一致）。数のうえでは、Cの「親と子で大きく姿形が異なる」をトンボ×・ザリガニ○としたのと同じ。トンボはヤゴ→成虫で姿が変わり、ザリガニの子は親と同じ形。名前の下の△□の記号の意味は紙面に書かれていないので、ここは断定しない。次は名前の横に A・B・C の○×を3つ並べ、○○○が1つだけ（①）になるかを見てから数字を写す。
コツ：水の中にいる4種（トンボ・カエル・メダカ・ザリガニ）に○をつけた所までは合っていた。そのあとは1種類につき3つの○×を書き終えてから区分を探す。頭の中で2つの条件をまとめて判断しない。

大問2 まとめ 1/2 正解・50点

  • (1)は「各区分＝1種類」「×＝いない」を正体として書けば、足し算だけで4つ全部に○×がつく。知識はいらない。
  • (2)の落とし穴はC。トンボはヤゴ→成虫で姿が変わる（C○）、ザリガニの子は親と同じ形（C×）。この1組を直せば①と⑤が入れかわる。
  • 解き直しは、名前の横に A・B・C の○×を3つ書く表を作り、○の数（0・1・2・3個）で区分をたどる。○○○が1種類・×××が1種類・Cだけが「×」になれば合っている。

YR-03 大問3（タンポポの高さAと花茎の長さBのグラフ＝倒れて起き上がる花茎）

大問3 全体像 タンポポのグラフ 記号1問＋記述3問（各25点）

図1のA＝地面から頭花のつけねまでの高さ、B＝花茎そのものの長さ。この2本が同じなら花茎はまっすぐ立っていて、Aだけ小さければ花茎は倒れている。図2と図3を同じ日付で縦に見比べるのが入口で、(1)〜(4)は全部ここから決まる。

グラフが語る物語は1本。5/5に開花（A＝B＝15cm）→ 5/8に花茎が倒れる（A＝0、Bは15のまま）→ 5/11から起き上がりながら花茎が伸びる → 5/18に綿毛をつけ、30cmに伸びた花茎で25cmの高さに立つ。知識で足すのは「倒れたあとに起き上がるのは綿毛をつけたとき」と「セイヨウタンポポは受粉しなくても種子ができる」の2つだけ。

大問3 (1) 図2と図3の説明で正しいもの 資料問題・すべて選ぶ

👀 まず見るところ

【資料問題】部品は2つのグラフの正体「A＝地面から頭花のつけねまでの高さ」「B＝花茎の長さ」（単位cm・4/30〜5/21）と、聞かれ方「正しいものをすべて」。正体を1行書く → AとBが同じ日に同じ値なら「まっすぐ立っている」、Aだけ小さいなら「倒れている」と読み替えられる。

📚 前提知識（あれば答え合わせに使う）

  • 花茎が地面に対して垂直に立っていれば、頭花の高さ＝花茎の長さ（A＝B）。倒れればAはBより小さくなり、地面につけばA＝0。長さBは倒れても変わらない。
  • 「枯れた」なら花茎の長さも増えない。Bがそのまま残っていて、あとで伸びるなら生きている。

🔍 こう読み解く

  1. ア「開花まで垂直」→ 4/30〜5/5は図2も図3も 2.5→15cm と同じ形。A＝Bなので垂直 → ○。
  2. イ「5/8に枯れた」→ 図2のAは0cmだが、図3のBは15cmのまま。長さが残っているので倒れただけ → ×。
  3. ウ「5/11以降、長さは変わらず起き上がった」→ 後半の「起き上がった」はAが0→25で合っているが、前半は図3で Bが15→30cmに伸びている → ×。
  4. エ「開花時と5/18で長さが2倍」→ 図3で開花時15cm、5/18は30cm → ○。
答え：ア・エ
自分で解くときのチェック：4つ全部に○×をつけてから答えを書く。ウは後半だけ読むと○にしたくなるので、文を「／」で前半・後半に切り、両方を図3・図2で確かめる。

大問3 (2) 5月18日の頭花の様子 記述・25点

👀 まず見るところ

【まざり型→資料問題】設問の部品は「5月5日と5月18日」「色や形などまったく違う」に丸。図2で5/5は開花、5/18は一度倒れてから再び25cmで立った日 → 開花のあとに起き上がるタンポポの姿は綿毛、と決まる。

📚 前提知識

  • タンポポは開花のあと花を閉じ、花茎を倒して種子を育てる。種子が実ると、綿毛（白い冠毛）をつけた頭花で再び花茎を立てる（解答冊子「綿毛をつけた状態で再び起き上がります」）。
  • 黄色い花（5/5）と白い綿毛（5/18）は、色も形もまったく違う。

✍️ 答案の組み立て

  1. 要素：頭花が綿毛をつけている状態。
  2. 「簡単に説明」なので1文でよい。「白い綿毛」「種子に綿毛がついている」と書いても同じ内容。
模範解答：綿毛をつけている状態。
自分で解くときのチェック：「倒れている」「高くなっている」は花茎の話で、設問が聞いているのは頭花の様子。設問の「頭花」に丸をつけてから書く。

大問3 (3) 5月18日以降の状態の利点 記述・25点

👀 まず見るところ

【まざり型→資料問題】設問の部品は「タンポポにとってどのような利点」と「図2のグラフを参考に」に丸。図2の5/18は開花時の15cmより高い25cm → 綿毛を高い所に持ち上げる利点＝風で種子を遠くへ飛ばせる、と決まる。

📚 前提知識

  • タンポポの種子は綿毛で風に運ばれる。高い位置から放すほど風を受けやすく、遠くまで飛ぶ（解答冊子「種子を風で飛ばすために…再び起き上がります」）。
  • 遠くに散らばれば、親のそばで日光や養分を取り合わずに済む。利点を「種子を遠くへ」までで止めてよい。

✍️ 答案の組み立て

  1. 要素A（手段）：風によって種子を飛ばす。
  2. 要素B（利点）：より遠くまで飛ばすことができる。図2で開花時15cm→5/18は25cm、と高さが上がっているのが根拠。
模範解答：風によって種子をより遠くまで飛ばすことができる。
自分で解くときのチェック：「図2を参考に」と言われたら、答案に図2から読んだこと（高さが上がった）が反映されているか。「風」と「遠く」の2語がそろって初めて利点になる。

大問3 (4) 昆虫なしで種子ができることの証明 記述・25点・実験の設計

👀 まず見るところ

【まざり型→条件文】部品は「いつ、どのようなことを」「昆虫の助けがなくても」「移動させてはいけません」に丸。昆虫が来るのは花が開いている時なので、「いつ」＝図2の5/5の開花より前、「何を」＝つぼみに袋をかぶせて昆虫を入れない、と決まる。

📚 前提知識

  • ふつうの花は昆虫が花粉を運んで受粉し、種子ができる。セイヨウタンポポは受粉しなくても種子を作れる（解答冊子）。これを確かめるには「昆虫が来られない状態で種子ができるか」を見ればよい。
  • 移動させてはいけない＝部屋の中や虫のいない場所へ運ぶ方法は使えない。その場で昆虫を防ぐ道具が袋。

✍️ 答案の組み立て

  1. 要素A（いつ）：5月5日の開花より前、つぼみのうちに。開いてからでは昆虫がもう来ているかもしれない。
  2. 要素B（何を）：昆虫が入らないように袋をかぶせる。移動させずに昆虫だけを防ぐ。
  3. 要素C（確かめること）：それでも種子ができることを確認する。証明の文は「〜しても、〜できる」の形で結ぶ。
模範解答：5月5日の開花より前のつぼみに昆虫が入らないように袋をかぶせても、種子ができることを確認する。
