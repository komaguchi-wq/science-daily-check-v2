大問1 (1) 酸素の重さは空気の何倍 条件文・比の計算

👀 まず見るところ

【条件文】部品は「窒素80%、酸素20%」と「重さの比が7：8」、答え方「小数第2位まで」に丸。体積の比を 窒素4：酸素1 に直して書く → 同じ体積5ぶんの重さ（空気36・酸素40）で比べれば決まる。

📚 前提知識

  • 体積%濃度が80%と20%なら、空気5ぶんのうち窒素が4、酸素が1。「空気の体積は窒素と酸素の体積の和」というただし書きは、この分け方をしてよいという意味。
  • 「同体積で比べる」ので、空気も酸素も同じ体積5ぶんにそろえてから重さを出す。

🔍 こう読み解く

  1. 空気5ぶんの重さ：窒素 7×4＝28、酸素 8×1＝8。合わせて 36。
  2. 酸素だけで5ぶんの重さ：8×5＝40。
  3. 40÷36＝1.111…（解答冊子：(⑧×❺)÷(⑦×❹＋⑧×❶)）。小数第3位を四捨五入して 1.11。
答え：1.11倍
今回：1.11 ○。余白に「4：1」「7：8」をたてにならべて「28：8」と書き、そのあと 40/36 を 10/9 に約分している。体積の比と重さの比を紙の上でかけ合わせてから割る、という置き方ができていた。

大問1 (2) 何年後にインドネシアの森林が消えるか まざり型・グラフの数字で計算

👀 まず見るところ

【まざり型→条件文】部品はグラフの吹き出し「2000年 7（百万トン）」「2010年 21（百万トン）」と「250万トン増産するために100万ヘクタール」。単位を万トンにそろえ、1年に消える森林の広さに直して書く → 9400万ヘクタールをそれで割る。

📚 前提知識

  • グラフのたて軸は「百万トン」。7百万トン＝700万トン、21百万トン＝2100万トン。問題文の「250万トン」と単位をそろえてから使う。
  • 「2000〜2010年までの増加の割合で」＝この10年と同じペースで毎年増やし続ける、という仮定。増やしたぶんだけ森林を切り開く。

🔍 こう読み解く

  1. 1年あたりの増え方：(2100万トン−700万トン)÷10年＝140万トン。
  2. 1年に切り開く森林：250万トンで100万ヘクタールなので、100÷250×140＝56万ヘクタール。
  3. 森林がなくなるまで：9400÷56＝167.8…。小数第1位を四捨五入して 168。
答え：168年後
自分で解くときのチェック：21÷7 や 21−7 のまま進めず、先に「百万トン→万トン」に直す。使う森林面積は吹き出しの数でなく、本文の「約9400万ヘクタール」。

大問1 (3) 地殻をつくる岩石の密度 条件文・単位をそろえる計算

👀 まず見るところ

【条件文】部品は「1km増すごとに320気圧」「1気圧は高さ10m分の水の圧力」「水の密度は1g/cm³」。底面1cm²の柱を図にかき、水10m＝1000g、岩石1km＝320000g と重さに直して書く → 岩石の柱の体積で割れば決まる。

📚 前提知識

  • 圧力は、上にのっているものの重さで決まる。底面が1cm²の柱で考えると、高さ（cm）がそのまま体積（cm³）になるので計算しやすい。
  • 密度＝重さ÷体積。水は1cm³が1gなので、高さ10m＝1000cmの水の柱は1000g。

🔍 こう読み解く

  1. 1気圧＝水10mぶん＝1cm²あたり1000gの力。
  2. 320気圧＝1000g×320＝320000g。これが岩石1kmぶんの柱の重さ。
  3. 岩石の柱の体積：1km＝100000cm なので 100000cm×1cm²＝100000cm³。
  4. 320000g÷100000cm³＝3.2g/cm³。
答え：3.2g/cm³
自分で解くときのチェック：320気圧は水なら 10m×320＝3200mぶん。同じ圧力を岩石は1000mで出すので、3200÷1000＝3.2倍重い、とたしかめられる。mとkmとcmをまぜたまま割らない。

大問1 まとめ (1)○・(2)(3)は未解答

  • (1)でできた「比をたてにならべて書いてから計算する」置き方を、(2)(3)でもそのまま使う。
  • (2)は「百万トン→万トン」、(3)は「km・m→cm」。単位をそろえる1行を式の前に書く。
  • 答え方の指示（小数第2位まで・整数で）は、答えを書く直前にもう一度見る。

大問2 (1) 容器3・容器5に残っている球●の重さ まざり型・表の変わり目をさがす

👀 まず見るところ

【まざり型→資料問題】部品は表の正体「入れた●の重さ／できたかたまりの重さ・g」と、右はしの「68・68」。容器1の 17−9＝8 を表の下に書く → かたまりが17の何倍かを見れば、●が全部使われたか余ったかが決まる。

📚 前提知識

  • 「いちどかたまりになると、もう他の球を引きつけることはない」ので、相手がいなくなった球はそのまま残る。

🔍 こう読み解く

  3. 68gのかたまりに入っている●は、容器4と同じ36g。残りは 45−36＝9g。

自分で解くときのチェック：表の数が「同じ倍で増えているところ」と「増えなくなったところ」の間に線を引く。線の右側だけ、余りが出ている。

YR-13 大問3（手回し発電機とモーター・コンデンサー）

大問3 全体像 条件文の読み取り 4問（各25点）

リード文にある決まりは3つだけ。①時計回りにまわすと、電流は黒い端子→白い端子（図1・発電機として）。②電流が白い端子→黒い端子のとき、時計回りに回転（図2・モーターとして）。③手応えは電流が大きいほど大きい。

4問とも、この3つを図に矢印で書きこめば決まる。「→」は、発電機の外の導線をたどった向きを表している。図1は「黒い端子から出て、豆電球を通り、白い端子にもどる」向き。図2は「白い端子から出て、乾電池を通り、黒い端子にもどる」向き＝電流は乾電池の＋極から黒い端子に入っている。

大問3 (1) G1を時計回りにまわすとG2は まざり型・図に電流の矢印を書く

👀 まず見るところ

【まざり型→条件文】部品は「時計回りにまわすと、電流は黒い端子→白い端子」と図3の導線のつなぎ方。G1の黒い端子から矢印をかき、導線を指でたどる → G2に入る端子が図2と逆なので、回る向きも逆に決まる。

📚 前提知識

  • 図2で時計回りに回るのは、電流が黒い端子から入り、白い端子から出るとき。入る端子が逆になれば、回る向きも逆になる。
  • 図3では、G1が電流を出す側（発電機）、G2が電流をもらって回る側（モーター）。

🔍 こう読み解く

  1. G1を時計回りにまわす → 決まり①より、電流はG1の黒い端子から出る。
  2. 図3の導線をたどると、G1の黒い端子の先はG2の白い端子。G2には白い端子から電流が入り、黒い端子から出ていく。
  3. 図2とは入る端子が逆（解答冊子：図2と比べると電流の向きが逆）→ G2は反時計回りにまわる。
答え：ウ
自分で解くときのチェック：図3の2本の導線は、ならんで曲がっているので取りちがえやすい。1本ずつ色をぬるか指でたどって、どの端子とどの端子がつながるかを書く。

大問3 (2) G2を反時計回りに変えたときの手応え 条件文・電流の大小で決める

👀 まず見るところ

【条件文】部品は「手応えは、流れる電流が大きいほど大きく」と、前と変わった言葉「G2を反時計回りに」に丸。手応えを「電流の大きさ」に直して書く → 2台が電流を同じ向きに流すか、打ち消し合うかで決まる。

📚 前提知識

  • (1)より、G1を時計回りにまわすと、G2を反時計回りに回す向きの電流が流れる。G2を手で時計回りにまわすと、G2自身も電流を流す発電機になる。
  • 2台の流そうとする電流が同じ向きなら大きくなり、逆向きなら打ち消し合う。

🔍 こう読み解く

  1. 変える前（どちらも時計回り）：2台が同じ向きに電流を流そうとする → 電流が大きい → 手応えは大きい（解答冊子）。
  2. 変えたあと（G2だけ反時計回り）：G2の流そうとする向きが逆になり、G1と打ち消し合う。同じ速さなので電流が流れない（解答冊子）。
  3. 電流が大きい→流れない、に変わったので、手応えは小さくなる。
答え：ウ
自分で解くときのチェック：「反対向きにまわすほうが重そう」という感じで選ばない。聞かれているのは手応え＝電流の大きさ。変える前と後の両方について、電流が大きいか小さいかを書いてから比べる。

大問3 (3) G2を手で止めるとG1は 条件文・電流の大小で決める

👀 まず見るところ

【条件文】部品は「図2よりも遅く回転」と「G2のハンドルがまわっているのを手で止める」。図4に電流の通り道を1本の線でかく → G1とG2は同じ電流が通る1本道。G2を止めて電流が大きくなるか小さくなるかで、G1の速さが決まる。

📚 前提知識

  • 図4は、乾電池→G2→G1→乾電池と、電流の通り道が1本。G2を止めても、電流はG2の中を通ってG1に流れる。
  • まわっている手回し発電機（モーター）を手で止めると、電気が流れやすくなる（解答冊子）。まわっているモーターは発電機でもあり、乾電池の電流を押し返す向きにはたらいているから。

🔍 こう読み解く

  1. G2を止める → G2が電気を通しやすくなる。
  2. 1本道なので、回路全体に流れる電流が大きくなる。
  3. G1に流れる電流も大きくなる → G1の回転は速くなる。
答え：イ
自分で解くときのチェック：「G2を止めたからG1も止まる」としない。止めたのはハンドルで、電流の通り道は切れていない。

大問3 (4) コンデンサーにつないで手をはなすと 条件文・決まりを順に当てはめる

👀 まず見るところ

【条件文】部品は「乾電池のように使うことができ」と「蓄えたときに流した電流の向きと逆」。蓄えるときの向き（黒い端子→白い端子）を図5に書き、その逆（白い端子→黒い端子）を書き足す → 決まり②で回る向きが決まる。

📚 前提知識

  • 手をはなすと、G1は発電機からモーターに変わる。電流を出すのは、乾電池の代わりになったコンデンサー。
  • コンデンサーはたくわえた電気を出すだけで、新しく電気をつくらない。使うほど残りがへるので、流れる電流は小さくなっていくと考えられる。

🔍 こう読み解く

  1. 蓄えるとき：時計回りにまわしているので、決まり①より電流は黒い端子→白い端子。
  2. 手をはなしたあと：電流はその逆で、白い端子→黒い端子。乾電池をつないだ図2と同じ向きになる。
  3. 決まり②「白い端子→黒い端子のとき時計回りに回転」→ ハンドルは時計回りのまま回り続ける。反時計回りのイ・ウと、止まるアが消える。
  4. 残るのはエとオ。たくわえた電気は使うとへっていくので、回転はだんだん遅くなると考えられる → エでなくオ（解答冊子の答えはオ。考え方は冊子にのっていない）。
答え：オ
自分で解くときのチェック：「電流の向きが逆」を「回る向きが逆」と読みかえない。発電機のときとモーターのときでは、同じ時計回りでも電流の向きが逆（決まり①と②）なので、電流が逆になると回る向きは同じになる。

大問3 まとめ 未解答（自分で解くとき用）

  • 読みはじめに、決まり①②③を図1・図2の横に短く書く。①と②は、同じ時計回りで電流の向きが逆。
  • 回る向きの問題（(1)(4)）は、電流の矢印を図に書いてから決まり②に当てはめる。
  • 手応え・速さの問題（(2)(3)）は、「電流が大きくなるか小さくなるか」に直してから答える。
